# 1. 测试方法与登录页面测试设计

测试岗位面试里，“了解哪些测试手段”和“如何测试登录界面”通常考察的是测试思维：能否从功能、异常、安全、性能、兼容性和可观测性多个维度设计用例。

## 1. 常见测试方法

| 类型 | 关注点 | 例子 |
| --- | --- | --- |
| 单元测试 | 函数或类的局部逻辑 | 校验密码规则函数 |
| 集成测试 | 模块之间交互 | 登录服务调用用户中心、Redis、数据库 |
| 系统测试 | 完整系统行为 | 从页面输入账号密码到成功进入首页 |
| 回归测试 | 修改后旧功能是否受影响 | 修复验证码后重新跑登录主流程 |
| 冒烟测试 | 核心链路是否可用 | 部署后先测登录、首页、下单 |
| 性能测试 | QPS、延迟、吞吐、资源 | 登录接口压测、峰值并发 |
| 安全测试 | 权限、注入、暴力破解、泄露 | SQL 注入、XSS、CSRF、撞库 |
| 兼容性测试 | 浏览器、系统、设备 | Chrome、Safari、移动端 |
| 可用性测试 | 用户体验 | 错误提示是否清晰、Tab 顺序是否合理 |
| 接口测试 | API 协议和返回 | 登录接口参数、状态码、错误码 |
| UI 自动化 | 页面交互回归 | Selenium、Playwright、Appium |

按测试视角还可以分为黑盒、白盒和灰盒。黑盒关注输入输出，白盒关注代码路径和覆盖率，灰盒结合接口、日志、数据库状态和链路追踪。

## 2. 常见用例设计方法

1. **等价类划分**：把输入分为有效等价类和无效等价类，例如合法手机号、非法手机号。
2. **边界值分析**：测试长度边界、次数边界、金额边界，例如密码 7、8、32、33 位。
3. **判定表**：多条件组合，例如账号状态、密码正确性、验证码正确性。
4. **状态迁移**：账号从正常、锁定、冻结、注销等状态切换。
5. **正交/Pairwise**：多浏览器、多系统、多语言组合时减少用例数量。
6. **错误猜测**：基于经验补充容易出错的场景，例如空格、大小写、Unicode、重复提交。

## 3. 登录页面功能测试

基础功能：

1. 正确账号密码登录成功。
2. 错误密码登录失败，并给出合理错误提示。
3. 不存在账号、冻结账号、注销账号、锁定账号的处理。
4. 用户名、手机号、邮箱等不同登录方式。
5. 验证码、短信码、MFA、多因子认证流程。
6. 记住登录、自动登录、退出登录。
7. 忘记密码、重置密码、注册入口跳转。
8. 多次点击登录按钮、刷新页面、浏览器返回的行为。

输入校验：

1. 用户名为空、密码为空、前后空格。
2. 超长输入、特殊字符、中文、Emoji。
3. 密码大小写敏感。
4. 复制粘贴、自动填充、浏览器保存密码。

## 4. 登录页面安全测试

1. **传输安全**：登录页和接口必须使用 HTTPS，敏感参数不能出现在 URL。
2. **密码安全**：密码输入框脱敏，后端不明文存储密码，日志不打印密码。
3. **暴力破解防护**：账号维度、IP 维度、设备维度限流，必要时触发验证码或锁定。
4. **SQL 注入**：用户名、密码、验证码参数不能拼接 SQL。
5. **XSS**：错误提示、回跳地址、用户名展示要转义。
6. **CSRF**：修改状态类请求要有 CSRF token 或 SameSite Cookie。
7. **会话安全**：登录成功后更新 session id，Cookie 设置 `HttpOnly`、`Secure`、`SameSite`。
8. **越权访问**：未登录访问受保护页面应跳转登录，登录后只能访问自己的资源。
9. **错误提示**：避免明确提示“账号存在但密码错误”，降低账号枚举风险。

## 5. 性能、兼容性和可观测性

性能测试：

1. 登录接口峰值 QPS。
2. P95/P99 延迟。
3. 数据库、Redis、短信服务、风控服务耗时。
4. 大量失败登录时限流是否生效。

兼容性测试：

1. 主流浏览器和移动端适配。
2. 弱网、断网、接口超时。
3. 多语言、时区、输入法。

可观测性：

1. 登录成功率、失败原因分布。
2. 验证码触发率、短信发送成功率。
3. 风控拒绝率、账号锁定数量。
4. 日志中有 requestId/traceId，便于排查问题。

## 6. 易错点

1. 只测正确账号密码，不测异常状态和安全场景。
2. 只看页面提示，不校验后端 session、Cookie 和数据库状态。
3. 登录接口错误码过于详细，可能泄露账号是否存在。
4. 忽略重复提交和并发登录，导致 session 状态混乱。
5. 忽略第三方依赖失败，例如短信、风控、用户中心超时。

## 7. 面试回答模板

测试登录页面我会从功能、异常、安全、性能、兼容性和可观测性展开。功能上覆盖正确登录、错误密码、账号不存在、账号锁定、验证码、忘记密码、退出和自动登录；输入上覆盖空值、超长、特殊字符、空格、复制粘贴和浏览器自动填充；安全上重点看 HTTPS、密码脱敏、SQL 注入、XSS、CSRF、暴力破解限流、Cookie 安全属性和 session 固定攻击；性能上压测登录接口和依赖服务；兼容性上覆盖浏览器、移动端和弱网；最后用日志、指标和 traceId 保证问题可定位。
