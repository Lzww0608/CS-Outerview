# 3. 算法题测试样例设计

算法题测试的目标不是只跑一个示例，而是覆盖正常路径、边界、异常结构、重复数据和题目特有的不变量。面试里可以按“输入规模、边界值、结构形态、正确性校验、复杂度风险”来组织。

## 1. 通用思路

1. **空输入和最小输入**：空数组、空字符串、空链表、单节点。
2. **普通样例**：覆盖题目主流程，便于手算预期结果。
3. **边界值**：最大值、最小值、长度边界、进位、溢出、重复值。
4. **特殊结构**：链表有环、树退化成链、图不连通、重复边、自环。
5. **反例和非法输入**：如果题目允许，要验证函数能拒绝或安全处理。
6. **性能样例**：构造最坏情况，防止 `O(n^2)` 写法在大输入下超时。
7. **不变量校验**：不只看返回值，还要检查原数据是否被错误修改、新旧对象是否共享。

## 2. 链表深复制怎么测

链表深复制不能只打印值相同，还要验证指针结构和深拷贝语义。

用例：

1. `head = nullptr`。
2. 单节点无环：`1 -> null`。
3. 单节点自环：`1 -> 1`。
4. 多节点无环：`1 -> 2 -> 3 -> null`。
5. 尾节点指向中间节点：`1 -> 2 -> 3 -> 2`。
6. 双向链表：同时检查 `next` 和 `prev`。

校验点：

1. 新链表的值序列与原链表一致。
2. 新节点地址都不等于原节点地址。
3. 原链表中相同指针关系，在新链表中映射后仍然成立。
4. 修改新链表节点值或指针，不影响原链表。
5. 有环时遍历要限制步数或用 visited，避免测试代码自己死循环。

## 3. 字符串和滑动窗口题怎么测

无重复字符最长子串：

1. 空字符串：`"" -> 0`。
2. 全不重复：`"abc" -> 3`。
3. 全重复：`"aaaa" -> 1`。
4. 左边界不能回退：`"abba" -> 2`。
5. 普通样例：`"abcabcbb" -> 3`。
6. 如果支持 Unicode，要说明按字节还是按字符处理。

字符串相加：

1. `"0" + "0" -> "0"`。
2. `"9" + "1" -> "10"`。
3. `"999" + "1" -> "1000"`。
4. 长度不同：`"123" + "77" -> "200"`。
5. 超长数字：验证不能依赖 `long long`。
6. 前导零：根据题意确认输出 `"0012"` 还是 `"12"`。

## 4. 图和搜索题怎么测

BFS、Dijkstra、A* 这类题要同时测连通性和路径代价：

1. 起点等于终点。
2. 无路可达。
3. 多条最短路径。
4. 存在障碍或高权重边。
5. Dijkstra 中所有边权非负；如果有负权，应验证实现拒绝或改用 Bellman-Ford。
6. A* 的启发函数不能高估；可以用小图和 Dijkstra 结果对拍。

## 5. 面试回答模板

我设计测试样例会先覆盖空输入、最小输入、普通样例和边界值，再针对题目结构补特殊场景。比如链表深复制要测无环、有环、单节点自环、双向链表，并校验新旧节点地址不同、指针关系一致；字符串相加要测进位、长度不同、超长数字和前导零；图搜索要测不可达、多路径、边权和起终点相同。最后还会准备大规模样例验证复杂度，避免隐藏的死循环或 `O(n^2)`。
