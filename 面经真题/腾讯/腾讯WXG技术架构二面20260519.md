## 算法题

1. 两数之和。

2. 某一个大文件被拆成了 N 个小文件，每个小文件编号从 0 至 N-1，相应大小分别记为 S(i)。给定磁盘空间为 C，试实现一个函数从 N 个文件中连续选出若干个文件拷贝到磁盘中，使得磁盘剩余空间最小。

3. 40 亿个随机排列的 32 位整数，找出 X 是否存在于 40 亿个数中，内存 1GB。
   - 输入：第一行为总整数个数 N，后续 N 行每行一个整数，最后一行为目标 X。
   - 输出：如果在，则输出 1，否则输出 0。

4. 一个二维平面上有 n 个点，找出两两之间斜率最大的两个点。

5. 用尽量简洁的代码，实现一个单链表，支持添加、删除操作。并对该单链表实现一个接口，其功能是将该链表内容反转。
