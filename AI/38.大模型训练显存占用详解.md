# 38. 大模型训练显存占用详解

## 1. 问题背景

大模型训练的显存问题是最核心的工程挑战之一。理解显存占用的组成是进行显存优化的基础，也是选择训练策略的前提。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  显存占用组成：                                            │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 1. 模型参数 (Weights)                                │  │
│  │ 2. 梯度 (Gradients)                                 │  │
│  │ 3. 优化器状态 (Optimizer States)                   │  │
│  │ 4. 激活值 (Activations)                            │  │
│  │ 5. 临时缓冲区 (Temporary Buffers)                   │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| OOM 错误 | 训练过程显存不足 |
| Batch size 小 | 受限显存无法增大 |
| 训练不稳定 | 显存不足导致性能下降 |
| 分布式受限 | 无法使用多卡 |

---

## 3. 影响范围

- 所有大模型训练任务
- 模型选型和架构设计
- 训练策略制定
- 硬件采购决策

## 4. 原因分析

### 4.1 显存占用详细分解

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  显存占用公式：                                           │
│                                                             │
│  Total = Weights + Gradients + Optimizer + Activations + Buffers  │
│                                                             │
│  各部分详解：                                              │
│                                                             │
│  1. 模型参数 (Weights)                                     │
│     • 参数矩阵                                            │
│     • 偏置向量                                            │
│     • LayerNorm 参数                                      │
│     • Embedding 表                                        │
│                                                             │
│  2. 梯度 (Gradients)                                      │
│     • 与权重形状相同                                      │
│     • 反向传播计算                                        │
│                                                             │
│  3. 优化器状态 (Optimizer States)                         │
│     • Adam: m (一阶矩) + v (二阶矩)                      │
│     • SGD: momentum                                      │
│     • 每参数需要额外 2-4x 存储                           │
│                                                             │
│  4. 激活值 (Activations)                                   │
│     • 每层前向传播产生的中间结果                          │
│     • Q, K, V 矩阵                                        │
│     • Attention 矩阵 (SxS)                               │
│     • FFN 输出                                            │
│                                                             │
│  5. 临时缓冲区                                            │
│     • 注意力计算的临时张量                                │
│     • 融合算子的临时存储                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 各类参数显存计算

```python
# 显存计算示例

def calculate_model_memory(model, precision='fp32'):
    """计算模型参数量和显存"""
    
    # 精度字节数
    bytes_per_param = {
        'fp32': 4,
        'fp16': 2,
        'bf16': 2,
        'int8': 1
    }
    
    total_params = 0
    param_memory = {}
    
    for name, param in model.named_parameters():
        param_count = param.numel()
        total_params += param_count
        
        # 参数显存
        memory = param_count * bytes_per_param[precision]
        param_memory[name] = {
            'count': param_count,
            'bytes_fp32': param_count * 4,
            'bytes_current': memory
        }
    
    return {
        'total_params': total_params,
        'weights_fp32': total_params * 4,
        'weights_current': total_params * bytes_per_param[precision],
        'gradients': total_params * bytes_per_param[precision],
        'param_details': param_memory
    }

# Transformer 模型显存估算
def estimate_transformer_memory(
    vocab_size=50000,
    hidden_dim=4096,
    num_layers=32,
    num_heads=32,
    seq_len=2048,
    batch_size=4,
    precision='fp16'
):
    """
    Transformer 模型显存估算
    """
    
    # 精度字节数
    if precision == 'fp32':
        bytes_per_param = 4
    elif precision in ['fp16', 'bf16']:
        bytes_per_param = 2
    else:
        bytes_per_param = 1
    
    # 1. 模型参数 (Weights)
    # Embedding
    embedding_params = vocab_size * hidden_dim
    # Attention
    attention_params = 3 * hidden_dim * hidden_dim + hidden_dim  # QKV + bias
    # FFN
    ffn_params = 2 * hidden_dim * 4 * hidden_dim + hidden_dim * 4 + 4 * hidden_dim
    # LayerNorm
    ln_params = 2 * hidden_dim
    
    params_per_layer = attention_params + ffn_params + ln_params * 2
    total_params = embedding_params + num_layers * params_per_layer
    
    weights_memory = total_params * bytes_per_param
    
    # 2. 梯度 (Gradients) - 与参数相同形状
    gradients_memory = total_params * bytes_per_param
    
    # 3. 优化器状态 (Adam)
    # m + v = 2x 参数
    optimizer_memory = total_params * 4  # FP32 优化器状态
    
    # 4. 激活值 (Activations)
    # 每层激活值
    # Q, K, V: 3 * B * S * H
    qkv_memory = 3 * batch_size * seq_len * hidden_dim * 2  # fp16
    # Attention: B * H * S * S
    attention_memory = batch_size * num_heads * seq_len * seq_len * 2
    # FFN: B * S * 4H
    ffn_memory = batch_size * seq_len * 4 * hidden_dim * 2
    
    activations_per_layer = qkv_memory + attention_memory + ffn_memory
    total_activations = activations_per_layer * num_layers
    
    # 5. 临时缓冲区
    buffer_memory = batch_size * seq_len * hidden_dim * 4  # 估算
    
    total_memory = (weights_memory + gradients_memory + 
                   optimizer_memory + total_activations + buffer_memory)
    
    return {
        'weights': weights_memory / (1024**3),
        'gradients': gradients_memory / (1024**3),
        'optimizer': optimizer_memory / (1024**3),
        'activations': total_activations / (1024**3),
        'buffers': buffer_memory / (1024**3),
        'total': total_memory / (1024**3),
        'total_params': total_params
    }
```

### 5.3 显存估算工具

```python
# 显存估算工具

class MemoryEstimator:
    """训练显存估算器"""
    
    @staticmethod
    def estimate(
        model_params: int,
        batch_size: int,
        seq_len: int,
        hidden_dim: int,
        num_layers: int,
        precision: str = 'fp16',
        use_gradient_checkpointing: bool = False,
        use_optimizer: str = 'adamw',  # adamw, sgd
        zero_stage: int = 0
    ) -> dict:
        """
        估算训练显存
        """
        
        bytes_per_param = {'fp32': 4, 'fp16': 2, 'bf16': 2}[precision]
        
        # 1. 模型参数
        weights = model_params * bytes_per_param
        
        # 2. 梯度
        gradients = model_params * bytes_per_param
        
        # 3. 优化器状态
        if use_optimizer == 'adamw':
            # Adam: m + v = 2x FP32
            optimizer_mult = 4  # FP32 m, v
        elif use_optimizer == 'sgd':
            optimizer_mult = 4  # FP32 momentum
        else:
            optimizer_mult = 4
        optimizer = model_params * optimizer_mult
        
        # 4. 激活值（估算）
        # 简化估算：激活值 ≈ 34 * B * S * H * L
        activations = 34 * batch_size * seq_len * hidden_dim * num_layers * bytes_per_param
        
        if use_gradient_checkpointing:
            # 检查点减少激活值约 70%
            activations *= 0.3
        
        # 5. ZeRO 分片
        if zero_stage >= 1:
            optimizer /= 1  # 分片数取决于 GPU 数
        
        # 计算总显存
        total = weights + gradients + optimizer + activations
        
        # 分片后显存
        per_device = total
        if zero_stage >= 1:
            per_device = total / 1  # 假设 1 GPU
        
        return {
            'weights_gb': weights / (1024**3),
            'gradients_gb': gradients / (1024**3),
            'optimizer_gb': optimizer / (1024**3),
            'activations_gb': activations / (1024**3),
            'total_gb': total / (1024**3),
            'per_device_gb': per_device / (1024**3),
            'breakdown': {
                'weights': weights / total,
                'gradients': gradients / total,
                'optimizer': optimizer / total,
                'activations': activations / total
            }
        }
```

# 验证显存占用

def verify_memory_usage(model, dataloader):
    torch.cuda.reset_peak_memory_stats()
    
    model.train()
    for batch in dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        loss.backward()
        
        # 记录峰值显存
        peak_memory = torch.cuda.max_memory_allocated()
        print(f"Peak memory: {peak_memory / 1024**3:.2f} GB")
        
        model.zero_grad()
        break
    
    # 分析显存分布
    allocations = torch.cuda.memory_summary()
    print(allocations)

## 11. 总结

1. **显存组成**：参数 + 梯度 + 优化器 + 激活值
2. **优化器状态占大头**：Adam 需要 4x FP32 存储
3. **激活值次之**：Attention 矩阵占大部分
4. **混合精度**：节省 50% 显存
5. **ZeRO + Checkpoint**：可节省 80-90%
