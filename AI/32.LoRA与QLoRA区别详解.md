# LoRA 与 QLoRA 的区别详解

## 1. 问题背景

LoRA（Low-Rank Adaptation）和 QLoRA（Quantized LoRA）是 LLM 高效微调的两大主流方法。理解它们的区别对于选择合适的微调方案至关重要。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  核心对比：                                                 │
│                                                             │
│  LoRA：低秩适配，直接训练低秩矩阵                          │
│  QLoRA：量化 + LoRA，4-bit 量化 + LoRA                     │
│                                                             │
│  显存对比（7B 模型）：                                     │
│  LoRA：~14GB 显存                                         │
│  QLoRA：~5GB 显存                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 疑问 | 回答 |
|------|------|
| 哪个显存占用更低？ | QLoRA 更低 |
| 哪个训练速度更快？ | LoRA 更快 |
| 哪个效果更好？ | 相当（QLoRA 略低） |
| 如何选择？ | 资源有限选 QLoRA |

## 4. 原因分析

### 4.1 LoRA 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  LoRA 核心思想：                                           │
│                                                             │
│  冻结预训练权重 W0，只训练低秩矩阵 A 和 B                  │
│                                                             │
│  前向计算：                                                │
│  h = W0 · x + ΔW · x                                     │
│      = W0 · x + BA · x                                   │
│                                                             │
│  其中 B ∈ R^(d×r), A ∈ R^(r×k), r << min(d,k)           │
│                                                             │
│  训练参数：d×r + r×k，只占原参数的极小部分                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 QLoRA 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  QLoRA = Quantization + LoRA                              │
│                                                             │
│  核心步骤：                                                │
│  1. 4-bit NormalFloat (NF4) 量化预训练权重               │
│     • 权重从 FP16 量化到 4-bit                            │
│     • 使用 NF4 数据类型保持精度                           │
│                                                             │
│  2. LoRA 应用于量化权重                                   │
│     • LoRA 部分仍用 FP16                                  │
│     • 只训练 LoRA 参数                                    │
│                                                             │
│  3. 双重量化                                              │
│     • 对量化索引也做量化                                  │
│                                                             │
│  4. 分页优化器                                            │
│     • 处理显存峰值                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 核心区别对比

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  LoRA vs QLoRA 核心区别：                                 │
│                                                             │
│  ┌────────────┬─────────────────────────────────────────┐ │
│  │ 维度        │ LoRA          │ QLoRA                   │ │
│  ├────────────┼─────────────────────────────────────────┤ │
│  │ 预训练权重  │ FP16 全精度   │ 4-bit 量化             │ │
│  │ 显存占用    │ 较高          │ 极低                   │ │
│  │ 训练速度    │ 快            │ 较慢（反量化开销）     │ │
│  │ 精度损失    │ 无            │ 极小（可忽略）        │ │
│  │ 适用硬件    │ 16GB+ GPU     │ 8GB+ GPU              │ │
│  │ 实现复杂度  │ 简单          │ 较复杂                 │ │
│  └────────────┴─────────────────────────────────────────┘ │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 LoRA 实现

```python
import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    """
    LoRA 线性层实现
    """
    
    def __init__(self, in_features, out_features, rank=4, alpha=1.0):
        super().__init__()
        self.rank = rank
        self.alpha = alpha
        
        # 冻结原权重
        self.weight = nn.Parameter(
            torch.randn(out_features, in_features), 
            requires_grad=False
        )
        
        # LoRA 低秩矩阵
        self.lora_A = nn.Parameter(torch.randn(rank, in_features))
        self.lora_B = nn.Parameter(torch.zeros(out_features, rank))
        
        self.scale = alpha / rank
    
    def forward(self, x):
        # 原权重前向
        base_output = torch.nn.functional.linear(x, self.weight)
        
        # LoRA 前向
        lora_output = (self.lora_A @ self.lora_B) * self.scale
        lora_output = torch.nn.functional.linear(x, lora_output.t())
        
        return base_output + lora_output

# 使用示例
model = load_pretrained_model()
apply_lora(model, rank=4, alpha=8)
```

### 5.2 QLoRA 实现

```python
from transformers import BitsAndBytesConfig
from peft import get_peft_model, LoraConfig

# QLoRA 配置
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,                    # 4-bit 量化
    bnb_4bit_quant_type="nf4",           # NF4 数据类型
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True        # 双重量化
)

# 加载量化模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto"
)

# LoRA 配置
lora_config = LoraConfig(
    r=4,                                  # rank
    lora_alpha=8,                         # alpha
    target_modules=["q_proj", "v_proj"],  # 目标层
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

# 应用 LoRA
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# trainable params: 4,194,304 || all params: 6,738,415,616 || trainable%: 0.0622
```

### 5.3 显存对比计算

```python
def calculate_vram_usage():
    """
    7B 模型显存估算
    """
    
    # LoRA 显存估算
    lora_params = {
        "model_weights_fp16": 7 * 2 * 1e9 / 8,  # 14GB
        "optimizer_states": 7 * 2 * 4 * 1e9 / 8 * 2,  # ~56GB (Adam)
        "gradients": 7 * 2 * 4 * 1e9 / 8,  # ~28GB
        "activations": 4 * 2,  # ~8GB
        "total_lora": 14 + 56 + 28 + 8  # ~106GB
    }
    
    # QLoRA 显存估算
    qlora_params = {
        "model_weights_4bit": 7 * 0.5 * 1e9 / 8,  # ~3.5GB
        "optimizer_states": 7 * 0.5 * 4 * 1e9 / 8 * 2,  # ~14GB
        "gradients": 7 * 0.5 * 4 * 1e9 / 8,  # ~7GB
        "activations": 2,  # ~2GB
        "total_qlora": 3.5 + 14 + 7 + 2  # ~26.5GB
    }
    
    return lora_params, qlora_params
```

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |

## 11. 总结

1. **LoRA**：冻结原权重，只训练低秩矩阵 A 和 B，参数高效
2. **QLoRA**：在 LoRA 基础上对原权重做 4-bit 量化，显存减半
3. **显存对比**：7B 模型 LoRA ~14GB，QLoRA ~5GB
4. **选择建议**：资源充足用 LoRA，资源有限用 QLoRA
5. **核心差异**：QLoRA = 量化 + LoRA，以精度换显存
