# 17. Transformer 核心机制与残差连接

Transformer 是以注意力机制为核心的序列建模架构。面试里如果问“除了 Attention 还有什么创新”，要把它回答成一套可训练、可并行、可扩展的深层网络结构，而不是只说 `QK^T V`。

## 1. Transformer 的核心组件

以 Decoder-only 大语言模型为例，一层 Transformer 通常包含：

```text
token ids
  -> token embedding + position encoding
  -> masked self-attention
  -> residual connection + layer norm
  -> FFN / MLP
  -> residual connection + layer norm
  -> logits
```

核心组件：

1. **Token Embedding**：把离散 token 映射为连续向量。
2. **位置编码**：补充序列位置信息，例如绝对位置编码、RoPE、ALiBi。
3. **Self-Attention**：让每个 token 根据上下文动态聚合信息。
4. **Multi-Head Attention**：把表示空间拆成多个 head，学习不同关系。
5. **FFN/MLP**：对每个 token 独立做非线性变换，提升模型容量。
6. **Residual Connection**：让信息和梯度可以跨层直通。
7. **LayerNorm/RMSNorm**：稳定激活分布和训练过程。
8. **Mask**：在 Decoder 中屏蔽未来 token，保证自回归生成。

## 2. 除了 Attention 的关键创新

Transformer 的工程价值来自多个设计组合：

1. **并行训练**：相比 RNN 逐步递归，Transformer 训练时可以对一个序列内的 token 并行计算，大幅提升 GPU 利用率。
2. **位置编码解耦**：模型不依赖循环结构，通过位置编码表达顺序信息。
3. **残差连接和归一化**：支撑网络堆得很深，缓解梯度消失和训练不稳定。
4. **FFN 扩展容量**：每层注意力之后的 MLP 提供大量参数和非线性表达能力，LLM 中 FFN 通常占很大参数比例。
5. **Mask 机制**：同一套结构可以表达 Encoder 双向理解、Decoder 单向生成、Encoder-Decoder 交叉注意力。
6. **预训练范式**：通过大规模自监督任务学习通用表示，再微调或指令对齐到具体任务。

所以 Attention 是核心，但 Transformer 成功还依赖并行化、位置编码、残差、归一化、FFN、mask 和大规模预训练。

## 3. 残差连接的作用

残差连接把某一层输入 `x` 直接加到子层输出上：

```text
y = x + F(x)
```

它的作用：

1. **保留原始信息**：如果当前层学不到有用变换，至少可以近似走恒等映射。
2. **提供梯度捷径**：反向传播时梯度可以沿着加法分支直接回到浅层。
3. **降低深层退化问题**：网络变深后不至于因为每层都必须学习复杂变换而性能下降。
4. **帮助训练稳定**：配合 LayerNorm、合适初始化和学习率 warmup，深层 Transformer 更容易收敛。

从梯度角度看：

```text
y = x + F(x)
dL/dx = dL/dy * (1 + dF/dx)
```

即使 `dF/dx` 很小，仍然有一条系数接近 1 的路径把梯度传回去。这就是残差缓解梯度消失的关键。

## 4. Pre-Norm 和 Post-Norm

Transformer 中 LayerNorm 和残差的位置有两种常见写法。

Post-Norm：

```text
y = LayerNorm(x + Sublayer(x))
```

Pre-Norm：

```text
y = x + Sublayer(LayerNorm(x))
```

早期 Transformer 使用 Post-Norm，现代大模型常用 Pre-Norm 或 RMSNorm 变体。Pre-Norm 让残差路径更直接，深层训练更稳定，但最终表达和收敛细节还取决于初始化、学习率、深度和训练配方。

## 5. 易错点

1. Transformer 不是“只有 Attention”，FFN、残差、归一化、位置编码同样关键。
2. Self-Attention 本身不感知顺序，需要位置编码或相对位置机制。
3. 多头不是多个完整模型，而是在同一层里把 hidden size 拆成多个子空间并行计算。
4. 残差连接缓解梯度消失，不等于完全消除梯度爆炸；仍需要归一化、初始化和梯度裁剪等配套。
5. Decoder 的 causal mask 是为了防止训练时看到未来 token，否则生成任务会信息泄漏。

## 6. 真实场景

1. **大语言模型**：Decoder-only Transformer 通过 causal mask 做自回归生成。
2. **文本理解模型**：Encoder-only Transformer 使用双向 attention，例如分类、检索向量表示。
3. **翻译和摘要**：Encoder-Decoder Transformer 同时使用 encoder self-attention、decoder masked attention 和 cross-attention。
4. **长上下文推理**：注意力复杂度是 `O(T^2)`，工程上会引入 FlashAttention、GQA/MQA、滑动窗口、KV Cache、PagedAttention 等优化。

## 7. 面试回答模板

Transformer 的核心是 self-attention，它用 Q/K/V 让每个 token 动态关注上下文；但它的创新不只有 Attention，还包括位置编码、Multi-Head、残差连接、LayerNorm、FFN、mask 机制和并行训练。残差连接是 `y = x + F(x)`，既保留原始信息，也给梯度提供一条近似恒等的回传路径，`dL/dx = dL/dy * (1 + dF/dx)`，所以深层网络不容易因为多层导数连乘而梯度消失。现代大模型还会结合 Pre-Norm/RMSNorm、RoPE、KV Cache、FlashAttention、GQA/MQA 等工程优化来提升稳定性和推理效率。
