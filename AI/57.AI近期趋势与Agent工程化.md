# 57. AI 近期趋势与 Agent 工程化

面试里问“AI 最近的趋势是什么”，不要只回答某个模型名字。更稳的回答是把趋势拆成模型能力、应用形态、工程基础设施、评测治理和商业落地几层。

以下内容按 2026 年上半年的公开报告和产业动向整理，适合面试时作为回答框架。

## 1. Agent 从 Demo 走向生产系统

Agentic AI 是近两年最明显的应用趋势。它不再只是聊天框回答问题，而是让模型在权限边界内使用工具、访问数据、执行多步任务，并把过程纳入状态机、审批、Trace 和评测。

生产级 Agent 的关键变化：

1. 从单轮问答变成 `Plan -> Act -> Observe -> Verify` 的循环。
2. 从自然语言提示词变成结构化工具调用和工作流节点。
3. 从“模型觉得完成”变成外部系统可验证的结果。
4. 从单 Agent 自由执行变成 Workflow、Supervisor/Worker、HIL 审批和 Guardrail。
5. 从人工试用变成 Harness、回归集、线上 badcase 闭环。

真实场景：

1. 研发 Agent：读代码、改文件、跑测试、修 CI。
2. 数据 Agent：生成 SQL、查指标、解释异常，但要限制扫描量和权限。
3. 运维 Agent：聚合告警、日志、Trace 和 runbook，执行低风险修复。
4. 企业办公 Agent：跨 CRM、文档、工单、日历执行流程。

## 2. 多模态和长上下文成为基础能力

多模态能力从“看图问答”扩展到图像、视频、音频、屏幕操作和实时交互。对应用开发来说，重点不是模型能不能识别图片，而是如何把不同模态接入业务流程。

工程关注点：

1. 输入层要支持文本、图片、文件、截图、语音和视频片段。
2. 上下文层要区分原始文件、解析文本、视觉特征和引用位置。
3. 输出层要支持文本、结构化 JSON、图片、音频或操作指令。
4. 评测层要覆盖跨模态一致性，例如图片证据是否真的支持文本结论。

长上下文也在普及，但长上下文不等于可以无限塞资料。真实系统仍然要做上下文压缩、RAG、摘要、工具结果裁剪和 token 预算，否则成本、延迟和注意力稀释都会变成问题。

## 3. 推理成本和推理基础设施变成核心竞争力

模型能力提升后，线上应用的瓶颈经常变成延迟、吞吐、显存和成本。

常见优化方向：

1. **模型路由**：简单任务用小模型，复杂推理用强模型。
2. **缓存**：Prompt Cache、KV Cache、Embedding Cache、RAG 结果缓存。
3. **批处理**：连续批处理、动态 batching、异步队列。
4. **量化和蒸馏**：降低显存和推理成本。
5. **推理引擎**：vLLM、SGLang、TensorRT-LLM、Triton 等。
6. **端侧部署**：隐私、低延迟或离线场景使用小模型、量化模型和 NPU。

面试里可以强调：AI 应用不是“调一次模型 API”就结束，模型网关、限流、重试、降级、成本统计、token 预算和多模型路由都是后端系统的一部分。

## 4. Harness、评测和治理成为上线门槛

随着 AI 系统进入生产，评测从“看几个 demo”变成工程门禁。

趋势：

1. 离线评测集覆盖正常、失败、越权、长上下文和对抗样本。
2. Trace 记录模型输入、工具调用、观察结果、token、成本和最终答案。
3. 线上 badcase 脱敏后进入回归集。
4. LLM-as-Judge 只处理开放语义判断，安全、权限、格式和测试通过必须用确定性规则。
5. Prompt、工具 schema、模型版本都要版本化，支持 A/B 和回滚。

这也是 Harness Engineering 变重要的原因：它把 AI 系统从“主观感觉变好了”变成“用数据证明没有回归”。

## 5. 企业落地从试点转向流程重构

很多企业已经试用生成式 AI，但真正产生高价值的团队，往往不是把 AI 当独立聊天工具，而是把它嵌入业务流程。

落地方式：

1. 在客服、研发、销售、法务、数据分析等场景找到高频流程。
2. 接入企业知识库、工单、CRM、代码仓库和权限系统。
3. 先做人机协同，再逐步自动化低风险步骤。
4. 用指标衡量效果，例如处理时长、人工接管率、一次解决率、错误率和成本。
5. 把权限、审计、数据脱敏和合规放在工具层和网关层，而不是只靠提示词。

## 6. 面试回答模板

我理解最近 AI 的趋势有几条主线。第一是 Agent 化，模型不再只是聊天，而是通过工具调用、状态机和工作流完成多步任务；第二是多模态和长上下文成为基础能力，应用会同时处理文本、图片、语音、文件和屏幕信息；第三是推理基础设施变重要，线上系统要做模型路由、缓存、批处理、量化、限流和成本治理；第四是 Harness 和评测成为上线门槛，Prompt、模型和工具变更都要回放历史样本，观察任务成功率、工具调用、延迟、成本和安全违规；第五是企业落地从试点走向流程重构，真正的价值来自把 AI 嵌入客服、研发、数据分析、运维等业务链路，并配套权限、审计和人工确认。
