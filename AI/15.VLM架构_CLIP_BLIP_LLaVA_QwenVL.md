# 15. VLM 架构：CLIP、BLIP、LLaVA、Qwen-VL

VLM（Vision-Language Model）把视觉信息和语言信息放到同一模型或同一表示空间里，使模型能做图文检索、图像描述、视觉问答、OCR、grounding 和多模态对话。

## 1. CLIP

CLIP 的核心是图文对比学习：

```text
image encoder -> image embedding
text encoder  -> text embedding
对比学习：拉近匹配图文，拉远不匹配图文
```

特点：

1. 用大规模图文对训练。
2. 学到统一语义空间。
3. 可以做 zero-shot 分类：把类别写成 prompt，和图像 embedding 比相似度。
4. 更偏理解和检索，不直接生成长文本答案。

## 2. BLIP / BLIP-2

BLIP 同时面向理解和生成任务，强调用 captioner 和 filter 处理噪声图文数据。

BLIP-2 的关键思路是冻结已有强模型，用轻量桥接模块连接视觉和语言：

```text
frozen image encoder
-> Q-Former
-> frozen LLM
```

优点：

1. 减少端到端训练成本。
2. 利用强视觉编码器和强语言模型。
3. Q-Former 负责把视觉特征转成语言模型可用的少量 query 表示。

## 3. LLaVA

LLaVA 是面试最常让写的 VLM 架构之一。经典结构：

```text
image
-> CLIP vision encoder
-> projector / MLP
-> visual tokens

text
-> tokenizer
-> text tokens

visual tokens + text tokens
-> LLM
-> answer
```

训练通常分两阶段：

1. **视觉-语言对齐**：冻结 vision encoder 和 LLM，训练 projector，让视觉特征对齐到 LLM embedding 空间。
2. **视觉指令微调**：用多模态 instruction data 微调 projector 和部分/全部 LLM，让模型学会图像问答和对话。

LLaVA 的关键不是“图像直接喂给 LLM”，而是先把图像编码成视觉 token，再通过 projector 映射到语言模型能处理的 embedding 空间。

## 4. Qwen-VL

Qwen-VL 系列从 Qwen-LM 出发加入视觉能力，公开资料强调视觉 receptor、输入输出接口、多阶段训练和多语言多模态语料。

常见能力：

1. 图像描述和视觉问答。
2. OCR 和文本阅读。
3. grounding / 框选定位。
4. 多语言图文理解。
5. 指令对话能力。

相比基础 LLaVA 结构，Qwen-VL 更强调模型族工程化、多任务能力和实际视觉中心任务表现。

## 5. DeepSeek-VL 和 DeepSeek 系列

DeepSeek-VL 关注真实世界视觉语言理解，公开资料中常见关键词是混合视觉编码器、视觉-语言预训练和保持语言能力。

DeepSeek-R1 不是 VLM，而是强化学习增强推理能力的 reasoning model。DeepSeek-V3 则是 MoE 语言模型技术报告，公开关键词包括 DeepSeekMoE、MLA 和大规模高效训练。回答“DeepSeek 系列”时要区分：

1. **DeepSeek-VL**：视觉语言理解。
2. **DeepSeek-V2/V3**：MoE、注意力优化、训练效率。
3. **DeepSeek-R1**：RL 激发推理能力，数学、代码、STEM 等可验证任务。

不要把某个版本的技术点混到所有 DeepSeek 模型上。

## 6. VLM 的核心设计问题

1. **视觉编码器**：CLIP ViT、SigLIP、EVA、ConvNeXt 等。
2. **模态桥接**：线性层、MLP projector、Q-Former、cross-attention。
3. **token 数量**：图像 patch token 多会增加 LLM attention 成本。
4. **位置编码**：图像二维位置和文本一维位置如何融合。
5. **训练阶段**：预训练、对齐、指令微调、偏好对齐。
6. **任务能力**：caption、VQA、OCR、grounding、图表理解、视频理解。
7. **推理成本**：高分辨率图像会显著增加视觉 token 和显存。

## 7. 面试回答模板

VLM 的核心是把图像转成语言模型能处理的表示。CLIP 用图文对比学习把 image encoder 和 text encoder 对齐到同一语义空间，适合检索和 zero-shot 分类。BLIP/BLIP-2 更强调理解和生成，BLIP-2 用冻结视觉编码器、Q-Former 和冻结 LLM 降低训练成本。LLaVA 是典型面试架构：图像经过 CLIP vision encoder，projector 把视觉特征映射成 visual tokens，再和文本 tokens 拼接送入 LLM，先做视觉-语言对齐，再做视觉指令微调。Qwen-VL、DeepSeek-VL 等模型在这个范式上进一步强化 OCR、grounding、多语言和真实场景视觉理解。
