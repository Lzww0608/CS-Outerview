# 10. RLHF 与 PPO、DPO、GRPO、DAPO

大模型后训练里的强化学习，目标不是让模型学会“环境物理规律”，而是用偏好、规则或可验证答案作为奖励信号，把模型输出往更符合人类偏好、任务目标或推理正确性的方向推。

## 1. RLHF 基本流程

RLHF（Reinforcement Learning from Human Feedback）常见三阶段：

```text
预训练语言模型
-> SFT：用高质量指令数据监督微调
-> Reward Model：用偏好对训练奖励模型
-> RL：用 PPO/GRPO 等方法优化策略模型
```

在数学、代码这类可验证任务中，也可以不用人工偏好奖励模型，而是用答案是否正确、测试用例是否通过、格式是否满足约束作为 reward，这类训练常被称为 RLVR（Reinforcement Learning with Verifiable Rewards）。

## 2. PPO

PPO（Proximal Policy Optimization）是经典策略梯度方法。它用新旧策略概率比限制单次更新幅度，避免策略一步走太远导致训练崩掉。

核心形式：

```text
r_t = pi_new(a_t|s_t) / pi_old(a_t|s_t)
loss = -min(r_t * A_t, clip(r_t, 1-eps, 1+eps) * A_t)
```

在 LLM RLHF 中：

1. action 是生成 token。
2. state 是 prompt 和已生成 token。
3. advantage 表示这次输出比基线好多少。
4. 常加 KL penalty，约束模型不要偏离 reference model 太远。
5. PPO 通常需要 actor、critic、reward model、reference model，系统复杂且显存开销大。

易错点：

1. PPO 不是简单“有 reward 就训练”，还需要优势估计、KL 约束和稳定采样。
2. critic/value model 训练不好会影响 advantage，长 CoT 场景下更容易不稳定。
3. clip 太松会策略漂移，太紧会学习慢。

## 3. DPO

DPO（Direct Preference Optimization）把偏好对齐转化为一个监督式优化目标，不显式训练 reward model，也不跑在线 RL rollout。

输入是偏好对：

```text
prompt, chosen response, rejected response
```

直观目标是：提升 chosen 相对 rejected 的概率，同时用 reference model 做约束，避免模型偏离太远。

优点：

1. 实现比 PPO 简单。
2. 不需要在线采样和 critic。
3. 训练稳定，适合偏好数据充足的对齐任务。

限制：

1. 依赖偏好数据质量。
2. 不能像在线 RL 那样持续从当前策略采样探索。
3. 对数学、代码这类可验证任务，在线生成并用规则奖励往往更直接。

## 4. GRPO

GRPO（Group Relative Policy Optimization）常见于 reasoning model 的 RLVR 训练。它对同一个 prompt 采样一组 responses，用组内 reward 的相对关系估计 advantage，从而减少对独立 value model 的依赖。

简化理解：

```text
对同一个 prompt 采样 G 个答案
-> 每个答案得到 reward
-> 用组内均值/方差归一化 reward
-> 得到每个答案的相对 advantage
-> 用策略梯度更新模型
```

优点：

1. 不需要单独 critic/value model，显存和训练复杂度下降。
2. 对可验证任务友好，例如数学答案、代码测试、格式校验。
3. 组内相对比较能减少 prompt 难度差异带来的 reward 尺度问题。

问题：

1. 如果一个 group 内 reward 全是 0 或全是 1，组内方差为 0，advantage 区分度消失。
2. 采样质量直接影响训练信号；模型太强或太弱都可能产生全对或全错 group。
3. 过强 KL 或过低 temperature 会导致探索不足。

## 5. DAPO

DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）是 2025 年公开的大规模 LLM RL 系统和算法方案，目标是提升 long-CoT RL 的稳定性和可复现性。公开论文中强调了几类关键技术：

1. **Dynamic Sampling**：过滤掉没有有效学习信号的样本，例如组内全对或全错，保留 reward 有区分度的 prompt。
2. **Clip-Higher / Decoupled Clip**：对 PPO/GRPO 类目标的 clip 做更细粒度控制，给有益探索更大上界。
3. **Token-Level Policy Gradient Loss**：把损失从样本级调整到 token 级，缓解长回答长度差异带来的训练偏置。
4. **Overlong Reward Shaping**：对超长输出做形状化惩罚，避免模型无意义延长推理。

面试中问“GRPO 里 group 全 0 或全 1 怎么办”，可以回答：

1. 这种 group 没有相对 advantage，训练信号弱。
2. 可以提高采样多样性，例如调大 temperature 或 top-p。
3. 使用 DAPO 的 dynamic sampling，筛掉全对/全错 group，重新采样或替换 prompt。
4. 调整任务难度分布，让 prompt 不要过易或过难。
5. 使用更细粒度 reward，例如过程奖励、格式奖励、步骤奖励，增加区分度。

## 6. 熵崩溃怎么处理

熵崩溃指模型输出分布过早变尖，探索能力下降，生成模式单一，RL 训练进入低多样性状态。

常见手段：

1. **熵正则**：在 loss 中鼓励策略保持一定 entropy。
2. **提高采样 temperature**：rollout 时提高探索。
3. **调 KL 系数**：过强 KL 可能限制探索，过弱 KL 可能漂移。
4. **DAPO Clip-Higher**：给高 advantage token 更大的更新空间。
5. **动态采样**：过滤低信息量 group，提高有效梯度比例。
6. **控制长度奖励**：防止模型通过输出更长内容获得非预期 reward。

## 7. 面试回答模板

RLHF 传统流程是 SFT、奖励模型、PPO。PPO 用新旧策略概率比和 clip 限制更新幅度，稳定但系统复杂，需要 actor、critic、reward 和 reference。DPO 不跑在线 RL，而是直接用 chosen/rejected 偏好对优化策略，简单稳定。GRPO 更适合数学、代码这类可验证任务：同一个 prompt 采样一组答案，用组内 reward 相对值估计 advantage，省掉 value model。GRPO 的问题是 group 全 0 或全 1 时没有区分度，可以用更高 temperature、调整题目难度、过程 reward 或 DAPO 的 dynamic sampling 过滤无效 group。DAPO 还引入 decoupled clip、token-level loss 和 overlong reward shaping 来稳定 long-CoT RL。
