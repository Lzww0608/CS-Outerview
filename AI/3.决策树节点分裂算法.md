# 决策树节点分裂算法

决策树训练的核心问题是：在当前节点上选择哪个特征、哪个切分点，把样本分成更“纯”的子节点。不同决策树算法的主要区别之一，就是节点分裂准则不同。

## 1. 信息增益 ID3

信息熵衡量样本集合的不确定性：

```text
H(D) = - sum p_k log2(p_k)
```

用特征 `A` 切分后的信息增益：

```text
Gain(D, A) = H(D) - sum (|D_v| / |D|) * H(D_v)
```

信息增益越大，说明切分后不确定性下降越多。

特点：

1. ID3 使用信息增益选择特征。
2. 容易偏向取值很多的离散特征，例如用户 ID。
3. 原始 ID3 更适合离散特征，连续特征需要先找候选切分点。

## 2. 信息增益率 C4.5

C4.5 用信息增益率缓解“偏好取值多特征”的问题：

```text
GainRatio(D, A) = Gain(D, A) / IV(A)
```

其中 `IV(A)` 是特征 `A` 的固有值，取值越分散，`IV(A)` 越大。

特点：

1. 相比信息增益，更不容易盲目选择高基数特征。
2. 实现中通常先筛掉信息增益太低的特征，再比较增益率，避免偏向取值过少的特征。
3. 支持连续特征、缺失值处理和剪枝，是 ID3 的工程化增强。

## 3. 基尼指数 CART

CART 分类树常用基尼指数：

```text
Gini(D) = 1 - sum p_k^2
```

切分后的基尼指数：

```text
GiniSplit(D, A) = sum (|D_i| / |D|) * Gini(D_i)
```

选择让 `GiniSplit` 最小的特征和切分点。

特点：

1. CART 每次做二叉切分。
2. 分类树用 Gini，回归树通常用平方误差或方差下降。
3. Gini 不需要计算对数，工程实现更快。
4. 随机森林、GBDT、XGBoost 的树模型都和 CART 思路关系密切。

## 4. 连续特征怎么找切分点

对连续特征，常见做法是排序后枚举相邻不同取值的中点：

```text
候选切分点 = (x_i + x_{i+1}) / 2
```

流程：

1. 按特征值排序样本。
2. 枚举相邻取值变化的位置作为候选切分点。
3. 维护左右两侧类别计数，增量计算 Gini 或 entropy。
4. 选择指标最优的切分点。

朴素枚举每个特征的复杂度较高，工程实现会用预排序、直方图、分位数近似等方式加速。XGBoost、LightGBM 常用直方图或近似分裂查找提升训练效率。

## 5. 易错点

1. 信息增益不是越大越一定泛化好，高基数特征容易过拟合。
2. 决策树生长太深会过拟合，需要预剪枝或后剪枝。
3. 分类树和回归树分裂指标不同，不能都回答“信息增益”。
4. 类别不平衡时，只看准确率或纯度可能误导，要结合样本权重、召回率或代价敏感学习。
5. 缺失值可以单独成分支、按比例分配，或在工程库中学习默认方向。

## 6. 面试回答模板

决策树节点分裂就是选一个特征和切分点，让子节点更纯。ID3 用信息增益，衡量切分前后熵下降；C4.5 用信息增益率，缓解信息增益偏向高基数特征的问题；CART 分类树常用基尼指数，选择切分后加权 Gini 最小的方案，回归树常用平方误差下降。连续特征一般先排序，再枚举相邻取值中点作为候选切分点。真实训练还要考虑剪枝、缺失值、类别不平衡和直方图加速。
