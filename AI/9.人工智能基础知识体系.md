# 9. 人工智能基础知识体系

面试里问“人工智能都学什么”，可以从问题类型、模型方法、训练流程和工程工具四层回答。不要只说“机器学习、深度学习”，要说明它们分别解决什么问题。

## 1. 基础分支

1. **机器学习**：从数据中学习规律，用于分类、回归、聚类、排序、推荐等任务。
2. **深度学习**：用多层神经网络学习特征表示，常用于视觉、语音、自然语言和多模态任务。
3. **计算机视觉**：图像分类、目标检测、分割、OCR、视频理解。
4. **自然语言处理**：分词、文本分类、信息抽取、机器翻译、问答、对话系统。
5. **强化学习**：智能体通过和环境交互学习策略，常见于游戏、机器人、控制和资源调度。
6. **大模型和生成式 AI**：预训练、微调、提示工程、RAG、Agent、工具调用和评测。

## 2. 常见学习任务

| 任务 | 定义 | 示例 |
| --- | --- | --- |
| 监督学习 | 样本有标签，学习输入到标签的映射 | 垃圾邮件识别、房价预测 |
| 无监督学习 | 样本无标签，发现数据结构 | 聚类、降维、异常检测 |
| 半监督学习 | 少量标签加大量无标签数据 | 医学影像、内容审核 |
| 自监督学习 | 从数据自身构造监督信号 | BERT Mask LM、对比学习 |
| 强化学习 | 通过奖励信号学习决策策略 | 游戏 AI、自动控制 |

## 3. 训练流程

典型机器学习项目流程：

```text
问题定义
-> 数据采集和清洗
-> 特征工程或表示学习
-> 划分训练/验证/测试集
-> 选择模型
-> 训练和调参
-> 评估指标
-> 部署推理
-> 线上监控和迭代
```

评估指标要和任务匹配：

1. 分类：Accuracy、Precision、Recall、F1、AUC。
2. 回归：MSE、MAE、RMSE。
3. 检索和推荐：Recall@K、NDCG、MRR。
4. 目标检测：mAP、IoU。
5. 生成模型：人工评测、自动指标和业务指标结合。

## 4. 常见模型和框架

1. 传统模型：线性回归、逻辑回归、SVM、决策树、随机森林、GBDT、XGBoost。
2. 深度模型：MLP、CNN、RNN/LSTM、Transformer、Diffusion。
3. 视觉框架：OpenCV、Pillow、MMDetection、Detectron2。
4. 深度学习框架：PyTorch、TensorFlow、JAX。
5. 工程工具：ONNX、TensorRT、Triton Inference Server、MLflow、Kubeflow。

## 5. 工程落地关注点

1. **数据质量**：脏数据、标签噪声、数据泄漏会比模型选择更影响效果。
2. **泛化能力**：训练集好不代表线上好，要关注过拟合和分布漂移。
3. **推理性能**：延迟、吞吐、显存、批处理、量化和模型压缩。
4. **可解释性**：金融、医疗、风控等场景需要解释模型依据。
5. **安全和合规**：隐私、偏见、版权、提示注入和模型越权。

## 6. 面试回答模板

人工智能可以按任务和技术栈来理解。基础包括机器学习、深度学习、计算机视觉、自然语言处理、强化学习和大模型。机器学习关注分类、回归、聚类、排序等问题；深度学习用神经网络自动学习表示；视觉处理图像和视频，NLP 处理文本和对话。一个 AI 项目通常从数据采集清洗开始，划分训练验证测试集，选择模型并训练调参，再用合适指标评估，最后部署推理并监控线上效果。工程上除了模型精度，还要关注数据质量、延迟、显存、可解释性和安全合规。
