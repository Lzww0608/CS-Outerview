# 5. 全连接层、CNN、梯度与梯度消失

这几个问题经常连在一起考：先问神经网络层的作用，再问训练时梯度如何传播，最后追问为什么深层网络会梯度消失。

## 全连接层是什么

全连接层（Fully Connected Layer, Dense Layer）指当前层每个神经元都与上一层所有输出相连。数学形式通常是：

```text
y = W x + b
```

其中：

1. `x` 是输入向量。
2. `W` 是权重矩阵。
3. `b` 是偏置。
4. `y` 是线性变换后的输出，通常还会接激活函数。

核心作用：

1. 把输入特征组合成更适合任务的表示。
2. 在分类任务末端把特征映射到类别 logits。
3. 在回归任务中输出连续值预测。

注意事项：

1. 参数量大，输入维度高时容易过拟合。
2. 全连接层不利用图像的空间局部性和平移不变性。
3. 大模型中 Dense/Linear 层仍然很重要，例如 Transformer 的 FFN 和投影层。

## 卷积神经网络 CNN 是什么

CNN（Convolutional Neural Network）主要用于处理图像、视频、语音谱图等具有局部结构的数据。它的核心是卷积层：用一个小卷积核在输入上滑动，并共享同一组参数。

核心特点：

1. **局部连接**：卷积核只看局部区域，适合提取边缘、纹理、局部模式。
2. **参数共享**：同一个卷积核在不同位置复用，参数量远小于全连接。
3. **平移等变**：输入平移后，特征图也相应平移。
4. **层级特征**：浅层提取边缘纹理，深层组合成目标部件和语义。

常见组件：

1. 卷积层：提取局部特征。
2. 激活函数：引入非线性，例如 ReLU、GELU。
3. 池化或步幅卷积：降低空间分辨率、扩大感受野。
4. BatchNorm/LayerNorm：稳定训练。
5. 全连接或全局平均池化：输出分类或回归结果。

## 全连接层和 CNN 的区别

| 对比项 | 全连接层 | 卷积层 |
| --- | --- | --- |
| 连接方式 | 每个输出连接所有输入 | 只连接局部感受野 |
| 参数共享 | 通常不共享 | 同一卷积核跨位置共享 |
| 参数量 | 输入维度高时很大 | 通常更少 |
| 空间结构 | 不显式利用空间邻近关系 | 适合图像、视频等网格数据 |
| 常见位置 | 分类头、投影层、MLP/FFN | 图像特征提取主干 |

## 什么是梯度

梯度是多元函数对各个参数偏导数组成的向量，表示函数在当前位置上升最快的方向。训练神经网络时，损失函数 `L` 对参数 `theta` 的梯度写作：

```text
grad = dL / dtheta
```

优化器通常沿负梯度方向更新参数：

```text
theta = theta - lr * grad
```

其中 `lr` 是学习率。直观理解：梯度告诉模型“当前参数往哪个方向改，损失会变大或变小”。

## 反向传播的核心原理

反向传播（Backpropagation）本质是链式法则在计算图上的高效应用。

前向传播：

```text
x -> layer1 -> layer2 -> ... -> loss
```

反向传播从 loss 开始，逐层计算每个参数对 loss 的影响：

```text
dL/dW2 = dL/dy2 * dy2/dW2
dL/dW1 = dL/dy2 * dy2/dy1 * dy1/dW1
```

深层网络中，梯度要经过很多层的导数连乘，这正是梯度消失和梯度爆炸的根源。

## 为什么会梯度消失

梯度消失是指反向传播到浅层时，梯度变得非常小，导致浅层参数几乎不更新。

主要原因：

1. **链式法则连乘**：如果每层局部导数绝对值都小于 1，多层相乘后会指数级变小。
2. **饱和激活函数**：Sigmoid、Tanh 在输入很大或很小时导数接近 0。
3. **初始化不合适**：权重尺度过小会让信号和梯度逐层衰减。
4. **网络过深且缺少跳连**：梯度路径太长，浅层难以获得有效更新。
5. **归一化不足**：激活分布漂移，部分层长期进入饱和区域。

以 Sigmoid 为例：

```text
sigmoid'(x) = sigmoid(x) * (1 - sigmoid(x))
```

它的最大导数只有 0.25。多层连乘时，`0.25^n` 会很快接近 0。

## 怎么缓解梯度消失

1. 使用 ReLU、Leaky ReLU、GELU 等更不容易饱和的激活函数。
2. 使用 Xavier/He 初始化，让前向激活和反向梯度的方差更稳定。
3. 使用 BatchNorm、LayerNorm 稳定中间分布。
4. 使用残差连接，让梯度可以通过短路径回传。
5. 使用 LSTM/GRU、门控结构或注意力机制缓解长序列梯度问题。
6. 合理设置学习率，配合 warmup、梯度裁剪处理不稳定训练。

## 真实场景

1. CNN 图像分类里，卷积层提取空间特征，最后常接全局平均池化和全连接分类头。
2. Transformer 虽然不用卷积作为主干，但大量使用全连接投影和 FFN。
3. ResNet 的残差连接是缓解深层 CNN 梯度消失的经典工程方案。
4. RNN 处理长序列时容易梯度消失，LSTM/GRU 用门控机制改善长期依赖。

## 面试回答模板

全连接层就是 `y = Wx + b`，每个输出都连接所有输入，表达能力强但参数多，不利用空间结构。CNN 用局部卷积核和参数共享提取图像等网格数据的局部特征，参数更少，也更适合视觉任务。梯度是损失函数对参数的偏导，表示参数更新方向；反向传播用链式法则从 loss 往前逐层计算梯度。梯度消失来自多层导数连乘，特别是 Sigmoid/Tanh 饱和区导数接近 0，深层网络传到浅层时梯度可能变得极小。常见缓解方法是 ReLU/GELU、合适初始化、归一化、残差连接和门控结构。
