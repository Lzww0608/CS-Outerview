# 40. AI模型嵌入式硬件优化部署技术

## 1. 问题背景

嵌入式硬件（MCU、边缘AI芯片、NPU）资源受限，需要对AI模型进行专门优化才能部署。本文介绍模型压缩、量化、硬件适配等核心优化技术。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  嵌入式部署挑战：                                          │
│                                                             │
│  资源限制：                                                │
│  • 算力：100 GOPS - 10 TOPS                             │
│  • 内存：512KB - 2GB                                     │
│  • 功耗：100mW - 10W                                     │
│  • 存储：1MB - 1GB                                       │
│                                                             │
│  优化方向：                                                │
│  • 模型压缩（剪枝、知识蒸馏）                           │
│  • 量化（FP32 → INT8 → INT4）                          │
│  • 硬件适配（TFLite、ONNX Runtime、TensorRT）            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 模型剪枝

```python
# 结构化剪枝示例

import torch.nn.utils.prune as prune

class PrunedModel:
    @staticmethod
    def structured_prune(model, amount=0.3):
        """结构化剪枝：移除整个通道"""
        
        for name, module in model.named_modules():
            if isinstance(module, nn.Conv2d):
                # L1 正则化剪枝
                prune.l1_unstructured(
                    module, 
                    name='weight', 
                    amount=amount
                )
                
                # 转为永久剪枝
                prune.remove(module, 'weight')
        
        return model
    
    @staticmethod
    def magnitude_prune(model, threshold=0.01):
        """幅度剪枝：移除小权重"""
        
        for name, param in model.named_parameters():
            if 'weight' in name:
                mask = torch.abs(param) > threshold
                param.data *= mask
        
        return model
```

### 5.3 知识蒸馏

```python
# 知识蒸馏实现

class Distiller:
    def __init__(self, teacher, student, temperature=2.0, alpha=0.5):
        self.teacher = teacher
        self.student = student
        self.temperature = temperature
        self.alpha = alpha
        self.teacher.eval()
        self.student.train()
    
    def train_step(self, batch):
        # 学生预测
        student_logits = self.student(batch['input'])
        
        # 教师预测（不计算梯度）
        with torch.no_grad():
            teacher_logits = self.teacher(batch['input'])
        
        # 蒸馏损失
        soft_loss = nn.KLDivLoss()(
            torch.log_softmax(student_logits / self.temperature, dim=-1),
            torch.softmax(teacher_logits / self.temperature, dim=-1)
        ) * (self.temperature ** 2)
        
        # 硬标签损失
        hard_loss = nn.CrossEntropyLoss()(
            student_logits, 
            batch['labels']
        )
        
        # 总损失
        loss = self.alpha * soft_loss + (1 - self.alpha) * hard_loss
        
        loss.backward()
        return loss.item()
```

```cpp
// 嵌入式 C++ 推理代码

#include "tflite_model.h"
#include "tensorflow/lite/interpreter.h"
#include "tensorflow/lite/kernels/register.h"

class TFLiteInference {
private:
    std::unique_ptr<tflite::FlatBufferModel> model;
    std::unique_ptr<tflite::Interpreter> interpreter;
    
public:
    bool loadModel(const char* model_path) {
        model = tflite::FlatBufferModel::BuildFromFile(model_path);
        if (!model) return false;
        
        tflite::ops::builtin::BuiltinOpResolver resolver;
        tflite::InterpreterBuilder(*model, resolver)(&interpreter);
        
        interpreter->AllocateTensors();
        return true;
    }
    
    float* infer(float* input_data, int input_size) {
        // 设置输入
        float* input = interpreter->typed_input_tensor<float>(0);
        memcpy(input, input_data, input_size * sizeof(float));
        
        // 推理
        interpreter->Invoke();
        
        // 获取输出
        float* output = interpreter->typed_output_tensor<float>(0);
        return output;
    }
};
```

## 6. 可选方案对比

| 技术 | 压缩比 | 精度损失 | 速度提升 | 适用场景 |
|------|--------|----------|----------|----------|

| 轻量模型 | 10-50x | 视情况 | 5-20x | 极致场景 |
