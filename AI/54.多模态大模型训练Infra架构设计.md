# 54. 多模态大模型训练Infra架构设计

## 1. 问题背景

多模态大模型（如 GPT-4V、LLaVA、Qwen-VL、InternVL）需要同时处理文本、图像、视频、音频等多种模态数据，对训练 Infra 提出了更高的要求。相比纯语言模型，多模态训练面临数据异构性、计算不对称、存储多样化等独特挑战。

**假设条件**：本文档基于 VL（视觉-语言）多模态模型的训练场景，假设使用 PyTorch + DeepSpeed/Megatron 框架，数据包含文本（100B tokens）、图像（100M 张）、视频（1M 片段），训练集群为 64~512 张 A100/H100 GPU，图像编码器使用 ViT/ConvNeXt，视频编码器使用 VideoTransformer。

## 2. 问题现象

1. **数据加载瓶颈**：图像/视频预处理耗时长，数据加载成为训练瓶颈。
2. **显存分布不均**：视觉编码器、语言模型、交叉注意力模块的显存占用差异大。
3. **异构计算效率低**：视觉编码（前 CNN/Transformer）和语言模型（Transformer）的计算特性不同，GPU 利用率不一致。
4. **多模态预训练-微调差异**：预训练阶段需要大规模数据，微调阶段需要高质量数据，数据管道路径不同。
5. **存储成本高**：原始图像/视频数据量远大于文本，存储和管理成本高。

## 3. 影响范围

| 影响维度 | 程度 | 说明 |
| --- | --- | --- |
| 训练效率 | 高 | 数据加载和异构计算直接影响吞吐量 |
| 显存利用率 | 高 | 不同模块显存需求差异导致资源浪费 |
| 模型质量 | 高 | 数据质量和采样策略影响最终效果 |
| 成本 | 高 | 存储和计算资源消耗大 |
| 工程复杂度 | 高 | 多模态数据处理和调度复杂 |

## 4. 原因分析

### 4.1 多模态数据特征对比

```text
各模态数据特征对比：

文本：
- 数据量：100B tokens ≈ 400GB
- 预处理：分词、BPE/WordPiece 编码
- 计算：Transformer 计算密集
- 显存：激活值与 seq_len 线性相关

图像：
- 数据量：100M 张 ≈ 10TB（压缩后）
- 预处理：resize、normalize、augmentation
- 计算：ViT/ConvNeXt，图像级并行
- 显存：Patch 化后与图像尺寸相关

视频：
- 数据量：1M 片段 ≈ 100TB（压缩后）
- 预处理：解码、采样、resize
- 计算：时空 Transformer，3D attention
- 显存：时序维度增加激活显存

问题：
- 视频单帧数据量是图像的 N 倍
- 视频预处理（解码）是 CPU 瓶颈
- 视频 3D attention 显存是 2D 的 seq_len 倍
```

### 4.3 计算与显存不对称问题

```text
各模块计算和显存特征：

语言模型（32 层 Transformer）：
- 计算：每层 2 次 Attention + 1 次 FFN
- 显存：参数量大，但激活相对较小（取决于 seq_len）
- 并行策略：TP/PP/DP

视觉编码器（24 层 ViT）：
- 计算：每层 Image Attention
- 显存：参数量较小，但 Patch 数 = (224/14)^2 = 256
- 显存：256 个 Patch 的注意力矩阵 = 256 * 256 = 65K
- 并行策略：主要是 DP

视频编码器（多帧 ViT）：
- 计算：时空 Attention，O(T * H * W)^2
- 显存：T 帧的 Patch 数 = T * 256，注意力矩阵 = (T*256)^2
- 问题：T=16 时，注意力矩阵是图像的 256 倍
```

```python
# multimodal_dataloader.py
import torch
from torch.utils.data import DataLoader, IterableDataset
from typing import Dict, List
import asyncio

class MultiModalDataLoader:
    """
    多模态数据加载器
    支持文本、图像、视频的异构数据加载
    """
    
    def __init__(self, config):
        self.text_loader = self._build_text_loader(config.text_data)
        self.image_loader = self._build_image_loader(config.image_data)
        self.video_loader = self._build_video_loader(config.video_data)
        
        # 采样比例配置
        self.sampling_ratios = {
            "text": 0.7,
            "image": 0.2,
            "video": 0.1,
        }
        
        # 预处理 worker 池
        self.preprocess_workers = ProcessPoolExecutor(max_workers=32)
    
    def _build_text_loader(self, data_config):
        """文本数据加载"""
        return DataLoader(
            TextDataset(data_config),
            batch_size=256,
            num_workers=8,
            pin_memory=True,
            prefetch_factor=4,
        )
    
    def _build_image_loader(self, data_config):
        """图像数据加载"""
        return DataLoader(
            ImageDataset(data_config, transform=self._get_image_transform()),
            batch_size=64,  # 图像 batch size 通常较小
            num_workers=16,  # 图像预处理更耗时
            pin_memory=True,
            prefetch_factor=2,
        )
    
    def _get_image_transform(self):
        """图像预处理（CUDA 加速）"""
        from torchvision.transforms import transforms
        
        return transforms.Compose([
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.485, 0.456, 0.406], 
                               std=[0.229, 0.224, 0.225]),
            transforms.Resize((224, 224)),
            # 可选：使用 GPU 加速的数据增强
            # GPURandAugment(),
        ])
    
    def __iter__(self):
        """统一迭代接口"""
        text_iter = iter(self.text_loader)
        image_iter = iter(self.image_loader)
        video_iter = iter(self.video_loader)
        
        while True:
            # 根据采样比例选择模态
            modality = self._sample_modality()
            
            if modality == "text":
                try:
                    batch = next(text_iter)
                    batch["modality"] = "text"
                except StopIteration:
                    text_iter = iter(self.text_loader)
                    batch = next(text_iter)
            elif modality == "image":
                try:
                    batch = next(image_iter)
                    batch["modality"] = "image"
                except StopIteration:
                    image_iter = iter(self.image_loader)
                    batch = next(image_iter)
            else:
                try:
                    batch = next(video_iter)
                    batch["modality"] = "video"
                except StopIteration:
                    video_iter = iter(self.video_loader)
                    batch = next(video_iter)
            
            yield self._collate(batch)
```

### 5.2 异构并行策略

```python
# heterogeneous_parallel.py
class HeterogeneousParallelism:
    """
    异构并行：针对不同模态模块使用不同并行策略
    
    策略：
    - 语言模型：TP + PP + DP
    - 视觉编码器：DP（参数量小，主要数据并行）
    - 交叉注意力：与语言模型联合 TP
    """
    
    def __init__(self, model, num_gpus=64):
        self.num_gpus = num_gpus
        self.model = model
        
        # 分区策略
        # 语言模型：TP=8, PP=4, DP=2 -> 64 GPU
        self.lm_tp = 8
        self.lm_pp = 4
        self.lm_dp = 2
        
        # 视觉编码器：仅 DP
        self.vision_dp = num_gpus // (self.lm_tp * self.lm_pp)
    
    def partition_model(self):
        """
        模型分区
        
        将不同模块放置到不同的并行组
        """
        # 语言模型分区
        lm_model = self.model.language_model
        lm_sharded = deepspeed.utils.zero_to_fp32_utils.get_fp32_param_groups_from_zero_checkpoint(
            self.lm_model_path
        )
        
        # 视觉编码器（全部复制到每个 DP 组）
        vision_model = self.model.vision_encoder
        # vision_model 每 DP 组复制一份
        
        # 交叉注意力层（与语言模型联合分区）
        cross_attn = self.model.cross_attention
        # cross_attn 与语言模型联合 TP
        
        return {
            "language_model": lm_sharded,
            "vision_encoder": vision_model,
            "cross_attention": cross_attn,
        }
```

### 5.3 视觉特征压缩与缓存

```python
# vision_feature_cache.py
import faiss
import numpy as np

class VisionFeatureCache:
    """
    视觉特征缓存：减少重复的视觉编码计算
    
    策略：
    1. 预处理阶段计算所有图像的特征
    2. 训练时直接使用缓存的特征
    3. 节省大量视觉编码计算
    """
    
    def __init__(self, vision_encoder, cache_dir):
        self.vision_encoder = vision_encoder
        self.cache_dir = cache_dir
        
        # FAISS 索引（用于相似图像去重和检索）
        self.feature_index = faiss.IndexFlatIP(1024)  # 视觉特征维度
        self.feature_metadata = []
    
    def preprocess_images(self, image_paths):
        """预处理：计算并缓存视觉特征"""
        features = []
        
        for img_path in image_paths:
            cache_path = self._get_cache_path(img_path)
            
            if os.path.exists(cache_path):
                # 加载缓存
                feature = np.load(cache_path)
            else:
                # 计算特征
                image = self._load_image(img_path)
                with torch.no_grad():
                    feature = self.vision_encoder(image)
                # 保存缓存
                np.save(cache_path, feature.cpu().numpy())
            
            features.append(feature)
        
        return features
    
    def _get_cache_path(self, image_path):
        """生成缓存路径"""
        import hashlib
        img_hash = hashlib.md5(image_path.encode()).hexdigest()
        return f"{self.cache_dir}/{img_hash}.npy"
```

## 6. 可选方案对比

| 方案 | 数据加载效率 | 显存优化 | 实现复杂度 | 适用场景 |
| --- | --- | --- | --- | --- |
| 独立数据加载器 | 中 | 无 | 低 | 小规模多模态 |
| 分层异步加载 | 高 | 中 | 中 | 通用场景 |
| 视觉特征预计算 | 极高 | 高 | 高 | 大规模图像训练 |
| 动态模态调度 | 高 | 高 | 高 | 多模态平衡训练 |
| 异构并行分区 | 中 | 高 | 高 | 超大规模 |

## 7. 推荐方案

**推荐方案：分层异步加载 + 视觉特征缓存 + 异构并行分区**

1. **分层异步加载**：不同模态使用独立数据管线和预处理 worker
2. **视觉特征缓存**：预处理阶段计算并缓存视觉特征，减少训练时计算
3. **异构并行分区**：语言模型用 TP/PP/DP，视觉编码器用 DP

**实施优先级**：
1. 首先实现分层数据加载架构
2. 配置视觉特征预计算和缓存
3. 实现异构并行分区
4. 调优数据采样比例

## 9. 风险与注意事项

| 风险 | 缓解措施 |
| --- | --- |
| 视觉特征缓存占用大量磁盘 | 使用分布式文件系统，按需加载 |

## 11. 总结

多模态大模型训练 Infra 需要解决数据异构性、计算不对称、存储多样化等独特挑战。核心设计要点包括：

- **分层数据加载**：不同模态使用独立数据管线和预处理 worker
- **视觉特征缓存**：预计算视觉特征，减少训练时计算开销
- **异构并行分区**：语言模型用 TP/PP/DP，视觉编码器用 DP
- **模态平衡采样**：根据训练目标动态调整各模态采样比例
- **显存优化**：视频使用稀疏采样和序列并行
