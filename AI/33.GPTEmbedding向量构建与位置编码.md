# GPT Embedding 向量构建与位置编码

## 1. 问题背景

GPT（Generative Pre-trained Transformer）的 embedding 是将离散 token 映射到连续向量空间的关键组件，位置编码则负责注入序列位置信息。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  GPT Embedding 构成：                                      │
│                                                             │
│  Input Tokens: [Token1, Token2, Token3, ...]            │
│       │                                                     │
│       ▼ Token Embedding                                   │
│  Token Embeddings: [vec1, vec2, vec3, ...]               │
│       │                                                     │
│       ▼ Position Encoding                                  │
│  Position Embeddings: PE1, PE2, PE3, ...                 │
│       │                                                     │
│       ▼ Sum                                                │
│  Final Embeddings = Token Embeddings + Position Embeddings │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 疑问 | 回答 |

### 4.2 位置编码对比

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  位置编码类型对比：                                        │
│                                                             │
│  ┌─────────────────┬────────────────────────────────────┐ │
│  │ 类型            │ 说明                                │ │
│  ├─────────────────┼────────────────────────────────────┤ │
│  │ 绝对位置编码    │ Sinusoidal (原始 Transformer)       │ │
```

### 4.3 GPT 位置编码实现

```python
class GPTPositionEmbedding(nn.Module):
    """
    GPT 的学习型位置编码实现
    """
    
    def __init__(self, n_positions, n_embd):
        super().__init__()
        # 可学习的绝对位置编码
        self.weight = nn.Parameter(torch.zeros(1, n_positions, n_embd))
        
        # 随机初始化
        nn.init.normal_(self.weight, mean=0, std=0.02)
    
    def forward(self, x):
        # x: [batch, seq_len, n_embd]
        # 位置编码直接加到 token embedding 上
        return x + self.weight[:, :x.size(1), :]
```

### 4.4 完整 Embedding 层

```python
class GPTEmbedding(nn.Module):
    """
    GPT 完整 Embedding 层
    """
    
    def __init__(self, vocab_size, n_positions, n_embd):
        super().__init__()
        
        # Token Embedding
        self.token_embedding = nn.Embedding(vocab_size, n_embd)
        
        # Position Embedding (学习型)
        self.position_embedding = nn.Embedding(n_positions, n_embd)
        
        # Layer Norm
        self.ln = nn.LayerNorm(n_embd)
    
    def forward(self, input_ids):
        """
        Args:
            input_ids: [batch, seq_len]
        
        Returns:
            embeddings: [batch, seq_len, n_embd]
        """
        batch_size, seq_len = input_ids.size()
        
        # Token Embedding
        token_embeds = self.token_embedding(input_ids)
        
        # Position Embedding
        position_ids = torch.arange(seq_len, device=input_ids.device)
        position_ids = position_ids.unsqueeze(0).expand(batch_size, -1)
        position_embeds = self.position_embedding(position_ids)
        
        # 相加
        embeddings = token_embeds + position_embeds
        
        # Layer Norm
        embeddings = self.ln(embeddings)
        
        return embeddings
```

## 5. 解决方案

### 5.1 从零实现 GPT Embedding

```python
import torch
import torch.nn as nn
import math

class GPTEmbeddingFromScratch(nn.Module):
    """
    从零实现 GPT Embedding
    """
    
    def __init__(self, vocab_size=50257, max_seq_len=2048, n_embd=768):
        super().__init__()
        
        # 1. Token Embedding
        self.token_embedding = nn.Embedding(vocab_size, n_embd)
        
        # 2. Position Embedding (Learnable)
        self.position_embedding = nn.Embedding(max_seq_len, n_embd)
        
        # 初始化
        self._init_weights()
    
    def _init_weights(self):
        """权重初始化"""
        nn.init.normal_(self.token_embedding.weight, mean=0, std=0.02)
        nn.init.normal_(self.position_embedding.weight, mean=0, std=0.02)
    
    def forward(self, input_ids):
        """
        input_ids: LongTensor [batch, seq_len]
        """
        batch_size, seq_len = input_ids.shape
        
        # Token Embedding
        token_embeds = self.token_embedding(input_ids)
        
        # Position Embedding
        position_ids = torch.arange(seq_len, device=input_ids.device)
        position_ids = position_ids.unsqueeze(0).expand(batch_size, -1)
        position_embeds = self.position_embedding(position_ids)
        
        # Add & Norm
        embeddings = token_embeds + position_embeds
        
        return embeddings
```

## 6. 可选方案对比

| 位置编码 | 计算方式 | 外推能力 | 适用模型 | 备注 |
|----------|----------|----------|----------|------|
| Sinusoidal | 三角函数 | 有限 | 原始 Transformer | 无需训练 |
| Learnable | 可学习参数 | 有限 | GPT 系列 | 随训练更新 |
| RoPE | 旋转矩阵 | 强 | LLaMA, Falcon | 相对位置 |
| ALiBi | 线性偏置 | 强 | BLOOM | 无位置编码 |
| Kerple | 对数旋转 | 强 | - | 可学习外推 |

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 位置编码外推 | 长序列推理失败 | 使用 RoPE/ALiBi |

```python
def test_embedding():
    """验证 Embedding 实现"""
    
    # 1. 创建 Embedding 层
    vocab_size = 1000
    seq_len = 50
    n_embd = 128
    
    embedding = GPTEmbeddingFromScratch(vocab_size, seq_len, n_embd)
    
    # 2. 输入
    input_ids = torch.randint(0, vocab_size, (2, seq_len))
    
    # 3. 前向
    output = embedding(input_ids)
    
    # 4. 验证
    assert output.shape == (2, seq_len, n_embd)
    print(f"Output shape: {output.shape}")
    
    # 5. 检查位置编码效果
    # 相同 token 不同位置应有不同输出
    same_token = torch.tensor([[0, 0, 0]])  # 三个相同 token
    out = embedding(same_token)
    # 检查位置 0, 1, 2 的输出是否不同
    assert not torch.allclose(out[0, 0], out[0, 1])
    print("✅ 位置编码验证通过")
```

## 11. 总结

1. **GPT Embedding 构成**：Token Embedding（词表映射）+ Position Embedding（位置信息）+ Layer Norm
2. **位置编码选择**：GPT 使用学习型位置编码，可与模型联合优化
3. **位置编码对比**：Sinusoidal（固定）vs Learnable（可学习）vs RoPE（旋转）vs ALiBi（线性）
4. **外推能力**：RoPE 和 ALiBi 外推能力强，适合长序列
5. **核心理解**：Embedding 是离散了 token 到连续向量的映射，位置编码注入序列顺序信息
