# SGD 与 Adam 优化器

SGD 和 Adam 都是训练神经网络时常见的参数优化算法。面试里不要只说“Adam 收敛快，SGD 泛化好”，还要能解释它们更新参数时到底用了哪些梯度统计量，以及项目中怎么调参。

## 1. SGD 是什么

SGD（Stochastic Gradient Descent，随机梯度下降）每次用一个样本或一个 mini-batch 的梯度近似全量数据梯度，然后沿负梯度方向更新参数。

基本形式：

```text
theta = theta - lr * grad
```

其中：

1. `theta` 是模型参数。
2. `lr` 是学习率。
3. `grad` 是当前 mini-batch 上的梯度。

SGD 的特点：

1. 实现简单，内存开销小。
2. mini-batch 梯度有噪声，可能帮助跳出较差局部区域。
3. 对学习率比较敏感，学习率太大会震荡，太小会收敛慢。
4. 常配合 Momentum、Nesterov Momentum、学习率衰减使用。

Momentum 版本会累计历史梯度方向：

```text
v = beta * v + grad
theta = theta - lr * v
```

它能减少来回震荡，让参数在稳定方向上走得更快。

## 2. Adam 是什么

Adam（Adaptive Moment Estimation）结合了 Momentum 和 RMSProp 的思想，同时维护梯度的一阶矩估计和二阶矩估计。

核心更新：

```text
m = beta1 * m + (1 - beta1) * grad
v = beta2 * v + (1 - beta2) * grad^2

m_hat = m / (1 - beta1^t)
v_hat = v / (1 - beta2^t)

theta = theta - lr * m_hat / (sqrt(v_hat) + eps)
```

含义：

1. `m` 类似动量，记录梯度方向的指数滑动平均。
2. `v` 记录梯度平方的指数滑动平均，用来调整每个参数的步长。
3. `m_hat` 和 `v_hat` 是偏差修正，避免训练初期估计偏小。
4. `eps` 防止除零，也会影响极小梯度场景下的数值稳定性。

Adam 的特点：

1. 每个参数有自适应学习率，对稀疏梯度和尺度差异较大的参数更友好。
2. 前期通常收敛更快，调参门槛相对低。
3. 需要额外保存 `m` 和 `v`，显存/内存开销大于 SGD。
4. 权重衰减建议使用 AdamW，把 weight decay 从梯度自适应更新中解耦出来。

## 3. SGD 和 Adam 的区别

| 对比项 | SGD | Adam |
| --- | --- | --- |
| 更新依据 | 当前 mini-batch 梯度 | 梯度一阶矩和二阶矩 |
| 学习率 | 全局学习率为主 | 每个参数自适应步长 |
| 内存开销 | 低 | 需要额外保存 `m`、`v` |
| 收敛速度 | 常需要更细学习率策略 | 前期通常更快 |
| 泛化表现 | 在部分视觉任务中最终泛化可能更好 | 收敛快，但需关注泛化和 weight decay |
| 常见搭配 | Momentum、Nesterov、Step/Cosine LR | AdamW、Warmup、Cosine LR |

实践选择：

1. Transformer、LLM、推荐模型常以 AdamW 作为默认起点。
2. CNN 分类任务可以先用 AdamW 快速验证，再用 SGD + Momentum 做最终精调。
3. 小数据集容易过拟合时，优化器不是唯一因素，还要看数据增强、正则化和早停。

## 4. 项目训练怎么调参

一个可落地的调参顺序：

1. **先保证数据正确**：检查标签、归一化、缺失值、类别分布、训练/验证划分是否泄漏。
2. **确定基线**：用简单模型或默认 AdamW 跑通，记录训练损失、验证损失和关键指标。
3. **调学习率**：学习率是最关键超参数，可以用 LR finder、网格搜索或按数量级尝试。
4. **调 batch size**：大 batch 更稳定但可能泛化变差，小 batch 噪声大但显存友好。
5. **使用调度器**：常见策略有 warmup、cosine decay、step decay、ReduceLROnPlateau。
6. **控制过拟合**：weight decay、dropout、数据增强、early stopping、降低模型容量。
7. **控制不稳定**：梯度裁剪、降低学习率、检查初始化、混合精度下检查 loss scale。
8. **固定实验变量**：记录随机种子、数据版本、代码版本、超参数和指标，避免凭感觉调参。

常见现象和处理：

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| loss 爆炸或 NaN | 学习率过大、梯度爆炸、数据异常 | 降学习率、梯度裁剪、检查输入和标签 |
| train loss 降，val loss 升 | 过拟合 | 增强正则、早停、数据增强、减少模型容量 |
| train/val 都不降 | 学习率不合适、模型不足、特征无效 | 调学习率、检查数据、增大模型或训练轮数 |
| 指标波动大 | batch 太小、数据噪声大 | 增大 batch、滑动平均、多次实验取均值 |

## 5. 面试回答模板

SGD 用当前 mini-batch 梯度直接更新参数，简单省内存，但对学习率敏感，通常配合 Momentum 和学习率衰减。Adam 同时维护梯度的一阶矩和二阶矩，相当于既有动量又能给不同参数自适应步长，前期收敛通常更快，但内存开销更大，现代训练里常用 AdamW 处理权重衰减。项目调参时我会先确认数据和基线，再优先调学习率、batch size、优化器和 scheduler，最后根据过拟合、欠拟合、梯度不稳定等现象加正则、早停、梯度裁剪或数据增强。
