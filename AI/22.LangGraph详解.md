# LangGraph 详解

## 一、LangGraph 概述

### 1.1 什么是 LangGraph

LangGraph 是 LangChain 生态的一部分，用于构建有状态、多角色的 LLM 应用。通过图结构实现 Agent 编排，支持循环、条件分支、人机交互等复杂流程。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  LangGraph 核心定位：                                       │
│                                                             │
│  1. 有状态的 Agent 编排                                    │
│  2. 图结构建模工作流                                      │
│  3. 支持循环和条件分支                                   │
│  4. 人机交互与中断恢复                                    │
│  5. 多 Agent 协作                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

│  │                                                      │  │

│  │       └──┬───┘            │                         │  │

## 三、LangGraph 核心概念

### 3.1 图的基本结构

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated

# 定义状态
class AgentState(TypedDict):
    messages: list[str]
    next_action: str
    iteration_count: int

# 创建图
graph = StateGraph(AgentState)

# 添加节点
graph.add_node("agent", agent_node)
graph.add_node("tools", tool_node)

# 添加边
graph.add_edge("__start__", "agent")  # 入口
graph.add_edge("agent", END)           # 出口

# 编译
app = graph.compile()
```

### 3.2 状态管理

```python
from typing import TypedDict, Annotated
from langgraph.graph import add_messages
import operator

class AgentState(TypedDict):
    # 使用 add_messages 合并消息
    messages: Annotated[list, add_messages]
    
    # 使用 operator 累加
    counter: Annotated[int, operator.add]
    
    # 普通字段
    user_input: str
    context: dict

def agent_node(state: AgentState) -> AgentState:
    return {
        "messages": [f"Agent processed: {state['user_input']}"],
        "counter": 1,
    }
```

## 四、实战示例

### 4.1 基础 Agent

```python
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

# 初始化 LLM
llm = ChatOpenAI(model="gpt-4")

# 定义状态
class AgentState(TypedDict):
    messages: Annotated[list, add_messages]

# Agent 节点
def call_llm(state: AgentState):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

# 工具节点
def should_continue(state: AgentState) -> str:
    last_message = state["messages"][-1]
    if "需要工具" in str(last_message.content):
        return "tools"
    return END

# 构建图
graph = StateGraph(AgentState)
graph.add_node("llm", call_llm)
graph.add_edge("__start__", "llm")
graph.add_conditional_edges(
    "llm",
    should_continue,
    {"tools": "tools", END: END}
)
graph.add_node("tools", tool_node)
graph.add_edge("tools", "llm")

# 编译运行
app = graph.compile()
result = app.invoke({"messages": [HumanMessage(content="你好")]})
```

### 4.2 带记忆的聊天

```python
from langgraph.graph import StateGraph
from langgraph.checkpoint.sqlite import SqliteSaver

# 持久化检查点
checkpointer = SqliteSaver.from_conn_string(":memory:")

graph = StateGraph(AgentState)
# ... 添加节点和边 ...

app = graph.compile(checkpointer=checkpointer)

# 第一次对话
config = {"configurable": {"thread_id": "user-123"}}
app.invoke({"messages": [HumanMessage(content="我叫张三")]}, config)

# 第二次对话（带记忆）
app.invoke({"messages": [HumanMessage(content="我叫什么？")]}, config)
# 输出：您叫张三
```

### 4.3 工具调用 Agent

```python
from langchain_core.tools import tool

@tool
def calculate(expression: str) -> str:
    """执行数学计算"""
    return str(eval(expression))

@tool
def search(query: str) -> str:
    """搜索信息"""
    return f"搜索结果: {query}"

tools = [calculate, search]

# Agent 节点
def agent(state: AgentState):
    llm_with_tools = llm.bind_tools(tools)
    response = llm_with_tools.invoke(state["messages"])
    return {"messages": [response]}

# 工具节点
def tool_node(state: AgentState):
    last_message = state["messages"][-1]
    tool_calls = last_message.tool_calls
    
    results = []
    for call in tool_calls:
        tool = next(t for t in tools if t.name == call["name"])
        result = tool.invoke(call["args"])
        results.append(ToolMessage(content=str(result), tool_call_id=call["id"]))
    
    return {"messages": results}
```

## 五、高级特性

### 5.1 条件分支

```python
from langgraph.graph import Branch

# 定义条件分支
def route_based_on_intent(state: AgentState) -> str:
    intent = detect_intent(state["messages"][-1])
    if intent == "code":
        return "code_agent"
    elif intent == "search":
        return "search_agent"
    else:
        return "chat_agent"

# 添加条件边
graph.add_conditional_edges(
    "router",
    route_based_on_intent,
    {
        "code_agent": "code_agent",
        "search_agent": "search_agent",
        "chat_agent": "chat_agent",
    }
)
```

### 5.2 人机交互

```python
from langgraph.checkpoint import Interrupt

def human_review_node(state: AgentState):
    # 中断等待人工审核
    response = Interrupt({
        "question": "确认执行?",
        "state": state
    })
    return response

# 执行并中断
app = StateGraph(AgentState).compile()

# 第一阶段
app.invoke({"task": "删除数据"})

# 人工审核后继续
app.invoke(Command(resume={"approved": True}))
```

### 5.3 多 Agent 协作

```python
# 主管 Agent
def supervisor(state: AgentState):
    task = state["current_task"]
    
    # 分配给子 Agent
    if "代码" in task:
        return {"next": "coder"}
    elif "搜索" in task:
        return {"next": "researcher"}
    else:
        return {"next": END}

# 子 Agent
def coder(state: AgentState):
    code = generate_code(state["task"])
    return {"code": code, "messages": [f"生成代码: {code}"]}

def researcher(state: AgentState):
    results = search_web(state["task"])
    return {"results": results, "messages": [f"搜索结果: {results}"]}

# 构建层次图
graph = StateGraph(AgentState)
graph.add_node("supervisor", supervisor)
graph.add_node("coder", coder)
graph.add_node("researcher", researcher)
```

## 七、面试常见问题

### Q1: LangGraph 和 LangChain 的区别？

LangChain 是线性链，适合简单流程；LangGraph 是图结构，适合有状态、循环、条件分支的复杂 Agent。

### Q2: LangGraph 的状态如何管理？

通过 `TypedDict` 定义状态，使用 `Annotated` 标记需要特殊处理的字段（如 `add_messages` 合并消息、`operator.add` 累加）。

### Q3: LangGraph 如何实现持久化？

通过 `checkpointer`（如 `SqliteSaver`）保存图执行状态，支持从中断点恢复。

### Q4: LangGraph 适合什么场景？

1. 多步骤推理（ReAct、CoT）
2. 工具调用 Agent
3. 人机交互审批流程
4. 多 Agent 协作
5. 需要中断恢复的流程

## 八、总结

1. **LangGraph 定义**：基于图结构的有状态 Agent 编排框架
2. **核心概念**：节点（Node）、边（Edge）、状态（State）、检查点（Checkpoint）
3. **与 LangChain 区别**：图结构 vs 线性链，有状态 vs 无状态
4. **适用场景**：复杂 Agent、循环推理、多 Agent 协作、人机交互
5. **未来趋势**：与 LangChain 深度集成，扩展多 Agent 能力
