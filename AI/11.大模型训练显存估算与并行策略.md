# 11. 大模型训练显存估算与并行策略

面试里问“8B LM 训练需要多少静态显存”或“训练显存不够怎么办”，要先拆显存组成，再讲降低显存的训练策略。

## 1. 训练显存由什么组成

训练显存主要包括：

1. **参数 weights**：模型参数本身。
2. **梯度 gradients**：反向传播得到的梯度。
3. **优化器状态 optimizer states**：Adam 通常保存一阶矩和二阶矩。
4. **激活 activations**：前向中间结果，反向时要用。
5. **临时 buffer**：通信、attention、归一化、算子 workspace。
6. **KV cache / rollout cache**：RL 或长序列推理生成时额外占用。

静态显存估算一般先看前三项：参数、梯度、优化器状态。

## 2. 8B 模型静态显存估算

假设模型有 8B 参数。

### FP16/BF16 参数 + Adam 优化器

常见混合精度训练中：

1. 参数：BF16/FP16，2 bytes/param。
2. 梯度：BF16/FP16，2 bytes/param。
3. Adam 一阶矩：FP32，4 bytes/param。
4. Adam 二阶矩：FP32，4 bytes/param。
5. 有些实现还保存 FP32 master weights，4 bytes/param。

如果只按“参数 + 梯度 + Adam 两份状态”估算：

```text
2 + 2 + 4 + 4 = 12 bytes/param
8B * 12 bytes = 96GB
```

如果包含 FP32 master weights：

```text
2 + 2 + 4 + 4 + 4 = 16 bytes/param
8B * 16 bytes = 128GB
```

面经里说“大约参数显存的 6 倍”，通常是以 BF16 参数显存 `8B * 2 = 16GB` 为基准：

```text
参数 16GB
梯度 16GB
Adam m 32GB
Adam v 32GB
合计约 96GB = 参数显存 6 倍
```

这还没有算激活、通信 buffer 和碎片，所以真实训练需要更高显存，或必须做并行/重计算/低秩微调。

## 3. 显存不够怎么办

### 3.1 数据并行

数据并行每张卡放一份完整模型，切分 batch。优点简单，缺点是每张卡仍要完整保存参数、梯度和优化器状态。

适合：模型单卡放得下，但 batch 或吞吐需要扩展。

### 3.2 ZeRO

DeepSpeed ZeRO 把数据并行中的冗余状态切分到多张卡：

| 阶段 | 切分内容 | 效果 |
| --- | --- | --- |
| ZeRO-1 | optimizer states | 优化器状态按卡分片 |
| ZeRO-2 | optimizer states + gradients | 进一步切梯度 |
| ZeRO-3 | optimizer states + gradients + parameters | 参数也分片，单卡显存最低 |

ZeRO-3 显存省最多，但通信和调度更复杂。

### 3.3 张量并行

张量并行把单层矩阵乘拆到多张 GPU，例如把 attention head 或 FFN 隐层维度切分。它能让单层参数和计算跨卡分担，但需要频繁 all-reduce/all-gather。

适合：单层太大，无法单卡放下或单卡算不过来。

### 3.4 流水线并行

流水线并行按层切分模型，不同 GPU 负责不同层。通过 micro-batch 让多个 stage 同时工作。

优点：

1. 每张卡只保存部分层。
2. 适合层数深的大模型。

缺点：

1. 有 pipeline bubble。
2. stage 切分不均会负载不平衡。
3. 跨 stage 激活传输和调度复杂。

### 3.5 激活重计算

Activation Checkpointing 不保存所有中间激活，反向时重新计算一部分前向，换显存为计算。

适合：激活显存占比较高，训练吞吐还能接受下降。

### 3.6 LoRA 和 QLoRA

LoRA 冻结原模型参数，只训练低秩适配矩阵：

```text
W 不更新
Delta W = A * B
只训练 A、B
```

优点是可训练参数少、优化器状态少、显存下降明显。

QLoRA 进一步把基础模型量化到 4-bit，只通过量化权重反传到 LoRA adapter，常配合 NF4、double quantization 和 paged optimizer 降低显存峰值。

适合：微调和对齐，不适合从头训练基础模型。

## 4. 真实训练组合

大模型训练常组合多种技术：

```text
FSDP/ZeRO-3
+ tensor parallel
+ pipeline parallel
+ activation checkpointing
+ flash attention
+ sequence packing
+ gradient accumulation
+ bf16
```

RLHF/GRPO 训练还要考虑 rollout 生成显存。训练侧可能用 FSDP/ZeRO/Megatron，生成侧用 vLLM/SGLang 加速，并通过 Ray 调度 actor、reference、reward、rollout worker。

## 5. 面试回答模板

8B 模型如果用 BF16 参数训练，参数本身大约 `8B*2=16GB`。静态显存至少还要梯度 16GB、Adam 一阶矩 32GB、二阶矩 32GB，加起来约 96GB，也就是参数显存的 6 倍；如果还有 FP32 master weights 会更高。这还没算激活和通信 buffer。显存不够时可以用 ZeRO/FSDP 切参数、梯度和优化器状态，用张量并行切单层矩阵，用流水线并行切层，用 activation checkpointing 换计算省激活，用 LoRA/QLoRA 做参数高效微调，还可以通过 bf16、flash attention、sequence packing、gradient accumulation 和 vLLM rollout 优化整体资源。
