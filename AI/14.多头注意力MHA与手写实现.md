# 14. 多头注意力 MHA 与手写实现

Multi-Head Attention（MHA）是 Transformer 的核心模块。它把同一组输入投影到多个注意力子空间，每个 head 学习不同关系，再把各 head 输出拼接并线性变换。

## 1. Scaled Dot-Product Attention

给定：

```text
Q: query
K: key
V: value
```

注意力计算：

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V
```

为什么除以 `sqrt(d_k)`：

1. `d_k` 很大时，点积方差会变大。
2. softmax 输入过大容易饱和，梯度变小。
3. 缩放能让训练更稳定。

## 2. Multi-Head Attention

MHA 不是只算一次 attention，而是把 hidden size 拆成多个 head：

```text
X
-> Q = XWq, K = XWk, V = XWv
-> reshape: [B, T, H] -> [B, heads, T, head_dim]
-> 每个 head 单独 attention
-> concat heads
-> output projection
```

约束：

```text
hidden_size % num_heads == 0
head_dim = hidden_size / num_heads
```

## 3. Mask

常见 mask：

1. **Padding mask**：屏蔽 padding token，避免模型关注无效位置。
2. **Causal mask**：Decoder 自回归生成时屏蔽未来 token。
3. **Attention bias**：某些模型用 bias 表示相对位置或特殊约束。

Causal mask 形状通常可广播到 `[B, heads, T, T]`。

## 4. NumPy 手写 MHA

下面是面试手写版本，重点是 shape 正确和 softmax 稳定。

```python
import numpy as np


def softmax(x, axis=-1):
    x = x - np.max(x, axis=axis, keepdims=True)
    e = np.exp(x)
    return e / np.sum(e, axis=axis, keepdims=True)


def multi_head_attention(x, wq, wk, wv, wo, num_heads, mask=None):
    # x:  [B, T, D]
    # w*: [D, D]
    b, t, d = x.shape
    assert d % num_heads == 0
    head_dim = d // num_heads

    q = x @ wq
    k = x @ wk
    v = x @ wv

    def split_heads(y):
        # [B, T, D] -> [B, heads, T, head_dim]
        return y.reshape(b, t, num_heads, head_dim).transpose(0, 2, 1, 3)

    q = split_heads(q)
    k = split_heads(k)
    v = split_heads(v)

    scores = q @ k.transpose(0, 1, 3, 2)
    scores = scores / np.sqrt(head_dim)

    if mask is not None:
        # mask 中 True 表示允许关注，False 表示屏蔽
        scores = np.where(mask, scores, -1e30)

    attn = softmax(scores, axis=-1)
    out = attn @ v  # [B, heads, T, head_dim]

    out = out.transpose(0, 2, 1, 3).reshape(b, t, d)
    return out @ wo
```

构造 causal mask：

```python
def causal_mask(seq_len):
    m = np.tril(np.ones((seq_len, seq_len), dtype=bool))
    return m[None, None, :, :]
```

## 5. 复杂度和优化

对序列长度 `T`，hidden size `D`：

1. 注意力矩阵大小是 `T*T`。
2. 时间复杂度约 `O(B * heads * T^2 * head_dim)`，也就是 `O(B*T^2*D)`。
3. 显存复杂度主要来自 attention scores 和 KV cache。

优化方向：

1. FlashAttention：减少 attention 中间矩阵落显存。
2. GQA/MQA：多个 query head 共享较少 KV head，减少 KV cache。
3. Sliding Window Attention：只关注局部窗口，降低长序列成本。
4. MLA/低秩 KV：压缩 KV 表示，降低缓存显存。
5. PagedAttention：推理服务中分页管理 KV cache。

## 6. MoT 和 MHA 的关系

面经中的 MoT（Mixture of Transformer）描述是“图片和文本分别过 FFN 层，再 concat 做 self-attention”。可以抽象为：

```text
image tokens -> image FFN/projection
text tokens  -> text FFN/projection
concat tokens
-> self-attention 做跨模态交互
```

重点仍是 MHA：concat 后的 token 序列通过 self-attention，让文本 token 可以关注图像 token，图像 token 也可以关注文本 token。工程上要处理模态位置编码、attention mask、token 长度和显存复杂度。

## 7. 面试回答模板

MHA 先把输入投影成 Q/K/V，再 reshape 成多个 head。每个 head 计算 `softmax(QK^T/sqrt(d_k))V`，最后把各 head 拼接并过输出线性层。手写时重点是 shape：`[B,T,D] -> [B,H,T,D/H]`，scores 是 `[B,H,T,T]`，mask 要能广播，softmax 前要减最大值保证数值稳定。复杂度是序列长度平方级，长上下文会被 attention 矩阵和 KV cache 卡住，所以工程上会用 FlashAttention、GQA/MQA、窗口注意力、KV 压缩或 vLLM 的分页 KV 管理。
