# 37. 梯度检查点技术原理与权衡分析

## 1. 问题背景

梯度检查点（Gradient Checkpointing / Activation Checkpointing）是一种用计算换显存的技术，通过在反向传播时重新计算中间激活值，避免保存所有前向传播的激活值，大幅降低显存占用。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  显存占用组成：                                            │
│                                                             │
│  • 参数（Weights）：固定，不可优化                         │
│  • 激活值（Activations）：可优化                          │
│  • 梯度（Gradients）：与激活值相关                         │
│  • 优化器状态（Optimizer States）：Adam 等需保存            │
│                                                             │
│  梯度检查点核心思想：                                      │
│  • 不保存所有激活值                                       │
│  • 在反向传播时重新计算                                   │
│  • 用计算时间换显存                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| OOM 错误 | 激活值过大导致显存不足 |
| Batch size 受限 | 无法使用大 batch size |
| 模型深度受限 | 深网络无法训练 |
| 训练速度慢 | 计算量增加 |

---

## 3. 影响范围

- 大模型预训练（Swin Transformer、VIT 等）
- 深度网络（100+ 层）
- 显存受限场景（消费级 GPU）
- 分布式训练

## 4. 原因分析

### 4.1 显存占用分析

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  前向传播显存占用：                                        │
│                                                             │
│  对于 Transformer Layer：                                   │
│  • Input: [B, S, H]                                      │
│  • QKV: [B, S, 3H]                                        │
│  • Attention: [B, S, S] × Heads                          │
│  • Output: [B, S, H]                                      │
│                                                             │
│  单层激活值大小 ≈ 序列长度 × batch_size × hidden_dim × layers  │
│                                                             │
│  示例：B=4, S=2048, H=4096, L=32                         │
│  激活值 ≈ 4 × 2048 × 4096 × 32 × 4 bytes ≈ 4 GB/layer   │
│  32 层总计 ≈ 128 GB（仅激活值！）                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 传统前向传播 vs 检查点

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  传统方式（前向保留所有激活值）：                         │
│                                                             │
│  Forward: A1 → A2 → A3 → A4 → Loss                      │
│  │        ↓    ↓    ↓    ↓                               │
│  │       保存  保存  保存  保存                           │
│  │        ↓                                     │           │
│  Backward: Loss → grad(A4) → grad(A3) → grad(A2) → grad(A1)│
│                                                             │
│  显存：O(n) - 保存所有激活值                               │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  检查点方式（只保存部分激活值）：                         │
│                                                             │
│  Forward: A1 → A2 → A3 → A4 → Loss                      │
│  │              ↑             ↑                            │
│  │          检查点        检查点                            │
│  │                        ↓                                │
│  Backward: Loss → recompute A3 → A2 → A1                 │
│                                                             │
│  显存：O(√n) - 只保存检查点处的激活值                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 时间空间权衡

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  梯度检查点权衡：                                         │
│                                                             │
│  • 显存节省：约 50-70%                                   │
│  • 计算增加：约 20-30%（重新计算）                       │
│  • 内存带宽：增加（重新计算需要读取权重）                 │
│                                                             │
│  策略：                                                   │
│  • 理想情况：选择 √n 个检查点                            │
│  • 经验法则：每 √n 层设置一个检查点                      │
│  • 深层网络：可设置更多检查点                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 PyTorch 实现

```python
# PyTorch 梯度检查点实现

import torch
import torch.nn as nn
from torch.utils.checkpoint import checkpoint, checkpoint_sequential

class TransformerBlock(nn.Module):
    """Transformer 层，支持梯度检查点"""
    
    def __init__(self, hidden_dim, num_heads):
        super().__init__()
        self.attention = nn.MultiheadAttention(hidden_dim, num_heads)
        self.ffn = nn.Sequential(
            nn.Linear(hidden_dim, 4 * hidden_dim),
            nn.GELU(),
            nn.Linear(4 * hidden_dim, hidden_dim)
        )
        self.norm1 = nn.LayerNorm(hidden_dim)
        self.norm2 = nn.LayerNorm(hidden_dim)
    
    def forward(self, x):
        # 自注意力 + 残差
        attn_out, _ = self.attention(x, x, x)
        x = self.norm1(x + attn_out)
        
        # FFN + 残差
        ffn_out = self.ffn(x)
        x = self.norm2(x + ffn_out)
        
        return x

class CheckpointedTransformer(nn.Module):
    """使用梯度检查点的 Transformer"""
    
    def __init__(self, num_layers, hidden_dim, num_heads):
        super().__init__()
        self.embedding = nn.Embedding(10000, hidden_dim)
        self.layers = nn.ModuleList([
            TransformerBlock(hidden_dim, num_heads)
            for _ in range(num_layers)
        ])
        self.num_layers = num_layers
    
    def forward(self, input_ids):
        x = self.embedding(input_ids)
        
        # 方法 1：checkpoint_sequential（推荐用于 Sequential）
        # 每 2 层一个检查点
        modules = [module for layer in self.layers for module in [layer]]
        x = checkpoint_sequential(modules, 2, x)
        
        return x
    
    def forward_with_custom_checkpointing(self, x):
        """自定义检查点策略"""
        for i, layer in enumerate(self.layers):
            # 每 4 层设置一个检查点
            if i % 4 == 0:
                x = checkpoint(layer, x, use_reentrant=False)
            else:
                x = layer(x)
        
        return x
```

### 5.2 自定义检查点函数

```python
# 自定义检查点实现

def checkpointed_layer(module, *args, **kwargs):
    """
    使用 torch.utils.checkpoint.checkpoint
    use_reentrant=True: 更快，但不能用某些优化
    use_reentrant=False: 更安全，支持 gradient checkpointing
    """
    return checkpoint(
        module,
        *args,
        use_reentrant=False,  # 推荐设置
        **kwargs
    )

# 自定义反向传播逻辑
class CustomCheckpointFunction(torch.autograd.Function):
    """自定义检查点函数"""
    
    @staticmethod
    def forward(ctx, run_function, *args):
        # 保存函数和输入
        ctx.run_function = run_function
        ctx.save_for_backward(*args)
        
        # 只保存检查点的输出
        with torch.no_grad():
            output = run_function(*args)
        
        return output
    
    @staticmethod
    def backward(ctx, *grad_outputs):
        # 重新计算前向传播
        args = ctx.saved_tensors
        output = ctx.run_function(*args)
        
        # 计算梯度
        torch.autograd.backward(output, grad_outputs)
```

### 5.4 混合检查点策略

```python
# 混合策略：部分层使用检查点

class SelectiveCheckpointing(nn.Module):
    """选择性梯度检查点"""
    
    def __init__(self, model, checkpoint_every_n=2):
        super().__init__()
        self.model = model
        self.checkpoint_every_n = checkpoint_every_n
        self.checkpointed_layers = set()
    
    def _should_checkpoint(self, layer_idx):
        """判断是否应该设置检查点"""
        return layer_idx % self.checkpoint_every_n == 0
    
    def forward(self, x):
        for i, layer in enumerate(self.model.layers):
            if self._should_checkpoint(i):
                x = checkpoint(layer, x, use_reentrant=False)
                self.checkpointed_layers.add(i)
            else:
                x = layer(x)
        
        return x
    
    def get_checkpoint_ratio(self):
        """返回检查点覆盖率"""
        total = len(self.model.layers)
        checked = len(self.checkpointed_layers)
        return checked / total
```

```python
# 验证梯度检查点

def verify_checkpointing(model, input_ids):
    """验证检查点是否正确"""
    
    # 1. 启用检查点
    model.gradient_checkpointing_enable()
    
    # 2. 前向传播
    with torch.cuda.amp.autocast():
        output1 = model(input_ids)
        loss1 = output1.logits.sum()
    
    # 3. 反向传播
    loss1.backward()
    
    # 4. 检查梯度
    for name, param in model.named_parameters():
        if param.grad is not None:
            assert not torch.isnan(param.grad).any(), f"NaN in {name}"
            assert not torch.isinf(param.grad).any(), f"Inf in {name}"
```

## 11. 总结

1. **核心原理**：用计算换显存，保存部分激活值，反向时重新计算
2. **显存节省**：约 50-70%，具体取决于检查点策略
3. **计算开销**：约 20-30%，可通过调整间隔优化
4. **实现方式**：checkpoint / checkpoint_sequential
5. **最佳实践**：配合混合精度 + ZeRO + 适当检查点间隔
