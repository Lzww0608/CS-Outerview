# LLM Tokenize 原理与规则详解

## 一、什么是 Tokenize

Tokenize（分词/标记化）是 LLM 处理文本的第一步，将原始文本转换成模型能处理的 token 序列。

### 1.1 Token 的定义

Token 是文本的最小处理单元，可以是：
- 完整单词（如 "hello", "world"）
- 单词片段（如 "hell", "o", "world"）
- 子词（如 "un", "##break", "##able"）
- 标点符号（如 ",", "."）
- 特殊符号（如 "[PAD]", "[UNK]"）

### 1.2 为什么需要 Tokenize

## 二、主流 Tokenize 方法

### 2.1 BPE（Byte Pair Encoding）

**原理**：基于频率的子词分词，通过合并最常见的字符对来构建词表。

**算法流程**：

```python
# 1. 初始化：每个字符作为一个 token
vocab = ['a', 'b', 'c', 'd', ...]

# 2. 统计相邻字符对的频率
text = "aaabba"
pairs = [("a","a"), ("a","a"), ("a","b"), ("b","b"), ("b","a")]

# 3. 合并最常见的对（如 "aa" 出现2次）
# aa + bb -> aabb

# 4. 重复直到达到词表大小
```

**GPT-2、GPT-3 使用 BPE**

### 2.2 WordPiece

**原理**：基于语言学的子词分词，从词根词缀构建词表。

**特点**：
- 使用 "##" 前缀标记子词
- 贪心算法构建词表
- Google 的 BERT 使用 WordPiece

**示例**：

```python
原始: "unbelievable"
分词: ["un", "##believ", "##able"]
```

### 2.3 SentencePiece

**原理**：无监督文本分词，支持字节级别的 BPE。

**特点**：
- 不依赖空格
- 统一处理所有语言
- Google 的 T5、ALBERT 使用

### 2.4 TikToken（GPT-4/BPE 变体）

**原理**：优化的 BPE 实现，使用预计算和并行化。

## 三、Tokenize 规则详解

### 3.1 特殊标记（Special Tokens）

| Token | 含义 | 用途 |
|-------|------|------|
| [PAD] | 填充 | 批处理时补齐长度 |
| [UNK] | 未知 | 未登录词 |
| [CLS] | 分类 | 分类任务起始 |
| [SEP] | 分隔 | 分隔多个句子 |
| [MASK] | 掩码 | 掩码语言模型 |

### 3.2 常见分词规则

```python
# 英文分词示例（GPT-2 BPE）
text = "Hello, world! Hello again."
tokens = encode(text)
# 可能结果: [15496, 11, 1917, 0, 15496, 1049, 13]

# 中文分词示例（BBPE/WordPiece）
text = "今天天气真好"
tokens = encode(text)
# 可能结果: [100, 200, 300, 400, 500]
```

### 3.3 字节级别分词

```python
# UTF-8 字节编码
text = "你好"
bytes = text.encode('utf-8')
# [228, 189, 160, 229, 165, 189]

# GPT-2 的 BPE 在字节上运行
# 避免 UNK，支持所有语言
```

## 四、Tokenize 实践

### 4.1 Python 实现示例

```python
# 使用 transformers 库
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("gpt2")
text = "Hello, world!"
tokens = tokenizer.encode(text, return_tensors="pt")

print(tokens)
# tensor([[15496,    11,  1917,     0]])
```

### 4.2 中文 Tokenize

```python
# ChatGLM 使用 SentencePiece
tokenizer = AutoTokenizer.from_pretrained("chatglm-6b", trust_remote_code=True)

text = "今天天气真好"
tokens = tokenizer.encode(text)

print(tokens)
# [131, 203, 345, 203, 456, 789]
```

## 五、面试常见问题

### Q1: 为什么 LLM 使用子词分词？

1. **处理未知词**：可以切分未见过的单词
2. **控制词表大小**：避免词典爆炸
3. **语义保留**：保留词根词缀的语义
4. **多语言支持**：字节级 BPE 可以处理任意语言

### Q2: BPE 和 WordPiece 的区别？

| 特性 | BPE | WordPiece |
|------|-----|-----------|
| 合并依据 | 最高频率 | 最大似然 |
| 子词标记 | 无特殊标记 | "##" 前缀 |
| 代表模型 | GPT | BERT |

### Q3: Token 数量如何影响 LLM 成本？

1. API 按 token 计费
2. 上下文窗口限制（token 数量）
3. 计算成本与 token 数量成正比

## 六、总结

1. Tokenize 是 LLM 的第一步
2. 主流方法：BPE、WordPiece、SentencePiece
3. 通过子词分词实现未知词处理和词表压缩
4. 特殊标记处理分类、分隔等任务
