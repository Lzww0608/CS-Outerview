# 36. 混合精度训练原理与实现细节

## 1. 问题背景

混合精度训练（Mixed Precision Training）通过结合不同精度的数值格式，显著降低显存占用和计算时间，同时保持模型精度，是大模型训练的必备技术。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  混合精度核心思想：                                        │
│                                                             │
│  • 前向传播：FP32 Master Weights + FP16 Computation       │
│  • 反向传播：FP16 Gradients                               │
│  • 优化器状态：FP32 (Adam 等动量)                         │
│                                                             │
│  效果：显存降低 50%+，速度提升 30-50%                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 显存不足 | FP32 训练OOM |
| 训练速度慢 | 计算瓶颈 |
| 精度损失 | 低精度溢出 |
| NaN/Inf | 数值不稳定 |

---

## 3. 影响范围

- 所有大模型训练任务
- Transformer 类模型
- 分布式训练场景
- 生产部署优化

## 4. 原因分析

### 4.1 数值精度类型

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  常见数值格式：                                           │
│                                                             │
│  FP32 (Float32)：                                         │
│  • 32 bits = 1 sign + 8 exponent + 23 mantissa           │
│  • 精度：~7 位十进制                                      │
│  • 显存：4 bytes/param                                    │
│                                                             │
│  FP16 (Float16)：                                         │
│  • 16 bits = 1 sign + 5 exponent + 10 mantissa            │
│  • 精度：~3-4 位十进制                                    │
│  • 显存：2 bytes/param                                    │
│  • 范围：±65504                                           │
│                                                             │
│  BF16 (BFloat16)：                                       │
│  • 16 bits = 1 sign + 8 exponent + 7 mantissa            │
│  • 精度：~2-3 位十进制                                    │
│  • 显存：2 bytes/param                                    │
│  • 范围：与 FP32 相同（指数相同）                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 FP16 的问题

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  FP16 的局限性：                                          │
│                                                             │
│  问题 1：下溢（Underflow）                                │
│  • 梯度值太小，低于 FP16 表示范围                        │
│  • 梯度变为 0                                            │
│  • 模型无法更新                                          │
│                                                             │
│  问题 2：溢出（Overflow）                                 │
│  • 梯度值太大，超过 FP16 最大值                          │
│  • 梯度变为 INF                                          │
│  • 训练崩溃                                              │
│                                                             │
│  问题 3：精度不足                                        │
│  • 权重更新量级不对                                      │
│  • 累积误差影响收敛                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 混合精度解决方案

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  混合精度策略：                                           │
│                                                             │
│  • Master Weights：FP32 保存                               │
│    → 保证权重精度                                          │
│                                                             │
│  • Forward/Backward：FP16 计算                             │
│    → 加速计算，节省显存                                    │
│                                                             │
│  • Gradients：FP16                                        │
│    → 减少通信量                                            │
│                                                             │
│  • Optimizer States：FP32                                 │
│    → 动量、方差精确累积                                    │
│                                                             │
│  • Loss Scale：动态调整                                   │
│    → 防止梯度下溢                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 PyTorch AMP 实现

```python
# PyTorch 原生 AMP 实现

import torch
from torch.cuda.amp import autocast, GradScaler

class MixedPrecisionTrainer:
    """混合精度训练器"""
    
    def __init__(self, model, optimizer, init_scale=2**16):
        self.model = model
        self.optimizer = optimizer
        # 动态 Loss Scale
        self.scaler = GradScaler(init_scale=init_scale)
    
    def train_step(self, batch):
        # 1. Forward with FP16
        with autocast(dtype=torch.float16):
            outputs = self.model(**batch)
            loss = outputs.loss
        
        # 2. Backward with Loss Scaling
        self.optimizer.zero_grad()
        self.scaler.scale(loss).backward()
        
        # 3. Unscale gradients for clipping/checking
        self.scaler.unscale_(self.optimizer)
        
        # 4. Gradient clipping
        torch.nn.utils.clip_grad_norm_(self.model.parameters(), max_norm=1.0)
        
        # 5. Optimizer step with unscaled gradients
        self.scaler.step(self.optimizer)
        
        # 6. Update scale for next iteration
        self.scaler.update()
        
        return loss.item()
```

        # GradScaler for each rank
        self.scaler = GradScaler()
        
        # 同步 BN
        self.model = sync_batchnorm(self.model)
    
    def train_step(self, batch):
        with autocast(dtype=torch.float16):
            outputs = self.model(**batch)
            loss = outputs.loss
        
        # Scale loss
        self.scaler.scale(loss).backward()
        
        # AllReduce gradients
        self.scaler.unscale_(self.optimizer)
        
        # 梯度同步（自动通过 DDP）
        self.model.backward(loss)
        
        # 优化器步骤
        self.scaler.step(self.optimizer)
        self.scaler.update()
        
        # 同步 loss（用于日志）
        reduced_loss = loss.clone()
        dist.all_reduce(reduced_loss)
        reduced_loss /= dist.get_world_size()
        
        return reduced_loss.item()

### 5.5 Loss Scale 动态调整

```python
# 动态 Loss Scale 实现

class DynamicLossScaler:
    """动态 Loss Scale 管理器"""
    
    def __init__(self, 
                 init_scale=2**16,
                 scale_factor=2.0,
                 scale_window=1000,
                 min_scale=1.0):
        self.scale = init_scale
        self.scale_factor = scale_factor
        self.scale_window = scale_window
        self.min_scale = min_scale
        
        self._iter = 0
        self._overflow_count = 0
    
    def scale_loss(self, loss):
        """缩放 loss"""
        return loss * self.scale
    
    def update_scale(self, overflow):
        """更新 scale"""
        if overflow:
            # 溢出：减小 scale
            self.scale /= self.scale_factor
            self._overflow_count += 1
            
            if self.scale < self.min_scale:
                self.scale = self.min_scale
        else:
            # 正常：增加 scale
            self._iter += 1
            if self._iter >= self.scale_window:
                self.scale *= self.scale_factor
                self._iter = 0
        
        return self.scale
    
    def check_overflow(self, params):
        """检查是否有 NaN/Inf"""
        for p in params:
            if p.grad is not None:
                if torch.isnan(p.grad).any() or torch.isinf(p.grad).any():
                    return True
        return False
```

## 11. 总结

1. **核心原理**：FP16 计算 + FP32 权重 + 动态 Loss Scale
2. **BF16 优势**：指数位与 FP32 相同，训练更稳定
3. **实现关键**：GradScaler、梯度裁剪、溢出检测
4. **框架支持**：PyTorch AMP、DeepSpeed、Megatron
5. **最佳实践**：大模型用 BF16，推理用 INT8
