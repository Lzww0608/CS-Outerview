# CS-Outerview

收集网络各种资源，以及自己整理。总结出一套可以直接面试回答的集合。

## 项目定位

本仓库主要面向计算机相关岗位面试复习，内容覆盖 C++、Go、Linux、计算机网络、数据库、中间件、分布式、系统设计、手撕代码、设计题与真实面经。多数文档以问题、概念拆解、实现思路或面试回答模板的形式整理，方便快速查漏补缺和临场复盘。

## 使用建议

如果目标是快速准备面试，可以先按岗位方向选择主线：

1. C++ 后端：优先阅读 `cpp/`、`Linux/`、`计算机网络/`、`数据库/`、`中间件/`、`分布式/`。
2. Go 后端：优先阅读 `go/`、`Linux/`、`计算机网络/`、`中间件/`、`分布式/`。
3. 系统设计：优先阅读 `systemdesign/`、`设计题/`、`中间件/`、`数据库/`、`分布式/`。
4. 真题复盘：结合 `面经真题/` 中对应公司的问题，再回到相关专题目录补齐知识点。
