# CS-Outerview

收集网络各种资源，以及自己整理。总结出一套可以直接面试回答的集合。

## 项目定位

本仓库主要面向计算机相关岗位面试复习，内容覆盖 C++、Go、Linux、计算机网络、数据库、中间件、分布式、系统设计、手撕代码、设计题与真实面经。多数文档以问题、概念拆解、实现思路或面试回答模板的形式整理，方便快速查漏补缺和临场复盘。

## 目录说明

| 目录 | 内容简介 |
| --- | --- |
| `cpp/` | C++ 面试知识点，包含语法特性、STL/智能指针、并发、内存管理、网络与工程实践问题；同时整理了 GCC、GDB、内存泄漏排查等工具相关内容。 |
| `go/` | Go 语言面试题与知识点，覆盖 goroutine、channel、defer、error/panic、零值、GC、map、context、逃逸分析、调度、pprof、sync.Map、反射、Gin/Kratos 等常见考点。 |
| `rust/` | Rust 学习与实验代码，目前以 futures/异步编程相关示例和概念整理为主。 |
| `Linux/` | Linux 系统知识，包含 CPU 中断/调度、内存、文件系统、IPC、线程、epoll、零拷贝、常用命令等底层与工程实践内容。 |
| `计算机网络/` | 网络协议与原理，包含 OSI/TCP-IP 网络模型、ARP、HTTP/SSE、TCP 三次握手与四次挥手、Ping、Traceroute，以及 BBR、CUBIC、DCTCP、RENO、Vegas 等拥塞控制算法。 |
| `计算机基础/` | 通用底层基础，包含 GC、锁、无锁队列、缓存淘汰、内存池、哈希、排序下界/线性排序、日志系统、websocket、软件发布策略等内容。 |
| `数据库/` | 数据库面试知识，当前主要包含 MySQL 事务/锁/binlog/B+树索引/SQL 语句分类，以及 LevelDB 写入流程等存储引擎内容。 |
| `中间件/` | 常见中间件专题，包含 Redis Bitmap/布隆过滤器、Canal、Kafka、MQ、RPC 的原理、架构、可靠性、高可用、性能优化和典型面试问答。 |
| `分布式/` | 分布式系统基础，包含微服务、CAP、分布式 ID、一致性协议、Merkle Tree、分布式哈希、负载均衡、docker 等主题。 |
| `systemdesign/` | 系统设计专题，包含项目复盘、RAG/向量数据库、限流器、短链接、聊天系统、Feed 流、通知系统、搜索补全、网盘、YouTube、爬虫、KVStore、一致性哈希等典型设计题。 |
| `设计题/` | 偏开放式的场景设计题，包含日志系统、抢红包、网盘限速、二维码、VPN 访问链路、大文件统计、海量数据判重、分布式 ID 迁移等问题。 |
| `手撕代码/` | 手写代码题与实现思路，包含出栈顺序、memmove、IPv4 转整数、快照数组、有限状态机、螺旋打印二维数组、版本号排序、链表判环、合并两个有序数组等题目。 |
| `智力题/` | 概率、逻辑推理等智力题整理，例如扑克牌概率问题。 |
| `面经真题/` | 真实公司面经汇总，按公司分类整理，覆盖腾讯、字节、阿里、拼多多、小米、网易、京东、百度、微软等多家公司。 |
| `pic/` | 文档中使用的配图资源，主要包括系统设计、限流算法、GC、KVStore、Feed、通知系统等示意图。 |

## 使用建议

如果目标是快速准备面试，可以先按岗位方向选择主线：

1. C++ 后端：优先阅读 `cpp/`、`Linux/`、`计算机网络/`、`数据库/`、`中间件/`、`分布式/`。
2. Go 后端：优先阅读 `go/`、`Linux/`、`计算机网络/`、`中间件/`、`分布式/`。
3. 系统设计：优先阅读 `systemdesign/`、`设计题/`、`中间件/`、`数据库/`、`分布式/`。
4. 真题复盘：结合 `面经真题/` 中对应公司的问题，再回到相关专题目录补齐知识点。
