# Q24.init()函数初始化顺序

+ init() 函数用于程序执行前做包初始化，比如初始化注册表、全局变量、驱动插件等。
+ 一个包可以出现多个 init() 函数，一个源文件也可以包含多个 init() 函数。
+ 初始化顺序是：先初始化被 import 的包，再初始化当前包；同一个包内先初始化包级变量，再执行 init()。
+ 同一个源文件内，多个 init() 按出现顺序执行；同一个包跨文件的顺序由编译器接收文件顺序决定，工程上不要依赖跨文件 init 顺序。
+ init() 函数不能被显式调用、不能被引用（赋值给函数变量），否则编译错误。
+ 一个包被引用多次，如 A import B、C import B、A import C，B 只会初始化一次。
+ import 不能出现循环依赖，即 A import B、B import A 会编译失败。

代码示例如下所示：

```go
package mypackage

import "fmt"

func init() {
	fmt.Println("Mypackage Init Function")
}

func MyFunction() {
	fmt.Println("Hello from MyFunction!")
}

var MyVariable = "Hello from MyVariable"

```

```go
package main

import (
	"fmt"
	"myproject/mypackage"
)

var a = c + b // Declaration and initialization of variables

var b = 1
var c = 2

func init() {
	fmt.Println("Init function")
}

func main() {
	fmt.Println("main function")
	mypackage.MyFunction()
	fmt.Println(mypackage.MyVariable)
}
```

## 面试回答模板

`init` 是包初始化钩子，不能被手动调用。Go 程序启动时会按 import 依赖先初始化被依赖包，每个包内部先初始化包级变量，再执行该包的 `init`，最后才执行 `main.main`。一个包可以有多个 `init`，同文件按代码顺序执行，跨文件不要依赖具体顺序。`init` 适合注册驱动、初始化配置和做轻量准备，但不适合做耗时网络调用或复杂业务逻辑，否则会拖慢程序启动并增加隐式依赖。
