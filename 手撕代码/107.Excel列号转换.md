# 107. Excel 列号转换

## 题目

实现 Excel 表格列头和数字之间的转换：

```text
1 -> A
26 -> Z
27 -> AA
28 -> AB

A -> 1
Z -> 26
AA -> 27
AB -> 28
```

## 1. 数字转列头

Excel 列号本质是没有 0 的 26 进制。普通 26 进制是 `0..25`，Excel 是 `A..Z` 对应 `1..26`，所以每次取余前要先 `--n`。

```cpp
#include <algorithm>
#include <string>
using namespace std;

string numToTitle(int n) {
    if (n <= 0) {
        return "";
    }

    string ans;
    while (n > 0) {
        --n;
        ans.push_back(static_cast<char>('A' + n % 26));
        n /= 26;
    }

    reverse(ans.begin(), ans.end());
    return ans;
}
```

## 2. 列头转数字

从左到右按 26 进制累加：

```cpp
#include <climits>
#include <string>
using namespace std;

int titleToNum(const string& s) {
    long long ans = 0;
    for (char ch : s) {
        if (ch < 'A' || ch > 'Z') {
            return -1;
        }
        ans = ans * 26 + (ch - 'A' + 1);
        if (ans > INT32_MAX) {
            return -1;
        }
    }
    return static_cast<int>(ans);
}
```

## 3. 为什么数字转列头要先减一

以 `26 -> Z` 为例：

```text
如果直接 26 % 26 = 0，会得到 A 或空位，这是错误的。
先减一后 25 % 26 = 25，对应 Z。
```

再看 `27 -> AA`：

```text
27 - 1 = 26, 26 % 26 = 0 -> A
26 / 26 = 1
1 - 1 = 0, 0 % 26 = 0 -> A
结果 AA
```

## 4. 易错点

1. Excel 列号从 1 开始，没有 0。
2. 数字转列头要先 `--n` 再取模。
3. 列头转数字要校验字符范围。
4. 输入很长时可能溢出，要用 `long long` 中间变量或约定返回错误。
5. 如果允许小写，要先转大写或扩展校验逻辑。

## 5. 面试回答模板

Excel 列号是没有 0 的 26 进制。数字转列头时，每轮先 `n--`，再用 `n % 26` 得到当前字符，最后 `n /= 26`，因为 `A..Z` 对应的是 `1..26` 而不是 `0..25`。列头转数字则按普通进制从左到右累加：`ans = ans * 26 + 当前字符值`。要注意非法字符和整数溢出。
