# 根据中序和后序构建前序

给定二叉树中序遍历和后序遍历，要求输出前序遍历。核心是：后序最后一个元素是根节点；中序中根节点左边是左子树，右边是右子树。

## 核心思路

遍历定义：

```text
前序: 根 -> 左 -> 右
中序: 左 -> 根 -> 右
后序: 左 -> 右 -> 根
```

递归处理一个子树：

1. 后序区间最后一个值是根。
2. 在中序区间找到根的位置 `idx`。
3. 左子树大小 `left_size = idx - in_l`。
4. 前序先输出根。
5. 递归处理左子树。
6. 递归处理右子树。

为了避免每次在线性中序中找根，用哈希表记录 `value -> index`。

## 代码：直接生成前序

```cpp
#include <unordered_map>
#include <vector>

class Solution {
public:
    std::vector<int> buildPreorder(const std::vector<int>& inorder,
                                   const std::vector<int>& postorder) {
        for (int i = 0; i < static_cast<int>(inorder.size()); ++i) {
            pos_[inorder[i]] = i;
        }
        preorder_.clear();
        dfs(inorder, postorder,
            0, static_cast<int>(inorder.size()),
            0, static_cast<int>(postorder.size()));
        return preorder_;
    }

private:
    std::unordered_map<int, int> pos_;
    std::vector<int> preorder_;

    void dfs(const std::vector<int>& inorder,
             const std::vector<int>& postorder,
             int in_l, int in_r,
             int post_l, int post_r) {
        if (in_l >= in_r) {
            return;
        }

        int root = postorder[post_r - 1];
        preorder_.push_back(root);

        int idx = pos_[root];
        int left_size = idx - in_l;

        dfs(inorder, postorder,
            in_l, idx,
            post_l, post_l + left_size);

        dfs(inorder, postorder,
            idx + 1, in_r,
            post_l + left_size, post_r - 1);
    }
};
```

复杂度：

```text
时间 O(n)
空间 O(n)
```

## 区间对应关系

如果当前子树：

```text
inorder   = [in_l, in_r)
postorder = [post_l, post_r)
```

根：

```text
root = postorder[post_r - 1]
```

左子树：

```text
inorder   = [in_l, idx)
postorder = [post_l, post_l + left_size)
```

右子树：

```text
inorder   = [idx + 1, in_r)
postorder = [post_l + left_size, post_r - 1)
```

## 易错点

1. 题目默认节点值不重复；如果有重复值，单靠中序和后序无法唯一确定树。
2. 后序区间右端点要排除根，所以右子树后序是 `[post_l + left_size, post_r - 1)`。
3. 空树要能处理。
4. 如果要求构建树节点，只需要把 `preorder_.push_back(root)` 换成创建节点并挂左右子树。

## 面试回答模板

后序遍历最后一个元素是当前根，在中序遍历中找到根的位置，就能知道左子树和右子树的大小。然后前序输出顺序是根、左、右，所以递归时先输出根，再根据左右子树在中序和后序里的区间继续递归。为了做到 `O(n)`，用哈希表保存中序里每个值的位置，避免每层线性查找。
