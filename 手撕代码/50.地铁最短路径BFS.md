# 地铁最短路径 BFS

题目：给定一个接口，可以获得与当前地铁站相通的站点，如何找到从起点到目的地的最短路径。

如果每条边权重相同，例如每经过一站代价都是 1，那么这是无权图最短路径，使用 BFS。BFS 按层扩展，第一次到达终点时经过的边数最少。

## 1. BFS 思路

1. 起点入队，标记已访问。
2. 每次从队首取出一个站点。
3. 调用接口获取相邻站点。
4. 未访问的相邻站点记录前驱并入队。
5. 第一次访问到终点时停止。
6. 根据 `parent` 从终点回溯出路径。

## 2. 伪代码

```text
BFS(start, target):
    queue = new Queue()
    visited = new Set()
    parent = new Map()

    queue.push(start)
    visited.add(start)
    parent[start] = null

    while queue is not empty:
        cur = queue.pop()
        if cur == target:
            return buildPath(parent, target)

        for next in getNeighbors(cur):
            if next not in visited:
                visited.add(next)
                parent[next] = cur
                queue.push(next)

    return no path
```

## 3. C++ 示例

```cpp
#include <algorithm>
#include <functional>
#include <queue>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

using Station = string;

vector<Station> shortestPath(
    const Station& start,
    const Station& target,
    const function<vector<Station>(const Station&)>& getNeighbors) {
    queue<Station> q;
    unordered_set<Station> visited;
    unordered_map<Station, Station> parent;

    q.push(start);
    visited.insert(start);
    parent[start] = "";

    while (!q.empty()) {
        Station cur = q.front();
        q.pop();

        if (cur == target) {
            vector<Station> path;
            for (Station x = target; !x.empty(); x = parent[x]) {
                path.push_back(x);
            }
            reverse(path.begin(), path.end());
            return path;
        }

        for (const Station& next : getNeighbors(cur)) {
            if (visited.insert(next).second) {
                parent[next] = cur;
                q.push(next);
            }
        }
    }

    return {};
}
```

## 4. 如果边权不同

如果不同线路、换乘、站间耗时不同，就不是普通 BFS：

1. 边权非负：用 Dijkstra。
2. 边权只有 0 和 1：用 0-1 BFS。
3. 要考虑换乘次数：可以把状态扩展为 `(station, line)`。
4. 要实时避让拥堵：边权需要动态更新，可能用 A*、Dijkstra 或多源预计算结合实时修正。

## 5. 易错点

1. BFS 只保证无权图或等权图最短路径。
2. 入队时就应标记 visited，避免同一站点重复入队。
3. 如果要输出路径，需要记录 `parent`，只记录距离不够。
4. 地铁换乘场景中，“站点”可能不是唯一状态，线路也可能影响代价。

## 6. 面试回答模板

如果相邻站点之间代价相同，我会把地铁网络看成无权图，用 BFS 求最短路径。起点入队并标记访问，每次弹出当前站，调用接口获取相邻站，未访问的站记录 parent 后入队。BFS 按层扩展，所以第一次到达终点就是最少站数路径。若站间耗时或换乘代价不同，就要改成 Dijkstra，必要时把状态扩展成站点加线路。
