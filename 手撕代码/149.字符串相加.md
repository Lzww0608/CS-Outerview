# 149. 字符串相加

题目：给定两个非负整数字符串 `num1`、`num2`，返回它们的和，不能直接转换成内置整数。

## 1. 核心思路

从两个字符串末尾开始模拟竖式加法：

1. `i` 指向 `num1` 末尾，`j` 指向 `num2` 末尾。
2. 每轮取两个当前数字和进位 `carry` 相加。
3. 当前位是 `sum % 10`，新的进位是 `sum / 10`。
4. 最后反转结果字符串。

## 2. C++ 实现

```cpp
#include <algorithm>
#include <string>
using namespace std;

string addStrings(string num1, string num2) {
    int i = static_cast<int>(num1.size()) - 1;
    int j = static_cast<int>(num2.size()) - 1;
    int carry = 0;
    string ans;

    while (i >= 0 || j >= 0 || carry != 0) {
        int x = (i >= 0) ? num1[i--] - '0' : 0;
        int y = (j >= 0) ? num2[j--] - '0' : 0;
        int sum = x + y + carry;
        ans.push_back(static_cast<char>('0' + sum % 10));
        carry = sum / 10;
    }

    reverse(ans.begin(), ans.end());
    return ans;
}
```

复杂度：

```text
时间复杂度: O(max(m, n))
空间复杂度: O(max(m, n))
```

## 3. 输入扩展

如果题目可能包含前导零：

```text
"00012" + "003" = "15"
```

上面的实现会得到 `"00015"`。如果要求规范输出，需要去掉前导零：

```cpp
size_t p = ans.find_first_not_of('0');
return p == string::npos ? "0" : ans.substr(p);
```

如果可能包含负数，应该先处理符号，把问题拆成：

1. 同号：绝对值相加，结果符号相同。
2. 异号：绝对值相减，结果符号取绝对值较大的一方。

## 4. 易错点

1. 不能用 `stoi/stoll`，输入可能远超内置整数范围。
2. 最后一位进位不能漏掉，例如 `"999" + "1" = "1000"`。
3. 字符转数字要减 `'0'`，数字转字符要加 `'0'`。
4. 如果从前往后加，会很难处理低位进位；从后往前最自然。

## 5. 面试回答模板

字符串相加就是模拟竖式加法。从两个字符串末尾开始，每次取一位数字加上进位，结果位是 `sum % 10`，进位是 `sum / 10`。循环条件要包含两个指针和最后的进位，最后反转结果。时间复杂度 `O(max(m,n))`。
