# 90. 消消乐连续数字消除

题目：给定一个数字序列，把连续相同的数字全部消除。升级版要求消除后如果新的相邻数字又相同，也要继续消除，直到序列稳定。

## 1. 只消除原序列中的连续相同段

如果只做一轮扫描，遇到长度大于 1 的相同连续段就跳过，长度为 1 的段保留。

例如：

```text
[1, 2, 2, 3, 4, 4, 4, 5] -> [1, 3, 5]
```

代码：

```cpp
#include <utility>
#include <vector>
using namespace std;

vector<int> removeOnePass(const vector<int>& nums) {
    vector<int> ans;
    int n = static_cast<int>(nums.size());
    int i = 0;
    while (i < n) {
        int j = i + 1;
        while (j < n && nums[j] == nums[i]) {
            ++j;
        }
        if (j == i + 1) {
            ans.push_back(nums[i]);
        }
        i = j;
    }
    return ans;
}
```

复杂度：时间 `O(n)`，额外空间 `O(n)`。

## 2. 升级版：支持连锁消除

升级版的关键是处理“消除后新形成的连续段”。例如：

```text
[1, 2, 2, 1] -> [1, 1] -> []
```

可以用栈保存已经稳定的段，每个栈元素记录数字和连续次数。扫描新数字时：

1. 如果和栈顶数字相同，增加计数。
2. 如果和栈顶数字不同，先检查栈顶计数是否大于 1；如果是，弹出栈顶，相当于完成一轮消除，然后重新尝试和新的栈顶合并。
3. 扫描结束后，还要清理栈顶可能存在的重复段。

为了让逻辑更清晰，可以把“压入一个数字”封装成函数：

```cpp
#include <vector>
using namespace std;

vector<int> removeCascade(const vector<int>& nums) {
    vector<pair<int, int>> st;

    auto normalize = [&]() {
        while (!st.empty() && st.back().second > 1) {
            st.pop_back();
            if (st.size() >= 2 && st[st.size() - 1].first == st[st.size() - 2].first) {
                st[st.size() - 2].second += st.back().second;
                st.pop_back();
            }
        }
    };

    for (int x : nums) {
        if (!st.empty() && st.back().first == x) {
            ++st.back().second;
        } else {
            normalize();
            if (!st.empty() && st.back().first == x) {
                ++st.back().second;
            } else {
                st.push_back({x, 1});
            }
        }
    }
    normalize();

    vector<int> ans;
    for (auto [value, count] : st) {
        for (int i = 0; i < count; ++i) {
            ans.push_back(value);
        }
    }
    return ans;
}
```

上面写法强调思路。也可以用“栈 + 当前连续段”的方式实现，核心都是把已经确定要消除的段弹掉，并让两侧重新相遇。

## 3. 更稳的实现方式

为了避免 lambda 中合并边界写错，可以每次扫描一个连续段，再与栈顶合并：

```cpp
vector<int> removeCascadeByRuns(const vector<int>& nums) {
    vector<pair<int, int>> st;
    int n = static_cast<int>(nums.size());

    for (int i = 0; i < n;) {
        int j = i + 1;
        while (j < n && nums[j] == nums[i]) {
            ++j;
        }

        int value = nums[i];
        int count = j - i;

        if (!st.empty() && st.back().first == value) {
            st.back().second += count;
        } else {
            st.push_back({value, count});
        }

        while (!st.empty() && st.back().second > 1) {
            st.pop_back();
            if (st.size() >= 2 && st[st.size() - 1].first == st[st.size() - 2].first) {
                st[st.size() - 2].second += st[st.size() - 1].second;
                st.pop_back();
            }
        }

        i = j;
    }

    vector<int> ans;
    for (auto [value, count] : st) {
        for (int k = 0; k < count; ++k) {
            ans.push_back(value);
        }
    }
    return ans;
}
```

复杂度：每个连续段最多入栈、出栈一次，时间 `O(n)`，额外空间 `O(n)`。

## 4. 易错点

1. 要先确认“连续数字”是否指连续相同数字，而不是数值连续递增。
2. 一轮消除和连锁消除不是同一个问题。
3. 升级版中，消除中间段后两侧可能合并，需要用栈处理回退。
4. 如果题目规定“至少 3 个相同才消除”，只需要把判断条件从 `count > 1` 改成 `count >= 3`。

## 5. 面试回答模板

普通版可以双指针扫描连续相同段，长度为 1 就保留，长度大于 1 就跳过。升级版要处理连锁反应，用栈保存已经稳定的连续段，遇到相同值就合并计数；一旦某段满足消除条件就弹出，弹出后再检查两侧是否形成新的相同段。每个元素或连续段最多进出栈一次，时间 `O(n)`，空间 `O(n)`。
