# 数组重复数字判断

题目常见版本：数组长度为 `n`，数字都在 `0~n-1`，判断是否有重复数字。这个版本可以利用“值域刚好对应下标”的特点，把元素放回自己的位置。

## 1. 原地交换

遍历数组，尝试把值 `x` 放到下标 `x` 上。如果发现 `nums[i] == nums[nums[i]]` 且 `i != nums[i]`，说明值 `nums[i]` 已经在自己的位置出现过，存在重复。

```cpp
#include <vector>
using namespace std;

bool hasDuplicate(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; ++i) {
        if (nums[i] < 0 || nums[i] >= n) {
            return false; // 或抛异常，取决于题目约定
        }

        while (nums[i] != i) {
            int x = nums[i];
            if (nums[x] == x) {
                return true;
            }
            swap(nums[i], nums[x]);
        }
    }
    return false;
}
```

复杂度：

1. 时间复杂度：`O(n)`，每次交换至少让一个数回到正确位置。
2. 空间复杂度：`O(1)`。
3. 会修改原数组。

## 2. 不修改数组

如果不能修改数组，可以用：

1. 哈希集合：时间 `O(n)`，空间 `O(n)`。
2. Bitmap：值域较小时空间更省，`0~n-1` 只需要 `n` bit。
3. 排序：时间 `O(nlogn)`，原地排序可做到较低额外空间，但会改变顺序。

## 3. 数字范围是 0~n 怎么办

要先问清楚数组长度。如果数组长度仍是 `n`，值域有 `n+1` 个数，重复不是必然存在，不能用“抽屉原理”直接断言有重复。此时可以用哈希、Bitmap 或排序判断。

如果数组长度是 `n+1`，数字范围是 `0~n`，则值域大小和数组长度相等，也不必然有重复；如果范围是 `1~n` 且长度是 `n+1`，才是经典“必有重复数”版本，可以用二分计数或快慢指针。

## 4. 易错点

1. 原地交换法依赖值域是 `0~n-1`，否则可能越界。
2. 如果题目不允许修改数组，不能用原地交换。
3. 异或或求和只适用于非常特殊的约束，例如只有一个重复且其他数完整出现一次。
4. “范围是 `0~n`”时要确认数组长度，否则结论不同。

## 5. 面试回答模板

如果数组长度为 `n` 且值域是 `0~n-1`，可以用原地交换：把每个数放回同名下标，如果发现目标位置已经是同一个值，就说明重复，时间 `O(n)`、空间 `O(1)`，但会修改原数组。不能修改数组时用哈希表、Bitmap 或排序。若值域变成 `0~n`，要先确认数组长度，不能直接套用原地交换或抽屉原理。
