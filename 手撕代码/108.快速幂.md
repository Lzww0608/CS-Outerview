# 108. 快速幂

## 题目

实现 `pow(x, n)`，要求时间复杂度尽量优。`n` 可能为负数。

## 1. 核心思想

快速幂利用二进制拆分指数：

```text
x^13 = x^(8+4+1)
```

每次把底数平方，指数右移一位。如果当前指数最低位为 1，就把当前底数乘到答案里。

## 2. 迭代实现

```cpp
double myPow(double x, int n) {
    long long exp = n;
    if (exp < 0) {
        x = 1.0 / x;
        exp = -exp;
    }

    double ans = 1.0;
    while (exp > 0) {
        if (exp & 1LL) {
            ans *= x;
        }
        x *= x;
        exp >>= 1;
    }
    return ans;
}
```

## 3. 为什么用 long long

`int` 的最小值 `INT_MIN = -2147483648`，直接取负会溢出，因为正数范围最大只有 `2147483647`。因此要先转成 `long long`：

```cpp
long long exp = n;
if (exp < 0) {
    exp = -exp;
}
```

## 4. 复杂度

```text
时间复杂度: O(log |n|)
空间复杂度: O(1)
```

普通连乘需要 `O(|n|)`，快速幂把指数每次减半，因此是 `O(log |n|)`。

## 5. 易错点

1. 负指数要转成倒数。
2. `INT_MIN` 取负会溢出，必须用更大类型保存指数。
3. `x = 0` 且 `n < 0` 数学上无定义，面试时要说明输入约束。
4. 浮点数比较不能要求完全精确。
5. 如果是整数取模快速幂，每次乘法后要取模，并注意乘法溢出。

## 6. 面试回答模板

`pow` 最优常见写法是快速幂。把指数看成二进制，当前位为 1 就把当前底数乘到答案里；每轮底数平方，指数右移一位。这样指数每次减半，时间复杂度是 `O(log |n|)`。如果指数为负，就先把底数变成倒数；为了处理 `INT_MIN` 取负溢出，指数要先转成 `long long`。
