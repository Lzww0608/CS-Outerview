# 简化路径

题目：给定 Unix 风格绝对路径，将其简化为规范路径。规则包括：多个 `/` 合并为一个，`.` 表示当前目录，`..` 表示返回上一级，路径不能越过根目录。

## 思路

用栈保存有效目录名：

1. 按 `/` 分割路径。
2. 空串和 `.` 忽略。
3. 遇到 `..`，如果栈非空则弹出一个目录。
4. 其他字符串作为目录名入栈。
5. 最后用 `/` 拼接；如果栈为空返回 `/`。

## 代码

```cpp
#include <sstream>
#include <string>
#include <vector>

std::string simplifyPath(std::string path) {
    std::vector<std::string> dirs;
    std::stringstream ss(path);
    std::string part;

    while (std::getline(ss, part, '/')) {
        if (part.empty() || part == ".") {
            continue;
        }
        if (part == "..") {
            if (!dirs.empty()) {
                dirs.pop_back();
            }
        } else {
            dirs.push_back(part);
        }
    }

    if (dirs.empty()) {
        return "/";
    }

    std::string ans;
    for (const auto& dir : dirs) {
        ans += "/";
        ans += dir;
    }
    return ans;
}
```

## 复杂度

1. 时间复杂度：`O(n)`，`n` 是路径长度。
2. 空间复杂度：`O(n)`，最坏情况下所有目录名都入栈。

## 易错点

1. `...` 不是 `..`，应该当作普通目录名。
2. 根目录下遇到 `..` 不能继续向上，仍然保持 `/`。
3. 多个连续 `/` 要忽略空片段。
4. 返回结果不能有末尾 `/`，除非结果就是根目录 `/`。

## 面试回答模板

简化路径用栈即可。按 `/` 拆分路径，空串和 `.` 跳过，`..` 就弹出一个目录，普通目录名入栈。最后从栈中按顺序用 `/` 拼回结果，栈空返回根目录。时间 `O(n)`，空间 `O(n)`。注意 `...` 是合法目录名，不是返回上一级。
