# 145. 1 到 n 字典序遍历

题目要求把 `1` 到 `n` 按字典序输出，不能先生成所有数字再按字符串排序。字典序可以看成一棵十叉前缀树的先序遍历。

例如 `n = 13`：

```text
1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9
```

## 1. 前缀树思路

把每个数字看成字符串。前缀 `1` 下面有 `10`、`11`、`12` ...，前缀 `2` 下面有 `20`、`21` ...。按字典序遍历就是：

1. 优先进入当前数字的下一层：`cur * 10`。
2. 如果不能进入下一层，就走同层下一个兄弟：`cur + 1`。
3. 如果当前已经是 `9` 结尾，或者 `cur + 1 > n`，就不断回退到父前缀。

## 2. 迭代实现

```cpp
#include <vector>
using namespace std;

vector<int> lexicalOrder(int n) {
    vector<int> ans;
    ans.reserve(n);

    int cur = 1;
    for (int i = 0; i < n; ++i) {
        ans.push_back(cur);

        if ((long long)cur * 10 <= n) {
            cur *= 10;
        } else {
            while (cur % 10 == 9 || cur + 1 > n) {
                cur /= 10;
            }
            ++cur;
        }
    }

    return ans;
}
```

复杂度：每个数字输出一次，时间复杂度 `O(n)`；除了结果数组外，额外空间 `O(1)`。

## 3. DFS 实现

如果允许递归，也可以从 `1~9` 做 DFS：

```cpp
void dfs(int prefix, int n, vector<int>& ans) {
    if (prefix > n) {
        return;
    }
    ans.push_back(prefix);
    for (int d = 0; d <= 9; ++d) {
        long long next = 1LL * prefix * 10 + d;
        if (next > n) {
            break;
        }
        dfs((int)next, n, ans);
    }
}

vector<int> lexicalOrderDfs(int n) {
    vector<int> ans;
    ans.reserve(n);
    for (int i = 1; i <= 9 && i <= n; ++i) {
        dfs(i, n, ans);
    }
    return ans;
}
```

递归写法更直观，但递归深度是数字位数，极端场景要注意栈深度和函数调用开销。

## 4. 易错点

1. 字典序不是数值顺序，`10` 会排在 `2` 前面。
2. `cur * 10` 可能溢出，判断时最好转成 `long long`。
3. 回退条件不只是 `cur % 10 == 9`，还包括 `cur + 1 > n`。
4. 题目说“不能暴力”通常是指不能字符串排序，`O(n)` 前缀遍历是可以接受的，因为输出本身就需要 `O(n)`。

## 5. 面试回答模板

可以把 `1~n` 看成一棵十叉前缀树，字典序就是先序遍历。当前数字如果乘 10 不超过 `n`，就进入下一层；否则尝试同层加 1，如果加 1 超过 `n` 或当前以 9 结尾，就不断除以 10 回退到父前缀，再加 1。这样每个数字只访问一次，时间 `O(n)`，额外空间 `O(1)`，不需要把数字转成字符串排序。
