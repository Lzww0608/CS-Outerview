# 二叉树两个节点最大路径长度

题目：给定一棵二叉树，求任意两个节点之间路径长度的最大值。这个值通常叫二叉树直径。

路径长度有两种口径：

1. 按边数计算：两个相邻节点距离为 1。
2. 按节点数计算：路径上包含几个节点。

面试时要先说明口径。下面默认按边数计算。

## 1. 核心思路

任意两个节点的最长路径，一定会在某个节点处“拐弯”：

```text
左子树最深叶子 -> 当前节点 -> 右子树最深叶子
```

所以 DFS 时同时计算两件事：

1. 当前节点向下的最大深度。
2. 经过当前节点的最长路径长度。

经过当前节点的路径长度为：

```text
left_depth + right_depth
```

其中 `depth` 按“从当前节点到最深叶子的边数贡献”计算时，空节点返回 0，非空节点返回 `max(left, right) + 1`。为了让边数公式自然，代码里也可以把返回值定义为“节点高度”，直径用 `left_height + right_height`。

## 2. C++ 实现

```cpp
#include <algorithm>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        int ans = 0;
        height(root, ans);
        return ans;
    }

private:
    int height(TreeNode* node, int& ans) {
        if (node == nullptr) {
            return 0;
        }

        int left = height(node->left, ans);
        int right = height(node->right, ans);

        ans = max(ans, left + right); // 按边数计算的直径
        return max(left, right) + 1;
    }
};
```

复杂度：

1. 时间复杂度：`O(n)`，每个节点访问一次。
2. 空间复杂度：`O(h)`，递归栈高度为树高。

## 3. 为什么不能每个节点都重新求深度

暴力做法是对每个节点都计算左右子树高度，再更新答案。计算高度本身又会遍历子树，最坏退化成 `O(n^2)`。

后序 DFS 的优化点是：子树高度在回溯时顺便返回，避免重复计算。

## 4. 扩展：路径和最大值

如果题目问的是“路径节点值之和最大”，就不是直径，而是二叉树最大路径和。那时返回的是向父节点贡献的最大单边路径和，答案更新为 `node->val + max(0, left) + max(0, right)`。

直径题关注边数或节点数，最大路径和关注节点权值，不要混淆。

## 5. 易错点

1. 先确认路径长度按边数还是节点数。
2. 空树直径通常为 0。
3. 直径不一定经过根节点。
4. DFS 要后序遍历，先拿到左右高度再更新答案。
5. 链状树的递归深度可能达到 `O(n)`，极端大树要考虑栈溢出，改成显式栈或提高栈空间。

## 6. 面试回答模板

这题是二叉树直径。最长路径不一定经过根，但一定会经过某个节点，并由该节点左侧最深路径和右侧最深路径拼起来。因此做一次后序 DFS，递归返回当前节点向下的高度，同时用 `left_height + right_height` 更新全局最大值。每个节点只访问一次，时间 `O(n)`，递归栈 `O(h)`。如果按节点数计算，答案可以在边数结果基础上根据题意调整。
