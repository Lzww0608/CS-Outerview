# 右边第一个更大的数

题目通常要求：给定数组，对每个位置 `i` 找到它右侧第一个比 `nums[i]` 大的元素；如果不存在，返回 `-1`。要求 `O(n)` 时使用单调栈。

## 核心思路

维护一个单调递减栈，栈里存还没找到右侧更大元素的下标。

遍历数组 `nums[i]`：

1. 当栈不空且 `nums[i] > nums[st.top()]`，说明 `nums[i]` 是栈顶下标的右边第一个更大元素。
2. 弹出栈顶并记录答案。
3. 重复直到栈顶元素大于等于当前元素。
4. 当前下标入栈。

每个元素最多入栈一次、出栈一次，所以总时间 `O(n)`。

## 代码

```cpp
#include <stack>
#include <vector>

std::vector<int> nextGreaterElement(const std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    std::vector<int> ans(n, -1);
    std::stack<int> st; // 存下标，nums[st] 单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }

    return ans;
}
```

如果题目要返回右边第一个更大数的下标，把赋值改成：

```cpp
ans[st.top()] = i;
```

## 从右往左的写法

也可以从右往左遍历，栈中保存当前元素右侧可能成为答案的值：

```cpp
std::vector<int> nextGreaterFromRight(const std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    std::vector<int> ans(n, -1);
    std::stack<int> st;

    for (int i = n - 1; i >= 0; --i) {
        while (!st.empty() && st.top() <= nums[i]) {
            st.pop();
        }
        if (!st.empty()) {
            ans[i] = st.top();
        }
        st.push(nums[i]);
    }
    return ans;
}
```

这种写法适合只返回值；如果要返回下标，栈仍然存下标。

## 易错点

1. “第一个更大”不是“右边最大”，不能用后缀最大直接替代。
2. 如果要求严格更大，判断用 `>`；如果要求大于等于，判断要改。
3. 有重复元素时，要明确相等是否算更大。
4. 单调栈存下标更通用，因为可以同时拿到值和位置。

## 面试回答模板

右边第一个更大的数用单调栈。栈中保存还没有找到答案的下标，并让对应值保持单调递减。遍历到 `nums[i]` 时，只要它比栈顶下标对应的值大，就说明它是栈顶元素右侧遇到的第一个更大值，弹栈并记录答案；最后把当前下标入栈。每个元素最多入栈出栈一次，所以时间 `O(n)`，空间 `O(n)`。
