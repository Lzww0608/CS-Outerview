# 19. 五个星号分隔数字串

## 题目

给定一串只包含数字的字符串，用 5 个星号 `*` 分隔成 6 段，要求每段数值不大于 600，打印所有可能结果。

例如：

```text
input = "123456"
output = "1*2*3*4*5*6"
```

## 思路：回溯

要切成 6 段，本质是从字符串中选择 5 个切分点。

回溯参数：

1. 当前扫描位置 `pos`。
2. 当前已经切出的段数 `part`。
3. 当前路径 `path`。

每段至少 1 个字符。因为每段数值不大于 600，所以单段长度最多 3 位，可以剪枝。

## 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

void dfs(const string& s, int pos, int part, vector<string>& path) {
    if (part == 6) {
        if (pos == static_cast<int>(s.size())) {
            for (int i = 0; i < 6; ++i) {
                if (i > 0) {
                    cout << '*';
                }
                cout << path[i];
            }
            cout << '\n';
        }
        return;
    }

    int remainChars = static_cast<int>(s.size()) - pos;
    int remainParts = 6 - part;
    if (remainChars < remainParts || remainChars > remainParts * 3) {
        return;
    }

    int value = 0;
    for (int len = 1; len <= 3 && pos + len <= static_cast<int>(s.size()); ++len) {
        value = value * 10 + (s[pos + len - 1] - '0');
        if (value > 600) {
            break;
        }

        path.push_back(s.substr(pos, len));
        dfs(s, pos + len, part + 1, path);
        path.pop_back();
    }
}

void printAllSplits(const string& s) {
    vector<string> path;
    dfs(s, 0, 0, path);
}
```

## 是否允许前导零

题目只说“每段数值不大于 600”，没有禁止前导零时，`"001"` 的数值可以按 1 处理。

如果面试官要求不允许前导零，除单个 `"0"` 外，遇到 `s[pos] == '0'` 时只能选择长度 1：

```cpp
int maxLen = s[pos] == '0' ? 1 : 3;
```

## 复杂度

每段最多尝试 3 种长度，段数固定为 6：

```text
时间复杂度: O(3^6)
空间复杂度: O(6)
```

由于段数固定，实际复杂度是常数级；如果推广到 `k` 段，则是 `O(3^k)`。

## 易错点

1. 必须刚好切成 6 段，不能少也不能多。
2. 每段不能为空。
3. 要用剩余字符数剪枝：`remainParts <= remainChars <= remainParts * 3`。
4. 是否允许前导零需要和面试官确认。
