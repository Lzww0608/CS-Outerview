# 171. 最长半重复子字符串

题目对应 LeetCode 2730：给定一个只包含数字字符的字符串 `s`，找出最长的半重复子字符串长度。半重复子字符串指的是：子字符串中最多只有一组相邻字符相同。

例如：

```text
s = "52233"
"5223" 中只有 "22" 一组相邻相同，合法，长度 4
"52233" 中有 "22" 和 "33" 两组相邻相同，不合法
```

## 1. 核心思路

用滑动窗口维护一个区间 `[left, right]`，并记录窗口内相邻相同字符对的数量 `samePairs`。

当右端点 `right` 向右扩展时：

1. 如果 `s[right] == s[right - 1]`，说明新增加了一组相邻相同字符对，`samePairs++`。
2. 如果 `samePairs > 1`，窗口不合法，需要移动 `left`。
3. 移动 `left` 时，如果移除的是一组相邻相同字符对的左端，即 `s[left] == s[left + 1]`，则 `samePairs--`。
4. 每次窗口合法时更新最大长度。

注意这里统计的是“相邻相同对”的数量，不是某个字符出现的次数。例如 `"111"` 里有两组相邻相同对：`s[0]==s[1]` 和 `s[1]==s[2]`，因此长度为 3 的窗口不合法。

## 2. 代码

```cpp
#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int longestSemiRepetitiveSubstring(string s) {
        int n = static_cast<int>(s.size());
        int left = 0;
        int samePairs = 0;
        int ans = 0;

        for (int right = 0; right < n; ++right) {
            if (right > 0 && s[right] == s[right - 1]) {
                ++samePairs;
            }

            while (samePairs > 1) {
                if (left + 1 <= right && s[left] == s[left + 1]) {
                    --samePairs;
                }
                ++left;
            }

            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```

## 3. 复杂度

1. 时间复杂度：`O(n)`，每个字符最多被左右指针各访问一次。
2. 空间复杂度：`O(1)`，只维护计数和指针。

## 4. 易错点

1. 不要统计重复字符个数，而要统计窗口内的相邻相同对数量。
2. `"111"` 不是只有一组重复，而是有两组相邻相同对，因此最长合法窗口只能是 `"11"`。
3. 左指针移动时要判断 `s[left] == s[left + 1]`，因为被移出的相邻关系只可能发生在窗口左边界。
4. 窗口里允许 `samePairs == 1`，只有大于 1 时才需要收缩。

## 5. 面试回答模板

这题可以用滑动窗口。窗口内维护相邻相同字符对的数量 `samePairs`，右指针每加入一个字符，就检查它和前一个字符是否相同；如果相同，说明窗口多了一组相邻重复。题目要求最多一组，所以当 `samePairs > 1` 时移动左指针，移动过程中如果左边界和它右侧字符相同，就把这组相邻重复从计数里删掉。窗口重新合法后更新答案。整体是双指针线性扫描，时间 `O(n)`，空间 `O(1)`。
