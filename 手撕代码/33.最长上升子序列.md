# 最长上升子序列

最长上升子序列（LIS）是在数组中选出一个下标递增、数值严格递增的子序列，使长度最大。面试要求 `O(n log n)` 时，要用“贪心 + 二分”的 tails 数组。

## 核心思路

维护数组 `tails`：

```text
tails[len - 1] = 长度为 len 的上升子序列中，结尾元素的最小可能值
```

遍历每个数 `x`：

1. 在 `tails` 中找第一个 `>= x` 的位置。
2. 如果找到，就用 `x` 替换它，让同长度子序列结尾更小。
3. 如果找不到，说明 `x` 比所有结尾都大，可以扩展出更长子序列。

`tails` 本身不一定是最终 LIS，但它的长度就是 LIS 长度。

## 代码

```cpp
#include <algorithm>
#include <vector>

int lengthOfLIS(const std::vector<int>& nums) {
    std::vector<int> tails;
    for (int x : nums) {
        auto it = std::lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);
        } else {
            *it = x;
        }
    }
    return static_cast<int>(tails.size());
}
```

复杂度：

```text
时间 O(n log n)
空间 O(n)
```

## 严格递增和非递减

1. 严格递增：找第一个 `>= x`，使用 `lower_bound`。
2. 非递减：找第一个 `> x`，使用 `upper_bound`。

示例：

```text
nums = [2, 2, 2]
严格递增 LIS = 1
非递减 LIS = 3
```

## 如果要恢复具体序列

需要额外维护：

1. `pos[len]`：长度为 `len + 1` 的最优结尾下标。
2. `pre[i]`：元素 `i` 在 LIS 中的前驱下标。

每次更新 tails 位置时同步记录下标，最后从最长长度的结尾下标往前追 `pre`。

## 易错点

1. `tails` 不是最终答案序列，不要直接输出它当 LIS。
2. 严格递增用 `lower_bound`，非递减用 `upper_bound`。
3. 子序列不要求连续，子数组才要求连续。
4. 如果输入为空，答案是 0。

## 面试回答模板

`O(n log n)` 的 LIS 用 tails 数组。`tails[i]` 表示长度为 `i+1` 的递增子序列中最小的结尾值。遍历每个数，用二分找第一个大于等于它的位置并替换；如果它比所有结尾都大就追加。这样保证每种长度的结尾尽量小，后面更容易接上新元素。最终 `tails.size()` 就是 LIS 长度。严格递增用 `lower_bound`，非递减用 `upper_bound`。
