# 17. 扑克牌顺序问题

## 题目

常见“扑克牌顺序问题”是：

给定一组牌，操作规则为：

1. 展示牌顶一张牌。
2. 如果还剩牌，把新的牌顶放到牌底。
3. 重复直到所有牌展示完。

要求安排初始牌堆顺序，使展示出来的牌按升序排列。

这对应 LeetCode 950 `Reveal Cards In Increasing Order`。

## 思路

正向模拟下标：

1. 先把牌排序。
2. 用队列保存初始牌堆的下标 `0..n-1`。
3. 每次取队首下标，放入当前最小牌。
4. 再把新的队首下标移到队尾，模拟“把牌顶放到牌底”。

## 代码

```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

vector<int> deckRevealedIncreasing(vector<int>& deck) {
    sort(deck.begin(), deck.end());

    int n = static_cast<int>(deck.size());
    queue<int> q;
    for (int i = 0; i < n; ++i) {
        q.push(i);
    }

    vector<int> ans(n);
    for (int card : deck) {
        int idx = q.front();
        q.pop();
        ans[idx] = card;

        if (!q.empty()) {
            q.push(q.front());
            q.pop();
        }
    }

    return ans;
}
```

## 示例

```text
deck = [17,13,11,2,3,5,7]
输出初始牌序: [2,13,3,11,5,17,7]

展示过程:
2,3,5,7,11,13,17
```

## 复杂度

```text
时间复杂度: O(n log n)
空间复杂度: O(n)
```

排序是主要成本，队列模拟是 O(n)。

## 易错点

1. 不要直接模拟牌值移动，模拟下标更清晰。
2. 每次放入一张牌后，才移动下一张牌顶到底部。
3. 队列为空时不要再移动队首。
4. 如果面试官说的是另一种扑克牌顺序题，例如约瑟夫发牌、魔术师发牌还原，要先澄清操作规则。
