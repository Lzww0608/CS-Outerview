## 快照数组类实现，要求支持快照操作（时间O（1）复杂度），以及根据快照ID获取指定快照版本的指定索引的值



### 解题思路与设计哲学

我的设计思路是采用一种 **“写时复制”（Copy-on-Write）的变体** 或 **“历史版本追溯”** 的策略。我们不存储数组在每个快照时刻的完整状态，而是只记录每个索引位置上的值变更历史。

1.  **核心数据结构**：
    *   我会使用一个主数据结构，它是一个数组（或 `vector`/`slice`），我们称之为 `data`。
    *   `data` 的每个元素不再是一个单一的值，而是一个**“历史记录列表”**。
    *   这个“历史记录列表”会存储一系列的 `(snap_id, value)` 对。这个列表有一个非常重要的特性：它将始终按 `snap_id` 升序排列。

2.  **快照ID管理**：
    *   我们会有一个全局的 `snap_id` 计数器，从 0 开始。每调用一次 `snap()`，这个计数器就加一。

3.  **各操作的实现逻辑**：
    *   **`Constructor(length)`**: 初始化 `data` 为一个长度为 `length` 的数组。数组的每个元素都是一个初始的历史记录列表。为了处理边界情况（即在第一次 `set` 之前 `get` 某个快照），我们会为每个索引的列表预置一个初始值，例如 `[(snap_id: 0, value: 0)]`。同时，初始化 `snap_id` 计数器为 0。
    *   **`set(index, val)`**: 当我们要在索引 `index` 处设置一个新值 `val` 时，我们实际上是在为**当前**的 `snap_id` 版本记录一个值。我们找到 `data[index]` 对应的历史记录列表。
        *   **优化**：如果该列表的最后一个元素的 `snap_id` 和当前的 `snap_id` 相同，说明在同一次快照中对同一索引进行了多次 `set`。我们不需要追加新记录，只需更新最后一个记录的值即可。
        *   **常规**：如果最后一个记录的 `snap_id` 小于当前的 `snap_id`，我们就在列表末尾追加一个新的记录 `(current_snap_id, val)`。
        这个操作的均摊时间复杂度是 O(1)。
    *   **`snap()`**: 这是最关键的操作。根据我们的设计，我们完全不需要接触 `data` 数组。我们唯一要做的就是将全局的 `snap_id` 计数器加一。这个操作显然是 O(1) 的。然后返回自增前的 `snap_id` 作为本次快照的ID。
    *   **`get(index, snap_id)`**: 这是体现我们数据结构优势的地方。我们需要在 `data[index]` 的历史记录列表中，找到**小于等于**我们给定的 `snap_id` 的、且 `snap_id` 最大的那条记录。
        *   由于历史记录列表是按 `snap_id` 排序的，我们可以非常高效地使用**二分查找**来定位。
        *   我们要查找的是目标 `snap_id` 的 "上界"（upper bound），然后取其前一个元素，就是我们想要的结果。
        *   这个操作的时间复杂度是 O(log K)，其中 K 是对该特定 `index` 执行 `set` 操作的次数。这是一个非常高效的查询。

### 复杂度分析

*   **`snap()`**: O(1) 时间复杂度，O(1) 空间复杂度。
*   **`set()`**: 均摊 O(1) 时间复杂度，O(1) 空间复杂度（用于创建一个新的历史记录条目）。
*   **`get()`**: O(log K) 时间复杂度，其中 K 是对该索引的修改次数。O(1) 空间复杂度。
*   **空间复杂度（整体）**: O(S)，其中 S 是调用 `set()` 的总次数。这是因为每次 `set` 最多创建一个历史条目。

### C++ 实现

下面是使用 C++ 的一个高质量实现。我将使用 `std::vector` 和 `std::pair`，并利用 `std::upper_bound` 来高效实现二分查找。

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // for std::upper_bound

class SnapshotArray {
private:
    // data[i] 存储了索引 i 的历史值记录
    // 每个历史记录是一个 {snap_id, value} 对
    std::vector<std::vector<std::pair<int, int>>> data;
    int current_snap_id;

public:
    SnapshotArray(int length) {
        // 初始化数据结构
        // 为每个索引预置一个 snap_id=0, value=0 的初始记录
        // 这简化了 get 操作，无需处理空历史记录的边界情况
        data.resize(length);
        for (int i = 0; i < length; ++i) {
            data[i].push_back({0, 0});
        }
        current_snap_id = 0;
    }

    void set(int index, int val) {
        // 获取对应索引的历史记录列表
        auto& history = data[index];
        
        // 优化：如果最近一次的修改就在当前快照版本，直接更新值
        if (history.back().first == current_snap_id) {
            history.back().second = val;
        } else {
            // 否则，追加一条新的历史记录
            history.push_back({current_snap_id, val});
        }
    }

    int snap() {
        // 增加快照ID，这是一个 O(1) 操作
        return current_snap_id++;
    }

    int get(int index, int snap_id) {
        const auto& history = data[index];

        // 使用二分查找 (upper_bound) 寻找第一个 snap_id 大于目标 snap_id 的记录
        // upper_bound 在 C++ STL 中非常高效，其原理就是二分查找
        auto it = std::upper_bound(history.begin(), history.end(), std::make_pair(snap_id, -1));
        
        // 我们需要的是小于等于 snap_id 的最后一个记录，所以取找到的迭代器的前一个
        // it 指向的是第一个 > snap_id 的元素，所以 it-1 就是 <= snap_id 的最后一个元素
        return std::prev(it)->second;
    }
};

// --- 使用示例 ---
int main() {
    SnapshotArray snapshotArr(3); // 初始化长度为 3 的数组，所有值为 0
    snapshotArr.set(0, 5);       // arr = [5, 0, 0]
    int snap_id_0 = snapshotArr.snap(); // 拍摄快照 0, arr = [5, 0, 0]
    std::cout << "Snap ID 0 created." << std::endl;

    snapshotArr.set(0, 6);       // arr = [6, 0, 0]
    snapshotArr.set(1, 2);       // arr = [6, 2, 0]
    
    // 从快照 0 中获取索引 0 的值，应该是快照拍摄时的值 5
    std::cout << "Get(index=0, snap_id=0): " << snapshotArr.get(0, snap_id_0) << std::endl; // 输出 5

    int snap_id_1 = snapshotArr.snap(); // 拍摄快照 1, arr = [6, 2, 0]
    std::cout << "Snap ID 1 created." << std::endl;

    // 从快照 1 中获取索引 0 和 1 的值
    std::cout << "Get(index=0, snap_id=1): " << snapshotArr.get(0, snap_id_1) << std::endl; // 输出 6
    std::cout << "Get(index=1, snap_id=1): " << snapshotArr.get(1, snap_id_1) << std::endl; // 输出 2

    return 0;
}
```

### Golang 实现

同样地，这是使用 Golang 的实现。我将使用 `slice` 和 `struct`，并利用 `sort.Search` 来实现二分查找，这在 Go 中是标准且高效的做法。

```go
package main

import (
	"fmt"
	"sort"
)

// SnapEntry 结构体用于存储历史记录
type SnapEntry struct {
	snapID int
	value  int
}

type SnapshotArray struct {
	data          [][]SnapEntry
	currentSnapID int
}

func Constructor(length int) SnapshotArray {
	sa := SnapshotArray{
		data:          make([][]SnapEntry, length),
		currentSnapID: 0,
	}
	// 为每个索引预置初始值，简化 get 逻辑
	for i := 0; i < length; i++ {
		sa.data[i] = append(sa.data[i], SnapEntry{snapID: 0, value: 0})
	}
	return sa
}

func (sa *SnapshotArray) Set(index int, val int) {
	history := sa.data[index]
	lastEntry := history[len(history)-1]

	// 优化：如果最近一次修改就在当前快照版本，直接更新
	if lastEntry.snapID == sa.currentSnapID {
		sa.data[index][len(history)-1].value = val
	} else {
		// 否则，追加新记录
		sa.data[index] = append(sa.data[index], SnapEntry{snapID: sa.currentSnapID, value: val})
	}
}

func (sa *SnapshotArray) Snap() int {
	// O(1) 操作
	id := sa.currentSnapID
	sa.currentSnapID++
	return id
}

func (sa *SnapshotArray) Get(index int, snap_id int) int {
	history := sa.data[index]

	// sort.Search 实现了二分查找，它会找到第一个满足条件的索引 i
	// 我们要找的是第一个 snapID > 目标 snap_id 的记录
	searchFunc := func(i int) bool {
		return history[i].snapID > snap_id
	}
	
	// 'i' 是第一个 history[i].snapID > snap_id 的位置
	i := sort.Search(len(history), searchFunc)

	// 我们需要的是小于等于 snap_id 的最后一个记录，所以取 i-1
	// i=0 的情况意味着所有记录的 snapID 都 <= snap_id，我们取最后一个
	// 这里 i-1 就是正确的索引
	return history[i-1].value
}

// --- 使用示例 ---
func main() {
	snapshotArr := Constructor(3) // 初始化长度为 3 的数组
	snapshotArr.Set(0, 5)
	snapID0 := snapshotArr.Snap()
	fmt.Println("Snap ID 0 created.")

	snapshotArr.Set(0, 6)
	snapshotArr.Set(1, 2)

	fmt.Printf("Get(index=0, snap_id=0): %d\n", snapshotArr.Get(0, snapID0)) // 输出 5

	snapID1 := snapshotArr.Snap()
	fmt.Println("Snap ID 1 created.")

	fmt.Printf("Get(index=0, snap_id=1): %d\n", snapshotArr.Get(0, snapID1)) // 输出 6
	fmt.Printf("Get(index=1, snap_id=1): %d\n", snapshotArr.Get(1, snapID1)) // 输出 2
}
```
