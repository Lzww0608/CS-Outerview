# 21. 二叉搜索树第 K 小

## 题目

给定一棵二叉搜索树 BST，返回第 `k` 小的节点值。

BST 的中序遍历是升序序列，所以第 `k` 小就是中序遍历的第 `k` 个元素。

## 迭代中序遍历

```cpp
#include <stack>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

int kthSmallest(TreeNode* root, int k) {
    stack<TreeNode*> st;
    TreeNode* cur = root;

    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) {
            st.push(cur);
            cur = cur->left;
        }

        cur = st.top();
        st.pop();

        --k;
        if (k == 0) {
            return cur->val;
        }

        cur = cur->right;
    }

    return -1;
}
```

## 复杂度

```text
时间复杂度: O(h + k)
空间复杂度: O(h)
```

`h` 是树高。平衡 BST 中 `h = log n`，退化成链时 `h = n`。

## 如果频繁查询

如果树会频繁查询第 `k` 小，可以在每个节点维护子树大小：

```text
left_size = size(root->left)
if k == left_size + 1: root 是答案
if k <= left_size: 去左子树
else: 去右子树找 k - left_size - 1
```

这样单次查询是 `O(h)`，但插入删除时要维护 size。

## 易错点

1. `k` 通常从 1 开始，不是从 0 开始。
2. 递归中序写法简单，但树很深时可能栈溢出。
3. 普通二叉树不能用这个方法，必须利用 BST 的中序有序性。
4. 如果有重复值，要先和面试官确认重复值是否作为独立节点计数。
