# 115. 最长公共子串

## 题目

给定两个字符串 `a` 和 `b`，求它们的最长公共子串。子串要求连续，不同于最长公共子序列。

示例：

```text
a = "ababc"
b = "babca"
最长公共子串 = "babc"
长度 = 4
```

## 思路

使用动态规划。设 `dp[i][j]` 表示：

```text
a[0..i-1] 和 b[0..j-1] 中，以 a[i-1] 和 b[j-1] 结尾的最长公共后缀长度
```

状态转移：

```text
if a[i - 1] == b[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
else:
    dp[i][j] = 0
```

每次更新最大长度和结束位置，最后从 `a` 中截取答案。

由于 `dp[i][j]` 只依赖左上角，可以把空间从 `O(nm)` 优化到 `O(m)`，并且内层循环要从右往左更新，避免覆盖上一行的 `dp[j - 1]`。

## 代码

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

string longestCommonSubstring(const string& a, const string& b) {
    if (a.empty() || b.empty()) {
        return "";
    }

    vector<int> dp(b.size() + 1, 0);
    int bestLen = 0;
    int bestEnd = 0; // 在 a 中的结束位置，开区间

    for (int i = 1; i <= static_cast<int>(a.size()); ++i) {
        for (int j = static_cast<int>(b.size()); j >= 1; --j) {
            if (a[i - 1] == b[j - 1]) {
                dp[j] = dp[j - 1] + 1;
                if (dp[j] > bestLen) {
                    bestLen = dp[j];
                    bestEnd = i;
                }
            } else {
                dp[j] = 0;
            }
        }
    }

    return a.substr(bestEnd - bestLen, bestLen);
}
```

## 复杂度

```text
时间复杂度: O(n * m)
空间复杂度: O(m)
```

其中 `n = a.size()`，`m = b.size()`。

## 易错点

1. 最长公共子串要求连续，字符不相等时 `dp[i][j]` 必须置为 `0`。
2. 最长公共子序列不要求连续，状态转移是 `max(dp[i-1][j], dp[i][j-1])`，不要混淆。
3. 一维优化时内层循环必须从右往左，否则 `dp[j - 1]` 会被当前行覆盖。
4. 如果题目只要求长度，可以只返回 `bestLen`。
5. 如果字符串很长，`O(nm)` 可能无法接受，可以考虑后缀自动机、后缀数组，或二分长度 + rolling hash。

## 可扩展方案

1. **后缀自动机**：对一个字符串建 SAM，再用另一个字符串在自动机上匹配，时间复杂度可做到 `O(n + m)`，适合长字符串。
2. **二分 + Rolling Hash**：二分答案长度，判断两个字符串是否存在相同长度的子串哈希。要处理哈希冲突，可以用双哈希或最终字符串校验。
3. **后缀数组**：把两个字符串用特殊分隔符拼接，对后缀排序后，在相邻且来自不同原串的后缀中取最长公共前缀。

## 面试回答模板

这题是最长公共子串，不是子序列。可以定义 `dp[i][j]` 为以 `a[i-1]`、`b[j-1]` 结尾的最长公共后缀长度，字符相等就从左上角转移加一，不相等就清零。遍历过程中记录最大长度和在 `a` 中的结束位置即可。普通 DP 时间 `O(nm)`，空间可以用一维数组优化到 `O(m)`；如果数据规模很大，可以进一步讲后缀自动机或 rolling hash。
