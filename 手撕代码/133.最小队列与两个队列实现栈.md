# 133. 最小队列与两个队列实现栈

面经里常见两类题：

1. 实现一个队列，要求平均 `O(1)` 返回最小值。
2. 用两个 `queue` 实现一个 `stack`。

两题都在考“额外维护状态”以及对摊还复杂度的理解。

## 1. 平均 O(1) 返回最小值的队列

可以用一个普通队列保存真实数据，再用一个单调递增双端队列保存候选最小值。

入队 `x` 时，把单调队列尾部所有大于 `x` 的元素弹掉，再把 `x` 放进去。出队时，如果弹出的值等于单调队列队首，也同步弹出队首。

```cpp
#include <deque>
#include <queue>
#include <stdexcept>
using namespace std;

class MinQueue {
public:
    void push(int x) {
        data_.push(x);
        while (!mins_.empty() && mins_.back() > x) {
            mins_.pop_back();
        }
        mins_.push_back(x);
    }

    void pop() {
        if (data_.empty()) {
            throw runtime_error("empty queue");
        }
        int x = data_.front();
        data_.pop();
        if (!mins_.empty() && mins_.front() == x) {
            mins_.pop_front();
        }
    }

    int front() const {
        if (data_.empty()) {
            throw runtime_error("empty queue");
        }
        return data_.front();
    }

    int getMin() const {
        if (mins_.empty()) {
            throw runtime_error("empty queue");
        }
        return mins_.front();
    }

private:
    queue<int> data_;
    deque<int> mins_;
};
```

每个元素最多进入和离开单调队列一次，所以 `push/pop` 是摊还 `O(1)`，`getMin` 是严格 `O(1)`。

## 2. 用两个最小栈实现最小队列

另一种常见做法是用两个支持 `getMin` 的栈：

1. `in` 负责入队。
2. `out` 负责出队。
3. 出队时如果 `out` 为空，就把 `in` 全部倒入 `out`。
4. 队列最小值是 `min(in.getMin(), out.getMin())`。

这种方案更适合复用“最小栈”的实现，也能做到摊还 `O(1)`。

## 3. 两个 queue 实现 stack

栈要求后进先出。用两个队列时可以让 `push` 变贵，让每次新元素都排到队首：

```cpp
#include <queue>
#include <stdexcept>
using namespace std;

class StackByQueues {
public:
    void push(int x) {
        q2_.push(x);
        while (!q1_.empty()) {
            q2_.push(q1_.front());
            q1_.pop();
        }
        swap(q1_, q2_);
    }

    void pop() {
        if (q1_.empty()) {
            throw runtime_error("empty stack");
        }
        q1_.pop();
    }

    int top() const {
        if (q1_.empty()) {
            throw runtime_error("empty stack");
        }
        return q1_.front();
    }

    bool empty() const {
        return q1_.empty();
    }

private:
    queue<int> q1_;
    queue<int> q2_;
};
```

复杂度：

| 操作 | 复杂度 |
| --- | --- |
| `push` | `O(n)` |
| `pop` | `O(1)` |
| `top` | `O(1)` |

也可以反过来让 `push` 为 `O(1)`，在 `pop/top` 时搬运 `n-1` 个元素。

## 4. 易错点

1. 单调队列里不能只存一个最小值，否则最小值出队后无法知道下一个最小值。
2. 单调队列处理重复值时，出队要按值同步；也可以存 `(value, count)`。
3. “平均 `O(1)`”通常指摊还复杂度，不是每一步都固定常数。
4. 用两个队列实现栈时，要明确是让 `push` 变贵还是让 `pop` 变贵。

## 5. 面试回答模板

最小队列可以用普通队列加单调递增双端队列。入队时把单调队列尾部比新值大的元素删除，保证队首始终是当前窗口最小值；出队时如果真实出队值等于单调队列队首，也同步弹出。每个元素最多进出单调队列一次，所以入队出队摊还 `O(1)`，取最小值 `O(1)`。两个队列实现栈时，可以每次 `push` 后把旧队列元素接到新元素后面，从而让队首始终是栈顶。
