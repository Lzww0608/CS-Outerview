# 153. 双向链表逆置

题目：给定双向链表头节点，反转链表并返回新的头节点。

双向链表每个节点有 `prev` 和 `next` 两个指针。反转时要同时交换这两个指针，不能只改 `next`。

## 1. 迭代写法

```cpp
struct DListNode {
    int val;
    DListNode* prev;
    DListNode* next;

    explicit DListNode(int x) : val(x), prev(nullptr), next(nullptr) {}
};

DListNode* reverseDoublyList(DListNode* head) {
    DListNode* cur = head;
    DListNode* newHead = nullptr;

    while (cur != nullptr) {
        DListNode* next = cur->next;

        cur->next = cur->prev;
        cur->prev = next;

        newHead = cur;
        cur = next;
    }

    return newHead;
}
```

遍历过程中，`next` 必须先保存原来的后继节点。交换后，`cur->prev` 才是原来的后继。

## 2. 带 tail 的链表

如果链表结构同时保存 `head` 和 `tail`，反转后直接交换二者：

```cpp
struct DList {
    DListNode* head = nullptr;
    DListNode* tail = nullptr;
};

void reverse(DList& list) {
    DListNode* cur = list.head;
    while (cur != nullptr) {
        DListNode* next = cur->next;
        cur->next = cur->prev;
        cur->prev = next;
        cur = next;
    }
    std::swap(list.head, list.tail);
}
```

## 3. 复杂度

1. 时间复杂度：`O(n)`。
2. 额外空间复杂度：`O(1)`。

## 4. 易错点

1. 先保存原始 `next`，否则交换指针后找不到后续节点。
2. 空链表和单节点链表天然可处理，返回原节点即可。
3. 如果链表维护 `tail`，反转后要更新 `tail`，不能只返回新头。
4. 如果是循环双向链表，停止条件不是 `cur != nullptr`，需要按起点循环一圈后停止。

## 5. 面试回答模板

双向链表反转时，每个节点只需要交换 `prev` 和 `next`。遍历时先保存原始 `next`，再交换当前节点两个指针，然后沿着原始 `next` 前进。最后访问到的节点就是新头。时间复杂度 `O(n)`，额外空间 `O(1)`；如果链表结构维护尾指针，还要把原来的 head 和 tail 交换。
