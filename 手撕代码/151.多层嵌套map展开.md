# 151. 多层嵌套 map 展开

题目：给定一个多层嵌套的 `map`，把它展开成一层 key-value。常见输出形式是用点号连接路径，例如 `{"a": {"b": 1}}` 展开为 `{"a.b": 1}`。

## 1. 定义清楚输入输出

面试前要先问清楚：

1. key 路径用什么分隔符，例如 `.`、`/`。
2. value 是否只有整数/字符串，还是可能继续嵌套对象。
3. 数组要不要处理，如果有数组，路径是否加下标。
4. key 自身包含分隔符时如何转义。
5. 输出顺序是否有要求。

如果只考虑 C++ 中的嵌套 map，可以用一个简单递归结构表示：

```cpp
#include <map>
#include <string>
#include <variant>

struct Value;
using Object = std::map<std::string, Value>;

struct Value {
    std::variant<std::string, Object> data;
};
```

## 2. DFS 递归展开

```cpp
#include <map>
#include <string>
#include <variant>

struct Value;
using Object = std::map<std::string, Value>;

struct Value {
    std::variant<std::string, Object> data;
};

void flattenDfs(const Object& obj,
                const std::string& prefix,
                std::map<std::string, std::string>& out) {
    for (const auto& [key, value] : obj) {
        std::string path = prefix.empty() ? key : prefix + "." + key;

        if (std::holds_alternative<std::string>(value.data)) {
            out[path] = std::get<std::string>(value.data);
        } else {
            flattenDfs(std::get<Object>(value.data), path, out);
        }
    }
}
```

调用：

```cpp
std::map<std::string, std::string> out;
flattenDfs(root, "", out);
```

## 3. 迭代写法

如果嵌套层数可能很深，递归会有栈溢出风险，可以用显式栈：

```cpp
#include <stack>

std::map<std::string, std::string> flattenIter(const Object& root) {
    std::map<std::string, std::string> out;
    std::stack<std::pair<std::string, const Object*>> st;
    st.push({"", &root});

    while (!st.empty()) {
        auto [prefix, obj] = st.top();
        st.pop();

        for (const auto& [key, value] : *obj) {
            std::string path = prefix.empty() ? key : prefix + "." + key;
            if (std::holds_alternative<std::string>(value.data)) {
                out[path] = std::get<std::string>(value.data);
            } else {
                st.push({path, &std::get<Object>(value.data)});
            }
        }
    }
    return out;
}
```

## 4. 易错点

1. 递归终止条件是 value 不再是 map，而不是 key 为空。
2. 路径拼接要处理根节点前缀，避免生成 `.a.b`。
3. 如果 key 可以包含分隔符，需要转义，否则展开后无法无损还原。
4. 如果输入可能有共享引用或环，就不能只按树处理，要加 visited 防止无限递归。
5. 输出顺序如果要和输入一致，应使用有序 `map` 或保留输入顺序的数据结构。

## 5. 真实场景

1. 配置中心把嵌套配置展开成环境变量或扁平 key。
2. 日志系统把 JSON 展开成可索引字段。
3. 数据同步时把文档型结构转换成关系型宽表。
4. 前端表单提交嵌套对象，后端转换成校验路径。

## 6. 面试回答模板

多层嵌套 map 展开本质是 DFS。递归时维护当前路径前缀，遇到普通值就写入 `out[prefix.key]`，遇到子 map 就继续递归。路径分隔符、key 转义、数组和输出顺序要提前定义。层数很深时递归可能栈溢出，可以改成显式栈；如果结构可能有环，要加 visited。
