# 重排链表

## 1. 问题描述

给定一个单链表 L: L0→L1→...→Ln-1→Ln

将其重新排列为 L0→Ln→L1→Ln-1→L2→Ln-2→...

要求：**原地修改**，时间复杂度 **O(n)**。

```
示例：
输入: 1 -> 2 -> 3 -> 4 -> 5
输出: 1 -> 5 -> 2 -> 4 -> 3

输入: 1 -> 2 -> 3 -> 4
输出: 1 -> 4 -> 2 -> 3
```

## 2. 解题思路

分三步走，每步都是经典的链表操作：

```
Step 1: 找中点（快慢指针）
1 -> 2 -> 3 -> 4 -> 5
      ↑
    slow/fast

Step 2: 反转后半部分
前半: 1 -> 2 -> 3
后半: 4 <- 5  (反转后)

Step 3: 交替合并
1 -> 2 -> 3
4 -> 5         (已反转)
↓交替合并↓
1 -> 4 -> 2 -> 5 -> 3
```

## 3. 复杂度分析

| 步骤 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 找中点 | O(n) | O(1) |
| 反转后半 | O(n/2) | O(1) |
| 合并链表 | O(n) | O(1) |
| **总计** | **O(n)** | **O(1)** |

## 4. C++ 实现

```cpp
#include <iostream>

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

class Solution {
public:
    // 主函数：重排链表
    void reorderList(ListNode* head) {
        if (!head || !head->next || !head->next->next) {
            return;  // 边界情况：空链表或只有1-2个节点
        }
        
        // Step 1: 找中点（分成前后两半）
        ListNode* slow = head;
        ListNode* fast = head;
        
        while (fast->next && fast->next->next) {
            slow = slow->next;           // slow 走一步
            fast = fast->next->next;     // fast 走两步
        }
        // 循环结束后，slow 指向中点
        
        // Step 2: 反转后半部分
        ListNode* prev = nullptr;
        ListNode* curr = slow->next;
        slow->next = nullptr;  // 断开前后两半
        
        while (curr) {
            ListNode* nextTemp = curr->next;  // 保存下一个
            curr->next = prev;                 // 反转指针
            prev = curr;                       // prev 前移
            curr = nextTemp;                   // curr 前移
        }
        // 循环结束后，prev 指向反转后的链表头
        
        // Step 3: 交替合并前后两半
        ListNode* first = head;   // 前半链表头
        ListNode* second = prev;   // 反转后的后半链表头
        
        while (first && second) {
            // 保存下一个节点
            ListNode* firstNext = first->next;
            ListNode* secondNext = second->next;
            
            // 链接
            first->next = second;
            if (firstNext) {
                second->next = firstNext;
            }
            
            // 前移
            first = firstNext;
            second = secondNext;
        }
    }
    
    // 辅助函数：打印链表
    void printList(ListNode* head) {
        while (head) {
            std::cout << head->val;
            if (head->next) std::cout << " -> ";
            head = head->next;
        }
        std::cout << std::endl;
    }
    
    // 辅助函数：创建链表
    ListNode* createList(std::initializer_list<int> values) {
        if (values.size() == 0) return nullptr;
        
        ListNode* head = new ListNode(*values.begin());
        ListNode* current = head;
        
        for (auto it = values.begin() + 1; it != values.end(); ++it) {
            current->next = new ListNode(*it);
            current = current->next;
        }
        return head;
    }
};

// 测试
int main() {
    Solution sol;
    
    // 测试用例1: 奇数个节点
    std::cout << "Test 1 (5 nodes):" << std::endl;
    ListNode* head1 = sol.createList({1, 2, 3, 4, 5});
    std::cout << "Before: ";
    sol.printList(head1);
    sol.reorderList(head1);
    std::cout << "After:  ";
    sol.printList(head1);
    
    // 测试用例2: 偶数个节点
    std::cout << "\nTest 2 (4 nodes):" << std::endl;
    ListNode* head2 = sol.createList({1, 2, 3, 4});
    std::cout << "Before: ";
    sol.printList(head2);
    sol.reorderList(head2);
    std::cout << "After:  ";
    sol.printList(head2);
    
    // 测试用例3: 只有2个节点
    std::cout << "\nTest 3 (2 nodes):" << std::endl;
    ListNode* head3 = sol.createList({1, 2});
    std::cout << "Before: ";
    sol.printList(head3);
    sol.reorderList(head3);
    std::cout << "After:  ";
    sol.printList(head3);
    
    return 0;
}
```

**运行结果**：

```
Test 1 (5 nodes):
Before: 1 -> 2 -> 3 -> 4 -> 5
After:  1 -> 5 -> 2 -> 4 -> 3

Test 2 (4 nodes):
Before: 1 -> 2 -> 3 -> 4
After:  1 -> 4 -> 2 -> 3

Test 3 (2 nodes):
Before: 1 -> 2
After:  1 -> 2
```

## 5. Go 实现

```go
package main

import "fmt"

// ListNode 定义
type ListNode struct {
    Val  int
    Next *ListNode
}

// 打印链表
func printList(head *ListNode) {
    for head != nil {
        fmt.Print(head.Val)
        if head.Next != nil {
            fmt.Print(" -> ")
        }
        head = head.Next
    }
    fmt.Println()
}

// 重排链表
func reorderList(head *ListNode) {
    if head == nil || head.Next == nil || head.Next.Next == nil {
        return // 边界情况
    }

    // Step 1: 找中点（快慢指针）
    slow := head
    fast := head

    for fast.Next != nil && fast.Next.Next != nil {
        slow = slow.Next     // slow 走一步
        fast = fast.Next.Next // fast 走两步
    }

    // Step 2: 反转后半部分
    var prev *ListNode = nil
    curr := slow.Next
    slow.Next = nil // 断开前后两半

    for curr != nil {
        nextTemp := curr.Next // 保存下一个
        curr.Next = prev     // 反转指针
        prev = curr          // prev 前移
        curr = nextTemp       // curr 前移
    }

    // Step 3: 交替合并前后两半
    first := head   // 前半链表头
    second := prev   // 反转后的后半链表头

    for first != nil && second != nil {
        // 保存下一个节点
        firstNext := first.Next
        secondNext := second.Next

        // 链接
        first.Next = second
        if firstNext != nil {
            second.Next = firstNext
        }

        // 前移
        first = firstNext
        second = secondNext
    }
}

// 创建链表
func createList(values []int) *ListNode {
    if len(values) == 0 {
        return nil
    }

    head := &ListNode{Val: values[0]}
    current := head

    for i := 1; i < len(values); i++ {
        current.Next = &ListNode{Val: values[i]}
        current = current.Next
    }
    return head
}

// 测试
func main() {
    // 测试用例1: 奇数个节点
    fmt.Println("Test 1 (5 nodes):")
    head1 := createList([]int{1, 2, 3, 4, 5})
    fmt.Print("Before: ")
    printList(head1)
    reorderList(head1)
    fmt.Print("After:  ")
    printList(head1)

    // 测试用例2: 偶数个节点
    fmt.Println("\nTest 2 (4 nodes):")
    head2 := createList([]int{1, 2, 3, 4})
    fmt.Print("Before: ")
    printList(head2)
    reorderList(head2)
    fmt.Print("After:  ")
    printList(head2)

    // 测试用例3: 只有2个节点
    fmt.Println("\nTest 3 (2 nodes):")
    head3 := createList([]int{1, 2})
    fmt.Print("Before: ")
    printList(head3)
    reorderList(head3)
    fmt.Print("After:  ")
    printList(head3)
}
```

**运行结果**：

```
Test 1 (5 nodes):
Before: 1 -> 2 -> 3 -> 4 -> 5
After:  1 -> 5 -> 2 -> 4 -> 3

Test 2 (4 nodes):
Before: 1 -> 2 -> 3 -> 4
After:  1 -> 4 -> 2 -> 3

Test 3 (2 nodes):
Before: 1 -> 2
After:  1 -> 2
```

## 6. 核心步骤图解

### Step 1: 快慢指针找中点

```
原始链表: 1 -> 2 -> 3 -> 4 -> 5
                    ↑
               slow (中点)

快指针走两步，慢指针走一步
```

### Step 2: 反转后半

```
前半: 1 -> 2 -> 3 -> NULL
后半: 4 -> 5 -> NULL

反转后:
1 -> 2 -> 3 -> NULL
5 -> 4 -> NULL
```

### Step 3: 交替合并

```
first:  1 -> 2 -> 3
second: 5 -> 4

合并过程:
1 -> 5 -> 2 -> 4 -> 3
```

## 7. 易错点

1. **断开链表**：找完中点后要断开前后两半
2. **边界条件**：空链表、1个节点、2个节点要特殊处理
3. **保存 next**：合并前一定要保存下一个节点的引用

## 8. 面试追问

### Q: 为什么这题是 O(n) 时间复杂度？

因为三个步骤都是一次遍历：
- 快慢指针找中点：O(n/2)
- 反转后半：O(n/2)
- 合并：O(n)

总时间 = O(n/2 + n/2 + n) = O(n)

### Q: 空间复杂度是多少？

**O(1)**，只使用了几个指针变量，没有额外空间。

### Q: 如果要求用递归实现呢？

递归实现会更复杂，而且会使用 O(log n) 的栈空间，不符合原地 O(1) 的要求。
