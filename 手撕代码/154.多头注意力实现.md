# 154. 多头注意力实现

题目：手写 Multi-Head Attention，有时要求用 NumPy 写。

## 1. 核心公式

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V
```

多头注意力把 hidden size 拆成多个 head，每个 head 单独算 attention，最后拼接。

## 2. NumPy 实现

```python
import numpy as np


def softmax(x, axis=-1):
    x = x - np.max(x, axis=axis, keepdims=True)
    exp = np.exp(x)
    return exp / np.sum(exp, axis=axis, keepdims=True)


def mha(x, wq, wk, wv, wo, num_heads, mask=None):
    # x: [B, T, D]
    b, t, d = x.shape
    assert d % num_heads == 0
    head_dim = d // num_heads

    q = x @ wq
    k = x @ wk
    v = x @ wv

    def split(y):
        return y.reshape(b, t, num_heads, head_dim).transpose(0, 2, 1, 3)

    q = split(q)  # [B, H, T, Dh]
    k = split(k)
    v = split(v)

    scores = q @ k.transpose(0, 1, 3, 2)
    scores = scores / np.sqrt(head_dim)

    if mask is not None:
        scores = np.where(mask, scores, -1e30)

    attn = softmax(scores, axis=-1)
    out = attn @ v
    out = out.transpose(0, 2, 1, 3).reshape(b, t, d)
    return out @ wo
```

## 3. Causal Mask

```python
def causal_mask(seq_len):
    mask = np.tril(np.ones((seq_len, seq_len), dtype=bool))
    return mask[None, None, :, :]
```

`mask=True` 表示允许关注，`False` 表示屏蔽。屏蔽位置在 softmax 前加一个很大的负数。

## 4. PyTorch 版本

```python
import math
import torch
import torch.nn as nn


class MultiHeadAttention(nn.Module):
    def __init__(self, dim, num_heads):
        super().__init__()
        assert dim % num_heads == 0
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.qkv = nn.Linear(dim, 3 * dim)
        self.out = nn.Linear(dim, dim)

    def forward(self, x, mask=None):
        b, t, d = x.shape
        qkv = self.qkv(x)
        q, k, v = qkv.chunk(3, dim=-1)

        def split(y):
            return y.view(b, t, self.num_heads, self.head_dim).transpose(1, 2)

        q, k, v = split(q), split(k), split(v)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.head_dim)

        if mask is not None:
            scores = scores.masked_fill(~mask, float("-inf"))

        attn = torch.softmax(scores, dim=-1)
        y = attn @ v
        y = y.transpose(1, 2).contiguous().view(b, t, d)
        return self.out(y)
```

## 5. 易错点

1. `hidden_size` 必须能被 `num_heads` 整除。
2. softmax 前要除以 `sqrt(head_dim)`。
3. mask 要能广播到 `[B, heads, T, T]`。
4. softmax 要做减最大值的稳定化处理。
5. transpose 后在 PyTorch 中通常要 `.contiguous()` 再 `view`。
6. Causal mask 是下三角，不能让当前位置看到未来 token。

## 6. 面试回答模板

手写 MHA 时，我会先线性投影出 Q/K/V，再把 `[B,T,D]` reshape 成 `[B,H,T,D/H]`。scores 是 `QK^T/sqrt(head_dim)`，形状 `[B,H,T,T]`，加 mask 后对最后一维 softmax，再乘 V 得到每个 head 的输出，最后 transpose 回 `[B,T,H,D/H]` 并 reshape 成 `[B,T,D]`，过输出线性层。复杂度是 `O(B*T^2*D)`，长序列下主要瓶颈是 attention 矩阵和 KV cache。
