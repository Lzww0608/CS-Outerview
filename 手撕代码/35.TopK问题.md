# Top K 问题

Top K 是从一组数据中找最大的 K 个、最小的 K 个，或第 K 大/第 K 小元素。面试要先问清楚：数据能否全部放内存、是否需要有序输出、是否是动态数据流。

## 小顶堆求最大的 K 个

如果要找最大的 K 个元素，维护大小为 K 的小顶堆：

1. 堆未满时直接入堆。
2. 堆满后，如果新元素大于堆顶，弹出堆顶并插入新元素。
3. 遍历结束后，堆中就是最大的 K 个元素。

```cpp
#include <functional>
#include <queue>
#include <vector>

std::vector<int> topKLargest(const std::vector<int>& nums, int k) {
    if (k <= 0) {
        return {};
    }

    std::priority_queue<int, std::vector<int>, std::greater<int>> heap;
    for (int x : nums) {
        if (static_cast<int>(heap.size()) < k) {
            heap.push(x);
        } else if (x > heap.top()) {
            heap.pop();
            heap.push(x);
        }
    }

    std::vector<int> ans;
    while (!heap.empty()) {
        ans.push_back(heap.top());
        heap.pop();
    }
    return ans; // 升序；如需降序可 reverse
}
```

复杂度：

```text
时间 O(n log k)
空间 O(k)
```

适合 K 远小于 n、数据流式到达、不能全量排序的场景。

## 大顶堆求最小的 K 个

如果要找最小的 K 个元素，思路正好反过来：维护大小为 K 的大顶堆。堆顶是当前保留的 K 个数里最大的那个。

1. 堆未满时直接入堆。
2. 堆满后，如果新元素小于堆顶，说明它应该进入最小 K 个，弹出堆顶并插入新元素。
3. 遍历结束后，堆中就是最小的 K 个元素。

```cpp
#include <queue>
#include <vector>

std::vector<int> smallestK(const std::vector<int>& nums, int k) {
    if (k <= 0) {
        return {};
    }

    std::priority_queue<int> heap;
    for (int x : nums) {
        if (static_cast<int>(heap.size()) < k) {
            heap.push(x);
        } else if (x < heap.top()) {
            heap.pop();
            heap.push(x);
        }
    }

    std::vector<int> ans;
    while (!heap.empty()) {
        ans.push_back(heap.top());
        heap.pop();
    }
    return ans; // 降序；如需升序可 reverse 或 sort
}
```

复杂度同样是：

```text
时间 O(n log k)
空间 O(k)
```

## Quickselect 求第 K 大

如果只要第 K 大元素，可以用快速选择，平均 `O(n)`：

```cpp
#include <algorithm>
#include <random>
#include <vector>

int kthLargest(std::vector<int> nums, int k) {
    int target = static_cast<int>(nums.size()) - k; // 转成第 target 小，0-based
    int l = 0, r = static_cast<int>(nums.size()) - 1;
    std::mt19937 gen(std::random_device{}());

    while (l <= r) {
        std::uniform_int_distribution<int> dist(l, r);
        int pivot_idx = dist(gen);
        std::swap(nums[pivot_idx], nums[r]);

        int pivot = nums[r];
        int store = l;
        for (int i = l; i < r; ++i) {
            if (nums[i] < pivot) {
                std::swap(nums[store++], nums[i]);
            }
        }
        std::swap(nums[store], nums[r]);

        if (store == target) {
            return nums[store];
        }
        if (store < target) {
            l = store + 1;
        } else {
            r = store - 1;
        }
    }
    return -1;
}
```

## 方案对比

| 方案 | 时间复杂度 | 空间复杂度 | 适用场景 |
| --- | --- | --- | --- |
| 全量排序 | `O(n log n)` | 取决于排序实现 | 数据不大且需要有序输出 |
| 大小为 K 的堆 | `O(n log k)` | `O(k)` | K 小、流式数据、内存受限 |
| Quickselect | 平均 `O(n)`，最坏 `O(n^2)` | `O(1)` 或递归栈 | 只要第 K 个，不要求 Top K 有序 |
| BFPRT | 最坏 `O(n)` | `O(1)` 或递归栈 | 理论最坏保证，工程较少手写 |

## 海量数据场景

1. 数据无法全部进内存时，按 hash 或范围分片后分别求局部 Top K，再归并。
2. 多机环境下，每台机器求本地 Top K，汇总后再求全局 Top K。
3. 实时排行榜通常用有序集合、跳表、堆或近似 heavy hitter 算法。

### 出现次数最多的前 K 个元素

如果题目是“海量数据中出现次数最多的前 K 个元素”，要先从“求最大值”切换成“先统计频次，再对频次做 Top K”。

单机内存足够时：

1. 用 `hash_map<元素, 次数>` 扫描计数。
2. 维护大小为 K 的小顶堆，堆元素是 `(count, value)`。
3. 计数完成后遍历哈希表，保留频次最高的 K 个。

如果数据太大，哈希表也放不下：

1. 按 `hash(value) % N` 把原始数据分到 N 个小文件，保证相同元素一定进入同一个分片。
2. 每个分片单独统计频次，并求局部 Top K。
3. 将所有局部 Top K 汇总后再用小顶堆求全局 Top K。
4. 分片仍然过大时继续二级分片，或者使用外部排序，把相同元素排到一起后顺序计数。

如果允许近似结果，可以用 Count-Min Sketch、Space-Saving、Lossy Counting 等 heavy hitter 算法，空间远小于全量哈希表，但会引入误差，适合实时监控、热点词、风控特征统计等场景。

易错点：

1. 不能对每个分片直接取“局部 Top K 后简单拼接”，必须再做一次全局 Top K。
2. 分片必须按元素哈希，不能随机切分，否则同一个元素的频次会散落在多个分片。
3. 频次相同的元素要明确排序规则，例如按值、字典序或首次出现时间打破平局。

### 100 亿个 QQ 号删除最大的 10 个

如果题目是“给 100 亿个 QQ 号，删除其中最大的 10 个”，本质仍是找全局最大的 10 个。QQ 号可以看作 64 位整数，100 亿个约 80GB 原始数据，通常不能全量放入单机内存排序。

方案：

1. 顺序扫描文件或数据流。
2. 维护大小为 10 的小顶堆。
3. 堆未满直接放入；堆满后，如果当前 QQ 号大于堆顶，则弹出堆顶并插入当前 QQ 号。
4. 扫描结束后，堆中就是最大的 10 个 QQ 号。
5. 如果要“删除”这些记录，可以第二次顺序扫描输入，把不在 Top10 集合里的记录写到新文件。

复杂度：

```text
找 Top10: 时间 O(n log 10)，空间 O(10)
删除输出: 再顺序扫描一遍，时间 O(n)，空间 O(10)
```

如果数据分布在多台机器上，每台机器先求本地 Top10，汇总后再求全局 Top10，然后把全局 Top10 下发到各分片做过滤删除。

## 易错点

1. 最大 K 个用小顶堆，最小 K 个用大顶堆。
2. 第 K 大和下标要转换清楚，K 通常从 1 开始。
3. Quickselect 改变原数组，不想修改输入要拷贝。
4. 堆里得到的 Top K 不一定有序，需要额外排序才有序输出。

## 面试回答模板

Top K 先看需求。如果只求最大的 K 个且 K 远小于 n，用大小为 K 的小顶堆，遍历数据时只保留当前最大的 K 个，时间 `O(n log k)`，空间 `O(k)`，也适合数据流。如果只求第 K 大，可以用 Quickselect，平均 `O(n)`。如果数据很小或需要完整有序结果，直接排序也可以。海量数据则先分片求局部 Top K，再做全局归并。
