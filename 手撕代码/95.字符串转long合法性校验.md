# 95. 字符串转 long 合法性校验

## 题目

给一个字符串 `str`，将其转换为对应的 `long` 值；如果不是合法数字，返回空值。面试中可以用 `std::optional<long>` 表达“返回 null”。

需要提前约定合法格式：

1. 可以有前导空白。
2. 可以有一个可选的 `+` 或 `-`。
3. 至少有一个数字。
4. 数字后只能有尾随空白。
5. 溢出或下溢视为非法。

## C++ 实现

```cpp
#include <cctype>
#include <climits>
#include <optional>
#include <string>
using namespace std;

optional<long> parseLong(const string& s) {
    int n = static_cast<int>(s.size());
    int i = 0;

    while (i < n && isspace(static_cast<unsigned char>(s[i]))) {
        ++i;
    }

    int sign = 1;
    if (i < n && (s[i] == '+' || s[i] == '-')) {
        sign = s[i] == '-' ? -1 : 1;
        ++i;
    }

    if (i == n || !isdigit(static_cast<unsigned char>(s[i]))) {
        return nullopt;
    }

    unsigned long limit = sign == 1
        ? static_cast<unsigned long>(LONG_MAX)
        : static_cast<unsigned long>(LONG_MAX) + 1UL;

    unsigned long value = 0;
    while (i < n && isdigit(static_cast<unsigned char>(s[i]))) {
        int digit = s[i] - '0';
        if (value > (limit - digit) / 10) {
            return nullopt;
        }
        value = value * 10 + digit;
        ++i;
    }

    while (i < n && isspace(static_cast<unsigned char>(s[i]))) {
        ++i;
    }
    if (i != n) {
        return nullopt;
    }

    if (sign == 1) {
        return static_cast<long>(value);
    }
    if (value == static_cast<unsigned long>(LONG_MAX) + 1UL) {
        return LONG_MIN;
    }
    return -static_cast<long>(value);
}
```

## 为什么不能先累乘再判断

如果写成：

```cpp
value = value * 10 + digit;
if (value > LONG_MAX) ...
```

在有符号整数里，乘法本身可能已经溢出，而有符号溢出是未定义行为。正确做法是在乘加之前判断：

```text
value > (limit - digit) / 10
```

这样能保证下一步乘加仍在安全范围内。

## 测试样例

```text
"123"                  -> 123
"  -42 "               -> -42
"+0"                   -> 0
""                     -> null
"+"                    -> null
"12abc"                -> null
"9223372036854775807"  -> LONG_MAX，64 位 long 场景
"9223372036854775808"  -> null，64 位 long 场景
"-9223372036854775808" -> LONG_MIN，64 位 long 场景
```

## 易错点

1. `isdigit(s[i])` 要把 `char` 转成 `unsigned char`，避免负值字符导致未定义行为。
2. `LONG_MIN` 的绝对值比 `LONG_MAX` 大 1，负数边界要单独处理。
3. 只看到符号但没有数字不是合法数字。
4. 是否允许前后空白、前导零、`+` 号，要和面试官确认。

## 面试回答模板

我会手写状态解析：先跳过前导空白，再处理可选符号，随后至少读取一个数字。累积数值时用无符号变量保存绝对值，并在乘 10 加 digit 之前用 `(limit - digit) / 10` 判断溢出。读完数字后只允许尾随空白，如果还有其他字符就返回空。返回值用 `optional<long>` 表示合法值或 null。
