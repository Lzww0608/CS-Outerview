# 字典序第 K 个数字

题目常见版本：给定 `n` 和 `k`，在整数 `1~n` 中按字典序排序，找到第 `k` 个数字。面试里如果说“从 1 开始的有序数组”，通常可以抽象成 `[1, 2, ..., n]` 的字典序第 `k` 个数。

例如 `n = 13` 时，字典序为：

```text
1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9
```

## 1. 十叉树前缀计数

把 `1~n` 看成一棵十叉前缀树：

```text
1
  10
  11
  ...
2
3
...
9
```

如果当前前缀是 `prefix`，需要计算以它为前缀、且不超过 `n` 的数字有多少个。若这棵子树节点数小于等于 `k`，说明答案不在该子树，跳到下一个兄弟前缀；否则进入子树下一层。

```cpp
#include <algorithm>
using namespace std;

long long countPrefix(long long prefix, long long n) {
    long long next = prefix + 1;
    long long count = 0;

    while (prefix <= n) {
        count += min(n + 1, next) - prefix;
        prefix *= 10;
        next *= 10;
    }

    return count;
}

int findKthLexicographical(int n, int k) {
    long long cur = 1;
    --k; // 第一个数是 1

    while (k > 0) {
        long long cnt = countPrefix(cur, n);
        if (cnt <= k) {
            ++cur;
            k -= cnt;
        } else {
            cur *= 10;
            --k; // 进入子树时访问了 cur 本身
        }
    }

    return static_cast<int>(cur);
}
```

复杂度：

1. `countPrefix` 是 `O(log10 n)`。
2. 主循环最多在前缀树上横向和纵向移动，常见复杂度可认为是 `O(log n * 10 * log n)` 量级，远小于生成并排序所有数字。
3. 空间复杂度 `O(1)`。

## 2. 如果问第 k 大

要先确认“第 k 大”是按数值大小还是字典序逆序。如果是字典序第 `k` 大，可以转成字典序升序第 `n - k + 1` 个：

```cpp
int findKthLargestLexicographical(int n, int k) {
    return findKthLexicographical(n, n - k + 1);
}
```

如果是给定任意数组而不是 `1~n`，则要把数字转字符串排序，或者用 trie/比较器处理，不能直接套前缀计数。

## 3. 易错点

1. 字典序不是数值大小顺序，`10` 会排在 `2` 前面。
2. `countPrefix` 要用 `long long`，否则 `prefix *= 10` 可能溢出。
3. `min(n + 1, next) - prefix` 用于计算当前层这个前缀覆盖多少个合法数字。
4. 题目说“第 k 大”时要确认排序方向和比较规则。

## 4. 面试回答模板

可以把 `1~n` 的数字看成十叉前缀树，按字典序就是这棵树的先序遍历。每次计算当前前缀子树里有多少个不超过 `n` 的数字，如果数量小于等于 `k` 就跳过整棵子树去兄弟前缀，否则进入下一层。这样不需要生成所有数字，空间 `O(1)`，时间和数字位数相关。
