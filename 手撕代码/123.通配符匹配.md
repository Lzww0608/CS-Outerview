# 123. 通配符匹配

## 题目

实现支持 `?` 和 `*` 的简化通配符匹配：

1. `?` 匹配任意单个字符。
2. `*` 匹配任意长度字符串，包括空串。

对应 LeetCode 44。

## 思路

设 `dp[i][j]` 表示 `s[0..i-1]` 是否能被 `p[0..j-1]` 匹配。

转移：

1. 普通字符或 `?`：`dp[i][j] = dp[i-1][j-1]`。
2. `*`：可以匹配空串，也可以匹配一个或多个字符：

```text
dp[i][j] = dp[i][j-1] || dp[i-1][j]
```

## 代码

```cpp
#include <string>
#include <vector>
using namespace std;

bool isMatch(string s, string p) {
    int n = s.size();
    int m = p.size();
    vector<vector<bool>> dp(n + 1, vector<bool>(m + 1, false));
    dp[0][0] = true;

    for (int j = 1; j <= m; ++j) {
        if (p[j - 1] == '*') dp[0][j] = dp[0][j - 1];
    }

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (p[j - 1] == '*') {
                dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
            } else if (p[j - 1] == '?' || p[j - 1] == s[i - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            }
        }
    }
    return dp[n][m];
}
```

## 易错点

1. `*` 可以匹配空串，所以 `dp[0][j]` 要初始化连续星号。
2. `?` 只能匹配一个字符，不能匹配空串。
3. 这是通配符匹配，不是正则表达式；正则里的 `*` 表示重复前一个元素。
4. 空间可以滚动优化到 `O(m)`，但二维 DP 更适合面试讲清楚。
