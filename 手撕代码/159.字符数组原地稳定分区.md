# 159. 字符数组原地稳定分区

## 题目

给一个字符数组，写一个排序函数：数字排在字母前面，但数字之间相对顺序不变，字母之间相对顺序不变。要求原地操作，不能使用新数组。

这本质是**稳定分区**问题：按“是否为数字”把数组分成两段，同时保持每段内部原有相对顺序。

## 插入式稳定分区

最直观的原地做法是维护 `[0, digitEnd)` 为已经排好的数字区。扫描到数字时，把它插入到数字区末尾，并把中间的字母整体右移一位。

```cpp
#include <vector>
using namespace std;

bool isDigit(char c) {
    return c >= '0' && c <= '9';
}

void stableDigitsFirst(vector<char>& s) {
    int digitEnd = 0;

    for (int i = 0; i < static_cast<int>(s.size()); ++i) {
        if (!isDigit(s[i])) {
            continue;
        }

        char cur = s[i];
        for (int j = i; j > digitEnd; --j) {
            s[j] = s[j - 1];
        }
        s[digitEnd] = cur;
        ++digitEnd;
    }
}
```

示例：

```text
输入: a 1 b 2 c 3
输出: 1 2 3 a b c
```

复杂度：

```text
时间复杂度：O(n^2)
额外空间：O(1)
```

这个方法适合面试先写出正确版本。它稳定、原地、逻辑简单，但最坏情况下每个数字都要移动很多字母。

## 为什么普通双指针不行

普通快排式 partition 可以做到数字在前、字母在后，但不稳定：

```text
a 1 b 2
```

如果直接左右交换，可能得到：

```text
2 1 b a
```

数字和字母内部顺序都被破坏，不满足题意。

## 分治旋转优化

如果追求更好的时间复杂度，可以用稳定分区的分治做法：

1. 递归稳定分区左半段。
2. 递归稳定分区右半段。
3. 此时左半段形如 `digits_left letters_left`，右半段形如 `digits_right letters_right`。
4. 需要把中间的 `letters_left digits_right` 旋转成 `digits_right letters_left`。

```text
digits_left letters_left digits_right letters_right
-> digits_left digits_right letters_left letters_right
```

旋转可以用三次反转完成，额外空间 `O(1)`，时间复杂度 `O(n log n)`。实现更复杂，面试中可以先说明思路，再根据要求展开。

## 易错点

1. 题目要求稳定，不能用简单左右交换。
2. “不能用新数组”通常允许 `O(1)` 临时变量，但不允许再开一个结果数组。
3. 要确认字符范围：是否只有数字和字母，是否包含符号、空格、中文。
4. 如果允许使用库函数，C++ `stable_partition` 能表达意图，但它内部可能使用额外缓冲，面试手写时要说明约束。

## 面试回答模板

这题是原地稳定分区。普通双指针交换虽然能把数字放前面，但会破坏数字和字母各自的相对顺序。我会维护一个数字区尾指针 `digitEnd`，从左到右扫描，遇到数字就把它暂存起来，将 `[digitEnd, i)` 这一段字母整体右移一位，再把数字放到 `digitEnd`，最后 `digitEnd++`。这样额外空间 `O(1)`，稳定，但最坏时间 `O(n^2)`。如果追求更优时间，可以用分治加旋转做稳定分区，达到 `O(n log n)` 时间和 `O(1)` 额外空间。
