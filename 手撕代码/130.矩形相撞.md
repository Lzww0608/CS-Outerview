# 130. 矩形相撞

## 题目

给定两个矩形，判断它们是否相交或发生碰撞。面试中通常默认矩形与坐标轴平行，也就是 AABB（Axis-Aligned Bounding Box）。

## 核心思路

二维矩形相交可以拆成两个一维区间相交：

1. x 轴投影相交。
2. y 轴投影相交。

如果两个方向都相交，则矩形相交；只要某个方向分离，就不相交。

## 代码

```cpp
#include <algorithm>

struct Rect {
    int left;
    int bottom;
    int right;
    int top;
};

bool overlapStrict(const Rect& a, const Rect& b) {
    int xOverlap = std::min(a.right, b.right) - std::max(a.left, b.left);
    int yOverlap = std::min(a.top, b.top) - std::max(a.bottom, b.bottom);
    return xOverlap > 0 && yOverlap > 0;
}

bool overlapAllowTouch(const Rect& a, const Rect& b) {
    int xOverlap = std::min(a.right, b.right) - std::max(a.left, b.left);
    int yOverlap = std::min(a.top, b.top) - std::max(a.bottom, b.bottom);
    return xOverlap >= 0 && yOverlap >= 0;
}
```

`overlapStrict` 表示有正面积重叠，边界相贴不算碰撞。`overlapAllowTouch` 表示边界接触也算相交。

也可以用“不相交条件”写：

```cpp
bool overlapStrict2(const Rect& a, const Rect& b) {
    if (a.right <= b.left) return false;
    if (b.right <= a.left) return false;
    if (a.top <= b.bottom) return false;
    if (b.top <= a.bottom) return false;
    return true;
}
```

## 复杂度

时间复杂度 `O(1)`，空间复杂度 `O(1)`。

## 易错点

1. 要先明确“贴边”算不算碰撞。算贴边用 `>=`，不算贴边用 `>`。
2. 坐标输入可能不是左下和右上，需要先归一化：

```cpp
Rect normalize(Rect r) {
    if (r.left > r.right) std::swap(r.left, r.right);
    if (r.bottom > r.top) std::swap(r.bottom, r.top);
    return r;
}
```

3. 如果是旋转矩形，AABB 判断不够，需要用分离轴定理（SAT）。
4. 如果坐标是浮点数，边界判断要考虑精度误差，可以引入 `eps`。

## 真实场景

1. 游戏服务端做技能命中粗筛：先用 AABB 快速过滤，再做圆形、扇形或多边形精确判断。
2. UI 布局和鼠标点击检测。
3. 物理引擎 broad phase 碰撞检测。
4. 地图对象、障碍物、AOI 范围的快速相交判断。

## 面试回答模板

轴对齐矩形碰撞可以看成 x、y 两个方向的区间是否同时相交。计算 `min(right) - max(left)` 和 `min(top) - max(bottom)`，两个都大于 0 就有正面积重叠；如果边界相贴也算碰撞，则改成大于等于 0。这个方法是 `O(1)`，但只适用于轴对齐矩形；旋转矩形要用分离轴定理。
