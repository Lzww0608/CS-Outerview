# 判断 2 的幂

判断一个整数是否为 2 的幂，最优解通常使用位运算：

```text
n > 0 && (n & (n - 1)) == 0
```

## 1. 核心原理

正整数如果是 2 的幂，二进制中只会有一个 `1`：

```text
1  -> 0001
2  -> 0010
4  -> 0100
8  -> 1000
16 -> 10000
```

`n - 1` 会把这个唯一的 `1` 变成 `0`，并把它右侧的所有位变成 `1`。因此 `n & (n - 1)` 会清掉最低位的 `1`：

```text
n     = 1000
n - 1 = 0111
&     = 0000
```

如果一个数不是 2 的幂，它至少有两个 `1`，清掉最低位的 `1` 后结果仍然不为 0。

## 2. Go 实现

```go
func isPowerOfTwo(n int) bool {
    return n > 0 && (n&(n-1)) == 0
}
```

如果输入是无符号整数：

```go
func isPowerOfTwoUnsigned(n uint64) bool {
    return n != 0 && (n&(n-1)) == 0
}
```

复杂度：

```text
时间复杂度 O(1)
空间复杂度 O(1)
```

## 3. 易错点

1. `0` 不是 2 的幂，所以必须先判断 `n > 0` 或 `n != 0`。
2. 负数在补码表示下也可能满足某些位运算形态，不能省略正数判断。
3. `n & -n` 可以取出最低位的 `1`，但判断 2 的幂时 `(n & (n - 1)) == 0` 更直接。
4. 如果语言存在有符号整数溢出风险，`n - 1` 前要先排除最小值或使用无符号类型；Go 的整数溢出有确定的补码行为，但逻辑上仍应先判断正数。

## 4. 拓展

类似技巧：

1. 清除最低位的 `1`：`n &= n - 1`，常用于统计二进制中 `1` 的个数。
2. 取出最低位的 `1`：`lowbit := n & -n`，常用于树状数组。
3. 判断是否只有一个标志位被设置：同样可以用 `x != 0 && (x & (x - 1)) == 0`。

## 5. 面试回答模板

判断 2 的幂可以利用二进制特征：正整数如果是 2 的幂，二进制中只有一个 `1`。`n - 1` 会把这个 `1` 右侧全部变成 `1`，所以 `n & (n - 1)` 会等于 0。代码就是 `n > 0 && (n & (n - 1)) == 0`，时间和空间复杂度都是 `O(1)`。
