# 132. 质数筛与区间质数和

题目：求 `1` 到 `1000000` 的质数和。

这类题重点不是逐个试除，而是根据数据范围选择筛法。`1000000` 很小，可以直接用埃氏筛；如果范围更大、只给区间 `[L, R]`，再考虑分段筛。

## 1. 埃氏筛

埃氏筛维护一个布尔数组 `isPrime`，从 `2` 开始枚举质数 `p`，把 `p` 的倍数标记为合数。标记从 `p * p` 开始，因为更小的倍数已经被更小质因子标记过。

```cpp
#include <vector>
using namespace std;

long long primeSum(int n) {
    if (n < 2) {
        return 0;
    }

    vector<bool> isPrime(n + 1, true);
    isPrime[0] = false;
    isPrime[1] = false;

    for (long long p = 2; p * p <= n; ++p) {
        if (!isPrime[p]) {
            continue;
        }
        for (long long x = p * p; x <= n; x += p) {
            isPrime[x] = false;
        }
    }

    long long sum = 0;
    for (int i = 2; i <= n; ++i) {
        if (isPrime[i]) {
            sum += i;
        }
    }
    return sum;
}
```

`1` 到 `1000000` 的质数和是 `37550402023`，必须使用 `long long`，`int` 会溢出。

## 2. 复杂度

1. 时间复杂度：`O(n log log n)`。
2. 空间复杂度：`O(n)`。
3. 对 `n = 1000000`，布尔数组和循环次数都很小，面试中不需要做复杂优化。

## 3. 易错点

1. `1` 不是质数，`0` 也不是质数。
2. `p * p` 可能溢出 `int`，循环变量建议用 `long long` 或写成 `p <= n / p`。
3. 从 `2 * p` 开始标记也能正确，但会重复标记，效率差一些。
4. `vector<bool>` 是特化压缩存储，面试代码可用；工程中如果关注性能，也可以用 `vector<char>`。

## 4. 扩展：分段筛

如果要求求 `[L, R]` 内质数和，且 `R` 很大、区间长度可控，可以先筛出 `sqrt(R)` 以内的质数，再用这些质数标记 `[L, R]` 区间内的合数。这样空间从 `O(R)` 降到 `O(R-L+1)`。

真实场景里，筛法也常用于：

1. 预处理小范围质数表。
2. 哈希表选择质数桶数量。
3. 数论题中的质因子分解加速。

## 5. 面试回答模板

我会用埃氏筛。先开 `isPrime[0..n]`，把 `0` 和 `1` 标成非质数；从 `2` 枚举到 `sqrt(n)`，如果当前是质数，就从 `p*p` 开始把倍数标成合数。最后遍历数组累加质数。复杂度是 `O(n log log n)`，空间 `O(n)`。`1..1000000` 的和超过 `int`，要用 `long long`。
