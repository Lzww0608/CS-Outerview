# 175. 字符串大数相减

题目：给定两个用字符串表示的大整数 `S1` 和 `S2`，计算 `S1 - S2`，结果仍用字符串表示。输入可能超过内置整数范围，不能直接转成 `long long`。

## 1. 核心思路

大数减法本质是模拟竖式减法：

1. 先去掉两个数字的前导零。
2. 比较两个数字绝对值大小，决定结果符号。
3. 用较大的绝对值减较小的绝对值。
4. 从低位到高位逐位相减，不够减就向高位借位。
5. 最后去掉结果前导零；结果为 0 时不带负号。

例如：

```text
S1 = "1000", S2 = "999"

低位开始：
0 - 9 不够，借位 -> 10 - 9 = 1
下一位原本 0，被借后是 -1，再向高位借 -> 9 - 9 = 0
...
结果为 "1"
```

## 2. C++ 实现

```cpp
#include <algorithm>
#include <string>
using namespace std;

string stripLeadingZeros(const string& s) {
    size_t pos = s.find_first_not_of('0');
    return pos == string::npos ? "0" : s.substr(pos);
}

int compareAbs(string a, string b) {
    a = stripLeadingZeros(a);
    b = stripLeadingZeros(b);
    if (a.size() != b.size()) {
        return a.size() < b.size() ? -1 : 1;
    }
    if (a == b) {
        return 0;
    }
    return a < b ? -1 : 1;
}

string subtractAbs(string a, string b) {
    // 前提：a >= b，且二者都是非负整数字符串。
    int i = static_cast<int>(a.size()) - 1;
    int j = static_cast<int>(b.size()) - 1;
    int borrow = 0;
    string ans;

    while (i >= 0 || j >= 0) {
        int x = (i >= 0 ? a[i] - '0' : 0) - borrow;
        int y = (j >= 0 ? b[j] - '0' : 0);

        if (x < y) {
            x += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }

        ans.push_back(static_cast<char>('0' + (x - y)));
        --i;
        --j;
    }

    while (ans.size() > 1 && ans.back() == '0') {
        ans.pop_back();
    }

    reverse(ans.begin(), ans.end());
    return ans;
}

string subtractStrings(string s1, string s2) {
    s1 = stripLeadingZeros(s1);
    s2 = stripLeadingZeros(s2);

    int cmp = compareAbs(s1, s2);
    if (cmp == 0) {
        return "0";
    }

    if (cmp > 0) {
        return subtractAbs(s1, s2);
    }
    return "-" + subtractAbs(s2, s1);
}
```

## 3. 复杂度

```text
时间复杂度: O(max(m, n))
空间复杂度: O(max(m, n))
```

每一位最多处理一次，结果字符串长度最多是两个输入长度的最大值。

## 4. 易错点

1. 不能用 `stoi`、`stoll`，输入长度可能远超内置整数。
2. 要先比较绝对值，决定是否需要负号。
3. 借位是向下一轮传递 `borrow = 1`，不要直接修改原字符串导致边界复杂。
4. 结果要去掉前导零，例如 `"1000" - "0999" = "1"`。
5. 结果为 0 时返回 `"0"`，不能返回 `"-0"`。
6. 如果输入可能带正负号，需要先解析符号，把问题拆成同号相减或异号相加。

## 5. 面试回答模板

这题不能转整数，要模拟竖式减法。先去前导零，再比较两个字符串表示的绝对值大小；如果 `S1 < S2`，就交换顺序并给结果加负号。真正相减时从低位向高位处理，每位计算 `当前位 - borrow - 对方位`，如果不够减就加 10 并把 `borrow` 置为 1。最后反转结果并去掉前导零。时间复杂度是 `O(max(m,n))`。
