# 简单括号匹配

## 题目

给定一个只包含括号字符的字符串，判断括号是否匹配。常见括号包括 `()[]{}`。

示例：

```text
输入: "{[()]}"
输出: true

输入: "([)]"
输出: false
```

## 思路

使用栈保存尚未匹配的左括号：

1. 遇到左括号，入栈。
2. 遇到右括号，栈为空则非法。
3. 栈顶左括号和当前右括号不匹配则非法。
4. 扫描结束后，栈为空才合法。

栈的意义是括号必须满足后进先出的嵌套结构。

## 代码

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isValid(const string& s) {
    stack<char> st;

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
            continue;
        }

        if (st.empty()) {
            return false;
        }

        char top = st.top();
        st.pop();

        if ((c == ')' && top != '(') ||
            (c == ']' && top != '[') ||
            (c == '}' && top != '{')) {
            return false;
        }
    }

    return st.empty();
}

int main() {
    string s;
    cin >> s;
    cout << (isValid(s) ? "true" : "false") << endl;
    return 0;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

最坏情况下字符串全是左括号，栈大小为 `O(n)`。

## 易错点

1. 遇到右括号时要先判断栈是否为空。
2. 扫描结束后必须检查栈为空，只有没有未匹配左括号才合法。
3. 如果输入可能包含普通字符，要先明确题意：普通字符是忽略还是直接判非法。
4. 只用计数器只能处理单一括号类型，无法处理 `([)]` 这种交叉错误。
