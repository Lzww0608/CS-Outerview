# 87. 高精度乘法

高精度乘法用于处理整数超出内置类型范围的情况。常见输入是两个非负整数字符串，输出它们乘积的字符串。

## 核心思路

模拟竖式乘法。设两个数长度分别为 `m` 和 `n`，结果最多有 `m + n` 位。把每一位相乘的结果累加到数组中，再统一处理进位。

对于下标从左到右的字符串：

```text
num1[i] * num2[j] 对结果的贡献落在 i + j + 1
进位落在 i + j
```

## 代码

```cpp
#include <string>
#include <vector>
using namespace std;

string multiply(string num1, string num2) {
    if (num1 == "0" || num2 == "0") {
        return "0";
    }

    int m = static_cast<int>(num1.size());
    int n = static_cast<int>(num2.size());
    vector<int> res(m + n, 0);

    for (int i = m - 1; i >= 0; --i) {
        for (int j = n - 1; j >= 0; --j) {
            int mul = (num1[i] - '0') * (num2[j] - '0');
            int sum = res[i + j + 1] + mul;
            res[i + j + 1] = sum % 10;
            res[i + j] += sum / 10;
        }
    }

    string ans;
    int i = 0;
    while (i < static_cast<int>(res.size()) && res[i] == 0) {
        ++i;
    }
    for (; i < static_cast<int>(res.size()); ++i) {
        ans.push_back(static_cast<char>('0' + res[i]));
    }
    return ans.empty() ? "0" : ans;
}
```

复杂度：时间 `O(mn)`，空间 `O(m+n)`。

## 易错点

1. 结果数组长度最多是 `m + n`，例如 `99 * 99 = 9801`。
2. 处理进位时要累加到已有位置，不能直接覆盖。
3. 最终要去掉前导零。
4. 如果输入可能有负号，需要先记录符号，再对绝对值做乘法。
5. 如果输入很长，`O(mn)` 可能不够快，可以拓展到 Karatsuba 或 FFT/NTT。

## 真实场景

1. 大整数库、密码学实验、区块链金额计算。
2. 编程题中禁止使用 BigInteger 时的字符串乘法。
3. 科学计算或高精度阶乘、组合数计算的基础组件。

## 面试回答模板

高精度乘法可以用数组模拟竖式乘法。两个长度为 `m`、`n` 的数相乘，结果最多 `m+n` 位；`num1[i] * num2[j]` 的低位累加到 `res[i+j+1]`，进位累加到 `res[i+j]`。最后去掉前导零即可，时间复杂度 `O(mn)`，空间复杂度 `O(m+n)`。
