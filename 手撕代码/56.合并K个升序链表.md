# 合并 K 个升序链表

题目：给定 `k` 个升序链表，合并成一个升序链表。对应 LeetCode 23。

## 1. 最小堆

每次从 `k` 个链表当前头节点中取最小值，接到结果链表后，把该节点的下一个节点放回堆。

```cpp
#include <queue>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* mergeKLists(vector<ListNode*>& lists) {
    struct Cmp {
        bool operator()(const ListNode* a, const ListNode* b) const {
            return a->val > b->val; // 小根堆
        }
    };

    priority_queue<ListNode*, vector<ListNode*>, Cmp> heap;

    for (ListNode* head : lists) {
        if (head != nullptr) {
            heap.push(head);
        }
    }

    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (!heap.empty()) {
        ListNode* node = heap.top();
        heap.pop();

        if (node->next != nullptr) {
            heap.push(node->next);
        }

        tail->next = node;
        tail = tail->next;
    }

    tail->next = nullptr;
    return dummy.next;
}
```

复杂度：

1. 设总节点数为 `N`，链表数量为 `k`。
2. 时间复杂度：`O(N log k)`。
3. 空间复杂度：`O(k)`，堆最多保存 `k` 个节点。

## 2. 分治合并

也可以两两合并，类似归并排序：

```cpp
ListNode* mergeTwo(ListNode* a, ListNode* b) {
    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (a != nullptr && b != nullptr) {
        if (a->val <= b->val) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }

    tail->next = (a != nullptr) ? a : b;
    return dummy.next;
}

ListNode* mergeRange(vector<ListNode*>& lists, int left, int right) {
    if (left > right) {
        return nullptr;
    }
    if (left == right) {
        return lists[left];
    }

    int mid = left + (right - left) / 2;
    return mergeTwo(
        mergeRange(lists, left, mid),
        mergeRange(lists, mid + 1, right)
    );
}

ListNode* mergeKListsDivide(vector<ListNode*>& lists) {
    return mergeRange(lists, 0, static_cast<int>(lists.size()) - 1);
}
```

复杂度同样是：

1. 时间复杂度：`O(N log k)`。
2. 空间复杂度：递归栈 `O(log k)`。

## 3. 易错点

1. 空链表数组、空链表头节点都要处理。
2. 最小堆比较器要写成 `a->val > b->val`，因为 `priority_queue` 默认是大根堆。
3. 复用原节点时，最后最好把 `tail->next = nullptr`，避免旧链表残留连接导致意外环或脏尾巴。
4. 逐个链表顺序合并最坏可能是 `O(kN)`，当 `k` 很大时不如堆或分治。
5. 如果输入链表节点不能被修改，需要新建节点，空间复杂度会变为 `O(N)`。

## 4. 面试回答模板

合并 K 个升序链表常用两种做法。第一种是最小堆，把每个链表头节点放进堆，每次取最小节点接到结果链表，再把它的下一个节点入堆，时间 `O(N log k)`、空间 `O(k)`。第二种是分治，两两合并链表，像归并排序一样把 `k` 条链表合并成一条，时间也是 `O(N log k)`，递归栈 `O(log k)`。如果面试现场写代码，最小堆版本边界更直接。
