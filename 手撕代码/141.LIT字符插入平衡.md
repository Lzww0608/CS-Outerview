# 141. LIT 字符插入平衡

## 题目

给定一个只包含 `L`、`I`、`T` 的字符串，长度为 `n`。一次操作可以选择一对相邻且不同的字符，在它们中间插入第三种字符。例如 `LI` 中间只能插入 `T`。要求在不超过 `2n` 次操作内，使最终字符串中 `L`、`I`、`T` 的数量相等，并输出每一步插入位置。

如果初始字符串所有字符都相同且三种字符数量不相等，则无法操作。

## 思路

最终长度如果取 `3n`，每种字符的目标数量就是 `n`，最多需要插入 `2n` 个字符，满足题目限制。

贪心策略：

1. 统计三种字符数量。
2. 每次优先选择当前数量最少且还没达到 `n` 的字符 `c`。
3. 在字符串中寻找一对相邻字符，它们不同且都不是 `c`，这样插入的第三种字符就是 `c`。
4. 如果找不到当前最少字符的插入位置，就尝试其他还未达到 `n` 的字符。
5. 每次插入都会让某一种未达标字符数量增加 1，最多执行 `2n` 次。

只要字符串中存在相邻不同字符，插入第三种字符后会产生新的相邻不同边界，后续可以继续制造需要的字符。

## C++ 代码

下面代码输出的是 1-based 插入位置：输出 `pos` 表示在原字符串当前状态的第 `pos` 个字符后面插入。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int id(char c) {
    if (c == 'L') return 0;
    if (c == 'I') return 1;
    return 2;
}

char ch(int x) {
    static const char table[3] = {'L', 'I', 'T'};
    return table[x];
}

char missing(char a, char b) {
    bool seen[3] = {false, false, false};
    seen[id(a)] = true;
    seen[id(b)] = true;
    for (int i = 0; i < 3; ++i) {
        if (!seen[i]) return ch(i);
    }
    return '?';
}

std::vector<int> solveLIT(std::string s) {
    int n = static_cast<int>(s.size());
    int cnt[3] = {0, 0, 0};
    for (char c : s) {
        ++cnt[id(c)];
    }

    if (cnt[0] == cnt[1] && cnt[1] == cnt[2]) {
        return {};
    }

    if (cnt[0] == n || cnt[1] == n || cnt[2] == n) {
        return {-1};
    }

    std::vector<int> ans;
    while (!(cnt[0] == n && cnt[1] == n && cnt[2] == n)) {
        std::vector<int> order = {0, 1, 2};
        std::sort(order.begin(), order.end(), [&](int a, int b) {
            return cnt[a] < cnt[b];
        });

        bool inserted = false;
        for (int want : order) {
            if (cnt[want] >= n) {
                continue;
            }
            for (int i = 0; i + 1 < static_cast<int>(s.size()); ++i) {
                if (s[i] == s[i + 1]) {
                    continue;
                }
                char add = missing(s[i], s[i + 1]);
                if (id(add) == want) {
                    s.insert(s.begin() + i + 1, add);
                    ++cnt[want];
                    ans.push_back(i + 1);
                    inserted = true;
                    break;
                }
            }
            if (inserted) {
                break;
            }
        }

        if (!inserted || static_cast<int>(ans.size()) > 2 * n) {
            return {-1};
        }
    }
    return ans;
}
```

## 示例

`LLITL` 中三种字符数量为：

```text
L = 3, I = 1, T = 1
```

目标是每种字符数量都达到 `5`。算法会优先补 `I` 和 `T`，每次选择相邻不同字符插入缺失字符，最多插入 `10` 次。

## 易错点

1. 插入位置会随着字符串变化而变化，输出的是“当前字符串”的位置，不是原始字符串位置。
2. 相邻相同字符之间不能插入。
3. 插入字符不是任意选择，而是相邻两个不同字符之外的第三种字符。
4. 初始字符串全相同且数量不相等时无法开始操作。
5. 目标数量选 `n` 可以天然保证操作次数不超过 `2n`。

## 复杂度

最多插入 `2n` 次，每次线性扫描当前字符串，当前长度不超过 `3n`，时间复杂度 `O(n^2)`，空间复杂度 `O(n)`。
