# 用栈实现队列

题目：只使用栈实现队列，支持 `push`、`pop`、`peek` 和 `empty`。

## 1. 双栈法

使用两个栈：

1. `in`：负责入队。
2. `out`：负责出队。

当 `out` 为空且需要出队时，把 `in` 中所有元素倒到 `out`。这样最早入队的元素会在 `out` 栈顶。

```cpp
#include <stack>
#include <stdexcept>
using namespace std;

class MyQueue {
public:
    void push(int x) {
        in_.push(x);
    }

    int pop() {
        moveIfNeeded();
        if (out_.empty()) {
            throw out_of_range("queue is empty");
        }
        int x = out_.top();
        out_.pop();
        return x;
    }

    int peek() {
        moveIfNeeded();
        if (out_.empty()) {
            throw out_of_range("queue is empty");
        }
        return out_.top();
    }

    bool empty() const {
        return in_.empty() && out_.empty();
    }

private:
    void moveIfNeeded() {
        if (!out_.empty()) {
            return;
        }
        while (!in_.empty()) {
            out_.push(in_.top());
            in_.pop();
        }
    }

    stack<int> in_;
    stack<int> out_;
};
```

## 2. 复杂度

1. `push`：`O(1)`。
2. `pop/peek`：均摊 `O(1)`，最坏 `O(n)`。
3. 空间复杂度：`O(n)`。

每个元素最多从 `in` 进入一次、从 `in` 移到 `out` 一次、从 `out` 弹出一次，所以均摊是 `O(1)`。

## 3. 易错点

1. 不要每次 `pop` 都把两个栈来回倒，这样会退化。
2. 只有 `out` 为空时才从 `in` 倒数据。
3. 空队列 `pop/peek` 要明确返回错误、抛异常或按题目约定处理。

## 4. 面试回答模板

用两个栈实现队列：入队只压入 `in`；出队时如果 `out` 非空就直接弹 `out`，如果 `out` 为空就把 `in` 全部倒入 `out`，再弹 `out`。这样每个元素最多搬移一次，`push` 是 `O(1)`，`pop` 和 `peek` 均摊 `O(1)`。
