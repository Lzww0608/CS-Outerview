# 83. 1到n构造二叉树

## 题目

给定整数 `n`，用 `1, 2, 3, ..., n` 构造一棵二叉树。

这类题面通常比较简略，面试时要先确认约束：是任意二叉树、完全二叉树，还是二叉搜索树。如果没有额外约束，能构造出的树有很多种。

## 情况一：构造完全二叉树

如果要求按层序放入 `1..n`，可以利用数组下标关系：

```text
节点 i 的左孩子: 2 * i + 1
节点 i 的右孩子: 2 * i + 2
```

其中 `i` 是从 0 开始的数组下标。

```cpp
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

TreeNode* buildComplete(int n) {
    if (n <= 0) {
        return nullptr;
    }

    vector<TreeNode*> nodes;
    nodes.reserve(n);

    for (int i = 1; i <= n; ++i) {
        nodes.push_back(new TreeNode(i));
    }

    for (int i = 0; i < n; ++i) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < n) {
            nodes[i]->left = nodes[left];
        }
        if (right < n) {
            nodes[i]->right = nodes[right];
        }
    }

    return nodes[0];
}
```

## 情况二：构造平衡二叉搜索树

如果面试官强调输入是有序序列，常见目标是构造高度尽量低的二叉搜索树。做法是每次取中点作为根：

1. 区间 `[l, r]` 的中点 `mid` 作为当前根。
2. `[l, mid - 1]` 递归构造左子树。
3. `[mid + 1, r]` 递归构造右子树。

```cpp
TreeNode* buildBalancedBST(int l, int r) {
    if (l > r) {
        return nullptr;
    }

    int mid = l + (r - l) / 2;
    TreeNode* root = new TreeNode(mid);
    root->left = buildBalancedBST(l, mid - 1);
    root->right = buildBalancedBST(mid + 1, r);
    return root;
}

TreeNode* buildBalancedBST(int n) {
    return buildBalancedBST(1, n);
}
```

## 复杂度

两种构造方式都会创建 `n` 个节点：

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

完全二叉树方案的额外数组是 `O(n)`；平衡 BST 方案如果不算返回的树节点，递归栈高度是 `O(log n)`。

## 易错点

1. 题目只说“构造二叉树”时，要先问清楚是否要求搜索树、平衡、完全或层序。
2. 用数组下标构造完全二叉树时，要注意 0 下标和 1 下标公式不同。
3. 构造平衡 BST 时，`mid` 建议写成 `l + (r - l) / 2`，避免 `l + r` 溢出。
4. C++ 面试中如果用 `new` 创建节点，要说明真实工程会用智能指针或统一释放逻辑管理内存。

## 面试回答模板

如果只是要求把 `1..n` 放进一棵二叉树，可以按层序构造完全二叉树，数组下标 `i` 的左右孩子是 `2i+1` 和 `2i+2`。如果要求由有序序列构造二叉搜索树，应该每次取中点作为根，递归构造左右区间，这样得到高度约为 `O(log n)` 的平衡 BST。题面不明确时先确认约束，否则答案不唯一。
