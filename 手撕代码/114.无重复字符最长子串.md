# 无重复字符最长子串

题目：给定一个字符串，求不包含重复字符的最长连续子串长度。对应 LeetCode 3。

## 1. 核心思路

使用滑动窗口维护一个没有重复字符的区间 `[left, right]`。

遍历 `right`：

1. 记录每个字符上一次出现的位置。
2. 如果当前字符 `s[right]` 上次出现位置在当前窗口内，说明出现重复，需要把 `left` 移到重复字符上次位置的下一位。
3. 更新当前字符位置。
4. 用 `right - left + 1` 更新答案。

关键点是 `left` 只能向右移动，不能回退。

## 2. C++ 实现

如果输入只按 ASCII 字符处理，可以用固定数组：

```cpp
#include <algorithm>
#include <string>
#include <vector>

int lengthOfLongestSubstring(const std::string& s) {
    std::vector<int> last(256, -1);
    int left = 0;
    int ans = 0;

    for (int right = 0; right < static_cast<int>(s.size()); ++right) {
        unsigned char ch = static_cast<unsigned char>(s[right]);
        if (last[ch] >= left) {
            left = last[ch] + 1;
        }
        last[ch] = right;
        ans = std::max(ans, right - left + 1);
    }
    return ans;
}
```

复杂度：

```text
时间复杂度 O(n)
空间复杂度 O(1)   // 字符集大小固定
```

如果需要支持完整 Unicode，不能直接按 `char` 字节处理，应该按 Unicode code point 或业务定义的字符单元遍历，并用哈希表记录位置。

## 3. 示例

```text
s = "abcabcbb"

right=0, a -> 窗口 "a", ans=1
right=1, b -> 窗口 "ab", ans=2
right=2, c -> 窗口 "abc", ans=3
right=3, a 重复，left 移到 1 -> 窗口 "bca", ans=3
```

最终答案为 `3`。

## 4. 易错点

1. 更新 `left` 时要取 `last[ch] + 1`，并且只在 `last[ch] >= left` 时更新。
2. `left` 不能回退，例如 `"abba"` 中第二个 `a` 的上次位置在窗口外，不应把 `left` 从 2 改回 1。
3. C++ 中 `char` 可能是有符号类型，作为数组下标时要转成 `unsigned char`。
4. 题目问的是“连续子串”，不是子序列，不能跳着选字符。
5. 如果面试输入包含中文、Emoji，要先说明字符编码边界。

## 5. 面试回答模板

这题用滑动窗口。窗口 `[left, right]` 始终保持无重复字符，用数组或哈希表记录每个字符上次出现的位置。遍历右端点时，如果当前字符上次出现位置在窗口内，就把 `left` 移到它上次位置的下一位；然后更新位置和答案。每个指针只向右移动一次，时间 `O(n)`，固定字符集下空间 `O(1)`。
