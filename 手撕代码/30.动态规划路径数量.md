# 动态规划路径数量

常见题目：机器人从 `m x n` 网格左上角走到右下角，每次只能向右或向下，问路径数量。

## 状态定义

`dp[i][j]` 表示从左上角走到 `(i, j)` 的路径数量。

状态转移：

```text
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
```

第一行和第一列只有一种走法。

## 二维 DP

```cpp
#include <vector>

long long uniquePaths(int m, int n) {
    std::vector<std::vector<long long>> dp(m, std::vector<long long>(n, 1));

    for (int i = 1; i < m; ++i) {
        for (int j = 1; j < n; ++j) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }

    return dp[m - 1][n - 1];
}
```

## 一维优化

因为当前行只依赖上一行和左侧，可以压缩为一维数组：

```cpp
#include <vector>

long long uniquePaths(int m, int n) {
    std::vector<long long> dp(n, 1);

    for (int i = 1; i < m; ++i) {
        for (int j = 1; j < n; ++j) {
            dp[j] += dp[j - 1];
        }
    }

    return dp[n - 1];
}
```

## 有障碍物的变形

如果 `grid[i][j] == 1` 表示障碍：

```cpp
#include <vector>

long long uniquePathsWithObstacles(const std::vector<std::vector<int>>& grid) {
    int m = static_cast<int>(grid.size());
    int n = static_cast<int>(grid[0].size());
    std::vector<long long> dp(n, 0);
    dp[0] = (grid[0][0] == 0) ? 1 : 0;

    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] == 1) {
                dp[j] = 0;
            } else if (j > 0) {
                dp[j] += dp[j - 1];
            }
        }
    }

    return dp[n - 1];
}
```

## 复杂度

1. 二维 DP：时间 `O(mn)`，空间 `O(mn)`。
2. 一维优化：时间 `O(mn)`，空间 `O(n)`。

## 易错点

1. 结果可能很大，面试中可用 `long long`，线上题要看是否需要取模。
2. 有障碍物时，障碍位置的路径数必须置 0。
3. 一维 DP 中 `dp[j]` 原值表示上方路径，`dp[j - 1]` 表示左方路径。

## 面试回答模板

路径数量用动态规划：`dp[i][j]` 表示到达 `(i,j)` 的路径数，只能从上方或左方来，所以 `dp[i][j]=dp[i-1][j]+dp[i][j-1]`，第一行和第一列初始化为 1。可以用一维数组优化空间，`dp[j] += dp[j-1]`。有障碍时障碍格置 0。时间复杂度 `O(mn)`。
