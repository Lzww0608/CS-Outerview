# 142. 滑动窗口最大值

## 题目

给定数组 `nums` 和窗口大小 `k`，窗口每次向右移动一格，返回每个窗口中的最大值。

示例：

```text
nums = [1,3,-1,-3,5,3,6,7], k = 3
输出 [3,3,5,5,6,7]
```

## 思路

使用单调递减双端队列，队列里保存下标：

1. 队首始终是当前窗口最大值的下标。
2. 新元素进来时，把队尾所有不大于它的元素下标弹出，因为这些元素以后不可能成为最大值。
3. 如果队首下标已经滑出窗口，也要弹出。

每个元素最多入队一次、出队一次，所以整体是 `O(n)`。

## C++ 代码

```cpp
#include <deque>
#include <vector>

std::vector<int> maxSlidingWindow(const std::vector<int>& nums, int k) {
    std::vector<int> ans;
    if (nums.empty() || k <= 0) {
        return ans;
    }

    std::deque<int> q;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!q.empty() && q.front() <= i - k) {
            q.pop_front();
        }

        while (!q.empty() && nums[q.back()] <= nums[i]) {
            q.pop_back();
        }

        q.push_back(i);

        if (i >= k - 1) {
            ans.push_back(nums[q.front()]);
        }
    }
    return ans;
}
```

## 为什么队列里存下标

只存值无法判断元素是否已经滑出窗口，尤其是有重复值时容易误删。存下标既能通过 `nums[index]` 比较大小，也能通过 `index <= i - k` 判断过期。

## 易错点

1. 窗口过期判断是 `q.front() <= i - k`。
2. 单调队列弹尾时用 `<` 或 `<=` 都能得到正确最大值；用 `<=` 可以保留更新的重复元素，下标更靠后，过期处理更简单。
3. `k == 1` 时输出原数组。
4. 输入为空或 `k <= 0` 要返回空结果。
5. 这是“单调队列”，不是优先队列；优先队列需要额外懒删除，复杂度通常是 `O(n log k)`。

## 真实场景

滑动窗口最大值常用于限流统计、监控窗口峰值、固定容量缓存最大值、时间序列窗口聚合。和队列实现 `getMax()` 的区别在于，滑动窗口按下标自然过期，而普通队列按入队顺序出队。
