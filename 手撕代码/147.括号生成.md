# 147. 括号生成

题目：给定 `n` 对括号，生成所有合法括号组合。对应 LeetCode 22。

## 1. 核心思路

使用回溯构造字符串。任何前缀都必须满足：

```text
已经使用的左括号数 >= 已经使用的右括号数
左括号数 <= n
右括号数 <= n
```

递归状态：

1. `left`：已经放入的左括号数量。
2. `right`：已经放入的右括号数量。
3. `path`：当前构造出的前缀。

转移：

1. 如果 `left < n`，可以继续放 `'('`。
2. 如果 `right < left`，可以放 `')'`。
3. 当 `path.size() == 2 * n` 时，得到一个合法结果。

## 2. C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> ans;
        string path;
        path.reserve(2 * n);
        dfs(n, 0, 0, path, ans);
        return ans;
    }

private:
    void dfs(int n, int left, int right,
             string& path, vector<string>& ans) {
        if (static_cast<int>(path.size()) == 2 * n) {
            ans.push_back(path);
            return;
        }

        if (left < n) {
            path.push_back('(');
            dfs(n, left + 1, right, path, ans);
            path.pop_back();
        }

        if (right < left) {
            path.push_back(')');
            dfs(n, left, right + 1, path, ans);
            path.pop_back();
        }
    }
};
```

## 3. 为什么这样不会生成非法结果

合法括号序列的任意前缀中，右括号数量不能超过左括号数量。否则在这个前缀处已经出现了无法匹配的右括号，后面再补左括号也无法修复。

所以剪枝条件 `right < left` 是关键。它保证每一步生成的前缀都是可能变成合法答案的前缀。

## 4. 复杂度

合法结果数量是第 `n` 个 Catalan 数：

```text
C_n = (1 / (n + 1)) * C(2n, n)
```

因此时间复杂度至少是输出规模：

```text
时间复杂度: O(C_n * n)
空间复杂度: O(n)  // 递归栈和 path，不算输出
```

## 5. 易错点

1. 不能先生成所有 `2n` 长度字符串再过滤，复杂度会变成 `O(2^(2n))`，浪费大量非法分支。
2. 右括号可用条件是 `right < left`，不是 `right < n`。
3. `path` 回溯后要 `pop_back()`，否则不同分支会互相污染。
4. `n = 0` 时按题意可能返回 `[""]` 或空数组，面试中要先确认。

## 6. 面试回答模板

括号生成用回溯。每一步可以放左括号或右括号，但左括号最多放 `n` 个，右括号只有在当前右括号数小于左括号数时才能放。这样保证任意前缀都合法，不会产生无法匹配的右括号。生成长度达到 `2n` 时加入答案。复杂度主要由 Catalan 数决定，时间是 `O(C_n * n)`。
