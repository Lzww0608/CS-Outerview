# 最大子数组和

题目：给定整数数组，求连续子数组的最大和。经典做法是 Kadane 算法，也可以用动态规划表述。

## 1. Kadane 算法

定义 `cur` 表示“以当前位置结尾的最大连续子数组和”，`best` 表示全局最大值。

状态转移：

```text
cur = max(nums[i], cur + nums[i])
best = max(best, cur)
```

如果前面的和 `cur` 已经为负，再接当前数只会拖累结果，不如从当前数重新开始。

```cpp
#include <stdexcept>
#include <vector>
using namespace std;

int maxSubArray(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    int cur = nums[0];
    int best = nums[0];

    for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
        cur = max(nums[i], cur + nums[i]);
        best = max(best, cur);
    }

    return best;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(1)`。

## 2. 返回区间

如果还要返回左右边界，可以在重新开始时记录候选起点：

```cpp
struct Result {
    int sum;
    int left;
    int right;
};

Result maxSubArrayRange(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    int cur = nums[0];
    int best = nums[0];
    int start = 0;
    int bestL = 0;
    int bestR = 0;

    for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
        if (cur + nums[i] < nums[i]) {
            cur = nums[i];
            start = i;
        } else {
            cur += nums[i];
        }

        if (cur > best) {
            best = cur;
            bestL = start;
            bestR = i;
        }
    }

    return {best, bestL, bestR};
}
```

## 3. 易错点

1. 全是负数时，答案是最大的那个负数，不能初始化为 0。
2. 题目如果允许空子数组，答案定义可能变成至少 0，要先问清楚。
3. 如果数组值和长度很大，和可能溢出 `int`，可改用 `long long`。

## 4. 面试回答模板

最大子数组和可以用动态规划：`cur` 表示以当前元素结尾的最大子数组和，转移是 `cur = max(nums[i], cur + nums[i])`，再用 `best` 维护全局最大值。遍历一次即可，时间 `O(n)`、空间 `O(1)`。注意全负数组不能把答案初始化为 0。
