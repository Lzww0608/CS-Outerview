# 89. 牛顿迭代求立方根

求一个数 `a` 的立方根，可以把问题转化为求方程：

```text
f(x) = x^3 - a = 0
```

牛顿迭代公式为：

```text
x_{k+1} = x_k - f(x_k) / f'(x_k)
        = x_k - (x_k^3 - a) / (3x_k^2)
        = (2x_k + a / x_k^2) / 3
```

## 代码

```cpp
#include <cmath>

double cubeRoot(double a) {
    if (a == 0.0) {
        return 0.0;
    }

    bool neg = a < 0;
    double target = neg ? -a : a;
    double x = target >= 1.0 ? target : 1.0;

    const double eps = 1e-12;
    for (int i = 0; i < 100; ++i) {
        double next = (2.0 * x + target / (x * x)) / 3.0;
        if (std::fabs(next - x) < eps) {
            x = next;
            break;
        }
        x = next;
    }
    return neg ? -x : x;
}
```

## 初值和终止条件

1. `a > 1` 时可以取 `x = a`，保证初值为正。
2. `0 < a < 1` 时取 `x = 1` 更稳定，避免初值过小导致除法放大误差。
3. 负数可以先对绝对值求立方根，最后加负号。
4. 终止条件可以是 `fabs(next - x) < eps`，也可以是 `fabs(x * x * x - a) < eps`。
5. 为避免极端情况下死循环，实际代码要限制最大迭代次数。

## 和二分法对比

| 方法 | 优点 | 缺点 |
| --- | --- | --- |
| 牛顿迭代 | 收敛快，通常迭代次数少 | 要推导公式，初值和除零要处理 |
| 二分法 | 稳定、容易证明正确 | 收敛慢，需要确定搜索区间 |

如果面试更重视鲁棒性，也可以用二分：

```text
a >= 1: 区间 [0, a]
0 < a < 1: 区间 [0, 1]
a < 0: 对 -a 求解后取负
```

## 易错点

1. 不能用整数除法。
2. `a = 0` 要单独处理，否则公式里会出现除以 `x * x` 的风险。
3. 小数和负数要考虑完整。
4. 输出保留几位要按题目要求，不要把误差精度和打印精度混在一起。

## 面试回答模板

立方根可以用牛顿迭代，把 `x^3 = a` 写成 `f(x)=x^3-a`，由 `x_next = x - f(x)/f'(x)` 得到 `(2x + a/x^2)/3`。负数先对绝对值求解再取负，`0` 单独返回。每轮迭代直到相邻两次结果差小于 `eps`，通常收敛很快。
