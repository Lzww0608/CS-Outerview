# 122. 分割数组的最大值

## 题目

给定非负整数数组 `nums` 和整数 `k`，把数组分成 `k` 个非空连续子数组，使这些子数组和的最大值最小。对应 LeetCode 410。

## 思路

答案具有单调性。假设最大子数组和不能超过 `limit`，贪心从左到右切分：

1. 当前段加上 `x` 不超过 `limit`，继续加入。
2. 否则新开一段。
3. 最终段数 `<= k`，说明 `limit` 可行。

二分最小可行 `limit`。

## 代码

```cpp
#include <algorithm>
#include <numeric>
#include <vector>
using namespace std;

bool canSplit(const vector<int>& nums, int k, long long limit) {
    int parts = 1;
    long long cur = 0;
    for (int x : nums) {
        if (cur + x <= limit) {
            cur += x;
        } else {
            ++parts;
            cur = x;
        }
    }
    return parts <= k;
}

int splitArray(vector<int>& nums, int k) {
    long long left = *max_element(nums.begin(), nums.end());
    long long right = accumulate(nums.begin(), nums.end(), 0LL);

    while (left < right) {
        long long mid = left + (right - left) / 2;
        if (canSplit(nums, k, mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return static_cast<int>(left);
}
```

## 易错点

1. 左边界是最大元素，不是 0。
2. 右边界是数组总和。
3. 数组和可能超过 `int`，用 `long long`。
4. 这题要求连续子数组，不能随意把元素分配到不同组。
