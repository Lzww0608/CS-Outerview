# 167. 简洁单链表增删反转

题目：用尽量简洁的代码实现一个单链表，支持添加、删除操作，并实现接口反转链表内容。

## 1. 核心思路

单链表节点只保存值和 `next` 指针。为了让删除头节点更统一，可以使用哨兵头节点 `dummy`：

1. 添加到头部：新节点指向原头节点，`dummy.next` 指向新节点。
2. 添加到尾部：维护 `tail` 指针可以做到 `O(1)`。
3. 删除指定值：从 `dummy` 开始找前驱节点，改前驱的 `next`。
4. 反转链表：用 `prev/cur/next` 三指针原地反转。

## 2. C++ 实现

```cpp
#include <iostream>
using namespace std;

class SinglyLinkedList {
private:
    struct Node {
        int value;
        Node* next;
        explicit Node(int v) : value(v), next(nullptr) {}
    };

    Node dummy_{0};
    Node* tail_ = &dummy_;

public:
    ~SinglyLinkedList() {
        clear();
    }

    void pushFront(int value) {
        Node* node = new Node(value);
        node->next = dummy_.next;
        dummy_.next = node;
        if (tail_ == &dummy_) {
            tail_ = node;
        }
    }

    void pushBack(int value) {
        Node* node = new Node(value);
        tail_->next = node;
        tail_ = node;
    }

    bool erase(int value) {
        Node* prev = &dummy_;
        while (prev->next != nullptr && prev->next->value != value) {
            prev = prev->next;
        }
        if (prev->next == nullptr) {
            return false;
        }

        Node* victim = prev->next;
        prev->next = victim->next;
        if (tail_ == victim) {
            tail_ = prev;
        }
        delete victim;
        return true;
    }

    void reverse() {
        Node* prev = nullptr;
        Node* cur = dummy_.next;
        tail_ = (cur == nullptr) ? &dummy_ : cur;

        while (cur != nullptr) {
            Node* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }

        dummy_.next = prev;
    }

    void clear() {
        Node* cur = dummy_.next;
        while (cur != nullptr) {
            Node* next = cur->next;
            delete cur;
            cur = next;
        }
        dummy_.next = nullptr;
        tail_ = &dummy_;
    }

    void print() const {
        for (Node* cur = dummy_.next; cur != nullptr; cur = cur->next) {
            cout << cur->value << ' ';
        }
        cout << '\n';
    }
};
```

## 3. 复杂度

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| `pushFront` | `O(1)` | 修改头部指针 |
| `pushBack` | `O(1)` | 依赖 `tail` 指针 |
| `erase` | `O(n)` | 单链表需要找前驱 |
| `reverse` | `O(n)` | 每个节点指针反转一次 |
| `clear` | `O(n)` | 释放所有节点 |

## 4. 易错点

1. 删除头节点时容易写特殊分支，哨兵节点可以统一处理。
2. 删除尾节点后要更新 `tail`，否则后续 `pushBack` 会访问野指针。
3. 反转前要保存 `next`，否则会丢失后续链表。
4. 反转后原头节点会变成尾节点，要更新 `tail`。
5. C++ 手写链表要释放内存，避免泄漏；真实项目优先用标准容器。

## 5. 面试回答模板

我会用哨兵头节点简化边界条件，并维护一个 `tail` 指针让尾插是 `O(1)`。删除时从哨兵节点开始找目标节点的前驱，修改前驱 `next` 并释放节点；如果删除的是尾节点，要把 `tail` 更新为前驱。反转用 `prev/cur/next` 三指针原地完成，每次保存后继、反转当前指针、再整体前进，时间 `O(n)`、额外空间 `O(1)`。
