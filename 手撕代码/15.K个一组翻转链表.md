# 15. K个一组翻转链表

## 题目

给定链表，每 `k` 个节点一组进行翻转。如果最后不足 `k` 个节点，则保持原顺序。

示例：

```text
1 -> 2 -> 3 -> 4 -> 5, k = 2
输出: 2 -> 1 -> 4 -> 3 -> 5
```

## 思路

使用 dummy 节点和迭代翻转。

每一轮：

1. 从 `groupPrev` 开始向后找第 `k` 个节点 `kth`。
2. 如果不足 `k` 个，结束。
3. 记录下一组开头 `groupNext = kth->next`。
4. 翻转 `[groupPrev->next, kth]` 这段链表。
5. 接回前后链表，移动 `groupPrev` 到本组翻转后的尾部。

## 代码

```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* getKth(ListNode* cur, int k) {
    while (cur != nullptr && k > 0) {
        cur = cur->next;
        --k;
    }
    return cur;
}

ListNode* reverseKGroup(ListNode* head, int k) {
    if (head == nullptr || k <= 1) {
        return head;
    }

    ListNode dummy(0);
    dummy.next = head;
    ListNode* groupPrev = &dummy;

    while (true) {
        ListNode* kth = getKth(groupPrev, k);
        if (kth == nullptr) {
            break;
        }

        ListNode* groupNext = kth->next;
        ListNode* prev = groupNext;
        ListNode* cur = groupPrev->next;

        while (cur != groupNext) {
            ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }

        ListNode* oldHead = groupPrev->next;
        groupPrev->next = kth;
        groupPrev = oldHead;
    }

    return dummy.next;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 易错点

1. 最后一组不足 `k` 个不能翻转。
2. 翻转前要保存 `groupNext`，否则容易断链。
3. 翻转后本组原头节点变成尾节点，下一轮的 `groupPrev` 应移动到它。
4. 使用 dummy 可以统一处理头节点被翻转的情况。
