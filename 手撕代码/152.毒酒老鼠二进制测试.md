# 152. 毒酒老鼠二进制测试

题目：1000 瓶酒中有 1 瓶有毒，老鼠喝到毒酒后会死亡。问最快找出毒酒编号至少需要多少只老鼠。

## 1. 一轮测试的二进制思路

如果只做一轮实验，每只老鼠最后只有两种状态：

```text
死 / 活
```

`m` 只老鼠可以表达 `2^m` 种状态组合。要区分 1000 瓶酒，需要：

```text
2^m >= 1000
```

因为：

```text
2^9 = 512
2^10 = 1024
```

所以至少需要 10 只老鼠。

## 2. 怎么设计实验

给每瓶酒编号 `0..999`，把编号写成 10 位二进制。第 `i` 只老鼠喝所有“第 `i` 位为 1”的酒。

实验结束后，把死亡老鼠对应的 bit 记为 1，存活老鼠对应的 bit 记为 0，得到的二进制数就是毒酒编号。

示例：毒酒编号是 13：

```text
13 = 0000001101
```

那么第 0、2、3 位对应的老鼠会死亡，组合出的编号就是 13。

## 3. 多轮测试扩展

如果题目允许在总时间内做多轮测试，每只老鼠不只有“死/活”两种信息，还可以通过“第几轮死亡”携带更多状态。

假设：

1. 毒发时间是 `t`。
2. 总测试时间允许做 `r` 轮。
3. 每只老鼠可能在第 1 到第 `r` 轮死亡，或者最后仍存活。

那么每只老鼠有 `r + 1` 种状态，`m` 只老鼠可以区分：

```text
(r + 1)^m
```

需要满足：

```text
(r + 1)^m >= 瓶数
```

一轮测试就是 `r = 1`，退化为 `2^m >= n`。

## 4. 易错点

1. 不是每瓶酒用一只老鼠，而是每只老鼠承载一个二进制位。
2. “最快”通常意味着只等一次毒发结果，所以是二进制状态。
3. 如果题目给了总时间和毒发时间，就要用多轮公式，而不是固定回答 10。
4. 编号可以从 0 开始，1000 瓶需要覆盖 0 到 999 共 1000 种状态。

## 5. 面试回答模板

最快一轮测完时，每只老鼠只有死和活两种状态，`m` 只老鼠能表达 `2^m` 种组合。要区分 1000 瓶，需要 `2^m >= 1000`，因为 `2^9=512`、`2^10=1024`，所以最少 10 只。做法是给瓶子按 10 位二进制编号，第 i 只老鼠喝所有第 i 位为 1 的酒，最后死亡老鼠组成的二进制编号就是毒酒编号。
