# 16. LRU缓存

## 题目

设计一个 LRU Cache，支持：

1. `get(key)`：如果 key 存在，返回 value，并把 key 标记为最近使用；否则返回 `-1`。
2. `put(key, value)`：写入 key-value。如果超过容量，淘汰最久未使用的 key。

要求 `get` 和 `put` 都是 O(1)。

## 思路

使用哈希表 + 双向链表：

1. 哈希表：`key -> 链表节点迭代器`，O(1) 定位节点。
2. 双向链表：头部是最近使用，尾部是最久未使用，O(1) 移动和删除。

访问或更新 key 时，把节点移动到链表头。容量超限时删除链表尾部节点。

## 代码

```cpp
#include <iostream>
#include <list>
#include <unordered_map>
#include <utility>
using namespace std;

class LRUCache {
public:
    explicit LRUCache(int capacity) : capacity_(capacity) {}

    int get(int key) {
        auto it = index_.find(key);
        if (it == index_.end()) {
            return -1;
        }

        cache_.splice(cache_.begin(), cache_, it->second);
        return it->second->second;
    }

    void put(int key, int value) {
        auto it = index_.find(key);
        if (it != index_.end()) {
            it->second->second = value;
            cache_.splice(cache_.begin(), cache_, it->second);
            return;
        }

        cache_.push_front({key, value});
        index_[key] = cache_.begin();

        if (static_cast<int>(cache_.size()) > capacity_) {
            auto last = cache_.end();
            --last;
            index_.erase(last->first);
            cache_.pop_back();
        }
    }

private:
    int capacity_;
    list<pair<int, int>> cache_;
    unordered_map<int, list<pair<int, int>>::iterator> index_;
};
```

## 不使用 std::list，自己写双向链表

如果面试明确要求“自己写双向链表”，可以用哨兵头尾节点降低边界处理复杂度：

```cpp
#include <unordered_map>
using namespace std;

class LRUCache {
private:
    struct Node {
        int key;
        int value;
        Node* prev;
        Node* next;

        Node(int k, int v) : key(k), value(v), prev(nullptr), next(nullptr) {}
    };

public:
    explicit LRUCache(int capacity) : capacity_(capacity) {
        head_ = new Node(0, 0);
        tail_ = new Node(0, 0);
        head_->next = tail_;
        tail_->prev = head_;
    }

    ~LRUCache() {
        Node* cur = head_;
        while (cur != nullptr) {
            Node* next = cur->next;
            delete cur;
            cur = next;
        }
    }

    LRUCache(const LRUCache&) = delete;
    LRUCache& operator=(const LRUCache&) = delete;

    int get(int key) {
        auto it = index_.find(key);
        if (it == index_.end()) {
            return -1;
        }
        moveToFront(it->second);
        return it->second->value;
    }

    void put(int key, int value) {
        if (capacity_ <= 0) {
            return;
        }

        auto it = index_.find(key);
        if (it != index_.end()) {
            it->second->value = value;
            moveToFront(it->second);
            return;
        }

        Node* node = new Node(key, value);
        index_[key] = node;
        addAfterHead(node);

        if (static_cast<int>(index_.size()) > capacity_) {
            Node* victim = tail_->prev;
            remove(victim);
            index_.erase(victim->key);
            delete victim;
        }
    }

private:
    void addAfterHead(Node* node) {
        node->prev = head_;
        node->next = head_->next;
        head_->next->prev = node;
        head_->next = node;
    }

    void remove(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }

    void moveToFront(Node* node) {
        remove(node);
        addAfterHead(node);
    }

private:
    int capacity_;
    Node* head_;
    Node* tail_;
    unordered_map<int, Node*> index_;
};
```

这个版本的关键点：

1. 哈希表保存 `key -> Node*`，保证 O(1) 定位节点。
2. 双向链表头部表示最近使用，尾部表示最久未使用。
3. 哨兵节点让插入、删除、淘汰不需要特判空链表和首尾节点。
4. 淘汰节点时必须先从链表摘除，再从哈希表删除，最后释放节点内存。

## 复杂度

```text
get: O(1)
put: O(1)
空间复杂度: O(capacity)
```

## 易错点

1. 更新已有 key 时，也要移动到链表头。
2. 淘汰尾节点时，要同步删除哈希表中的 key。
3. C++ `std::list::splice` 可以 O(1) 移动节点，不会使节点迭代器失效。
4. 多线程环境下，链表和哈希表的一致性需要加锁或分段锁保护。
5. 真实缓存可能还需要 TTL、按内存大小淘汰、淘汰回调和监控指标。
