# vector 实现队列

题目：用数组 `vector` 实现队列，并优化 `pop()` 的时间复杂度。

## 1. 直接 erase 的问题

最直观写法：

```cpp
vector<int> q;
q.push_back(x);
q.erase(q.begin());
```

`erase(q.begin())` 会把后面的所有元素整体前移，单次 `pop` 是 `O(n)`，大量出队会退化。

## 2. 头指针法

用一个 `head` 下标表示队头位置，出队时只移动 `head`，不移动元素。

```cpp
#include <stdexcept>
#include <vector>
using namespace std;

class VectorQueue {
public:
    void push(int x) {
        data_.push_back(x);
    }

    int pop() {
        if (empty()) {
            throw out_of_range("queue is empty");
        }
        int x = data_[head_++];
        compactIfNeeded();
        return x;
    }

    int front() const {
        if (empty()) {
            throw out_of_range("queue is empty");
        }
        return data_[head_];
    }

    bool empty() const {
        return head_ == data_.size();
    }

    size_t size() const {
        return data_.size() - head_;
    }

private:
    void compactIfNeeded() {
        if (head_ > 1024 && head_ * 2 >= data_.size()) {
            data_.erase(data_.begin(), data_.begin() + static_cast<long long>(head_));
            head_ = 0;
        }
    }

    vector<int> data_;
    size_t head_ = 0;
};
```

这里 `pop` 平时是 `O(1)`，偶尔压缩数组是 `O(n)`，均摊复杂度接近 `O(1)`。

## 3. 环形数组

更标准的数组队列是环形缓冲区，维护 `head`、`tail`、`size`：

```cpp
class CircularQueue {
public:
    explicit CircularQueue(size_t capacity) : data_(capacity) {}

    bool push(int x) {
        if (size_ == data_.size()) {
            return false;
        }
        data_[tail_] = x;
        tail_ = (tail_ + 1) % data_.size();
        ++size_;
        return true;
    }

    bool pop(int& x) {
        if (size_ == 0) {
            return false;
        }
        x = data_[head_];
        head_ = (head_ + 1) % data_.size();
        --size_;
        return true;
    }

private:
    vector<int> data_;
    size_t head_ = 0;
    size_t tail_ = 0;
    size_t size_ = 0;
};
```

固定容量场景下，环形数组入队出队都是 `O(1)`，非常适合生产者消费者队列、网络缓冲区和日志缓冲区。

## 4. 面试回答模板

`vector` 队列不能用 `erase(begin)` 做出队，因为每次都会搬移后续元素，复杂度是 `O(n)`。优化方式是维护队头下标 `head`，出队只做 `head++`，等前面废弃空间足够大时再批量压缩，均摊 `O(1)`。如果容量可以固定，更推荐环形数组，用 `head/tail/size` 取模移动，入队出队都是 `O(1)`。
