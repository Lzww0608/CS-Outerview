# 01 背包动态规划

题目：有 `n` 个物品，每个物品只能选 0 次或 1 次。第 `i` 个物品重量为 `w[i]`、价值为 `v[i]`，背包容量为 `cap`，求不超过容量时能获得的最大价值。

## 1. 状态定义

二维 DP：

```text
dp[i][j] = 只考虑前 i 个物品，容量不超过 j 时的最大价值
```

对第 `i` 个物品，有两种选择：

1. 不选：`dp[i][j] = dp[i - 1][j]`
2. 选：`dp[i][j] = dp[i - 1][j - w[i]] + v[i]`

状态转移：

```text
dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i])
```

前提是 `j >= w[i]`；否则只能不选。

## 2. 二维写法

```cpp
#include <algorithm>
#include <vector>
using namespace std;

int knapsack01(const vector<int>& weight, const vector<int>& value, int cap) {
    int n = static_cast<int>(weight.size());
    vector<vector<int>> dp(n + 1, vector<int>(cap + 1, 0));

    for (int i = 1; i <= n; ++i) {
        int w = weight[i - 1];
        int v = value[i - 1];
        for (int j = 0; j <= cap; ++j) {
            dp[i][j] = dp[i - 1][j];
            if (j >= w) {
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w] + v);
            }
        }
    }
    return dp[n][cap];
}
```

复杂度：

1. 时间复杂度：`O(n * cap)`。
2. 空间复杂度：`O(n * cap)`。

## 3. 一维滚动数组

因为第 `i` 层只依赖第 `i - 1` 层，可以压缩成一维：

```cpp
#include <algorithm>
#include <vector>
using namespace std;

int knapsack01Compressed(const vector<int>& weight, const vector<int>& value, int cap) {
    vector<int> dp(cap + 1, 0);

    for (int i = 0; i < static_cast<int>(weight.size()); ++i) {
        for (int j = cap; j >= weight[i]; --j) {
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }
    return dp[cap];
}
```

一维写法必须倒序枚举容量。原因是 01 背包每个物品只能用一次，倒序可以确保 `dp[j - weight[i]]` 仍然来自上一轮物品；如果正序枚举，同一个物品会在当前轮被重复使用，变成完全背包。

## 4. 恰好装满和方案恢复

如果题目要求“恰好装满”，初始化要变化：

```text
dp[0] = 0
dp[j] = -INF, j > 0
```

这样只有可达容量才会被转移出来。

如果要恢复选择了哪些物品，可以：

1. 使用二维 `dp`，从 `dp[n][cap]` 倒推：如果 `dp[i][j] == dp[i - 1][j]`，说明没选第 `i` 个；否则选了第 `i` 个并令 `j -= w[i]`。
2. 一维压缩时额外记录 `from[j]` 和 `choose[j]`，但实现更容易出错，面试手写优先二维恢复。

## 5. 变体对比

| 类型 | 每个物品可选次数 | 容量枚举方向 |
| --- | --- | --- |
| 01 背包 | 0 或 1 次 | 倒序 |
| 完全背包 | 无限次 | 正序 |
| 多重背包 | 有限次 | 可拆成多个 01 物品，或用单调队列优化 |

## 6. 易错点

1. 01 背包一维优化必须倒序遍历容量。
2. `weight` 和 `value` 下标要对应，二维 DP 常用 `i - 1` 访问第 `i` 个物品。
3. 普通“最多装这么多”初始化为 0；“恰好装满”不可达状态要初始化为负无穷。
4. 容量很大时 `O(n * cap)` 可能不可接受，需要考虑价值维 DP、分支限界或近似算法。
5. 如果价值总和小而容量大，可以定义 `dp[value] = 达到该价值的最小重量`，反向优化维度。

## 7. 真实场景

01 背包本质是资源受限下的子集选择，可类比：

1. 固定预算下选择收益最大的项目。
2. 固定内存容量下选择缓存哪些对象。
3. 固定时间窗口内选择执行哪些任务。
4. 区块链或交易系统中，在块容量、gas 或批处理大小限制下选择交易集合时，也会出现类似约束优化问题，但真实系统还会加入手续费、依赖关系和公平性约束。

## 8. 面试回答模板

01 背包定义 `dp[i][j]` 为前 `i` 个物品、容量 `j` 下的最大价值。第 `i` 个物品要么不选，继承 `dp[i-1][j]`；要么选，得到 `dp[i-1][j-w[i]] + v[i]`，二者取最大。时间复杂度 `O(n*cap)`。空间可以压缩成一维 `dp[j]`，但容量必须倒序枚举，防止同一个物品在当前轮被重复使用。如果题目要求恰好装满，需要把不可达状态初始化成负无穷。
