# 124. 链表交点

## 题目

给定两个单链表头节点，判断它们是否相交。如果相交，返回第一个相交节点。

链表相交指节点对象相同，不是节点值相同。

## 思路一：双指针

两个指针分别从 `headA`、`headB` 出发，走到末尾后切换到另一个链表头。若相交，两个指针会在交点相遇；若不相交，最终同时为 `nullptr`。

原因是两个指针都走了 `lenA + lenB` 的长度。

## 代码

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    ListNode* p = headA;
    ListNode* q = headB;
    while (p != q) {
        p = p ? p->next : headB;
        q = q ? q->next : headA;
    }
    return p;
}
```

## 思路二：长度差

先分别求两个链表长度，让长链表先走差值步，然后两个指针同步走，第一次相等就是交点。

## 易错点

1. 判断的是节点地址相同，不是 `val` 相同。
2. 如果链表可能有环，要先做环检测，带环相交问题需要分情况讨论。
3. 双指针写法不会死循环，不相交时两个指针最终都为 `nullptr`。
