# 字符串去空格

题目：给定一个字符串，删除其中所有空格字符，返回处理后的字符串。

## 1. 双指针原地压缩

如果字符串可修改，可以用读写双指针：

```cpp
#include <string>

std::string removeSpaces(std::string s) {
    size_t write = 0;
    for (size_t read = 0; read < s.size(); ++read) {
        if (s[read] != ' ') {
            s[write++] = s[read];
        }
    }
    s.resize(write);
    return s;
}
```

时间复杂度 `O(n)`，额外空间 `O(1)`（不考虑返回值拷贝）。这个写法会删除所有普通空格，不保留单词间隔。

## 2. 删除所有空白字符

如果题目里的“空格”泛指空白字符，包括 `\t`、`\n`、`\r`，可以使用 `std::isspace`：

```cpp
#include <cctype>
#include <string>

std::string removeWhitespaces(std::string s) {
    size_t write = 0;
    for (unsigned char ch : s) {
        if (!std::isspace(ch)) {
            s[write++] = static_cast<char>(ch);
        }
    }
    s.resize(write);
    return s;
}
```

注意要把 `char` 转成 `unsigned char` 再传给 `std::isspace`，否则负值字符可能导致未定义行为。

## 3. 易错点

1. 先确认是删除所有空格，还是压缩连续空格并保留单词间一个空格。
2. `erase` 每删一个字符都会移动后续字符，循环里频繁 `erase` 可能退化成 `O(n^2)`。
3. `std::remove` 只是把保留元素移动到前面，还需要配合 `erase`。
4. 如果输入是 UTF-8，普通 ASCII 空格和中文全角空格不是一回事，需要按编码处理。

## 4. STL 写法

```cpp
#include <algorithm>
#include <string>

std::string removeSpacesStl(std::string s) {
    s.erase(std::remove(s.begin(), s.end(), ' '), s.end());
    return s;
}
```

## 5. 面试回答模板

我会用读写双指针原地压缩。读指针遍历原字符串，遇到非空格就写到 `write` 位置并递增，最后把字符串 resize 到 `write`。这样每个字符只处理一次，时间 `O(n)`，额外空间 `O(1)`。如果要求删除所有空白字符，用 `std::isspace`，并注意参数转成 `unsigned char`。
