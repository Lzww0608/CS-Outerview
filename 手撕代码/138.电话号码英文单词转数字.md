# 138. 电话号码英文单词转数字

题目：给定一个由电话号码英文单词形式组成的字符串，例如 `onethreefive`，转换成数字形式 `135`。

如果输入保证由 `zero` 到 `nine` 的英文单词顺序拼接而成，可以用 Trie 或逐段匹配。Trie 更容易扩展，也能在非法输入时定位错误。

## 1. Trie 解析

十个数字单词之间没有前缀冲突，但用 Trie 仍然是通用做法。

```cpp
#include <array>
#include <stdexcept>
#include <string>
#include <vector>
using namespace std;

struct TrieNode {
    array<int, 26> next;
    int digit = -1;

    TrieNode() {
        next.fill(-1);
    }
};

class PhoneWordParser {
public:
    PhoneWordParser() {
        nodes_.push_back(TrieNode{});
        const vector<string> words = {
            "zero", "one", "two", "three", "four",
            "five", "six", "seven", "eight", "nine"
        };
        for (int d = 0; d < 10; ++d) {
            insert(words[d], d);
        }
    }

    string parse(const string& s) const {
        string ans;
        int i = 0;
        while (i < static_cast<int>(s.size())) {
            int cur = 0;
            int j = i;
            int matchedDigit = -1;
            int matchedEnd = -1;

            while (j < static_cast<int>(s.size())) {
                char ch = s[j];
                if (ch < 'a' || ch > 'z') {
                    break;
                }
                int idx = ch - 'a';
                int nxt = nodes_[cur].next[idx];
                if (nxt == -1) {
                    break;
                }
                cur = nxt;
                if (nodes_[cur].digit != -1) {
                    matchedDigit = nodes_[cur].digit;
                    matchedEnd = j + 1;
                }
                ++j;
            }

            if (matchedDigit == -1) {
                throw invalid_argument("invalid phone word");
            }
            ans.push_back(static_cast<char>('0' + matchedDigit));
            i = matchedEnd;
        }
        return ans;
    }

private:
    void insert(const string& word, int digit) {
        int cur = 0;
        for (char ch : word) {
            int idx = ch - 'a';
            if (nodes_[cur].next[idx] == -1) {
                nodes_[cur].next[idx] = static_cast<int>(nodes_.size());
                nodes_.push_back(TrieNode{});
            }
            cur = nodes_[cur].next[idx];
        }
        nodes_[cur].digit = digit;
    }

    vector<TrieNode> nodes_;
};
```

复杂度：

1. 建 Trie：十个固定单词，视为 `O(1)`。
2. 解析：每个字符最多走一次，`O(n)`。
3. 空间：固定词表，`O(1)`。

## 2. 简化做法

因为数字英文单词没有前缀关系，也可以从当前位置依次尝试十个单词是否匹配。代码更短，但每个位置最多尝试 10 次，常数仍然很小。

## 3. 易错点

1. 要明确是否允许大写、空格、短横线，例如 `"one-three-five"`。
2. 输入非法时不能死循环，必须报错或返回失败。
3. 如果扩展到任意词典，可能出现前缀冲突，此时要定义最长匹配、最短匹配或回溯策略。
4. 电话号码前导零不能丢，所以结果应保存为字符串，不应直接转整数。

## 4. 面试回答模板

我会把 `zero` 到 `nine` 建成 Trie，然后从输入串左到右扫描。每次从根节点开始沿字符走，走到某个数字单词结尾就得到一个数字，把扫描位置推进到这个结尾。这样每个字符处理一次，时间 `O(n)`。结果用字符串保存，因为电话号码可能有前导零。非法字符或无法匹配完整单词时返回错误。
