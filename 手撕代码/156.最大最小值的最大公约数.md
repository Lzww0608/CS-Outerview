# 156. 最大值和最小值的最大公约数

题目：给定一个整数数组，求数组中最大值和最小值的最大公约数。

## 1. 思路

题目不要求所有元素的最大公约数，只要求数组最大值和最小值的 `gcd`。

流程：

```text
遍历数组找到 minVal 和 maxVal
-> 使用欧几里得算法 gcd(maxVal, minVal)
```

欧几里得算法基于：

```text
gcd(a, b) = gcd(b, a % b)
```

直到 `b == 0`，此时 `a` 就是最大公约数。

## 2. 复杂度

1. 找最大最小值需要遍历一次数组，时间复杂度 `O(n)`。
2. `gcd` 的复杂度是 `O(log min(maxVal, minVal))`。
3. 额外空间复杂度 `O(1)`。

## 3. C++ 实现

```cpp
#include <algorithm>
#include <cstdlib>
#include <stdexcept>
#include <vector>

int gcd(int a, int b) {
    a = std::abs(a);
    b = std::abs(b);
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int gcdOfMinMax(const std::vector<int>& nums) {
    if (nums.empty()) {
        throw std::invalid_argument("empty array");
    }

    int minVal = nums[0];
    int maxVal = nums[0];
    for (int x : nums) {
        minVal = std::min(minVal, x);
        maxVal = std::max(maxVal, x);
    }

    return gcd(maxVal, minVal);
}
```

如果面试平台保证数组非空且元素为正数，可以去掉异常和 `abs`。

## 4. Java 实现

```java
class Solution {
    public int findGCD(int[] nums) {
        int minVal = nums[0];
        int maxVal = nums[0];
        for (int x : nums) {
            minVal = Math.min(minVal, x);
            maxVal = Math.max(maxVal, x);
        }
        return gcd(maxVal, minVal);
    }

    private int gcd(int a, int b) {
        a = Math.abs(a);
        b = Math.abs(b);
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
}
```

## 5. 易错点

1. 不要把题目误读成“整个数组所有元素的 gcd”。
2. 数组可能只有一个元素，此时最大值和最小值相同，答案是该元素的绝对值。
3. 如果允许负数，先取绝对值再做 gcd。
4. 如果允许 0，`gcd(a, 0) = |a|`；全为 0 时结果是 0。

## 6. 面试回答模板

这题先遍历一次数组找最大值和最小值，然后对这两个数跑欧几里得算法。欧几里得算法用 `gcd(a, b) = gcd(b, a % b)`，直到余数为 0。整体时间复杂度是 `O(n + logV)`，其中 `V` 是较小的那个值；额外空间 `O(1)`。要注意题目只要求最大值和最小值的 gcd，不是所有元素的 gcd。
