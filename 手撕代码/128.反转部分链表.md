# 128. 反转部分链表

题目：给定单链表头节点 `head`，以及位置 `left`、`right`，反转从第 `left` 个节点到第 `right` 个节点之间的链表，返回新的头节点。位置通常从 1 开始。

## 1. 核心思路

部分反转链表最稳的写法是使用哑节点 `dummy`，先找到待反转区间的前驱节点 `pre`，再用头插法把区间内节点逐个移动到区间头部。

示意：

```text
dummy -> 1 -> 2 -> 3 -> 4 -> 5
              ^         ^
            left      right
```

反转 `[2, 4]` 后：

```text
dummy -> 1 -> 4 -> 3 -> 2 -> 5
```

## 2. 代码实现

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* reverseBetween(ListNode* head, int left, int right) {
    if (head == nullptr || left >= right) {
        return head;
    }

    ListNode dummy(0);
    dummy.next = head;

    ListNode* pre = &dummy;
    for (int i = 1; i < left; ++i) {
        if (pre->next == nullptr) {
            return dummy.next;
        }
        pre = pre->next;
    }

    ListNode* cur = pre->next;
    if (cur == nullptr) {
        return dummy.next;
    }

    for (int i = 0; i < right - left; ++i) {
        ListNode* move = cur->next;
        if (move == nullptr) {
            break;
        }
        cur->next = move->next;
        move->next = pre->next;
        pre->next = move;
    }

    return dummy.next;
}
```

## 3. 指针变化解释

循环中保持两个关键指针：

1. `pre`：反转区间前一个节点，位置不变。
2. `cur`：反转区间原来的第一个节点，反转后会变成区间尾部。

每一轮把 `cur->next` 这个节点摘下来，插到 `pre->next` 前面：

```text
pre -> a -> b -> c
       ^
      cur

摘 b，插到 pre 后：

pre -> b -> a -> c
            ^
           cur
```

这样做不需要额外数组，也不需要真的把整个子链表断开。

## 4. 复杂度

1. 时间复杂度：`O(n)`，最坏需要走到 `right` 位置。
2. 空间复杂度：`O(1)`，只使用常数个指针。

## 5. 易错点

1. `left == 1` 时头节点会变化，所以建议使用 `dummy`。
2. 循环次数是 `right - left`，不是 `right - left + 1`。
3. 每次移动的是 `cur->next`，`cur` 自己不前进。
4. 要处理空链表、`left >= right`、`right` 超过链表长度等边界。
5. 如果面试官要求严格非法输入报错，应先扫描长度或在过程中返回错误状态。

## 6. 面试回答模板

反转部分链表我会用哑节点加头插法。先让 `pre` 指向反转区间前驱，`cur = pre->next` 指向区间第一个节点；然后执行 `right-left` 次，每次把 `cur->next` 摘下来插到 `pre->next` 前面。这样可以原地完成反转，时间 `O(n)`、空间 `O(1)`，并且 `left=1` 时也能通过 dummy 正确返回新头节点。
