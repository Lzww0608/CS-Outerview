# 168. cd 命令序列求最终路径

题目：输入一个字符串数组，每个元素是一条合法的 Linux `cd` 命令，输出执行完所有命令后 `pwd` 的结果。只关心最后路径，不关心中间过程。

假设初始目录是根目录 `/`。如果题目给了初始目录，也可以先把初始目录按路径规范化后放入栈。

## 1. 核心思路

把当前路径看成一个目录栈：

1. `cd /a/b`：绝对路径，从根目录重新开始。
2. `cd a/b`：相对路径，从当前目录继续追加。
3. `.`：当前目录，忽略。
4. `..`：返回上一级，栈非空时弹出一个目录。
5. 普通目录名：入栈。

每条 `cd` 命令本质都是对路径片段做一次规范化，最后把栈用 `/` 拼接即可。

## 2. C++ 实现

```cpp
#include <sstream>
#include <string>
#include <vector>
using namespace std;

class CdSimulator {
public:
    string run(const vector<string>& commands) {
        vector<string> dirs;

        for (const string& command : commands) {
            string path = parsePath(command);
            if (!path.empty() && path[0] == '/') {
                dirs.clear();
            }
            applyPath(path, dirs);
        }

        return buildPwd(dirs);
    }

private:
    string parsePath(const string& command) {
        const string prefix = "cd";
        size_t pos = command.find_first_not_of(' ', prefix.size());
        if (pos == string::npos) {
            return "";
        }
        return command.substr(pos);
    }

    void applyPath(const string& path, vector<string>& dirs) {
        stringstream ss(path);
        string part;

        while (getline(ss, part, '/')) {
            if (part.empty() || part == ".") {
                continue;
            }
            if (part == "..") {
                if (!dirs.empty()) {
                    dirs.pop_back();
                }
            } else {
                dirs.push_back(part);
            }
        }
    }

    string buildPwd(const vector<string>& dirs) {
        if (dirs.empty()) {
            return "/";
        }
        string ans;
        for (const string& dir : dirs) {
            ans += "/";
            ans += dir;
        }
        return ans;
    }
};
```

## 3. 示例

```text
输入:
["cd /home/user", "cd ../log", "cd ./app", "cd /tmp", "cd .."]

执行:
/home/user -> /home/log -> /home/log/app -> /tmp -> /

输出:
/
```

## 4. 复杂度

设所有命令字符串总长度为 `L`：

```text
时间复杂度: O(L)
空间复杂度: O(L)
```

空间主要来自目录栈，最坏情况下所有路径片段都保留。

## 5. 易错点

1. 绝对路径要先清空当前目录栈。
2. 根目录下执行 `cd ..` 仍然停留在 `/`。
3. 多个连续 `/` 要忽略空片段。
4. `...` 是普通目录名，不是 `..`。
5. 如果命令里可能有 `cd` 后多个空格，要先跳过空格再取路径。

## 6. 面试回答模板

我会用栈维护当前路径。每条 `cd` 命令取出路径参数，如果是绝对路径就清空栈；然后按 `/` 分割路径，空串和 `.` 忽略，遇到 `..` 就弹栈，普通目录名入栈。最后把栈里的目录按顺序用 `/` 拼起来，栈空就是根目录 `/`。整体按输入总长度线性处理。
