# 魔方矩阵

## 题目

给定 `n * n` 矩阵，调整或构造一个矩阵，使得每一行、每一列以及两条主对角线的和都相等。这类矩阵通常叫幻方或魔方矩阵。

面试时要先澄清输入：

1. 如果要求使用 `1..n^2` 构造标准幻方，奇数阶有经典 `O(n^2)` 解法。
2. 如果给定任意 `n * n` 数字并要求重新排列成幻方，需要先判断总和是否能被 `n` 整除，再做搜索或约束优化；一般不存在简单贪心。

## 奇数阶幻方

当 `n` 为奇数时，可以使用 Siamese method：

1. 从第一行中间位置放 `1`。
2. 下一个数默认放到“上一行、右一列”。
3. 如果越界则循环到另一侧。
4. 如果目标位置已经被占用，则改为放到当前位置的下一行。

## 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<vector<int>> magicSquareOdd(int n) {
    if (n <= 0 || n % 2 == 0) {
        return {};
    }

    vector<vector<int>> a(n, vector<int>(n, 0));

    int row = 0;
    int col = n / 2;

    for (int x = 1; x <= n * n; ++x) {
        a[row][col] = x;

        int nextRow = (row - 1 + n) % n;
        int nextCol = (col + 1) % n;

        if (a[nextRow][nextCol] != 0) {
            row = (row + 1) % n;
        } else {
            row = nextRow;
            col = nextCol;
        }
    }

    return a;
}

int main() {
    int n;
    cin >> n;

    vector<vector<int>> ans = magicSquareOdd(n);
    if (ans.empty()) {
        cout << "only odd n is supported" << endl;
        return 0;
    }

    for (const auto& row : ans) {
        for (int x : row) {
            cout << x << ' ';
        }
        cout << '\n';
    }
    return 0;
}
```

## 幻方和校验

标准 `1..n^2` 幻方的每行、每列、对角线目标和为：

```text
magic_sum = n * (n^2 + 1) / 2
```

因为所有数字总和是：

```text
1 + 2 + ... + n^2 = n^2 * (n^2 + 1) / 2
```

平均分到 `n` 行，所以得到上面的目标和。

## 任意数组重排

如果输入是任意 `n * n` 个数，问题要难很多。必要条件包括：

1. 总和必须能被 `n` 整除，目标行列和为 `sum / n`。
2. 最大元素不能大到无法放入任何目标和组合。
3. 对于小 `n` 可以回溯搜索，按行填充并剪枝。
4. 对于大 `n` 通常要转成约束满足问题，不适合用简单手撕算法承诺多项式解。

回溯剪枝思路：

1. 先排序，把大数优先放置，减少搜索分支。
2. 填每一行时维护行和、列和、两条对角线和。
3. 当前行超过目标和、当前列超过目标和直接剪枝。
4. 最后一行、最后一列和对角线必须精确等于目标和。

## 易错点

1. 奇数阶、双偶数阶、单偶数阶幻方构造方法不同，不能用一个简单公式覆盖所有 `n`。
2. 标准幻方构造和任意数组重排不是同一个难度的问题。
3. 题目如果只要求“调整给定矩阵”，必须确认是否允许改变数字、是否必须使用所有原数字。
4. 判断结果时要同时检查所有行、列和两条对角线。
