# 91. 二叉树路径长度、LCA 与直径

这类题经常把“两个节点之间的路径长度”“最近公共祖先 LCA”和“二叉树直径”放在一起问。核心是区分：给定两个节点求距离，用 LCA；整棵树任意两点最大距离，用直径 DFS。

## 1. 两个给定节点的路径长度

如果已知两个节点 `a`、`b`，它们之间的边数距离为：

```text
dist(a, b) = depth[a] + depth[b] - 2 * depth[lca(a, b)]
```

原因是从 `a` 向上走到 LCA，再从 LCA 向下走到 `b`。

普通二叉树可以递归求 LCA：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* a, TreeNode* b) {
    if (root == nullptr || root == a || root == b) {
        return root;
    }
    TreeNode* left = lowestCommonAncestor(root->left, a, b);
    TreeNode* right = lowestCommonAncestor(root->right, a, b);
    if (left != nullptr && right != nullptr) {
        return root;
    }
    return left != nullptr ? left : right;
}
```

再 DFS 一次记录深度，就能得到两个点的路径长度。

## 1.1 只遍历一遍树求两个节点距离

如果题目要求“只遍历一遍树”，可以在一次后序 DFS 中同时返回当前子树是否找到 `a`、是否找到 `b`、以及两个目标点到当前节点的距离。当某个节点的左右子树或自身同时覆盖了两个目标点时，这个节点就是 LCA，答案也能在这一层算出。

```cpp
struct Info {
    bool hasA = false;
    bool hasB = false;
    int distA = -1;
    int distB = -1;
};

Info dfsDistance(TreeNode* root, TreeNode* a, TreeNode* b, int& ans) {
    if (root == nullptr) {
        return {};
    }

    Info left = dfsDistance(root->left, a, b, ans);
    Info right = dfsDistance(root->right, a, b, ans);

    Info cur;
    cur.hasA = left.hasA || right.hasA || root == a;
    cur.hasB = left.hasB || right.hasB || root == b;

    if (root == a) {
        cur.distA = 0;
    } else if (left.distA != -1) {
        cur.distA = left.distA + 1;
    } else if (right.distA != -1) {
        cur.distA = right.distA + 1;
    }

    if (root == b) {
        cur.distB = 0;
    } else if (left.distB != -1) {
        cur.distB = left.distB + 1;
    } else if (right.distB != -1) {
        cur.distB = right.distB + 1;
    }

    if (ans == -1 && cur.hasA && cur.hasB) {
        ans = cur.distA + cur.distB;
    }
    return cur;
}

int distanceInOneTraversal(TreeNode* root, TreeNode* a, TreeNode* b) {
    int ans = -1;
    Info info = dfsDistance(root, a, b, ans);
    return info.hasA && info.hasB ? ans : -1;
}
```

这个写法的关键是：每个节点只访问一次，返回值携带足够信息；如果输入节点可能不存在，最终要检查 `hasA && hasB`，否则不能返回伪答案。

## 2. 二叉树直径

直径是整棵树中任意两个节点之间的最大路径长度。它不一定经过根节点，但一定经过某个“拐点”节点：

```text
某个节点左子树最深路径 + 该节点 + 右子树最深路径
```

后序 DFS 一边返回高度，一边更新答案：

```cpp
#include <algorithm>
using namespace std;

int height(TreeNode* root, int& diameter) {
    if (root == nullptr) {
        return 0;
    }
    int left = height(root->left, diameter);
    int right = height(root->right, diameter);
    diameter = max(diameter, left + right);
    return max(left, right) + 1;
}

int diameterOfBinaryTree(TreeNode* root) {
    int ans = 0;
    height(root, ans);
    return ans;
}
```

这里 `ans` 按边数计算。如果题目要求按节点数计算，非空树答案通常是边数直径加 1。

## 3. 结合题：直径端点和 LCA

如果题目要求“找出直径路径，并说明它和 LCA 的关系”，可以在 DFS 中额外记录每棵子树的最深叶子。经过某个节点的候选直径端点就是左侧最深叶子和右侧最深叶子；当它刷新全局答案时，记录这两个端点。

记录到直径端点 `u`、`v` 后：

1. `lca(u, v)` 就是这条直径路径上的最高拐点。
2. 直径长度可以再次用 `depth[u] + depth[v] - 2 * depth[lca]` 校验。
3. 如果需要输出路径，可以从 `u` 到 LCA、从 LCA 到 `v` 分别回溯父指针后拼接。

简化版结构：

```cpp
struct Info {
    int height;
    TreeNode* deepest;
};

Info dfs(TreeNode* root, int& best, TreeNode*& end1, TreeNode*& end2) {
    if (root == nullptr) {
        return {0, nullptr};
    }
    Info left = dfs(root->left, best, end1, end2);
    Info right = dfs(root->right, best, end1, end2);

    int candidate = left.height + right.height;
    if (candidate > best) {
        best = candidate;
        end1 = left.deepest != nullptr ? left.deepest : root;
        end2 = right.deepest != nullptr ? right.deepest : root;
    }

    if (left.height >= right.height) {
        return {left.height + 1, left.deepest != nullptr ? left.deepest : root};
    }
    return {right.height + 1, right.deepest != nullptr ? right.deepest : root};
}
```

## 4. 多次查询如何优化

如果树固定、要频繁查询任意两个节点距离，可以预处理：

1. DFS 记录 `depth` 和父节点。
2. 用倍增表 `up[node][k]` 支持 `O(log n)` 求 LCA。
3. 每次查询用距离公式 `depth[a] + depth[b] - 2 * depth[lca]`。

如果只是求一次直径，不需要 LCA 预处理，一次后序 DFS 就够。

## 5. 易错点

1. 直径不一定经过根节点。
2. LCA 解决的是给定两个节点的路径，直径解决的是全局最大路径。
3. 路径长度要确认按边数还是节点数。
4. 普通二叉树 LCA 不能用 BST 的大小关系。
5. 如果输入节点可能不存在，LCA 递归要同时返回找到数量，避免只找到一个节点也误判。

## 6. 面试回答模板

两个指定节点的距离用 LCA：先求深度和最近公共祖先，距离等于 `depth[a] + depth[b] - 2 * depth[lca]`。整棵树的最大路径是直径，用后序 DFS，返回当前节点向下高度，同时用 `left_height + right_height` 更新全局最大值。如果要结合两者，可以在求直径时记录直径两端点，再用 LCA 校验或输出路径。
