# 104. 打家劫舍

## 题目

给定一个非负整数数组 `nums`，每个元素表示一间房子的金额。相邻房子不能同时偷，求最多能偷到多少钱。

## 思路

这是典型动态规划。对第 `i` 间房，有两个选择：

1. 不偷第 `i` 间：收益是 `dp[i - 1]`。
2. 偷第 `i` 间：第 `i - 1` 间不能偷，收益是 `dp[i - 2] + nums[i]`。

状态转移：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

由于每次只依赖前两个状态，可以把空间优化到 `O(1)`。

## 代码

```cpp
#include <algorithm>
#include <vector>
using namespace std;

int rob(vector<int>& nums) {
    int prev2 = 0; // dp[i - 2]
    int prev1 = 0; // dp[i - 1]

    for (int x : nums) {
        int cur = max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }

    return prev1;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 易错点

1. 空数组答案是 `0`。
2. 不要贪心选择局部较大的房子，例如 `[2, 1, 1, 2]` 最优是 `4`。
3. `prev2` 和 `prev1` 更新顺序不能写反。
4. 如果题目变成首尾相邻的环形房屋，要拆成 `[0, n-2]` 和 `[1, n-1]` 两段分别求最大值。

## 面试回答模板

这题用动态规划。设 `dp[i]` 表示考虑到第 `i` 间房时的最大收益，第 `i` 间偷或不偷两种情况：不偷就是 `dp[i-1]`，偷就是 `dp[i-2] + nums[i]`，取最大值。因为只依赖前两个状态，所以用两个变量滚动更新即可，时间 `O(n)`，空间 `O(1)`。
