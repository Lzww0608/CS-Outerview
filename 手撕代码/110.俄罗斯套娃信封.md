# 俄罗斯套娃信封

题目：给定若干信封 `(w, h)`，一个信封能套进另一个信封，当且仅当宽和高都严格更小。求最多能套多少个。

## 1. 思路

先排序，再转成最长上升子序列问题：

1. 按宽度升序排序。
2. 宽度相同时按高度降序排序。
3. 在排序后的高度序列上求严格递增 LIS。

为什么同宽要按高度降序：同宽信封不能互相嵌套。如果同宽按高度升序，会在 LIS 中错误选择多个同宽信封；降序后同宽高度不会形成递增序列。

## 2. C++ 实现

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        sort(envelopes.begin(), envelopes.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a[0] != b[0]) {
                     return a[0] < b[0];
                 }
                 return a[1] > b[1];
             });

        vector<int> tails;
        for (const auto& e : envelopes) {
            int h = e[1];
            auto it = lower_bound(tails.begin(), tails.end(), h);
            if (it == tails.end()) {
                tails.push_back(h);
            } else {
                *it = h;
            }
        }
        return static_cast<int>(tails.size());
    }
};
```

## 3. 复杂度

1. 排序：`O(n log n)`。
2. LIS：每个高度二分一次，`O(n log n)`。
3. 额外空间：`O(n)`。

## 4. 易错点

1. 条件是宽高都严格小于，不能有任意一维相等。
2. 同宽必须按高度降序，否则会把不可嵌套的信封算进 LIS。
3. LIS 用 `lower_bound` 求严格递增；如果题目改成非下降，才考虑 `upper_bound`。
4. `tails[i]` 表示长度为 `i + 1` 的递增子序列的最小结尾，不一定是一条真实路径。
