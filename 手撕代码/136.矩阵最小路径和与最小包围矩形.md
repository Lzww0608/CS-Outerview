# 136. 矩阵最小路径和与最小包围矩形

微软面经里有两个矩阵题：

1. 给定 `m*n` 矩阵，求从左上角到右下角的最小值，常见理解是最小路径和。
2. 输入 `n*m` 的 0/1 矩阵，返回包含所有 `1` 的最小子矩阵。

## 1. 最小路径和

如果只能向右或向下走，定义 `dp[i][j]` 为走到 `(i, j)` 的最小路径和：

```text
dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1])
```

可以用一维数组压缩空间。

```cpp
#include <algorithm>
#include <limits>
#include <stdexcept>
#include <vector>
using namespace std;

int minPathSum(const vector<vector<int>>& grid) {
    if (grid.empty() || grid[0].empty()) {
        throw invalid_argument("empty grid");
    }

    int m = static_cast<int>(grid.size());
    int n = static_cast<int>(grid[0].size());
    vector<int> dp(n, numeric_limits<int>::max());
    dp[0] = 0;

    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (j == 0) {
                dp[j] = dp[j] + grid[i][j];
            } else {
                dp[j] = min(dp[j], dp[j - 1]) + grid[i][j];
            }
        }
    }
    return dp[n - 1];
}
```

复杂度：时间 `O(mn)`，空间 `O(n)`。

## 2. 包含所有 1 的最小子矩阵

只需要扫描所有元素，记录所有 `1` 的最小行、最大行、最小列、最大列。

```cpp
#include <algorithm>
#include <array>
#include <vector>
using namespace std;

// 返回 {top, left, bottom, right}，如果没有 1 返回 {-1, -1, -1, -1}
array<int, 4> minRectCoverOnes(const vector<vector<int>>& grid) {
    int m = static_cast<int>(grid.size());
    int n = m == 0 ? 0 : static_cast<int>(grid[0].size());

    int top = m;
    int left = n;
    int bottom = -1;
    int right = -1;

    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] == 1) {
                top = min(top, i);
                left = min(left, j);
                bottom = max(bottom, i);
                right = max(right, j);
            }
        }
    }

    if (bottom == -1) {
        return {-1, -1, -1, -1};
    }
    return {top, left, bottom, right};
}
```

面积为：

```text
(bottom - top + 1) * (right - left + 1)
```

## 3. 易错点

1. 最小路径和要确认可走方向，若允许上下左右且权重非负，问题会变成最短路。
2. 一维 DP 更新顺序必须从左到右，因为 `dp[j]` 表示上方，`dp[j-1]` 表示左方。
3. 最小包围矩形不是找全 1 子矩形，而是找能覆盖所有 1 的边界框。
4. 矩阵没有任何 `1` 时要定义返回值。

## 4. 面试回答模板

最小路径和如果限制只能向右和向下走，就用动态规划，`dp[i][j]` 等于当前位置值加上上方和左方的较小值，空间可以压缩到一行。包含所有 `1` 的最小子矩阵更简单，扫描矩阵记录所有 `1` 的最小行、最大行、最小列、最大列即可，最后这四个边界确定唯一的最小覆盖矩形。
