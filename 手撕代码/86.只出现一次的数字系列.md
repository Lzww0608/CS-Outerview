# 86. 只出现一次的数字系列

这类题考察位运算。核心是按位异或和按位计数的性质。

## 两个数字只出现一次，其他都出现两次

题目：数组中只有两个数出现一次，其他数都出现两次，找出这两个数。

思路：

1. 所有数异或，成对出现的数会抵消，结果为 `a ^ b`。
2. 因为 `a != b`，`a ^ b` 至少有一位是 1。
3. 取最低位的 1：`lowbit = xor_all & -xor_all`。
4. 用这一位把数组分成两组，`a` 和 `b` 一定被分到不同组。
5. 每组内部再异或，分别得到两个只出现一次的数。

```cpp
#include <vector>
using namespace std;

vector<int> singleNumberTwo(vector<int>& nums) {
    int x = 0;
    for (int v : nums) {
        x ^= v;
    }

    int lowbit = x & -x;
    int a = 0, b = 0;
    for (int v : nums) {
        if (v & lowbit) {
            a ^= v;
        } else {
            b ^= v;
        }
    }
    return {a, b};
}
```

复杂度：时间 `O(n)`，额外空间 `O(1)`。

## 一个数字出现一次，其他都出现三次

题目：数组中只有一个数出现一次，其他数都出现三次，找出这个数。

思路：

1. 对每个二进制位统计 1 的个数。
2. 出现三次的数字在每一位上的贡献都是 3 的倍数。
3. 每一位计数对 3 取模后，剩下的就是只出现一次的数字在该位上的值。

```cpp
#include <cstdint>
#include <vector>
using namespace std;

int singleNumberThree(vector<int>& nums) {
    int32_t ans = 0;
    for (int i = 0; i < 32; ++i) {
        int cnt = 0;
        for (int v : nums) {
            cnt += (static_cast<uint32_t>(v) >> i) & 1U;
        }
        if (cnt % 3 != 0) {
            ans |= static_cast<int32_t>(1U << i);
        }
    }
    return ans;
}
```

这里使用 `uint32_t` 做右移，避免负数右移的实现差异影响判断；最后按补码位模式还原成 `int32_t`。

## 易错点

1. 两个只出现一次的题，不能直接返回总异或值，因为总异或是 `a ^ b`。
2. `lowbit` 的作用是找到 `a` 和 `b` 不同的一位，不是找较小的数。
3. 三次题要考虑负数，按 32 位补码统计更稳妥。
4. 如果题目是“其他出现 k 次，一个出现 m 次”，可以把每一位计数对 k 取模，再判断是否等于 m。

## 面试回答模板

两个数只出现一次时，先异或所有元素得到 `a ^ b`，再用其中任意一个为 1 的 bit 把数组分成两组，两组分别异或得到答案。一个数出现一次、其他出现三次时，对 32 个 bit 分别计数，计数对 3 取模后重建答案。两种方法都是 `O(n)` 时间、`O(1)` 空间。
