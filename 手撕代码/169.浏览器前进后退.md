# 169. 浏览器前进后退

题目：实现浏览器的前进、后退功能。支持访问新页面、后退若干步、前进若干步，返回当前页面。

## 1. 核心思路

用两个栈维护历史：

1. `backStack`：当前页面之前的历史页面。
2. `forwardStack`：后退后可以前进回去的页面。
3. `current`：当前页面。

操作规则：

1. 访问新页面：当前页面压入 `backStack`，清空 `forwardStack`，新页面变成当前页。
2. 后退：当前页面压入 `forwardStack`，从 `backStack` 弹出作为当前页。
3. 前进：当前页面压入 `backStack`，从 `forwardStack` 弹出作为当前页。

访问新页面必须清空前进栈，因为浏览器历史分支被新的访问路径覆盖。

## 2. C++ 实现

```cpp
#include <string>
#include <utility>
#include <vector>
using namespace std;

class BrowserHistory {
public:
    explicit BrowserHistory(string homepage) : current_(std::move(homepage)) {}

    void visit(const string& url) {
        back_.push_back(current_);
        current_ = url;
        forward_.clear();
    }

    string back(int steps) {
        while (steps-- > 0 && !back_.empty()) {
            forward_.push_back(current_);
            current_ = back_.back();
            back_.pop_back();
        }
        return current_;
    }

    string forward(int steps) {
        while (steps-- > 0 && !forward_.empty()) {
            back_.push_back(current_);
            current_ = forward_.back();
            forward_.pop_back();
        }
        return current_;
    }

    string current() const {
        return current_;
    }

private:
    string current_;
    vector<string> back_;
    vector<string> forward_;
};
```

## 3. 示例

```text
init: a.com
visit b.com    current = b.com, back = [a], forward = []
visit c.com    current = c.com, back = [a,b], forward = []
back 1         current = b.com, back = [a], forward = [c]
visit d.com    current = d.com, back = [a,b], forward = []
```

最后一步访问 `d.com` 后，`c.com` 不再能通过前进到达。

## 4. 复杂度

```text
visit: O(1)
back(k): O(k)
forward(k): O(k)
空间复杂度: O(n)
```

如果只支持一步前进/后退，每次操作都是 `O(1)`。

## 5. 可扩展点

真实浏览器历史比双栈更复杂：

1. 需要限制历史容量，超过容量淘汰最老记录。
2. 同一个 tab 有自己的历史栈，多 tab 之间互不影响。
3. 刷新页面不应该新增历史记录。
4. `replaceState` 会替换当前历史项，不产生新记录。
5. 历史项还可能包含标题、滚动位置、表单状态、页面状态快照。

## 6. 易错点

1. `visit` 新页面时必须清空前进栈。
2. 后退步数超过历史长度时，只退到最早页面。
3. 前进一步数超过可前进长度时，只前进到最后一个可达页面。
4. 当前页不要同时放在两个栈里，否则容易重复。

## 7. 面试回答模板

浏览器前进后退用两个栈。后退栈保存当前页之前的页面，前进栈保存后退后可恢复的页面，当前页单独保存。访问新页面时把当前页压入后退栈，并清空前进栈；后退时当前页进前进栈，后退栈栈顶变当前页；前进则相反。这个模型也适用于撤销/重做，只是浏览器的状态对象可以扩展为 URL、标题、滚动位置和页面状态。
