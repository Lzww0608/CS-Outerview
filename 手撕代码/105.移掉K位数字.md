# 105. 移掉 K 位数字

## 题目

给定一个非负整数字符串 `num` 和整数 `k`，移掉 `k` 位数字，使剩下的数字最小。返回结果字符串，不能有多余前导零；如果结果为空，返回 `"0"`。

## 思路

要让最终数字尽量小，高位越小越重要。遍历数字时，如果当前数字比栈顶小，说明删除栈顶这个更大的高位能让结果更小。

使用单调递增栈：

1. 从左到右遍历每个字符 `c`。
2. 当栈非空、`k > 0` 且栈顶大于 `c` 时，弹出栈顶并 `k--`。
3. 把 `c` 入栈。
4. 如果遍历结束后 `k` 还没用完，说明数字整体递增，从尾部继续删。
5. 去掉前导零，空串返回 `"0"`。

## 代码

```cpp
#include <string>
using namespace std;

string removeKdigits(string num, int k) {
    string st;

    for (char c : num) {
        while (!st.empty() && k > 0 && st.back() > c) {
            st.pop_back();
            --k;
        }
        st.push_back(c);
    }

    while (k > 0 && !st.empty()) {
        st.pop_back();
        --k;
    }

    int pos = 0;
    while (pos < static_cast<int>(st.size()) && st[pos] == '0') {
        ++pos;
    }

    string ans = st.substr(pos);
    return ans.empty() ? "0" : ans;
}
```

## 为什么是单调栈

如果存在相邻高位 `a > b`，删除 `a` 一定比删除后面的 `b` 更优，因为高位权重更大。单调递增栈正是在维护“前面的数字尽量小”。当新数字更小，就尽可能删除前面更大的数字。

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

每个字符最多入栈一次、出栈一次。

## 易错点

1. 遍历结束后 `k` 可能没用完，例如 `12345, k=2`，要从尾部删。
2. 结果要去前导零，例如 `10200, k=1` 得到 `200`。
3. 如果全部删光或只剩零，返回 `"0"`。
4. 不要把字符串先转整数，长度可能很大，也会丢前导零信息。

## 面试回答模板

这题用单调递增栈。因为高位对数字大小影响最大，如果当前数字比前一个高位更小，就应该优先删除前面那个更大的数字。遍历字符串时维护递增栈，栈顶大于当前字符且还可以删除就弹栈；遍历结束后如果 `k` 没用完，从尾部删。最后去掉前导零，空串返回 `"0"`。每个字符最多进出栈一次，所以时间 `O(n)`。
