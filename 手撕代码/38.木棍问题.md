# 木棍问题

“木棍问题”在面试中常见题意有两类：一类是把若干小木棍拼成若干根等长木棍，求原始木棍的最小可能长度；另一类是判断火柴能否拼成正方形。它们本质都是回溯搜索 + 剪枝。

## 变体一：拼回等长木棍

题意：给定若干小木棍长度，它们来自若干根长度相同的原始木棍。要求求出原始木棍长度的最小可能值。

核心思路：

1. 原始长度 `target` 必须整除总长度 `sum`。
2. `target` 至少大于等于最长小木棍。
3. 从小到大枚举 `target`。
4. 对每个 `target` 用 DFS 尝试把所有小木棍分成 `sum / target` 组，每组和为 `target`。
5. 长木棍优先排序，能更快触发剪枝。

## 剪枝要点

1. **降序排序**：先放长木棍，失败更早暴露。
2. **同层去重**：同一层尝试过相同长度失败后，跳过后续相同长度。
3. **空桶失败剪枝**：如果某根木棍放进空桶失败，没必要换另一个空桶。
4. **刚好填满失败剪枝**：如果放入后刚好等于 `target` 但后续失败，换同层其他选择通常也无意义。
5. **从上次位置继续搜索**：减少排列重复。

## 代码：能否分成等长组

```cpp
#include <algorithm>
#include <functional>
#include <numeric>
#include <vector>

class StickSolver {
public:
    bool canMake(std::vector<int> sticks, int target) {
        int sum = std::accumulate(sticks.begin(), sticks.end(), 0);
        if (target <= 0 || sum % target != 0) {
            return false;
        }
        std::sort(sticks.begin(), sticks.end(), std::greater<int>());
        if (!sticks.empty() && sticks[0] > target) {
            return false;
        }

        sticks_ = std::move(sticks);
        used_.assign(sticks_.size(), false);
        target_ = target;
        group_count_ = sum / target;
        return dfs(0, 0, 0);
    }

private:
    std::vector<int> sticks_;
    std::vector<bool> used_;
    int target_ = 0;
    int group_count_ = 0;

    bool dfs(int group_idx, int cur_sum, int start) {
        if (group_idx == group_count_ - 1) {
            return true;
        }
        if (cur_sum == target_) {
            return dfs(group_idx + 1, 0, 0);
        }

        int prev = -1;
        for (int i = start; i < static_cast<int>(sticks_.size()); ++i) {
            if (used_[i] || sticks_[i] == prev || cur_sum + sticks_[i] > target_) {
                continue;
            }

            used_[i] = true;
            if (dfs(group_idx, cur_sum + sticks_[i], i + 1)) {
                return true;
            }
            used_[i] = false;

            prev = sticks_[i];
            if (cur_sum == 0 || cur_sum + sticks_[i] == target_) {
                return false;
            }
        }
        return false;
    }
};
```

## 变体二：火柴拼正方形

如果题目是“能否用所有火柴拼成正方形”，就是固定 `target = sum / 4`，判断能否分成 4 组。

```cpp
bool makesquare(std::vector<int>& matchsticks) {
    int sum = std::accumulate(matchsticks.begin(), matchsticks.end(), 0);
    if (sum % 4 != 0) {
        return false;
    }
    StickSolver solver;
    return solver.canMake(matchsticks, sum / 4);
}
```

## 易错点

1. 不能贪心地每次放当前最短或最长，局部最优不保证全局可行。
2. 必须用完所有木棍。
3. `target` 必须能整除总长度。
4. 没有剪枝时搜索会爆炸，面试要主动说降序、去重、空桶剪枝。
5. 如果题意不完整，要先确认是“求最小原始长度”还是“拼正方形/拼 k 组”。

## 面试回答模板

木棍问题本质是把数组划分成若干组，每组和相等，通常用 DFS 回溯加剪枝。先按长度降序排序，枚举或确定目标长度 `target`，然后尝试把木棍放入当前组，组满后进入下一组。剪枝包括：总长度必须整除 `target`，最长木棍不能超过 `target`，同层相同长度跳过，空桶尝试失败直接返回，刚好填满后失败也返回。这样能大幅减少重复排列搜索。
