# 13. 最大两数和组合数量

## 题目

给定一个数组，统计所有下标对 `(i, j)` 中，两数相加能得到最大和的组合数量，其中 `i < j`。

示例：

```text
nums = [4, 1, 2, -1, 9, 8, 8]
最大两数和 = 9 + 8 = 17
组合数量 = 2
```

因为两个 `8` 位于不同下标，所以 `(9, 第一个8)` 和 `(9, 第二个8)` 是两组组合。

## 思路

最大两数和只可能来自：

1. 最大值出现至少两次：答案是任意两个最大值组合，数量为 `C(cntMax, 2)`。
2. 最大值只出现一次：答案是最大值和次大值组合，数量为 `cntMax * cntSecond`，其中 `cntMax = 1`。

因此只需要一次遍历维护：

1. 当前最大值 `max1` 及出现次数 `cnt1`。
2. 当前次大值 `max2` 及出现次数 `cnt2`。

## 代码

```cpp
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

long long countMaxPairSum(const vector<int>& nums) {
    if (nums.size() < 2) {
        return 0;
    }

    long long max1 = LLONG_MIN;
    long long max2 = LLONG_MIN;
    long long cnt1 = 0;
    long long cnt2 = 0;

    for (int num : nums) {
        long long x = num;

        if (x > max1) {
            max2 = max1;
            cnt2 = cnt1;
            max1 = x;
            cnt1 = 1;
        } else if (x == max1) {
            ++cnt1;
        } else if (x > max2) {
            max2 = x;
            cnt2 = 1;
        } else if (x == max2) {
            ++cnt2;
        }
    }

    if (cnt1 >= 2) {
        return cnt1 * (cnt1 - 1) / 2;
    }

    return cnt1 * cnt2;
}

int main() {
    vector<int> nums = {4, 1, 2, -1, 9, 8, 8};
    cout << countMaxPairSum(nums) << endl;
    return 0;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 易错点

1. 题目统计的是下标组合，不是去重后的数值组合。
2. 最大值出现多次时，不需要次大值，例如 `[9, 9, 8]` 的最大和是 `18`，数量是 `C(2, 2) = 1`。
3. 数组可能全是负数，不能把最大值初始化为 `0`。
4. 组合数量可能很大，返回值建议使用 `long long`。
