# 85. O1最大最小栈与中位数

## 题目

实现一个栈，支持：

1. `push`
2. `pop`
3. `top`
4. `getMax`
5. `getMin`

要求 `getMax` 和 `getMin` 复杂度为 `O(1)`。进一步追问：如果还要支持查询栈中中位数，怎么实现？

## 最大最小栈思路

维护三个栈：

1. `data`：真实数据。
2. `mins`：每一层对应当前位置之前的最小值。
3. `maxs`：每一层对应当前位置之前的最大值。

每次 `push(x)` 时：

```text
mins.push(min(x, mins.top()))
maxs.push(max(x, maxs.top()))
```

每次 `pop()` 时三个栈一起弹出。

## 代码

```cpp
#include <algorithm>
#include <stdexcept>
#include <vector>
using namespace std;

class MinMaxStack {
public:
    void push(int x) {
        data_.push_back(x);
        mins_.push_back(mins_.empty() ? x : min(x, mins_.back()));
        maxs_.push_back(maxs_.empty() ? x : max(x, maxs_.back()));
    }

    void pop() {
        if (data_.empty()) {
            throw runtime_error("empty stack");
        }
        data_.pop_back();
        mins_.pop_back();
        maxs_.pop_back();
    }

    int top() const {
        if (data_.empty()) {
            throw runtime_error("empty stack");
        }
        return data_.back();
    }

    int getMin() const {
        if (mins_.empty()) {
            throw runtime_error("empty stack");
        }
        return mins_.back();
    }

    int getMax() const {
        if (maxs_.empty()) {
            throw runtime_error("empty stack");
        }
        return maxs_.back();
    }

private:
    vector<int> data_;
    vector<int> mins_;
    vector<int> maxs_;
};
```

## 空间优化

如果相同最大/最小值连续出现很多次，可以只在辅助栈里保存“值 + 次数”：

```text
mins: [(当前最小值, 出现次数)]
maxs: [(当前最大值, 出现次数)]
```

`push` 时只有新值刷新最小/最大或等于当前最小/最大时才更新辅助栈；`pop` 时如果弹出的值等于辅助栈顶，就减少次数，次数为 0 再弹出。这样在数据单调性不强时能减少辅助空间，但最坏空间仍是 `O(n)`。

## 支持中位数

如果只要求 `getMedian`，但栈仍然只在栈顶 `push/pop`，可以维护两个堆：

1. 大根堆 `low`：保存较小的一半。
2. 小根堆 `high`：保存较大的一半。

普通双堆适合插入和取中位数，但栈会删除“最后插入的元素”，这个元素不一定在堆顶。因此需要额外做懒删除：

1. `push(x)`：记录 `x` 入栈，同时放入某个堆并 rebalance。
2. `pop()`：从 `data` 栈知道要删除的值 `x`，在删除表中给 `x` 计数，不立即从堆中删除。
3. 每次取堆顶或 rebalance 前，清理堆顶中已标记删除的元素。
4. 保持 `low` 和 `high` 的有效元素数量差不超过 1。

复杂度：

| 操作 | 复杂度 |
| --- | --- |
| `push` | `O(log n)` |
| `pop` | `O(log n)` 摊还 |
| `getMedian` | `O(1)`，清理堆顶有摊还成本 |
| `getMin/getMax` | 仍可用辅助栈保持 `O(1)` |

如果要求所有操作都严格 `O(1)`，同时还要动态中位数，通常做不到。动态中位数本质需要维护有序关系，常用结构是双堆或平衡树，更新至少是 `O(log n)` 级别。除非值域很小，可以用计数数组/树状数组把复杂度转成和固定值域相关。

## 面试回答模板

最大最小栈可以用一个数据栈加两个辅助栈。辅助栈每层保存当前前缀最小值和最大值，`push/pop` 时同步更新，所以 `getMin/getMax` 都是 `O(1)`，空间 `O(n)`。如果要优化空间，可以在辅助栈里保存值和出现次数。若还要支持中位数，通常要额外维护双堆或平衡树；由于 `pop` 删除的是栈顶元素，不一定在堆顶，双堆需要懒删除。此时 `push/pop` 通常是 `O(log n)`，`getMedian` 可做到 `O(1)` 或摊还清理。
