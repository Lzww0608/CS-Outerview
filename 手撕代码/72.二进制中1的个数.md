# 二进制中 1 的个数

题目：给定一个整数，求它的二进制表示中 `1` 的个数。面试里常要求先写朴素做法，再优化。

## 1. 逐位统计

对无符号整数逐位右移：

```cpp
int countOnesLoop(unsigned int x) {
    int ans = 0;
    while (x != 0) {
        ans += x & 1U;
        x >>= 1;
    }
    return ans;
}
```

复杂度和整数位数相关。对 32 位整数可以看作 `O(32)`，通常也称为常数时间；如果按位数 `w` 泛化，就是 `O(w)`。

## 2. `x & (x - 1)`

`x & (x - 1)` 会把 x 的最低位 `1` 清零。

```cpp
int countOnesKernighan(unsigned int x) {
    int ans = 0;
    while (x != 0) {
        x &= (x - 1);
        ++ans;
    }
    return ans;
}
```

复杂度和 `1` 的个数相关，记为 `O(k)`。当数字中 `1` 很少时，比逐位扫描更快。

## 3. O(1) 位运算 SWAR

如果限定为 32 位整数，可以用固定次数的并行位计数，复杂度是严格常数：

```cpp
int countOnesO1(unsigned int x) {
    x = x - ((x >> 1) & 0x55555555U);
    x = (x & 0x33333333U) + ((x >> 2) & 0x33333333U);
    x = (x + (x >> 4)) & 0x0f0f0f0fU;
    x = x + (x >> 8);
    x = x + (x >> 16);
    return static_cast<int>(x & 0x3fU);
}
```

核心思想是分组累加：

1. 每 2 bit 内统计 1 的个数。
2. 每 4 bit 内合并结果。
3. 每 8 bit、16 bit、32 bit 继续合并。

因为操作次数固定，不随输入数值变化，所以是 `O(1)`。

## 4. 内置函数

工程中优先使用编译器或标准库提供的实现：

```cpp
int a = __builtin_popcount(x);      // GCC/Clang
int b = __builtin_popcountll(y);    // unsigned long long
```

C++20 可以使用：

```cpp
#include <bit>

int c = std::popcount(x);
```

这些实现通常会映射到 CPU 的 `POPCNT` 指令或高效位运算。

## 5. 有符号数注意事项

面试中最好把参数转成无符号类型处理：

```cpp
int countOnes(int n) {
    unsigned int x = static_cast<unsigned int>(n);
    return countOnesKernighan(x);
}
```

原因：

1. 负数右移是否补符号位和实现有关，不适合手写循环依赖。
2. 补码表示下，负数也可以按无符号位模式统计。
3. `x & (x - 1)` 对无符号整数语义更清晰。

## 6. 易错点

1. 不要对有符号负数直接做右移循环。
2. `x & (x - 1)` 每次清掉最低位的 1，不是最低位 bit。
3. 如果题目要求十进制数字中字符 `'1'` 的个数，那是另一个数位 DP/数学计数问题，要先和面试官确认。
4. `O(1)` 的说法通常建立在固定 32/64 位整数上；任意精度大整数仍与位数相关。
5. 工程代码优先用 `std::popcount` 或编译器 builtin，别自己维护复杂魔数实现。

## 7. 面试回答模板

二进制中 1 的个数可以逐位右移统计，复杂度和位数相关。更好的写法是 Brian Kernighan 算法：循环执行 `x &= x - 1`，每次清掉最低位的 1，循环次数等于 1 的个数。若面试官要求固定 32 位下优化到 `O(1)`，可以用 SWAR 分组统计，或者说明工程里使用 C++20 `std::popcount` / GCC `__builtin_popcount`，通常会编译成 CPU popcnt 指令。处理负数时建议先转成无符号整数。
