# 97. 按时间戳合并两个消息队列

## 题目

输入两个队列，每个元素是带时间戳的消息。两个队列内部都已经按时间戳升序排列，输出一个整体按时间排序的合并队列。

```cpp
struct Message {
    long long ts;
    std::string body;
};
```

## 双队列归并

这题本质是归并排序里的 merge 步骤。每次比较两个队头，把时间戳更小的消息弹出并放入输出队列。

```cpp
#include <queue>
#include <string>
#include <utility>
using namespace std;

struct Message {
    long long ts;
    string body;
};

queue<Message> mergeByTimestamp(queue<Message> a, queue<Message> b) {
    queue<Message> out;

    while (!a.empty() && !b.empty()) {
        if (a.front().ts <= b.front().ts) {
            out.push(a.front());
            a.pop();
        } else {
            out.push(b.front());
            b.pop();
        }
    }

    while (!a.empty()) {
        out.push(a.front());
        a.pop();
    }
    while (!b.empty()) {
        out.push(b.front());
        b.pop();
    }

    return out;
}
```

这里 `<=` 可以保证稳定性：当两个消息时间戳相等时，优先输出队列 `a` 中的消息。如果业务要求同时间戳按消息 ID、来源优先级排序，则比较函数需要扩展。

## 不复制输入的写法

如果队列很大，不想拷贝输入，可以传引用并消费原队列：

```cpp
queue<Message> mergeByTimestampInPlace(queue<Message>& a, queue<Message>& b) {
    queue<Message> out;
    while (!a.empty() && !b.empty()) {
        queue<Message>& src = a.front().ts <= b.front().ts ? a : b;
        out.push(std::move(src.front()));
        src.pop();
    }
    while (!a.empty()) {
        out.push(std::move(a.front()));
        a.pop();
    }
    while (!b.empty()) {
        out.push(std::move(b.front()));
        b.pop();
    }
    return out;
}
```

## 多队列扩展

如果不是两个队列，而是 `K` 个已经按时间排序的消息队列，可以用小顶堆保存每个队列的当前队头：

```text
堆元素: (timestamp, queue_id)
每次弹出最小 timestamp
从对应 queue_id 再取下一个消息入堆
```

复杂度：

```text
两个队列: 时间 O(n + m)，额外空间 O(1) 不计输出
K 个队列: 时间 O(total * log K)，额外空间 O(K)
```

## 真实场景注意事项

1. 时间戳可能来自不同机器，需要考虑时钟偏移，必要时用逻辑时钟或服务端写入时间。
2. 实时流合并不能无限等待慢队列，通常需要 watermark 或最大等待延迟。
3. 相同时间戳要定义稳定规则，否则重放和测试结果可能不确定。
4. 输出队列可能很大，生产环境更常见的是边归并边写下游，而不是全部放内存。

## 面试回答模板

两个队列内部已经按时间戳有序，所以用双指针归并即可。每次比较两个队头，时间戳小的先输出并弹出；相等时按固定规则保证稳定性。遍历结束后把剩余队列接到输出后面，时间复杂度 `O(n+m)`。如果扩展到多个队列，用小顶堆维护每个队列的队头，复杂度是 `O(total log K)`。
