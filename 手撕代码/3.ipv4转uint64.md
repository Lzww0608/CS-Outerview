## 127.0.0.1:8080转换成uint64

```cpp
#include <iostream>
#include <string>
#include <cstdint>
#include <stdexcept>

// 127.0.0.1:8080 --> uint64
uint64_t ipToUint64(const std::string& ip) {
    size_t pos = ip.find(':');
    if (pos == std::string::npos) {
        throw std::invalid_argument("Invalid IP address");
    }

    auto ip_part = ip.substr(0, pos);
    auto port_part = ip.substr(pos + 1);

    uint64_t ip_addr = 0;
    for (int i = 0, j = 0; i < 4; i++) {
        int num = 0;
        while (j < ip_part.size() && ip_part[j] >= '0' && ip_part[j] <= '9') {
            num = num * 10 + (ip_part[j] - '0');
            j++;
        }
        if (j != ip_part.size() && ip_part[j] != '.' || num > 255) {
            throw std::invalid_argument("Invalid IP address");
        }
        ip_addr |= num << (i * 8);
        j++;
    }

    uint16_t port = 0;
    for (int i = 0; i < port_part.size(); i++) {
        if (port_part[i] < '0' || port_part[i] > '9') {
            throw std::invalid_argument("Invalid port");
        }
        port = port * 10 + (port_part[i] - '0');
        if (port > 65535) {
            throw std::invalid_argument("Invalid port");
        }
    }
    return (ip_addr << 32) | (port << 16);
}

int main() {
    std::string ip = "127.0.0.1:8080";
    uint64_t ip_addr = ipToUint64(ip);
    std::cout << std::hex << ip_addr << std::endl;
    return 0;
}
```

## IPv4 每段转成整数

如果题目只要求把 IPv4 地址的四段解析成整数，核心是按字符扫描十进制数字，并校验格式：

1. 必须正好 4 段。
2. 每段只能包含数字。
3. 每段数值范围是 `[0, 255]`。
4. 不能出现空段，例如 `1..2.3`。
5. 是否允许前导零要和面试官确认；很多题会认为 `001` 合法但需要转成 1，也有题会禁止。

示例代码：

```cpp
#include <array>
#include <stdexcept>
#include <string>

std::array<int, 4> parseIPv4(const std::string& ip) {
    std::array<int, 4> parts{};
    int idx = 0;
    int value = 0;
    int digits = 0;

    for (size_t i = 0; i <= ip.size(); ++i) {
        char c = (i == ip.size()) ? '.' : ip[i];

        if (c >= '0' && c <= '9') {
            value = value * 10 + (c - '0');
            ++digits;
            if (value > 255) {
                throw std::invalid_argument("IPv4 segment out of range");
            }
        } else if (c == '.') {
            if (digits == 0 || idx >= 4) {
                throw std::invalid_argument("invalid IPv4 format");
            }
            parts[idx++] = value;
            value = 0;
            digits = 0;
        } else {
            throw std::invalid_argument("invalid IPv4 character");
        }
    }

    if (idx != 4) {
        throw std::invalid_argument("invalid IPv4 segment count");
    }
    return parts;
}
```

## 为什么解析阶段不用位操作

位操作适合在已经得到四个整数段之后做打包：

```cpp
uint32_t packIPv4(const std::array<int, 4>& p) {
    return (static_cast<uint32_t>(p[0]) << 24) |
           (static_cast<uint32_t>(p[1]) << 16) |
           (static_cast<uint32_t>(p[2]) << 8)  |
           static_cast<uint32_t>(p[3]);
}
```

但解析字符串时，输入是 ASCII 字符 `'0'` 到 `'9'`，每段是十进制文本。此时要做的是十进制累加 `value = value * 10 + digit`，并检查点号、段数和范围。用位操作不能自然表达十进制进位，也更容易漏掉非法格式校验。

工程中如果不是手撕题，优先使用系统库：

```cpp
in_addr addr{};
inet_pton(AF_INET, ip.c_str(), &addr);
```

面试回答可以总结为：解析阶段用十进制字符扫描，打包成 32 位整数时才用位移；不要为了“位运算快”牺牲可读性和格式校验。
