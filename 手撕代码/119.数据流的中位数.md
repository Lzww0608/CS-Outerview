# 119. 数据流的中位数

## 题目

不断插入整数，支持随时查询当前所有数的中位数。对应 LeetCode 295。

## 思路

维护两个堆：

1. 大根堆 `left` 保存较小的一半。
2. 小根堆 `right` 保存较大的一半。
3. 保证 `left.size() == right.size()` 或 `left.size() == right.size() + 1`。

中位数：

1. 元素个数奇数：`left.top()`。
2. 元素个数偶数：`(left.top() + right.top()) / 2`。

## 代码

```cpp
#include <queue>
#include <vector>
using namespace std;

class MedianFinder {
public:
    void addNum(int num) {
        if (left_.empty() || num <= left_.top()) {
            left_.push(num);
        } else {
            right_.push(num);
        }

        if (left_.size() > right_.size() + 1) {
            right_.push(left_.top());
            left_.pop();
        } else if (right_.size() > left_.size()) {
            left_.push(right_.top());
            right_.pop();
        }
    }

    double findMedian() const {
        if (left_.size() == right_.size()) {
            return (static_cast<double>(left_.top()) + right_.top()) / 2.0;
        }
        return left_.top();
    }

private:
    priority_queue<int> left_;
    priority_queue<int, vector<int>, greater<int>> right_;
};
```

## 易错点

1. 两堆大小差不能超过 1。
2. 大根堆所有元素都应小于等于小根堆元素。
3. 两个 `int` 相加可能溢出，计算中位数时先转 `double` 或用 `long long`。
4. 如果还要删除任意元素，需要平衡树或双堆懒删除。
