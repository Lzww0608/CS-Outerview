# 57. 删除数组中 3 的倍数

## 题目

给定一个随机数数组，删除其中所有能被 3 整除的元素。

面试中通常会继续追问：

1. 是否要求保持原数组相对顺序。
2. 是否允许开辟新数组。
3. 使用 `vector` 删除时迭代器是否会失效。
4. 时间复杂度能否做到 `O(n)`。

## 方法一：`erase-remove_if`

如果容器是 `std::vector<int>`，最推荐写法是：

```cpp
#include <algorithm>
#include <vector>

void removeMultiplesOfThree(std::vector<int>& nums) {
    nums.erase(
        std::remove_if(nums.begin(), nums.end(), [](int x) {
            return x % 3 == 0;
        }),
        nums.end()
    );
}
```

原理：

1. `remove_if` 不会真正缩短 `vector`，而是把不需要删除的元素稳定地搬到前面。
2. `remove_if` 返回新的逻辑尾迭代器。
3. `erase` 删除逻辑尾到真实尾部之间的冗余元素。

复杂度：

1. 时间复杂度 `O(n)`。
2. 额外空间复杂度 `O(1)`。
3. 保持未删除元素的相对顺序。

## 方法二：手写双指针覆盖

如果面试官要求不用 STL 算法，可以手写覆盖：

```cpp
#include <vector>

void removeMultiplesOfThree(std::vector<int>& nums) {
    int write = 0;
    for (int read = 0; read < static_cast<int>(nums.size()); ++read) {
        if (nums[read] % 3 != 0) {
            nums[write++] = nums[read];
        }
    }
    nums.resize(write);
}
```

这个方法和 `remove_if` 思路一致：`read` 扫描所有元素，`write` 指向下一个保留元素应该写入的位置。

## 方法三：迭代器循环删除

也可以逐个 `erase`，但要正确接收返回的新迭代器：

```cpp
#include <vector>

void removeMultiplesOfThree(std::vector<int>& nums) {
    for (auto it = nums.begin(); it != nums.end(); ) {
        if (*it % 3 == 0) {
            it = nums.erase(it);
        } else {
            ++it;
        }
    }
}
```

这种写法简单，但 `vector::erase` 每删除一个元素都要搬移后续元素，最坏时间复杂度是 `O(n^2)`，数据量大时不推荐。

## 易错点

1. `for (++it)` 的循环里直接 `nums.erase(it)` 后继续递增，会使用已经失效的迭代器。
2. `vector` 删除中间元素会导致被删位置及其后的迭代器、引用、指针失效。
3. `x % 3 == 0` 对负数同样成立，例如 `-6 % 3 == 0`。
4. 如果容器是 `list`，可以使用 `list::remove_if`，删除节点不会搬移其他元素，单次删除不会使其他节点迭代器失效。

## 面试回答模板

如果题目是 `vector` 删除 3 的倍数，我会优先用 `erase-remove_if`，一次线性扫描把保留元素搬到前面，再统一 erase 尾部，时间 `O(n)`、额外空间 `O(1)`，并保持相对顺序。手写时可以用读写双指针。不要在普通 `for` 循环里 erase 后继续使用旧迭代器，因为 `vector` 的中间删除会让当前位置及其后的迭代器失效。
