# 134. 最长回文子串

题目：给定字符串 `s`，求最长回文连续子串。

回文子串要求连续，和“最长回文子序列”不同。面试中最稳的做法是中心扩展；如果追求线性时间，可以讲 Manacher。

## 1. 中心扩展

每个回文串都有中心。中心可能是一个字符，也可能是两个字符之间的空隙。

```cpp
#include <string>
using namespace std;

string longestPalindrome(string s) {
    int n = static_cast<int>(s.size());
    if (n <= 1) {
        return s;
    }

    int bestL = 0;
    int bestLen = 1;

    auto expand = [&](int l, int r) {
        while (l >= 0 && r < n && s[l] == s[r]) {
            --l;
            ++r;
        }
        int len = r - l - 1;
        if (len > bestLen) {
            bestLen = len;
            bestL = l + 1;
        }
    };

    for (int i = 0; i < n; ++i) {
        expand(i, i);       // 奇数长度
        expand(i, i + 1);   // 偶数长度
    }

    return s.substr(bestL, bestLen);
}
```

复杂度：

1. 时间复杂度：最坏 `O(n^2)`。
2. 空间复杂度：`O(1)`。

## 2. 动态规划

定义 `dp[l][r]` 表示 `s[l..r]` 是否为回文：

```text
dp[l][r] = s[l] == s[r] && (r - l < 2 || dp[l + 1][r - 1])
```

动态规划也是 `O(n^2)` 时间和 `O(n^2)` 空间，适合解释状态转移，但面试手写通常不如中心扩展简洁。

## 3. Manacher

Manacher 通过在字符间插入分隔符，把奇偶长度统一处理，并维护当前最右回文边界。它可以做到 `O(n)` 时间，但实现细节更多。

真实工程里，如果只是普通业务校验或面试手撕，中心扩展通常足够；只有在超长字符串、大量查询或算法竞赛里才值得上 Manacher。

## 4. 易错点

1. 要同时处理奇数长度和偶数长度回文，例如 `"abba"`。
2. 空字符串和长度为 1 的字符串要能返回。
3. 返回的是子串本身还是长度，要先确认。
4. 字符串如果包含 UTF-8 中文或 Emoji，按 `char` 扩展会按字节处理，不等于按用户感知字符处理。

## 5. 面试回答模板

我会用中心扩展。枚举每个位置作为奇数回文中心，再枚举相邻两个位置作为偶数回文中心，向两边扩展直到字符不同，过程中记录最长区间。这样空间是 `O(1)`，时间最坏 `O(n^2)`。如果面试官追问线性解，可以说明 Manacher 用回文半径和最右边界把复杂度优化到 `O(n)`。
