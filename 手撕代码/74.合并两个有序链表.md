# 合并两个有序链表

合并两个升序链表是归并思想的基础题。核心是用两个指针分别扫描链表，每次取较小节点接到结果链表尾部。

## 1. 迭代写法

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (l1 != nullptr && l2 != nullptr) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }

    tail->next = (l1 != nullptr) ? l1 : l2;
    return dummy.next;
}
```

## 2. 复杂度

```text
时间复杂度：O(m + n)
空间复杂度：O(1)
```

迭代写法只重连原有节点，不新建节点，因此额外空间是常数级。

## 3. 递归写法

```cpp
ListNode* mergeTwoListsRecursive(ListNode* l1, ListNode* l2) {
    if (l1 == nullptr) {
        return l2;
    }
    if (l2 == nullptr) {
        return l1;
    }

    if (l1->val <= l2->val) {
        l1->next = mergeTwoListsRecursive(l1->next, l2);
        return l1;
    }
    l2->next = mergeTwoListsRecursive(l1, l2->next);
    return l2;
}
```

递归写法简洁，但递归深度最坏是 `O(m + n)`，链表很长时可能栈溢出。面试现场更推荐迭代写法。

## 4. 易错点

1. 使用 dummy 节点可以避免单独处理结果链表头。
2. 比较时用 `<=` 可以保持相同值节点在两个链表中的相对稳定性。
3. 主循环结束后不要忘记把剩余链表直接接到尾部。
4. 如果题目要求不修改原链表，需要新建节点；默认 LeetCode 类题目通常允许重连原节点。

## 5. 面试回答模板

两个有序链表合并就是归并过程。用 dummy 头节点和 tail 指针维护结果链表，同时扫描 `l1`、`l2`，每次把值更小的节点接到 tail 后面并移动对应指针。某个链表为空后，把另一个链表剩余部分整体接上。每个节点只访问一次，时间 `O(m+n)`，迭代版本额外空间 `O(1)`。
