# 150. 链表深复制

题目：复制一个链表，要求新链表节点与原链表节点互不共享。面试追问常包括：链表有环怎么办、双向链表有什么不同、单向链表能否有多个环。

## 1. 普通无环链表

无环单链表可以顺序遍历，逐个创建新节点并连接：

```cpp
struct Node {
    int val;
    Node* next;
    explicit Node(int v) : val(v), next(nullptr) {}
};

Node* cloneList(Node* head) {
    Node dummy(0);
    Node* tail = &dummy;
    for (Node* cur = head; cur != nullptr; cur = cur->next) {
        tail->next = new Node(cur->val);
        tail = tail->next;
    }
    return dummy.next;
}
```

但这个写法遇到环会死循环。

## 2. 有环链表的通用做法

如果链表可能有环，核心是用哈希表记录“原节点 -> 新节点”的映射。每个原节点只创建一次，后续再次遇到直接复用对应的新节点。

```cpp
#include <unordered_map>

struct Node {
    int val;
    Node* next;
    explicit Node(int v) : val(v), next(nullptr) {}
};

Node* cloneListWithCycle(Node* head) {
    if (head == nullptr) {
        return nullptr;
    }

    std::unordered_map<Node*, Node*> mp;
    Node* cur = head;

    while (cur != nullptr && !mp.count(cur)) {
        mp[cur] = new Node(cur->val);
        cur = cur->next;
    }

    for (auto& kv : mp) {
        Node* old_node = kv.first;
        Node* new_node = kv.second;
        if (old_node->next != nullptr) {
            new_node->next = mp[old_node->next];
        }
    }

    return mp[head];
}
```

这个方法的本质是把链表看成一个出度最多为 1 的有向图。从 `head` 出发，遇到已访问节点就停止建点，再按映射重建边。

## 3. 双向链表有什么不同

双向链表节点通常有 `prev` 和 `next` 两条边：

```cpp
struct DNode {
    int val;
    DNode* prev;
    DNode* next;
};
```

深复制时仍然用映射表，但要同时复制两个方向的指针：

```text
new_node->next = mp[old_node->next]
new_node->prev = mp[old_node->prev]
```

如果双向链表保证结构合法，从 `head` 沿 `next` 能访问所有节点，只遍历 `next` 就够；如果不保证，或者节点可能通过 `prev` 指向额外节点，就应按图遍历，把 `next`、`prev` 都当成邻居。

## 4. 单向链表会有多个环吗

标准单向链表每个节点只有一个 `next` 指针。从同一个 `head` 出发，路径是确定的，因此可达部分最多只有一个环：

```text
head -> ... -> entry -> ... -> entry
```

不可能在同一条从 `head` 出发的单链路径上同时进入两个不同环，因为一旦进入第一个环，就不会再离开它。

如果题目说“多个环”，通常说明结构已经不是普通单链表，而是：

1. 有多个不连通链表，每个链表各自有环。
2. 每个节点可能有多个指针，已经变成一般图。
3. 输入不是从单一 `head` 出发，而是一组节点。

这时应该用图的深拷贝思路：从所有入口 DFS/BFS，使用映射表避免重复创建和无限循环。

## 5. 测试样例

1. 空链表：`head = nullptr`。
2. 单节点无环：`1 -> null`。
3. 单节点自环：`1 -> 1`。
4. 多节点无环：`1 -> 2 -> 3 -> null`。
5. 尾节点指向中间节点：`1 -> 2 -> 3 -> 2`。
6. 双向链表：检查 `next` 和 `prev` 都指向新节点。
7. 深拷贝校验：修改新链表节点值，不应影响原链表。

## 6. 面试回答模板

链表深复制要保证新旧节点不共享。无环单链表可以顺序复制；如果可能有环，必须用哈希表记录原节点到新节点的映射，每个原节点只创建一次，再按映射重建 `next`。双向链表同理，只是还要复制 `prev`。标准单向链表从一个 head 出发最多只有一个环；如果题目说多个环，就已经接近一般图复制，需要 DFS/BFS 加 visited map。
