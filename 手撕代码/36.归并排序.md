# 归并排序

归并排序使用分治思想：把数组不断拆成两半，分别排序后再把两个有序区间合并成一个有序区间。

## 核心思想

```text
merge_sort(l, r):
    if 区间长度 <= 1: return
    mid = (l + r) / 2
    merge_sort(l, mid)
    merge_sort(mid, r)
    merge two sorted ranges
```

归并排序的关键是“合并两个有序数组”：用两个指针分别指向左右区间，每次取较小值放入临时数组。

## 代码

```cpp
#include <vector>

void mergeSort(std::vector<int>& nums, int l, int r, std::vector<int>& tmp) {
    if (r - l <= 1) {
        return;
    }

    int mid = l + (r - l) / 2;
    mergeSort(nums, l, mid, tmp);
    mergeSort(nums, mid, r, tmp);

    int i = l;
    int j = mid;
    int k = l;
    while (i < mid && j < r) {
        if (nums[i] <= nums[j]) {
            tmp[k++] = nums[i++];
        } else {
            tmp[k++] = nums[j++];
        }
    }
    while (i < mid) {
        tmp[k++] = nums[i++];
    }
    while (j < r) {
        tmp[k++] = nums[j++];
    }

    for (int p = l; p < r; ++p) {
        nums[p] = tmp[p];
    }
}

void mergeSort(std::vector<int>& nums) {
    std::vector<int> tmp(nums.size());
    mergeSort(nums, 0, static_cast<int>(nums.size()), tmp);
}
```

复杂度：

```text
时间 O(n log n)
空间 O(n)
```

## 归并用的是什么思想

归并排序体现两个思想：

1. **分治**：把原问题拆成规模更小、结构相同的子问题。
2. **双指针合并**：利用左右两段已有序的性质，线性合并。

每层合并总共处理 `n` 个元素，层数是 `log n`，所以总时间是 `O(n log n)`。

## 稳定性

归并排序可以稳定。合并时如果左右元素相等，先取左边元素：

```cpp
if (left_value <= right_value) {
    take_left();
}
```

这样相等元素的相对顺序不会被改变。

## 适用场景

1. 需要稳定排序。
2. 链表排序，因为链表合并不需要随机访问。
3. 外部排序，大文件无法全部放内存时，先分块排序，再多路归并。
4. 逆序对统计，合并时顺便统计跨区间逆序对。

## 易错点

1. 数组归并排序需要额外空间，普通实现不是原地排序。
2. 合并时相等元素先取左边，才能保证稳定性。
3. 递归区间用左闭右开 `[l, r)` 可以减少边界错误。
4. 大数组递归可能有栈深度问题，但深度是 `O(log n)`，通常可控。

## 面试回答模板

归并排序是分治算法：先把数组递归分成左右两半，分别排好序，再用双指针把两个有序区间线性合并。每一层合并总成本是 `O(n)`，递归层数是 `O(log n)`，所以总时间 `O(n log n)`，额外空间 `O(n)`。如果合并时相等元素先取左区间，它就是稳定排序。它适合链表排序、外部排序和需要稳定性的场景。
