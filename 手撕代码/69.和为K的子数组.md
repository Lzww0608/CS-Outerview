# 和为 K 的子数组

题目：给定一个整数数组和整数 `k`，统计和为 `k` 的连续子数组个数。

## 1. 前缀和思路

设前缀和：

```text
prefix[i] = nums[0] + nums[1] + ... + nums[i]
```

如果某个子数组 `nums[l..r]` 的和为 `k`，则：

```text
prefix[r] - prefix[l - 1] = k
prefix[l - 1] = prefix[r] - k
```

遍历到当前位置时，只需要知道之前出现过多少次 `prefix - k`，就能统计以当前位置结尾的合法子数组数量。

## 2. C++ 实现

```cpp
#include <unordered_map>
#include <vector>
using namespace std;

int subarraySum(vector<int>& nums, int k) {
    unordered_map<long long, int> count;
    count[0] = 1;

    long long prefix = 0;
    int ans = 0;

    for (int x : nums) {
        prefix += x;

        auto it = count.find(prefix - k);
        if (it != count.end()) {
            ans += it->second;
        }

        ++count[prefix];
    }

    return ans;
}
```

## 3. 为什么先查询再更新

当前前缀和代表 `prefix[r]`。要找的是之前的 `prefix[l - 1]`，所以应该先用 `prefix - k` 查询历史次数，再把当前 `prefix` 加入哈希表。

如果先更新，在 `k = 0` 时会把当前位置错误地当成之前位置，产生多计数。

## 4. 复杂度

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(n)`。

使用 `long long` 保存前缀和可以避免整数溢出。

## 5. 正整数数组的滑动窗口变体

如果题目明确数组只包含正整数，也可以用滑动窗口求“是否存在”和为 `k` 的连续子数组：

```cpp
bool existsSubarraySumK(const vector<int>& nums, int k) {
    int left = 0;
    long long sum = 0;

    for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
        sum += nums[right];
        while (sum > k && left <= right) {
            sum -= nums[left++];
        }
        if (sum == k) {
            return true;
        }
    }

    return false;
}
```

但如果数组中有负数，滑动窗口不再成立，因为窗口扩大和缩小时和不再单调，必须使用前缀和 + 哈希表。

## 6. 序列 0..N 中连续区间和为 N 的数量

如果题目是“给定 `N`，在整数序列 `0, 1, 2, ..., N` 中，统计连续子数组和为 `N` 的数量”，可以利用全是非负数的单调性，用滑动窗口做到 `O(N)`：

```cpp
int countRangesSumToN(int n) {
    int ans = 0;
    long long sum = 0;
    int left = 0;

    for (int right = 0; right <= n; ++right) {
        sum += right;

        while (sum > n && left <= right) {
            sum -= left;
            ++left;
        }

        if (sum == n) {
            ++ans;
        }
    }

    return ans;
}
```

这个问题也可以转成数学计数。连续区间 `[l, r]` 的和为：

```text
(l + r) * (r - l + 1) / 2 = N
```

设区间长度为 `len`，则：

```text
len * (2 * l + len - 1) = 2N
```

枚举 `len`，只要 `2N` 能被 `len` 整除，并且 `2 * l = 2N / len - len + 1` 是非负偶数，就存在一个合法起点 `l`。这个做法可以做到 `O(sqrt(N))` 级别，因为长度超过一定范围后最小和已经超过 `N`。

```cpp
int countRangesSumToNByMath(long long n) {
    int ans = 0;
    for (long long len = 1; len * (len - 1) / 2 <= n; ++len) {
        long long t = 2 * n;
        if (t % len != 0) {
            continue;
        }
        long long twoLeft = t / len - len + 1;
        if (twoLeft >= 0 && twoLeft % 2 == 0) {
            ++ans;
        }
    }
    return ans;
}
```

面试时要先确认序列是否包含 `0`。包含 `0` 时，`[N]` 和 `[0, N]` 都是合法连续区间；如果题目只允许正整数序列 `1..N`，答案会少掉以 0 开头的情况。

## 7. 易错点

1. `count[0] = 1` 不能漏，用来处理从下标 0 开始的子数组。
2. 要先统计答案，再更新当前前缀和次数。
3. 数组有负数时不能用普通滑动窗口。
4. 问“个数”时哈希表存出现次数，不是只存是否出现。
5. 前缀和可能溢出，建议用 `long long`。

## 8. 面试回答模板

我会用前缀和加哈希表。遍历数组维护当前前缀和 `prefix`，如果之前出现过 `prefix-k`，说明这些位置之后到当前位置的子数组和为 `k`，答案加上出现次数。哈希表初始化 `count[0]=1`，每一步先查询再把当前前缀和计数加一。这样可以处理正数、负数和 0，时间复杂度 `O(n)`，空间复杂度 `O(n)`。如果题目限定全是正整数，并且只问是否存在，也可以用滑动窗口。
