# 10.合并两个有序数组

## 题目

给定两个升序数组 `nums1` 和 `nums2`，其中 `nums1` 的长度为 `m + n`，前 `m` 个元素有效，后 `n` 个位置为空位。将 `nums2` 的 `n` 个元素合并到 `nums1` 中，使 `nums1` 成为一个升序数组。

要求只使用常量级别的额外空间。

示例：

```text
nums1 = [1,2,3,0,0,0], m = 3
nums2 = [2,5,6], n = 3

合并后:
[1,2,2,3,5,6]
```

## 思路

如果从前往后合并，`nums1` 前面的有效元素会被覆盖。为了避免额外数组，从后往前放元素：

1. `i = m - 1` 指向 `nums1` 的最后一个有效元素。
2. `j = n - 1` 指向 `nums2` 的最后一个元素。
3. `k = m + n - 1` 指向 `nums1` 的最后一个位置。
4. 每次把 `nums1[i]` 和 `nums2[j]` 中较大的放到 `nums1[k]`。

## 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void merge(vector<int>& nums1, int m, const vector<int>& nums2, int n) {
    int i = m - 1;
    int j = n - 1;
    int k = m + n - 1;

    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j]) {
            nums1[k--] = nums1[i--];
        } else {
            nums1[k--] = nums2[j--];
        }
    }

    while (j >= 0) {
        nums1[k--] = nums2[j--];
    }
}

int main() {
    int m, n;
    cin >> m >> n;

    vector<int> nums1(m + n);
    vector<int> nums2(n);

    for (int i = 0; i < m; ++i) {
        cin >> nums1[i];
    }

    for (int i = 0; i < n; ++i) {
        cin >> nums2[i];
    }

    merge(nums1, m, nums2, n);

    for (int i = 0; i < m + n; ++i) {
        if (i > 0) {
            cout << ' ';
        }
        cout << nums1[i];
    }
    cout << endl;

    return 0;
}
```

输入示例：

```text
3 3
1 2 3
2 5 6
```

输出：

```text
1 2 2 3 5 6
```

## 复杂度

```text
时间复杂度: O(m + n)
空间复杂度: O(1)
```

## 返回一个新有序数组

如果题目说“给两个有序整数数组，返回一个新的有序数组”，就不需要从后往前写，也不需要 `nums1` 预留空间。直接双指针从前往后合并即可。

```cpp
#include <vector>
using namespace std;

vector<int> mergeSortedArray(const vector<int>& a, const vector<int>& b) {
    vector<int> ans;
    ans.reserve(a.size() + b.size());

    size_t i = 0;
    size_t j = 0;
    while (i < a.size() && j < b.size()) {
        if (a[i] <= b[j]) {
            ans.push_back(a[i++]);
        } else {
            ans.push_back(b[j++]);
        }
    }

    while (i < a.size()) {
        ans.push_back(a[i++]);
    }
    while (j < b.size()) {
        ans.push_back(b[j++]);
    }
    return ans;
}
```

复杂度：

```text
时间复杂度: O(m + n)
空间复杂度: O(m + n)
```

这里 `reserve` 不是必须的，但可以提前申请结果数组容量，避免多次扩容。`push_back` 会在当前尾部构造新元素；如果容量不够，`vector` 会重新申请更大的连续空间并搬移旧元素。

## 易错点

1. 必须从后往前合并，否则会覆盖 `nums1` 中还没处理的元素。
2. 如果 `nums2` 还有剩余，需要继续拷贝到 `nums1` 前面。
3. 如果 `nums1` 还有剩余，不需要处理，因为它们已经在正确位置。
4. 下标用 `int` 更方便处理 `-1`，避免无符号整数下溢。

## 扩展：两个独立数组都没有额外空间

如果题目不是 LeetCode 88 形式，而是两个独立数组 `a` 和 `b`，要求合并后仍分别放在 `a` 和 `b` 中且只能用 `O(1)` 额外空间，可以使用 gap 方法，类似 Shell Sort：

```text
gap = ceil((m + n) / 2)
比较间隔为 gap 的两个元素，如果逆序则交换
不断缩小 gap，直到 gap = 1 完成最后一轮
```

这种方式空间是 `O(1)`，时间复杂度约 `O((m+n)log(m+n))`，但实现比逆向双指针复杂。面试时要先确认题目里的“合并到哪个数组”。

## 扩展：两个数组可能升序或降序，结果放回 a

如果 `a` 和 `b` 各自有序，但方向可能不同，并且要求合并结果放在 `a` 中，结果顺序按照 `a` 原来的顺序来，可以先判断方向，再仍然从 `a` 的尾部写入，避免覆盖 `a` 中还没处理的元素。

假设 `a` 前 `m` 个元素有效，容量至少是 `m + n`：

```cpp
void mergeKeepAOrder(vector<int>& a, int m, const vector<int>& b, int n) {
    if (static_cast<int>(a.size()) < m + n) {
        a.resize(m + n);
    }
    if (n == 0) {
        return;
    }
    if (m == 0) {
        for (int t = 0; t < n; ++t) {
            a[t] = b[t];
        }
        return;
    }

    bool ascA = (m < 2 || a[0] <= a[m - 1]);
    bool ascB = (n < 2 || b[0] <= b[n - 1]);
    int k = m + n - 1;

    if (ascA) {
        int i = m - 1;                 // a 中当前最大值
        int j = ascB ? n - 1 : 0;      // b 中当前最大值

        while (i >= 0 && (ascB ? j >= 0 : j < n)) {
            if (a[i] > b[j]) {
                a[k--] = a[i--];
            } else {
                a[k--] = b[j];
                j += ascB ? -1 : 1;
            }
        }

        while (ascB ? j >= 0 : j < n) {
            a[k--] = b[j];
            j += ascB ? -1 : 1;
        }
    } else {
        int i = m - 1;                 // a 中当前最小值
        int j = ascB ? 0 : n - 1;      // b 中当前最小值

        while (i >= 0 && (ascB ? j < n : j >= 0)) {
            if (a[i] < b[j]) {
                a[k--] = a[i--];
            } else {
                a[k--] = b[j];
                j += ascB ? 1 : -1;
            }
        }

        while (ascB ? j < n : j >= 0) {
            a[k--] = b[j];
            j += ascB ? 1 : -1;
        }
    }
}
```

例子：

```text
a = [9, 6, 3, _, _, _], m = 3
b = [1, 5, 8], n = 3

结果按 a 的降序:
[9, 8, 6, 5, 3, 1]
```

核心仍然是逆向写入。`a` 升序时，从后往前放最大值；`a` 降序时，从后往前放最小值。这样无论 `b` 是升序还是降序，都只需要移动指针方向，不需要额外排序。
