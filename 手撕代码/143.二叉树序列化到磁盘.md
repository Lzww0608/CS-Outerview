# 143. 二叉树序列化到磁盘

把二叉树保存到磁盘，本质是把内存中的指针结构转换成可持久化的字节流；下次读取时，再根据字节流重建节点和左右孩子关系。

## 1. 常见方案

1. **前序遍历 + 空节点标记**：记录 `根、左、右`，空指针写成 `#`。实现简单，反序列化时递归读取即可。
2. **层序遍历 + 空节点标记**：更接近数组表示，适合和队列、宽度优先遍历结合，但稀疏树会产生较多空标记。
3. **结构和值分离**：先记录树形结构 bitset，再记录节点值，适合追求空间压缩的场景。
4. **二进制格式**：为每个节点写入存在标记和值，读写更快，但要处理版本、大小端、类型长度和兼容性。

面试手写一般选前序遍历，因为代码短、逻辑清晰、能唯一还原任意二叉树。

## 2. 前序序列化

```cpp
#include <sstream>
#include <string>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

void serializeDfs(TreeNode* root, std::ostream& out) {
    if (root == nullptr) {
        out << "# ";
        return;
    }
    out << root->val << ' ';
    serializeDfs(root->left, out);
    serializeDfs(root->right, out);
}

std::string serialize(TreeNode* root) {
    std::ostringstream out;
    serializeDfs(root, out);
    return out.str();
}
```

写磁盘时可以直接把字符串写入文件；如果树很大，也可以把 `std::ostream&` 换成文件流，边遍历边写，避免一次性构造完整字符串。

## 3. 反序列化

```cpp
#include <istream>
#include <string>

TreeNode* deserializeDfs(std::istream& in) {
    std::string token;
    if (!(in >> token)) {
        return nullptr;
    }
    if (token == "#") {
        return nullptr;
    }

    TreeNode* root = new TreeNode(std::stoi(token));
    root->left = deserializeDfs(in);
    root->right = deserializeDfs(in);
    return root;
}

TreeNode* deserialize(const std::string& data) {
    std::istringstream in(data);
    return deserializeDfs(in);
}
```

复杂度：序列化和反序列化都访问每个节点一次，时间复杂度 `O(n)`，空间复杂度为递归栈 `O(h)`；如果输出字符串整体保存在内存中，还需要 `O(n)` 额外空间。

## 4. 工程注意事项

1. **格式版本**：磁盘格式要写版本号，便于以后字段扩展。
2. **校验能力**：可以写节点数、校验和或 CRC，避免文件截断后错误重建。
3. **类型长度**：二进制格式要明确 `int32/int64`，不要依赖不同平台的 `sizeof(int)`。
4. **大小端**：跨机器读取时要统一字节序。
5. **深树风险**：极度退化的树可能导致递归栈溢出，可以改成显式栈。
6. **内存释放**：反序列化失败时要释放已经创建的节点，生产代码建议用智能指针或对象池管理。

## 5. 面试回答模板

我会用前序遍历加空节点标记来保存二叉树。序列化时遇到空指针写 `#`，非空节点写值，然后递归写左子树和右子树；反序列化时按同样顺序读取 token，读到 `#` 返回空节点，否则创建节点并递归构造左右孩子。这样能唯一还原任意二叉树，时间 `O(n)`。如果要落磁盘，工程上还要加版本、节点数、校验和和统一字节序，大树可以边遍历边写文件，避免一次性占用大量内存。
