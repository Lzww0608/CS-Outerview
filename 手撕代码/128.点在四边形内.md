# 128. 点在四边形内

给定 4 个点和一个点 `P`，判断 `P` 是否在这 4 个点围成的区域内。面试里要先澄清两个条件：4 个点是否按顺序给出，以及四边形是否保证为凸四边形。不同条件下算法不同。

## 1. 凸四边形：同向叉积

如果 4 个点能构成凸四边形，并且已经按顺时针或逆时针顺序给出，可以用叉积判断 `P` 是否始终在每条边的同一侧。

对边 `A -> B` 和点 `P`：

```text
cross(B - A, P - A)
```

如果四边形顶点是逆时针顺序，那么内部点对每条有向边的叉积都应该 `>= 0`；顺时针则都应该 `<= 0`。如果允许点在边上，使用 `>= 0` / `<= 0`；如果要求严格在内部，使用 `> 0` / `< 0`。

## 2. 顶点无序：先排序

如果 4 个点没有顺序，可以先按中心点极角排序：

1. 计算 4 个点的中心 `C = average(points)`。
2. 按 `atan2(y - C.y, x - C.x)` 排序。
3. 排序后再用同向叉积判断。

这种方法适合 4 个点构成凸多边形的场景。如果点本身是凹四边形或自交四边形，需要使用射线法或先明确业务定义。

## 3. C++ 实现

```cpp
#include <algorithm>
#include <cmath>
#include <vector>

struct Point {
    double x;
    double y;
};

double cross(const Point& a, const Point& b, const Point& c) {
    double x1 = b.x - a.x;
    double y1 = b.y - a.y;
    double x2 = c.x - a.x;
    double y2 = c.y - a.y;
    return x1 * y2 - y1 * x2;
}

bool inConvexQuadrilateral(std::vector<Point> q, const Point& p) {
    if (q.size() != 4) {
        return false;
    }

    Point center{0.0, 0.0};
    for (const auto& pt : q) {
        center.x += pt.x;
        center.y += pt.y;
    }
    center.x /= 4.0;
    center.y /= 4.0;

    std::sort(q.begin(), q.end(), [&](const Point& a, const Point& b) {
        return std::atan2(a.y - center.y, a.x - center.x) <
               std::atan2(b.y - center.y, b.x - center.x);
    });

    const double eps = 1e-9;
    int sign = 0;
    for (int i = 0; i < 4; ++i) {
        const Point& a = q[i];
        const Point& b = q[(i + 1) % 4];
        double c = cross(a, b, p);
        if (std::fabs(c) <= eps) {
            continue; // 在边上，认为在四边形内
        }
        int curSign = c > 0 ? 1 : -1;
        if (sign == 0) {
            sign = curSign;
        } else if (sign != curSign) {
            return false;
        }
    }
    return true;
}
```

## 4. 凹四边形或任意多边形：射线法

如果四边形可能是凹的，可以用射线法：从 `P` 向右发射一条射线，统计它与多边形边的交点次数。交点次数为奇数表示在内部，偶数表示在外部。

```cpp
bool inPolygon(const std::vector<Point>& poly, const Point& p) {
    bool inside = false;
    int n = static_cast<int>(poly.size());
    const double eps = 1e-9;

    for (int i = 0, j = n - 1; i < n; j = i++) {
        const Point& a = poly[j];
        const Point& b = poly[i];

        double area = cross(a, b, p);
        bool onSegment =
            std::fabs(area) <= eps &&
            p.x >= std::min(a.x, b.x) - eps &&
            p.x <= std::max(a.x, b.x) + eps &&
            p.y >= std::min(a.y, b.y) - eps &&
            p.y <= std::max(a.y, b.y) + eps;
        if (onSegment) {
            return true;
        }

        bool intersect = ((a.y > p.y) != (b.y > p.y)) &&
            (p.x < (b.x - a.x) * (p.y - a.y) / (b.y - a.y) + a.x);
        if (intersect) {
            inside = !inside;
        }
    }
    return inside;
}
```

## 5. 易错点

1. 没有确认顶点顺序就直接叉积，可能把正确点判错。
2. 浮点坐标不能直接用 `== 0`，要设置 `eps`。
3. 点在边上算不算“在内部”要先约定。
4. 射线法要避免顶点重复计数，常用 `((a.y > p.y) != (b.y > p.y))` 处理半开区间。
5. 如果 4 个点里有三点共线或重复点，不能构成正常四边形，需要先做输入校验。

## 6. 面试回答模板

我会先问 4 个点是否已经按顺时针或逆时针给出，以及四边形是否保证凸。如果是凸四边形，按顺序遍历每条边，用叉积判断点是否始终在同一侧，时间复杂度 `O(1)`。如果 4 个点无序，先按中心点极角排序再判断。如果可能是凹多边形或任意多边形，就用射线法或 winding number；工程实现要处理边界点、浮点误差、重复点和三点共线。
