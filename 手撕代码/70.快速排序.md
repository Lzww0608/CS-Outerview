# 快速排序

题目：手写快速排序。

## 1. 思路

快速排序是分治算法：

1. 选择一个 pivot。
2. 通过 partition 把数组划分为 `< pivot` 和 `> pivot` 两侧。
3. 递归排序左右区间。

为了降低有序数组导致退化的风险，面试手写可以使用随机 pivot。

## 2. 二路快排实现

```cpp
#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

int partition(vector<int>& nums, int left, int right) {
    int pivotIndex = left + rand() % (right - left + 1);
    swap(nums[pivotIndex], nums[right]);

    int pivot = nums[right];
    int store = left;

    for (int i = left; i < right; ++i) {
        if (nums[i] < pivot) {
            swap(nums[store], nums[i]);
            ++store;
        }
    }

    swap(nums[store], nums[right]);
    return store;
}

void quickSort(vector<int>& nums, int left, int right) {
    if (left >= right) {
        return;
    }

    int mid = partition(nums, left, right);
    quickSort(nums, left, mid - 1);
    quickSort(nums, mid + 1, right);
}

void quickSort(vector<int>& nums) {
    if (!nums.empty()) {
        quickSort(nums, 0, static_cast<int>(nums.size()) - 1);
    }
}
```

这个版本逻辑清晰，但重复元素很多时可能划分不均。

## 3. 三路快排

如果数组中重复元素很多，三路快排更稳定。它把区间划分为：

```text
< pivot | == pivot | > pivot
```

```cpp
#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

void quickSort3Way(vector<int>& a, int left, int right) {
    if (left >= right) {
        return;
    }

    int pivotIndex = left + rand() % (right - left + 1);
    swap(a[left], a[pivotIndex]);
    int pivot = a[left];

    int lt = left;      // a[left + 1..lt] < pivot
    int gt = right + 1; // a[gt..right] > pivot
    int i = left + 1;   // a[lt + 1..i - 1] == pivot

    while (i < gt) {
        if (a[i] < pivot) {
            swap(a[++lt], a[i++]);
        } else if (a[i] > pivot) {
            swap(a[i], a[--gt]);
        } else {
            ++i;
        }
    }

    swap(a[left], a[lt]);

    quickSort3Way(a, left, lt - 1);
    quickSort3Way(a, gt, right);
}
```

## 4. 复杂度

| 情况 | 时间复杂度 | 原因 |
| --- | --- | --- |
| 最好 | `O(n log n)` | 每次划分接近均分 |
| 平均 | `O(n log n)` | 随机 pivot 下期望递归深度为 `log n` |
| 最坏 | `O(n^2)` | 每次 pivot 都选到极端值 |

空间复杂度来自递归栈：

1. 平均 `O(log n)`。
2. 最坏 `O(n)`。

## 5. 工程优化

1. **随机 pivot / 三数取中**：降低有序输入退化风险。
2. **三路快排**：处理大量重复元素。
3. **小区间插入排序**：小数组上插入排序常数更低。
4. **尾递归优化**：优先递归短区间，长区间用循环，控制栈深度。
5. **内省排序**：递归过深时切堆排序，C++ `std::sort` 常用这种思路。

## 6. 易错点

1. partition 返回位置后，不要把 pivot 所在位置再次纳入递归。
2. 普通原地快排不稳定。
3. 有大量重复值时，二路 partition 可能退化。
4. 随机 pivot 需要注意区间边界。
5. 面试手写要先处理空数组，避免 `size() - 1` 下溢。

## 7. 面试回答模板

快排是分治排序：选 pivot，partition 后递归排左右区间。平均时间复杂度 `O(n log n)`，最坏 `O(n^2)`，空间复杂度平均 `O(log n)`。为避免有序数组退化，可以随机选 pivot 或三数取中；重复元素多时用三路快排；工程中的 `std::sort` 通常用内省排序，在递归过深时切换堆排序保证最坏复杂度。
