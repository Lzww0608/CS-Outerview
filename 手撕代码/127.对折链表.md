# 127. 对折链表

对折链表通常指把链表后半部分反转后，与前半部分交替合并。例如：

```text
1 -> 2 -> 3 -> 4 -> 5
```

对折后变成：

```text
1 -> 5 -> 2 -> 4 -> 3
```

这类题常追问 `mid` 怎么找，本质是快慢指针找中点、反转后半段、再交替合并。

## 1. 核心思路

1. 用快慢指针找到链表中点。
2. 从中点之后断开链表，把后半部分反转。
3. 依次从前半部分和反转后的后半部分各取一个节点合并。

奇数长度时，中间节点留在前半部分末尾；偶数长度时，前后两半长度相同。

## 2. 代码实现

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

class Solution {
public:
    void foldList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return;
        }

        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        ListNode* second = slow->next;
        slow->next = nullptr;

        second = reverse(second);

        ListNode* first = head;
        while (second != nullptr) {
            ListNode* nextFirst = first->next;
            ListNode* nextSecond = second->next;

            first->next = second;
            second->next = nextFirst;

            first = nextFirst;
            second = nextSecond;
        }
    }

private:
    ListNode* reverse(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
};
```

## 3. 中点选择

上面循环条件是：

```cpp
while (fast->next != nullptr && fast->next->next != nullptr)
```

这样 `slow` 会停在前半部分的最后一个节点：

1. `1 -> 2 -> 3 -> 4 -> 5` 中，`slow` 停在 `3`。
2. `1 -> 2 -> 3 -> 4` 中，`slow` 停在 `2`。

这种写法方便直接从 `slow->next` 开始反转后半段，并用 `slow->next = nullptr` 断开，避免合并时形成环。

## 4. 易错点

1. 找到中点后必须断开前后两段，否则交替合并容易形成环。
2. 合并前要先保存 `nextFirst` 和 `nextSecond`，否则指针改写后会丢失剩余链表。
3. 奇数长度时，中间节点不需要移动；偶数长度时，两段长度一致。
4. 如果题目要求返回新头节点，头节点仍然是原来的 `head`。
5. 如果题目说“判断回文链表”，也是类似流程，但比较后通常要把后半段恢复，避免破坏输入。

## 5. 复杂度

1. 时间复杂度：`O(n)`，找中点、反转、合并都只遍历常数次。
2. 空间复杂度：`O(1)`，只使用若干指针。

## 6. 面试回答模板

对折链表我会先用快慢指针找到前半部分尾节点，然后断开链表并反转后半部分，最后把两个链表按一个前半节点、一个后半节点的顺序交替合并。中点写法要明确：偶数长度停在前半最后一个节点，奇数长度停在中间节点。实现里最容易错的是忘记断链导致成环，以及合并时没有提前保存 next 指针。
