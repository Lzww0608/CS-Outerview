# 实现 unique_ptr

`unique_ptr` 的核心语义是独占所有权：同一时刻只能有一个智能指针负责释放资源。它不需要引用计数，重点是删除拷贝、支持移动、析构自动释放。

## 实现思路

1. 用 `T* ptr_` 保存被管理对象。
2. 析构时释放 `ptr_`。
3. 删除拷贝构造和拷贝赋值，避免两个对象重复释放。
4. 移动构造把对方指针拿过来，并把对方置空。
5. 移动赋值先释放当前资源，再接管对方资源。
6. 提供 `get()`、`release()`、`reset()`、`operator*`、`operator->`、`operator bool()` 等接口。

## 代码

```cpp
#include <utility>

template <typename T>
class UniquePtr {
public:
    explicit UniquePtr(T* ptr = nullptr) noexcept : ptr_(ptr) {}

    ~UniquePtr() {
        delete ptr_;
    }

    UniquePtr(const UniquePtr&) = delete;
    UniquePtr& operator=(const UniquePtr&) = delete;

    UniquePtr(UniquePtr&& other) noexcept : ptr_(other.ptr_) {
        other.ptr_ = nullptr;
    }

    UniquePtr& operator=(UniquePtr&& other) noexcept {
        if (this == &other) {
            return *this;
        }
        reset();
        ptr_ = other.ptr_;
        other.ptr_ = nullptr;
        return *this;
    }

    T& operator*() const {
        return *ptr_;
    }

    T* operator->() const noexcept {
        return ptr_;
    }

    explicit operator bool() const noexcept {
        return ptr_ != nullptr;
    }

    T* get() const noexcept {
        return ptr_;
    }

    T* release() noexcept {
        T* old = ptr_;
        ptr_ = nullptr;
        return old;
    }

    void reset(T* ptr = nullptr) noexcept {
        if (ptr_ == ptr) {
            return;
        }
        delete ptr_;
        ptr_ = ptr;
    }

    void swap(UniquePtr& other) noexcept {
        std::swap(ptr_, other.ptr_);
    }

private:
    T* ptr_ = nullptr;
};
```

## 复杂度

1. 构造、析构、移动、`get()`、`release()`、`reset()` 都是 `O(1)`。
2. 空间复杂度通常是 `O(1)`，单对象无状态删除器版本一般只需要一个指针大小。

## 易错点

1. 移动后必须把源对象置空，否则两个 `UniquePtr` 会释放同一指针。
2. 移动赋值要处理自移动，至少不能先释放再读取同一个对象的指针。
3. `release()` 不释放资源，只返回裸指针并放弃所有权，调用方要负责后续释放。
4. `reset(ptr_)` 如果不判断同一指针，可能先 delete 再继续保存悬空指针。
5. 这个简化版只支持 `delete` 单对象，不支持 `delete[]`、自定义删除器、空基类优化和不完整类型的复杂标准库细节。

## 面试回答模板

手写 `unique_ptr` 时先说明它是独占所有权，不需要控制块和引用计数。类里保存一个裸指针，析构时 delete；拷贝构造和拷贝赋值删除；移动构造和移动赋值转移指针并把源对象置空；再补 `get/release/reset/operator*/operator->`。标准库版本还会处理数组特化、自定义删除器、异常安全和对象大小优化。
