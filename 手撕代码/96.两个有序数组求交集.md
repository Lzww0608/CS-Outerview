# 96. 两个有序数组求交集

## 题目

给两个很大的有序数组，求它们的交集。面试要先确认：

1. 数组是升序还是降序。
2. 交集是否去重。
3. 数据能否全部放进内存。
4. 输出是否也可能很大，需要流式写出。

## 内存可放下：双指针

如果两个数组都已经有序，双指针是最直接做法：

```cpp
#include <vector>
using namespace std;

vector<int> intersectionSorted(const vector<int>& a, const vector<int>& b) {
    vector<int> ans;
    int i = 0;
    int j = 0;

    while (i < static_cast<int>(a.size()) && j < static_cast<int>(b.size())) {
        if (a[i] == b[j]) {
            if (ans.empty() || ans.back() != a[i]) {
                ans.push_back(a[i]);
            }
            ++i;
            ++j;
        } else if (a[i] < b[j]) {
            ++i;
        } else {
            ++j;
        }
    }
    return ans;
}
```

复杂度：

```text
时间复杂度: O(n + m)
额外空间: O(1)，不计输出
```

如果要求保留重复次数，例如 `a = [1,2,2]`、`b = [2,2,2]` 输出 `[2,2]`，则命中相等时不要做 `ans.back()` 去重。

## 一个大一个小：二分查找

如果一个数组很小，另一个数组非常大，可以遍历小数组，在大数组中二分查找：

```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<int> intersectionByBinarySearch(const vector<int>& small,
                                       const vector<int>& large) {
    vector<int> ans;
    for (int x : small) {
        if (!ans.empty() && ans.back() == x) {
            continue;
        }
        if (binary_search(large.begin(), large.end(), x)) {
            ans.push_back(x);
        }
    }
    return ans;
}
```

复杂度是 `O(min(n,m) * log(max(n,m)))`，适合两边规模差距很大的场景。

## 超大文件：流式归并

如果两个数组来自磁盘文件或远程存储，不能全部加载内存，但都已经排序，可以使用流式双指针：

1. 每个文件维护一个顺序读取缓冲区。
2. 比较当前元素，小的一边继续读下一个。
3. 相等时输出交集元素，并推进两边。
4. 输出也使用缓冲写，避免把结果全部留在内存。

这种方式只需要 `O(buffer_size)` 内存，顺序 I/O 友好。真实系统里还要关注压缩格式是否支持顺序读取、网络拉取是否需要预取、输出是否需要去重。

## 易错点

1. 已排序数据不要先放哈希表，双指针更省内存。
2. 去重交集和保留重复次数是两个不同题。
3. 超大文件场景要考虑输出也可能超大。
4. 如果两个数组排序方向不同，先统一比较逻辑，或者从一个数组末尾开始扫。

## 面试回答模板

两个有序数组求交集优先用双指针，谁小谁后移，相等就输出并同时后移，时间 `O(n+m)`，额外空间 `O(1)`。如果一个数组很小、另一个很大，可以遍历小数组对大数组二分。若数据大到不能进内存，就把两个有序文件当作流做归并扫描，每边只保留读缓冲区，结果流式写出。
