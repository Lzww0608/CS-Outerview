# 118. 单词搜索 II

## 题目

给定字符矩阵 `board` 和单词列表 `words`，返回所有能在矩阵中通过上下左右相邻路径拼出的单词。对应 LeetCode 212。

## 思路

直接对每个单词 DFS 会重复搜索大量前缀。优化方式是先把 `words` 建成 Trie，然后从每个格子 DFS：

1. 当前字符不在 Trie 子节点中，立即剪枝。
2. 到达某个 Trie 节点的 `word` 不为空，说明找到一个单词。
3. 用原地标记避免同一路径重复使用格子。

## 代码

```cpp
#include <string>
#include <vector>
using namespace std;

struct TrieNode {
    TrieNode* next[26]{};
    string word;
};

class Solution {
public:
    vector<string> findWords(vector<vector<char>>& board, vector<string>& words) {
        root_ = new TrieNode();
        for (const auto& w : words) insert(w);

        rows_ = board.size();
        cols_ = board.empty() ? 0 : board[0].size();
        for (int r = 0; r < rows_; ++r) {
            for (int c = 0; c < cols_; ++c) {
                dfs(board, r, c, root_);
            }
        }
        return ans_;
    }

private:
    void insert(const string& s) {
        TrieNode* cur = root_;
        for (char ch : s) {
            int idx = ch - 'a';
            if (!cur->next[idx]) cur->next[idx] = new TrieNode();
            cur = cur->next[idx];
        }
        cur->word = s;
    }

    void dfs(vector<vector<char>>& board, int r, int c, TrieNode* node) {
        if (r < 0 || r >= rows_ || c < 0 || c >= cols_) return;
        char ch = board[r][c];
        if (ch == '#') return;
        TrieNode* next = node->next[ch - 'a'];
        if (!next) return;

        if (!next->word.empty()) {
            ans_.push_back(next->word);
            next->word.clear(); // 去重
        }

        board[r][c] = '#';
        dfs(board, r + 1, c, next);
        dfs(board, r - 1, c, next);
        dfs(board, r, c + 1, next);
        dfs(board, r, c - 1, next);
        board[r][c] = ch;
    }

    TrieNode* root_{nullptr};
    int rows_{0};
    int cols_{0};
    vector<string> ans_;
};
```

## 易错点

1. 找到单词后要去重，否则不同路径可能重复加入。
2. DFS 要恢复现场。
3. Trie 剪枝是这题通过大数据的关键。
4. 生产代码要管理 Trie 内存，面试手撕可说明用智能指针或统一释放。
