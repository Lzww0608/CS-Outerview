# 电话号码区号快速查找

题目：给定电话号码，需要快速找到它对应的地区区号。区号长度可能不同，例如 `010`、`021`、`0755`。

## 1. 问题本质

区号匹配通常是“最长前缀匹配”：

```text
号码: 075512345678
候选区号: 075, 0755
应该匹配 0755，而不是 075
```

如果区号表很小，直接枚举所有区号并判断前缀即可；如果区号很多、查询频繁，应使用 Trie 或按长度分组的 HashMap。

## 2. Trie 实现

Trie 每条边是一位数字，节点上保存“到这里是否形成一个区号”以及地区信息。查询时沿电话号码逐位向下走，记录最后一次命中的地区，直到走不下去。

```cpp
#include <array>
#include <string>
#include <vector>

struct TrieNode {
    std::array<int, 10> next{};
    int areaId = -1;

    TrieNode() {
        next.fill(-1);
    }
};

class AreaCodeTrie {
public:
    AreaCodeTrie() {
        nodes_.push_back(TrieNode{});
    }

    void insert(const std::string& code, int areaId) {
        int cur = 0;
        for (char ch : code) {
            int d = ch - '0';
            if (nodes_[cur].next[d] == -1) {
                nodes_[cur].next[d] = static_cast<int>(nodes_.size());
                nodes_.push_back(TrieNode{});
            }
            cur = nodes_[cur].next[d];
        }
        nodes_[cur].areaId = areaId;
    }

    int query(const std::string& phone) const {
        int cur = 0;
        int ans = -1;
        for (char ch : phone) {
            if (ch < '0' || ch > '9') {
                break;
            }
            int d = ch - '0';
            if (nodes_[cur].next[d] == -1) {
                break;
            }
            cur = nodes_[cur].next[d];
            if (nodes_[cur].areaId != -1) {
                ans = nodes_[cur].areaId;
            }
        }
        return ans;
    }

private:
    std::vector<TrieNode> nodes_;
};
```

查询复杂度是 `O(L)`，`L` 是电话号码长度或最长区号长度；空间复杂度和所有区号的总长度相关。

## 3. 按长度分组的 HashMap

如果区号长度范围很小，例如只可能是 3 或 4 位，可以按长度从大到小截取前缀并查 HashMap：

这种实现更简单，查询复杂度约为 `O(区号长度种类数)`，适合区号长度范围固定且数据规模不大的业务。

## 4. 易错点

1. 要做最长前缀匹配，不能找到第一个前缀就返回。
2. 电话号码可能带 `+86`、空格、短横线，查询前要归一化。
3. 区号表会更新时，可以离线构建新 Trie 后原子替换，避免在线更新影响查询。
4. 如果地区规则不只是前缀，还包含运营商号段、携号转网等因素，单纯区号 Trie 不够，需要规则引擎或数据库补充。

## 5. 面试回答模板

这题可以建 Trie 做最长前缀匹配。把所有区号按数字插入 Trie，节点上保存地区 ID。查询电话号码时从根开始逐位走，过程中记录最后一次命中的地区，走不下去时返回这个最后命中值。这样可以正确处理不同长度区号的包含关系，查询复杂度是 `O(最长区号长度)`。如果区号长度种类很少，也可以按长度从大到小截前缀，用 HashMap 查询。
