# 23. 最多包含 K 种字符的最长子串

## 题目

给定字符串 `s` 和整数 `k`，求最多包含 `k` 种不同字符的最长子串长度。

## 思路：滑动窗口

维护窗口 `[left, right]`，用哈希表统计窗口内字符频次。

1. 右指针不断扩张。
2. 如果不同字符数量超过 `k`，移动左指针并减少频次。
3. 每次窗口合法时更新答案。

## 代码

```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
using namespace std;

int lengthOfLongestSubstringKDistinct(const string& s, int k) {
    if (k <= 0) {
        return 0;
    }

    unordered_map<char, int> count;
    int ans = 0;
    int left = 0;

    for (int right = 0; right < static_cast<int>(s.size()); ++right) {
        ++count[s[right]];

        while (static_cast<int>(count.size()) > k) {
            char c = s[left++];
            --count[c];
            if (count[c] == 0) {
                count.erase(c);
            }
        }

        ans = max(ans, right - left + 1);
    }

    return ans;
}
```

如果字符集固定为 ASCII，可以用数组替代哈希表：

```cpp
int cnt[256] = {};
```

并用一个变量维护当前不同字符数，性能更稳定。

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(min(n, charset))
```

每个字符最多被右指针加入一次、左指针移出一次。

## 易错点

1. `k <= 0` 时答案是 0。
2. 收缩窗口时，频次降为 0 要从哈希表删除。
3. 题目是“最多 k 种”，不是“恰好 k 种”。
4. 如果输入包含中文或 Unicode，不能简单按 `char` 处理，需要按 code point 或业务字符切分。
