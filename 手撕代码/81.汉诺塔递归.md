# 汉诺塔递归

题目：有 `n` 个盘子从小到大叠在柱子 `A` 上，借助柱子 `B`，把所有盘子移动到柱子 `C`。每次只能移动一个盘子，且大盘不能压在小盘上。

## 1. 递归思路

把 `n` 个盘子从 `A` 移到 `C`，可以拆成三步：

1. 先把上面的 `n - 1` 个盘子从 `A` 移到 `B`，借助 `C`。
2. 把最大的第 `n` 个盘子从 `A` 移到 `C`。
3. 再把 `n - 1` 个盘子从 `B` 移到 `C`，借助 `A`。

递归终止条件：

1. `n == 0`：没有盘子，不需要移动。
2. `n == 1`：直接从源柱移动到目标柱。

## 2. 代码实现

```cpp
#include <iostream>

void hanoi(int n, char from, char aux, char to) {
    if (n <= 0) {
        return;
    }

    hanoi(n - 1, from, to, aux);
    std::cout << "move disk " << n << " from " << from << " to " << to << '\n';
    hanoi(n - 1, aux, from, to);
}

int main() {
    hanoi(3, 'A', 'B', 'C');
    return 0;
}
```

输出示例：

```text
move disk 1 from A to C
move disk 2 from A to B
move disk 1 from C to B
move disk 3 from A to C
move disk 1 from B to A
move disk 2 from B to C
move disk 1 from A to C
```

## 3. 复杂度

移动次数满足：

```text
T(n) = 2 * T(n - 1) + 1
T(1) = 1
```

因此：

```text
T(n) = 2^n - 1
```

复杂度：

1. 时间复杂度：`O(2^n)`。
2. 递归栈空间：`O(n)`。

## 4. 易错点

1. 参数顺序要清楚：`from` 是源柱，`aux` 是辅助柱，`to` 是目标柱。
2. 第一步和第三步的辅助柱、目标柱会交换，写错会导致移动序列非法。
3. `n <= 0` 应直接返回，避免无限递归。
4. 汉诺塔的最优移动次数是固定的 `2^n - 1`，无法用贪心减少。

## 5. 面试回答模板

汉诺塔用递归。要把 `n` 个盘子从 `A` 移到 `C`，先把 `n - 1` 个从 `A` 移到 `B`，再把最大盘从 `A` 移到 `C`，最后把 `n - 1` 个从 `B` 移到 `C`。递归出口是 `n <= 0` 或 `n == 1`。移动次数满足 `T(n)=2T(n-1)+1`，所以总次数是 `2^n-1`，时间复杂度 `O(2^n)`，递归栈 `O(n)`。
