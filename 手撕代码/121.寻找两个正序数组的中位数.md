# 121. 寻找两个正序数组的中位数

## 题目

给定两个正序数组 `a`、`b`，求合并后的中位数，要求 `O(log(m+n))`。对应 LeetCode 4。

## 思路

在较短数组上二分切分位置 `i`，另一个数组切分位置为 `j = half - i`。希望左半边元素个数等于右半边，并满足：

```text
a[i-1] <= b[j]
b[j-1] <= a[i]
```

此时左半最大值和右半最小值可以直接计算中位数。

## 代码

```cpp
#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

double findMedianSortedArrays(vector<int>& a, vector<int>& b) {
    if (a.size() > b.size()) return findMedianSortedArrays(b, a);

    int m = a.size();
    int n = b.size();
    int half = (m + n + 1) / 2;
    int left = 0, right = m;

    while (left <= right) {
        int i = left + (right - left) / 2;
        int j = half - i;

        int aLeft = (i == 0 ? INT_MIN : a[i - 1]);
        int aRight = (i == m ? INT_MAX : a[i]);
        int bLeft = (j == 0 ? INT_MIN : b[j - 1]);
        int bRight = (j == n ? INT_MAX : b[j]);

        if (aLeft <= bRight && bLeft <= aRight) {
            if ((m + n) % 2 == 1) {
                return max(aLeft, bLeft);
            }
            return (static_cast<double>(max(aLeft, bLeft)) + min(aRight, bRight)) / 2.0;
        } else if (aLeft > bRight) {
            right = i - 1;
        } else {
            left = i + 1;
        }
    }
    return 0.0;
}
```

## 易错点

1. 必须在短数组上二分，保证 `j` 不越界。
2. 总长度为奇数时，左半边多一个元素。
3. 边界用正负无穷处理空切分。
4. 两个 `int` 求平均要先转成 `double` 或 `long long`。
