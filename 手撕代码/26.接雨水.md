# 接雨水

题目：给定非负整数数组 `height`，每个元素表示柱子高度，计算下雨后能接多少水。

## 做法一：前后缀最大值

每个位置能接的水取决于左右两边最高柱子的较小值：

```text
water[i] = min(leftMax[i], rightMax[i]) - height[i]
```

代码：

```cpp
#include <algorithm>
#include <vector>

int trap(std::vector<int>& height) {
    int n = static_cast<int>(height.size());
    if (n < 3) {
        return 0;
    }

    std::vector<int> leftMax(n), rightMax(n);
    leftMax[0] = height[0];
    for (int i = 1; i < n; ++i) {
        leftMax[i] = std::max(leftMax[i - 1], height[i]);
    }

    rightMax[n - 1] = height[n - 1];
    for (int i = n - 2; i >= 0; --i) {
        rightMax[i] = std::max(rightMax[i + 1], height[i]);
    }

    int ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += std::min(leftMax[i], rightMax[i]) - height[i];
    }
    return ans;
}
```

复杂度：时间 `O(n)`，空间 `O(n)`。

## 做法二：双指针

前后缀数组可以压缩成两个变量 `leftMax` 和 `rightMax`。每次移动较矮的一边，因为较矮边的上界已经被另一边保证。

```cpp
#include <algorithm>
#include <vector>

int trap(std::vector<int>& height) {
    int left = 0;
    int right = static_cast<int>(height.size()) - 1;
    int leftMax = 0;
    int rightMax = 0;
    int ans = 0;

    while (left < right) {
        leftMax = std::max(leftMax, height[left]);
        rightMax = std::max(rightMax, height[right]);

        if (leftMax < rightMax) {
            ans += leftMax - height[left];
            ++left;
        } else {
            ans += rightMax - height[right];
            --right;
        }
    }

    return ans;
}
```

复杂度：时间 `O(n)`，空间 `O(1)`。

## 做法三：单调栈

维护一个单调递减栈。遇到更高柱子时，说明形成了右边界，可以弹出底部计算凹槽面积。

```cpp
#include <algorithm>
#include <stack>
#include <vector>

int trap(std::vector<int>& height) {
    std::stack<int> st;
    int ans = 0;

    for (int i = 0; i < static_cast<int>(height.size()); ++i) {
        while (!st.empty() && height[i] > height[st.top()]) {
            int bottom = st.top();
            st.pop();
            if (st.empty()) {
                break;
            }

            int left = st.top();
            int width = i - left - 1;
            int boundedHeight = std::min(height[left], height[i]) - height[bottom];
            ans += width * boundedHeight;
        }
        st.push(i);
    }

    return ans;
}
```

复杂度：时间 `O(n)`，空间 `O(n)`。

## 易错点

1. 两端位置不能接水，因为缺少一侧边界。
2. 双指针移动较矮的一侧，不是随便移动。
3. 单调栈计算宽度时是 `i - left - 1`。
4. 高度差可能为 0，相等高度可以入栈，不影响正确性。

## 面试回答模板

接雨水可以用三种做法。前后缀最大值最直观，每个位置接水量是 `min(左侧最高, 右侧最高) - 当前高度`，时间 `O(n)`、空间 `O(n)`。双指针把前后缀压缩成 `leftMax/rightMax`，每次移动较矮的一侧，时间 `O(n)`、空间 `O(1)`。单调栈维护递减柱子，遇到右边界时弹出底部计算凹槽面积，时间 `O(n)`、空间 `O(n)`。
