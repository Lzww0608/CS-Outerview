# 120. 戳气球

## 题目

给定气球分数数组 `nums`。戳破第 `i` 个气球得分为 `nums[left] * nums[i] * nums[right]`，其中 `left/right` 是当前相邻未戳破气球。求最大得分。对应 LeetCode 312。

## 思路

正向考虑“先戳哪个”会导致相邻关系不断变化。反过来考虑区间里“最后戳哪个”。

在两端补 `1`，设 `dp[l][r]` 表示开区间 `(l, r)` 内气球全部戳破的最大得分。枚举最后戳破的气球 `k`：

```text
dp[l][r] = max(dp[l][k] + val[l] * val[k] * val[r] + dp[k][r])
```

## 代码

```cpp
#include <algorithm>
#include <vector>
using namespace std;

int maxCoins(vector<int>& nums) {
    int n = nums.size();
    vector<int> val(n + 2, 1);
    for (int i = 0; i < n; ++i) val[i + 1] = nums[i];

    vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
    for (int len = 2; len <= n + 1; ++len) {
        for (int l = 0; l + len <= n + 1; ++l) {
            int r = l + len;
            for (int k = l + 1; k < r; ++k) {
                dp[l][r] = max(dp[l][r], dp[l][k] + val[l] * val[k] * val[r] + dp[k][r]);
            }
        }
    }
    return dp[0][n + 1];
}
```

## 复杂度

```text
时间复杂度: O(n^3)
空间复杂度: O(n^2)
```

## 易错点

1. `dp[l][r]` 是开区间，不包含两端。
2. 枚举的是最后戳破的气球，不是第一个。
3. 两端补 1 后答案是 `dp[0][n+1]`。
