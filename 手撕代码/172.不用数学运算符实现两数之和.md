# 172. 不用数学运算符实现两数之和

题目：不使用 `+`、`-`、`*`、`/` 等数学运算符，计算两个整数之和。对应 LeetCode 371。

这题和“数组两数之和”不同，考察的是补码、位运算和进位传播。

## 1. 核心思路

二进制加法可以拆成两部分：

1. **无进位和**：`a ^ b`，相同位相加后只保留当前位。
2. **进位**：`(a & b) << 1`，两个 1 相加产生进位，进位要加到更高一位。

然后把“无进位和”和“进位”继续相加，直到进位为 0。

```text
a + b
= (a ^ b) + ((a & b) << 1)
```

示例：

```text
a = 5  = 0101
b = 3  = 0011

sum   = a ^ b        = 0110
carry = (a & b) << 1 = 0010

继续加 0110 和 0010：
sum   = 0100
carry = 0100

继续加 0100 和 0100：
sum   = 0000
carry = 1000

继续加 0000 和 1000：
sum   = 1000
carry = 0000

答案 = 8
```

## 2. C++ 实现

C++ 中对有符号负数左移可能触发未定义行为，所以建议转成无符号数做位运算，再转回 `int`。

```cpp
int getSum(int a, int b) {
    unsigned x = static_cast<unsigned>(a);
    unsigned y = static_cast<unsigned>(b);

    while (y != 0) {
        unsigned carry = (x & y) << 1;
        x = x ^ y;
        y = carry;
    }

    return static_cast<int>(x);
}
```

复杂度：

```text
时间复杂度: O(w)，w 是整数位数，32 位 int 最多循环 32 次
空间复杂度: O(1)
```

## 3. Python 实现注意点

Python 的整数不是固定 32 位，负数会表现成“无限符号位”，所以要手动做 32 位 mask。

```python
def getSum(a: int, b: int) -> int:
    mask = 0xffffffff
    max_int = 0x7fffffff

    a &= mask
    b &= mask

    while b:
        carry = ((a & b) << 1) & mask
        a = (a ^ b) & mask
        b = carry

    return a if a <= max_int else ~(a ^ mask)
```

## 4. 易错点

1. `a ^ b` 只是无进位结果，不是最终答案。
2. 进位必须左移一位：`(a & b) << 1`。
3. 循环条件是进位不为 0，而不是两个数都不为 0。
4. C++ 不要直接左移负数，先转成 `unsigned` 更稳。
5. Python 要做固定宽度 mask，否则负数场景会死循环或结果异常。

## 5. 面试回答模板

不用数学运算符求和，可以把加法拆成无进位和进位两部分。`a ^ b` 得到每一位相加但不处理进位的结果，`(a & b) << 1` 得到需要加到高一位的进位。然后把这两个结果继续重复这个过程，直到进位为 0。C++ 里要注意有符号负数左移的未定义行为，所以通常转成 `unsigned` 做位运算，最后再转回 `int`。
