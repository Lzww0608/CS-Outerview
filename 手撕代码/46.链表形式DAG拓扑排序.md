# 链表形式 DAG 拓扑排序

题目：给一个链表形式的有向无环图，求拓扑排序。这里“链表形式”通常表示邻接表：每个点挂一条链表，链表中存储从该点出发的边。

拓扑排序适用于有向无环图。若图中有环，无法得到包含所有节点的拓扑序。

## 1. 邻接链表结构

一种常见输入结构：

```cpp
struct Edge {
    int to;
    Edge* next;
};

struct Vertex {
    Edge* head = nullptr;
};
```

`graph[u].head` 指向 u 的出边链表。

## 2. Kahn 算法

步骤：

1. 扫描所有邻接链表，统计每个点入度。
2. 把入度为 0 的点放入队列。
3. 每次弹出一个点加入答案，遍历它的出边，把后继节点入度减 1。
4. 后继节点入度变为 0 时入队。
5. 如果最终答案数量小于节点数，说明存在环或输入不完整。

```cpp
#include <queue>
#include <stdexcept>
#include <vector>
using namespace std;

struct Edge {
    int to;
    Edge* next;
};

struct Vertex {
    Edge* head = nullptr;
};

vector<int> topoSortLinkedGraph(const vector<Vertex>& graph) {
    int n = graph.size();
    vector<int> indeg(n, 0);

    for (int u = 0; u < n; ++u) {
        for (Edge* e = graph[u].head; e != nullptr; e = e->next) {
            if (e->to < 0 || e->to >= n) {
                throw invalid_argument("invalid edge");
            }
            ++indeg[e->to];
        }
    }

    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (indeg[i] == 0) {
            q.push(i);
        }
    }

    vector<int> order;
    order.reserve(n);

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (Edge* e = graph[u].head; e != nullptr; e = e->next) {
            if (--indeg[e->to] == 0) {
                q.push(e->to);
            }
        }
    }

    if (static_cast<int>(order.size()) != n) {
        throw runtime_error("graph has cycle");
    }
    return order;
}
```

复杂度：

1. 时间复杂度：`O(V + E)`。
2. 空间复杂度：`O(V)`，用于入度数组、队列和结果。

## 3. 易错点

1. 只遍历链表不能得到拓扑序，必须先统计入度。
2. 图可能有多个入度为 0 的点，拓扑序不唯一。
3. 如果最终没有输出所有点，说明不是 DAG，不能硬返回部分结果。
4. 如果节点编号不是 `0~n-1`，要先做 ID 压缩或用哈希表维护入度。

## 4. 面试回答模板

链表形式的有向图本质是邻接表。拓扑排序可以用 Kahn 算法：先扫描所有链表统计入度，把入度为 0 的节点入队；每弹出一个节点就遍历它的出边，把后继入度减一，变成 0 再入队。最后如果输出节点数等于总节点数，就是合法拓扑序；否则图里有环。复杂度 `O(V+E)`。
