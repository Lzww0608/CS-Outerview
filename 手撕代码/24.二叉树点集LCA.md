# 24. 二叉树点集 LCA

## 题目

给定一棵二叉树和一个节点集合，求集合内所有节点的最近公共祖先 LCA。

这是两个节点 LCA 的推广版本。

## 思路

递归遍历整棵树，每个子树返回：

1. 当前子树中找到了多少个目标节点。
2. 如果已经找到覆盖全部目标节点的最低祖先，则返回该祖先。

当某个节点的左右子树和自身合计覆盖全部目标节点时，第一个满足条件的节点就是答案。

## 代码

```cpp
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

struct Result {
    TreeNode* lca;
    int found;
};

Result dfs(TreeNode* root, const unordered_set<TreeNode*>& targets, int total) {
    if (root == nullptr) {
        return {nullptr, 0};
    }

    Result left = dfs(root->left, targets, total);
    if (left.lca != nullptr) {
        return left;
    }

    Result right = dfs(root->right, targets, total);
    if (right.lca != nullptr) {
        return right;
    }

    int found = left.found + right.found + (targets.count(root) ? 1 : 0);
    if (found == total) {
        return {root, found};
    }
    return {nullptr, found};
}

TreeNode* lcaOfSet(TreeNode* root, const vector<TreeNode*>& nodes) {
    unordered_set<TreeNode*> targets(nodes.begin(), nodes.end());
    if (targets.empty()) {
        return nullptr;
    }
    return dfs(root, targets, static_cast<int>(targets.size())).lca;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(h + m)
```

`n` 是树节点数，`h` 是树高，`m` 是目标集合大小。

## 易错点

1. 目标集合可能包含祖先节点本身，此时祖先就是 LCA。
2. 要确认目标节点是否一定存在于树中；如果不一定存在，需要检查 `found == targets.size()`。
3. 如果输入给的是节点值而不是节点指针，要先处理重复值问题。
4. BST 的 LCA 可以利用大小关系优化，但普通二叉树不能。
