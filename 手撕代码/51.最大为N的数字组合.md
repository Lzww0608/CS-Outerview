# 最大为 N 的数字组合

题目常见表述：给定一个数字集合 `digits` 和一个上界 `N`，求能组成多少个不大于 `N` 的正整数。数字可以重复使用，通常不允许数字有前导零。

这个题也可能被追问成“构造一个不超过 `N` 的最大数字”。两种问法都可以用数位 DP 或前缀计数思想解决。

## 1. 计数思路

设 `N` 的十进制长度为 `m`，数字集合大小为 `d`。

分两部分统计：

1. 长度小于 `m` 的所有合法数字。
2. 长度等于 `m` 且字典序不超过 `N` 的数字。

对于长度等于 `m` 的部分，从高位到低位扫描 `N`：

1. 当前位是 `cur`。
2. 统计 `digits` 中比 `cur` 小、且当前位可放的数字个数 `less`。
3. 如果当前位选一个更小数字，后面所有位都可以任意选，所以贡献 `less * d^(remaining)`。
4. 如果 `cur` 在 `digits` 中，继续看下一位。
5. 如果 `cur` 不在 `digits` 中，说明无法继续保持前缀相等，直接结束。
6. 如果所有位都匹配，最后把 `N` 自身计入答案。

## 2. 前导零处理

如果 `digits` 中包含 `0`，要注意：

1. 正整数第一位不能是 `0`。
2. 长度小于 `m` 的数字，第一位可选数字数是 `d - 1`，后续位是 `d`。
3. 长度等于 `m` 扫描第一位时，也不能把 `0` 算作合法第一位。

如果题目明确说数字集合不含 `0`，实现可以简化很多；面试中最好主动说明前导零规则。

## 3. C++ 实现

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

long long countAtMostN(vector<int> digits, long long n) {
    if (n <= 0 || digits.empty()) {
        return 0;
    }

    sort(digits.begin(), digits.end());
    digits.erase(unique(digits.begin(), digits.end()), digits.end());

    string s = to_string(n);
    int m = static_cast<int>(s.size());
    int d = static_cast<int>(digits.size());

    vector<long long> powD(m + 1, 1);
    for (int i = 1; i <= m; ++i) {
        powD[i] = powD[i - 1] * d;
    }

    bool hasZero = binary_search(digits.begin(), digits.end(), 0);
    int firstChoices = d - (hasZero ? 1 : 0);
    if (firstChoices <= 0) {
        return 0;
    }

    long long ans = 0;

    // 统计长度小于 m 的合法正整数。
    for (int len = 1; len < m; ++len) {
        ans += static_cast<long long>(firstChoices) * powD[len - 1];
    }

    // 统计长度等于 m 且 <= n 的合法数字。
    for (int i = 0; i < m; ++i) {
        int cur = s[i] - '0';
        int less = 0;

        for (int x : digits) {
            if (i == 0 && x == 0) {
                continue;
            }
            if (x < cur) {
                ++less;
            }
        }

        ans += static_cast<long long>(less) * powD[m - i - 1];

        if (!binary_search(digits.begin(), digits.end(), cur)) {
            return ans;
        }
        if (i == 0 && cur == 0) {
            return ans;
        }
    }

    // N 的每一位都能由 digits 组成，计入 N 自身。
    return ans + 1;
}
```

## 4. 复杂度

设 `N` 的位数为 `m`，数字集合大小为 `d`：

1. 排序去重：`O(d log d)`。
2. 扫描数位：`O(m * d)`。
3. 额外空间：`O(m)`。

如果提前预处理每个数字之前有多少个可选数字，可以把扫描部分降到 `O(m)`。

## 5. 如果要求构造最大值

构造最大不超过 `N` 的数字时，可以用类似前缀策略：

1. 从高位开始，尽量选择不超过当前位的最大可用数字。
2. 如果选择等于当前位，继续处理下一位。
3. 如果选择小于当前位，后续全部填最大数字。
4. 如果当前位没有可选数字，就回退到前一位，把前一位降到更小的可用数字，后续填最大数字。
5. 如果第一位也无法回退，就构造长度少一位、每位都是最大非零开头数字和最大数字的结果。

这种写法本质上是“带回退的贪心”，和数位 DP 的状态转移等价。

## 6. 易错点

1. 忘记排除前导零。
2. 忘记去重，导致重复计数。
3. 只统计长度等于 `N` 的数字，漏掉长度更短的合法数字。
4. 当前位不在 `digits` 中时，应立即结束，而不是继续扫描。
5. 如果用 `int` 保存答案，位数较大时可能溢出，应使用 `long long`。

## 7. 面试回答模板

我会按位数统计。先把所有长度小于 `N` 位数的数字计入答案；然后处理和 `N` 等长的数字，从高位到低位扫描。每一位统计可选数字中比当前位小的个数，如果这一位选小了，后面位数可以任意组合，贡献是 `less * d^(剩余位数)`；如果当前位本身在集合里，就继续保持前缀相等，否则停止。最后如果每一位都能匹配，再把 `N` 自身计入。需要特别注意数字集合包含 `0` 时第一位不能选 `0`。
