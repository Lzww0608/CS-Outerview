# 106. 交错字符串

## 题目

给定字符串 `s1`、`s2`、`s3`，判断 `s3` 是否可以由 `s1` 和 `s2` 交错组成。交错要求保持 `s1` 和 `s2` 各自字符的相对顺序。

例如：

```text
s1 = "abc", s2 = "def", s3 = "adbcef" -> true
s1 = "abc", s2 = "def", s3 = "abdecf" -> true
s1 = "abc", s2 = "def", s3 = "abdfec" -> false
```

## 1. 动态规划

定义：

```text
dp[i][j] = s1 前 i 个字符和 s2 前 j 个字符，能否组成 s3 前 i+j 个字符
```

状态转移：

```text
dp[i][j] =
  (dp[i-1][j] && s1[i-1] == s3[i+j-1]) ||
  (dp[i][j-1] && s2[j-1] == s3[i+j-1])
```

初始化：

```text
dp[0][0] = true
```

如果 `s1.size() + s2.size() != s3.size()`，直接返回 false。

## 2. C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

bool isInterleave(string s1, string s2, string s3) {
    int n = static_cast<int>(s1.size());
    int m = static_cast<int>(s2.size());
    if (n + m != static_cast<int>(s3.size())) {
        return false;
    }

    vector<vector<bool>> dp(n + 1, vector<bool>(m + 1, false));
    dp[0][0] = true;

    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j <= m; ++j) {
            int k = i + j - 1;
            if (i > 0 && dp[i - 1][j] && s1[i - 1] == s3[k]) {
                dp[i][j] = true;
            }
            if (j > 0 && dp[i][j - 1] && s2[j - 1] == s3[k]) {
                dp[i][j] = true;
            }
        }
    }

    return dp[n][m];
}
```

## 3. 空间优化

`dp[i][j]` 只依赖上一行和当前行左侧，可以压缩到一维：

```cpp
#include <string>
#include <vector>
using namespace std;

bool isInterleave1D(string s1, string s2, string s3) {
    int n = static_cast<int>(s1.size());
    int m = static_cast<int>(s2.size());
    if (n + m != static_cast<int>(s3.size())) {
        return false;
    }

    vector<bool> dp(m + 1, false);
    dp[0] = true;

    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j <= m; ++j) {
            int k = i + j - 1;
            if (i == 0 && j == 0) {
                continue;
            }

            bool fromS1 = i > 0 && dp[j] && s1[i - 1] == s3[k];
            bool fromS2 = j > 0 && dp[j - 1] && s2[j - 1] == s3[k];
            dp[j] = fromS1 || fromS2;
        }
    }

    return dp[m];
}
```

## 4. 复杂度

1. 二维 DP 时间复杂度 `O(n*m)`，空间复杂度 `O(n*m)`。
2. 一维 DP 时间复杂度 `O(n*m)`，空间复杂度 `O(m)`。

## 5. 易错点

1. 先判断长度，不等直接 false。
2. `s3` 当前下标是 `i + j - 1`。
3. 空字符串边界要能处理，例如 `s1=""` 或 `s2=""`。
4. 一维 DP 中 `dp[j]` 在更新前代表上一行，`dp[j-1]` 代表当前行左侧。

## 6. 面试回答模板

这题用动态规划。`dp[i][j]` 表示 `s1` 前 `i` 个字符和 `s2` 前 `j` 个字符能否交错组成 `s3` 前 `i+j` 个字符。最后一个字符要么来自 `s1[i-1]`，要么来自 `s2[j-1]`，所以分别从 `dp[i-1][j]` 和 `dp[i][j-1]` 转移。先判断长度是否相等，时间复杂度 `O(n*m)`，空间可以从二维压缩到一维。
