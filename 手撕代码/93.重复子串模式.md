# 93. 重复子串模式

## 题目

判断一个字符串是否可以由它的某个非空真子串重复多次得到。

例如：

```text
"abab"     -> true，"ab" 重复 2 次
"abcabc"   -> true，"abc" 重复 2 次
"aba"      -> false
"aaaa"     -> true，"a" 重复 4 次
```

## 方法一：拼接字符串

如果 `s` 可以由重复子串构成，那么把 `s + s` 去掉首尾字符后，里面仍然能找到原字符串。

```cpp
#include <string>
using namespace std;

bool repeatedSubstringPattern(string s) {
    if (s.empty()) {
        return false;
    }

    string doubled = s + s;
    string mid = doubled.substr(1, doubled.size() - 2);
    return mid.find(s) != string::npos;
}
```

原理：

1. 重复串在循环移位后仍能对齐回自己。
2. 去掉首尾是为了排除原字符串只在 `s + s` 的开头或结尾自然出现。

## 方法二：KMP 前缀函数

设 `n = s.size()`，`lps[n - 1]` 表示整个字符串最长相等真前后缀长度。如果存在重复子串，则最小循环节长度为：

```text
period = n - lps[n - 1]
```

当 `lps[n - 1] > 0` 且 `n % period == 0` 时，可以由长度为 `period` 的子串重复得到。

```cpp
#include <string>
#include <vector>
using namespace std;

bool repeatedSubstringPatternKmp(const string& s) {
    int n = static_cast<int>(s.size());
    if (n == 0) {
        return false;
    }

    vector<int> lps(n, 0);
    for (int i = 1, len = 0; i < n; ) {
        if (s[i] == s[len]) {
            lps[i++] = ++len;
        } else if (len > 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }

    int longest = lps[n - 1];
    int period = n - longest;
    return longest > 0 && n % period == 0;
}
```

## 易错点

1. 子串必须是非空真子串，整个字符串本身不能算一次重复。
2. 空字符串通常返回 `false`，面试时要先说明约定。
3. `"aaaa"` 的最小循环节是 `"a"`，不是只能按一半切。
4. KMP 判断要同时满足 `longest > 0` 和 `n % period == 0`。

## 复杂度

```text
拼接法:
时间复杂度: 取决于 find 实现，通常可认为 O(n) 到 O(n^2)
空间复杂度: O(n)

KMP:
时间复杂度: O(n)
空间复杂度: O(n)
```

## 面试回答模板

可以用两个思路。简单写法是判断 `s` 是否出现在 `(s + s)` 去掉首尾字符后的字符串里，能出现说明它有循环节。更严谨的线性做法是 KMP：求最长相等真前后缀长度 `lps[n-1]`，最小循环节长度是 `n - lps[n-1]`，如果 `lps[n-1] > 0` 且 `n` 能被循环节长度整除，就说明字符串可以由某个子串重复得到。
