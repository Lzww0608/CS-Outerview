# 12. 删除无效括号

## 题目

给定一个字符串 `s`，删除最少数量的无效括号，使得字符串合法，返回所有可能结果。字符串中可能包含非括号字符。

示例：

```text
s = "()())()"
输出: ["(())()", "()()()"]
```

## 思路一：BFS

BFS 按删除次数逐层搜索。第一层删除 0 个字符，第二层删除 1 个字符，依次类推。第一次找到合法字符串时，该层就是最少删除次数，收集该层所有合法结果即可，不再继续向下搜索。

判断合法：

1. 遇到 `(`，计数加一。
2. 遇到 `)`，如果计数为 0 则非法，否则计数减一。
3. 最后计数必须为 0。

## 代码

```cpp
#include <iostream>
#include <queue>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

bool isValid(const string& s) {
    int balance = 0;
    for (char c : s) {
        if (c == '(') {
            ++balance;
        } else if (c == ')') {
            if (balance == 0) {
                return false;
            }
            --balance;
        }
    }
    return balance == 0;
}

vector<string> removeInvalidParentheses(string s) {
    vector<string> ans;
    unordered_set<string> visited;
    queue<string> q;

    q.push(s);
    visited.insert(s);

    bool found = false;

    while (!q.empty()) {
        int levelSize = q.size();
        unordered_set<string> levelAns;

        for (int i = 0; i < levelSize; ++i) {
            string cur = q.front();
            q.pop();

            if (isValid(cur)) {
                found = true;
                levelAns.insert(cur);
                continue;
            }

            if (found) {
                continue;
            }

            for (int j = 0; j < static_cast<int>(cur.size()); ++j) {
                if (cur[j] != '(' && cur[j] != ')') {
                    continue;
                }
                string next = cur.substr(0, j) + cur.substr(j + 1);
                if (visited.insert(next).second) {
                    q.push(next);
                }
            }
        }

        if (found) {
            ans.assign(levelAns.begin(), levelAns.end());
            return ans;
        }
    }

    return {""};
}

int main() {
    string s;
    cin >> s;

    vector<string> ans = removeInvalidParentheses(s);
    for (const string& item : ans) {
        cout << item << endl;
    }
    return 0;
}
```

## 复杂度

最坏情况下需要枚举大量删除组合：

```text
时间复杂度: O(2^n * n)
空间复杂度: O(2^n * n)
```

BFS 的优势是天然保证最少删除次数，代码也比较直观。

## 思路二：DFS 剪枝

也可以先扫描计算需要删除的左括号数 `leftRemove` 和右括号数 `rightRemove`，再 DFS：

1. 当前字符是普通字符，必须保留。
2. 当前字符是 `(`，可以删除它或保留它。
3. 当前字符是 `)`，可以删除它；保留时要求当前未匹配左括号数大于 0。
4. DFS 结束时，删除额度用完且括号平衡，加入答案。

DFS 更适合需要强剪枝和控制输出顺序的场景；BFS 更适合面试快速证明“最少删除”。

## 易错点

1. 只删除括号字符，不能删除字母。
2. 需要去重，否则相同括号位置删除可能得到相同字符串。
3. BFS 找到第一层合法结果后，不要继续搜索更深层。
4. 空字符串也是合法括号字符串。
