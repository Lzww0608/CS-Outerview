# 线程交替输出序列

题目：两个线程交替输出 `abc` 和 `123`，要求使用信号量实现。

## 1. 核心思路

用两个信号量控制执行权：

```text
semA 初始为 1，允许线程 A 先输出 abc
semB 初始为 0，线程 B 等待 A 输出完成
```

线程 A 每轮先等待 `semA`，输出 `abc` 后释放 `semB`；线程 B 每轮先等待 `semB`，输出 `123` 后释放 `semA`。这样两个线程形成严格交替。

## 2. C++20 实现

```cpp
#include <iostream>
#include <semaphore>
#include <thread>

int main() {
    std::binary_semaphore semA(1);
    std::binary_semaphore semB(0);
    const int rounds = 5;

    std::thread t1([&] {
        for (int i = 0; i < rounds; ++i) {
            semA.acquire();
            std::cout << "abc";
            semB.release();
        }
    });

    std::thread t2([&] {
        for (int i = 0; i < rounds; ++i) {
            semB.acquire();
            std::cout << "123";
            semA.release();
        }
    });

    t1.join();
    t2.join();
    std::cout << '\n';
    return 0;
}
```

输出形如：

```text
abc123abc123abc123abc123abc123
```

## 3. C++17 条件变量写法

如果环境没有 C++20 `std::binary_semaphore`，可以用 `condition_variable` 模拟：

```cpp
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <thread>

int main() {
    std::mutex m;
    std::condition_variable cv;
    bool turnA = true;
    const int rounds = 5;

    std::thread t1([&] {
        for (int i = 0; i < rounds; ++i) {
            std::unique_lock<std::mutex> lk(m);
            cv.wait(lk, [&] { return turnA; });
            std::cout << "abc";
            turnA = false;
            cv.notify_one();
        }
    });

    std::thread t2([&] {
        for (int i = 0; i < rounds; ++i) {
            std::unique_lock<std::mutex> lk(m);
            cv.wait(lk, [&] { return !turnA; });
            std::cout << "123";
            turnA = true;
            cv.notify_one();
        }
    });

    t1.join();
    t2.join();
}
```

## 4. 易错点

1. 信号量初值决定谁先输出，两个都为 0 会死锁，两个都为 1 会失去严格交替。
2. 条件变量必须用谓词版本 `wait(lk, pred)`，防止虚假唤醒。
3. 输出本身也可能被缓冲，面试重点是同步顺序，不是终端刷新。
4. 如果要求字符级输出 `a1b2c3`，需要更细粒度的状态机，而不是简单交替输出整段字符串。

## 5. 面试回答模板

我会用两个二值信号量控制两个线程的执行权。线程 A 等待 `semA` 后输出 `abc`，再释放 `semB`；线程 B 等待 `semB` 后输出 `123`，再释放 `semA`。把 `semA` 初始化为 1、`semB` 初始化为 0，就能保证 A 先执行，并且两个线程严格交替。
