# 二叉树 Z 字打印

二叉树 Z 字打印也叫锯齿形层序遍历。第 1 层从左到右，第 2 层从右到左，第 3 层再从左到右，依次交替。

## 1. BFS + 层内反转

最直接做法是普通层序遍历，每层收集节点值，根据方向决定是否反转。

```cpp
#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
    vector<vector<int>> ans;
    if (root == nullptr) {
        return ans;
    }

    queue<TreeNode*> q;
    q.push(root);
    bool leftToRight = true;

    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        level.reserve(sz);

        for (int i = 0; i < sz; ++i) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);

            if (node->left) {
                q.push(node->left);
            }
            if (node->right) {
                q.push(node->right);
            }
        }

        if (!leftToRight) {
            reverse(level.begin(), level.end());
        }
        ans.push_back(std::move(level));
        leftToRight = !leftToRight;
    }

    return ans;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(w)`，`w` 是二叉树最大宽度；输出结果另算。

## 2. BFS + 下标填充

如果不想每层 `reverse`，可以根据方向写入对应下标：

```cpp
vector<vector<int>> zigzagLevelOrderNoReverse(TreeNode* root) {
    vector<vector<int>> ans;
    if (!root) {
        return ans;
    }

    queue<TreeNode*> q;
    q.push(root);
    bool leftToRight = true;

    while (!q.empty()) {
        int sz = q.size();
        vector<int> level(sz);

        for (int i = 0; i < sz; ++i) {
            TreeNode* node = q.front();
            q.pop();
            int index = leftToRight ? i : (sz - 1 - i);
            level[index] = node->val;

            if (node->left) {
                q.push(node->left);
            }
            if (node->right) {
                q.push(node->right);
            }
        }

        ans.push_back(std::move(level));
        leftToRight = !leftToRight;
    }

    return ans;
}
```

## 3. 易错点

1. 入队左右孩子的顺序始终保持左再右，Z 字只影响当前层输出顺序。
2. 要按层处理，不能每弹一个节点就切换方向。
3. 空树返回空数组。

## 4. 面试回答模板

用 BFS 按层遍历，每次记录当前队列大小，只处理这一层的节点。层内值可以先按普通顺序收集，再根据方向反转；也可以按方向计算下标直接填入。每处理完一层翻转方向。时间 `O(n)`，额外空间是队列最大宽度 `O(w)`。
