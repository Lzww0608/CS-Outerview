# 14. 缺失的第一个正数

## 题目

给定一个未排序整数数组，找出其中没有出现的最小正整数。

示例：

```text
nums = [3, 4, -1, 1]
输出: 2
```

要求通常是：

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 思路：原地哈希

长度为 `n` 的数组中，缺失的第一个正数一定在 `[1, n + 1]` 范围内。

我们把值 `x` 放到下标 `x - 1` 的位置：

```text
值 1 放到 nums[0]
值 2 放到 nums[1]
值 x 放到 nums[x - 1]
```

遍历数组，对每个位置不断交换，直到当前位置的值不在 `[1, n]`，或者目标位置已经是相同值。最后再扫描一遍，第一个不满足 `nums[i] == i + 1` 的位置，答案就是 `i + 1`。

## 代码

```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int firstMissingPositive(vector<int>& nums) {
    int n = static_cast<int>(nums.size());

    for (int i = 0; i < n; ++i) {
        while (nums[i] >= 1 && nums[i] <= n &&
               nums[nums[i] - 1] != nums[i]) {
            swap(nums[i], nums[nums[i] - 1]);
        }
    }

    for (int i = 0; i < n; ++i) {
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }

    return n + 1;
}

int main() {
    vector<int> nums = {3, 4, -1, 1};
    cout << firstMissingPositive(nums) << endl;
    return 0;
}
```

## 复杂度

每个数最多被交换到正确位置一次，整体：

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 易错点

1. 答案范围是 `[1, n + 1]`，不是 `[1, n]`。
2. 只处理 `[1, n]` 范围内的数，负数、0、大于 n 的数都不需要放置。
3. `nums[nums[i] - 1] != nums[i]` 是防止重复数字导致死循环的关键。
4. 不要使用额外哈希表，否则不满足 O(1) 空间要求。
