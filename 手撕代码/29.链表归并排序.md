# 链表归并排序

链表排序适合使用归并排序，因为链表不支持随机访问，快速排序按下标分区不方便；归并排序只需要断链和合并两个有序链表。

## 思路

1. 用快慢指针找到链表中点。
2. 从中点断开，递归排序左右两半。
3. 合并两个有序链表。

## 代码

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (a != nullptr && b != nullptr) {
        if (a->val <= b->val) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }

    tail->next = (a != nullptr) ? a : b;
    return dummy.next;
}

ListNode* sortList(ListNode* head) {
    if (head == nullptr || head->next == nullptr) {
        return head;
    }

    ListNode* slow = head;
    ListNode* fast = head->next;
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }

    ListNode* right = slow->next;
    slow->next = nullptr;

    ListNode* leftSorted = sortList(head);
    ListNode* rightSorted = sortList(right);
    return mergeTwoLists(leftSorted, rightSorted);
}
```

## 复杂度

1. 时间复杂度：`O(n log n)`。
2. 空间复杂度：递归栈 `O(log n)`；如果改成自底向上归并，可以做到额外空间 `O(1)`。

## 易错点

1. 快慢指针找中点后必须 `slow->next = nullptr` 断开，否则递归不会收敛。
2. 合并时复用原节点即可，不需要新建节点。
3. `fast = head->next` 可以让左半和右半更均衡，避免两个节点时中点不前进。
4. 如果面试要求严格 `O(1)` 额外空间，要写自底向上迭代归并。

## 面试回答模板

链表排序我会用归并排序。用快慢指针找到中点并断链，递归排序左右两段，再用合并两个有序链表的方法合并。因为链表合并只改 `next` 指针，不需要随机访问，所以比数组快排更适合链表。时间复杂度 `O(n log n)`，递归版空间是 `O(log n)`，迭代版可以做到 `O(1)`。
