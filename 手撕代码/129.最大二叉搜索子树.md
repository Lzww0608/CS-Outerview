# 129. 最大二叉搜索子树

## 题目

给定一棵二叉树，找出其中节点数量最多的二叉搜索子树（BST）。面试中也可能问“找到最大的 BST 子树根节点”或“返回最大 BST 子树大小”。

## 思路

用后序遍历做树形 DP。对每个节点，必须先知道左子树和右子树是否是 BST，以及它们的最小值、最大值和节点数量。

一个以 `root` 为根的子树是 BST，需要满足：

1. 左子树是 BST。
2. 右子树是 BST。
3. 左子树最大值 `< root->val`。
4. 右子树最小值 `> root->val`。

如果满足，就可以合并成更大的 BST；否则当前子树不是 BST，但答案可以来自左右子树中较大的那个。

## 状态设计

```cpp
struct Info {
    bool isBST;
    int minVal;
    int maxVal;
    int size;
    int bestSize;
    TreeNode* bestRoot;
};
```

字段含义：

1. `isBST`：当前子树是否是 BST。
2. `minVal/maxVal`：当前子树作为 BST 时的最小值和最大值。
3. `size`：当前子树节点数。
4. `bestSize/bestRoot`：当前子树范围内最大的 BST 子树信息。

## 代码

```cpp
#include <algorithm>
#include <climits>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

struct Info {
    bool isBST;
    int minVal;
    int maxVal;
    int size;
    int bestSize;
    TreeNode* bestRoot;
};

Info dfs(TreeNode* root) {
    if (root == nullptr) {
        return {true, INT_MAX, INT_MIN, 0, 0, nullptr};
    }

    Info left = dfs(root->left);
    Info right = dfs(root->right);

    Info cur{};
    cur.size = left.size + right.size + 1;

    if (left.isBST && right.isBST &&
        left.maxVal < root->val && root->val < right.minVal) {
        cur.isBST = true;
        cur.minVal = std::min(left.minVal, root->val);
        cur.maxVal = std::max(right.maxVal, root->val);
        cur.bestSize = cur.size;
        cur.bestRoot = root;
        return cur;
    }

    cur.isBST = false;
    cur.minVal = INT_MIN;
    cur.maxVal = INT_MAX;
    if (left.bestSize >= right.bestSize) {
        cur.bestSize = left.bestSize;
        cur.bestRoot = left.bestRoot;
    } else {
        cur.bestSize = right.bestSize;
        cur.bestRoot = right.bestRoot;
    }
    return cur;
}

TreeNode* largestBSTSubtree(TreeNode* root) {
    return dfs(root).bestRoot;
}

int largestBSTSubtreeSize(TreeNode* root) {
    return dfs(root).bestSize;
}
```

## 复杂度

1. 时间复杂度：`O(n)`，每个节点只访问一次。
2. 空间复杂度：`O(h)`，递归栈高度为树高，最坏 `O(n)`，平衡树为 `O(log n)`。

## 易错点

1. 不能只看当前节点和左右孩子，要看左子树最大值和右子树最小值。
2. 空树要返回 `isBST = true`，并用 `INT_MAX/INT_MIN` 作为边界，方便叶子节点合并。
3. 如果允许重复值，需要提前定义重复值放左边还是右边，并把 `<` 改成对应的 `<=` 规则。
4. 如果节点值可能等于 `INT_MIN/INT_MAX`，可以把边界类型改成 `long long`，避免哨兵冲突。

## 面试回答模板

这题用后序遍历，因为一个节点是否能作为 BST 根，取决于左右子树的信息。每个递归返回当前子树是否是 BST、最小值、最大值、节点数，以及当前范围内最大 BST 子树。若左右都是 BST 且 `left.max < root.val < right.min`，就合并；否则答案取左右较大者。整体每个节点访问一次，时间复杂度 `O(n)`。
