# 94. 返回出现两次的元素

## 题目

给定一个整数序列，其中有些元素出现一次，有些元素出现两次，返回所有出现两次的元素。

例如：

```text
nums = [4, 3, 2, 7, 8, 2, 3, 1]
返回 [2, 3]
```

## 方法一：哈希集合

如果元素范围没有限制，最稳妥的方法是用两个集合：

```cpp
#include <unordered_set>
#include <vector>
using namespace std;

vector<int> findDuplicatesHash(const vector<int>& nums) {
    unordered_set<int> seen;
    unordered_set<int> duplicated;
    vector<int> ans;

    for (int x : nums) {
        if (seen.find(x) == seen.end()) {
            seen.insert(x);
        } else if (duplicated.insert(x).second) {
            ans.push_back(x);
        }
    }
    return ans;
}
```

这里 `duplicated` 用来防止题目变体中某个元素出现超过两次时重复加入答案。

复杂度：

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

## 方法二：原地标记

如果题目额外保证 `1 <= nums[i] <= n`，可以用数组自身做标记。访问数字 `x` 时，把下标 `abs(x) - 1` 的位置变成负数；如果再次访问时该位置已经是负数，说明 `x` 出现了第二次。

```cpp
#include <cstdlib>
#include <vector>
using namespace std;

vector<int> findDuplicatesInPlace(vector<int>& nums) {
    vector<int> ans;
    for (int x : nums) {
        int idx = abs(x) - 1;
        if (nums[idx] < 0) {
            ans.push_back(idx + 1);
        } else {
            nums[idx] = -nums[idx];
        }
    }
    return ans;
}
```

复杂度：

```text
时间复杂度: O(n)
额外空间复杂度: O(1)，不计答案数组
```

这种方法会修改原数组。如果不能修改输入，需要先复制一份，或者使用哈希集合。

## 方法三：排序

如果允许改变顺序，可以排序后扫描相邻元素：

```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<int> findDuplicatesSort(vector<int> nums) {
    sort(nums.begin(), nums.end());
    vector<int> ans;

    for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
        if (nums[i] == nums[i - 1] && (ans.empty() || ans.back() != nums[i])) {
            ans.push_back(nums[i]);
        }
    }
    return ans;
}
```

复杂度：

```text
时间复杂度: O(nlogn)
空间复杂度: 取决于排序实现
```

## 易错点

1. 先问清楚是返回一个重复元素，还是所有出现两次的元素。
2. 原地标记法依赖取值范围是 `1..n`，不能直接用于任意整数。
3. 原地标记会修改输入数组，接口语义要提前说明。
4. 如果元素可能出现三次以上，哈希法要避免答案重复。

## 面试回答模板

通用解法用哈希集合，遍历时记录已经出现过的元素，第二次遇到就加入答案，时间 `O(n)`，空间 `O(n)`。如果题目保证元素都在 `1..n`，可以用原地负号标记，把值映射到数组下标，第二次遇到同一个值时对应位置已经是负数，就说明它重复出现，额外空间可以降到 `O(1)`。
