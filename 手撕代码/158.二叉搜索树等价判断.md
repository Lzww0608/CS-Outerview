# 158. 二叉搜索树等价判断

## 题目

一个有序序列可以构造成很多种不同形状的二叉搜索树。给两棵二叉搜索树，判断它们表示的有序集合是否一样。

如果题目问的是“树结构是否完全一样”，直接比较节点值和左右子树即可；如果面试官提示“最小的数不相等就不往下遍历”，通常考的是：**不要先把完整中序序列存下来，而是用两个迭代器边遍历边比较**。

## 思路

BST 的中序遍历是有序序列。两棵 BST 表示的元素集合一样，当且仅当它们的中序遍历序列一样。

朴素做法是分别中序遍历得到两个数组，再比较数组。但这会用 `O(n)` 额外空间，也不能提前停止。更好的做法是维护两个中序迭代器，每次只取当前最小值：

```text
取 tree1 当前最小值
取 tree2 当前最小值
不同 -> 立即返回 false
相同 -> 两边都前进
```

## 代码

```cpp
#include <stack>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

class BSTIterator {
public:
    explicit BSTIterator(TreeNode* root) {
        pushLeft(root);
    }

    bool hasNext() const {
        return !st.empty();
    }

    int next() {
        TreeNode* node = st.top();
        st.pop();
        int value = node->val;
        pushLeft(node->right);
        return value;
    }

private:
    stack<TreeNode*> st;

    void pushLeft(TreeNode* node) {
        while (node != nullptr) {
            st.push(node);
            node = node->left;
        }
    }
};

bool sameBSTValues(TreeNode* a, TreeNode* b) {
    BSTIterator ia(a);
    BSTIterator ib(b);

    while (ia.hasNext() && ib.hasNext()) {
        if (ia.next() != ib.next()) {
            return false;
        }
    }

    return !ia.hasNext() && !ib.hasNext();
}
```

复杂度：

```text
时间复杂度：O(n + m)，如果前面就不同可以提前结束
额外空间：O(ha + hb)，h 是树高
```

## 如果要判断结构完全相同

结构完全相同需要同时比较当前节点和左右子树：

```cpp
bool sameTree(TreeNode* a, TreeNode* b) {
    if (a == nullptr || b == nullptr) {
        return a == b;
    }
    return a->val == b->val
        && sameTree(a->left, b->left)
        && sameTree(a->right, b->right);
}
```

这和“BST 表示的有序集合是否一样”不是同一个问题。例如 `[1,2,3]` 可以构造成不同形状的 BST，它们中序序列一样，但结构不一样。

## 重复元素怎么办

如果 BST 允许重复值，要先确认重复值规则：

1. 重复值统一放左子树或右子树，中序遍历仍能比较多重集合。
2. 节点带 `count` 字段时，迭代器要输出 `count` 次，或比较 `(value, count)`。
3. 如果只比较集合而忽略重复次数，则相同值需要去重后比较。

## 易错点

1. 不要把“结构相同”和“有序集合相同”混为一谈。
2. 中序遍历数组比较能做，但空间不是最优，也不能早停。
3. 普通 BST 可能退化成链表，迭代器栈空间最坏 `O(n)`。
4. 如果输入不是合法 BST，中序遍历有序这个前提不成立，需要先校验 BST。

## 面试回答模板

如果判断两棵 BST 表示的数据是否一样，可以利用 BST 中序遍历有序的性质。不要先完整生成两个数组，而是为两棵树各维护一个中序迭代器，栈里保存当前路径上的左链。每次取两个迭代器的下一个最小值，值不同立即返回 false，值相同继续；最后两个迭代器必须同时结束。这样能提前停止，时间 `O(n+m)`，额外空间是两棵树高度之和。
