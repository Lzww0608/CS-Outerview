# 链表第 K 个节点

题目：给定单链表头节点和整数 `k`，返回链表中的第 `k` 个节点。默认 `k` 从 1 开始计数。

## 1. 从头计数的第 K 个节点

从头计数的第 `k` 个节点只需要顺序遍历：

1. 如果 `k <= 0`，输入非法，返回 `nullptr`。
2. 从头节点开始走 `k - 1` 步。
3. 如果中途到达空指针，说明链表长度小于 `k`。
4. 否则当前节点就是第 `k` 个节点。

## 2. 代码实现

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* kthFromBegin(ListNode* head, int k) {
    if (k <= 0) {
        return nullptr;
    }

    ListNode* cur = head;
    for (int i = 1; i < k && cur != nullptr; ++i) {
        cur = cur->next;
    }

    return cur;
}
```

复杂度：

1. 时间复杂度：`O(k)`，最坏 `O(n)`。
2. 空间复杂度：`O(1)`。

## 3. 如果题目实际问倒数第 K 个

面试时“第 K 个结点”容易和“倒数第 K 个结点”混淆，要主动确认。如果是倒数第 `k` 个，用快慢指针：

```cpp
ListNode* kthFromEnd(ListNode* head, int k) {
    if (k <= 0) {
        return nullptr;
    }

    ListNode* fast = head;
    ListNode* slow = head;

    for (int i = 0; i < k; ++i) {
        if (fast == nullptr) {
            return nullptr;
        }
        fast = fast->next;
    }

    while (fast != nullptr) {
        fast = fast->next;
        slow = slow->next;
    }

    return slow;
}
```

## 4. 易错点

1. 先确认 `k` 是从 0 开始还是从 1 开始，面试默认多为从 1 开始。
2. 空链表、`k <= 0`、链表长度小于 `k` 都要处理。
3. 从头第 `k` 个和倒数第 `k` 个不是同一个问题，复杂度都可以做到 `O(n)` 和 `O(1)`。
4. 如果要删除第 `k` 个节点，头节点删除要用 dummy 节点简化边界。

## 5. 面试回答模板

如果是从头第 `K` 个节点，直接从头指针走 `K - 1` 步，中途遇到空指针说明长度不足，时间 `O(n)`、空间 `O(1)`。如果面试官实际问倒数第 `K` 个节点，用快慢指针：快指针先走 `K` 步，然后快慢一起走，快指针到空时慢指针就是目标节点。边界要处理空链表、`K <= 0` 和长度不足。
