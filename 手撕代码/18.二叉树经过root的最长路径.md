# 18. 二叉树经过 root 的最长路径

## 题目

给定一棵二叉树，求必须经过 `root` 节点的最长路径长度。

路径可以从左子树某个节点出发，经过 `root`，再到右子树某个节点。面试时要先确认长度按“边数”还是“节点数”计算。

## 思路

如果长度按边数计算：

1. 求 root 左子树最大深度。
2. 求 root 右子树最大深度。
3. 经过 root 的最长路径边数就是 `leftDepth + rightDepth`。

这里把空节点深度定义为 `0`，叶子节点深度定义为 `1`，所以左右深度相加得到的是边数。例如只有 root 一个节点时，左右深度都是 0，答案是 0。

## 代码

```cpp
#include <algorithm>
#include <iostream>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

int depth(TreeNode* node) {
    if (node == nullptr) {
        return 0;
    }
    return max(depth(node->left), depth(node->right)) + 1;
}

int longestPathThroughRoot(TreeNode* root) {
    if (root == nullptr) {
        return 0;
    }
    return depth(root->left) + depth(root->right);
}
```

如果面试官要求按节点数计算：

```cpp
int longestNodeCountThroughRoot(TreeNode* root) {
    if (root == nullptr) {
        return 0;
    }
    return depth(root->left) + depth(root->right) + 1;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(h)
```

`n` 是节点数，`h` 是树高。空间来自递归栈。

## 易错点

1. “经过 root”不是整棵树直径，整棵树直径可以不经过 root。
2. 要明确路径长度是边数还是节点数。
3. 空树答案通常为 0。
4. 树很深时递归可能栈溢出，工程上可以改成迭代后序遍历。
