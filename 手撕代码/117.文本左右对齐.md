# 117. 文本左右对齐

## 题目

给定单词数组和每行最大宽度 `maxWidth`，按 LeetCode 68 要求做文本左右对齐。

## 思路

贪心确定每一行放哪些单词：从左到右尽量放，保证单词长度加最少空格不超过 `maxWidth`。

对一行单词：

1. 如果是最后一行，左对齐，单词间一个空格，右侧补空格。
2. 如果只有一个单词，左对齐，右侧补空格。
3. 否则把多余空格尽量均匀分布到单词间隙，不能整除时左边间隙多一个空格。

## 代码

```cpp
#include <string>
#include <vector>
using namespace std;

vector<string> fullJustify(vector<string>& words, int maxWidth) {
    vector<string> ans;
    int n = static_cast<int>(words.size());

    for (int i = 0; i < n;) {
        int j = i;
        int wordsLen = 0;
        while (j < n && wordsLen + static_cast<int>(words[j].size()) + (j - i) <= maxWidth) {
            wordsLen += static_cast<int>(words[j].size());
            ++j;
        }

        int gaps = j - i - 1;
        string line;
        bool lastLine = (j == n);

        if (lastLine || gaps == 0) {
            for (int k = i; k < j; ++k) {
                if (k > i) line.push_back(' ');
                line += words[k];
            }
            line += string(maxWidth - line.size(), ' ');
        } else {
            int spaces = maxWidth - wordsLen;
            int each = spaces / gaps;
            int extra = spaces % gaps;
            for (int k = i; k < j; ++k) {
                if (k > i) {
                    int cnt = each + ((k - i) <= extra ? 1 : 0);
                    line += string(cnt, ' ');
                }
                line += words[k];
            }
        }

        ans.push_back(line);
        i = j;
    }
    return ans;
}
```

## 易错点

1. 判断一行能否加入下一个词时，至少要给已有单词间留一个空格。
2. 最后一行必须左对齐，不做左右均匀分布。
3. 只有一个单词的非最后一行也只能左对齐。
4. 额外空格从左到右分配。
