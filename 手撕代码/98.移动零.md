# 移动零

题目：给定一个数组，将所有 `0` 移动到数组尾部，同时保持非零元素的相对顺序。

示例：

```text
输入: [0, 1, 0, 3, 12]
输出: [1, 3, 12, 0, 0]
```

## 1. 双指针原地写入

核心思路是维护一个写指针 `write`，表示下一个非零元素应该写入的位置。遍历数组，把非零元素按原顺序写到前面，最后把剩余位置填成 0。

```cpp
#include <vector>

void moveZeroes(std::vector<int>& nums) {
    int write = 0;

    for (int x : nums) {
        if (x != 0) {
            nums[write++] = x;
        }
    }

    while (write < static_cast<int>(nums.size())) {
        nums[write++] = 0;
    }
}
```

复杂度：

1. 时间复杂度 `O(n)`。
2. 额外空间复杂度 `O(1)`。
3. 非零元素相对顺序保持不变。

## 2. 交换写法

也可以在扫描时把非零元素交换到前面：

```cpp
#include <utility>
#include <vector>

void moveZeroes(std::vector<int>& nums) {
    int write = 0;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        if (nums[i] != 0) {
            std::swap(nums[write++], nums[i]);
        }
    }
}
```

这种写法也保持非零元素相对顺序，因为每个非零元素按扫描顺序被交换到前面的下一个位置。缺点是当 `write == i` 时会做一次无意义自交换，可以加判断跳过。

## 3. 用 STL 怎么写

`std::remove` 不会真的删除元素，而是把“不等于给定值”的元素稳定移动到前面，并返回新的逻辑尾迭代器。再把尾部填 0：

```cpp
#include <algorithm>
#include <vector>

void moveZeroes(std::vector<int>& nums) {
    auto it = std::remove(nums.begin(), nums.end(), 0);
    std::fill(it, nums.end(), 0);
}
```

注意：这里不能只调用 `remove` 就结束，因为 `remove` 之后容器大小不变，尾部元素处于“未指定但仍有效”的值，需要显式填成 0。

## 4. 易错点

1. 不要使用 `erase(remove(...), end())`，那会改变数组长度，不符合“移动到尾部”的题意。
2. 题目要求保持非零元素相对顺序，所以不能用简单的左右指针把 0 和末尾元素交换。
3. 如果元素类型不是基础类型，写入/交换成本不同，要关注移动构造和赋值成本。

## 5. 面试回答模板

移动零可以用稳定双指针。`write` 指向下一个非零元素应该放的位置，遍历数组时遇到非零就写入 `nums[write++]`，遍历结束后把 `[write, end)` 全部填 0。这样时间 `O(n)`、额外空间 `O(1)`，并保持非零元素相对顺序。如果允许用 STL，可以用 `std::remove(nums.begin(), nums.end(), 0)` 把非零元素移动到前面，再用 `std::fill` 把尾部填 0。
