# 139. 位或折叠序列还原

题目描述类似：给定一个递增序列，左边数字集合通过按位或 `|` 折叠形成右边序列；现在给定右边序列，返回一个可能的左边集合。

这类题必须先和面试官确认“折叠”的精确定义。常见可解释模型是：

```text
b[i] = a[0] | a[1] | ... | a[i]
```

也就是 `b` 是 `a` 的前缀按位或序列。

## 1. 逆问题不唯一

按位或只会把 bit 从 `0` 变成 `1`，不会记录某个 bit 是由哪个元素贡献的。因此从 `b` 反推 `a` 通常不唯一。

例如：

```text
a = [1, 2]  -> b = [1, 3]
a = [1, 3]  -> b = [1, 3]
```

所以正确回答不是直接写唯一解，而是先说明：只能返回一个满足条件的构造，或在额外约束下判断无解。

## 2. 合法性判断

如果 `b` 是前缀 OR 序列，那么它必须满足：

```text
(b[i] | b[i - 1]) == b[i]
```

也就是说，后一个值的 bit 集合必须包含前一个值的 bit 集合。如果某一步丢了 bit，就不可能由按位或得到。

## 3. 返回一个可行集合

最简单的构造是直接令：

```text
a[i] = b[i]
```

只要 `b` 是合法的前缀 OR 序列，就有：

```text
b[0] | b[1] | ... | b[i] == b[i]
```

因此这个构造一定成立。如果题目还要求 `a` 递增，而 `b` 本身递增，这个构造也满足递增。

```cpp
#include <stdexcept>
#include <vector>
using namespace std;

vector<int> recoverByPrefixOr(const vector<int>& b) {
    vector<int> a;
    a.reserve(b.size());

    int prev = 0;
    for (int x : b) {
        if ((x | prev) != x) {
            throw invalid_argument("not a valid prefix-or sequence");
        }
        a.push_back(x);
        prev = x;
    }
    return a;
}
```

## 4. 如果想返回“新增 bit”

也可以构造每一步新出现的 bit：

```text
delta[i] = b[i] & ~b[i - 1]
```

这种构造能解释每一步新增了哪些能力或标签，但可能出现 `0`，也不一定满足递增。

## 5. 易错点

1. 按位或不可逆，不能承诺恢复原始唯一集合。
2. 数值递增不等于 bit 集合单调，例如 `3 -> 4` 数值变大，但 bit `1` 和 `2` 消失了，不是合法前缀 OR。
3. 如果输入包含负数，补码高位会干扰直觉，面试题通常默认非负整数。
4. 如果折叠不是前缀 OR，而是任意子集 OR、区间 OR 或树形折叠，算法会完全不同。

## 6. 面试回答模板

我会先确认折叠定义。如果右边序列是前缀按位或结果，那么反推原序列不是唯一的，因为 OR 会丢失“哪个元素贡献了这个 bit”的信息。可以先判断合法性：后一个数必须 bitwise 包含前一个数，即 `(prev | cur) == cur`。若只要求返回一个可行左边集合，可以直接返回 `a[i]=b[i]`；若想表达每一步新增内容，可以返回 `b[i] & ~b[i-1]`，但这不一定满足递增。
