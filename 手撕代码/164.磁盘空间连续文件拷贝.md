# 164. 磁盘空间连续文件拷贝

题目：大文件被拆成 `N` 个小文件，编号为 `0` 到 `N - 1`，每个文件大小为 `S(i)`。给定磁盘空间 `C`，从中连续选择若干个文件拷贝到磁盘，使得磁盘剩余空间最小。

等价问题：在数组 `S` 中找一个连续子数组，使其和 `sum <= C`，并且 `sum` 尽可能大。

## 1. 核心思路

文件大小都是非负数，因此可以用滑动窗口。

维护窗口 `[left, right]` 和当前大小 `cur`：

1. 右指针不断加入文件。
2. 如果 `cur > C`，移动左指针并减去左侧文件大小，直到 `cur <= C`。
3. 每次窗口合法时，用 `cur` 更新最优答案。

因为每个元素最多进窗口一次、出窗口一次，所以时间复杂度是 `O(n)`。

## 2. C++ 实现

```cpp
#include <cstdint>
#include <vector>
using namespace std;

struct CopyRange {
    int left = -1;
    int right = -1;
    long long used = 0;
    long long remain = 0;
};

CopyRange bestCopyRange(const vector<long long>& size, long long capacity) {
    CopyRange ans;
    ans.remain = capacity;

    long long cur = 0;
    int left = 0;

    for (int right = 0; right < static_cast<int>(size.size()); ++right) {
        cur += size[right];

        while (left <= right && cur > capacity) {
            cur -= size[left];
            ++left;
        }

        if (cur > ans.used) {
            ans.left = left;
            ans.right = right;
            ans.used = cur;
            ans.remain = capacity - cur;
        }
    }

    return ans;
}
```

如果没有任何单个文件能放入磁盘，返回的 `left/right` 仍为 `-1`，表示不选择文件，剩余空间为 `C`。

## 3. 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(1)
```

## 4. 易错点

1. 题目要求“连续选出若干个文件”，不是任意挑选文件；任意挑选会变成背包问题。
2. 文件大小要用 `long long`，多个文件大小累加可能超过 `int`。
3. 滑动窗口成立的前提是文件大小非负；如果数组有负数，就不能这样收缩窗口。
4. 如果允许选择 0 个文件，要明确返回空区间；如果题目要求至少一个文件，要单独处理所有文件都超过 `C` 的情况。

## 5. 面试回答模板

这个题是找和不超过 `C` 的最大连续子数组。因为文件大小非负，可以用滑动窗口：右指针扩张窗口，超过容量就移动左指针收缩；每次窗口合法时更新最大已使用空间。这样每个文件最多被加入和移出一次，时间 `O(n)`，空间 `O(1)`。如果题目改成非连续选择，才需要背包或近似算法。
