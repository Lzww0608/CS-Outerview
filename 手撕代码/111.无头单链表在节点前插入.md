# 无头单链表在节点前插入

题目：只给定单链表中的某个节点 `p`，不给头指针，如何在 `p` 前面插入一个新值。

## 1. 核心技巧

单链表没有前驱指针，无法真正找到 `p` 的前一个节点。但可以把“在 p 前插入”转换成“在 p 后插入并交换值”：

1. 新建节点 `node`，值设为 `p->val`。
2. `node->next = p->next`。
3. `p->next = node`。
4. 把 `p->val` 改成要插入的新值。

链表从外部看，新值出现在了原来 `p` 的位置，原 `p` 的值被挪到了后一个节点，相当于在 `p` 前插入。

## 2. C++ 实现

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

bool insertBeforeWithoutHead(ListNode* p, int value) {
    if (p == nullptr) {
        return false;
    }

    ListNode* node = new ListNode(p->val);
    node->next = p->next;
    p->next = node;
    p->val = value;
    return true;
}
```

## 3. 限制

这个方法只适用于节点值可以被移动或覆盖的场景。如果节点里保存的是复杂对象、外部持有节点身份、或者节点值不能交换，就不能简单使用。

此外，如果题目要求“在尾节点前插入”，该方法仍可用；但如果题目是“删除给定尾节点且无头指针”，则做不到，因为无法修改前驱的 `next`。

## 4. 易错点

1. 不是修改指针让新节点真的位于 `p` 的物理前面，而是通过值交换达成逻辑效果。
2. 如果链表节点有唯一 ID、锁、引用计数等身份语义，交换值可能破坏业务含义。
3. C++ 中新节点内存要由链表生命周期统一释放，避免泄漏。
4. 面试时要先说明限制条件，不能把这个技巧说成所有单链表场景都适用。
