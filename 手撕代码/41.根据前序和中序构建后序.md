# 根据前序和中序构建后序

前序遍历顺序是 `根 -> 左 -> 右`，中序遍历顺序是 `左 -> 根 -> 右`，后序遍历顺序是 `左 -> 右 -> 根`。只要节点值不重复，就可以用前序和中序唯一确定二叉树，再输出后序。

## 1. 核心思路

1. 前序区间第一个元素是当前子树根节点。
2. 在中序区间中找到根节点位置。
3. 根左侧是左子树，根右侧是右子树。
4. 根据左子树大小切分前序区间。
5. 递归输出左子树后序、右子树后序、根节点。

## 2. C++ 实现

```cpp
#include <stdexcept>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> postorderFromPreIn(const vector<int>& preorder, const vector<int>& inorder) {
        if (preorder.size() != inorder.size()) {
            throw invalid_argument("invalid traversal size");
        }

        unordered_map<int, int> pos;
        for (int i = 0; i < static_cast<int>(inorder.size()); ++i) {
            pos[inorder[i]] = i;
        }

        vector<int> postorder;
        build(preorder, 0, preorder.size(), 0, inorder.size(), pos, postorder);
        return postorder;
    }

private:
    void build(const vector<int>& pre,
               int preL,
               int preR,
               int inL,
               int inR,
               const unordered_map<int, int>& pos,
               vector<int>& post) {
        if (preL >= preR) {
            return;
        }

        int root = pre[preL];
        auto it = pos.find(root);
        if (it == pos.end() || it->second < inL || it->second >= inR) {
            throw invalid_argument("invalid traversal content");
        }

        int mid = it->second;
        int leftSize = mid - inL;

        build(pre, preL + 1, preL + 1 + leftSize, inL, mid, pos, post);
        build(pre, preL + 1 + leftSize, preR, mid + 1, inR, pos, post);
        post.push_back(root);
    }
};
```

这里区间使用左闭右开 `[L, R)`，能减少边界判断。

## 3. 复杂度和边界

1. 时间复杂度：`O(n)`，哈希表让根节点在中序中的位置查询为平均 `O(1)`。
2. 空间复杂度：`O(n)`，哈希表和递归栈。
3. 如果节点值重复，前序和中序不能唯一确定二叉树。
4. 如果输入遍历不一致，要能识别并返回错误。

## 4. 面试回答模板

前序第一个节点是根，在中序中找到根的位置后，左边就是左子树、右边就是右子树。根据左子树大小可以切分前序数组，然后递归处理左右子树，最后输出根节点就是后序。用哈希表保存中序位置可以把复杂度做到 `O(n)`。前提是节点值不重复，否则树不唯一。
