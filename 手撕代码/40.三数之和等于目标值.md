# 三数之和等于目标值

题目：给定一个数组，找到所有满足 `a + b + c = 99` 的组合。一般要求输出不重复三元组。

## 1. 排序 + 双指针

先排序，固定第一个数，再用左右指针在后缀区间中找两数之和。

```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<vector<int>> threeSumTarget(vector<int> nums, int target = 99) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> ans;
    int n = nums.size();

    for (int i = 0; i < n; ++i) {
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }

        int l = i + 1;
        int r = n - 1;
        while (l < r) {
            long long sum = 1LL * nums[i] + nums[l] + nums[r];
            if (sum == target) {
                ans.push_back({nums[i], nums[l], nums[r]});
                ++l;
                --r;
                while (l < r && nums[l] == nums[l - 1]) {
                    ++l;
                }
                while (l < r && nums[r] == nums[r + 1]) {
                    --r;
                }
            } else if (sum < target) {
                ++l;
            } else {
                --r;
            }
        }
    }

    return ans;
}
```

复杂度：

1. 排序 `O(nlogn)`。
2. 外层固定一个数，内层双指针总计 `O(n)`，整体 `O(n^2)`。
3. 除输出结果外，额外空间 `O(1)` 或排序栈空间。

## 2. 为什么要去重

如果数组中有重复数字，例如 `[1, 1, 2, 96]`，不去重会输出重复三元组。去重分三处：

1. 固定的 `i` 和前一个相同则跳过。
2. 找到一组答案后，左指针跳过相同值。
3. 找到一组答案后，右指针跳过相同值。

如果题目要求按下标组合计数，而不是按数值去重，就不能这样跳过重复值，需要改为统计频次或枚举下标。

## 3. 面试回答模板

三数之和可以先排序，然后固定第一个数，在右侧用双指针找剩余两数。和小了左指针右移，和大了右指针左移，命中后记录答案并跳过重复值。时间复杂度 `O(n^2)`，空间复杂度取决于排序实现和输出规模。关键是问清楚结果是否要按数值去重，还是按下标组合计数。
