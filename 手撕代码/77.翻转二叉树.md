# 翻转二叉树

## 题目

给定一棵二叉树，将每个节点的左右子树交换，返回翻转后的根节点。

示例：

```text
    1              1
   / \            / \
  2   3    ->    3   2
```

## 思路一：递归

对每个节点做同一件事：交换左右孩子，然后递归翻转左右子树。

## 递归代码

```cpp
#include <algorithm>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) {
        return nullptr;
    }

    swap(root->left, root->right);
    invertTree(root->left);
    invertTree(root->right);
    return root;
}
```

也可以先递归拿到翻转后的左右子树，再交换赋值：

```cpp
TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) {
        return nullptr;
    }
    TreeNode* left = invertTree(root->left);
    TreeNode* right = invertTree(root->right);
    root->left = right;
    root->right = left;
    return root;
}
```

## 思路二：迭代

用队列做 BFS，或者用栈做 DFS。每弹出一个节点，就交换它的左右孩子，再把非空孩子加入容器。

## 迭代代码

```cpp
#include <algorithm>
#include <queue>
using namespace std;

TreeNode* invertTreeIterative(TreeNode* root) {
    if (root == nullptr) {
        return nullptr;
    }

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* node = q.front();
        q.pop();

        swap(node->left, node->right);

        if (node->left != nullptr) {
            q.push(node->left);
        }
        if (node->right != nullptr) {
            q.push(node->right);
        }
    }

    return root;
}
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(h) 或 O(w)
```

递归空间复杂度取决于树高 `h`；BFS 队列空间复杂度取决于最大宽度 `w`。最坏情况下都可能是 `O(n)`。

## 易错点

1. 空树直接返回 `nullptr`。
2. 交换后继续递归哪一边都可以，因为两边最终都会被处理。
3. 递归写法在极深树上可能栈溢出，生产环境可以改成显式栈或队列。
4. 不需要新建节点，原地交换指针即可。
