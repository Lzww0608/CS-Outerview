# 反转句子中的单词顺序

题目：给定一个句子，反转其中单词的顺序。例如：

```text
"  hello   world  " -> "world hello"
```

常见要求是去掉首尾空格，并把多个空格压缩成一个空格。

## 1. 使用字符串流

如果面试不限制空间，最直接的做法是按空白切分单词，再反向拼接。

```cpp
#include <algorithm>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

string reverseWords(string s) {
    istringstream iss(s);
    vector<string> words;
    string word;

    while (iss >> word) {
        words.push_back(word);
    }

    reverse(words.begin(), words.end());

    string ans;
    for (int i = 0; i < static_cast<int>(words.size()); ++i) {
        if (i > 0) {
            ans.push_back(' ');
        }
        ans += words[i];
    }
    return ans;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(n)`。

## 2. 原地思路

如果要求在可修改字符串上尽量少用额外空间，可以分三步：

1. 去掉多余空格，得到规范字符串。
2. 整体反转字符串。
3. 再逐个反转每个单词。

```text
"hello world"
整体反转: "dlrow olleh"
单词反转: "world hello"
```

```cpp
#include <algorithm>
#include <string>
using namespace std;

string reverseWordsInPlace(string s) {
    int write = 0;
    int n = static_cast<int>(s.size());

    for (int read = 0; read < n; ) {
        while (read < n && s[read] == ' ') {
            ++read;
        }
        if (read == n) {
            break;
        }
        if (write > 0) {
            s[write++] = ' ';
        }
        while (read < n && s[read] != ' ') {
            s[write++] = s[read++];
        }
    }
    s.resize(write);

    reverse(s.begin(), s.end());

    int start = 0;
    for (int i = 0; i <= static_cast<int>(s.size()); ++i) {
        if (i == static_cast<int>(s.size()) || s[i] == ' ') {
            reverse(s.begin() + start, s.begin() + i);
            start = i + 1;
        }
    }
    return s;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 额外空间复杂度：`O(1)`，不计字符串自身存储。

## 3. 易错点

1. 多个连续空格要压缩。
2. 首尾空格要删除。
3. 空字符串或全空格字符串要返回空字符串。
4. 如果用整体反转方案，必须再反转每个单词。
5. 中文或 Unicode 分词不是这个题的默认语义，面试中一般按 ASCII 空格分隔英文单词。

## 4. 面试回答模板

这题可以用两种做法。简单版本用 `istringstream` 按空白切出单词，放入数组后反向拼接，时间 `O(n)`、空间 `O(n)`。如果要求更少空间，可以先原地去掉多余空格，再整体反转字符串，最后逐个反转每个单词，时间 `O(n)`、额外空间 `O(1)`。关键边界是首尾空格、连续空格、空字符串和全空格字符串。
