# 11. 单词接龙

## 题目

给定 `beginWord`、`endWord` 和一个单词列表 `wordList`，每次只能改变一个字符，且变化后的单词必须在 `wordList` 中。求从 `beginWord` 到 `endWord` 的最短转换序列长度。如果无法转换，返回 0。

示例：

```text
beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log","cog"]

输出: 5
路径: hit -> hot -> dot -> dog -> cog
```

## 思路

这是无权图最短路问题：

1. 每个单词是一个节点。
2. 两个单词只差一个字符，就有一条边。
3. 求最短转换次数，用 BFS。

直接两两比较建图是 `O(n^2 * L)`，可以用通配模式优化：

```text
hot -> *ot, h*t, ho*
dot -> *ot, d*t, do*
```

具有相同通配模式的单词互为候选邻居。

## 代码

```cpp
#include <iostream>
#include <queue>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
    unordered_set<string> dict(wordList.begin(), wordList.end());
    if (!dict.count(endWord)) {
        return 0;
    }

    int len = beginWord.size();
    unordered_map<string, vector<string>> pattern_to_words;

    for (const string& word : wordList) {
        for (int i = 0; i < len; ++i) {
            string pattern = word;
            pattern[i] = '*';
            pattern_to_words[pattern].push_back(word);
        }
    }

    queue<pair<string, int>> q;
    unordered_set<string> visited;
    q.push({beginWord, 1});
    visited.insert(beginWord);

    while (!q.empty()) {
        auto [word, step] = q.front();
        q.pop();

        if (word == endWord) {
            return step;
        }

        for (int i = 0; i < len; ++i) {
            string pattern = word;
            pattern[i] = '*';

            auto it = pattern_to_words.find(pattern);
            if (it == pattern_to_words.end()) {
                continue;
            }

            for (const string& next : it->second) {
                if (visited.count(next)) {
                    continue;
                }
                visited.insert(next);
                q.push({next, step + 1});
            }

            it->second.clear(); // 避免重复遍历同一批邻居
        }
    }

    return 0;
}

int main() {
    string beginWord, endWord;
    int n;
    cin >> beginWord >> endWord >> n;

    vector<string> wordList(n);
    for (int i = 0; i < n; ++i) {
        cin >> wordList[i];
    }

    cout << ladderLength(beginWord, endWord, wordList) << endl;
    return 0;
}
```

输入示例：

```text
hit cog 6
hot dot dog lot log cog
```

输出：

```text
5
```

## 复杂度

设单词数量为 `n`，单词长度为 `L`。

```text
时间复杂度: O(n * L^2)
空间复杂度: O(n * L)
```

这里的 `L^2` 来自生成 pattern 时复制字符串；如果用原地修改或更底层表示，可以降低常数。

## 易错点

1. 如果 `endWord` 不在词表中，直接返回 0。
2. BFS 的初始步数是 1，因为路径包含 `beginWord`。
3. 访问过的单词要立刻标记，避免重复入队。
4. 清空已处理的 pattern 邻接表可以减少重复遍历，否则容易超时。
5. 如果题目要求输出路径，需要额外记录 parent，而不仅是距离。
