# 9.判断链表是否有环

## 题目

给定一个单链表，判断链表中是否存在环。面试中如果要求“自己写输入输出构建链表”，通常会额外给出一个 `pos`，表示尾节点连接到第几个节点：

```text
values = [3, 2, 0, -4]
pos = 1
```

表示尾节点 `-4` 指向下标为 1 的节点 `2`，链表有环。

如果 `pos = -1`，表示尾节点不连接任何节点，链表无环。

## 思路

使用 Floyd 快慢指针：

1. `slow` 每次走一步。
2. `fast` 每次走两步。
3. 如果链表有环，`fast` 一定会在环中追上 `slow`。
4. 如果 `fast` 或 `fast->next` 先走到空，说明无环。

## 扩展：两个速度不同、起点不同的指针一定相遇吗

不一定。进入环以后，可以把环看成长度为 `L` 的模空间。两个指针每轮分别走 `v1`、`v2` 步，初始相对距离为 `d`，第 `t` 轮后相对距离满足：

```text
d + (v2 - v1) * t ≡ 0 (mod L)
```

这个同余方程有解的条件是：

```text
gcd(|v2 - v1|, L) 能整除 d
```

因此：

1. 如果速度相同，只有起点相同才会相遇。
2. 如果 `|v2 - v1|` 和环长 `L` 互质，那么无论初始距离是多少，最终都会相遇。
3. Floyd 判环里慢指针走 1 步、快指针走 2 步，相对速度是 1，`gcd(1, L) = 1`，所以只要有环就一定相遇。
4. 如果一个走 2 步、一个走 4 步，相对速度是 2，环长是偶数且初始距离是奇数时，就永远不会踩到同一个节点。

## 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;

    explicit ListNode(int x) : val(x), next(nullptr) {}
};

bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast) {
            return true;
        }
    }

    return false;
}

ListNode* buildList(const vector<int>& values, int pos) {
    if (values.empty()) {
        return nullptr;
    }

    vector<ListNode*> nodes;
    nodes.reserve(values.size());

    for (int value : values) {
        nodes.push_back(new ListNode(value));
    }

    for (size_t i = 1; i < nodes.size(); ++i) {
        nodes[i - 1]->next = nodes[i];
    }

    if (pos >= 0 && pos < static_cast<int>(nodes.size())) {
        nodes.back()->next = nodes[pos];
    }

    return nodes[0];
}

int main() {
    int n;
    cin >> n;

    vector<int> values(n);
    for (int i = 0; i < n; ++i) {
        cin >> values[i];
    }

    int pos;
    cin >> pos;

    ListNode* head = buildList(values, pos);
    cout << (hasCycle(head) ? "true" : "false") << endl;

    return 0;
}
```

输入示例：

```text
4
3 2 0 -4
1
```

输出：

```text
true
```

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(1)，不算构建链表时为了保存节点地址使用的辅助数组
```

## 易错点

1. 循环条件必须是 `fast != nullptr && fast->next != nullptr`，否则 `fast->next->next` 可能空指针。
2. 判环比较的是节点指针是否相等，不是节点值是否相等。
3. 如果题目要求构建带环链表，必须保存每个节点地址，才能让尾节点指回指定节点。
4. 带环链表不能用普通遍历释放全部节点，否则会死循环；面试手撕一般不要求释放。

## 扩展：找到入环点

如果快慢指针相遇，再让一个指针从头节点出发，另一个从相遇点出发，每次都走一步，它们再次相遇的位置就是入环点。

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast) {
            ListNode* p = head;
            while (p != slow) {
                p = p->next;
                slow = slow->next;
            }
            return p;
        }
    }

    return nullptr;
}
```
