# 8.版本号排序

## 题目

给定一个存储版本号的字符串数组，按版本号从小到大排序。

例如：

```text
["1.0.10", "1.0.2", "1.0", "1.0.0", "2.0"]

排序后:
["1.0", "1.0.0", "1.0.2", "1.0.10", "2.0"]
```

这里默认版本号由数字和点号组成。缺失的段按 `0` 处理，因此 `1.0` 和 `1.0.0` 数值上相等。

## 思路

不能直接按字符串字典序排序，因为：

```text
"1.0.10" < "1.0.2"  // 字典序成立，但版本语义不成立
```

正确做法是：

1. 按 `.` 拆分版本号。
2. 逐段按数字大小比较。
3. 为避免整数溢出，不直接转成 `int` 或 `long long`，而是去掉前导零后比较长度和字典序。
4. 如果某个版本段数较少，缺失段按 `"0"` 处理。

## 代码

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> sortVersions(vector<string> versions) {
        stable_sort(versions.begin(), versions.end(), [](const string& a, const string& b) {
            return compareVersion(a, b) < 0;
        });
        return versions;
    }

private:
    static vector<string> split(const string& s) {
        vector<string> parts;
        string cur;

        for (char ch : s) {
            if (ch == '.') {
                parts.push_back(cur);
                cur.clear();
            } else {
                cur.push_back(ch);
            }
        }
        parts.push_back(cur);
        return parts;
    }

    static string normalize(const string& part) {
        size_t pos = part.find_first_not_of('0');
        if (pos == string::npos) {
            return "0";
        }
        return part.substr(pos);
    }

    static int comparePart(const string& lhs, const string& rhs) {
        string a = normalize(lhs);
        string b = normalize(rhs);

        if (a.size() != b.size()) {
            return a.size() < b.size() ? -1 : 1;
        }
        if (a == b) {
            return 0;
        }
        return a < b ? -1 : 1;
    }

    static int compareVersion(const string& lhs, const string& rhs) {
        vector<string> a = split(lhs);
        vector<string> b = split(rhs);
        size_t n = max(a.size(), b.size());

        for (size_t i = 0; i < n; ++i) {
            const string partA = i < a.size() ? a[i] : "0";
            const string partB = i < b.size() ? b[i] : "0";

            int cmp = comparePart(partA, partB);
            if (cmp != 0) {
                return cmp;
            }
        }
        return 0;
    }
};
```

## 复杂度

假设有 `n` 个版本号，平均长度为 `L`：

```text
比较一次: O(L)
排序整体: O(n log n * L)
额外空间: O(L)，比较时拆分字符串
```

## 易错点

1. 不能用普通字符串排序。
2. 直接转整数可能溢出，尤其是版本段很长时。
3. 前导零不影响数值大小，例如 `1.02` 和 `1.2` 相等。
4. `1.0` 和 `1.0.0` 是否相等要提前和面试官确认；常见规则是缺失段按 0。
5. 如果版本号带 `alpha`、`beta`、`rc` 等后缀，需要额外定义预发布版本的比较规则。
