# 根据前序和中序还原二叉树

给定二叉树的前序遍历和中序遍历，如果节点值不重复，可以唯一还原这棵二叉树。

## 1. 核心思路

1. 前序遍历顺序是 `根 -> 左 -> 右`，所以当前前序区间第一个元素就是根。
2. 中序遍历顺序是 `左 -> 根 -> 右`，在中序中找到根的位置后，左边是左子树，右边是右子树。
3. 左子树节点数为 `rootIndex - inLeft`，据此切分前序区间。
4. 递归构造左子树和右子树。
5. 用哈希表保存中序下标，避免每层线性查找。

## 2. C++ 实现

```cpp
#include <stdexcept>
#include <unordered_map>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;

    explicit TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        if (preorder.size() != inorder.size()) {
            throw invalid_argument("invalid traversal size");
        }

        unordered_map<int, int> pos;
        for (int i = 0; i < static_cast<int>(inorder.size()); ++i) {
            pos[inorder[i]] = i;
        }

        return build(preorder, 0, preorder.size(),
                     0, inorder.size(), pos);
    }

private:
    TreeNode* build(const vector<int>& pre,
                    int preL,
                    int preR,
                    int inL,
                    int inR,
                    const unordered_map<int, int>& pos) {
        if (preL >= preR) {
            return nullptr;
        }

        int rootVal = pre[preL];
        auto it = pos.find(rootVal);
        if (it == pos.end() || it->second < inL || it->second >= inR) {
            throw invalid_argument("invalid traversal content");
        }

        int mid = it->second;
        int leftSize = mid - inL;

        TreeNode* root = new TreeNode(rootVal);
        root->left = build(pre, preL + 1, preL + 1 + leftSize,
                           inL, mid, pos);
        root->right = build(pre, preL + 1 + leftSize, preR,
                            mid + 1, inR, pos);
        return root;
    }
};
```

这里使用左闭右开区间 `[L, R)`，可以减少 `+1/-1` 边界错误。

## 3. 复杂度

1. 时间复杂度：`O(n)`，每个节点构造一次，哈希表查询均摊 `O(1)`。
2. 空间复杂度：`O(n)`，哈希表 `O(n)`，递归栈最坏 `O(n)`。
3. 如果不使用哈希表，每层在中序数组中查找根，最坏会退化为 `O(n^2)`。

## 4. 易错点

1. 节点值重复时，前序和中序不能唯一确定一棵树。
2. 前序和中序元素集合不一致时，输入非法。
3. 递归区间要保持语义一致，推荐全程使用左闭右开。
4. C++ 手写 `new` 后要明确谁释放树；工程中可以用 `unique_ptr` 表达所有权。
5. 树退化成链表时递归深度是 `O(n)`，极大输入可能栈溢出。

## 5. 面试回答模板

前序第一个元素是根节点，在中序里找到根的位置，左边就是左子树，右边就是右子树。左子树大小可以用来切分前序数组，然后递归构建左右子树。为了避免每层扫描中序数组，先用哈希表记录每个值在中序中的位置，整体时间复杂度 `O(n)`、空间复杂度 `O(n)`。前提是节点值不重复，否则无法唯一还原。
