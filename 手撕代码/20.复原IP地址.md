# 20. 复原 IP 地址

## 题目

给定一个只包含数字的字符串，返回所有可能的合法 IPv4 地址。

IPv4 地址由 4 段组成，每段范围是 `[0, 255]`，段与段之间用 `.` 分隔。

## 思路：回溯

每一段长度只能是 1 到 3。

合法段满足：

1. 不能为空。
2. 数值在 `[0, 255]`。
3. 如果长度大于 1，不能以 `0` 开头。

用回溯枚举 4 段即可。

## 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> restoreIpAddresses(string s) {
        vector<string> ans;
        vector<string> path;
        dfs(s, 0, 0, path, ans);
        return ans;
    }

private:
    void dfs(const string& s, int pos, int part,
             vector<string>& path, vector<string>& ans) {
        if (part == 4) {
            if (pos == static_cast<int>(s.size())) {
                ans.push_back(path[0] + "." + path[1] + "." + path[2] + "." + path[3]);
            }
            return;
        }

        int remainChars = static_cast<int>(s.size()) - pos;
        int remainParts = 4 - part;
        if (remainChars < remainParts || remainChars > remainParts * 3) {
            return;
        }

        int value = 0;
        for (int len = 1; len <= 3 && pos + len <= static_cast<int>(s.size()); ++len) {
            if (len > 1 && s[pos] == '0') {
                break;
            }

            value = value * 10 + (s[pos + len - 1] - '0');
            if (value > 255) {
                break;
            }

            path.push_back(s.substr(pos, len));
            dfs(s, pos + len, part + 1, path, ans);
            path.pop_back();
        }
    }
};
```

## 复杂度

IPv4 固定 4 段，每段最多 3 种长度，搜索空间很小：

```text
时间复杂度: O(3^4)
空间复杂度: O(4)
```

如果把输出结果算入空间，则还要加上结果集大小。

## 易错点

1. `"0"` 合法，`"00"`、`"01"` 不合法。
2. 每段最大值是 255。
3. 必须刚好用完整个字符串。
4. 可以用剩余字符数剪枝，避免无意义递归。
