# 排序数组查找首尾位置

题目：给定一个非降序数组 `nums` 和目标值 `target`，返回目标值在数组中的第一个和最后一个位置；不存在则返回 `[-1, -1]`。

## 1. 思路

这题是二分边界问题：

1. 用 `lower_bound` 找第一个 `>= target` 的位置。
2. 用 `upper_bound` 找第一个 `> target` 的位置。
3. 如果 `left` 越界或 `nums[left] != target`，说明不存在。
4. 否则答案是 `[left, right - 1]`。

复杂度：时间 `O(log n)`，空间 `O(1)`。

## 2. C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int left = lowerBound(nums, target);
        if (left == static_cast<int>(nums.size()) || nums[left] != target) {
            return {-1, -1};
        }

        int right = upperBound(nums, target) - 1;
        return {left, right};
    }

private:
    int lowerBound(const vector<int>& nums, int target) {
        int l = 0;
        int r = static_cast<int>(nums.size());
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] < target) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return l;
    }

    int upperBound(const vector<int>& nums, int target) {
        int l = 0;
        int r = static_cast<int>(nums.size());
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] <= target) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return l;
    }
};
```

## 3. 易错点

1. 普通二分命中后不能直接返回，因为目标可能有多个重复值。
2. `mid` 用 `l + (r - l) / 2`，避免 `l + r` 溢出。
3. 半开区间 `[l, r)` 更适合写边界查找。
4. 空数组时 `r = nums.size()` 仍然安全。
5. `upper_bound` 返回的是第一个大于 target 的位置，最后一个 target 要减 1。
