# 翻转链表

题目：给定单链表头节点，反转链表并返回新的头节点。

## 迭代写法

用三个指针：`prev` 保存已反转部分头部，`cur` 当前节点，`next` 暂存后续节点。

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* cur = head;

    while (cur != nullptr) {
        ListNode* next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }

    return prev;
}
```

## 递归写法

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* reverseListRecursive(ListNode* head) {
    if (head == nullptr || head->next == nullptr) {
        return head;
    }

    ListNode* newHead = reverseListRecursive(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}
```

## 两两翻转链表

两两翻转是链表反转的局部版本：每次只交换相邻两个节点，不能只交换节点值。常见写法是使用虚拟头节点，维护 `prev` 指向当前待交换 pair 的前一个节点。

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* swapPairs(ListNode* head) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;

    while (prev->next && prev->next->next) {
        ListNode* first = prev->next;
        ListNode* second = first->next;

        first->next = second->next;
        second->next = first;
        prev->next = second;

        prev = first;
    }

    return dummy.next;
}
```

易错点：

1. 交换的是节点指针，不是 `val`，否则会破坏节点对象语义。
2. 每轮交换后 `prev` 要移动到原来的第一个节点，也就是交换后的第二个节点。
3. 奇数长度链表最后一个节点保持不变。

## 复杂度

1. 迭代：时间 `O(n)`，空间 `O(1)`。
2. 递归：时间 `O(n)`，递归栈空间 `O(n)`。
3. 两两翻转：时间 `O(n)`，空间 `O(1)`。

## 易错点

1. 反转前必须暂存 `next`，否则会丢失后续链表。
2. 递归写法最后要把 `head->next = nullptr`，否则会形成环。
3. 空链表和单节点链表要直接返回。
4. 工程中长链表优先用迭代，避免递归栈过深。

## 面试回答模板

翻转链表用迭代最稳：维护 `prev`、`cur`，每次先保存 `cur->next`，再把 `cur->next` 指向 `prev`，然后两个指针前进。结束时 `prev` 就是新头。时间 `O(n)`，额外空间 `O(1)`。递归也能写，但长链表有栈溢出风险。
