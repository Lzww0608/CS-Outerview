# 131. 匹配子序列数量

## 题目

给定主串 `s` 和一组单词 `words`，统计有多少个单词是 `s` 的子序列。子序列要求字符相对顺序不变，但不要求连续。

例如：

```text
s = "abcde"
words = ["a", "bb", "acd", "ace"]
```

答案是 `3`，因为 `"a"`、`"acd"`、`"ace"` 是 `s` 的子序列。

## 方法一：逐个双指针

对每个单词用双指针判断是否为子序列。

```cpp
#include <string>
#include <vector>

bool isSubsequence(const std::string& word, const std::string& s) {
    int i = 0;
    for (char c : s) {
        if (i < static_cast<int>(word.size()) && word[i] == c) {
            ++i;
        }
    }
    return i == static_cast<int>(word.size());
}

int numMatchingSubseqSimple(const std::string& s,
                            const std::vector<std::string>& words) {
    int ans = 0;
    for (const auto& word : words) {
        if (isSubsequence(word, s)) {
            ++ans;
        }
    }
    return ans;
}
```

复杂度是 `O(|s| * words.size())` 级别，单词多时会慢。

## 方法二：按等待字符分桶

把每个单词当前等待匹配的位置放到对应字符桶中。遍历主串 `s` 时，只推进正在等待当前字符的单词。

```cpp
#include <array>
#include <queue>
#include <string>
#include <utility>
#include <vector>

int numMatchingSubseq(const std::string& s,
                      const std::vector<std::string>& words) {
    using State = std::pair<int, int>; // word index, next position
    std::array<std::queue<State>, 26> buckets;

    int emptyWords = 0;
    for (int i = 0; i < static_cast<int>(words.size()); ++i) {
        if (words[i].empty()) {
            ++emptyWords;
        } else {
            buckets[words[i][0] - 'a'].push({i, 0});
        }
    }

    int ans = emptyWords;
    for (char c : s) {
        auto& q = buckets[c - 'a'];
        int cnt = static_cast<int>(q.size());
        while (cnt-- > 0) {
            auto [idx, pos] = q.front();
            q.pop();

            ++pos;
            if (pos == static_cast<int>(words[idx].size())) {
                ++ans;
            } else {
                buckets[words[idx][pos] - 'a'].push({idx, pos});
            }
        }
    }
    return ans;
}
```

每个单词的每个字符最多被推进一次，复杂度是 `O(|s| + totalLen(words))`。

## 扩展：统计一个目标串出现为子序列的次数

如果题目变成“给定 `s` 和 `t`，问 `t` 在 `s` 中作为子序列出现多少次”，用动态规划：

```cpp
#include <string>
#include <vector>

long long countSubsequence(const std::string& s, const std::string& t) {
    std::vector<long long> dp(t.size() + 1, 0);
    dp[0] = 1;

    for (char c : s) {
        for (int j = static_cast<int>(t.size()) - 1; j >= 0; --j) {
            if (t[j] == c) {
                dp[j + 1] += dp[j];
            }
        }
    }
    return dp[t.size()];
}
```

`dp[j]` 表示已经匹配 `t` 的前 `j` 个字符的方案数。倒序更新是为了避免同一个 `s[i]` 被重复使用。

## 易错点

1. 子序列不是子串，不要求连续。
2. 分桶法遍历桶时要先记录当前桶大小，只处理本轮已有状态；否则当前字符可能被同一个单词重复消费。
3. 字符集不一定只有小写字母，工程中可用 `unordered_map<char, queue<State>>`。
4. 统计方案数时可能溢出，面试要说明是否取模或使用更大整数类型。

## 面试回答模板

如果是统计 `words` 中多少单词是主串子序列，简单做法是每个单词双指针，但复杂度偏高。更好的方法是按“当前等待的字符”分桶，遍历主串时只推进等待当前字符的状态，每个字符最多推进一次，复杂度 `O(|s| + totalLen)`。如果题意是统计某个目标串作为子序列出现的次数，则用一维 DP，`dp[j]` 表示匹配目标前 `j` 个字符的方案数，并倒序更新。
