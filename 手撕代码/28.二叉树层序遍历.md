# 二叉树层序遍历

层序遍历是按深度从上到下、同一层从左到右遍历二叉树，本质是 BFS，使用队列保存下一批要访问的节点。

## 代码

```cpp
#include <queue>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

std::vector<std::vector<int>> levelOrder(TreeNode* root) {
    std::vector<std::vector<int>> ans;
    if (root == nullptr) {
        return ans;
    }

    std::queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int levelSize = static_cast<int>(q.size());
        std::vector<int> level;
        level.reserve(levelSize);

        for (int i = 0; i < levelSize; ++i) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);

            if (node->left != nullptr) {
                q.push(node->left);
            }
            if (node->right != nullptr) {
                q.push(node->right);
            }
        }

        ans.push_back(std::move(level));
    }

    return ans;
}
```

## 复杂度

1. 时间复杂度：`O(n)`，每个节点入队出队一次。
2. 空间复杂度：`O(w)`，`w` 是二叉树最大宽度，最坏 `O(n)`。

## 易错点

1. 每一层开始时要固定当前队列长度，否则新入队的下一层节点会被混到当前层。
2. 空树直接返回空数组。
3. 如果只要求一维层序遍历，可以不记录 `levelSize`，直接按队列顺序输出。

## 面试回答模板

层序遍历用队列做 BFS。先把根节点入队，每轮记录当前队列大小，这个大小就是当前层节点数；依次弹出这些节点，把它们的左右孩子入队，并把值加入当前层结果。每个节点只处理一次，时间 `O(n)`，空间取决于树的最大宽度。
