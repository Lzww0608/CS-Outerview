# STL unique 函数实现

题目：手写 STL 中 `unique` 的核心逻辑。`std::unique` 的作用是把相邻重复元素移动到区间尾部，并返回去重后逻辑区间的尾迭代器。它不会真正删除容器元素。

## 1. unique 的语义

`unique` 只去除相邻重复元素：

```text
[1, 1, 2, 2, 3] -> [1, 2, 3, ?, ?]
返回指向第一个 ? 的迭代器
```

如果输入是：

```text
[1, 2, 1]
```

由于重复的 `1` 不相邻，`unique` 不会把它们合并。通常要先排序，再 `unique`：

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```

## 2. 双指针实现

核心思路：

1. `result` 指向去重后区间最后一个有效元素。
2. `first` 扫描后续元素。
3. 如果当前元素和 `result` 不相等，就把当前元素移动到 `++result`。
4. 最后返回 `++result`，表示逻辑尾部。

```cpp
#include <iterator>
#include <utility>

template <class ForwardIt>
ForwardIt my_unique(ForwardIt first, ForwardIt last) {
    if (first == last) {
        return last;
    }

    ForwardIt result = first;
    while (++first != last) {
        if (!(*result == *first)) {
            ++result;
            if (result != first) {
                *result = std::move(*first);
            }
        }
    }
    return ++result;
}
```

这个版本要求迭代器至少是 Forward Iterator，因为需要多次读写同一区间。

## 3. 支持自定义谓词

标准库还支持传入二元谓词：

```cpp
template <class ForwardIt, class BinaryPred>
ForwardIt my_unique(ForwardIt first, ForwardIt last, BinaryPred pred) {
    if (first == last) {
        return last;
    }

    ForwardIt result = first;
    while (++first != last) {
        if (!pred(*result, *first)) {
            ++result;
            if (result != first) {
                *result = std::move(*first);
            }
        }
    }
    return ++result;
}
```

示例：忽略大小写去重相邻字符时，可以自定义比较函数。

## 4. 为什么 unique 后还要 erase

`unique` 是泛型算法，只操作迭代器区间，不知道底层容器是什么，也不能改变容器大小。因此它只能把不重复元素移动到前面，并返回新的逻辑尾部。

真正删除尾部元素需要容器自己完成：

```cpp
v.erase(my_unique(v.begin(), v.end()), v.end());
```

这就是常见的 erase-remove idiom。

## 5. 复杂度

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(1)`。
3. 最多做 `n - 1` 次相等比较。
4. 赋值或移动次数不超过 `n`。

## 6. 易错点

1. `unique` 只处理相邻重复，不是全局去重。
2. 空区间要直接返回 `last`。
3. 返回的是新逻辑尾迭代器，不是容器。
4. 算法不会改变容器 size，需要配合 `erase`。
5. 使用 `std::move` 可以减少大对象拷贝，但被移动到尾部的元素值处于有效但未指定状态。
6. 判断不相等建议写成 `!(*result == *first)`，更符合只要求 `==` 的语义。

## 7. 面试回答模板

`std::unique` 的语义是去除相邻重复元素，把不重复元素稳定地移动到前面，并返回新的逻辑尾部。实现上用两个迭代器：`result` 指向当前去重区间最后一个元素，`first` 向后扫描；如果 `*first` 和 `*result` 不相等，就把 `*first` 移动到 `++result`。最后返回 `++result`。它只做区间重排，不改变容器大小，所以 vector 真正删除尾部元素时要写 `v.erase(unique(v.begin(), v.end()), v.end())`。
