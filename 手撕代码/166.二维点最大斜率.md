# 166. 二维点最大斜率

题目：二维平面上有 `n` 个点，找出两两之间斜率最大的两个点。

## 1. 核心结论

如果不存在相同 `x` 坐标的点，把点按 `x` 从小到大排序后，最大斜率一定出现在相邻两个点之间。

原因是：对排序后的点 `i < j`，

```text
slope(i, j) = (y[j] - y[i]) / (x[j] - x[i])
```

可以看成中间相邻线段斜率的加权平均：

```text
y[j] - y[i] = sum(y[k+1] - y[k])
x[j] - x[i] = sum(x[k+1] - x[k])
```

因为所有 `x[k+1] - x[k] > 0`，所以整体斜率不会超过这些相邻斜率中的最大值。于是只需要排序后检查相邻点。

## 2. 垂直线怎么处理

如果存在两个点 `x` 相同但 `y` 不同，它们之间斜率可以视为正无穷或不存在。很多面试题会认为这是最大斜率，应直接返回这对点。

如果题目明确不允许垂直线，或者只讨论有限斜率，则需要跳过相同 `x` 的点，并提前向面试官确认。

## 3. C++ 实现

用交叉相乘比较斜率，避免浮点误差：

```cpp
#include <algorithm>
#include <optional>
#include <vector>
using namespace std;

struct Point {
    long long x;
    long long y;
};

struct Answer {
    Point a;
    Point b;
    bool infinite = false;
};

bool greaterSlope(const Point& a1, const Point& b1,
                  const Point& a2, const Point& b2) {
    long long dy1 = b1.y - a1.y;
    long long dx1 = b1.x - a1.x;
    long long dy2 = b2.y - a2.y;
    long long dx2 = b2.x - a2.x;
    return static_cast<__int128>(dy1) * dx2 >
           static_cast<__int128>(dy2) * dx1;
}

optional<Answer> maxSlopePair(vector<Point> points) {
    if (points.size() < 2) {
        return nullopt;
    }

    sort(points.begin(), points.end(), [](const Point& a, const Point& b) {
        if (a.x != b.x) return a.x < b.x;
        return a.y < b.y;
    });

    for (int i = 1; i < static_cast<int>(points.size()); ++i) {
        if (points[i].x == points[i - 1].x && points[i].y != points[i - 1].y) {
            return Answer{points[i - 1], points[i], true};
        }
    }

    bool has = false;
    Answer ans;
    for (int i = 1; i < static_cast<int>(points.size()); ++i) {
        if (points[i].x == points[i - 1].x) {
            continue; // 重复点
        }
        if (!has || greaterSlope(points[i - 1], points[i], ans.a, ans.b)) {
            ans = Answer{points[i - 1], points[i], false};
            has = true;
        }
    }

    if (!has) {
        return nullopt;
    }
    return ans;
}
```

## 4. 复杂度

```text
时间复杂度: O(n log n)
空间复杂度: O(1) 或 O(n)，取决于排序是否原地
```

排序是主要成本，扫描相邻点是 `O(n)`。

## 5. 易错点

1. 暴力枚举所有点对是 `O(n^2)`，数据量大时不可接受。
2. 要先确认相同 `x` 的垂直线如何定义；如果算无穷大，可以直接返回。
3. 比较斜率不要直接用 `double`，坐标大时有精度问题。
4. 排序后只比较相邻点的结论依赖 `x` 严格递增；有重复 `x` 时要单独处理。
5. 如果题目把斜率定义成无向直线的绝对斜率，需要比较绝对值，结论和实现要相应调整。

## 6. 面试回答模板

我会先按 `x` 排序。任意两个点之间的斜率等于它们之间若干相邻线段斜率的加权平均，所以最大斜率一定出现在排序后相邻点之间。然后线性扫描相邻点，用交叉相乘比较斜率，避免浮点误差。相同 `x` 的点如果 `y` 不同，斜率是无穷大，需要提前按题意直接返回或排除。整体复杂度 `O(n log n)`。
