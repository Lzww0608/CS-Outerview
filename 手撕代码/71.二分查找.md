# 二分查找

题目：在有序数组中查找目标值，返回下标；如果不存在返回 `-1`。

## 1. 基础版本

```cpp
#include <vector>
using namespace std;

int binarySearch(const vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        }
        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

`mid = left + (right - left) / 2` 可以避免 `left + right` 整数溢出。

## 2. 查找第一个大于等于 target 的位置

很多二分题更适合写成 lower_bound 模板：

```cpp
int lowerBound(const vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()); // [left, right)

    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

返回值含义：

1. `left == nums.size()`：所有元素都小于 target。
2. `nums[left] == target`：target 第一次出现的位置。
3. `nums[left] > target`：第一个大于 target 的位置。

## 3. 查找最后一个小于等于 target 的位置

可以基于 upper_bound：

```cpp
int upperBound(const vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size());

    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left; // 第一个 > target 的位置
}
```

最后一个 `<= target` 的位置是 `upperBound(nums, target) - 1`。

## 4. 二分的本质

二分不只用于数组查找，也用于“答案具有单调性”的问题。

形式化地看，是在一个布尔序列中找边界：

```text
false false false true true true
                  ^
              第一个 true
```

例如：

1. 最小可行速度。
2. 最小容量。
3. 第一个错误版本。
4. 峰值或旋转数组中的边界。

## 5. 易错点

1. 区间定义要统一：闭区间 `[left, right]` 用 `left <= right`，半开区间 `[left, right)` 用 `left < right`。
2. 更新边界时必须保证区间缩小，否则会死循环。
3. 不要写 `(left + right) / 2`，可能溢出。
4. 有重复元素时，普通二分返回任意一个命中位置；要找左右边界用 lower_bound/upper_bound。
5. 空数组时闭区间版本的 `right = size - 1` 要注意类型转换，避免 unsigned 下溢。

## 6. 面试回答模板

二分查找要求数组有序，或者答案空间具有单调性。普通查找用闭区间 `[left, right]`，每次取 `mid = left + (right-left)/2`，命中返回；小于目标就去右半边，否则去左半边，时间复杂度 `O(log n)`。如果要处理重复元素，建议写 lower_bound 模板，也就是在半开区间 `[left, right)` 中找第一个大于等于 target 的位置。二分最关键的是区间语义一致、边界更新能收缩、mid 计算不溢出。
