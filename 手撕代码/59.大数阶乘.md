# 大数阶乘

题目：计算 `n!`，其中结果可能远超 `long long` 范围，需要输出完整十进制结果。

## 1. 思路

大数阶乘的核心是用数组或字符串模拟十进制高精度乘法。最常见做法是用 `vector<int>` 按低位在前存储每一位数字：

```text
12345 存为 [5, 4, 3, 2, 1]
```

计算时从 `1` 乘到 `n`，每次把当前大整数乘以一个普通整数 `x`，逐位处理进位。

## 2. C++ 实现

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

std::string factorial(int n) {
    if (n < 0) {
        return "";
    }

    std::vector<int> digits{1};

    for (int x = 2; x <= n; ++x) {
        int carry = 0;
        for (int& digit : digits) {
            int value = digit * x + carry;
            digit = value % 10;
            carry = value / 10;
        }

        while (carry > 0) {
            digits.push_back(carry % 10);
            carry /= 10;
        }
    }

    std::string ans;
    ans.reserve(digits.size());
    for (auto it = digits.rbegin(); it != digits.rend(); ++it) {
        ans.push_back(static_cast<char>('0' + *it));
    }
    return ans;
}

int main() {
    int n;
    std::cin >> n;
    std::cout << factorial(n) << '\n';
    return 0;
}
```

## 3. 复杂度

设 `n!` 的十进制位数为 `D`，每次乘法需要扫描当前位数：

```text
时间复杂度：O(n * D)
空间复杂度：O(D)
```

更准确地说，`D = Θ(n log n)`，来自 Stirling 公式：

```text
log10(n!) = Θ(n log10 n)
```

面试手写通常不需要使用 FFT 或大整数库，数组模拟乘法足够。

## 4. 优化写法

如果 `n` 较大，可以把进制从 10 改成 `10000` 或 `100000000`，每个数组元素保存多位，减少循环次数：

```text
base = 10000，一个元素保存 4 位
```

输出时最高位正常输出，其余块需要补前导零。

这种写法更快，但代码细节更多。普通面试场景先写单 digit 版本，讲清楚可以用大 base 优化即可。

## 5. 易错点

1. `0! = 1`，`1! = 1`。
2. 低位在前能让进位处理更简单，输出时再反转。
3. 进位可能有多位，内层循环结束后要 `while (carry > 0)`。
4. 不能用 `int`、`long long` 保存最终结果。
5. 如果使用大 base，输出中间块时要补齐固定位数。

## 6. 面试回答模板

大数阶乘可以用数组模拟高精度整数，低位在前保存十进制数字。初始结果为 1，从 2 到 n 依次把当前大整数乘以普通整数，逐位计算 `digit * x + carry`，当前位取模，进位向高位传递。最终反向输出数组。时间复杂度和结果位数有关，约为 `O(n * D)`，空间复杂度 `O(D)`。如果要优化，可以用 `10000` 或 `1e8` 作为进制减少数组长度。
