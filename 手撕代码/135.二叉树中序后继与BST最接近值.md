# 135. 二叉树中序后继与 BST 最接近值

这份微软面经里出现了两个二叉树查找题：

1. 给定有父指针的二叉树节点，找中序遍历下一个节点。
2. 给定二叉搜索树和 `val`，找最接近 `val` 的节点。

前者考中序遍历结构，后者考 BST 有序性。

## 1. 有父指针的中序后继

中序遍历顺序是“左、根、右”。节点 `x` 的后继分两种情况：

1. 如果 `x` 有右子树，后继是右子树中最左的节点。
2. 如果 `x` 没有右子树，就沿父指针向上找，直到当前节点是父节点的左孩子；这个父节点就是后继。

```cpp
struct Node {
    int val;
    Node* left = nullptr;
    Node* right = nullptr;
    Node* parent = nullptr;
};

Node* leftmost(Node* root) {
    while (root && root->left) {
        root = root->left;
    }
    return root;
}

Node* inorderSuccessor(Node* x) {
    if (x == nullptr) {
        return nullptr;
    }
    if (x->right != nullptr) {
        return leftmost(x->right);
    }

    Node* cur = x;
    Node* p = x->parent;
    while (p != nullptr && cur == p->right) {
        cur = p;
        p = p->parent;
    }
    return p;
}
```

复杂度是 `O(h)`，`h` 是树高。

## 2. BST 中找最接近 val 的节点

BST 满足左子树小于根、右子树大于根。可以像普通查找一样往下走，同时维护当前最优答案。

```cpp
#include <cstdlib>
#include <limits>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left = nullptr;
    TreeNode* right = nullptr;
};

TreeNode* closestInBST(TreeNode* root, int target) {
    TreeNode* best = nullptr;
    long long bestDiff = numeric_limits<long long>::max();

    while (root != nullptr) {
        long long diff = llabs(static_cast<long long>(root->val) - target);
        if (diff < bestDiff) {
            bestDiff = diff;
            best = root;
        }

        if (target < root->val) {
            root = root->left;
        } else if (target > root->val) {
            root = root->right;
        } else {
            return best;
        }
    }

    return best;
}
```

复杂度：

1. 平衡 BST：`O(log n)`。
2. 退化 BST：`O(n)`。
3. 额外空间：迭代写法 `O(1)`。

## 3. 易错点

1. 普通二叉树找中序后继不能用 BST 大小关系；有父指针时用结构关系。
2. 没有后继时返回 `nullptr`，例如中序遍历最后一个节点。
3. BST 最接近值遇到距离相等时要说明策略，例如返回较小值、较大值或先遇到的节点。
4. 差值计算可能溢出 `int`，用 `long long` 更稳。

## 4. 面试回答模板

有父指针的中序后继分两类：如果当前节点有右子树，就返回右子树最左节点；否则沿父指针向上走，直到当前节点是父节点左孩子，此时父节点就是后继。BST 找最接近值则利用有序性，从根开始按目标值向左或向右走，沿途维护差值最小的节点。平衡树下是 `O(log n)`，退化时是 `O(n)`。
