# 二叉树遍历

二叉树遍历是按某种顺序访问树中每个节点。常见遍历包括前序、中序、后序和层序。面试里要说明访问顺序、递归写法、迭代写法和复杂度。

## 1. 前序遍历

访问顺序：

```text
根 -> 左 -> 右
```

递归写法：

```cpp
void preorder(TreeNode* root, std::vector<int>& ans) {
    if (root == nullptr) {
        return;
    }
    ans.push_back(root->val);
    preorder(root->left, ans);
    preorder(root->right, ans);
}
```

迭代写法：

```cpp
std::vector<int> preorderTraversal(TreeNode* root) {
    std::vector<int> ans;
    if (root == nullptr) {
        return ans;
    }

    std::stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();
        ans.push_back(node->val);

        if (node->right != nullptr) {
            st.push(node->right);
        }
        if (node->left != nullptr) {
            st.push(node->left);
        }
    }
    return ans;
}
```

栈先进后出，所以先压右孩子，再压左孩子。

## 2. 中序遍历

访问顺序：

```text
左 -> 根 -> 右
```

二叉搜索树的中序遍历结果是升序序列。

```cpp
std::vector<int> inorderTraversal(TreeNode* root) {
    std::vector<int> ans;
    std::stack<TreeNode*> st;
    TreeNode* cur = root;

    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) {
            st.push(cur);
            cur = cur->left;
        }

        cur = st.top();
        st.pop();
        ans.push_back(cur->val);
        cur = cur->right;
    }
    return ans;
}
```

中序迭代的核心是一路向左压栈，左子树处理完后访问根，再转向右子树。

## 3. 后序遍历

访问顺序：

```text
左 -> 右 -> 根
```

后序常用于释放树、计算子树高度、判断平衡等“先处理孩子，再处理父节点”的场景。

一种稳定的迭代写法是记录上一次访问节点：

```cpp
std::vector<int> postorderTraversal(TreeNode* root) {
    std::vector<int> ans;
    std::stack<TreeNode*> st;
    TreeNode* cur = root;
    TreeNode* last = nullptr;

    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) {
            st.push(cur);
            cur = cur->left;
        }

        TreeNode* node = st.top();
        if (node->right == nullptr || node->right == last) {
            ans.push_back(node->val);
            st.pop();
            last = node;
        } else {
            cur = node->right;
        }
    }
    return ans;
}
```

## 4. 层序遍历

层序遍历按层访问，本质是 BFS，使用队列：

```text
第 0 层 -> 第 1 层 -> 第 2 层 ...
```

```cpp
std::vector<std::vector<int>> levelOrder(TreeNode* root) {
    std::vector<std::vector<int>> ans;
    if (root == nullptr) {
        return ans;
    }

    std::queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int n = static_cast<int>(q.size());
        std::vector<int> level;
        for (int i = 0; i < n; ++i) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);
            if (node->left != nullptr) {
                q.push(node->left);
            }
            if (node->right != nullptr) {
                q.push(node->right);
            }
        }
        ans.push_back(std::move(level));
    }
    return ans;
}
```

## 5. 复杂度

1. 时间复杂度都是 `O(n)`，每个节点访问一次。
2. 递归遍历空间复杂度是递归栈 `O(h)`，`h` 是树高，最坏退化为 `O(n)`。
3. 迭代 DFS 空间复杂度是显式栈 `O(h)`。
4. 层序遍历空间复杂度是队列最大宽度 `O(w)`，最坏 `O(n)`。

## 6. 易错点

1. 前序、中序、后序说的是根节点相对左右子树的访问位置。
2. 后序迭代不能在右子树没处理完时提前访问根。
3. 层序遍历如果要按层输出，要在每层开始固定当前队列长度。
4. 递归写法简洁，但树很深时可能栈溢出。
5. 二叉搜索树只有中序遍历天然有序，前序和后序不保证升序。

## 7. 面试回答模板

二叉树常见遍历有四种：前序是根左右，中序是左根右，后序是左右根，层序是 BFS 按层访问。递归写法最直接，时间都是 `O(n)`，递归栈是 `O(h)`；迭代 DFS 用显式栈，层序用队列。中序遍历二叉搜索树可以得到有序序列，后序适合释放树或做自底向上的子树计算。
