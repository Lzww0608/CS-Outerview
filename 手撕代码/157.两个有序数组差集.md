# 157. 两个有序数组差集

## 题目

给两个有序数组 `a` 和 `b`，数组中可能有重复元素。把 `a` 中存在、但 `b` 中不存在的数据加入新数组。

面试时要先确认输出语义：

1. 如果 `a` 中某个值出现多次，且 `b` 中没有这个值，是否保留这些重复值。
2. 如果 `a` 和 `b` 都有某个值，是否删除 `a` 中该值的所有出现。
3. 是否要求输出保持有序。

下面默认语义是：**按值做差集，`b` 中出现过的值，`a` 中该值的所有出现都不输出；`b` 中没出现过的值，保留 `a` 中原有重复次数**。

## 双指针

两个数组都有序，直接用双指针扫描，不需要哈希表。

```cpp
#include <vector>
using namespace std;

vector<int> differenceSorted(const vector<int>& a, const vector<int>& b) {
    vector<int> ans;
    int i = 0;
    int j = 0;

    while (i < static_cast<int>(a.size())) {
        while (j < static_cast<int>(b.size()) && b[j] < a[i]) {
            ++j;
        }

        if (j < static_cast<int>(b.size()) && b[j] == a[i]) {
            int x = a[i];
            while (i < static_cast<int>(a.size()) && a[i] == x) {
                ++i;
            }
        } else {
            ans.push_back(a[i]);
            ++i;
        }
    }

    return ans;
}
```

示例：

```text
a = [1, 1, 2, 3, 3, 5]
b = [1, 4]
输出 [2, 3, 3, 5]
```

复杂度：

```text
时间复杂度：O(n + m)
额外空间：O(1)，不计输出数组
```

## 如果按多重集合做差

如果题目要求“`b` 中出现一次，只抵消 `a` 中一次”，例如：

```text
a = [1, 1, 1, 2]
b = [1, 1]
输出 [1, 2]
```

则相等时只同时移动一次：

```cpp
vector<int> multisetDifferenceSorted(const vector<int>& a, const vector<int>& b) {
    vector<int> ans;
    int i = 0;
    int j = 0;
    while (i < static_cast<int>(a.size())) {
        if (j == static_cast<int>(b.size()) || a[i] < b[j]) {
            ans.push_back(a[i++]);
        } else if (a[i] > b[j]) {
            ++j;
        } else {
            ++i;
            ++j;
        }
    }
    return ans;
}
```

## 易错点

1. 题目说数组有序，不要先放进哈希表，双指针更省空间。
2. 要问清楚重复元素语义：按集合差集还是多重集合差集。
3. 当 `b[j] < a[i]` 时只移动 `j`，因为 `b` 的小值不可能再匹配后续更大的 `a[i]`。
4. 输出可能很大时，可以边扫描边写出，而不是全部保存在内存里。

## 面试回答模板

两个数组有序，我会用双指针。指针 `i` 扫 `a`，指针 `j` 扫 `b`；先让 `j` 追到不小于 `a[i]` 的位置，如果相等，说明这个值在 `b` 中存在，跳过 `a` 中所有相同值；如果不相等，说明 `a[i]` 不在 `b` 中，加入结果。时间 `O(n+m)`，额外空间 `O(1)`。如果按多重集合差集，则相等时只同时跳过一个元素。
