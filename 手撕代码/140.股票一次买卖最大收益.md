# 140. 股票一次买卖最大收益

题目：股票买卖问题中，如果只允许买卖一次，如何求最大收益？

只能先买后卖，因此遍历价格时维护历史最低买入价，并用当前价格尝试卖出。

## 1. 一次遍历

```cpp
#include <algorithm>
#include <vector>
using namespace std;

int maxProfitOnce(const vector<int>& prices) {
    if (prices.empty()) {
        return 0;
    }

    int minPrice = prices[0];
    int ans = 0;

    for (int price : prices) {
        ans = max(ans, price - minPrice);
        minPrice = min(minPrice, price);
    }

    return ans;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(1)`。

## 2. 为什么不能直接找最大值减最小值

最大值必须出现在最小值之后。如果先出现高价、后出现低价，不能用后面的低价去买前面的高价。

```text
prices = [9, 1, 5]
答案是 4，不是 9 - 1 = 8
```

## 3. 动态规划视角

也可以把状态写成：

```text
hold = 到今天为止，持有一股时的最大收益
cash = 到今天为止，不持股时的最大收益

hold = max(hold, -price)
cash = max(cash, hold + price)
```

一次交易下，这和维护历史最低价等价。动态规划写法方便扩展到多次交易、含手续费、含冷冻期等变体。

## 4. 易错点

1. 没有盈利机会时通常返回 `0`，表示不交易。
2. 如果价格和天数很大，收益可能超过 `int`，可以改用 `long long`。
3. 如果题目要求必须交易一次，答案初始化和全下降数组处理要改变。
4. 多次交易版本不能直接套一次交易的历史最低价。

## 5. 面试回答模板

只允许买卖一次时，我会从左到右扫描价格，维护当前之前出现过的最低价 `minPrice`。每到一天就用 `price - minPrice` 更新最大收益，然后再更新最低价。这样天然保证买入发生在卖出之前，时间 `O(n)`，空间 `O(1)`。如果没有正收益，就返回 `0` 表示不交易。
