# 148. 两数之和

题目：给定数组 `nums` 和目标值 `target`，返回两个数的下标，使得它们的和等于 `target`。对应 LeetCode 1。

## 1. 核心思路

一边遍历，一边用哈希表记录已经见过的数字及其下标。

对于当前数字 `x = nums[i]`：

1. 需要的另一个数是 `target - x`。
2. 如果哈希表中已经存在 `target - x`，直接返回它的下标和 `i`。
3. 否则把 `x -> i` 放入哈希表。

这样可以保证不会把同一个元素使用两次，因为当前元素是在查询之后才插入。

## 2. C++ 实现

```cpp
#include <unordered_map>
#include <vector>
using namespace std;

vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> pos;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        int need = target - nums[i];
        auto it = pos.find(need);
        if (it != pos.end()) {
            return {it->second, i};
        }
        pos[nums[i]] = i;
    }
    return {};
}
```

复杂度：

```text
时间复杂度: 平均 O(n)
空间复杂度: O(n)
```

## 3. 排序双指针变体

如果题目只要求返回数值，而不是原始下标，可以排序后双指针：

```text
left = 0, right = n - 1
sum = nums[left] + nums[right]
sum 小了 left++
sum 大了 right--
```

但排序会打乱下标。如果仍要返回原始下标，需要保存 `(value, index)` 后再排序。

## 4. 易错点

1. 先查再插，避免 `target = 2 * nums[i]` 时把同一个元素用两次。
2. 数组中有重复值时，哈希表保存最近或最早下标都可以，只要先查再插。
3. `target - nums[i]` 可能整数溢出，极端输入可以用 `long long` 计算。
4. 如果题目要求返回所有不重复数值对，就不是 LeetCode 1，要排序去重或统计频次。

## 5. 面试回答模板

两数之和用哈希表。遍历到 `nums[i]` 时，先查 `target - nums[i]` 是否已经出现；如果出现，返回之前下标和当前下标；否则把当前值和下标加入哈希表。因为是先查后插，不会重复使用同一个元素。平均时间 `O(n)`，空间 `O(n)`。
