# 137. 最小覆盖子串

题目：给定 `s1`、`s2` 两个字符串，在 `s1` 中找到一个连续子串，使它包含 `s2` 中所有字符，字符顺序不要求一致。

这是经典最小覆盖子串。若只问“是否存在”，找到任意满足条件的窗口即可；若问“找到一个”，通常默认找最短的那个。

## 1. 滑动窗口

用 `need` 统计 `s2` 所需字符次数，用 `window` 统计当前窗口字符次数。右指针扩张窗口，满足条件后左指针收缩窗口。

```cpp
#include <array>
#include <climits>
#include <string>
using namespace std;

string minWindow(string s, string t) {
    if (t.empty()) {
        return "";
    }

    array<int, 256> need{};
    array<int, 256> window{};
    int required = 0;

    for (unsigned char ch : t) {
        if (need[ch] == 0) {
            ++required;
        }
        ++need[ch];
    }

    int formed = 0;
    int left = 0;
    int bestL = 0;
    int bestLen = INT_MAX;

    for (int right = 0; right < static_cast<int>(s.size()); ++right) {
        unsigned char c = static_cast<unsigned char>(s[right]);
        ++window[c];
        if (need[c] > 0 && window[c] == need[c]) {
            ++formed;
        }

        while (formed == required) {
            int len = right - left + 1;
            if (len < bestLen) {
                bestLen = len;
                bestL = left;
            }

            unsigned char d = static_cast<unsigned char>(s[left]);
            --window[d];
            if (need[d] > 0 && window[d] < need[d]) {
                --formed;
            }
            ++left;
        }
    }

    return bestLen == INT_MAX ? "" : s.substr(bestL, bestLen);
}
```

复杂度：时间 `O(|s1| + |s2|)`，空间固定字符集下 `O(1)`。

## 2. 为什么不能只用 set

如果 `s2 = "aabc"`，窗口里必须有两个 `a`。只用 `set` 会丢失次数信息，导致 `"abc"` 被误判为满足条件。

## 3. 易错点

1. 子串是连续的，不能跳着选字符。
2. `s2` 中重复字符必须按次数满足。
3. `char` 可能是有符号类型，下标数组时建议转成 `unsigned char`。
4. 如果包含 Unicode，不能简单按单字节处理，要先确定按字节、码点还是用户感知字符统计。

## 4. 真实场景

最小覆盖子串本质是“在流式序列中找满足配额约束的最短窗口”，类似：

1. 日志中找包含一组关键事件的最短时间段。
2. 搜索召回中找覆盖多个关键词的最短文本片段。
3. 风控中找某些行为都出现过的最短操作区间。

## 5. 面试回答模板

这题用滑动窗口。先统计 `s2` 每个字符需要的次数，然后右指针不断扩张窗口；当窗口满足所有字符次数时，移动左指针尽量收缩，并更新最短答案。每个指针最多移动 `n` 次，所以时间复杂度是线性的。关键是不能只判断字符集合，要判断每个字符出现次数。
