# 单词转换 CanTransform

题目：给定起点、终点和字典，判断能否通过若干次单步转换从起点变成终点。每一步只能改变一个字符，且中间结果必须在字典中。

例如：

```text
hit -> hat -> cat -> fat
```

可以转换；但 `hit -> hog` 一步改变了两个字符，不是合法单步转换。

## 1. 图搜索建模

把每个单词看成图上的一个点。如果两个单词长度相同且只差一个字符，就在它们之间连边。问题就变成：起点和终点是否连通。

最直接做法是 BFS：

```text
queue = [begin]
visited = {begin}
while queue not empty:
    word = queue.pop()
    if word == target: return true
    枚举 word 的所有一字符变化
    如果变化结果在字典且没访问过，入队
return false
```

## 2. 枚举邻居

如果单词只包含小写英文字母，长度为 `L`，每个位置尝试 26 个字符即可。

```cpp
#include <queue>
#include <string>
#include <unordered_set>
using namespace std;

bool canTransform(string begin, string target, unordered_set<string> dict) {
    if (begin.size() != target.size()) {
        return false;
    }
    if (begin == target) {
        return true;
    }

    dict.insert(target);

    queue<string> q;
    unordered_set<string> visited;
    q.push(begin);
    visited.insert(begin);

    while (!q.empty()) {
        string cur = q.front();
        q.pop();

        for (int i = 0; i < static_cast<int>(cur.size()); ++i) {
            string next = cur;
            for (char c = 'a'; c <= 'z'; ++c) {
                if (c == cur[i]) {
                    continue;
                }
                next[i] = c;
                if (next == target) {
                    return true;
                }
                if (dict.count(next) && !visited.count(next)) {
                    visited.insert(next);
                    q.push(next);
                }
            }
        }
    }
    return false;
}
```

复杂度：

1. 设字典中可达单词数为 `N`，单词长度为 `L`，字符集大小为 `C`。
2. 时间复杂度：`O(N * L * C)`。
3. 空间复杂度：`O(N)`。

## 3. 通配符桶优化

如果字符集很大，或者不想每次枚举 26 个字符，可以预处理通配符模式：

```text
hot -> *ot, h*t, ho*
dot -> *ot, d*t, do*
```

同一个模式桶里的单词互为一字符变化候选。

```cpp
#include <queue>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

bool canTransformByBucket(
    const string& begin,
    const string& target,
    const vector<string>& words
) {
    if (begin.size() != target.size()) {
        return false;
    }

    unordered_map<string, vector<string>> buckets;
    vector<string> all = words;
    all.push_back(begin);
    all.push_back(target);

    for (const string& word : all) {
        if (word.size() != begin.size()) {
            continue;
        }
        for (int i = 0; i < static_cast<int>(word.size()); ++i) {
            string pattern = word;
            pattern[i] = '*';
            buckets[pattern].push_back(word);
        }
    }

    queue<string> q;
    unordered_set<string> visited;
    q.push(begin);
    visited.insert(begin);

    while (!q.empty()) {
        string cur = q.front();
        q.pop();
        if (cur == target) {
            return true;
        }

        for (int i = 0; i < static_cast<int>(cur.size()); ++i) {
            string pattern = cur;
            pattern[i] = '*';
            for (const string& next : buckets[pattern]) {
                if (!visited.count(next)) {
                    visited.insert(next);
                    q.push(next);
                }
            }
        }
    }
    return false;
}
```

## 4. 如果要求最短转换次数

判断能否转换只需要普通 BFS。如果要求最短路径长度，BFS 层序遍历天然得到最短步数。如果数据量很大，可以用双向 BFS，从起点和终点同时扩展，优先扩展较小的一侧。

## 5. 易错点

1. 单步只能改变一个字符，不能插入、删除或改变多个字符。
2. 起点和终点长度不同，直接返回 false。
3. 是否要求终点在字典中要按题意确认；很多 Word Ladder 题要求终点必须在字典。
4. BFS 要记录 visited，否则图中有环会重复访问。
5. 通配符桶要按单词长度过滤，不能把不同长度的词放到同一图里。

## 6. 面试回答模板

我会把每个单词看成图节点，只差一个字符的两个单词之间连边，问题就是判断起点和终点是否连通。可以从起点做 BFS，每次枚举每个位置替换成 26 个字母，如果新词在字典中且未访问就入队，直到找到终点或队列为空。复杂度是 `O(N * L * C)`。如果字典很大，可以预处理 `h*t` 这种通配符桶，快速找到一字符变化的邻居。如果要最短转换步数，BFS 层数就是答案，数据更大时可以用双向 BFS。
