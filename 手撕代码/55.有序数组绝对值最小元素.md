# 有序数组绝对值最小元素

题目：给定一个升序数组，查找绝对值最小的元素，要求尽量使用二分查找。

## 1. 核心思路

升序数组中，绝对值最小的元素只可能出现在“第一个大于等于 0 的位置”附近。

1. 如果所有元素都大于等于 0，答案是第一个元素。
2. 如果所有元素都小于等于 0，答案是最后一个元素。
3. 否则，用二分查找找到第一个 `>= 0` 的位置 `pos`，比较 `nums[pos]` 和 `nums[pos - 1]` 的绝对值。

## 2. 代码实现

```cpp
#include <cstdlib>
#include <stdexcept>
#include <vector>
using namespace std;

int minAbsElement(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    int n = static_cast<int>(nums.size());

    if (nums[0] >= 0) {
        return nums[0];
    }
    if (nums[n - 1] <= 0) {
        return nums[n - 1];
    }

    int left = 0;
    int right = n - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= 0) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    int pos = left;
    int nonNegative = nums[pos];
    int negative = nums[pos - 1];

    return abs(negative) <= abs(nonNegative) ? negative : nonNegative;
}
```

复杂度：

1. 时间复杂度：`O(log n)`。
2. 空间复杂度：`O(1)`。

## 3. 易错点

1. 不是找数值最小，而是找绝对值最小。
2. 找到第一个非负数后，必须和前一个负数比较。
3. 如果存在 `0`，答案一定是 `0`。
4. `abs(INT_MIN)` 会溢出，真实工程中如果输入可能包含 `INT_MIN`，比较时要转成 `long long`。
5. 如果绝对值相等，例如 `-3` 和 `3`，要按题目要求返回负数、正数、任意一个或下标。

避免 `INT_MIN` 溢出的比较写法：

```cpp
long long a = nums[pos - 1];
long long b = nums[pos];
return llabs(a) <= llabs(b) ? nums[pos - 1] : nums[pos];
```

## 4. 面试回答模板

升序数组里绝对值最小的元素一定在正负分界处。先二分找到第一个 `>= 0` 的元素，如果它是 0 直接返回；否则它和前一个负数是候选答案，比较两者绝对值即可。全正数组返回第一个，全负数组返回最后一个。整体时间 `O(log n)`、空间 `O(1)`，注意 `INT_MIN` 取绝对值可能溢出。
