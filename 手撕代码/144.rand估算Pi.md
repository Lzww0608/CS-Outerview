# 144. rand 估算 Pi

使用 `stdlib.h` 中的 `rand()` 估算 `π`，常见思路是蒙特卡洛方法：在单位正方形 `[0,1] x [0,1]` 中随机撒点，落在四分之一单位圆 `x^2 + y^2 <= 1` 内的比例约等于 `π / 4`。

## 1. 核心原理

单位正方形面积为 `1`，四分之一单位圆面积为 `π / 4`。如果随机点均匀分布，那么：

```text
圆内点数 / 总点数 ≈ (π / 4) / 1
π ≈ 4 * 圆内点数 / 总点数
```

样本越多，估计值通常越接近真实值，但误差收敛速度约为 `O(1 / sqrt(n))`，也就是说想多一位精度通常需要显著增加采样次数。

## 2. C 实现

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

double estimate_pi(long long samples) {
    long long inside = 0;

    for (long long i = 0; i < samples; ++i) {
        double x = (double)rand() / RAND_MAX;
        double y = (double)rand() / RAND_MAX;

        if (x * x + y * y <= 1.0) {
            ++inside;
        }
    }

    return 4.0 * inside / samples;
}

int main(void) {
    srand((unsigned)time(NULL));
    printf("%.8f\n", estimate_pi(1000000));
    return 0;
}
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 3. 易错点

1. `rand() / RAND_MAX` 如果两边都是整数会发生整数除法，必须强转为 `double`。
2. `rand()` 的随机质量有限，不适合严肃统计模拟或安全场景，面试题只关注方法。
3. 没有 `srand` 时，每次程序运行可能得到相同伪随机序列。
4. 样本量太小时误差很大，蒙特卡洛不是高精度计算 `π` 的好方法。
5. `RAND_MAX` 可能较小，随机点分辨率有限；C++ 场景可用 `<random>` 中的 `mt19937` 和 `uniform_real_distribution`。

## 4. 可拓展回答

如果面试官追问如何提高精度，可以从三个方向回答：

1. 增加样本量，但收益按平方根收敛。
2. 使用质量更好的随机数生成器，减少伪随机偏差。
3. 用多线程分片采样，每个线程维护局部计数，最后归并，避免共享计数造成锁竞争。

## 5. 面试回答模板

我会用蒙特卡洛估算。随机生成 `[0,1]` 内的 `x`、`y`，判断点是否落在四分之一单位圆中。因为四分之一圆面积是 `π/4`，正方形面积是 `1`，所以 `π` 约等于 `4 * inside / total`。实现时要注意把 `rand()` 转成浮点数，样本越多误差越小，但收敛速度是 `1/sqrt(n)`，所以它适合演示随机模拟，不适合高精度求 `π`。
