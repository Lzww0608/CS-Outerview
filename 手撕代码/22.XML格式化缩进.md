# 22. XML 格式化缩进

## 题目

给一段未缩进的 XML 字符串，输出带缩进的结果。

面试中通常默认 XML 合法，重点考察字符串扫描和栈式层级处理。

## 思路

逐个解析标签：

1. 遇到开始标签 `<tag>`：先按当前层级输出，再层级加 1。
2. 遇到结束标签 `</tag>`：先层级减 1，再输出。
3. 遇到自闭合标签 `<tag/>`：按当前层级输出，层级不变。
4. 遇到文本内容：按当前层级输出。

## 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<string> formatXml(const string& xml) {
    vector<string> ans;
    int indent = 0;
    size_t i = 0;
    size_t n = xml.size();

    auto pushLine = [&](int level, const string& text) {
        if (!text.empty()) {
            ans.push_back(string(level * 2, ' ') + text);
        }
    };

    while (i < n) {
        if (xml[i] == '<') {
            size_t j = xml.find('>', i);
            string tag = xml.substr(i, j - i + 1);

            if (tag.size() >= 2 && tag[1] == '/') {
                --indent;
                pushLine(indent, tag);
            } else if (tag.size() >= 2 && tag[tag.size() - 2] == '/') {
                pushLine(indent, tag);
            } else {
                pushLine(indent, tag);
                ++indent;
            }

            i = j + 1;
        } else {
            size_t j = xml.find('<', i);
            if (j == string::npos) {
                j = n;
            }
            string text = xml.substr(i, j - i);
            pushLine(indent, text);
            i = j;
        }
    }

    return ans;
}
```

## 示例

输入：

```text
<a><b>hello</b><c/></a>
```

输出：

```text
<a>
  <b>
    hello
  </b>
  <c/>
</a>
```

## 易错点

1. 结束标签要先减少缩进再输出。
2. 自闭合标签不改变缩进层级。
3. 标签内有属性时，不能简单按标签名长度判断，要按 `<` 到 `>` 整段处理。
4. 真实 XML 还涉及注释、CDATA、命名空间、转义字符；面试手写题通常只处理简化合法输入。
