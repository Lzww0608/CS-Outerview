# 155. 灯泡开关问题

常见题型：有 `n` 个灯泡，初始关闭。第 1 轮切换所有灯泡，第 2 轮切换编号为 2 的倍数的灯泡，第 `i` 轮切换编号为 `i` 的倍数的灯泡。问第 `n` 轮后有多少灯泡亮着。

## 1. 数学解法

第 `k` 个灯泡会在每个因子轮次被切换一次。例如 12 的因子是：

```text
1, 2, 3, 4, 6, 12
```

它会被切换 6 次，最后仍然关闭。

只有因子个数为奇数的编号最后会亮。一个数通常因子成对出现：

```text
d * q = k
```

只有完全平方数有一个因子和自己配对，例如：

```text
36 = 6 * 6
```

所以最终亮着的灯泡数量就是 `1..n` 中完全平方数的个数，即：

```text
floor(sqrt(n))
```

## 2. 代码

```cpp
#include <cmath>

int bulbSwitch(int n) {
    return static_cast<int>(std::sqrt(n));
}
```

为了避免浮点误差，也可以用整数二分：

```cpp
int bulbSwitch(int n) {
    long long left = 0;
    long long right = n;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (mid * mid <= n) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return static_cast<int>(right);
}
```

## 3. 如果要求模拟

小数据可以直接模拟：

```cpp
#include <vector>

int bulbSwitchSimulate(int n) {
    std::vector<bool> on(n + 1, false);
    for (int step = 1; step <= n; ++step) {
        for (int i = step; i <= n; i += step) {
            on[i] = !on[i];
        }
    }

    int ans = 0;
    for (int i = 1; i <= n; ++i) {
        if (on[i]) {
            ++ans;
        }
    }
    return ans;
}
```

模拟复杂度是 `O(n log n)` 量级，因为总切换次数约为 `n/1 + n/2 + ... + n/n`，只能用于小规模验证。

## 4. DP 变体

有些面试官会改成：每个开关控制一段灯泡，或者给定若干操作，问最终状态/最少操作次数。这时就不再是完全平方数结论，而是状态模拟或动态规划。

常见思路：

1. 状态只和奇偶翻转次数有关，可以用差分数组优化区间翻转。
2. 如果求最少按开关次数，通常定义 `dp[i][state]` 表示处理到第 `i` 个灯泡时的最小代价。
3. 如果灯泡数量很小，可以用 bitmask 表示状态并做 BFS/DP。

## 5. 易错点

1. 经典灯泡开关题不是返回所有奇数编号，而是返回完全平方数个数。
2. 因子个数奇偶性是关键。
3. 使用 `sqrt` 时注意类型转换；极大整数可以用二分避免误差。
4. 看到“模拟、dp”要先确认是否是经典倍数翻转，还是开关控制关系变体。

## 6. 面试回答模板

经典灯泡开关问题中，第 `k` 个灯泡被切换的次数等于 `k` 的因子个数。大多数因子成对出现，只有完全平方数有一个重复因子，所以只有完全平方数编号的灯泡最终亮着。`1..n` 中完全平方数个数是 `floor(sqrt(n))`。如果题目要求模拟或改成区间开关、任意开关关系，再根据数据规模用差分、bitmask BFS 或 DP。
