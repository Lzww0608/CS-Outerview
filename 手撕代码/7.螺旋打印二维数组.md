# 7.螺旋打印二维数组

## 题目

给定一个 `m * n` 的二维数组，按顺时针螺旋顺序输出所有元素。

例如：

```text
[
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]

输出: 1 2 3 6 9 8 7 4 5
```

## 思路

维护四个边界：

```text
top    当前上边界
bottom 当前下边界
left   当前左边界
right  当前右边界
```

每一轮按四个方向遍历：

1. 从左到右遍历 `top` 行，然后 `top++`。
2. 从上到下遍历 `right` 列，然后 `right--`。
3. 如果 `top <= bottom`，从右到左遍历 `bottom` 行，然后 `bottom--`。
4. 如果 `left <= right`，从下到上遍历 `left` 列，然后 `left++`。

每次收缩边界后都要判断是否越界，避免单行或单列时重复输出。

## 代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> ans;
        if (matrix.empty() || matrix[0].empty()) {
            return ans;
        }

        int top = 0;
        int bottom = static_cast<int>(matrix.size()) - 1;
        int left = 0;
        int right = static_cast<int>(matrix[0].size()) - 1;

        while (top <= bottom && left <= right) {
            for (int col = left; col <= right; ++col) {
                ans.push_back(matrix[top][col]);
            }
            ++top;

            for (int row = top; row <= bottom; ++row) {
                ans.push_back(matrix[row][right]);
            }
            --right;

            if (top <= bottom) {
                for (int col = right; col >= left; --col) {
                    ans.push_back(matrix[bottom][col]);
                }
                --bottom;
            }

            if (left <= right) {
                for (int row = bottom; row >= top; --row) {
                    ans.push_back(matrix[row][left]);
                }
                ++left;
            }
        }

        return ans;
    }
};
```

## 复杂度

每个元素只访问一次：

```text
时间复杂度: O(mn)
空间复杂度: O(1) 额外空间，不算输出数组
```

## 易错点

1. 空矩阵要提前返回。
2. 单行矩阵会在第三步重复输出，所以要判断 `top <= bottom`。
3. 单列矩阵会在第四步重复输出，所以要判断 `left <= right`。
4. `bottom`、`right` 用 `int` 更方便倒序循环，避免无符号整数下溢。
