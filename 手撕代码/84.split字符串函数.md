# 84. split字符串函数

## 题目

写一个 `split` 函数，将一个 `string` 按逗号分隔，返回 `vector<string>`。需要自己考虑异常输入并编写测试样例。

需要先确认边界语义：

1. 空字符串返回什么。
2. 连续分隔符是否保留空字段。
3. 首尾分隔符是否产生空字段。
4. 是否需要处理空白字符、转义、引号。

下面实现采用最常见的 CSV 简化语义：只按单个分隔符切分，保留空字段，不处理引号和转义。

## 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<string> split(const string& s, char delim = ',') {
    vector<string> result;
    string cur;

    for (char ch : s) {
        if (ch == delim) {
            result.push_back(cur);
            cur.clear();
        } else {
            cur.push_back(ch);
        }
    }

    result.push_back(cur);
    return result;
}
```

这个版本会保留空字段：

```text
split("")        -> [""]
split("a,b,c")   -> ["a", "b", "c"]
split("a,,c")    -> ["a", "", "c"]
split(",a,")     -> ["", "a", ""]
```

## 测试样例

```cpp
void print(const vector<string>& parts) {
    cout << '[';
    for (int i = 0; i < static_cast<int>(parts.size()); ++i) {
        if (i > 0) {
            cout << ", ";
        }
        cout << '"' << parts[i] << '"';
    }
    cout << "]\n";
}

int main() {
    print(split(""));
    print(split("a,b,c"));
    print(split("a,,c"));
    print(split(",a,"));
    print(split("abc"));
    print(split(",,"));
    return 0;
}
```

预期输出：

```text
[""]
["a", "b", "c"]
["a", "", "c"]
["", "a", ""]
["abc"]
["", "", ""]
```

## 使用 find 的写法

也可以用 `find` 逐段查找：

```cpp
vector<string> splitByFind(const string& s, char delim = ',') {
    vector<string> result;
    size_t start = 0;

    while (true) {
        size_t pos = s.find(delim, start);
        if (pos == string::npos) {
            result.push_back(s.substr(start));
            break;
        }
        result.push_back(s.substr(start, pos - start));
        start = pos + 1;
    }

    return result;
}
```

## 易错点

1. 不要漏掉最后一段，字符串末尾没有分隔符时也要入结果。
2. 连续分隔符是否保留空字段要提前说明。
3. `string::npos` 是无符号值，不要随意转成 `int`。
4. 真正 CSV 还涉及引号、转义、换行和逗号在字段内出现，不能用这个简单 split 替代完整 CSV parser。
5. 如果输入特别大，频繁 `substr` 会分配新字符串；可以考虑返回 `string_view`，但要保证原字符串生命周期更长。

## 复杂度

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

其中 `n` 是字符串长度，返回结果本身需要保存所有字段。

## 面试回答模板

我会先和面试官确认空字符串、连续逗号、首尾逗号是否保留空字段。若按常见 split 语义，遍历字符串，遇到逗号就把当前字段放入结果并清空，遍历结束后再放入最后一段。这样时间 `O(n)`、空间 `O(n)`。测试要覆盖空串、无逗号、连续逗号、首尾逗号和全是逗号的情况。如果要求完整 CSV 语义，还要额外处理引号和转义。
