# 先增后减数组峰值二分

题目：给定一个先递增后递减的数组，查找最大值。这样的数组也常叫 bitonic array，最大值位于峰值位置。

## 1. 二分思路

核心观察：比较 `nums[mid]` 和 `nums[mid + 1]`。

1. 如果 `nums[mid] < nums[mid + 1]`，说明 `mid` 处在上升段，峰值一定在右侧。
2. 如果 `nums[mid] > nums[mid + 1]`，说明 `mid` 处在下降段或峰值左侧边界，峰值在 `mid` 或左侧。

因此可以把搜索区间不断缩小到峰值。

## 2. 代码实现

```cpp
#include <stdexcept>
#include <vector>
using namespace std;

int findPeakInBitonic(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] < nums[mid + 1]) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return nums[left];
}
```

复杂度：

1. 时间复杂度：`O(log n)`。
2. 空间复杂度：`O(1)`。

## 3. 边界和变体

1. 如果数组严格先增后减，峰值唯一，上述代码直接成立。
2. 如果数组整体单调递增，代码会返回最后一个元素；整体单调递减，会返回第一个元素。
3. 如果存在平台峰值，例如 `[1, 3, 3, 3, 2]`，`nums[mid] == nums[mid + 1]` 时无法判断峰值在左还是右。可以退化为 `right--`，但最坏时间复杂度会退化到 `O(n)`。
4. 如果要求返回下标，返回 `left` 即可。

处理重复值的版本：

```cpp
int findPeakIndexWithDuplicate(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] < nums[mid + 1]) {
            left = mid + 1;
        } else if (nums[mid] > nums[mid + 1]) {
            right = mid;
        } else {
            --right;
        }
    }

    return left;
}
```

## 4. 面试回答模板

先增后减数组的最大值可以二分。每次取 `mid`，比较 `nums[mid]` 和 `nums[mid + 1]`：如果前者更小，说明还在上升段，峰值在右边；否则说明已经到下降段或峰值位置，峰值在 `mid` 或左边。循环到 `left == right` 时就是峰值下标。严格先增后减时复杂度是 `O(log n)`，有重复平台时可能需要额外处理并退化。
