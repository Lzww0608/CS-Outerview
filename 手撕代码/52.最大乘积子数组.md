# 最大乘积子数组

题目：给定一个整数数组，求连续子数组的最大乘积。这里的“连续子序列”通常按连续子数组理解。

## 1. 为什么不能只维护最大值

最大子数组和只需要维护“以当前位置结尾的最大和”，但乘积不一样，因为负数会翻转大小关系：

```text
正数 * 最大值 仍可能最大
负数 * 最小值 可能变成最大
0 会把连续乘积截断
```

因此要同时维护：

1. `maxEnd`：以当前位置结尾的最大乘积。
2. `minEnd`：以当前位置结尾的最小乘积。
3. `best`：全局最大乘积。

## 2. O(n) 动态规划

转移：

```text
maxEnd = max(nums[i], nums[i] * oldMax, nums[i] * oldMin)
minEnd = min(nums[i], nums[i] * oldMax, nums[i] * oldMin)
best = max(best, maxEnd)
```

代码：

```cpp
#include <algorithm>
#include <stdexcept>
#include <vector>
using namespace std;

long long maxProductSubarray(const vector<int>& nums) {
    if (nums.empty()) {
        throw invalid_argument("empty array");
    }

    long long maxEnd = nums[0];
    long long minEnd = nums[0];
    long long best = nums[0];

    for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
        long long x = nums[i];
        long long oldMax = maxEnd;
        long long oldMin = minEnd;

        maxEnd = max({x, x * oldMax, x * oldMin});
        minEnd = min({x, x * oldMax, x * oldMin});
        best = max(best, maxEnd);
    }

    return best;
}
```

复杂度：

1. 时间复杂度：`O(n)`。
2. 空间复杂度：`O(1)`。

## 3. 易错点

1. 不能只维护最大乘积，负数乘最小乘积可能变成最大。
2. 遇到 `0` 不需要特殊重置，上面的转移会自然把 `maxEnd/minEnd` 变成 `0` 或从下一个元素重新开始。
3. 全是负数时答案不一定是整个数组，例如 `[-2, -3, -4]` 的答案是 `12`。
4. 乘积容易溢出 `int`，面试代码可以用 `long long`，并说明真实业务要按题目范围处理溢出。
5. 如果题目允许空子数组，需要先确认空子数组乘积是否定义为 `1`，多数算法题不允许空子数组。

## 4. 面试回答模板

最大乘积子数组可以 `O(n)` 做。因为负数会让最大值和最小值互换，所以我同时维护以当前位置结尾的最大乘积 `maxEnd` 和最小乘积 `minEnd`。遍历到 `x` 时，新的最大值来自 `x`、`x * oldMax`、`x * oldMin` 三者最大值，新的最小值同理取最小，再更新全局答案。这样只遍历一次，时间 `O(n)`、空间 `O(1)`。
