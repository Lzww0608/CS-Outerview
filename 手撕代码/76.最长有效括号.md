# 最长有效括号

## 题目

给定一个只包含 `(` 和 `)` 的字符串，求最长合法括号子串的长度。

示例：

```text
输入: "(()"
输出: 2

输入: ")()())"
输出: 4
```

## 思路一：栈

栈中保存下标。为了方便计算长度，先放入一个哨兵下标 `-1`，表示当前有效子串左边界的前一个位置。

扫描字符串：

1. 遇到 `(`，下标入栈。
2. 遇到 `)`，弹出栈顶。
3. 如果弹出后栈为空，说明当前 `)` 无法匹配，把它的下标作为新的哨兵。
4. 如果栈不为空，用 `i - st.top()` 更新最长长度。

## 代码

```cpp
#include <algorithm>
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int longestValidParentheses(const string& s) {
    stack<int> st;
    st.push(-1);

    int ans = 0;
    for (int i = 0; i < static_cast<int>(s.size()); ++i) {
        if (s[i] == '(') {
            st.push(i);
        } else {
            st.pop();
            if (st.empty()) {
                st.push(i);
            } else {
                ans = max(ans, i - st.top());
            }
        }
    }
    return ans;
}

int main() {
    string s;
    cin >> s;
    cout << longestValidParentheses(s) << endl;
    return 0;
}
```

## 思路二：动态规划

定义 `dp[i]` 表示以 `s[i]` 结尾的最长有效括号长度。只有 `s[i] == ')'` 时才可能更新。

转移：

1. 如果 `s[i - 1] == '('`，则形成 `...()`：

```text
dp[i] = dp[i - 2] + 2
```

2. 如果 `s[i - 1] == ')'`，设前一个有效串长度为 `dp[i - 1]`，它前面的字符位置是：

```text
j = i - dp[i - 1] - 1
```

如果 `j >= 0 && s[j] == '('`，则：

```text
dp[i] = dp[i - 1] + 2 + dp[j - 1]
```

## 复杂度

栈和动态规划都是：

```text
时间复杂度: O(n)
空间复杂度: O(n)
```

如果只要求长度，也可以从左到右、从右到左各扫描一次，用计数器做到 `O(1)` 空间。

## 易错点

1. 栈法哨兵 `-1` 很关键，否则以 0 开始的有效串长度不好计算。
2. 遇到无法匹配的 `)` 时，要把当前位置作为新的边界。
3. 动态规划里访问 `dp[i - 2]`、`dp[j - 1]` 前要判断下标合法。
4. 题目问的是连续子串长度，不是最多能匹配多少个括号。
