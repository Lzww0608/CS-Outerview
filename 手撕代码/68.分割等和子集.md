# 分割等和子集

题目：给定一个只包含正整数的数组，判断能否把数组分成两个子集，使两个子集的元素和相等。

## 1. 思路

如果数组总和为 `sum`，两个子集和相等，则每个子集的目标和是 `sum / 2`。因此问题转化为：能否从数组中选出若干元素，使它们的和正好等于 `sum / 2`。

这就是 01 背包的可行性问题：

```text
dp[j] = 是否能选出若干数，使和为 j
```

每个数只能使用一次，所以容量必须倒序遍历。

## 2. C++ 实现

```cpp
#include <numeric>
#include <vector>
using namespace std;

bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2 != 0) {
        return false;
    }

    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;

    for (int x : nums) {
        for (int j = target; j >= x; --j) {
            dp[j] = dp[j] || dp[j - x];
        }
    }

    return dp[target];
}
```

## 3. 复杂度

1. 时间复杂度：`O(n * target)`。
2. 空间复杂度：`O(target)`。

其中 `target = sum / 2`。

## 4. 为什么倒序遍历

01 背包中每个元素只能选一次。倒序遍历时，`dp[j - x]` 仍然是处理当前元素之前的状态。

如果正序遍历，当前元素刚更新出的状态会被同一轮再次使用，相当于一个元素可以选多次，问题会变成完全背包。

## 5. bitset 优化

如果 `sum` 范围不大，也可以用 bitset 思想优化常数：

```cpp
// bits 的第 j 位表示和 j 是否可达
bits |= (bits << x);
```

每处理一个数 `x`，把已有可达和整体左移 `x` 位并合并，表示新增加“选 x”的所有可达状态。C++ 标准 `bitset` 需要编译期固定大小；动态大小可以用 `vector<unsigned long long>` 或 `boost::dynamic_bitset`。

## 6. 易错点

1. 总和为奇数时直接返回 false。
2. 题目说正整数，因此不用考虑负数；如果有负数，普通背包定义要改变。
3. 一维 DP 必须倒序。
4. `vector<bool>` 是特殊压缩实现，面试手写可用；工程中若需要引用语义可改用 `vector<char>`。
5. 如果数字总和很大，`O(n * sum)` 可能不可接受，需要结合约束考虑搜索、剪枝或 meet-in-the-middle。

## 7. 面试回答模板

等和分割先求总和，如果总和是奇数一定不能分。否则目标变成能否选出若干元素和为 `sum / 2`，这是 01 背包可行性问题。定义 `dp[j]` 表示和为 `j` 是否可达，初始 `dp[0]=true`，遍历每个数 `x` 时倒序更新 `dp[j] |= dp[j-x]`。最后看 `dp[target]`。倒序是为了保证每个数只用一次，时间复杂度 `O(n*target)`，空间复杂度 `O(target)`。
