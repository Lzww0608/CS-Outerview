# 无序数组第 K 小

题目：在无序数组中找到第 `k` 小的数，要求平均复杂度尽可能低。最常用做法是快速选择（Quickselect），平均时间 `O(n)`。

## 快速选择思路

快速选择和快速排序的 partition 类似：

1. 选择一个 pivot。
2. 把小于 pivot 的放左边，大于 pivot 的放右边。
3. 如果 pivot 最终位置正好是 `k - 1`，答案就是它。
4. 如果 `k - 1` 在左边，只递归/迭代左半边。
5. 如果在右边，只处理右半边。

相比快速排序，快速选择每轮只进入一侧，所以平均 `O(n)`。

## 代码

```cpp
#include <algorithm>
#include <random>
#include <stdexcept>
#include <vector>

int partition(std::vector<int>& nums, int left, int right, int pivotIndex) {
    int pivot = nums[pivotIndex];
    std::swap(nums[pivotIndex], nums[right]);

    int store = left;
    for (int i = left; i < right; ++i) {
        if (nums[i] < pivot) {
            std::swap(nums[store], nums[i]);
            ++store;
        }
    }

    std::swap(nums[store], nums[right]);
    return store;
}

int kthSmallest(std::vector<int>& nums, int k) {
    if (k < 1 || k > static_cast<int>(nums.size())) {
        throw std::invalid_argument("k out of range");
    }

    int target = k - 1;
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    std::mt19937 gen(std::random_device{}());

    while (left <= right) {
        std::uniform_int_distribution<int> dist(left, right);
        int pivotIndex = dist(gen);
        int pos = partition(nums, left, right, pivotIndex);

        if (pos == target) {
            return nums[pos];
        }
        if (target < pos) {
            right = pos - 1;
        } else {
            left = pos + 1;
        }
    }

    throw std::logic_error("unreachable");
}
```

## 复杂度

1. 平均时间复杂度：`O(n)`。
2. 最坏时间复杂度：`O(n^2)`，例如 pivot 总是选到极端位置。
3. 空间复杂度：迭代写法 `O(1)`。

如果要求最坏也稳定为线性，可以使用 BFPRT（Median of Medians），最坏 `O(n)`，但常数较大、实现复杂。工程中通常用随机 pivot 的 Quickselect。

## 其他做法

1. 排序：`O(n log n)`，简单但不是最优。
2. 大根堆维护 k 个最小值：`O(n log k)`，适合流式数据或 k 很小。
3. 计数排序/桶：如果值域很小，可做到接近 `O(n + range)`。

## 无序数组找中位数

中位数可以看成第 `k` 小问题的特例。

1. 如果数组长度 `n` 是奇数，中位数是第 `n / 2 + 1` 小。
2. 如果数组长度 `n` 是偶数，常见定义是第 `n / 2` 小和第 `n / 2 + 1` 小的平均值。
3. 如果题目只要求“下中位数”或“上中位数”，要先和面试官确认定义。

可以复用快速选择：

```cpp
double medianUnordered(std::vector<int> nums) {
    int n = static_cast<int>(nums.size());
    if (n == 0) {
        throw std::invalid_argument("empty array");
    }

    if (n % 2 == 1) {
        return kthSmallest(nums, n / 2 + 1);
    }

    int left = kthSmallest(nums, n / 2);
    int right = kthSmallest(nums, n / 2 + 1);
    return (static_cast<long long>(left) + right) / 2.0;
}
```

注意这里参数按值传入 `nums`，因为 `kthSmallest` 会修改数组。如果想减少一次 Quickselect，可以先找第 `n / 2` 小，再在另一侧继续选择；面试现场通常写两次更清晰。

如果数据量很大不能放入内存，可以参考“海量数据中位数”：外部排序、值域分桶或分位数摘要。

## 易错点

1. 第 `k` 小通常是 1-based，数组下标是 `k - 1`。
2. 有重复元素时，普通 partition 仍可用；如果重复很多，三路 partition 更稳。
3. Quickselect 会修改原数组，如果不能修改，需要复制一份。
4. 随机 pivot 能显著降低退化概率。

## 面试回答模板

无序数组找第 k 小，平均复杂度最低的常用方法是快速选择。每次随机选 pivot 做 partition，判断 pivot 排名和 `k-1` 的关系，只递归一边。平均时间 `O(n)`，空间 `O(1)`；最坏可能 `O(n^2)`，可以用随机化降低概率，或者用 BFPRT 保证最坏 `O(n)` 但实现复杂。k 很小或流式数据可以用大小为 k 的大根堆，复杂度 `O(n log k)`。
