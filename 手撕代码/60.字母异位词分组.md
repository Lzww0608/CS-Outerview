# 字母异位词分组

题目：给定一个字符串数组，把字母异位词分到同一组。对应 LeetCode 49。

字母异位词指两个字符串包含的字符种类和每种字符数量都相同，只是顺序不同。例如 `eat`、`tea`、`ate` 属于同一组。

## 1. 排序作为 key

最直接的做法是把每个字符串排序，排序后的结果作为哈希表 key。

```text
eat -> aet
tea -> aet
tan -> ant
```

同一个 key 下的原字符串就是一组异位词。

```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;

    for (const string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());
        groups[key].push_back(s);
    }

    vector<vector<string>> ans;
    ans.reserve(groups.size());
    for (auto& [key, group] : groups) {
        ans.push_back(std::move(group));
    }
    return ans;
}
```

复杂度：

1. 设字符串数量为 `n`，单个字符串最大长度为 `k`。
2. 时间复杂度：`O(n * k log k)`。
3. 空间复杂度：`O(n * k)`，哈希表保存所有字符串分组。

## 2. 字符计数作为 key

如果题目限定字符串只包含小写英文字母，可以用 26 维计数作为 key，避免每个字符串排序。

```cpp
#include <array>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

string buildKey(const string& s) {
    array<int, 26> cnt{};
    for (char ch : s) {
        ++cnt[ch - 'a'];
    }

    string key;
    for (int x : cnt) {
        key += '#';
        key += to_string(x);
    }
    return key;
}

vector<vector<string>> groupAnagramsCount(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;

    for (const string& s : strs) {
        groups[buildKey(s)].push_back(s);
    }

    vector<vector<string>> ans;
    ans.reserve(groups.size());
    for (auto& [key, group] : groups) {
        ans.push_back(std::move(group));
    }
    return ans;
}
```

复杂度：

1. 时间复杂度：`O(n * k)`。
2. 空间复杂度：`O(n * k)`。

计数 key 里要加分隔符，否则可能出现歧义。例如计数 `[1, 11]` 和 `[11, 1]` 如果直接拼接都可能变成类似 `"111"`。

## 3. 字典中是否存在某个单词的变异体

如果题目变成“如何判断一个字典中是否存在某个单词的变异体”，本质仍然是异位词签名查询。

预处理阶段把字典里每个单词转换成规范化 key：

1. 排序 key：`listen -> eilnst`。
2. 计数 key：小写字母场景用 26 维计数。

查询阶段把目标单词也转换成同样的 key，在哈希表中查找即可。

```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class AnagramDictionary {
public:
    explicit AnagramDictionary(const vector<string>& words) {
        for (const string& word : words) {
            dict_[signature(word)].push_back(word);
        }
    }

    bool existsVariant(const string& word) const {
        auto it = dict_.find(signature(word));
        if (it == dict_.end()) {
            return false;
        }
        for (const string& candidate : it->second) {
            if (candidate != word) {
                return true;
            }
        }
        return false;
    }

private:
    static string signature(string s) {
        sort(s.begin(), s.end());
        return s;
    }

    unordered_map<string, vector<string>> dict_;
};
```

复杂度：

1. 预处理：`O(n * k log k)`，`n` 是字典大小，`k` 是单词长度。
2. 单次查询：排序 key 是 `O(k log k)`，计数 key 可降到 `O(k)`。
3. 如果只需要判断是否存在，可以保存 key 到数量；如果要排除单词自身，则保存候选列表或计数时区分出现次数。

易错点：

1. 要明确“变异体”是否允许和原词完全相同。
2. 大小写、重音符号、空格、连字符是否归一化，要由业务规则决定。
3. 字典很大且查询频繁时，预处理比每次遍历字典比较更合适。

## 4. 真实场景类比

这题本质是“把对象映射到规范化签名，再按签名分桶”。

类似场景：

1. 文件去重：用内容哈希作为 key。
2. 用户画像聚合：用归一化后的标签组合作为 key。
3. 搜索倒排：把词项作为 key，把文档 ID 放入列表。
4. 数据清洗：把大小写、空格、顺序差异归一化后分组。

面试中可以强调：关键是设计一个满足“同类相同、异类尽量不同”的 key。

## 5. 易错点

1. 返回分组顺序通常不要求固定，除非题目额外说明。
2. 空字符串也要处理，排序 key 和计数 key 都能支持。
3. 计数法默认依赖字符集范围，如果包含 Unicode、大小写或标点，需要扩大计数维度或改用排序。
4. 计数拼接 key 时要加分隔符，避免数字串歧义。
5. `unordered_map` 的 value 可以直接保存原字符串，不要只保存排序后的 key。

## 6. 面试回答模板

字母异位词分组可以用哈希表。对每个字符串构造一个规范化 key，同组异位词必须得到相同 key。最简单的 key 是排序后的字符串，时间复杂度 `O(n * k log k)`。如果只包含小写字母，可以用 26 个字符计数构造 key，时间复杂度降到 `O(n * k)`。如果是判断字典中是否存在某个单词的变异体，就先把字典按 key 预处理成哈希表，查询时只需要构造目标单词的 key 再查表。注意计数 key 拼接时要加分隔符，空字符串要能正常处理。
