# 比特币原理详解

## 一、比特币概述

### 1.1 什么是比特币

比特币（Bitcoin）是中本聪于 2009 年发布的去中心化数字货币，基于密码学和分布式系统技术，无需央行或政府背书即可实现点对点价值转移。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  比特币核心特性：                                           │
│                                                             │
│  1. 去中心化：无发行机构，全球节点共同维护                  │
│  2. 总量固定：总量 2100 万枚，永不超发                      │
│  3. 匿名性：地址匿名，交易可追溯但身份不公开                │
│  4. 不可篡改：历史交易不可篡改                             │
│  5. 跨境转账：无需第三方，快速低费                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、比特币技术架构

### 2.1 区块结构

```c
// 比特币区块结构
struct BlockHeader {
    int32_t version;           // 版本号
    uint8_t prev_block[32];   // 前一个区块哈希（256位）
    uint8_t merkle_root[32];  // 默克尔根
    uint32_t timestamp;       // 时间戳
    uint32_t bits;            // 难度目标
    uint32_t nonce;           // 随机数
};

struct Block {
    BlockHeader header;       // 区块头（80字节）
    uint32_t tx_count;       // 交易数量
    Transaction* transactions; // 交易列表
};
```

### 2.2 交易结构（UTXO 模型）

```c
// 比特币交易输入
struct TxInput {
    uint8_t txid[32];         // 前序交易哈希

    uint8_t scriptSig[?];     // 解锁脚本

    uint8_t version;
    uint32_t input_count;
    TxInput* inputs;          // 花费的是之前的 UTXO
```

## 三、工作量证明（PoW）

### 3.1 挖矿原理

```c
// 比特币挖矿：找到满足条件的 nonce
#include <openssl/sha.h>

typedef unsigned char uint8_t;
typedef unsigned int uint32_t;

bool is_valid_proof(BlockHeader* header) {
    uint8_t hash[32];
    
    // double SHA-256
    SHA256(header, sizeof(BlockHeader), hash);
    SHA256(hash, 32, hash);
    
    // 检查哈希是否小于目标难度
    // 目标由 bits 字段计算得出
    for (int i = 0; i < 32; i++) {
        if (hash[i] < target[i]) return true;
        if (hash[i] > target[i]) return false;
    }
    return false;
}

// 简化挖矿过程
uint32_t mine_block(BlockHeader* header) {
    uint32_t nonce = 0;
    while (!is_valid_proof(header)) {
        header->nonce = nonce++;
    }
    return nonce;
}
```

### 3.2 难度调整

```c
// 每 2016 个区块（约 2 周）调整一次难度
// 目标：保持区块间隔约 10 分钟

uint32_t calculate_next_difficulty(uint32_t prev_bits, 
                                   uint32_t time_taken) {
    // 期望时间：2016 * 10 分钟 = 20160 分钟
    const uint32_t expected_time = 20160 * 60;
    
    // 实际时间超过期望太久，降低难度
    if (time_taken > expected_time * 4) {
        time_taken = expected_time * 4;
    }
    // 实际时间少于期望太多，提高难度
    if (time_taken < expected_time / 4) {
        time_taken = expected_time / 4;
    }
    
    // 调整系数的指数
    int64_t factor = (int64_t)time_taken / expected_time;
    
    // 限制调整范围：不能超过原来的 4 倍或小于 1/4
    if (factor > 4) factor = 4;
    if (factor < 1) factor = 1;
    
    return prev_bits * factor;
}
```

## 五、钱包与密钥

### 5.1 密钥生成

```python
import hashlib
import ecdsa

# 从随机数生成私钥
private_key = os.urandom(32)  # 256位随机数

# 从私钥生成公钥（椭圆曲线签名）
signing_key = ecdsa.SigningKey.from_string(
    private_key, curve=ecdsa.SECP256k1
)
verifying_key = signing_key.get_verifying_key()
public_key = verifying_key.to_string()

# RIPEMD-160(SHA-256(公钥)) = 公钥哈希
h = hashlib.new('ripemd160')
h.update(hashlib.sha256(public_key).digest())
public_key_hash = h.digest()
```

### 5.2 地址生成

```python
# 地址格式：Base58Check 编码
# 主网地址以 1 开头，测试网以 m/n 开头

def generate_address(public_key_hash):
    # 1. 添加版本字节（00 表示主网 P2PKH）
    versioned_payload = b'\x00' + public_key_hash
    
    # 2. 计算 SHA-256
    h1 = hashlib.sha256(versioned_payload).digest()
    
    # 3. 计算 SHA-256(SHA-256)
    h2 = hashlib.sha256(h1).digest()
    
    # 4. 取前 4 字节作为校验和
    checksum = h2[:4]
    
    # 5. 拼接后 Base58 编码
    payload = versioned_payload + checksum
    address = base58_encode(payload)
    
    return address

# 示例地址：1BvBMSEYstWetqTFn5Au4m4GFg7xJaNVN2
```

## 九、面试常见问题

### Q1: 比特币如何实现去中心化？

通过全节点网络，所有节点共同维护同一份账本；通过 PoW 共识机制，矿工竞争记账权；任何人可运行节点，无单一控制方。

### Q2: UTXO 模型和账户模型的优缺点？

- **UTXO**：隐私好，可并行处理，无余额字段；但实现复杂
- **账户模型**：简单高效，支持智能合约；但隐私较差

### Q3: 比特币为什么约 10 分钟出一个块？

这是中本聪的刻意设计，平衡了去中心化、安全性和最终确认时间。10 分钟足够交易广播到全网，又不会导致长时间等待。

### Q4: 什么是比特币的"减半"？

比特币每 21 万个区块（约 4 年）奖励减半，从最初的 50 BTC → 25 BTC → 12.5 BTC → 6.25 BTC，模拟贵金属的稀缺性。

### Q5: 比特币和以太坊的区别？

| 对比 | 比特币 | 以太坊 |
|------|--------|--------|
| 设计目标 | 数字货币 | 智能合约平台 |
| 共识 | PoW（转 PoS） | PoW（转 PoS） |
| 脚本 | 有限脚本 | 图灵完备（Solidity） |
| 平均出块 | 10 分钟 | 12 秒 |
| 供应量 | 2100 万枚 | 无上限 |

## 十、总结

1. **比特币定义**：去中心化数字货币，基于 PoW 共识
2. **核心原理**：区块链、UTXO、PoW 挖矿、椭圆曲线加密
3. **技术特点**：总量固定、匿名交易、跨境便捷
4. **安全机制**：最长链原则、51% 攻击门槛
5. **应用场景**：价值存储、跨境支付、微支付
