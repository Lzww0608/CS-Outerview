## 二、Merkle Patricia Trie

### 2.1 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Merkle Patricia Trie = Merkle 树 + Patricia Trie       │
│                                                             │
│  核心思想：                                               │
│  • Patricia Trie：共享公共前缀，节省空间                  │
│  • Merkle：每个节点有哈希，可验证完整性                  │
│                                                             │
│  以太坊应用：                                            │
│  • 账户状态存储                                          │
│  • 交易历史                                              │
│  • 合约存储                                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 节点类型

```python
class MerklePatriciaNode:
    """Merkle Patricia Trie 节点"""
    
    # 节点类型
    BRANCH = 0      # 分支节点（最多16个子节点）
    EXTENSION = 1  # 扩展节点（共享前缀）
    LEAF = 2       # 叶子节点
    
    def __init__(self, node_type):
        self.type = node_type
        self.rlp_encoding = b''  # RLP 编码
        self.hash = None
    
    def compute_hash(self):
        """计算节点的 Merkle 哈希"""
        import hashlib
        self.hash = hashlib.sha256(self.rlp_encoding).hexdigest()
        return self.hash
```

### 2.3 以太坊状态树

# 以太坊账户状态
class EthereumState:

        # 账户地址 -> 账户状态
        self.accounts = {}

## 三、Sparse Merkle Tree

### 3.1 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Sparse Merkle Tree（稀疏默克尔树）：                        │
│                                                             │
│  核心思想：                                               │
│  • 满二叉树，所有位置预分配                              │
│  • 缺失节点默认为固定值（如 0）                          │
│  • 高效证明"键不存在"                                   │
│                                                             │
│  应用场景：                                               │
│  • 区块链账户余额验证                                    │
│  • 密钥承诺                                              │
│  • 分布式账本                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 实现

```python
class SparseMerkleTree:
    """稀疏默克尔树"""
    
    def __init__(self, depth=256):
        self.depth = depth
        self.leaves = {}  # key -> value
        self.default_hash = self.hash(b'\x00' * 32)  # 默认空值
    
    def hash(self, data):
        import hashlib
        return hashlib.sha256(data).digest()
    
    def set(self, key, value):
        """设置键值对"""
        self.leaves[key] = self.hash(value)
        self.recalculate_root()
    
    def get(self, key):
        """获取值"""
        if key in self.leaves:
            return self.leaves[key]
        return self.default_hash
    
    def get_root(self):
        """计算根哈希"""
        return self.compute_node_hash(0, 0)
    
    def compute_node_hash(self, level, start_key):
        """
        递归计算节点哈希
        
        level: 当前层级（0 = 根）
        start_key: 当前子树下所有键的起始前缀
        """
        if level == self.depth:
            # 叶子节点
            key = start_key
            if key in self.leaves:
                return self.leaves[key]
            return self.default_hash
        
        # 左子树
        left_hash = self.compute_node_hash(
            level + 1, 
            start_key * 2
        )
        
        # 右子树
        right_hash = self.compute_node_hash(
            level + 1, 
            start_key * 2 + 1
        )
        
        # 当前节点哈希
        return self.hash(left_hash + right_hash)
```

### 3.3 零值证明

```python
class SparseMerkleProof:
    """稀疏默克尔树证明"""
    
    def generate_nonexistence_proof(self, tree, key):
        """
        生成"键不存在"的证明
        
        原理：证明从根到叶子路径上，所有兄弟节点
        都是默认值（空）
        """
        proof = {
            'siblings': [],
            'path': []
        }
        
        current_key = 0
        for level in range(tree.depth):
            # 判断当前键的该位
            bit = (key >> (255 - level)) & 1
            
            proof['path'].append(bit)
            
            # 兄弟节点
            sibling_key = current_key ^ 1
            if sibling_key in tree.leaves:
                proof['siblings'].append(tree.leaves[sibling_key])
            else:
                proof['siblings'].append(tree.default_hash)
            
            current_key = (current_key << 1) | bit
        
        return proof
    
    def verify_nonexistence(self, root, key, proof, default_hash):
        """验证不存在证明"""
        current_hash = default_hash
        
        for bit, sibling in zip(proof['path'], proof['siblings']):
            if bit == 0:
                current_hash = self.hash(current_hash + sibling)
            else:
                current_hash = self.hash(sibling + current_hash)
        
        return current_hash == root
```

### 4.3 Pedersen 承诺

```python
class PedersenCommitment(VectorCommitment):
    """Pedersen 承诺（Verkle 树使用）"""
    
    def __init__(self):
        # 椭圆曲线参数（简化示例）
        self.G = self.get_generator()
        self.H = self.get_generator()  # 不同生成元
    
    def commit(self, values):
        """
        Pedersen 承诺: C = g1^v1 * g2^v2 * ...
        
        承诺大小固定（一个椭圆曲线点）
        """
        commitment = self.point_at_infinity()
        
        for i, v in enumerate(values):
            commitment = commitment + self.G * v
        
        return commitment
    
    def open(self, values, index):
        """生成打开证明"""
        # 计算部分承诺（排除目标位置）
        partial_commitment = self.point_at_infinity()
        
        for i, v in enumerate(values):
            if i != index:
                partial_commitment = partial_commitment + self.G * v
        
        # 证明 = 原承诺 / 部分承诺
        proof = self.divide_points(
            commitment, 
            partial_commitment
        )
        
        return values[index], proof
```

### 4.4 Merkle vs Verkle

| 特性 | Merkle Patricia Trie | Verkle Tree |
|------|----------------------|--------------|
| 证明大小 | O(log n) | O(1)（固定大小） |
| 承诺大小 | O(1)（哈希） | O(1)（椭圆曲线点） |
| 计算成本 | 低 | 中等 |
| 密码学假设 | 无 | 椭圆曲线离散对数 |

### 5.2 递归哈希结构

```python
class DamgardMerkleHash:
    """Damgard-Merkle 递归哈希"""
    
    def __init__(self, block_size=64):
        self.block_size = block_size
        self.IV = self.get_initialization_vector()
    
    def hash(self, message):
        """
        递归哈希长消息
        
        结构：
        - 将消息分成固定大小的块
        - 链式计算每个块的哈希
        - 最后一块包含长度信息
        """
        import hashlib
        
        # 填充消息
        padded = self.pad(message)
        
        # 分块处理
        prev_hash = self.IV
        
        for i in range(0, len(padded), self.block_size):
            block = padded[i:i + self.block_size]
            
            # 当前块哈希
            block_hash = hashlib.sha256(block).digest()
            
            # 与前一块哈希链接
            prev_hash = hashlib.sha256(prev_hash + block_hash).digest()
        
        return prev_hash
    
    def pad(self, message):
        """消息填充"""
        # 长度编码填充
        length = len(message)
        message += b'\x80'
        
        # 填充到长度编码位置
        while len(message) % self.block_size != self.block_size - 8:
            message += b'\x00'
        
        # 添加 64 位长度（大端序）
        message += length.to_bytes(8, 'big')
        
        return message
```

### 5.3 增量更新

```python
class IncrementalDamgardMerkle:
    """支持增量更新的 Damgard-Merkle"""
    
    def __init__(self):
        self.blocks = []
        self.chain = []
        self.IV = self.get_initial_vector()
    
    def add_block(self, block):
        """添加新块"""
        self.blocks.append(block)
        
        # 计算新块的哈希
        if not self.chain:
            block_hash = self.hash(block)
        else:
            # 与前一块链接
            block_hash = self.hash(
                self.chain[-1] + self.hash(block)
            )
        
        self.chain.append(block_hash)
    
    def get_root(self):
        """获取根哈希"""
        if not self.chain:
            return self.IV
        return self.chain[-1]
    
    def update_block(self, index, new_block):
        """更新指定块（只需重新计算后续哈希）"""
        old_hash = self.chain[index]
        new_hash = self.hash(new_block)
        
        # 更新该块
        self.blocks[index] = new_block
        
        # 重新计算从该块到末尾的所有哈希
        for i in range(index, len(self.chain)):
            if i == 0:
                self.chain[i] = self.hash(self.blocks[i])
            else:
                self.chain[i] = self.hash(
                    self.chain[i-1] + self.hash(self.blocks[i])
                )
```

## 七、面试常见问题

### Q1: Merkle Patricia Trie 解决了什么问题？

解决了 Merkle 树无法共享公共前缀的问题，大幅减少存储空间，同时保留 Merkle 哈希验证能力，以太坊用它存储账户状态。

### Q2: Sparse Merkle Tree 的零值证明优势？

普通 Merkle 树无法高效证明"键不存在"，因为需要遍历所有叶子。Sparse Merkle Tree 通过预分配满二叉树，将不存在视为默认值，可高效证明不存在。

### Q3: 为什么以太坊要用 Verkle Tree 替代 Merkle Patricia Trie？

Verkle Tree 的证明大小是 O(1)，比 Merkle Patricia Trie 的 O(log n) 小得多，对以太坊轻节点和分片有重要意义。

### Q4: Damgard-Merkle 和普通 Merkle 树的区别？

Damgard-Merkle 通过链式连接实现增量哈希，适合长消息；普通 Merkle 树是二叉树结构，适合随机访问和验证。
