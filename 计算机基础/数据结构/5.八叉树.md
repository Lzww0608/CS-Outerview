# 八叉树（Octree）

## 1. 概述

八叉树（Octree）是一种**递归划分三维空间**的数据结构，是二维空间中**四叉树（Quadtree）**在三维空间的扩展。

核心思想：
- 每个节点代表一个立方体空间
- 非叶子节点有 **8 个子节点**，分别对应 8 个卦限（octant）
- 递归划分直到满足终止条件（深度达到阈值、区域内点数足够少等）

```
二维：四叉树                    三维：八叉树
┌───────┬───────┐            ┌───────┬───────┐
│   0   │   1   │            │ 0 │ 1 │ 4 │ 5 │
├───┬───┼───┬───┤            ├───┼───┼───┼───┤
│   2   │   3   │            │ 2 │ 3 │ 6 │ 7 │
└───┴───┴───┴───┘            ├───┼───┼───┼───┤
                              │   │   │   │   │
                              ├───┼───┼───┼───┤
                              │   │   │   │   │
                              └───┴───┴───┴───┘
```

## 2. 与四叉树的关系

| 维度 | 结构 | 每个节点子节点数 | 适用场景 |
| --- | --- | --- | --- |
| 2D | 四叉树 | 4 | 地图、GIS、图像分区 |
| 3D | 八叉树 | 8 | 3D 空间划分、点云 |
| N维 | KD 树 | 2^N | 维度较低的空间划分 |

**核心区别**：
- 四叉树：每个节点 4 个子节点，对应 4 个象限
- 八叉树：每个节点 8 个子节点，对应 8 个卦限
- KD 树：每个节点 2 个子节点，按某一维度划分

## 3. 数据结构定义

### 3.1 节点定义

```cpp
struct OctreeNode {
    // 节点表示的空间范围
    BoundingBox bounds;  // 立方体边界 [min_x, max_x] x [min_y, max_y] x [min_z, max_z]
    
    // 子节点指针（8个）
    std::array<std::unique_ptr<OctreeNode>, 8> children;
    
    // 存储的数据（可选）
    std::vector<Point3D> points;  // 该节点包含的点
    // 或者单个对象指针
    Object* object = nullptr;
    
    // 元信息
    int depth;                    // 节点深度
    bool is_leaf = true;         // 是否是叶子节点
};

// 边界框
struct BoundingBox {
    float min_x, max_x;
    float min_y, max_y;
    float min_z, max_z;
};
```

### 3.2 八卦限编号

```cpp
// 八叉树的 8 个子节点对应 8 个卦限
// 通常按位编码：x_bit | y_bit | z_bit

enum Octant {
    BOTTOM_LEFT_FRONT  = 0,  // x=0, y=0, z=0
    BOTTOM_RIGHT_FRONT = 1,  // x=1, y=0, z=0
    BOTTOM_LEFT_BACK    = 2,  // x=0, y=1, z=0
    BOTTOM_RIGHT_BACK   = 3,  // x=1, y=1, z=0
    TOP_LEFT_FRONT      = 4,  // x=0, y=0, z=1
    TOP_RIGHT_FRONT     = 5,  // x=1, y=0, z=1
    TOP_LEFT_BACK       = 6,  // x=0, y=1, z=1
    TOP_RIGHT_BACK      = 7   // x=1, y=1, z=1
};

// 根据点的坐标确定属于哪个卦限
int getOctant(const BoundingBox& parent, const Point3D& p) {
    float mid_x = (parent.min_x + parent.max_x) / 2;
    float mid_y = (parent.min_y + parent.max_y) / 2;
    float mid_z = (parent.min_z + parent.max_z) / 2;
    
    int octant = 0;
    if (p.x >= mid_x) octant |= 1;  // x bit
    if (p.y >= mid_y) octant |= 2;  // y bit
    if (p.z >= mid_z) octant |= 4;  // z bit
    
    return octant;
}
```

## 4. 核心操作

### 4.1 插入操作

```cpp
void insert(OctreeNode* node, const Point3D& point, int max_depth = 8) {
    // 如果是叶子节点
    if (node->is_leaf) {
        node->points.push_back(point);
        
        // 超过容量限制且未达到最大深度，则分裂
        if (node->points.size() > MAX_POINTS_PER_NODE && node->depth < max_depth) {
            split(node);
        }
        return;
    }
    
    // 找到应该插入的子节点
    int octant = getOctant(node->bounds, point);
    insert(node->children[octant].get(), point, max_depth);
}

void split(OctreeNode* node) {
    // 创建 8 个子节点
    for (int i = 0; i < 8; i++) {
        node->children[i] = std::make_unique<OctreeNode>();
        node->children[i]->bounds = computeChildBounds(node->bounds, i);
        node->children[i]->depth = node->depth + 1;
    }
    
    // 将当前点的点重新分配到子节点
    for (const auto& p : node->points) {
        int octant = getOctant(node->bounds, p);
        node->children[octant]->points.push_back(p);
    }
    
    node->points.clear();
    node->is_leaf = false;
}
```

### 4.2 范围查询

查找完全或部分落在给定范围内的所有点：

```cpp
void rangeQuery(OctreeNode* node, const BoundingBox& range, 
                std::vector<Point3D>& result) {
    // 如果当前节点范围与查询范围不相交，直接返回
    if (!intersects(node->bounds, range)) {
        return;
    }
    
    // 如果是叶子节点，遍历并检查每个点
    if (node->is_leaf) {
        for (const auto& p : node->points) {
            if (contains(range, p)) {
                result.push_back(p);
            }
        }
        return;
    }
    
    // 递归查询子节点
    for (int i = 0; i < 8; i++) {
        if (node->children[i]) {
            rangeQuery(node->children[i].get(), range, result);
        }
    }
}
```

### 4.3 邻近搜索（KNN）

```cpp
void knnSearch(OctreeNode* node, const Point3D& target, 
               int k, std::priority_queue<Point3D>& candidates) {
    if (!node) return;
    
    // 计算当前节点中心到目标点的距离
    Point3D center = getCenter(node->bounds);
    float dist_to_node = distance(center, target);
    
    // 如果候选已满且当前节点距离更远，跳过
    if (!candidates.empty() && 
        candidates.size() >= k && 
        dist_to_node > getMaxDist(candidates)) {
        return;
    }
    
    if (node->is_leaf) {
        for (const auto& p : node->points) {
            float dist = distance(p, target);
            candidates.push(p);
            if (candidates.size() > k) {
                candidates.pop();
            }
        }
    } else {
        // 按距离排序子节点顺序
        std::vector<std::pair<int, float>> child_distances;
        for (int i = 0; i < 8; i++) {
            if (node->children[i]) {
                float d = distance(getCenter(node->children[i]->bounds), target);
                child_distances.push_back({i, d});
            }
        }
        sort(child_distances.begin(), child_distances.end(), 
             [](auto& a, auto& b) { return a.second < b.second; });
        
        for (auto& [idx, dist] : child_distances) {
            knnSearch(node->children[idx].get(), target, k, candidates);
        }
    }
}
```

## 5. 复杂度分析

| 操作 | 平均复杂度 | 最坏复杂度 |
| --- | --- | --- |
| 插入 | O(log n) | O(n) |
| 查询（范围） | O(log n + k) | O(n) |
| KNN 搜索 | O(log n + k) | O(n) |
| 建树 | O(n log n) | O(n²) |

其中 n 是点数，k 是返回结果数量。

## 6. 应用场景

### 6.1 3D 点云处理

```cpp
// 点云可视化中的空间划分
class PointCloudOctree {
    OctreeNode* root;
    
public:
    // 空间剔除：只渲染视野内的点
    void frustumCulling(const Frustum& frustum) {
        std::vector<Point3D> visible_points;
        rangeQuery(root, frustum.getBounds(), visible_points);
        render(visible_points);
    }
    
    // LOD（多层次细节）
    Point3D getApproximatePoint(float x, float y, float z, int depth) {
        OctreeNode* node = findNodeAtDepth(root, x, y, z, depth);
        if (node->is_leaf && !node->points.empty()) {
            return node->points[0];  // 返回叶子节点代表点
        }
        return Point3D(x, y, z);  // 返回查询点
    }
};
```

    OctreeNode* octree;

    void reconstruct() {
        std::vector<Triangle> triangles;
        auto points = getAllPoints(octree);

                triangles.push_back({seed, n.p1, n.p2});

                visited.insert(n.p2);
            }
        }
        return triangles;
    }
};

## 7. 变体与优化

### 7.1 松散八叉树（Loose Octree）

解决普通八叉树的问题：**物体跨边界时需要修改多个节点**。

```cpp
struct LooseOctreeNode {
    BoundingBox tight_bounds;    // 紧凑边界
    BoundingBox loose_bounds;    // 松散边界（通常为紧凑边界的 2 倍）
    
    // 物体可以属于松散边界而不属于任何子节点
    bool containsLoose(const Point3D& p) {
        return contains(loose_bounds, p);
    }
};
```

## 8. 八叉树 vs 其他结构

| 特性 | 八叉树 | BVH | KD 树 | 均匀网格 |
| --- | --- | --- | --- | --- |
| **划分方式** | 自适应空间 | 物体包围盒 | 轴对齐平面 | 固定网格 |
| **节点数量** | 动态 | 物体数量 | 点数 | 固定 |
| **查询复杂度** | O(log n + k) | O(log n + k) | O(log n + k) | O(1) per cell |
| **内存开销** | 中等 | 较高 | 较低 | 高（3D 网格） |
| **适用场景** | 空间密集分布 | 物体分布不均 | 静态点云 | 均匀分布 |

## 9. 面试高频问题

### Q1: 八叉树和四叉树有什么区别？

**回答要点**：
- 四叉树是二维空间划分，每个节点 4 个子节点
- 八叉树是三维空间划分，每个节点 8 个子节点
- 都是递归划分，自适应空间分布
- 四叉树适用于 GIS、地图；八叉树适用于 3D 点云、游戏

### Q2: 八叉树的查询复杂度是多少？

**回答要点**：
- 建树：O(n log n)
- 插入：O(log n)
- 范围查询：O(log n + k)，k 是结果数量
- KNN 搜索：O(log n + k)
- 最坏情况可能退化为 O(n)

### Q3: 八叉树有什么优缺点？

**回答要点**：
- **优点**：空间自适应划分、查询效率高、适合稀疏/密集混合分布
- **缺点**：实现复杂、内存开销（每个节点 8 个指针）、更新代价大

### Q4: 八叉树在游戏开发中怎么用？

**回答要点**：
- 碰撞检测前的快速筛选
- 可见性剔除（ frustum culling ）
- 实体空间查询
- LOD 辅助计算

## 10. 总结

八叉树是一种重要的**三维空间划分数据结构**，核心特点：

1. **空间递归划分**：每个节点 8 个子节点，对应 8 个卦限
2. **自适应分布**：密集区域划分深，稀疏区域划分浅
3. **高效查询**：范围查询和 KNN 搜索接近 O(log n)
4. **广泛应用**：3D 点云、游戏引擎、碰撞检测、科学计算

与四叉树是 2D/3D 的对应关系，与 KD 树都是空间划分结构，但八叉树更适合规则的立方体空间划分。
