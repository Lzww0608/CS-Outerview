# Radix Tree（基数树/压缩前缀树）详解

## 一、什么是 Radix Tree

### 1.1 定义

Radix Tree（基数树），也叫 Radix Trie、Compact Prefix Tree，是一种空间优化的前缀树变体，通过合并只有一个子节点的路径来节省空间。

```text
前缀树（Trie）：
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                      (root)                                  │
│                    /   |   \                                 │
│                   a    b    c                               │
│                  / \   |    |                                │
│                 an  at b   ca                               │
│                                                             │
│  每个字符一个节点，空间浪费                                   │
└─────────────────────────────────────────────────────────────┘

基数树（Radix Tree）：
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                      (root)                                  │
│                    /   |   \                                 │
│                  an   b    ca                               │
│                  |         |                                │
│                  t        t                                 │
│                                                             │
│  合并单子节点路径，空间紧凑                                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 与其他数据结构对比

| 数据结构 | 查找复杂度 | 空间效率 | 特性 |
|----------|-----------|----------|------|
| 哈希表 | O(1) | 中 | 无序，不支持前缀匹配 |
| 平衡树 | O(log n) | 好 | 有序，支持范围查询 |
| 前缀树 | O(m) | 差 | 支持前缀匹配，m=字符串长度 |
| 基数树 | O(m) | 好 | 压缩前缀树，空间优化 |

## 二、Radix Tree 的核心原理

### 2.1 节点结构

```c
struct RadixNode {
    char* key;              // 节点的字符串标签（非叶节点）
    void* value;           // 叶子节点存储的值
    struct RadixNode** children;  // 子节点数组
    int children_count;     // 子节点数量
    int is_leaf;           // 是否是叶子节点
};
```

### 2.2 压缩规则

```text
压缩规则：
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  前缀树节点只有 1 个子节点时：                              │
│                                                             │
│  before: [root] ──► [a] ──► [n] ──► [t] ──► (leaf)     │
│                                                             │
│  after:  [root] ──► ["ant"] ──► (leaf)                    │
│                                                             │
│  合并成一个边，减少节点数量                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 基本操作

#### 插入操作

```c
int radix_insert(RadixTree* tree, const char* key, void* value) {
    if (!key || !*key) return -1;
    
    RadixNode* current = tree->root;
    const char* remaining = key;
    
    while (*remaining) {
        // 查找匹配的子节点
        RadixNode* match = find_matching_child(current, remaining);
        
        if (!match) {
            // 没有匹配，创建新节点
            RadixNode* new_node = create_node(remaining, value, 1);
            add_child(current, new_node);
            return 0;
        }
        
        // 找到匹配，分析匹配情况
        int common_len = common_prefix_length(match->key, remaining);
        
        if (common_len == strlen(match->key)) {
            // 完全匹配边，继续深入
            remaining += common_len;
            current = match;
        } else {
            // 部分匹配，需要分裂边
            split_edge(current, match, common_len, remaining, value);
            return 0;
        }
    }
    
    // 设置叶子节点值
    if (current->is_leaf) {
        current->value = value;
    }
    return 0;
}
```

#### 查找操作

```c
void* radix_lookup(RadixTree* tree, const char* key) {
    RadixNode* current = tree->root;
    const char* remaining = key;
    
    while (*remaining && current) {
        RadixNode* match = find_matching_child(current, remaining);
        
        if (!match) return NULL;
        
        if (strncmp(match->key, remaining, strlen(match->key)) == 0) {
            remaining += strlen(match->key);
            current = match;
        } else {
            return NULL;
        }
    }
    
    return current && current->is_leaf ? current->value : NULL;
}
```

## 三、应用场景

### 3.1 IP 路由最长前缀匹配

这是 Radix Tree 最经典的应用，用于路由表查找。

```text
路由表示例：
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  路由条目：                                                 │
│  10.0.0.0/8      ──► 网段 A                               │
│  10.1.0.0/16     ──► 网段 B                               │
│  10.1.2.0/24     ──► 网段 C                               │
│  192.168.0.0/16  ──► 网段 D                               │
│                                                             │
│  查找 10.1.2.100：最长匹配是 10.1.2.0/24 → 网段 C        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```c
// IP 路由查找
struct RouteEntry {
    char* prefix;        // IP 前缀
    int prefix_len;      // 前缀长度
    char* next_hop;      // 下一跳
};

void* route_lookup(RadixTree* tree, uint32_t ip) {
    char ip_str[16];
    format_ip(ip_str, ip);
    
    // Radix Tree 自动找到最长匹配前缀
    return radix_longest_prefix_match(tree, ip_str);
}
```

## 四、实现示例

### 4.1 C 语言实现

```c
#include <stdlib.h>
#include <string.h>
#include <stdio.h>

#define RADIX_MAX_KEY_LEN 256

typedef struct RadixNode {
    char key[RADIX_MAX_KEY_LEN];
    void* value;
    struct RadixNode** children;
    int children_count;
    int children_capacity;
    int is_leaf;
} RadixNode;

typedef struct RadixTree {
    RadixNode* root;
} RadixTree;

RadixNode* create_node(const char* key, void* value, int is_leaf) {
    RadixNode* node = calloc(1, sizeof(RadixNode));
    strncpy(node->key, key, RADIX_MAX_KEY_LEN - 1);
    node->value = value;
    node->is_leaf = is_leaf;
    node->children_capacity = 4;
    node->children = calloc(node->children_capacity, sizeof(RadixNode*));
    return node;
}

int common_prefix(const char* s1, const char* s2) {
    int len = 0;
    while (*s1 && *s2 && *s1 == *s2) {
        len++;
        s1++;
        s2++;
    }
    return len;
}

RadixNode* find_child(RadixNode* node, char c) {
    for (int i = 0; i < node->children_count; i++) {
        if (node->children[i]->key[0] == c) {
            return node->children[i];
        }
    }
    return NULL;
}

int radix_insert(RadixTree* tree, const char* key, void* value) {
    RadixNode* current = tree->root;
    const char* remaining = key;
    
    while (*remaining) {
        RadixNode* child = find_child(current, *remaining);
        
        if (!child) {
            // 没有匹配，创建新节点
            RadixNode* new_node = create_node(remaining, value, 1);
            current->children[current->children_count++] = new_node;
            return 1;
        }
        
        // 找到可能的匹配
        int prefix_len = common_prefix(child->key, remaining);
        
        if (prefix_len < strlen(child->key)) {
            // 需要分裂：child->key 被分成 [0:prefix_len] 和 [prefix_len:]
            // 创建新父节点
            RadixNode* parent = create_node(child->key, NULL, 0);
            parent->key[prefix_len] = '\0';
            
            // 原节点变为子节点
            child->key += prefix_len;
            parent->children[parent->children_count++] = child;
            
            // 新节点
            RadixNode* new_leaf = create_node(remaining + prefix_len, value, 1);
            parent->children[parent->children_count++] = new_leaf;
            
            return 1;
        }
        
        // 完全匹配，继续深入
        remaining += prefix_len;
        current = child;
    }
    
    // 到达叶子节点
    current->value = value;
    return 1;
}

void* radix_search(RadixTree* tree, const char* key) {
    RadixNode* current = tree->root;
    const char* remaining = key;
    
    while (*remaining && current) {
        RadixNode* child = find_child(current, *remaining);
        if (!child) return NULL;
        
        int prefix_len = common_prefix(child->key, remaining);
        if (prefix_len < strlen(child->key)) return NULL;
        
        remaining += prefix_len;
        current = child;
    }
    
    return current && current->is_leaf ? current->value : NULL;
}

void radix_free(RadixNode* node) {
    if (!node) return;
    for (int i = 0; i < node->children_count; i++) {
        radix_free(node->children[i]);
    }
    free(node->children);
    free(node);
}
```

## 五、复杂度分析

### 5.1 时间复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(k) | O(k) |
| 插入 | O(k) | O(k) |
| 删除 | O(k) | O(k) |
| 最长前缀匹配 | O(k) | O(k) |

k = 字符串长度或键的深度

### 5.2 空间复杂度

- 最坏：O(n × m)，n = 键数量，m = 平均键长度
- 最好：O(n × m / t)，t = 分支因子
- 实际：通常介于两者之间，取决于键的分布

## 六、面试常见问题

### Q1: Radix Tree 和 Trie（前缀树）的区别？

Radix Tree 是压缩后的 Trie，合并了只有单个子节点的路径，减少节点数量。对于长字符串（如 URL、IP）效果显著。

### Q2: Radix Tree 和哈希表的区别？

| 特性 | Radix Tree | 哈希表 |
|------|-------------|--------|
| 查找顺序 | 有序 | 无序 |
| 前缀匹配 | 支持 | 不支持 |
| 空间效率 | 高（共享前缀） | 中 |
| 最长前缀匹配 | 高效 | 不支持 |

### Q3: Radix Tree 的应用场景？

1. IP 路由：最长前缀匹配（Linux 内核路由表）
2. 文件系统：路径索引
3. 内存管理：页面缓存（Linux 内核 page cache）
4. DNS：域名查找
5. 配置管理：层级配置键

### Q4: Linux 内核中 Radix Tree 的应用？

Linux 使用 Radix Tree 管理：
- 页面缓存（page cache）：通过页索引快速查找
- 交换缓存（swap cache）
- 进程 ID 映射

## 七、总结

1. **定义**：Radix Tree 是压缩前缀树，通过合并单子节点路径节省空间
2. **核心操作**：插入、查找、最长前缀匹配
3. **应用场景**：IP 路由、文件系统、内存管理、DNS、配置管理
4. **复杂度**：O(k) 时间复杂度，高空间效率
5. **优势**：支持前缀匹配、有序、空间优化
