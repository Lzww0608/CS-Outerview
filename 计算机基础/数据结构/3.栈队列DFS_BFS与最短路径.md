# 栈、队列、DFS、BFS 与最短路径

这几个知识点经常被放在一起问。回答时不要只背定义，要把数据结构特性和实际场景联系起来：栈适合“最近的先处理”，队列适合“先来的先处理”，DFS 适合深入搜索和回溯，BFS 适合按层扩展和无权最短路。

## 1. 栈的实际应用

栈是后进先出结构，核心操作是 `push/pop/top`，通常都是 `O(1)`。

典型应用：

1. **函数调用栈**：保存返回地址、局部变量、寄存器现场。
2. **括号匹配**：遇到左括号入栈，遇到右括号检查栈顶。
3. **表达式求值**：操作数栈和运算符栈，例如逆波兰表达式。
4. **单调栈**：求下一个更大元素、柱状图最大矩形、每日温度。
5. **回溯搜索**：递归本质上依赖调用栈，也可以改成显式栈避免爆栈。
6. **撤销/重做**：编辑器 undo stack、浏览器历史回退。

易错点：栈适合处理嵌套、回退、最近未完成任务；如果任务需要按到达顺序处理，不应该用栈。

## 2. 队列的实际应用

队列是先进先出结构，核心操作是 `push/pop/front`，通常都是 `O(1)`。

典型应用：

1. **BFS 层序遍历**：队列保存下一批待访问节点。
2. **生产者消费者模型**：生产线程入队，消费线程出队。
3. **任务调度**：线程池任务队列、消息队列、事件队列。
4. **限流削峰**：请求先进入队列，再按固定速率消费。
5. **滑动窗口**：双端队列维护窗口最大/最小值。
6. **网络服务器**：accept 队列、事件队列、异步日志队列。

易错点：普通队列只支持 FIFO。如果要按优先级处理，用堆或优先队列；如果两端都要插删，用双端队列。

## 3. DFS 和 BFS

DFS 是深度优先搜索，优先沿着一条路径走到底，再回溯。BFS 是广度优先搜索，从起点按距离层层扩展。

| 对比项 | DFS | BFS |
| --- | --- | --- |
| 常用结构 | 递归栈或显式栈 | 队列 |
| 访问顺序 | 先深入再回溯 | 按层推进 |
| 空间特点 | 递归深度为 `O(h)`，最坏 `O(V)` | 队列可能保存一整层，最坏 `O(V)` |
| 常见场景 | 连通性、回溯、拓扑、环检测 | 层序遍历、无权最短路、最少步数 |

DFS 适合：

1. 图或树的连通性判断。
2. 回溯枚举，例如全排列、组合、棋盘搜索。
3. 拓扑排序和有向图判环。
4. 树的前序、中序、后序遍历。

BFS 适合：

1. 二叉树层序遍历。
2. 无权图最短路径。
3. 棋盘最少步数、单词接龙、迷宫最短步数。
4. 多源扩散，例如腐烂橘子、地图距离。

## 4. 最短路径怎么选算法

最短路径要先看边权。

| 场景 | 推荐算法 | 复杂度与说明 |
| --- | --- | --- |
| 无权图或每条边权相同 | BFS | 第一次到达节点就是最短步数 |
| 边权非负 | Dijkstra | 堆优化通常是 `O((V+E)logV)` |
| 有负权边但无负环 | Bellman-Ford / SPFA | Bellman-Ford 是 `O(VE)` |
| 多源最短路、点数较少 | Floyd | `O(V^3)`，实现简单 |
| 启发式搜索 | A* | 用估价函数加速，例如地图寻路 |

Dijkstra 的核心是贪心：每次取当前距离最小且未确定的点，它的最短距离就被确定。这个结论依赖边权非负；如果有负权边，后面可能出现更短路径推翻已经确定的结果。

## 5. 面试回答模板

栈是后进先出，适合函数调用、括号匹配、表达式求值、单调栈和回溯；队列是先进先出，适合 BFS、生产消费、任务调度和削峰。DFS 用递归栈或显式栈，适合连通性、回溯、拓扑和环检测；BFS 用队列按层扩展，适合无权图最短路和最少步数问题。最短路径要看边权：无权图用 BFS，非负权用 Dijkstra，有负权用 Bellman-Ford，点数小的多源最短路用 Floyd。
