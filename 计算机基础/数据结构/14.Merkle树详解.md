## 一、Merkle 树概述

### 1.1 什么是 Merkle 树

Merkle 树（默克尔树）是一种哈希树，由 Ralph Merkle 于 1979 年提出，用于高效验证大规模数据的完整性。

## 二、Merkle 树构建

### 2.1 构建算法

```python
import hashlib

class MerkleTree:
    def __init__(self, data_items):
        self.leaves = [self.hash(item) for item in data_items]
        self.tree = self.build_tree(self.leaves)
    
    @staticmethod
    def hash(data):
        """计算 SHA-256 哈希"""
        if isinstance(data, str):
            data = data.encode()
        return hashlib.sha256(data).hexdigest()
    
    def build_tree(self, nodes):
        """递归构建 Merkle 树"""
        if len(nodes) == 1:
            return nodes[0]
        
        new_level = []
        for i in range(0, len(nodes), 2):
            left = nodes[i]
            right = nodes[i + 1] if i + 1 < len(nodes) else left
            new_level.append(self.hash(left + right))
        
        return self.build_tree(new_level)
    
    def get_root(self):
        """获取根哈希"""
        return self.tree
```

### 2.2 构建示例

```python
# 构建 Merkle 树
data = ['A', 'B', 'C', 'D']

tree = MerkleTree(data)

# 层级展示
print("Leaf hashes:")
print(f"  Hash(A) = {tree.hash('A')}")
print(f"  Hash(B) = {tree.hash('B')}")
print(f"  Hash(C) = {tree.hash('C')}")
print(f"  Hash(D) = {tree.hash('D')}")

print("\nLevel 1 (pairs):")
# Hash(Hash(A) + Hash(B)), Hash(Hash(C) + Hash(D))

print("\nLevel 2 (root):")
print(f"  Root = {tree.get_root()}")
```

## 三、Merkle 证明

### 3.1 验证原理

```python
class MerkleProof:
    @staticmethod
    def generate_proof(root, leaf, path):
        """
        生成 Merkle 证明
        
        path: [(sibling_hash, direction), ...]
        direction: 'left' or 'right'
        """
        current = leaf
        proof = []
        
        for sibling, direction in path:
            if direction == 'left':
                current = hashlib.sha256(
                    (sibling + current).encode()
                ).hexdigest()
            else:  # right
                current = hashlib.sha256(
                    (current + sibling).encode()
                ).hexdigest()
            proof.append((sibling, direction))
        
        return current == root
    
    @staticmethod
    def verify(root, leaf, proof_hashes, proof_directions):
        """验证 Merkle 证明"""
        current = MerkleTree.hash(leaf)
        
        for sibling, direction in zip(proof_hashes, proof_directions):
            if direction == 'left':
                current = MerkleTree.hash(sibling + current)
            else:
                current = MerkleTree.hash(current + sibling)
        
        return current == root
```

### 4.2 分布式存储

```python
# 分布式存储中的 Merkle 树

class DistributedStorage:
    def __init__(self):
        self.chunks = {}  # chunk_id -> data
        self.merkle_trees = {}  # file_id -> MerkleTree
    
    def store_file(self, file_id, data):
        """存储文件并构建 Merkle 树"""
        # 分块
        chunks = self.split_into_chunks(data)
        
        # 存储块
        for i, chunk in enumerate(chunks):
            self.chunks[(file_id, i)] = chunk
        
        # 构建 Merkle 树
        self.merkle_trees[file_id] = MerkleTree(chunks)
        
        return self.merkle_trees[file_id].get_root()
    
    def verify_chunk(self, file_id, chunk_index, chunk_data):
        """验证数据块完整性"""
        tree = self.merkle_trees[file_id]
        
        # 生成该块的证明
        proof = self.generate_proof(file_id, chunk_index)
        
        # 验证
        return MerkleProof.verify(
            tree.get_root(),
            chunk_data,
            proof['hashes'],
            proof['directions']
        )
```

## 七、面试常见问题

### Q1: Merkle 树有什么作用？

高效验证数据完整性、支持部分验证、快速检测篡改、轻节点可行性。

### Q2: Merkle 树如何验证数据？

用户提供数据叶子节点和到根的路径哈希，接收方重放计算路径，比较根哈希是否一致。

### Q3: Merkle 树 vs 区块链的关系？

区块链用 Merkle 树组织交易数据，生成 Merkle 根存储在区块头中，支持 SPV 轻节点验证交易存在。

### Q4: Merkle Patricia Trie 是什么？

结合 Merkle 树和前缀树的变体，共享公共前缀节省空间，同时保留 Merkle 哈希验证能力，以太坊用其存储状态。

## 八、总结

1. **Merkle 树定义**：哈希组成的二叉/多叉树结构
2. **核心作用**：高效验证数据完整性、支持部分验证、快速检测篡改
3. **应用场景**：区块链、P2P 网络、分布式存储、Git
4. **变体**：Merkle Patricia Trie、Sparse Merkle Tree、Verkle Tree
5. **性能**：构建 O(n)，验证 O(log n)
