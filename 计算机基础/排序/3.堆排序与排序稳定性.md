# 3. 堆排序与排序稳定性

## 1. 堆排序是什么

堆排序利用二叉堆维护当前最大值或最小值。

以升序排序为例，通常使用大根堆：

1. 原地建大根堆。
2. 把堆顶最大值和数组末尾交换。
3. 堆大小减 1，对新堆顶下沉调整。
4. 重复直到数组有序。

## 1.1 如何维护堆

堆的核心性质是：父节点的值不小于两个子节点的值。数组下标从 0 开始时：

```text
left = 2 * i + 1
right = 2 * i + 2
parent = (i - 1) / 2
```

堆排序里最常用的是下沉 `siftDown`：当堆顶被交换到末尾后，把末尾元素放到根节点，再不断和较大的子节点交换，直到父节点重新不小于子节点。

```cpp
#include <algorithm>
#include <vector>

void siftDown(std::vector<int>& a, int heapSize, int i) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && a[left] > a[largest]) {
            largest = left;
        }
        if (right < heapSize && a[right] > a[largest]) {
            largest = right;
        }
        if (largest == i) {
            break;
        }

        std::swap(a[i], a[largest]);
        i = largest;
    }
}
```

建堆从最后一个非叶子节点开始向前下沉：

```cpp
for (int i = n / 2 - 1; i >= 0; --i) {
    siftDown(a, n, i);
}
```

为什么建堆是 `O(n)` 而不是 `O(n log n)`：底层节点数量多但下沉高度低，越靠近根节点数量越少，所有节点下沉高度求和是线性的。单次删除堆顶后维护堆是 `O(log n)`。

## 1.2 堆的插入、删除、上浮和下沉

二叉堆常见操作可以统一理解为“只修复一条从节点到根或从节点到叶子的路径”。

### 向上调整 siftUp

插入新元素时，先把元素放到数组末尾，再不断和父节点比较。如果大根堆中子节点比父节点大，就交换并继续向上。

```cpp
void siftUp(std::vector<int>& heap, int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[parent] >= heap[i]) {
            break;
        }
        std::swap(heap[parent], heap[i]);
        i = parent;
    }
}
```

插入操作：

```cpp
void pushHeap(std::vector<int>& heap, int x) {
    heap.push_back(x);
    siftUp(heap, static_cast<int>(heap.size()) - 1);
}
```

时间复杂度是 `O(log n)`，因为最多从叶子一路交换到根。

### 删除堆顶

删除堆顶时，不能直接删除数组第一个元素，否则会整体移动数组。常见做法是：

1. 保存堆顶答案。
2. 用末尾元素覆盖堆顶。
3. 删除末尾。
4. 对新的堆顶做下沉调整。

```cpp
int popHeap(std::vector<int>& heap) {
    int ans = heap.front();
    heap[0] = heap.back();
    heap.pop_back();
    if (!heap.empty()) {
        siftDown(heap, static_cast<int>(heap.size()), 0);
    }
    return ans;
}
```

时间复杂度也是 `O(log n)`。

### 修改任意节点

如果堆中某个下标的值被修改：

1. 新值变大：可能违反和父节点的关系，执行 `siftUp`。
2. 新值变小：可能违反和子节点的关系，执行 `siftDown`。
3. 不确定方向：可以和旧值比较，或先 `siftUp` 再 `siftDown`，但要避免不必要开销。

真实定时器或优先队列如果需要按 id 删除/更新元素，通常会维护 `id -> index` 的哈希表；每次交换堆元素时同步更新 index，否则只能 `O(n)` 查找元素位置。

## 2. 时间复杂度

| 阶段 | 复杂度 |
| --- | --- |
| 建堆 | `O(n)` |
| 每次取堆顶 | `O(log n)` |
| 取 `n` 次 | `O(n log n)` |

所以堆排序最好、平均、最坏时间复杂度都是：

```text
O(n log n)
```

空间复杂度是：

```text
O(1)
```

因为可以在原数组上原地建堆。

## 3. 稳不稳定

普通堆排序是不稳定排序。

原因是堆顶和末尾元素交换、下沉调整会让相等元素跨越彼此，破坏原有相对顺序。

例如两个值相同但业务含义不同的元素：

```text
5a, 5b, 3
```

经过建堆和交换后，`5a` 和 `5b` 的相对顺序可能改变。

## 4. 快排稳不稳定

普通原地快速排序也不稳定。partition 过程中元素会跨区交换，相等元素的原始顺序无法保证。

如果需要稳定性：

1. 使用归并排序。
2. 使用稳定排序接口，例如 C++ 的 `std::stable_sort`。
3. 排序 key 相同的时候追加原始下标作为第二关键字。

## 5. 常见排序稳定性

| 算法 | 是否稳定 | 备注 |
| --- | --- | --- |
| 冒泡排序 | 稳定 | 相等元素不交换即可 |
| 插入排序 | 稳定 | 插入时不跨越相等元素 |
| 归并排序 | 稳定 | 合并时相等元素先取左边 |
| 计数排序 | 可稳定 | 反向填充可稳定 |
| 快速排序 | 通常不稳定 | 原地 partition 会交换 |
| 堆排序 | 不稳定 | 堆调整会跨越相等元素 |
| 选择排序 | 不稳定 | 选择最值交换会跨越 |

## 6. 面试回答模板

堆排序先原地建堆，再不断把堆顶和末尾交换并下沉调整。建堆是 `O(n)`，每次调整 `O(log n)`，总时间复杂度最好、平均、最坏都是 `O(n log n)`，空间复杂度 `O(1)`。堆插入是在末尾追加后向上调整，删除堆顶是用末尾覆盖堆顶后向下调整，二者都是 `O(log n)`。普通堆排序不稳定，因为堆顶和末尾交换、下沉调整会改变相等元素的相对顺序。普通原地快排也不稳定；如果业务需要稳定性，可以用归并排序或 `std::stable_sort`。
