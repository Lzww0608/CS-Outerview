# 判断排序算法稳定性的方法

## 1. 问题背景

排序算法稳定性指相等的元素在排序后保持原有的相对顺序。在实际应用中，稳定排序对于多字段排序、保持业务逻辑一致性至关重要。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  排序稳定性定义：                                          │
│                                                             │
│  稳定排序：相同关键字的元素，排序后相对顺序不变             │
│  非稳定排序：相同关键字的元素，排序后相对顺序可能改变       │
│                                                             │
│  示例：                                                    │
│  原序列：[(A, 2), (B, 1), (C, 2), (D, 1)]                 │
│  按分数排序后：                                            │
│  稳定排序：[(B, 1), (D, 1), (A, 2), (C, 2)]  ✓           │
│  非稳定排序：[(D, 1), (B, 1), (C, 2), (A, 2)]  ✗         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 多字段排序结果不一致 | 先按 A 字段排，再按 B 字段排时相同 B 值内部顺序错乱 |
| 业务逻辑被破坏 | 如订单按时间+状态排序，稳定排序才能保证同状态订单时间顺序 |
| 算法选型困惑 | 不知如何判断新算法的稳定性 |

- 多字段排序场景
- 订单处理、数据报表

### 4.2 稳定性产生的条件

```python
# 导致不稳定的常见操作：

# 1. 交换操作（快速排序的 partition）
def unstable_partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            # 交换：可能导致相同元素位置改变
            arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i + 1

# 2. 堆排序的堆化过程
def heapify_unstable(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right
    
    if largest != i:
        # 交换：可能导致相同元素位置改变
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify_unstable(arr, n, largest)
```

## 5. 解决方案

### 5.1 形式化判断方法

```python
def is_sort_stable(sort_function, arr, key=lambda x: x):
    """
    判断排序算法是否稳定
    
    Args:
        sort_function: 排序函数
        arr: 输入数组
        key: 排序关键字函数
    
    Returns:
        bool: 是否稳定
    """
    # 1. 记录原始位置和值
    indexed_arr = [(item, i) for i, item in enumerate(arr)]
    
    # 2. 提取纯值用于排序
    values = [item for item, _ in indexed_arr]
    
    # 3. 执行排序
    sorted_values = sort_function(values.copy())
    
    # 4. 恢复排序后的位置
    value_to_indices = {}
    for i, item in enumerate(indexed_arr):
        value_to_indices.setdefault(item, []).append(i)
    
    # 5. 检查相同关键字元素的原始位置是否保持顺序
    for i in range(len(sorted_values) - 1):
        curr_key = key(sorted_values[i])
        next_key = key(sorted_values[i + 1])
        
        if curr_key == next_key:
            # 找到这两个元素在原数组中的位置
            curr_indices = value_to_indices[(sorted_values[i], 
                next(i for i, (v, _) in enumerate(indexed_arr) if v == sorted_values[i] and key(v) == curr_key))]
            next_indices = value_to_indices[(sorted_values[i + 1], 
                next(i for i, (v, _) in enumerate(indexed_arr) if v == sorted_values[i + 1] and key(v) == next_key))]
            
            # 如果相等元素的原始位置不保持顺序，则不稳定
            if len(curr_indices) > 1:
                continue  # 跳过重复值检查
    
    return True
```

### 5.2 简化验证方法

```python
def is_stable_simple(sort_func, n=1000):
    """
    简化稳定性测试：
    生成包含重复元素的数组，排序后检查相同元素的原始顺序
    
    核心思想：
    1. 给每个元素附加唯一索引作为第二排序关键字
    2. 如果算法稳定，排序后相同值元素的索引应保持升序
    """
    import random
    
    # 生成测试数据：值 + 原始索引
    test_data = [(random.choice(['A', 'B', 'C']), i) for i in range(n)]
    original_indices = {i for _, i in test_data}
    
    # 执行排序（只按值排序，忽略索引）
    values_only = [v for v, _ in test_data]
    sorted_values = sort_func(values_only)
    
    # 重建排序后的带索引数组
    sorted_with_index = []
    idx_map = {}
    for i, v in enumerate(test_data):
        idx_map.setdefault(v, []).append(i)
    
    for v in sorted_values:
        sorted_with_index.append(idx_map[v].pop(0))
    
    # 检查相同值的元素索引是否保持升序
    prev_key, prev_idx = None, -1
    for item, idx in sorted_with_index:
        if item == prev_key:
            if idx < prev_idx:  # 索引变小，说明顺序被改变
                return False
        prev_key, prev_idx = item, idx
    
    return True
```

```text
│                                                             │
│  稳定性快速判断口诀：                                       │
│                                                             │
│  1. 基于比较交换的算法，看是否会交换相等元素               │
│  2. 基于索引比较的算法，通常稳定                          │
│  3. 需要额外空间的算法，可以设计成稳定的                  │
│                                                             │
│  常见算法稳定性：                                          │
│  • 冒泡排序：稳定（只交换逆序对）                        │
│  • 插入排序：稳定（只移动比它大的元素）                   │
│  • 归并排序：稳定（合并时先放左半部分）                  │
│  • 快速排序：不稳定（partition 交换）                    │
│  • 堆排序：不稳定（堆化过程可能交换）                    │
│  • 希尔排序：不稳定（插入排序变体）                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 通用测试框架

```python
class StabilityTester:
    """
    排序稳定性测试框架
    """
    
    # 常见排序算法
    SORTING_ALGORITHMS = {
        'bubble': lambda arr: bubble_sort(arr.copy()),
        'insertion': lambda arr: insertion_sort(arr.copy()),
        'merge': lambda arr: merge_sort(arr.copy()),
        'quick': lambda arr: quick_sort(arr.copy()),
        'heap': lambda arr: heap_sort(arr.copy()),
    }
    
    def __init__(self):
        self.results = {}
    
    def generate_test_cases(self):
        """生成测试用例"""
        return [
            # 完全相同元素
            ([1, 1, 1, 1], "all_same"),
            # 两两相同
            ([1, 2, 1, 2, 1, 2], "pairwise"),
            # 少量不同值
            ([3, 1, 2, 3, 1, 2], "few_unique"),
            # 边界值
            ([0, 0, 1, 1, 0], "edge_values"),
            # 随机大量
            (self._random_with_duplicates(100, 10), "random"),
        ]
    
    def test_algorithm(self, name, sort_func, test_cases):
        """测试单个算法的稳定性"""
        for arr, case_name in test_cases:
            if not self._is_stable(sort_func, arr):
                return False, f"Failed at {case_name}"
        return True, "All passed"
    
    def _is_stable(self, sort_func, arr):
        """核心稳定性判断"""
        # 带索引的数组
        indexed = [(x, i) for i, x in enumerate(arr)]
        original_indices = {x: [i for i, v in indexed if v == x] for x, _ in indexed}
        
        # 排序（只按值排序）
        values = [x for x, _ in indexed]
        sorted_values = sort_func(values)
        
        # 检查相同值元素的原始索引是否保持顺序
        for i in range(len(sorted_values) - 1):
            if sorted_values[i] == sorted_values[i + 1]:
                # 获取这两个元素在原数组中的位置
                idx1 = original_indices[sorted_values[i]].pop(0)
                idx2 = original_indices[sorted_values[i + 1]].pop(0)
                if idx1 > idx2:
                    return False  # 顺序被改变，不稳定
        return True
    
    def run_all(self):
        """运行所有测试"""
        test_cases = self.generate_test_cases()
        for name, func in self.SORTING_ALGORITHMS.items():
            stable, msg = self.test_algorithm(name, func, test_cases)
            self.results[name] = {'stable': stable, 'message': msg}
        return self.results
```

## 10. 验证方式

### 10.1 自动化验证脚本

```python
#!/usr/bin/env python3
"""
排序算法稳定性验证脚本
"""

def verify_stability(sort_func, test_data):
    """
    核心验证逻辑：
    1. 给每个元素附加唯一索引
    2. 按第一关键字排序
    3. 检查相同第一关键字的元素索引是否保持升序
    """
    # 构造带索引的数据
    indexed = [(value, original_idx) for original_idx, value in enumerate(test_data)]
    
    # 排序（只按值排序）
    sorted_indexed = sorted(indexed, key=lambda x: x[0])
    
    # 检查相同值的索引是否保持顺序
    prev_key, prev_idx = None, -1
    for key, idx in sorted_indexed:
        if key == prev_key:
            if idx < prev_idx:
                return False  # 不稳定
        prev_key, prev_idx = key, idx
    
    return True

# 测试示例
if __name__ == "__main__":
    test_cases = [
        [1, 2, 1, 2, 1, 2],
        [3, 3, 2, 2, 1, 1],
        [1, 1, 1, 2, 2, 2],
    ]
    
    for case in test_cases:
        result = verify_stability(sorted, case)  # sorted 是稳定的
        print(f"数组 {case}: {'稳定' if result else '不稳定'}")
```

## 11. 总结

1. **稳定性定义**：相等元素的相对顺序在排序后保持不变
2. **判断方法**：理论分析（追踪相等元素路径）+ 实际测试（带索引验证）
3. **快速判断**：
   - 基于比较交换且不含相等判断的算法通常不稳定
   - 插入排序、归并排序可实现为稳定的
   - 快速排序、堆排序天生不稳定
4. **验证重点**：构造有重复元素的测试用例，检查相同值元素的原始索引顺序
5. **核心原则**：稳定性是排序算法的固有属性，由算法逻辑决定，不是参数可调的
