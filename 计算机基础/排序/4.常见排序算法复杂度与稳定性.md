# 4. 常见排序算法复杂度与稳定性

面试问“常见排序算法及其时间复杂度，以及是否稳定”时，建议同时回答：最好、平均、最坏复杂度，额外空间，是否稳定，是否原地，以及适用场景。

## 1. 稳定性是什么

排序算法的稳定性指：如果两个元素的 key 相等，排序后它们的相对顺序是否保持不变。

例如按分数排序学生：

```text
(Alice, 90), (Bob, 90)
```

稳定排序后 Alice 仍在 Bob 前面；不稳定排序可能交换它们的位置。

稳定性在多关键字排序里很重要。例如先按时间排序，再按优先级稳定排序，就可以在相同优先级内保留原时间顺序。

## 2. 复杂度总览

| --- | --- | --- | --- | --- | --- | --- | --- |
| 冒泡排序 | `O(n)` | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 | 是 | 教学，几乎不用在工程主路径 |
| 插入排序 | `O(n)` | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 | 是 | 小数组、基本有序数据 |
| 选择排序 | `O(n^2)` | `O(n^2)` | `O(n^2)` | `O(1)` | 通常不稳定 | 是 | 交换次数少但整体效率低 |
| 希尔排序 | 取决于 gap | 取决于 gap | 通常高于 `O(n^2)` 或接近 | `O(1)` | 不稳定 | 是 | 插入排序的分组优化 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 | 否 | 链表排序、外部排序、稳定排序 |
| 快速排序 | `O(n log n)` | `O(n log n)` | `O(n^2)` | 平均 `O(log n)` | 不稳定 | 通常是 | 通用内存排序，随机化可降低退化概率 |

| `std::sort` | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(log n)` | 不稳定 | 是 | C++ 通用排序，通常是 introsort |
| `std::stable_sort` | `O(n log n)` | `O(n log n)` | `O(n log n)` | 通常 `O(n)` | 稳定 | 否 | 需要保持相等元素相对顺序 |

## 3. 几个重点算法

### 快速排序

快速排序通过 partition 把数组分成小于 pivot 和大于 pivot 的两部分，再递归排序。

易错点：

1. 快排平均 `O(n log n)`，最坏 `O(n^2)`，例如每次 pivot 都选到极端位置。
2. 随机选 pivot、三数取中、尾递归优化可以降低退化风险。
3. 快排通常不稳定，因为 partition 过程中相等元素可能跨位置交换。
4. C++ `std::sort` 通常不是朴素快排，而是 introsort：快排递归过深时切换堆排序，小区间用插入排序优化。

### 归并排序

归并排序把数组分成两半递归排序，再合并两个有序区间。

特点：

1. 时间复杂度稳定为 `O(n log n)`。
2. 数组归并需要 `O(n)` 额外空间。
3. 稳定性好，适合多关键字排序。
4. 链表归并排序可以做到较低额外空间，因为合并链表只需要改指针。

### 堆排序

堆排序先建堆，再反复把堆顶放到最终位置。

特点：

1. 建堆是 `O(n)`。
2. 每次取堆顶并调整是 `O(log n)`，总复杂度 `O(n log n)`。
3. 额外空间 `O(1)`，最坏时间有保证。
4. 不稳定，且缓存局部性通常不如快排。

### 计数排序、基数排序和桶排序

这几类算法不是纯比较排序，所以能在满足约束时突破 `O(n log n)`。

1. 计数排序适合整数值域小的场景。
2. 基数排序适合位数固定或上界明确的整数、字符串。
3. 桶排序依赖数据分布，如果大量元素落入同一个桶，可能退化。
4. 计数排序和基数排序要实现稳定，通常需要前缀和并从后向前放置元素。

## 4. 多路归并

多路归并是把 `k` 个已经有序的序列合并成一个有序序列。它是归并排序思想在多文件、多链表、外部排序中的常见扩展。

最常用做法是小根堆：

1. 把每个有序序列的第一个元素放入小根堆，堆元素记录值、来自哪个序列、序列内下标。
2. 每次弹出堆顶最小值，写入结果。
3. 从同一个序列取下一个元素入堆。
4. 堆为空时归并结束。

复杂度：

```text
总元素数为 N，路数为 k
时间复杂度：O(N log k)
额外空间：O(k)
```

示例场景：

1. 合并 K 个升序链表。
2. 外部排序中，把多个磁盘有序 run 合并成一个大文件。
3. 日志系统按时间戳合并多台机器的有序日志。
4. 搜索系统合并多个分片返回的 TopN 结果。

易错点：

1. 多路归并的 `log k` 来自堆大小，不是 `log N`。
2. 如果只合并两个序列，双指针就够了，不需要堆。
3. 外部排序时瓶颈常在磁盘 I/O，要做顺序读写、缓冲区和批量输出。
4. TopK 合并时不一定要合并全部元素，弹出前 K 个即可停止。

## 5. 面试回答模板

常见排序里，冒泡、插入、选择都是 `O(n^2)`，插入排序在基本有序时最好 `O(n)` 且稳定。归并排序时间稳定 `O(n log n)`，稳定但需要 `O(n)` 额外空间。快速排序平均 `O(n log n)`，最坏 `O(n^2)`，通常不稳定；工程里会用随机化、三数取中或 introsort 降低风险。堆排序最坏 `O(n log n)`、额外空间 `O(1)`，但不稳定。计数、基数、桶排序能接近线性，但依赖整数值域、位数或分布假设，不属于通用比较排序。
