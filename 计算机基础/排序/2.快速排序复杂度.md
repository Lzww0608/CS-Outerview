# 2. 快速排序复杂度

## 1. 快速排序是什么

快速排序是一种分治排序算法：

1. 选择一个 pivot。
2. 把数组划分为小于 pivot 和大于 pivot 的两部分。
3. 递归排序左右两部分。

它是原地比较排序，工程中常作为通用排序算法的基础之一。

## 2. 时间复杂度

| 情况 | 复杂度 | 原因 |
| --- | --- | --- |
| 最好 | `O(n log n)` | 每次划分都接近均分 |
| 平均 | `O(n log n)` | 随机输入或随机 pivot 下期望递归深度为 `log n` |
| 最坏 | `O(n^2)` | 每次 pivot 都选到最小或最大，递归退化成链 |

如果每层划分都要扫描当前区间，单层总成本是 `O(n)`。递归深度接近 `log n` 时，总成本是 `O(n log n)`；递归深度退化为 `n` 时，总成本变成 `O(n^2)`。

## 3. 空间复杂度

快速排序主要空间来自递归栈：

1. 平均空间复杂度：`O(log n)`。
2. 最坏空间复杂度：`O(n)`。

如果每次优先递归较小区间、较大区间用循环处理，可以把栈深度控制到 `O(log n)`。

## 4. 如何降低最坏情况风险

1. **随机选择 pivot**：避免有序输入触发固定 pivot 的最坏情况。
2. **三数取中**：从左、中、右选中位数作为 pivot。
3. **三路快排**：对重复元素多的数组，把 `< pivot`、`== pivot`、`> pivot` 分开。
4. **小数组切插入排序**：小区间上插入排序常数更小。
5. **内省排序 introsort**：递归深度过大时切换到堆排序，保证最坏 `O(n log n)`，C++ `std::sort` 常用这种思路。

## 5. 易错点

1. 快排不是稳定排序，普通原地 partition 会改变相等元素相对顺序。
2. 快排平均很快，但最坏可能 `O(n^2)`。
3. 重复元素特别多时，普通二路 partition 可能退化，三路快排更稳。
4. `std::sort` 不是纯快排，通常是内省排序，会规避快排最坏复杂度。

## 6. 面试回答模板

快排平均和最好时间复杂度是 `O(n log n)`，因为每层 partition 总共扫 `n` 个元素，递归深度平均是 `log n`；最坏是 `O(n^2)`，例如每次 pivot 都选到最小或最大，递归深度退化为 `n`。空间复杂度平均 `O(log n)`，最坏 `O(n)`，来自递归栈。工程上会用随机 pivot、三数取中、三路快排、小数组插入排序和内省排序来降低退化风险。
