# 隐私保护下计算平均薪资

## 1. 问题背景

在保护隐私的前提下，多方协作计算aggregate统计量（如平均值）是密码学和分布式计算中的经典问题。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  问题定义：                                                 │
│                                                             │
│  • 10 名员工各自持有自己的薪资                               │
│  • 员工之间不能透露各自的薪资                                │
│  • 需要计算出所有人的平均薪资                               │
│                                                             │
│  核心挑战：                                                 │
│  • 数据隐私性：不能暴露个人薪资                              │
│  • 计算正确性：结果必须正确                                 │
│  • 抗恶意攻击：防止作弊                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 直接相加暴露隐私 | 求和后每人知道总数 |
| 轮流传递泄露 | 传递过程中可能窥探 |
| 中心节点风险 | 第三方知道所有数据 |

## 5. 解决方案

### 5.1 方案一：加法同态加密

```python
"""
方案：使用加法同态加密实现隐私保护求和
假设使用 Paillier 加密方案
"""

class PaillierCryptosystem:
    """
    Paillier 加密系统（加法同态）
    """
    
    def __init__(self, p, q):
        # 生成密钥
        n = p * q
        lambda_n = (p - 1) * (q - 1)
        g = n + 1
        # 简化版，实际需要更多参数
        self.public_key = (n, g)
        self.private_key = lambda_n
    
    def encrypt(self, m, pub_key):
        n, g = pub_key
        r = random.randrange(1, n)
        n_sq = n * n
        c = pow(g, m, n_sq) * pow(r, n, n_sq) % n_sq
        return c
    
    def add_encrypted(self, c1, c2, pub_key):
        """同态加法：E(m1) + E(m2) = E(m1 + m2)"""
        n, _ = pub_key
        n_sq = n * n
        return c1 * c2 % n_sq

def secure_average_paillier(salaries, public_key):
    """
    使用 Paillier 加密计算平均薪资
    """
    # 1. 每人对自己的薪资加密
    encrypted_salaries = [encrypt(s, public_key) for s in salaries]
    
    # 2. 所有人计算加密值的乘积（同态加法）
    encrypted_sum = 1
    for c in encrypted_salaries:
        encrypted_sum = encrypted_sum * c % (public_key[0] ** 2)
    
    # 3. 解密得到总和
    total = decrypt(encrypted_sum, private_key)
    
    # 4. 计算平均值
    return total / len(salaries)
```

### 5.2 方案二：秘密共享（推荐）

```python
"""
方案：使用 Shamir 秘密共享实现隐私保护求和
"""

from typing import List, Tuple
import random

class SecretSharingAverage:
    """
    基于秘密共享的安全平均计算
    """
    
    def __init__(self, threshold=3, participants=10):
        self.threshold = threshold  # 恢复秘密需要的份额数
        self.n = participants       # 参与者数量
    
    def share(self, secret: int) -> List[int]:
        """
        将秘密分割成 n 份
        
        使用 Shamir 秘密共享：
        f(x) = secret + a1*x + a2*x^2 + ... + a_{t-1}*x^{t-1}
        每个人得到 f(i)，i=1,...,n
        
        任意 t 个人可以恢复秘密
        """
        coeffs = [secret] + [random.randint(1, 10000) for _ in range(self.threshold - 1)]
        shares = []
        
        for x in range(1, self.n + 1):
            y = sum(coeff * (x ** i) for i, coeff in enumerate(coeffs))
            shares.append((x, y))
        
        return shares
    
    def combine(self, shares: List[Tuple[int, int]]) -> int:
        """
        恢复秘密（拉格朗日插值）
        """
        if len(shares) < self.threshold:
            raise ValueError("shares 不足，无法恢复秘密")
        
        secret = 0
        for i, (xi, yi) in enumerate(shares[:self.threshold]):
            # 拉格朗日基多项式在 x=0 处的值
            numerator = 1
            denominator = 1
            for j, (xj, _) in enumerate(shares[:self.threshold]):
                if i != j:
                    numerator *= -xj
                    denominator *= xi - xj
            li = numerator // denominator
            secret += yi * li
        
        return secret % 10001  # 取模

def secure_average_shares(salaries):
    """
    使用秘密共享计算平均薪资
    """
    calculator = SecretSharingAverage(threshold=3, participants=10)
    
    # 1. 每人将自己的薪资分成 10 份，分发给其他人
    all_shares = []
    for salary in salaries:
        shares = calculator.share(salary)
        all_shares.append(shares)
    
    # 2. 每人收集其他人的一份，计算总和
    # 每个人收集的份额来自不同人的同一位置
    collected_sum_shares = []
    for i in range(10):  # 每人收集第 i 份
        total = sum(shares[i][1] for shares in all_shares)
        collected_sum_shares.append((i + 1, total))
    
    # 3. 任意 3 人合作可以恢复总和
    total_salary = calculator.combine(collected_sum_shares[:3])
    
    # 4. 计算平均值
    return total_salary / len(salaries)
```

## 7. 推荐方案

### 7.1 实用方案：随机扰动

```python
"""
实用方案：添加随机扰动 + 中心聚合
适用于信任部分参与者的情况
"""

def practical_secure_average(salaries):
    """
    实用安全平均算法
    
    步骤：
    1. 每人生成随机数 Ri
    2. 每人计算 Si = salary_i + Ri
    3. 每人计算 Zi = Si - R_{i-1}（去掉前一个人的随机数）
    4. 中心节点收集所有 Zi
    5. 总和 = sum(Zi) + R_last
    
    原理：中心节点只知道总和，不知道每个人的薪资
    """
    n = len(salaries)
    random_values = [random.randint(-10000, 10000) for _ in range(n)]
    
    # 每人计算扰动后的值
    perturbed_values = []
    for i in range(n):
        Si = salaries[i] + random_values[i]
        Zi = Si - random_values[i - 1]  # 循环，去掉前一个人的随机数
        perturbed_values.append(Zi)
    
    # 中心节点计算
    total = sum(perturbed_values)
    
    # 恢复真实总和
    real_total = total + random_values[-1]
    
    return real_total / n
```

## 11. 总结

1. **核心问题**：如何在不暴露个人数据的情况下计算 aggregate 结果
2. **技术方案**：加法同态加密（Paillier）、秘密共享（Shamir）、混淆电路（Garbled Circuits）
3. **实用方案**：随机扰动 + 中心聚合，平衡安全性和实用性
4. **安全考虑**：防止串通攻击、恶意输入、随机数泄露
5. **选型建议**：高安全用密码学方案，实用场景用随机扰动方案
