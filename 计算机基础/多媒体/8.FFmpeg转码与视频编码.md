# 8. FFmpeg 转码与视频编码

FFmpeg 转码是把输入媒体从一种封装、编码、码率、分辨率或像素格式转换成另一种形式。面试里问“FFmpeg 转码算法”和“视频编码格式特点”，重点是讲清楚媒体处理链路和编码参数的取舍。

## 1. 转码基本链路

完整转码通常包括：

```text
demux 解封装
-> decode 解码
-> filter 处理
-> encode 编码
-> mux 封装
```

解释：

1. **解封装 demux**：从 MP4、FLV、MKV 等容器中取出音视频 packet。
2. **解码 decode**：把 H.264/H.265/AAC 等压缩数据解成原始帧，例如 YUV 或 PCM。
3. **滤镜 filter**：缩放、裁剪、水印、转像素格式、调帧率、降噪。
4. **编码 encode**：把原始帧重新压缩成目标编码格式。
5. **封装 mux**：把编码后的 packet 写入目标容器。

如果只是换容器、不改编码，可以 stream copy：

```bash
ffmpeg -i in.mkv -c copy out.mp4
```

这不重新编码，速度快、画质无损，但要求目标容器支持原编码流。

## 2. H.264 的核心特点

H.264/AVC 是常见视频编码格式，核心目标是在可接受复杂度下提高压缩率。

关键概念：

1. **帧内预测**：利用当前帧邻近像素预测块内容。
2. **帧间预测**：利用前后参考帧做运动估计和运动补偿。
3. **I/P/B 帧**：I 帧独立解码，P 帧参考过去帧，B 帧可参考前后帧。
4. **GOP**：两个关键帧之间的一组帧，GOP 越长压缩率通常越好，但随机访问和错误恢复变差。
5. **码率控制**：CBR、VBR、CRF 等模式在画质、体积和稳定带宽之间取舍。
6. **Profile/Level**：约束编码工具集合和解码能力，例如 Baseline、Main、High。
7. **YUV 4:2:0**：常见像素格式，色度降采样降低体积。

## 3. 常见转码参数

```bash
ffmpeg -i input.mp4 \
  -vf scale=1280:-2 \
  -c:v libx264 -preset medium -crf 23 \
  -c:a aac -b:a 128k \
  output.mp4
```

含义：

1. `scale=1280:-2`：宽度设为 1280，高度按比例并对齐到偶数。
2. `libx264`：使用 x264 编码 H.264。
3. `preset`：编码速度和压缩效率取舍，越慢通常压缩率越好。
4. `crf`：恒定质量模式，数值越小质量越高、文件越大。
5. `aac`：音频编码为 AAC。
6. `-b:a 128k`：音频码率。

## 4. 时间戳和音画同步

转码不是简单逐帧处理，还要处理时间戳：

1. `PTS` 表示展示时间。
2. `DTS` 表示解码时间。
3. B 帧会导致解码顺序和展示顺序不同。
4. 变帧率输入转恒定帧率时，要补帧、丢帧或调整时间戳。
5. 音频和视频要以共同时间基对齐，否则会出现音画不同步。

## 5. 真实场景取舍

1. **短视频上传**：转成统一分辨率、码率、封装和编码，便于播放端兼容。
2. **点播多码率**：生成 360p、720p、1080p 多档清晰度，配合 HLS/DASH 自适应码率。
3. **低延迟直播**：GOP 不能太长，B 帧可能减少或关闭，优先降低端到端延迟。
4. **存储成本优先**：使用更慢 preset、更高压缩率编码，或者选 H.265/AV1，但要考虑解码兼容性。
5. **移动端兼容**：H.264 + AAC + MP4/HLS 通常兼容性更稳。

## 6. 易错点

1. 容器格式和编码格式不是一回事，MP4 是容器，H.264 是视频编码。
2. 转封装不等于转码，`-c copy` 不会重新编码。
3. 降低分辨率不一定显著降低体积，码率控制才直接影响体积。
4. GOP 太长会影响拖动和错误恢复，太短会降低压缩率。
5. B 帧能提高压缩率，但会增加延迟和时间戳处理复杂度。

## 7. 面试回答模板

FFmpeg 转码链路通常是解封装、解码、滤镜处理、编码、再封装。比如输入 MP4 里是 H.264/AAC，先 demux 出 packet，decode 成 YUV/PCM，经过 scale、水印、像素格式转换等 filter，再用 x264/AAC 编码，最后 mux 成目标 MP4 或 HLS。H.264 的特点是帧内预测、帧间预测、I/P/B 帧、GOP 和码率控制，压缩率和随机访问、延迟、兼容性之间要取舍。真实项目里会根据上传、点播、直播或移动端兼容选择分辨率、码率、GOP、preset 和封装格式。
