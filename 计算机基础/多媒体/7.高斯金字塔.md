# 7. 高斯金字塔

高斯金字塔是图像多尺度表示方法。它通过反复对图像做高斯模糊和下采样，得到一组分辨率逐层降低的图像，用来在不同尺度上分析图像结构。

## 1. 核心过程

从原图 `G0` 开始：

```text
G0: 原始图像
G1: GaussianBlur(G0) 后下采样
G2: GaussianBlur(G1) 后下采样
...
```

每一层通常先用高斯核低通滤波，再隔行隔列下采样。先模糊再下采样的原因是避免高频信息在采样时产生混叠。

## 2. 为什么要用高斯滤波

图像下采样会降低采样率。如果直接丢掉像素，高频纹理可能折叠成错误的低频信号，表现为锯齿、闪烁或伪纹理。高斯滤波相当于低通滤波，先削弱高频，再下采样，结果更稳定。

## 3. 和拉普拉斯金字塔的关系

拉普拉斯金字塔保存的是相邻高斯层之间的差值：

```text
L_i = G_i - Expand(G_{i+1})
```

它更强调细节残差，常用于图像融合、压缩、增强和多尺度重建。高斯金字塔保存低频多尺度图，拉普拉斯金字塔保存各尺度细节。

## 4. 应用场景

1. **目标检测和图像匹配**：不同尺寸目标在不同尺度上更容易匹配。
2. **SIFT/特征提取**：多尺度空间用于寻找尺度不变关键点。
3. **图像融合**：多分辨率融合可以减少拼接边界突兀。
4. **视频分析**：场景切换、运动估计、缩略图生成可先在低分辨率层快速判断。
5. **计算加速**：先在低分辨率粗定位，再回到高分辨率精修。

## 5. 易错点

1. 高斯金字塔不是简单 resize，关键是下采样前要低通滤波。
2. 层数不是越多越好，过多层会丢失语义细节。
3. 高斯核大小和 sigma 会影响平滑程度，过强会抹掉边缘。
4. 不同库的边界填充方式不同，结果可能有细微差异。

## 6. 面试回答模板

高斯金字塔是图像的多尺度表示。每一层由上一层先做高斯模糊，再下采样得到。高斯模糊的作用是低通滤波，减少下采样造成的混叠。它常用于目标检测、图像匹配、SIFT 特征、多尺度融合和视频分析。与高斯金字塔保存低频尺度图不同，拉普拉斯金字塔保存相邻尺度之间的细节残差，适合图像融合和重建。
