# PNG 与 PNG-8

PNG（Portable Network Graphics）是一种无损图像格式，常用于图标、截图、透明背景图片和需要清晰边缘的 Web 图像。PNG-8 是 PNG 的一种调色板模式，最多使用 256 种颜色。

## PNG 是否有损

标准 PNG 压缩本身是无损的。它不会像 JPEG 那样通过丢弃高频信息换取压缩率，而是使用预测滤波 + DEFLATE 熵编码压缩像素数据。

PNG 编码大致流程：

1. 按行扫描像素。
2. 对每行选择滤波器，记录当前像素和左/上/左上像素的差值。
3. 对滤波后的字节流使用 DEFLATE 压缩。
4. 写入 PNG chunk，例如 `IHDR`、`PLTE`、`IDAT`、`IEND`。

## PNG-8 是什么

PNG-8 使用调色板（Palette）表示图像：

1. 图像最多有 256 个颜色索引。
2. 每个像素存储的是调色板下标，而不是完整 RGB/RGBA。
3. 可以通过 `PLTE` chunk 存储调色板。
4. 透明度可以通过 `tRNS` chunk 或调色板透明项表达。

如果原图本来颜色数不超过 256，转换成 PNG-8 可以是无损的；如果原图颜色很多，需要先做颜色量化，把大量颜色映射到 256 色，这个“量化步骤”是有损的，但 PNG-8 后续压缩仍是无损编码索引。

## PNG-8 如何实现

典型流程：

1. **颜色统计**：统计图片中的颜色分布。
2. **颜色量化**：用中位切分、八叉树、K-means 等算法选出最多 256 个代表色。
3. **像素映射**：把每个像素映射到最近的调色板颜色。
4. **抖动 Dithering**：可选，用 Floyd-Steinberg 等误差扩散降低色带感。
5. **索引编码**：存储像素索引，再用 PNG 的滤波和 DEFLATE 压缩。

## PNG 和 JPEG 对比

| 对比项 | PNG | JPEG |
| --- | --- | --- |
| 压缩类型 | 无损 | 有损 |
| 透明通道 | 支持 alpha | 通常不支持透明 |
| 适合内容 | 图标、截图、文字、线条、透明图 | 自然照片 |
| 压缩方式 | 滤波 + DEFLATE | DCT + 量化 + 熵编码 |
| 边缘质量 | 清晰 | 可能有块效应和振铃 |

## 易错点

1. PNG 是无损格式，但 PNG-8 的颜色量化可能让转换过程有损。
2. PNG-8 不等于一定更小，颜色复杂照片可能量化差且压缩收益有限。
3. PNG 支持 alpha，PNG-8 也可以支持简单透明或调色板透明。
4. 截图和 UI 图用 JPEG 容易出现文字边缘损伤，PNG 更合适。

## 面试回答模板

PNG 本身是无损压缩，核心是行滤波加 DEFLATE。PNG-8 是调色板模式，每个像素存 0 到 255 的颜色索引。如果原图颜色不超过 256，转 PNG-8 可以无损；如果原图颜色更多，需要颜色量化到 256 色，这个量化过程是有损的。PNG 适合图标、截图、透明图和文字线条，JPEG 更适合自然照片。
