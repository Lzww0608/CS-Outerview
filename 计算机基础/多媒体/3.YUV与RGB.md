# YUV 与 RGB

RGB 按红、绿、蓝三个颜色通道表示图像，适合显示设备；YUV 把亮度和色度分离，更适合视频采集、压缩、传输和播放。

## YUV 是什么

YUV 通常包含：

1. **Y**：亮度 Luma，表示明暗信息。
2. **U/V**：色度 Chroma，表示颜色差异信息。

人眼对亮度更敏感，对色度相对不敏感。视频系统利用这个特性，对色度做降采样，可以显著降低带宽，同时主观质量损失较小。

## 为什么视频传输常用 YUV 不用 RGB

1. **更适合压缩**：亮度和色度分离后，可以对色度降采样，例如 YUV420。
2. **带宽更低**：RGB 每个像素通常 24 bit；YUV420 平均每像素 12 bit，理论上约省一半。
3. **符合人眼感知**：人眼对亮度细节敏感，对颜色分辨率不那么敏感。
4. **视频编码标准适配**：H.264/H.265/AV1/VP9 等常见编码器内部主要处理 YUV。
5. **历史和设备链路**：摄像头、硬件编解码器、播放器、显示管线普遍支持 YUV 格式。

## 常见采样格式

| 格式 | 含义 | 平均每像素 |
| --- | --- | --- |
| YUV444 | 亮度和色度都不降采样 | 24 bit |
| YUV422 | 水平方向两个像素共享一组 UV | 16 bit |
| YUV420 | 2x2 像素共享一组 UV | 12 bit |

YUV420 是视频最常见格式之一，适合大多数自然视频内容。

## 常见存储布局

1. **Planar**：Y、U、V 三个平面分开存，例如 I420/YV12。
2. **Semi-planar**：Y 单独存，UV 交错存，例如 NV12/NV21。
3. **Packed**：YUV 交错存，例如 YUYV。

工程中要特别注意 UV 顺序和 stride，否则画面会偏色、花屏或错位。

## RGB 和 YUV 转换

实际转换通常有标准差异，例如 BT.601、BT.709、BT.2020，不同色彩空间系数不同。SD 视频常用 BT.601，HD 常用 BT.709。转换时还要注意 full range / limited range。

## 易错点

1. YUV 不是一种唯一格式，采样和内存布局都要说明。
2. NV12 和 NV21 只差 UV/VU 顺序，但错误使用会明显偏色。
3. YUV420 的 width/height 通常要求偶数，否则处理边界更复杂。
4. 视频编码用 YUV 不代表最终显示不用 RGB，显示前通常仍要转换或由 GPU 采样转换。

## 面试回答模板

视频传输常用 YUV，是因为 YUV 把亮度和色度分离，人眼对亮度更敏感、对色度不那么敏感，所以可以用 YUV420 等格式对色度降采样，把 24bpp 的 RGB 降到约 12bpp，同时主观质量损失较小。H.264/H.265/AV1 等编码器和硬件链路也主要围绕 YUV 设计。工程上要注意 YUV444/422/420、I420/NV12/NV21、stride、色彩空间和 full/limited range。
