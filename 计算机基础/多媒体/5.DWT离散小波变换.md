# DWT 离散小波变换

DWT（Discrete Wavelet Transform，离散小波变换）是一种把信号分解到不同尺度和频带上的时频分析方法。它既能表示低频轮廓，也能表示局部高频细节，常用于图像压缩、去噪、特征提取和多分辨率分析。

## 核心思想

傅里叶变换使用全局正弦/余弦基，适合分析整体频率，但局部时间/空间位置表达弱。小波变换使用局部化的小波基，可以同时表达“频率”和“位置”。

DWT 通常通过滤波器组实现：

1. 低通滤波器得到近似信息。
2. 高通滤波器得到细节信息。
3. 下采样减少数据量。
4. 对低频部分继续递归分解，形成多尺度表示。

## 图像二维 DWT

对图像先按行再按列做一维 DWT，可以得到四个子带：

| 子带 | 含义 |
| --- | --- |
| LL | 低频近似，图像主体轮廓 |
| LH | 水平方向低频、垂直方向高频 |
| HL | 水平方向高频、垂直方向低频 |
| HH | 对角高频细节 |

多级 DWT 会继续对 LL 子带分解，得到更粗尺度的图像轮廓和多层细节。

## DWT 和 DCT 对比

| 对比项 | DCT | DWT |
| --- | --- | --- |
| 处理方式 | 常按 8x8 块处理 | 可对整幅图或大块多尺度处理 |
| 局部性 | 频域集中好，但块边界明显 | 多分辨率，空间局部性好 |
| 典型标准 | JPEG | JPEG 2000 |
| 失真形态 | 高压缩下块效应 | 更容易出现模糊或振铃 |
| 实现复杂度 | 较低，硬件成熟 | 更复杂，内存和实现成本更高 |

## 常见小波

1. **Haar 小波**：最简单，计算快，适合教学和快速特征。
2. **Daubechies 小波**：紧支撑、正交，常用于压缩和分析。
3. **Biorthogonal 小波**：JPEG 2000 中常见，例如 5/3 可逆整数小波、9/7 有损小波。

## 应用场景

1. **JPEG 2000 图像压缩**：使用小波变换支持更好的渐进传输和 ROI 编码。
2. **图像去噪**：小波域中噪声常表现为小幅高频系数，可阈值抑制。
3. **特征提取**：纹理、边缘、多尺度结构分析。
4. **视频和医学图像处理**：多尺度表示利于压缩和分析。

## 易错点

1. DWT 不是只做频域分析，它强调时频/空频局部化。
2. DWT 不天然有损，有损通常来自量化和阈值处理。
3. 多级分解一般继续分解 LL 子带，而不是所有子带都递归。
4. JPEG 2000 使用 DWT，不代表传统 JPEG 也使用 DWT。

## 面试回答模板

DWT 是离散小波变换，通过低通/高通滤波和下采样把信号分解成不同尺度的低频近似和高频细节。二维图像 DWT 会得到 LL、LH、HL、HH 四个子带，并可继续分解 LL 做多分辨率表示。相比 DCT，DWT 不局限于 8x8 块，空间局部性和多尺度表达更好，典型应用是 JPEG 2000、图像去噪和纹理特征提取；有损主要来自量化或阈值，不是变换本身。
