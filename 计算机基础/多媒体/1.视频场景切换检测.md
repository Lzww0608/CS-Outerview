# 视频场景切换检测

视频场景切换检测（Scene Change Detection）用于判断相邻帧是否发生镜头切换、场景突变或渐变转场。它常用于视频摘要、关键帧提取、广告切分、转码 GOP 切分、内容审核和检索。

## 常见类型

1. **硬切 Hard Cut**：相邻两帧内容突然变化。
2. **淡入淡出 Fade**：亮度逐渐变亮或变暗。
3. **溶解 Dissolve**：一个场景逐渐叠加到另一个场景。
4. **快速运动/闪光**：不是场景切换，但可能造成误判。

## 基础检测方法

### 1. 像素差分

计算相邻帧像素差：

```text
score = mean(abs(frame_t - frame_{t-1}))
```

分数超过阈值判定为切换。优点是简单，缺点是对运动、闪光、噪声敏感。

### 2. 直方图差异

把帧转到 HSV/YUV，统计颜色或亮度直方图，再比较相邻帧直方图距离：

1. L1/L2 距离。
2. 卡方距离。
3. Bhattacharyya 距离。
4. 直方图交集。

直方图对局部运动更鲁棒，因为它忽略空间位置，但对大面积光照变化仍敏感。

### 3. 边缘或结构差异

先提取边缘、纹理或局部特征，再比较结构变化。相比像素差分，它对亮度变化更稳，但计算更重。

### 4. 编码域特征

如果已经有压缩视频，可以利用编码器信息：

1. I/P/B 帧类型变化。
2. 运动向量分布突变。
3. 残差能量增大。
4. 编码器 scene-cut 分数。

这种方法适合转码和流媒体处理，避免完全解码后再做重计算。

### 5. 深度学习方法

用 CNN/Transformer/双流网络对帧对或短片段分类，判断是否发生镜头边界。效果更好，但需要标注数据、模型推理成本和延迟预算。

## 工程实现流程

1. 抽帧或解码关键帧附近帧。
2. 缩放到较小分辨率，降低计算量。
3. 转换到 YUV/HSV，优先使用亮度或颜色直方图。
4. 计算相邻帧差异分数。
5. 做滑动平均、阈值自适应和非极大值抑制，减少重复检测。
6. 对候选点再用更重特征或模型复核。

## 易错点

1. 镜头内快速运动不一定是场景切换。
2. 闪光、爆炸、字幕、全屏转场会干扰像素差分。
3. 固定阈值跨视频泛化差，最好结合局部统计自适应。
4. 实时流检测要关注延迟，不能依赖太长的未来窗口。
5. 转码场景中，scene cut 检测会影响 GOP 切分和码率控制。

## 面试回答模板

检测视频场景切换可以从简单到复杂回答：最简单是相邻帧像素差，超过阈值判定 hard cut；更稳的是在 HSV/YUV 上做颜色或亮度直方图比较，减少局部运动影响；再进一步可以结合边缘、运动向量、残差能量等编码域特征；高精度场景可以用深度模型做帧对分类。工程上要处理快速运动、闪光、渐变转场和阈值自适应，实时流还要控制延迟和计算量。
