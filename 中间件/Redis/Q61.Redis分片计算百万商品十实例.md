# Redis 分片计算：百万商品十实例分布

## 1. 问题背景

在 Redis 分布式架构中，当单机 Redis 无法承载所有数据时，需要进行分片（Sharding）。本文分析百万商品在 10 个 Redis 实例间的分布策略。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  问题设定：                                                │
│                                                             │
│  • 商品数量：100 万                                        │
│  • Redis 实例：10 台                                      │
│  • 每台实例分配：100,000 商品                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 | 影响 |
|------|------|------|
| 热点数据 | 热门商品访问量大 | 单实例压力大 |
| 数据倾斜 | 商品分布不均 | 部分实例过载 |
| 扩缩容 | 增加实例时数据重分布 | 迁移成本高 |
| 路由一致 | 访问能正确路由到实例 | 数据一致性 |

## 4. 原因分析

### 4.1 分片计算

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  基础计算：                                                │
│                                                             │
│  商品总数：1,000,000                                      │
│  Redis 实例：10                                            │
│  每台实例商品数：1,000,000 / 10 = 100,000              │
│                                                             │
│  Redis Cluster 分片：                                     │
│  • 16384 个哈希槽                                         │
│  • 10 台实例，每台约 1638 个槽                          │
│  • 1,000,000 / 16384 ≈ 61 个槽/万商品               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 分片原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  哈希槽分片流程：                                          │
│                                                             │
│  1. 计算商品 key 的哈希值                                │
│     CRC16(key) % 16384 = 哈希槽                          │
│                                                             │
│  2. 槽映射到实例                                          │
│     hash_slot → instance_id                               │
│                                                             │
│  3. 实例处理请求                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 客户端路由实现

```python
# Python 客户端实现
import redis
from redis.cluster import RedisCluster

class ProductShard:
    def __init__(self, nodes):
        self.rc = RedisCluster(
            startup_nodes=nodes,
            decode_responses=True
        )
    
    def get_product(self, product_id):
        """获取商品"""
        key = f"product:{product_id}"
        return self.rc.get(key)
    
    def set_product(self, product_id, data):
        """设置商品"""
        key = f"product:{product_id}"
        return self.rc.set(key, data)
    
    def get_slot(self, key):
        """计算槽位"""
        # Redis Cluster 使用 CRC16
        slot = self._crc16(key) % 16384
        return slot
    
    @staticmethod
    def _crc16(key: str) -> int:
        """CRC16 校验"""
        crc = 0
        for char in key:
            crc = (crc >> 8) ^ crc16_table[(crc ^ ord(char)) & 0xFF]
        return crc
```

### 5.3 哈希标签

```python
# 使用哈希标签确保相关数据在同一槽

# 假设：同一商家的所有商品需要在一起

# key 格式：{shop_id}:product:{product_id}
rc.set("{123}:product:1001", "商品1数据")
rc.set("{123}:product:1002", "商品2数据")

# shop_id=123 的商品会在同一槽

# 路由示例：
# CRC16("{123}:product:1001") % 16384 = 5462
# CRC16("{123}:product:1002") % 16384 = 5462  # 同一槽
```

```python
from redis.cluster import RedisCluster

# 配置
nodes = [
    {"host": "192.168.1.1", "port": 6379},
    {"host": "192.168.1.2", "port": 6379},
    # ... 10 台
]

rc = RedisCluster(
    startup_nodes=nodes,
    decode_responses=True,
    max_connections_per_node=100
)

# 验证分片
for i in range(10):
    key = f"product:{i}"
    slot = rc.get_node(key).get_slot(key)
    print(f"{key} -> slot {slot}")
```

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 数据倾斜 | 部分实例过载 | 预分片，虚拟节点 |
| 扩缩容 | 槽迁移 | 使用代理，无感知 |
| 热点 key | 单槽压力大 | 本地缓存，复制 |
| 跨槽操作 | MGET/MSET 不支持 | 客户端聚合 |

## 10. 验证方式

```python
# 验证数据分布
def verify_distribution(rc, total_products=1000000):
    slot_counts = {}
    
    for i in range(total_products):
        key = f"product:{i}"
        slot = rc.get_slot(key)
        slot_counts[slot] = slot_counts.get(slot, 0) + 1
    
    # 统计每个实例
    instance_counts = {}
    for slot, count in slot_counts.items():
        node = rc.get_node_from_slot(slot)
        host = f"{node.host}:{node.port}"
        instance_counts[host] = instance_counts.get(host, 0) + count
    
    # 验证均衡
    avg = total_products / 10
    for host, count in instance_counts.items():
        print(f"{host}: {count} (avg: {avg}, diff: {abs(count-avg)/avg*100:.2f}%)")
```

## 11. 总结

1. **每台实例商品数**：1,000,000 / 10 = 100,000 商品
2. **Redis Cluster 分片**：16384 槽 / 10 ≈ 1638 槽/实例
3. **分片原理**：CRC16(key) % 16384 确定槽位
4. **推荐方案**：Redis Cluster 原生分片
5. **注意事项**：数据倾斜、热点 key、扩缩容成本
