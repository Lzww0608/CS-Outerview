# 端口占用排查

排查端口占用时，核心是确认四件事：端口是否处于监听状态、由哪个进程持有、连接处于什么 TCP 状态，以及是否存在容器或代理转发。

## 1. ss

`ss` 是 Linux 上优先使用的网络连接查看工具：

```bash
ss -lntup
ss -lntup '( sport = :8080 )'
ss -antp | grep ':8080'
```

常用参数：

1. `-l`：只看监听 socket。
2. `-n`：不做 DNS 和服务名解析，速度更快。
3. `-t`：TCP。
4. `-u`：UDP。
5. `-p`：显示进程信息，需要足够权限。

`LISTEN` 表示服务正在监听端口；`ESTABLISHED` 表示已有连接；`TIME-WAIT`、`CLOSE-WAIT` 等状态用于判断连接关闭阶段是否异常。

## 2. lsof

如果想从文件描述符角度看端口：

```bash
lsof -iTCP:8080 -sTCP:LISTEN
lsof -i :8080
```

输出里的 `PID`、`COMMAND` 可以定位进程，再配合：

```bash
ps -fp <pid>
readlink /proc/<pid>/exe
ls -l /proc/<pid>/fd
```

确认进程路径和 fd。

## 3. netstat 和 fuser

老系统可能没有 `ss`，可以用：

```bash
netstat -tulnp | grep ':8080'
```

如果只想快速找占用端口的 PID：

```bash
fuser -n tcp 8080
```

不要在不确认进程用途的情况下直接 `kill`，生产环境需要先确认服务归属、启动方式和是否有守护进程自动拉起。

## 4. 容器和代理场景

如果端口来自 Docker、Kubernetes、Nginx、Envoy 等组件，需要继续确认：

1. 宿主机端口是否由代理进程监听。
2. 容器内进程监听的是哪个端口。
3. iptables、IPVS、eBPF 或负载均衡规则是否做了转发。
4. IPv4 和 IPv6 是否分别监听，例如 `0.0.0.0:8080` 与 `[::]:8080`。

## 5. 面试回答模板

Linux 查端口占用我会先用 `ss -lntup` 看监听端口和进程，再用 `lsof -i :端口` 从 fd 角度确认 PID、命令和可执行文件路径。老系统可以用 `netstat -tulnp`，快速查 PID 可以用 `fuser -n tcp 端口`。如果是容器或网关场景，还要继续看代理进程、容器端口映射和 iptables/IPVS/eBPF 转发规则。
