# 5. awk 文本处理

`awk` 是 Linux 下常用的文本处理工具，适合按行读取、按列切分、过滤、统计和格式化输出。面试里如果被问“Shell 脚本和 awk 用过吗”，重点是说清楚它的执行模型、字段变量和真实排查场景。

## 1. awk 的执行模型

基本结构：

```bash
awk 'BEGIN { 初始化 } pattern { action } END { 汇总 }' file
```

执行流程：

1. `BEGIN` 在读取文件前执行一次，常用于初始化变量、打印表头。
2. 对输入逐行处理，每行会被切成字段。
3. `pattern` 为真时执行对应 `action`。
4. `END` 在所有输入处理完后执行一次，常用于输出统计结果。

## 2. 常用内置变量

| 变量 | 含义 |
| --- | --- |
| `$0` | 当前整行 |
| `$1`、`$2` | 第 1、2 个字段 |
| `NF` | 当前行字段数 |
| `NR` | 已读取总行号 |
| `FNR` | 当前文件内行号 |
| `FS` | 输入分隔符 |
| `OFS` | 输出分隔符 |

默认分隔符是空白字符。可以用 `-F` 指定：

```bash
awk -F',' '{print $1, $3}' data.csv
```

## 3. 常见用法

### 3.1 按列过滤

筛选状态码为 500 的访问日志：

```bash
awk '$9 == 500 {print $0}' access.log
```

如果日志格式是：

```text
ip - - [time] "GET /api HTTP/1.1" 500 123
```

`$9` 通常是 HTTP 状态码。

### 3.2 分组统计

统计每个 IP 的请求次数：

```bash
awk '{cnt[$1]++} END {for (ip in cnt) print ip, cnt[ip]}' access.log
```

按状态码统计：

```bash
awk '{cnt[$9]++} END {for (code in cnt) print code, cnt[code]}' access.log
```

### 3.3 求和和平均值

统计第 10 列响应体大小总和：

```bash
awk '{sum += $10} END {print sum}' access.log
```

计算平均耗时：

```bash
awk '{sum += $NF; n++} END {if (n > 0) print sum / n}' latency.log
```

### 3.4 配合 sort 查看 TopN

统计访问最多的 10 个 IP：

```bash
awk '{cnt[$1]++} END {for (ip in cnt) print cnt[ip], ip}' access.log | sort -nr | head -10
```

这里 `awk` 做聚合，`sort` 做排序，`head` 截取 TopN。

## 4. 真实场景

1. 分析 Nginx 访问日志，找 5xx 数量最多的接口或 IP。
2. 从应用日志中提取 trace id、错误码和耗时，做临时统计。
3. 处理 CSV/TSV 文件，按字段过滤和汇总。
4. 排查线上问题时快速估算错误率、P99 原始样本、流量分布。

如果是长期、复杂、结构化的数据分析，应该进入日志平台、ClickHouse、Python/Pandas 或 Spark；`awk` 更适合临时排查和轻量脚本。

## 5. 易错点

1. `awk` 默认按空白分隔，遇到带空格的字段要确认日志格式。
2. shell 变量传给 awk 应使用 `-v name="$value"`，不要直接拼字符串。
3. `for (k in arr)` 遍历顺序不保证有序，需要排序时交给 `sort`。
4. 大文件聚合时，关联数组会占用内存，key 很多时要注意机器资源。
5. 复杂正则和引号嵌套容易写错，脚本化时要加测试样例。

## 6. 面试回答模板

`awk` 适合按行按列处理文本，结构是 `BEGIN/pattern/action/END`。它默认按空白切字段，`$0` 是整行，`$1` 是第一列，`NF` 是字段数，`NR` 是行号，`-F` 可以指定分隔符。我常用它分析日志，例如按状态码过滤、按 IP 统计请求数、对耗时列求平均，再配合 `sort/head` 找 TopN。需要注意默认分隔符、数组无序、shell 变量传入和大文件聚合的内存占用。
