# Linux 环境变量配置与常见问题

## 1. 问题背景

Linux 环境变量是操作系统和应用程序正常运行的基础配置。环境变量分为系统级和用户级，不同变量控制着程序查找路径、语言设置、终端行为等核心功能。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Linux 环境变量分层架构：                                   │
│                                                             │
│  系统级（/etc/environment, /etc/profile）                  │
│      ↓                                                     │
│  用户级（~/.bashrc, ~/.bash_profile, ~/.profile）          │
│      ↓                                                     │
│  会话级（当前终端 session）                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 | 示例 |
|------|------|------|
| 命令找不到 | `command not found` | `$JAVA_HOME/bin` 未配置 |
| 库文件加载失败 | `error while loading shared libraries` | `LD_LIBRARY_PATH` 缺失 |
| 语言乱码 | 中文显示为方块 | `LANG` 未设置 |
| 权限不足 | `Permission denied` | `LD_PRELOAD` 被禁用 |
| 配置不生效 | 修改后需要重新登录 | 仅修改了 `/etc/profile` |

## 4. 原因分析

### 4.1 环境变量加载顺序

```bash
# Linux 环境变量加载顺序（按优先级从低到高）

# 1. 系统级（所有用户）
/etc/environment          # 登录时加载，纯 key=value
/etc/profile              # 登录 shell 执行
/etc/profile.d/*.sh       # profile.d 目录下脚本

# 2. 用户级
~/.bash_profile           # bash 登录时执行（不存在则读 .bash_login）
~/.bash_login             # bash 登录时执行（如果 .bash_profile 不存在）
~/.profile                # 登录 shell 执行（Ubuntu 默认）
~/.bashrc                 # 交互式非登录 shell 执行

# 3. 会话级
export VAR=value          # 当前 shell 有效
```

### 4.2 常见配置错误

```bash
# 错误示例 1：profile 和 bashrc 混淆
# ~/.bash_profile 中设置（登录时执行一次）
export PATH=$PATH:/opt/java/bin

# 问题：新建非登录 shell 时不生效

# 错误示例 2：变量引用错误
export LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_Path  # 拼写错误

# 错误示例 3：覆盖而非追加
export PATH=/opt/java/bin  # 丢失原有 PATH
```

## 5. 解决方案

### 5.1 系统级环境变量配置

```bash
# /etc/profile.d/custom.sh（推荐方式）
# 创建自定义环境变量脚本

cat > /etc/profile.d/custom.sh << 'EOF'
#!/bin/bash

# Java 环境
export JAVA_HOME=/usr/local/java/jdk1.8.0_301
export JRE_HOME=$JAVA_HOME/jre
export CLASSPATH=.:$JAVA_HOME/lib:$JRE_HOME/lib
export PATH=$JAVA_HOME/bin:$PATH

# Go 环境
export GOROOT=/usr/local/go
export GOPATH=/home/user/go
export PATH=$PATH:$GOROOT/bin:$GOPATH/bin

# 自定义路径
export CUSTOM_HOME=/opt/custom
export PATH=$CUSTOM_HOME/bin:$PATH
EOF

chmod +x /etc/profile.d/custom.sh
source /etc/profile.d/custom.sh
```

### 5.2 用户级环境变量配置

```bash
# ~/.bashrc（交互式非登录 shell）
# 添加以下内容

#alias 定义
alias ll='ls -la'
alias gs='git status'

# 函数定义
function maven() {
    export MAVEN_OPTS="-Xmx512m"
    /opt/maven/bin/mvn "$@"
}

# PATH 追加
export PATH=$PATH:$HOME/.local/bin:$HOME/bin
```

### 5.3 永久生效配置

```bash
# ~/.bash_profile（登录 shell）
# 会读取 .bashrc

if [ -f ~/.bashrc ]; then
    source ~/.bashrc
fi

# 在此添加登录 shell 专属配置
export EDITOR=vim
```

### 5.4 临时环境变量

```bash
# 临时设置（仅当前 session 有效）
export TMP_VAR="temporary_value"

# 单次命令使用
LD_LIBRARY_PATH=/opt/lib ./my_program

# 查看当前所有环境变量
env
printenv
printenv PATH
```

## 6. 可选方案对比

### 6.1 环境变量配置方式对比

| 配置方式 | 作用域 | 持久性 | 生效时机 | 适用场景 |
|----------|--------|--------|----------|----------|
| `/etc/environment` | 全系统 | 永久 | 系统启动 | 系统级基础变量 |
| `/etc/profile.d/*.sh` | 全系统 | 永久 | 登录时 | 业务环境变量 |
| `/etc/profile` | 全系统 | 永久 | 登录时 | 全局初始化 |
| `~/.bashrc` | 当前用户 | 永久 | 非登录 shell | 用户别名、函数 |
| `~/.bash_profile` | 当前用户 | 永久 | 登录时 | 用户环境变量 |
| `export VAR=value` | 当前 session | 临时 | 立即生效 | 测试、调试 |

### 6.2 常用环境变量速查表

| 变量名 | 用途 | 示例 |
|--------|------|------|
| `PATH` | 命令搜索路径 | `/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin` |
| `HOME` | 用户主目录 | `/root`、`/home/user` |
| `USER` | 当前用户名 | `root`、`deploy` |
| `SHELL` | 登录 shell | `/bin/bash` |
| `LANG` | 语言和编码 | `en_US.UTF-8`、`zh_CN.UTF-8` |
| `PWD` | 当前工作目录 | `/home/user/project` |
| `LD_LIBRARY_PATH` | 动态库搜索路径 | `/usr/local/lib` |
| `LD_PRELOAD` | 预加载动态库 | `/opt/custom/libhook.so` |
| `JAVA_HOME` | Java 安装目录 | `/usr/local/java/jdk1.8` |
| `CLASSPATH` | Java 类路径 | `.:/opt/app/lib/*` |
| `PYTHONPATH` | Python 模块路径 | `/opt/custom_modules` |
| `GOPATH` | Go 工作目录 | `/root/go` |
| `GOPROXY` | Go 模块代理 | `https://goproxy.cn,direct` |
| `MAVEN_HOME` | Maven 安装目录 | `/opt/maven` |
| `NODE_ENV` | Node 环境 | `production`、`development` |
| `PS1` | 命令提示符 | `\u@\h:\w\$` |
| `TERM` | 终端类型 | `xterm-256color` |
| `EDITOR` | 默认编辑器 | `vim`、`nano` |

## 7. 推荐方案

### 7.1 生产环境推荐配置

```bash
# 1. 创建 /etc/profile.d/business-env.sh
cat > /etc/profile.d/business-env.sh << 'EOF'
#!/bin/bash
# 业务环境变量配置

# 应用目录
export APP_HOME=/opt/application
export APP_LOG=$APP_HOME/logs
export APP_CONF=$APP_HOME/conf

# 中间件路径
export REDIS_HOME=/usr/local/redis
export KAFKA_HOME=/opt/kafka
export ES_HOME=/opt/elasticsearch

# 应用特定配置
export APP_ENV=production
export APP_DEBUG=false
export APP_PORT=8080

# JVM 参数
export JVM_OPTS="-Xms2g -Xmx2g -XX:+UseG1GC"

# PATH 追加
export PATH=$APP_HOME/bin:$REDIS_HOME/bin:$KAFKA_HOME/bin:$PATH
EOF

# 2. 设置权限
chmod +x /etc/profile.d/business-env.sh

# 3. 验证配置
source /etc/profile.d/business-env.sh
echo $APP_HOME
env | grep APP_
```

## 8. 实施步骤

### 8.1 查看当前环境变量

```bash
# 查看所有环境变量
env

# 查看特定变量
echo $PATH
printenv HOME

# 查看变量定义位置
type -a python    # 查找命令位置
which java        # 查找 java 路径
```

### 8.2 添加新的环境变量

```bash
# 步骤 1：选择配置位置
# 用户级：~/.bashrc
# 系统级：/etc/profile.d/

# 步骤 2：编辑配置文件
vim ~/.bashrc

# 添加以下内容
export MY_VARIABLE="/opt/myapp"
export PATH=$PATH:$MY_VARIABLE/bin

# 步骤 3：使配置生效
source ~/.bashrc        # 当前 session 生效
exec bash               # 新 shell 生效

# 步骤 4：验证
echo $MY_VARIABLE
```

### 8.3 删除环境变量

```bash
# 临时删除（仅当前 session）
unset MY_VARIABLE

# 永久删除：编辑配置文件并删除对应行
vim ~/.bashrc
# 删除 export MY_VARIABLE=...
source ~/.bashrc
```

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| `PATH` 被覆盖 | 系统命令找不到 | 使用 `PATH=$PATH:...` 追加而非覆盖 |
| `LD_LIBRARY_PATH` 冲突 | 程序加载错误库 | 尽量使用 `/etc/ld.so.conf.d/` |
| 登录 shell 阻塞 | 登录缓慢 | 避免在 profile 中执行耗时操作 |
| 环境变量泄露 | 安全风险 | 敏感变量存放在受限文件 |
| 编码不一致 | 乱码 | 统一使用 `UTF-8` 编码 |

## 10. 验证方式

### 10.1 验证脚本

```bash
#!/bin/bash
# verify_env.sh - 环境变量验证脚本

echo "========== 环境变量验证 =========="

# 1. 检查关键变量
check_var() {
    if [ -z "${!1}" ]; then
        echo "❌ $1 未设置"
        return 1
    else
        echo "✅ $1 = ${!1}"
        return 0
    fi
}

# 2. 验证必要变量
check_var "PATH"
check_var "HOME"
check_var "SHELL"
check_var "LANG"

# 3. 验证 Java 环境（如果需要）
if command -v java &> /dev/null; then
    echo "✅ Java: $(java -version 2>&1 | head -1)"
fi

# 4. 验证 Python 环境（如果需要）
if command -v python3 &> /dev/null; then
    echo "✅ Python: $(python3 --version)"
fi

echo "========== 验证完成 =========="
```

### 10.2 常见问题排查

```bash
# 问题 1：变量定义在 ~/.bashrc 但不生效
# 原因：使用的是登录 shell，~/.bashrc 未被加载
# 解决：在 ~/.bash_profile 中添加 source ~/.bashrc

# 问题 2：sudo 环境下变量不生效
# 原因：sudo 默认重置环境变量
# 解决：使用 sudo -E 或配置 /etc/sudoers

# 问题 3：变量有空格或特殊字符
# 解决：使用引号包裹
export GREETING="Hello World"
```

## 11. 总结

1. **环境变量分层**：系统级 `/etc/` → 用户级 `~/.` → 会话级 `export`
2. **推荐配置位置**：
   - 系统级：使用 `/etc/profile.d/*.sh`
   - 用户级：使用 `~/.bashrc` + `~/.bash_profile`
3. **PATH 安全**：始终使用追加而非覆盖
4. **生效方式**：`source` 或新开 shell
5. **验证检查**：使用 `env`、`printenv`、`echo $VAR`
