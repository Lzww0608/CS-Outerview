# 日志第 N 列提取、排序与去重

## 1. 问题背景

日志分析是日常运维和开发中的常见需求。提取日志中特定列、排序、去重是三个基础但强大的操作组合。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  典型日志格式：                                            │
│                                                             │
│  2025-01-15 10:23:45 INFO 192.168.1.100 /api/login 200    │
│  2025-01-15 10:23:46 ERROR 192.168.1.101 /api/query 500  │
│  2025-01-15 10:23:47 INFO 192.168.1.102 /api/login 200    │
│                                                             │
│  需求：提取第 4 列（IP），排序，去重                       │
│  结果：192.168.1.100, 192.168.1.101, 192.168.1.102       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 列位置不固定 | 日志格式变化导致列位置偏移 |
| 分隔符不一致 | 空格、TAB、逗号等不同分隔符 |
| 大文件处理 | 日志文件过大，处理速度慢 |
| 特殊字符 | IP 地址中包含特殊字符导致解析错误 |

---

## 3. 影响范围

- 运维日志分析
- 错误统计和告警
- 访问日志分析
- 性能监控

## 5. 解决方案

### 5.1 基础方案：awk + sort + uniq

```bash
# 基本语法
awk '{print $N}' filename | sort | uniq

# 示例：提取日志第 4 列并去重
awk '{print $4}' access.log | sort | uniq

# 提取第 4 列，排序，统计出现次数
awk '{print $4}' access.log | sort | uniq -c | sort -rn

# 提取第 4 列，去重并保存到文件
awk '{print $4}' access.log | sort -u > unique_ips.txt
```

### 5.2 多列提取与排序

```bash
# 提取多列（用 OFS 指定输出分隔符）
awk '{print $4, $5}' access.log | sort -u

# 按第 4 列排序
awk '{print $4, $5, $6}' access.log | sort -k1,1 -u

# 数值排序（假设第 4 列是数字）
awk '{print $4, $5}' access.log | sort -n -k1,1 -u
```

### 5.3 复杂场景处理

```bash
# 场景 1：分隔符不是空格
# 使用 -F 指定分隔符
awk -F',' '{print $4}' csv.log           # 逗号分隔
awk -F'|' '{print $4}' pipe.log         # 竖线分隔
awk -F'[:\t]' '{print $4}' mixed.log    # 冒号或TAB分隔

# 场景 2：跳过前几行（表头）
awk 'NR>1 {print $4}' log.txt           # 跳过第1行
awk 'NR>5 {print $4}' log.txt           # 跳过前5行

# 场景 3：条件过滤
awk '$5 > 400 {print $4}' access.log | sort -u  # 只取第5列>400的

# 场景 4：提取 IP 地址
awk '{print $4}' access.log | grep -E '^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$' | sort -u
```

### 5.4 大文件优化

```bash
# 场景 5：大文件处理
# 分块处理 + 并行
split -l 100000 access.log chunk_        # 每10万行分一个文件
for f in chunk_*; do
    awk '{print $4}' "$f" | sort -u &
done | sort -u > result.txt
wait
rm chunk_*

# 场景 6：使用更快的工具
# 安装 GNU parallel
parallel awk \'{print \$4\}\' ::: access.log | sort -u > result.txt
```

### 5.5 一行命令解决

```bash
# 完整管道：提取 + 排序 + 去重
awk '{print $4}' access.log | sort | uniq -c | sort -rn | head -20

# 等价简化写法（sort -u = sort | uniq）
awk '{print $4}' access.log | sort -u

# 带条件的复杂查询
awk '$5 ~ /^[45][0-9]{2}$/ {print $4}' access.log | sort -u

# 统计去重后的总数
awk '{print $4}' access.log | sort -u | wc -l
```

## 7. 推荐方案

### 7.1 日常使用推荐

```bash
# 推荐：awk + sort + uniq
# 功能全面，语法简洁，性能足够

# 提取第 N 列并排序去重
awk '{print $N}' logfile | sort -u

# 提取并统计 TOP 10
awk '{print $N}' logfile | sort | uniq -c | sort -rn | head -10
```

### 7.2 Python 方案（复杂场景）

```python
#!/usr/bin/env python3
"""
日志列提取、排序、去重脚本
"""

import sys
from collections import OrderedDict

def process_log(filename, column, delimiter=' ', skip_lines=0):
    """
    处理日志文件
    
    Args:
        filename: 日志文件名
        column: 列号（从1开始）
        delimiter: 分隔符
        skip_lines: 跳过的行数
    """
    values = []
    
    with open(filename, 'r', encoding='utf-8', errors='ignore') as f:
        for i, line in enumerate(f):
            if i < skip_lines:
                continue
            
            parts = line.strip().split(delimiter)
            if len(parts) >= column:
                values.append(parts[column - 1])
    
    # 排序并去重（保持顺序）
    seen = OrderedDict()
    for v in sorted(values):
        if v not in seen:
            seen[v] = True
    
    return list(seen.keys())

if __name__ == '__main__':
    if len(sys.argv) < 3:
        print("Usage: log_extract.py <file> <column> [delimiter] [skip_lines]")
        sys.exit(1)
    
    filename = sys.argv[1]
    column = int(sys.argv[2])
    delimiter = sys.argv[3] if len(sys.argv) > 3 else ' '
    skip_lines = int(sys.argv[4]) if len(sys.argv) > 4 else 0
    
    results = process_log(filename, column, delimiter, skip_lines)
    
    for r in results:
        print(r)
```

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 列位置错误 | 提取数据不正确 | 先用 head 确认格式 |
| 内存不足 | 大文件处理失败 | 分块处理或用磁盘排序 |
| 特殊字符 | 解析失败 | 使用正确的分隔符 |
| 编码问题 | 中文乱码 | 指定文件编码 |

## 10. 验证方式

head -3 access.log

# 2. 确认列数
awk '{print NF}' access.log | head -1

# 3. 测试提取
awk '{print $4}' access.log | head

# 4. 完整命令
awk '{print $4}' access.log | sort | uniq | head

# 5. 统计验证
echo "总行数: $(wc -l < access.log)"
echo "去重后: $(awk '{print $4}' access.log | sort -u | wc -l)"

## 11. 总结

1. **核心命令**：`awk '{print $N}'` 提取列 + `sort` 排序 + `uniq` 去重
2. **常用组合**：`awk '{print $N}' file | sort | uniq -c | sort -rn`（提取+去重+统计+排序）
3. **分隔符处理**：使用 `-F` 参数指定分隔符
4. **性能优化**：大文件使用分块或并行处理
5. **验证步骤**：先 `head` 看格式，再逐步构建完整命令
