# 8. Unix Domain Socket

## 1. 本地套接字是什么

Unix Domain Socket（UDS，本地套接字）是同一台机器上进程间通信的一种 socket。它使用 `AF_UNIX` / `AF_LOCAL` 地址族，不经过完整 TCP/IP 协议栈。

UDS 支持两种常用类型：

1. `SOCK_STREAM`：面向连接的字节流，语义类似 TCP。
2. `SOCK_DGRAM`：无连接数据报，保留消息边界，语义类似 UDP。

UDS 的地址可以是文件系统路径，也可以是 Linux 抽象命名空间地址。

## 2. 服务端 API 调用过程

流式 UDS 服务端典型流程：

```c
int fd = socket(AF_UNIX, SOCK_STREAM, 0);

struct sockaddr_un addr;
memset(&addr, 0, sizeof(addr));
addr.sun_family = AF_UNIX;
strncpy(addr.sun_path, "/tmp/demo.sock", sizeof(addr.sun_path) - 1);

unlink("/tmp/demo.sock");
bind(fd, (struct sockaddr*)&addr, sizeof(addr));
listen(fd, SOMAXCONN);

int conn = accept(fd, NULL, NULL);
char buf[1024];
ssize_t n = read(conn, buf, sizeof(buf));
write(conn, buf, n);

close(conn);
close(fd);
unlink("/tmp/demo.sock");
```

关键点：

1. `socket()` 创建本地套接字 fd。
2. `bind()` 绑定本地路径，路径会在文件系统中出现一个 socket 类型文件。
3. `listen()` 进入监听状态。
4. `accept()` 接受客户端连接，返回连接 fd。
5. `read/write` 或 `send/recv` 传输数据。
6. 退出时关闭 fd，并删除 socket 路径。

## 3. 客户端 API 调用过程

```c
int fd = socket(AF_UNIX, SOCK_STREAM, 0);

struct sockaddr_un addr;
memset(&addr, 0, sizeof(addr));
addr.sun_family = AF_UNIX;
strncpy(addr.sun_path, "/tmp/demo.sock", sizeof(addr.sun_path) - 1);

connect(fd, (struct sockaddr*)&addr, sizeof(addr));

write(fd, "hello", 5);
char buf[1024];
read(fd, buf, sizeof(buf));

close(fd);
```

客户端和 TCP 客户端类似，只是地址族和地址结构不同。

## 4. 数据报 UDS

数据报模式不需要 `listen/accept`，常用 `sendto/recvfrom`：

```c
int fd = socket(AF_UNIX, SOCK_DGRAM, 0);
bind(fd, (struct sockaddr*)&local_addr, sizeof(local_addr));
sendto(fd, data, len, 0, (struct sockaddr*)&peer_addr, sizeof(peer_addr));
recvfrom(fd, buf, sizeof(buf), 0, NULL, NULL);
```

数据报 UDS 保留单条消息边界，适合通知、日志、小控制消息。

## 5. UDS 的优势

1. 比 TCP loopback 少了 IP 层路由、分片、校验等协议栈成本。
2. API 和网络 socket 接近，容易迁移已有网络编程模型。
3. 支持通过 `sendmsg/recvmsg` 传递文件描述符。
4. 可以配合 `epoll` 做高并发本机服务。
5. 文件系统路径可以配合权限控制访问。

传递 fd 的典型场景是 master 进程打开文件、socket 或设备 fd，再把 fd 传给 worker 进程处理。

## 6. 易错点

1. UDS 流式模式也是字节流，没有消息边界，需要长度字段或分隔符。
2. 绑定文件路径前通常要先 `unlink` 旧 socket 文件，否则 `bind` 可能失败。
3. 路径长度受 `sockaddr_un.sun_path` 限制，Linux 通常是 108 字节左右。
4. 进程退出不会自动删除 socket 路径文件，需要清理。
5. UDS 只适合同机通信，不能跨机器。

## 7. 面试回答模板

本地套接字用 `socket(AF_UNIX, type, 0)` 创建。服务端一般是 `socket -> unlink旧路径 -> bind -> listen -> accept -> read/write -> close -> unlink`；客户端是 `socket -> connect -> read/write -> close`。它比 TCP loopback 更轻，因为不走完整网络协议栈，还支持 `sendmsg/recvmsg` 传递文件描述符。流式 UDS 没有消息边界，工程上要自己设计包头或长度字段。
