# 查看 Linux 线程 task_struct 信息

## 1. 问题背景

Linux 内核使用 task_struct（进程描述符）管理进程和线程。了解如何查看 task_struct 中的信息对于系统调试和性能分析至关重要。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  task_struct 核心信息：                                    │
│                                                             │
│  • 进程/线程标识（PID、TGID）                           │
│  • 状态信息（state、flags）                               │
│  • 调度信息（priority、policy）                           │
│  • 内存信息（mm、rss、vm）                               │
│  • 文件信息（files、fs）                                  │
│  • 信号信息（signal、sighand）                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 如何查看进程信息 | /proc/pid/status |
| 如何查看线程信息 | /proc/pid/task/tid/status |
| task_struct 在哪 | 内核源码 sched.h |
| 如何获取内核结构 | gdb、crash 工具 |

## 4. 原因分析

### 4.1 task_struct 结构

```c
// 内核源码：include/linux/sched.h

struct task_struct {
    // 进程标识
    volatile long state;           // 进程状态
    pid_t pid;                     // 进程ID
    pid_t tgid;                    // 线程组ID
    
    // 调度信息
    int prio;
    int static_prio;
    int normal_prio;
    unsigned int rt_priority;
    const struct sched_class *sched_class;
    struct sched_entity se;
    struct sched_rt_entity rt;
    
    // 内存信息
    struct mm_struct *mm;
    struct mm_struct *active_mm;
    
    // 文件信息
    struct files_struct *files;
    struct fs_struct *fs;
    
    // 信号信息
    struct signal_struct *signal;
    struct sighand_struct *sighand;
    
    // 其他重要字段
    char comm[TASK_COMM_LEN];     // 命令名
    struct thread_struct *thread;  // 线程硬件上下文
};
```

## 5. 解决方案

### 5.1 /proc 文件系统查看

```bash
# 1. 查看进程基本信息
cat /proc/PID/status

# 输出示例：
# Name:   nginx
# State:  S (sleeping)
# Tgid:   1234
# Pid:    1234
# PPid:   1
# TracerPid:  0
# Uid:    1000    1000    1000    1000
# Gid:    1000    1000    1000    1000
# FDSize: 64
# Groups: 1000
# VmPeak:  123456 kB
# VmSize:  123456 kB
# VmLck:       0 kB
# VmPin:       0 kB
# VmRSS:   12345 kB
# VmData:  12345 kB
# VmStk:     132 kB
# VmExe:     123 kB
# VmLib:    1234 kB
# VmPTE:      56 kb
# Threads:    8
# SigQ:   0/12345
# SigPnd: 0000000000000000
# ShdPnd: 0000000000000000
# ...
```

```bash
# 2. 查看线程信息
# /proc/PID/task/ 目录下每个 TID 对应一个线程
ls /proc/PID/task/

# 查看特定线程的 status
cat /proc/PID/task/TID/status

# 3. 查看线程组信息
# 所有线程的 Tgid 相同（主线程 PID）
cat /proc/PID/status | grep -E "Tgid|Threads"

# 4. 查看详细的 statm（内存映射）
cat /proc/PID/statm
# 格式：size resident shared text lib data dt
```

### 5.2 内核参数详解

```bash
# 常用 /proc/pid/status 字段说明

# 标识信息
Name:           # 进程名
Pid:            # 进程ID
PPid:           # 父进程ID
Tgid:           # 线程组ID
TracerPid:      # 跟踪该进程的PID（0表示未被跟踪）

# 状态信息
State:          # 进程状态
# R: 运行中
# S: 可中断睡眠
# D: 不可中断睡眠
# Z: 僵尸进程
# T: 停止

# 内存信息
VmPeak:         # 峰值虚拟内存大小
VmSize:         # 当前虚拟内存大小
VmRSS:          # 实际使用的物理内存
VmData:         # 数据段大小
VmStk:          # 栈大小
VmExe:          # 代码段大小

# 信号信息
SigQ:           # 信号队列状态
SigPnd:         # 待处理信号
ShdPnd:         # 共享待处理信号
SigBlk:         # 阻塞信号
SigIgn:         # 忽略信号
SigCgt:         # 捕获信号
```

### 5.3 使用 pstack 和进程树

```bash
# 1. pstack 查看线程堆栈
pstack PID

# 2. 查看进程树
pstree -p PID

# 3. 查看线程详情
ps -eLf | grep PID

# 输出：
# UID        PID  PPID   LWP  C NLWP STIME TTY      STAT   TIME CMD
# user      1234  1230  1234  0    8 10:00 ?        Sl     0:00 nginx
# user      1234  1230  1235  0    8 10:00 ?        Sl     0:00 nginx
# user      1234  1230  1236  0    8 10:00 ?        Sl     0:00 nginx

# 4. top 查看线程
top -H -p PID

# 进入 top 后按 H 切换线程视图
```

### 5.4 使用 gdb 查看内核结构

```bash
# gdb 查看运行中进程的内核结构

# 1. 附加到进程
gdb -p PID

# 2. 查看 task_struct
(gdb) p *((struct task_struct *)0xXXXXXXXX)

# 3. 查看特定字段
(gdb) p task->pid
(gdb) p task->comm
(gdb) p task->state
(gdb) p task->mm

# 4. 查看线程信息
(gdb) p *task->group_leader
(gdb) p task->signal->live

# 5. 列出所有线程
(gdb) info threads
(gdb) thread apply all bt
```

### 5.5 使用 eBPF 追踪

```python
#!/usr/bin/env python3
"""
使用 bcc Python 接口查看 task_struct 信息
"""

from bcc import BPF

program = """
#include <linux/sched.h>

// 输出进程/线程基本信息
int probe_task(struct pt_regs *ctx) {
    struct task_struct *task = (struct task_struct *)bpf_get_current_task();
    
    u32 pid = bpf_get_current_pid_tgid() >> 32;
    u32 tid = bpf_get_current_pid_tgid();
    u32 ppid = 0;
    struct task_struct *parent = task->parent;
    if (parent) {
        ppid = parent->tgid;
    }
    
    bpf_trace_printk("PID: %d, TID: %d, PPID: %d, State: %ld\\n", 
                     pid, tid, ppid, task->state);
    return 0;
}
"""

b = BPF(text=program)
b.attach_uprobe(name="/bin/bash", sym="readline", fn_name="probe_task")
b.trace_print()
```

## 6. 可选方案对比

| 方案 | 使用场景 | 优点 | 缺点 |
|------|----------|------|------|
| /proc | 日常运维 | 简单易用 | 信息有限 |
| pstack | 堆栈查看 | 快速 | 只看堆栈 |
| gdb | 内核开发 | 信息完整 | 需要调试环境 |
| eBPF | 实时追踪 | 无侵入 | 需 root 权限 |

## 7. 推荐方案

### 7.1 日常运维推荐

```bash
# 推荐命令组合

# 1. 查看进程基本信息和线程数
ps -ef | grep PID
cat /proc/PID/status | grep -E "Name|Pid|State|Threads|Vm"

# 2. 查看线程堆栈
pstack PID

# 3. top 线程视图
top -H -p PID

# 4. 查看打开的文件
ls -la /proc/PID/fd/
lsof -p PID

# 5. 查看内存映射
cat /proc/PID/maps
pmap -X PID
```

## 9. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| gdb 附加进程 | 进程暂停 | 谨慎使用 |
| eBPF 权限 | 需要 root | 使用 sudo |

## 10. 验证方式

```bash
# 验证查看的信息

# 1. 创建一个测试进程
sleep 1000 &
PID=$!

# 2. 查看其 task_struct 信息
echo "=== Process Info ==="
cat /proc/$PID/status | grep -E "Name|Pid|State|Threads"

echo "=== Thread Info ==="
ls /proc/$PID/task/
cat /proc/$PID/task/$PID/status | grep -E "Name|Pid|State"

# 3. 清理
kill $PID
```

## 11. 总结

1. **task_struct 定义**：Linux 内核用于描述进程/线程的核心数据结构
2. **查看方式**：/proc 文件系统（用户态）、gdb（内核调试）、eBPF（动态追踪）
3. **关键信息**：PID/TID、State、内存信息、线程数、文件描述符
4. **日常运维**：`/proc/PID/status` + `pstack` + `top -H` 组合使用
5. **深入分析**：gdb 附加进程查看完整结构，或使用 eBPF 进行无侵入追踪
