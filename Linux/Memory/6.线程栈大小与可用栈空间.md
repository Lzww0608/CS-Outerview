# 6. 线程栈大小与可用栈空间

## 1. 栈是什么

线程栈保存函数调用过程中的栈帧，包括局部变量、返回地址、保存的寄存器、函数参数等。每个线程都有自己的栈，同一进程内线程共享堆、全局区和文件描述符，但不共享各自的执行栈。

主线程栈大小通常受进程资源限制控制；新建线程的栈大小通常由线程库默认值或 `pthread_attr_setstacksize()` 指定。

## 2. 怎么看栈大小

查看当前 shell 启动进程的主线程栈限制：

```bash
ulimit -s
```

程序内可以用：

```cpp
#include <sys/resource.h>
#include <iostream>

int main() {
    rlimit limit{};
    if (getrlimit(RLIMIT_STACK, &limit) == 0) {
        std::cout << "soft stack limit: " << limit.rlim_cur << "\n";
        std::cout << "hard stack limit: " << limit.rlim_max << "\n";
    }
}
```

查看当前 pthread 的栈起始地址和栈大小，Linux/glibc 可以用 `pthread_getattr_np`：

```cpp
#define _GNU_SOURCE
#include <pthread.h>
#include <iostream>

int main() {
    pthread_attr_t attr;
    pthread_getattr_np(pthread_self(), &attr);

    void* stack_addr = nullptr;
    size_t stack_size = 0;
    pthread_attr_getstack(&attr, &stack_addr, &stack_size);
    pthread_attr_destroy(&attr);

    std::cout << "stack addr: " << stack_addr << "\n";
    std::cout << "stack size: " << stack_size << "\n";
}
```

## 3. 怎么判断还能用多少栈

严格来说，不能完全精确判断“还能用多少栈”，因为：

1. 栈增长方向和 guard page 是平台相关实现。
2. 编译优化、内联、栈保护、异常处理都会改变栈帧大小。
3. 线程栈附近可能有保护页，越界时触发 `SIGSEGV`。
4. 递归函数每层栈帧大小可能不固定。

工程上可以估算：

1. 通过 `pthread_getattr_np` 获取栈区间。
2. 取一个当前局部变量地址，和栈边界做差。
3. 留出 guard page 和安全余量。

示例只用于诊断，不建议作为业务逻辑依赖：

```cpp
#include <pthread.h>
#include <cstdint>
#include <iostream>

size_t estimateUsedStack() {
    pthread_attr_t attr;
    pthread_getattr_np(pthread_self(), &attr);

    void* stack_addr = nullptr;
    size_t stack_size = 0;
    pthread_attr_getstack(&attr, &stack_addr, &stack_size);
    pthread_attr_destroy(&attr);

    int local = 0;
    auto low = reinterpret_cast<uintptr_t>(stack_addr);
    auto high = low + stack_size;
    auto cur = reinterpret_cast<uintptr_t>(&local);

    if (cur >= low && cur <= high) {
        return high - cur; // x86_64 Linux 常见栈向低地址增长时的近似已用量
    }
    return 0;
}
```

## 4. 怎么控制线程栈大小

创建 pthread 时可以指定栈大小：

```cpp
#include <pthread.h>

void* run(void*) {
    return nullptr;
}

int main() {
    pthread_attr_t attr;
    pthread_attr_init(&attr);
    pthread_attr_setstacksize(&attr, 2 * 1024 * 1024);

    pthread_t tid;
    pthread_create(&tid, &attr, run, nullptr);
    pthread_join(tid, nullptr);

    pthread_attr_destroy(&attr);
}
```

注意事项：

1. 栈不能设置得太小，否则稍深的调用链、较大的局部数组就可能溢出。
2. 栈也不能无限调大，线程多时会消耗大量虚拟地址空间和提交内存。
3. 大对象不要放栈上，优先放堆或复用对象池。
4. 递归算法要估算深度，必要时改成显式栈迭代。

## 5. 面试回答模板

判断能用的栈大小可以分两层回答：主线程看 `ulimit -s` 或 `getrlimit(RLIMIT_STACK)`；pthread 可以通过线程属性或 `pthread_getattr_np` 查看实际栈区间。至于“还剩多少栈”，只能根据当前局部变量地址和栈边界做近似估算，不能作为强保证。工程上更重要的是避免大对象上栈、控制递归深度、必要时用 `pthread_attr_setstacksize` 调整线程栈，并通过 ASan 或压测发现栈溢出风险。
