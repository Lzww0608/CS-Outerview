# 4. 数据手册阅读与寄存器配置

嵌入式面试让读英文数据手册，通常考察的不是英语翻译本身，而是能否把 datasheet 里的电气、时序、寄存器和初始化要求转成可靠驱动代码。

## 1. 数据手册重点看什么

读一个外设 datasheet，可以按下面顺序：

1. **芯片概述**：设备功能、接口类型、供电范围、封装和典型应用。
2. **Pin Description**：管脚方向、复用功能、上拉下拉、复位默认状态。
3. **Electrical Characteristics**：电压、电流、时钟频率、输入高低阈值。
4. **Power Sequence**：上电、复位、时钟稳定、初始化等待时间。
5. **Timing Diagram**：I2C/SPI/UART/并口时序，setup/hold 时间。
6. **Register Map**：寄存器地址、默认值、读写属性、bit 含义。
7. **Initialization Sequence**：推荐初始化流程和必要延时。
8. **Interrupt/Status**：状态位、清中断方式、错误标志。
9. **Application Notes**：厂商给出的典型配置和注意事项。

## 2. 寄存器字段怎么翻译成代码

数据手册常见表述：

```text
CTRL_REG0 (0x10)
Bit[7]: ENABLE, 1 = enable device
Bit[3:2]: MODE, 00 = standby, 01 = normal, 10 = low power
Bit[0]: INT_CLR, write 1 to clear
```

对应代码应避免魔法数字：

```c
#define CTRL_REG0              0x10
#define CTRL_ENABLE            BIT(7)
#define CTRL_MODE_SHIFT        2
#define CTRL_MODE_MASK         GENMASK(3, 2)
#define CTRL_MODE_NORMAL       1
#define CTRL_INT_CLR           BIT(0)

static int demo_enable(struct regmap *map)
{
    int ret;

    ret = regmap_update_bits(map, CTRL_REG0,
                             CTRL_MODE_MASK,
                             CTRL_MODE_NORMAL << CTRL_MODE_SHIFT);
    if (ret)
        return ret;

    return regmap_update_bits(map, CTRL_REG0,
                              CTRL_ENABLE, CTRL_ENABLE);
}
```

Linux 驱动里常用 `regmap` 封装 I2C/SPI 寄存器访问，减少重复读改写、缓存和大小端处理代码。

## 3. 易错字段

1. **reserved bit**：保留位不要随便写 1，读改写时要保留原值。
2. **W1C**：write 1 clear，写 1 清除，写 0 保持；不能按普通位理解。
3. **RO/WO/RW**：只读、只写、可读写属性不同，只写寄存器读回值可能无意义。
4. **默认值**：芯片 reset 后默认值不一定等于驱动期望值，初始化要显式配置关键位。
5. **地址宽度**：寄存器地址可能是 8/16 bit，数据可能是 8/16/24/32 bit。
6. **大小端**：多字节寄存器的高低字节顺序要按手册处理。
7. **延时要求**：上电、复位、模式切换后可能要 `msleep/usleep_range`。

## 4. 真实场景

摄像头 sensor、触摸 IC、PMIC、音频 codec 这类设备，驱动初始化通常都来自 datasheet 或 vendor init table：

```text
上电 regulator
-> 配置 pinctrl
-> 释放 reset
-> 等待芯片稳定
-> 读取 chip id
-> 写初始化寄存器表
-> 配置中断或数据通路
-> 注册到 V4L2/input/ALSA 等子系统
```

读英文手册时，遇到 `must`、`shall`、`do not`、`reserved`、`undefined`、`typical/max/min` 要格外谨慎。这些词通常对应硬件必须满足的约束，不能当成说明性文字略过。

## 5. 面试回答模板

读英文数据手册我会先抓接口、电气和初始化主线：看 pin description、供电范围、power sequence、timing diagram、register map、interrupt/status 和推荐初始化流程。寄存器表会转成宏定义和 bit mask，保留位用读改写保护，W1C 位按写 1 清除处理，多字节寄存器注意地址宽度和大小端。真正写驱动时，还要把手册里的上电延时、reset 时序、clock、pinctrl 和中断清除方式都落到代码里，再用逻辑分析仪或寄存器 dump 验证。
