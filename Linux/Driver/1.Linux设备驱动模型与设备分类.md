# 1. Linux 设备驱动模型与设备分类

Linux 驱动是内核中管理硬件或虚拟设备的软件层。它向上给内核子系统和用户态提供统一接口，向下操作寄存器、中断、DMA、总线协议和电源管理。面试里问“Linux 驱动设备有哪些种类”，通常要先按用户接口分，再按总线和子系统补充。

## 1. 常见设备类型

| 类型 | 典型接口 | 例子 | 特点 |
| --- | --- | --- | --- |
| 字符设备 | `/dev/xxx`、`file_operations` | 串口、GPIO、传感器、misc 设备 | 按字节流或命令访问，常用 `read/write/ioctl` |
| 块设备 | block layer、请求队列 | eMMC、SD 卡、SSD | 按块读写，经过页缓存、调度和文件系统 |
| 网络设备 | `net_device`、协议栈 | 以太网、Wi-Fi、虚拟网卡 | 不表现为普通文件读写，通过 socket 收发 |

除了三大类，工程里还会按子系统看到：

1. **输入设备**：按键、触摸屏、鼠标，走 input subsystem。
2. **显示/图形设备**：LCD、HDMI、GPU，走 DRM/KMS、framebuffer。
3. **声音设备**：Codec、I2S，走 ALSA/ASoC。
4. **摄像头设备**：Sensor、ISP，走 V4L2/media framework。
5. **总线设备**：I2C、SPI、USB、PCI、platform device。
6. **电源管理设备**：regulator、clock、pinctrl、reset、PMIC。

## 2. Linux 设备模型

Linux 设备模型把设备、驱动、总线抽象成三个核心对象：

```text
bus_type
  -> device
  -> device_driver
```

匹配成功后，内核调用驱动的 `probe()`：

```text
设备来自设备树/ACPI/总线枚举
-> 注册到 bus
-> bus 按 compatible/id_table/name 匹配 driver
-> 调用 driver.probe
-> 驱动申请资源、初始化硬件、注册子系统接口
```

以 platform 驱动为例：

```c
static const struct of_device_id demo_of_match[] = {
    { .compatible = "vendor,demo-device" },
    {}
};

static int demo_probe(struct platform_device *pdev) {
    return 0;
}

static struct platform_driver demo_driver = {
    .probe = demo_probe,
    .driver = {
        .name = "demo",
        .of_match_table = demo_of_match,
    },
};
module_platform_driver(demo_driver);
```

## 3. 字符设备基本流程

字符设备常见步骤：

1. 分配设备号：`alloc_chrdev_region()`。
2. 初始化 `cdev`：绑定 `file_operations`。
3. 创建 class/device：让 udev 生成 `/dev/xxx`。
4. 实现 `open/read/write/ioctl/poll/mmap` 等接口。
5. 卸载时按相反顺序释放资源。

`file_operations` 是用户态系统调用进入驱动的主要入口：

```c
static const struct file_operations demo_fops = {
    .owner = THIS_MODULE,
    .open = demo_open,
    .read = demo_read,
    .write = demo_write,
    .unlocked_ioctl = demo_ioctl,
};
```

## 4. 易错点

1. 不要把所有设备都说成字符设备。网卡主要走网络协议栈，磁盘主要走块层。
2. `probe()` 里要用 `devm_*` 或清晰的错误回滚路径，避免初始化失败后资源泄漏。
3. 中断、DMA、clock、pinctrl、regulator、reset 都是驱动稳定工作的一部分，不只是读写寄存器。
4. 用户态传入数据要校验长度和权限，不能直接解引用用户指针。
5. 驱动卸载、设备热拔、系统 suspend/resume 都要考虑对象生命周期。

## 5. 面试回答模板

Linux 驱动设备常按接口分为字符设备、块设备和网络设备。字符设备通过 `/dev` 节点和 `file_operations` 提供 `read/write/ioctl`；块设备接入 block layer，服务文件系统和页缓存；网络设备注册 `net_device`，通过协议栈和 socket 收发。更细还可以按 I2C、SPI、USB、PCI、platform 总线和 input、DRM、ALSA、V4L2 等子系统划分。Linux 设备模型核心是 bus、device、driver，设备和驱动匹配后调用 `probe()`，驱动申请资源、初始化硬件并注册上层接口。
