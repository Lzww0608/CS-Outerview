# 指纹浏览器详解

## 一、指纹浏览器概述

### 1.1 什么是指纹浏览器

指纹浏览器是一种通过模拟或隐藏浏览器特征指纹，使用户在互联网上的身份更难被追踪的技术工具。

### 2.2 Canvas 指纹原理

```javascript
// Canvas 指纹生成
function getCanvasFingerprint() {
    const canvas = document.createElement('canvas');
    const ctx = canvas.getContext('2d');
    
    // 绘制包含文字和图形的图像
    ctx.textBaseline = 'top';
    ctx.font = '14px Arial';
    ctx.fillStyle = '#f60';
    ctx.fillRect(125, 1, 62, 20);
    ctx.fillStyle = '#069';
    ctx.fillText('Fingerprint', 2, 15);
    ctx.fillStyle = 'rgba(102, 204, 0, 0.7)';
    ctx.fillText('Fingerprint', 4, 17);
    
    // 获取 Canvas 数据并计算哈希
    const data = canvas.toDataURL();
    return hash(data);
}
```

### 2.3 WebGL 指纹

```javascript
// WebGL 指纹
function getWebGLFingerprint() {
    const canvas = document.createElement('canvas');
    const gl = canvas.getContext('webgl');
    
    const debugInfo = gl.getExtension('WEBGL_debug_renderer_info');
    
    return {
        vendor: gl.getParameter(debugInfo.UNMASKED_VENDOR_WEBGL),
        renderer: gl.getParameter(debugInfo.UNMASKED_RENDERER_WEBGL),
        version: gl.getParameter(gl.VERSION),
        shadingLanguageVersion: gl.getParameter(gl.SHADING_LANGUAGE_VERSION)
    };
}
```

### 3.2 浏览器指纹篡改

```javascript
// Canvas 指纹篡改
class CanvasFingerprintSpoofer {
    spoofCanvasFingerprint() {
        const originalToDataURL = HTMLCanvasElement.prototype.toDataURL;
        
        HTMLCanvasElement.prototype.toDataURL = function(type, ...args) {
            // 获取原始 Canvas 数据
            const data = originalToDataURL.call(this, type, ...args);
            
            // 添加微小的随机噪声
            const ctx = this.getContext('2d');
            if (ctx) {
                const imageData = ctx.getImageData(0, 0, this.width, this.height);
                // 添加不可察觉的噪声
                for (let i = 0; i < imageData.data.length; i += 4) {
                    imageData.data[i] += Math.random() * 1;
                    imageData.data[i + 1] += Math.random() * 1;
                    imageData.data[i + 2] += Math.random() * 1;
                }
                ctx.putImageData(imageData, 0, 0);
            }
            
            return data;
        };
    }
}
```

## 四、防泄漏技术

### 4.1 WebRTC 泄漏防护

```javascript
// WebRTC 泄漏防护
class WebRTCLeakProtector {
    disableWebRTCLeak() {
        // 方法1：禁用 WebRTC
        if (!window.RTCPeerConnection) return;
        
        const OrigRTCPeerConnection = window.RTCPeerConnection;
        
        window.RTCPeerConnection = function(...args) {
            const pc = new OrigRTCPeerConnection(...args);
            
            // 拦截 onicecandidate
            const originalOnIceCandidate = pc.onicecandidate;
            pc.onicecandidate = function(event) {
                if (event.candidate) {
                    // 只保留 TURN 候选
                    if (!event.candidate.candidate.includes('typ srflx')) {
                        return;
                    }
                }
                if (originalOnIceCandidate) {
                    originalOnIceCandidate.call(this, event);
                }
            };
            
            return pc;
        };
        
        // 方法2：修改 ICE 候选策略
        const origCreateOffer = OrigRTCPeerConnection.prototype.createOffer;
        OrigRTCPeerConnection.prototype.createOffer = function(options) {
            if (options) {
                options.iceRestart = false;
            }
            return origCreateOffer.call(this, options);
        };
    }
}
```

## 八、面试常见问题

### Q1: 什么是浏览器指纹？

浏览器指纹是通过收集浏览器和系统的各种特征（Canvas、WebGL、字体等）生成的唯一标识，用于追踪用户身份。

### Q2: 指纹浏览器如何防关联？

通过容器隔离、指纹篡改、代理轮换等技术，让每个浏览器实例呈现不同的特征，从而避免被关联。

### Q3: 指纹浏览器的局限性？

平台检测技术持续升级，行为分析难以规避，需要不断更新防护策略。

### Q4: 指纹浏览器合法吗？

本身技术是中性的，合法性取决于使用目的。用于隐私保护和合规运营是合法的，用于规避监管则违法。
