# GROUP BY 条件聚合

条件聚合是指在分组统计时，只统计满足某个条件的行。面试里常见问题是：学生表有学生、班级、性别字段，如何一条 SQL 查出每个班级分别有多少男生和女生。

## 1. 标准写法

假设表结构为：

```sql
student(id, name, class_id, gender)
```

可以使用 `SUM(CASE WHEN ...)`：

```sql
SELECT
    class_id,
    SUM(CASE WHEN gender = '男' THEN 1 ELSE 0 END) AS male_count,
    SUM(CASE WHEN gender = '女' THEN 1 ELSE 0 END) AS female_count
FROM student
GROUP BY class_id;
```

核心原理是：每一行先根据性别映射成 0 或 1，然后在班级维度求和。

## 2. COUNT 写法

也可以利用 `COUNT` 不统计 `NULL` 的特性：

```sql
SELECT
    class_id,
    COUNT(CASE WHEN gender = '男' THEN 1 END) AS male_count,
    COUNT(CASE WHEN gender = '女' THEN 1 END) AS female_count
FROM student
GROUP BY class_id;
```

MySQL 中还常见：

```sql
SELECT
    class_id,
    SUM(gender = '男') AS male_count,
    SUM(gender = '女') AS female_count
FROM student
GROUP BY class_id;
```

这是因为 MySQL 中条件表达式为真时是 1，为假时是 0。但跨数据库可移植性不如 `CASE WHEN`。

## 3. 易错点

1. `COUNT(gender = '男')` 是错的，因为表达式无论 true/false 都不是 `NULL`，会把男女都统计进去。
2. 如果 `gender` 可能为 `NULL` 或有其他取值，`CASE WHEN ... ELSE 0 END` 更明确。
3. `GROUP BY` 字段要和业务维度一致，如果按班级名称分组，要考虑同名班级问题，最好用 `class_id`。
4. 数据量大时可以给 `(class_id, gender)` 建联合索引，减少分组扫描和回表成本。
5. 如果经常查统计结果，可以考虑按班级维护汇总表或物化视图，避免每次扫明细表。

## 4. 查询每门课程都不低于 60 分的学生

假设表结构为：

```sql
score(student_id, student_name, course_id, score)
```

题目要求“每门课程得分都不低于 60 分”，本质是按学生分组后检查组内最低分：

```sql
SELECT student_id, student_name
FROM score
GROUP BY student_id, student_name
HAVING MIN(score) >= 60;
```

如果还要确保学生确实修了全部课程，例如总课程表为 `course(id)`，则要同时判断课程数量：

```sql
SELECT s.student_id, s.student_name
FROM score s
GROUP BY s.student_id, s.student_name
HAVING MIN(s.score) >= 60
   AND COUNT(DISTINCT s.course_id) = (SELECT COUNT(*) FROM course);
```

另一种条件聚合写法是统计不及格课程数：

```sql
SELECT student_id, student_name
FROM score
GROUP BY student_id, student_name
HAVING SUM(CASE WHEN score < 60 THEN 1 ELSE 0 END) = 0;
```

注意 `WHERE score >= 60` 再分组是错误思路，因为它会先过滤掉不及格记录，导致原本有不及格课程的学生看起来“剩下的课程都及格”。

## 5. 面试回答模板

我会用条件聚合：按班级 `GROUP BY`，男生列写 `SUM(CASE WHEN gender='男' THEN 1 ELSE 0 END)`，女生列同理。`CASE WHEN` 把每行映射成 0/1，聚合后就是数量。也可以写 `COUNT(CASE WHEN gender='男' THEN 1 END)`，因为 `COUNT` 不统计 `NULL`。注意不要写 `COUNT(gender='男')`，在 MySQL 中 false 也是非 NULL，会把所有行都算进去。

如果题目是查询每门课都不低于 60 分的学生，我会按学生分组，用 `HAVING MIN(score) >= 60`，或者用条件聚合统计不及格课程数为 0。不要先 `WHERE score >= 60` 再分组，因为这样会把不及格记录过滤掉，造成误判。
