# 自然语言钱包Swap操作的安全执行流程设计

## 1. 问题背景

用户通过自然语言与 Agent 交互完成链上操作（如 ETH 换 USDC）涉及多个安全风险点：意图识别、参数提取、安全验证、交易执行等。需要设计完整的安全流程，确保用户资产安全。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  自然语言钱包操作流程：                                     │
│                                                             │
│  用户："帮我把钱包里的 ETH 换成 USDC"                     │
│                                                             │
│       ▼                                                     │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 1. 意图识别：识别 Swap 操作                         │  │
│  │ 2. 参数提取：获取钱包、金额、交易对                 │  │
│  │ 3. 安全确认：显示详情、请求授权                     │  │
│  │ 4. 执行交易：签名并发送                             │  │
│  │ 5. 结果反馈：确认成功/失败                         │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 意图误判 | Agent 误解用户意图，执行错误操作 |
| 参数错误 | 金额、地址、滑点设置不当 |
| 授权风险 | 无限授权导致资产被盗 |
| 交易失败 | gas、nonce、网络问题 |
| 滑点损失 | 价格滑点过大导致损失 |

- DeFi 聚合器

### 4.3 完整意图解析

```typescript
// 意图解析流程

interface SwapIntent {
    action: 'swap';           // 操作类型
    sourceToken: {
        symbol: string;       // ETH
        amount?: 'all' | 'half' | number;  // 金额
    };
    targetToken: {
        symbol: string;       // USDC
    };
    wallet?: string;          // 钱包地址（可选）
    constraints: {
        slippage?: number;    // 滑点容忍度
        gasLimit?: number;    // gas 上限
        deadline?: number;    // 交易截止时间
    };
}

// 解析示例
class IntentParser {
    async parse(userInput: string): Promise<SwapIntent> {
        const llm = new LLM();
        
        const prompt = `
            从以下用户输入中提取 Swap 意图：
            "${userInput}"
            
            返回 JSON 格式：
            {
                action: "swap",
                sourceToken: { symbol, amount },
                targetToken: { symbol },
                constraints: { slippage, gasLimit }
            }
        `;
        
        const result = await llm.generate(prompt);
        return JSON.parse(result);
    }
}
```

### 5.2 智能参数推荐

```typescript
// 智能参数推荐系统

class SmartParameterRecommender {
    // 根据金额推荐滑点
    recommendSlippage(amountUSD: number): number {
        if (amountUSD < 100) return 0.03;      // 3% - 小额
        if (amountUSD < 1000) return 0.01;    // 1% - 中额
        if (amountUSD < 10000) return 0.005;  // 0.5% - 大额
        return 0.003;                          // 0.3% - 超大额
    }
    
    // 推荐预留 gas
    recommendGasReserve(): bigint {
        // 始终预留至少 0.005 ETH 作为 gas
        return 5000000000000000n;  // 0.005 ETH
    }
    
    // 推荐 DEX
    async recommendDEX(tokenIn: string, tokenOut: string, amount: bigint) {
        // 比较多个 DEX 的输出
        const quotes = await Promise.all([
            this.getQuote('uniswap', tokenIn, tokenOut, amount),
            this.getQuote('sushiswap', tokenIn, tokenOut, amount),
            this.getQuote('curve', tokenIn, tokenOut, amount),
        ]);
        
        // 选择最优价格，同时考虑流动性
        return quotes.sort((a, b) => 
            Number(b.output - a.output) - Number(a.output - b.output)
        )[0];
    }
}
```

### 5.3 风险检测层

```typescript
// 风险检测中间层

class RiskDetector {
    async check(tx: SwapTransaction): Promise<RiskReport> {
        const risks: Risk[] = [];
        
        // 1. 检查是否是恶意代币
        if (await this.isMaliciousToken(tx.tokenOut)) {
            risks.push({
                level: 'CRITICAL',
                message: '目标代币存在风险，建议取消'
            });
        }
        
        // 2. 检查滑点
        if (tx.slippage > 0.05) {
            risks.push({
                level: 'WARNING',
                message: '滑点设置较高，可能导致较大损失'
            });
        }
        
        // 3. 检查授权额度
        if (tx.approveAmount === 'unlimited') {
            risks.push({
                level: 'WARNING',
                message: '建议设置具体授权额度'
            });
        }
        
        // 4. 检查合约安全
        const auditResult = await this.checkContractAudit(tx.dexAddress);
        if (!auditResult.passed) {
            risks.push({
                level: 'HIGH',
                message: 'DEX 合约未完成安全审计'
            });
        }
        
        return {
            pass: risks.filter(r => r.level === 'CRITICAL').length === 0,
            risks
        };
    }
}
```

            type: 'INTENT_CONFIRM',

## 11. 总结

1. **安全核心**：用户确认 + 风险检测 + 参数推荐
2. **关键环节**：意图解析 → 参数确认 → 风险检测 → 多阶段确认 → 执行 → 反馈
3. **分级策略**：基于金额的差异化确认机制
4. **白名单机制**：信任合约预验证，减少风险
5. **审计日志**：完整记录操作，便于追溯
