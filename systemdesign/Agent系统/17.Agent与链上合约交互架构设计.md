# Agent 与链上合约交互架构设计

## 1. 问题背景

Agent 系统需要与区块链合约进行交互，执行交易、读取状态、监听事件等操作。这个过程涉及 RPC 调用、交易签名、事件解析等多个环节，需要设计合理的中间层来桥接 Agent 的决策能力与链上执行能力。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Agent 与链上交互架构：                                     │
│                                                             │
│  ┌─────────┐     ┌──────────────┐     ┌─────────────────┐  │
│  │  Agent  │────►│  中间层      │────►│  RPC 节点       │  │
│  │ (大脑)  │     │ (Blockchain  │     │  (Ethereum/     │  │
│  │         │◄────│   Adapter)   │◄────│   Solana)       │  │
│  └─────────┘     └──────────────┘     └─────────────────┘  │
│                           │                                  │
│                           ▼                                  │
│                    ┌──────────────┐                         │
│                    │  合约 ABI    │                         │
│                    │  (接口定义)  │                         │
│                    └──────────────┘                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 交易失败率高 | 签名、nonce、gas 估算问题 |
| 状态读取延迟 | RPC 调用慢或限流 |
| 事件解析困难 | 大量 event 难以过滤 |
| 多链支持复杂 | 不同链 RPC 格式各异 |

- DeFi Agent（套利、流动性管理）

- 跨链 Agent

## 5. 解决方案

### 5.1 Blockchain Adapter 中间层设计

```typescript
// 中间层核心接口

interface BlockchainAdapter {
    // 读取链上状态（view 函数）
    call<T>(target: string, abi: AbiFunction, params?: any[]): Promise<T>;
    
    // 发送交易（state-changing 函数）
    sendTransaction(params: TransactionParams): Promise<TransactionReceipt>;
    
    // 监听事件
    subscribe<T>(params: SubscribeParams, callback: (event: T) => void): UnsubscribeFn;
    
    // 获取链信息
    getNetworkInfo(): Promise<NetworkInfo>;
}

// 交易参数
interface TransactionParams {
    from: string;
    to: string;
    data: string;
    value?: bigint;
    gasLimit?: bigint;
    maxFeePerGas?: bigint;
    maxPriorityFeePerGas?: bigint;
    nonce?: number;
}
```

### 5.2 完整中间层实现

```typescript
// AgentBlockchainAdapter.ts

import { ethers } from 'ethers';

export class AgentBlockchainAdapter {
    private provider: ethers.JsonRpcProvider;
    private wallet: ethers.Wallet;
    private nonceCache: Map<string, number> = new Map();
    private pendingTxs: Map<string, Promise<string>> = new Map();
    
    constructor(
        private rpcUrl: string,
        private privateKey: string,
        private chainId: number
    ) {
        this.provider = new ethers.JsonRpcProvider(rpcUrl);
        this.wallet = new ethers.Wallet(privateKey, this.provider);
    }
    
    // 读取合约状态（view/pure 函数）
    async readContract<T>(
        address: string,
        abi: ethers.InterfaceAbi,
        functionName: string,
        args?: any[]
    ): Promise<T> {
        const contract = new ethers.Contract(address, abi, this.provider);
        
        try {
            const result = await contract[functionName](...args);
            return result as T;
        } catch (error: any) {
            throw new BlockchainError(
                `Read failed: ${functionName}`,
                error
            );
        }
    }
    
    // 发送交易
    async sendTransaction(
        to: string,
        abi: ethers.InterfaceAbi,
        functionName: string,
        args?: any[],
        options?: {
            value?: bigint;
            gasMultiplier?: number;
            timeout?: number;
        }
    ): Promise<ethers.TransactionReceipt> {
        const contract = new ethers.Contract(to, abi, this.wallet);
        const fn = contract[functionName];
        
        // 获取 nonce（带缓存）
        const nonce = await this.getNonce();
        
        // 估算 gas
        const gasEstimate = await fn.estimateGas(...args, { value: options?.value || 0 });
        const gasLimit = BigInt(Math.ceil(Number(gasEstimate) * (options?.gasMultiplier || 1.2)));
        
        // 构建交易
        const txRequest = {
            to,
            from: this.wallet.address,
            data: contract.interface.encodeFunctionData(functionName, args),
            nonce,
            gasLimit,
            value: options?.value || 0n,
            chainId: this.chainId,
            type: 2,  // EIP-1559
            maxFeePerGas: await this.provider.getFeeData().then(f => f.maxFeePerGas!),
            maxPriorityFeePerGas: await this.provider.getFeeData().then(f => f.maxPriorityFeePerGas!),
        };
        
        // 签名和发送
        const tx = await this.wallet.signTransaction(txRequest);
        const response = await this.provider.broadcastTransaction(tx);
        
        // 等待确认
        const receipt = await this.waitForTransaction(
            response.hash,
            options?.timeout || 60000
        );
        
        return receipt;
    }
    
    // 监听事件
    subscribe<T>(
        address: string,
        abi: ethers.InterfaceAbi,
        eventName: string,
        filter?: ethers.ContractEventPayload,
        callback: (event: T) => void
    ): () => void {
        const contract = new ethers.Contract(address, abi, this.provider);
        const listener = (...args: any[]) => {
            callback(args[0]);
        };
        
        contract.on(eventName, listener);
        
        // 返回取消订阅函数
        return () => {
            contract.off(eventName, listener);
        };
    }
    
    // nonce 管理
    private async getNonce(): Promise<number> {
        const key = `${this.wallet.address}_${this.chainId}`;
        let nonce = this.nonceCache.get(key);
        
        if (nonce === undefined) {
            nonce = await this.provider.getTransactionCount(this.wallet.address);
        } else {
            nonce++;
        }
        
        this.nonceCache.set(key, nonce);
        return nonce;
    }
    
    // 等待交易确认
    private async waitForTransaction(
        hash: string,
        timeout: number
    ): Promise<ethers.TransactionReceipt> {
        const startTime = Date.now();
        
        while (Date.now() - startTime < timeout) {
            const receipt = await this.provider.getTransactionReceipt(hash);
            
            if (receipt && receipt.confirmations() >= 1) {
                // 更新 nonce 缓存
                if (receipt.status === 1) {
                    const key = `${this.wallet.address}_${this.chainId}`;
                    this.nonceCache.set(key, receipt.nonce);
                }
                return receipt;
            }
            
            await new Promise(resolve => setTimeout(resolve, 1000));
        }
        
        throw new BlockchainError(`Transaction timeout: ${hash}`);
    }
}

// 错误处理
class BlockchainError extends Error {
    constructor(
        message: string,
        public cause: any
    ) {
        super(message);
        this.name = 'BlockchainError';
    }
}
```

## 11. 总结

1. **中间层必要性**：RPC 直接调用复杂，中间层封装提高复用性
2. **核心功能**：ABI 编解码、交易管理、事件订阅、错误处理
3. **架构设计**：分层解耦，Agent 专注决策，适配层专注链上交互
4. **技术选型**：推荐 viem（轻量）或 ethers.js（功能全）
5. **安全要点**：私钥管理、nonce 控制、gas 估算、多 RPC 备份
