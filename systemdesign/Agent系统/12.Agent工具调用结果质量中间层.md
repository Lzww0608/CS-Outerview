# Agent 工具调用结果质量保障中间层设计

## 1. 问题背景

Agent 在调用工具时，可能遇到工具返回成功但结果语义不完整的情况，模型容易误判为完整信息。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  问题场景：                                                 │
│                                                             │
│  工具调用成功 ──► 返回结果 ──► 模型误判为完整            │
│                                                             │
│  示例：                                                    │
│  工具：获取用户订单列表                                    │
│  返回：[{"id": 1, "status": "shipped"}, ...]            │
│  问题：只返回了第一页，模型误以为全部订单                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 分页截断 | 只返回部分结果 |
| 字段缺失 | 关键字段为空 |
| 长度限制 | 超长被截断 |
| 格式异常 | 返回格式不符合预期 |

---

## 3. 影响范围

- Agent 回答准确性
- 工具调用可靠性
- 用户满意度

---

## 4. 原因分析

### 4.1 语义不完整的原因

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  语义不完整的常见原因：                                     │
│                                                             │
│  1. 分页限制                                              │
│     • API 返回第一页/前 N 条                               │
│     • 后续数据被截断                                      │
│                                                             │
│  2. 字段限制                                              │
│     • API 设置了返回字段白名单                            │
│     • 敏感字段被过滤                                      │
│                                                             │
│  3. 长度限制                                              │
│     • API 响应体大小限制                                  │
│     • JSON 截断                                          │
│                                                             │
│  4. 服务端策略                                            │
│     • 限流返回部分数据                                    │
│     • 权限级别限制                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 中间层架构

```python
class ToolResultMiddleware:
    """
    工具调用结果质量保障中间层
    """
    
    def __init__(self):
        self.analyzers = [
            CompletenessAnalyzer(),      # 完整性分析
            SchemaValidator(),           # 模式验证
            SemanticChecker(),           # 语义检查
            QualityScorer()             # 质量评分
        ]
    
    async def process(self, tool_name, raw_result):
        """
        处理工具返回结果
        """
        # 1. 基础结构检查
        if not raw_result.get('success'):
            return self.wrap_result(raw_result, status='failed')
        
        # 2. 多维度分析
        analysis = await self.analyze(raw_result, tool_name)
        
        # 3. 构建带有元信息的结果
        wrapped = self.wrap_result(raw_result, analysis)
        
        # 4. 判断是否需要补充
        if analysis.requires_completion():
            wrapped['action'] = 'need_more'
            wrapped['hint'] = analysis.get_hint()
        else:
            wrapped['action'] = 'proceed'
        
        return wrapped
    
    async def analyze(self, result, tool_name):
        """多维度分析"""
        analysis_result = AnalysisResult()
        
        for analyzer in self.analyzers:
            await analyzer.analyze(result, tool_name, analysis_result)
        
        return analysis_result
```

### 5.2 完整性分析器

```python
class CompletenessAnalyzer:
    """
    完整性分析器：检测结果是否完整
    """
    
    def __init__(self):
        self.completeness_rules = {
            'get_orders': {
                'type': 'pagination',
                'check_fields': ['has_more', 'total', 'next_cursor'],
                'data_field': 'orders'
            },
            'get_user_info': {
                'type': 'schema',
                'required_fields': ['id', 'name', 'email']
            },
            'search_products': {
                'type': 'size_limit',
                'max_size': 100,
                'check_truncation': True
            }
        }
    
    async def analyze(self, result, tool_name, analysis_result):
        """分析结果完整性"""
        rule = self.completeness_rules.get(tool_name)
        if not rule:
            return
        
        if rule['type'] == 'pagination':
            self._check_pagination(result, rule, analysis_result)
        elif rule['type'] == 'schema':
            self._check_schema(result, rule, analysis_result)
        elif rule['type'] == 'size_limit':
            self._check_size_limit(result, rule, analysis_result)
    
    def _check_pagination(self, result, rule, analysis_result):
        """检查分页完整性"""
        data = result.get(rule['data_field'], [])
        
        # 检查分页指示器
        has_indicator = any(
            result.get(f) is not None 
            for f in rule['check_fields']
        )
        
        if not has_indicator and len(data) > 0:
            # 缺少分页指示器，可能不完整
            analysis_result.add_issue({
                'type': 'missing_pagination_indicator',
                'severity': 'warning',
                'message': '缺少分页指示器，结果可能不完整',
                'suggestion': '建议使用游标或检查是否有更多数据'
            })
        
        # 检查是否标记了"更多"
        if result.get('has_more') or result.get('total'):
            analysis_result.set_flag('may_have_more', True)
    
    def _check_size_limit(self, result, rule, analysis_result):
        """检查大小限制"""
        data_field = rule.get('data_field', 'data')
        data = result.get(data_field, [])
        
        if len(data) >= rule['max_size'] and rule.get('check_truncation'):
            analysis_result.add_issue({
                'type': 'result_truncated',
                'severity': 'warning',
                'message': f'结果达到上限 {rule["max_size"]}，可能被截断',
                'suggestion': '建议分页获取完整数据'
            })
            analysis_result.set_flag('may_have_more', True)
```

### 5.3 语义检查器

```python
class SemanticChecker:
    """
    语义检查器：检测返回内容的语义合理性
    """
    
    def __init__(self):
        self.semantic_rules = {
            'get_user_orders': self._check_orders,
            'search_products': self._check_products,
            'get_balance': self._check_balance
        }
    
    async def analyze(self, result, tool_name, analysis_result):
        """进行语义检查"""
        checker = self.semantic_rules.get(tool_name)
        if checker:
            await checker(result, analysis_result)
    
    async def _check_orders(self, result, analysis_result):
        """检查订单语义合理性"""
        orders = result.get('orders', [])
        
        for order in orders:
            # 检查订单状态是否合理
            status = order.get('status')
            if status == 'completed' and not order.get('completed_at'):
                analysis_result.add_issue({
                    'type': 'inconsistent_status',
                    'severity': 'info',
                    'message': f'订单 {order.get("id")} 状态为已完成但无完成时间'
                })
            
            # 检查金额是否合理
            amount = order.get('amount', 0)
            if amount < 0:
                analysis_result.add_issue({
                    'type': 'invalid_amount',
                    'severity': 'error',
                    'message': f'订单 {order.get("id")} 金额为负数'
                })
    
    async def _check_balance(self, result, analysis_result):
        """检查余额语义"""
        balance = result.get('balance')
        
        if balance is not None:
            # 检查是否为合理数值
            if balance < 0:
                analysis_result.add_issue({
                    'type': 'negative_balance',
                    'severity': 'error',
                    'message': '余额为负数，可能数据异常'
                })
            
            # 检查是否包含货币单位
            if 'currency' not in result:
                analysis_result.add_issue({
                    'type': 'missing_currency',
                    'severity': 'warning',
                    'message': '缺少货币单位标注'
                })
```

### 5.4 质量评分器

```python
class QualityScorer:
    """
    工具调用结果质量评分器
    """
    
    def __init__(self):
        self.weights = {
            'completeness': 0.4,
            'semantic': 0.3,
            'schema': 0.3
        }
    
    def calculate_score(self, analysis_result):
        """
        计算综合质量分数
        
        返回：
        - score: 0-1 的质量分数
        - level: high/medium/low
        - recommendations: 改进建议
        """
        scores = {}
        
        # 完整性得分
        if analysis_result.has_flag('may_have_more'):
            scores['completeness'] = 0.5
        else:
            scores['completeness'] = 1.0 - len(analysis_result.issues) * 0.1
        
        # 语义得分
        error_count = sum(
            1 for issue in analysis_result.issues 
            if issue['severity'] == 'error'
        )
        scores['semantic'] = max(0, 1 - error_count * 0.3)
        
        # 模式得分
        if analysis_result.has_flag('schema_invalid'):
            scores['schema'] = 0.3
        elif analysis_result.has_flag('schema_warning'):
            scores['schema'] = 0.7
        else:
            scores['schema'] = 1.0
        
        # 综合得分
        total_score = sum(
            scores[key] * self.weights[key] 
            for key in self.weights
        )
        
        # 确定级别
        if total_score >= 0.8:
            level = 'high'
        elif total_score >= 0.5:
            level = 'medium'
        else:
            level = 'low'
        
        return {
            'score': round(total_score, 2),
            'level': level,
            'breakdown': scores,
            'recommendations': analysis_result.get_recommendations()
        }
```

### 5.5 Agent 集成

```python
class ToolAwareAgent:
    """
    支持中间层的 Agent
    """
    
    def __init__(self, llm, tool_registry):
        self.llm = llm
        self.tool_registry = tool_registry
        self.middleware = ToolResultMiddleware()
    
    async def execute_tool(self, tool_name, params):
        """执行工具并处理结果"""
        # 1. 调用工具
        raw_result = await self.tool_registry.call(tool_name, params)
        
        # 2. 通过中间层处理
        wrapped_result = await self.middleware.process(tool_name, raw_result)
        
        # 3. 根据处理结果决定行动
        if wrapped_result['action'] == 'need_more':
            # 需要补充数据
            hint = wrapped_result['hint']
            
            if hint.get('type') == 'pagination':
                # 循环获取完整数据
                all_data = await self._fetch_all_pages(tool_name, params)
                wrapped_result['data'] = all_data
                wrapped_result['action'] = 'proceed'
        
        # 4. 生成回答时附带质量信息
        if wrapped_result['action'] == 'proceed':
            quality = wrapped_result.get('quality')
            answer = self.generate_answer(wrapped_result, quality)
        else:
            answer = self.generate_answer_with_warning(wrapped_result)
        
        return answer
    
    async def _fetch_all_pages(self, tool_name, params):
        """获取所有分页数据"""
        all_data = []
        cursor = None
        
        while True:
            page_params = {**params}
            if cursor:
                page_params['cursor'] = cursor
            
            result = await self.tool_registry.call(tool_name, page_params)
            
            if tool_name == 'get_orders':
                all_data.extend(result.get('orders', []))
                cursor = result.get('next_cursor')
            elif tool_name == 'search_products':
                all_data.extend(result.get('products', []))
                cursor = result.get('next_cursor')
            
            if not cursor:
                break
        
        return all_data
    
    def generate_answer(self, result, quality):
        """生成回答"""
        # 根据质量决定回答方式
        if quality['level'] == 'high':
            return self._generate_straightforward(result)
        elif quality['level'] == 'medium':
            return self._generate_qualified(result, quality)
        else:
            return self._generate_cautious(result, quality)
```

## 11. 总结

1. **问题本质**：工具调用技术成功但返回语义不完整，模型难以判断
2. **核心方案**：中间层进行多维度分析（完整性、语义、模式、质量评分）
3. **关键组件**：完整性分析器、语义检查器、质量评分器
4. **处理策略**：自动补充、分级回答、附带质量信息
5. **实施要点**：规则配置 + 分析器组合 + Agent 集成
