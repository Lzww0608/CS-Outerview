# Agent 追问与自推理决策机制

## 1. 问题背景

Agent 在处理用户问题时，需要在"追问用户"和"自行推理"之间做出选择。这个决策直接影响用户体验和任务完成效率。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Agent 决策场景：                                          │
│                                                             │
│  用户："帮我订票"                                        │
│                                                             │
│  选项 A - 追问：                                          │
│  Agent："请问您要订哪天的票？"                          │
│                                                             │
│  选项 B - 自推理：                                       │
│  Agent："根据您最近的出行记录，本周五去上海的票..."      │
│                                                             │
│  何时追问？何时自推理？                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 过度追问 | 信息足够但仍追问，骚扰用户 |
| 过早推理 | 信息不足强行回答，错误率高 |
| 决策不稳定 | 同一问题时而追问时而自推 |
| 用户困惑 | 不清楚 Agent 需要什么信息 |

---

## 3. 影响范围

- 对话式 Agent 系统
- 任务型 Agent
- 个人助手应用

---

## 4. 原因分析

### 4.1 追问 vs 自推理 的权衡

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  追问的代价：                                             │
│  • 增加对话轮次                                          │
│  • 打断用户思路                                          │
│  • 可能让用户觉得 Agent 能力不足                         │
│                                                             │
│  自推理的代价：                                          │
│  • 可能猜错用户意图                                      │
│  • 信息不足时回答质量低                                   │
│  • 用户纠正成本更高                                      │
│                                                             │
│  决策原则：                                               │
│  • 追问成本 < 纠正成本 → 追问                           │
│  • 推理置信度高 → 自推理                                 │
│  • 追问成本高 → 自推理                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 置信度驱动的决策

```python
class ConfidenceBasedDecider:
    """
    基于置信度的决策器
    """
    
    def __init__(self):
        self.thresholds = {
            "ask_user": 0.6,    # 置信度 < 0.6，追问
            "try_inference": 0.8,  # 置信度 > 0.8，自推理
            "uncertain": 0.7     # 置信度在之间，混合策略
        }
    
    def decide(self, context):
        """
        决定是追问还是自推理
        
        Args:
            context: {
                "confidence": float,        # 推理置信度
                "missing_info": list,       # 缺失信息列表
                "inference_cost": float,    # 推理成本
                "clarification_cost": float, # 追问成本
                "user_profile": dict         # 用户画像
            }
        
        Returns:
            decision: {
                "action": "ask_user" | "infer" | "partial_infer",
                "reasoning": str,
                "next_step": dict
            }
        """
        confidence = context["confidence"]
        
        # 高置信度：直接自推理
        if confidence >= self.thresholds["try_inference"]:
            return self._decide_infer(context)
        
        # 低置信度：追问
        if confidence < self.thresholds["ask_user"]:
            return self._decide_ask_user(context)
        
        # 中等置信度：混合策略
        return self._decide_partial_infer(context)
    
    def _decide_infer(self, context):
        """高置信度：自推理"""
        return {
            "action": "infer",
            "reasoning": f"置信度 {context['confidence']:.2f} >= {self.thresholds['try_inference']}",
            "next_step": {
                "type": "generate_response",
                "include_confidence": True
            }
        }
    
    def _decide_ask_user(self, context):
        """低置信度：追问"""
        missing = context["missing_info"]
        
        return {
            "action": "ask_user",
            "reasoning": f"置信度 {context['confidence']:.2f} < {self.thresholds['ask_user']}",
            "next_step": {
                "type": "clarify",
                "missing_fields": missing,
                "suggested_questions": self._generate_questions(missing)
            }
        }
    
    def _decide_partial_infer(self, context):
        """中等置信度：部分推理 + 确认"""
        return {
            "action": "partial_infer",
            "reasoning": f"置信度 {context['confidence']:.2f} 在不确定区间",
            "next_step": {
                "type": "infer_with_confirmation",
                "inference": context["current_inference"],
                "confirm_fields": context["uncertain_fields"]
            }
        }
```

### 5.2 信息缺失检测

```python
class InformationAnalyzer:
    """
    信息缺失分析器
    """
    
    def __init__(self, schema_registry):
        self.schema_registry = schema_registry
    
    def analyze(self, user_input, required_schema):
        """
        分析用户输入是否满足要求
        
        Returns:
            analysis: {
                "is_complete": bool,
                "missing_fields": list,
                "confidence": float,
                "suggestions": list
            }
        """
        required = required_schema["required"]
        optional = required_schema.get("optional", [])
        
        # 提取用户输入中的信息
        extracted = self._extract_entities(user_input)
        
        missing_required = []
        missing_optional = []
        
        for field in required:
            if field not in extracted:
                missing_required.append(field)
        
        for field in optional:
            if field not in extracted:
                missing_optional.append(field)
        
        # 计算完整度
        completeness = len(extracted) / (len(required) + len(optional))
        
        # 判断是否需要追问
        # 关键字段缺失 → 必须追问
        # 非关键字段缺失 → 可自推理
        is_complete = len(missing_required) == 0
        
        return {
            "is_complete": is_complete,
            "missing_required": missing_required,
            "missing_optional": missing_optional,
            "completeness": completeness,
            "suggestions": self._generate_suggestions(missing_required)
        }
    
    def _extract_entities(self, text):
        """从文本中提取实体"""
        # 简化实现
        return {}
```

class UserPreferenceLearner:
    """
    用户偏好学习器
    """
    
    def __init__(self):
        self.preference_model = None
    
    def should_auto_infer(self, user_id):
        """
        判断用户是否偏好自推理
        """
        # 获取用户历史交互
        history = self.get_interaction_history(user_id)
        
        # 分析用户行为
        auto_infer_count = sum(1 for h in history if h.get("action") == "auto_infer")
        clarify_count = sum(1 for h in history if h.get("action") == "clarify")
        
        total = auto_infer_count + clarify_count
        if total == 0:
            return None  # 无历史，返回 None 使用默认策略
        
        ratio = auto_infer_count / total
        
        if ratio > 0.7:
            return True   # 用户偏好自推理
        elif ratio < 0.3:
            return False  # 用户偏好追问
        else:
            return None   # 无明显偏好
    
    def record_interaction(self, user_id, interaction):
        """记录交互用于学习"""

        pass

### 5.4 成本效益分析

```python
class CostBenefitAnalyzer:
    """
    成本效益分析器
    """
    
    def __init__(self):
        self.costs = {
            "clarification": {
                "time_cost": 2,        # 平均耗时（轮）
                "user_frustration": 0.3,  # 用户挫败感
                "opportunity_cost": 0.2  # 错失机会
            },
            "inference_error": {
                "correction_cost": 5,   # 纠正成本
                "trust_impact": 0.4     # 信任影响
            }
        }
    
    def should_clarify(self, context):
        """
        成本效益分析决定是否追问
        
        规则：
        如果 追问成本 < 推理错误成本 → 追问
        """
        # 计算追问成本
        clarify_cost = self._calculate_clarify_cost(context)
        
        # 计算推理错误成本
        inference_error_cost = self._calculate_inference_error_cost(context)
        
        # 决策
        if clarify_cost < inference_error_cost:
            return {
                "decision": "clarify",
                "reasoning": f"追问成本 {clarify_cost:.2f} < 推理错误成本 {inference_error_cost:.2f}"
            }
        else:
            return {
                "decision": "infer",
                "reasoning": f"推理成本更低，尝试自推理"
            }
    
    def _calculate_clarify_cost(self, context):
        """计算追问成本"""
        base_cost = self.costs["clarification"]["time_cost"]
        
        # 根据缺失信息数量调整
        missing_count = len(context.get("missing_info", []))
        
        # 根据用户偏好调整
        if context.get("user_prefers_infer"):
            base_cost *= 1.5  # 用户不喜欢被追问
        
        return base_cost + missing_count * 0.5
    
    def _calculate_inference_error_cost(self, context):
        """计算推理错误成本"""
        base_cost = self.costs["inference_error"]["correction_cost"]
        
        # 根据置信度调整
        confidence = context.get("confidence", 0.5)
        error_probability = 1 - confidence
        
        return base_cost * error_probability
```

### 5.5 完整决策系统

```python
class AskVsInferDecider:
    """
    追问 vs 自推理 完整决策系统
    """
    
    def __init__(self):
        self.confidence_decider = ConfidenceBasedDecider()
        self.info_analyzer = InformationAnalyzer()
        self.preference_learner = UserPreferenceLearner()
        self.cost_analyzer = CostBenefitAnalyzer()
    
    def decide(self, user_input, task_schema, user_id=None):
        """
        综合决策：追问还是自推理
        """
        # 1. 信息完整性分析
        info_analysis = self.info_analyzer.analyze(user_input, task_schema)
        
        # 2. 推理置信度评估
        confidence = self._evaluate_confidence(
            user_input, 
            info_analysis
        )
        
        # 3. 用户偏好（如果有）
        user_prefers = None
        if user_id:
            user_prefers = self.preference_learner.should_auto_infer(user_id)
        
        # 4. 成本效益分析
        context = {
            "confidence": confidence,
            "missing_info": info_analysis["missing_required"],
            "user_prefers_infer": user_prefers
        }
        
        cost_decision = self.cost_analyzer.should_clarify(context)
        
        # 5. 综合决策
        if user_prefers is not None:
            # 用户有明确偏好，优先遵循
            return {
                "action": "infer" if user_prefers else "ask_user",
                "reasoning": f"遵循用户偏好: {'自推理' if user_prefers else '追问'}",
                "confidence": confidence,
                "info_analysis": info_analysis
            }
        
        # 使用置信度和成本效益
        return {
            **cost_decision,
            "confidence": confidence,
            "info_analysis": info_analysis
        }
    
    def _evaluate_confidence(self, user_input, info_analysis):
        """评估推理置信度"""
        # 基础置信度
        base_confidence = info_analysis["completeness"]
        
        # 信息量置信度
        if info_analysis["is_complete"]:
            base_confidence += 0.2
        
        # 惩罚缺失关键信息
        base_confidence -= len(info_analysis["missing_required"]) * 0.15
        
        return max(0, min(1, base_confidence))
```

## 11. 总结

1. **核心决策**：信息充足度、推理置信度、追问成本、用户偏好
2. **决策原则**：追问成本 < 推理错误成本 → 追问
3. **实现方案**：置信度阈值 + 成本效益分析 + 用户偏好学习
4. **关键参数**：追问阈值 0.6、自推理阈值 0.8
5. **持续优化**：收集反馈，学习用户偏好，A/B 测试调优
