# Agent 规划器路径震荡问题与解决

## 1. 问题背景

Agent 规划器在执行多步任务时，可能出现"每一步都重新规划"导致路径震荡的问题——即在多个可行路径之间反复横跳，无法稳定收敛。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  路径震荡问题：                                            │
│                                                             │
│  目标: A → B → C → D                                     │
│                                                             │
│  震荡表现：                                                │
│  A → B → A → B → C → B → A → ...                       │
│                                                             │
│  原因：每步重新规划，缺乏全局视野和路径记忆              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 规划循环 | 反复回到相同状态 |
| 路径不稳定 | 每次执行路径不同 |
| 资源浪费 | 重复执行已完成的步骤 |
| 效率低下 | 任务完成时间不可预期 |

---

## 3. 影响范围

- 多步复杂任务执行
- 长期运行的 Agent
- 资源敏感场景

---

## 4. 原因分析

### 4.1 震荡产生原因

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  路径震荡的根源：                                          │
│                                                             │
│  1. 缺乏全局规划                                          │
│     • 只看当前状态和下一步                                  │
│     • 缺少完整路径规划                                      │
│                                                             │
│  2. 缺乏路径记忆                                          │
│     • 不记得已走过的路径                                    │
│     • 无法识别"回到起点"                                    │
│                                                             │
│  3. 过度响应环境变化                                       │
│     • 环境微小变化触发重新规划                              │
│     • 缺少置信度阈值                                        │
│                                                             │
│  4. 探索与利用失衡                                         │
│     • 过度探索新路径                                        │
│     • 缺乏利用已有知识的机制                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 问题建模

```python
class PathOscillationAnalysis:
    """
    路径震荡问题分析
    """
    
    def __init__(self):
        self.states_visited = []  # 访问过的状态序列
        self.transitions = {}     # 状态转换记录
    
    def detect_oscillation(self, state_sequence):
        """
        检测震荡模式
        
        震荡特征：
        1. 状态序列中出现循环
        2. 短周期重复
        3. 转换次数过多
        """
        n = len(state_sequence)
        
        # 检测短周期循环
        for period in range(2, n // 2):
            is_oscillating = True
            for i in range(n - period):
                if state_sequence[i] != state_sequence[i + period]:
                    is_oscillating = False
                    break
            
            if is_oscillating:
                return True, period
        
        return False, 0
    
    def calculate_stability(self, state_sequence):
        """计算路径稳定性指标"""
        # 震荡比率：重复访问的状态数 / 总状态数
        unique_states = len(set(state_sequence))
        total_visits = len(state_sequence)
        
        oscillation_ratio = 1 - (unique_states / total_visits)
        
        return oscillation_ratio
```

## 5. 解决方案

### 5.1 方案一：路径记忆与约束

```python
class PathAwarePlanner:
    """
    带路径记忆的规划器：避免震荡
    """
    
    def __init__(self, max_history=50):
        self.execution_history = []      # 执行历史
        self.planned_path = []          # 已规划的路径
        self.forbidden_transitions = set()  # 禁止的转换
        self.max_history = max_history
    
    def plan(self, current_state, goal_state, available_actions):
        """
        规划下一步，带路径约束
        """
        # 1. 检查是否在循环中
        if self.is_in_loop(current_state):
            # 在循环中，强制选择不同路径
            return self.break_loop(current_state, available_actions)
        
        # 2. 过滤禁止的转换
        valid_actions = self.filter_forbidden_actions(
            current_state, available_actions
        )
        
        # 3. 标准规划
        next_action = self.standard_plan(
            current_state, goal_state, valid_actions
        )
        
        # 4. 记录执行历史
        self.execution_history.append({
            'state': current_state,
            'action': next_action,
            'timestamp': time.time()
        })
        
        # 5. 更新已规划路径
        self.planned_path.append(current_state)
        
        # 6. 添加禁止的逆向转换
        if len(self.planned_path) >= 2:
            prev_state = self.planned_path[-2]
            self.forbidden_transitions.add((current_state, prev_state))
        
        return next_action
    
    def is_in_loop(self, current_state):
        """检测是否在循环中"""
        if len(self.execution_history) < 4:
            return False
        
        # 检查最近的状态序列是否形成循环
        recent = self.execution_history[-4:]
        recent_states = [h['state'] for h in recent]
        
        # 检测 A-B-A-B 模式
        if (recent_states[0] == recent_states[2] and
            recent_states[1] == recent_states[3]):
            return True
        
        return False
    
    def filter_forbidden_actions(self, state, actions):
        """过滤禁止的动作"""
        valid = []
        for action in actions:
            next_state = self.simulate(state, action)
            
            # 禁止直接回到上一个状态
            if len(self.planned_path) > 0:
                prev_state = self.planned_path[-1]
                if next_state == prev_state:
                    continue
            
            # 禁止导致循环的动作
            transition = (state, next_state)
            if transition in self.forbidden_transitions:
                continue
            
            valid.append(action)
        
        return valid if valid else actions  # 至少返回一个动作
```

### 5.2 方案二：分层规划

```python
class HierarchicalPlanner:
    """
    分层规划器：从粗粒度到细粒度
    """
    
    def __init__(self):
        self.high_level_plan = []    # 高层规划
        self.current_htn_index = 0   # 当前 HTN 索引
    
    def high_level_plan(self, start, goal):
        """
        高层规划：确定关键里程碑
        
        例如：A → B → C → D
        细分为：
        阶段1: A → B
        阶段2: B → C
        阶段3: C → D
        """
        milestones = self.decompose_task(start, goal)
        self.high_level_plan = milestones
        self.current_htn_index = 0
        
        return milestones
    
    def execute_high_level_step(self, current_state):
        """
        执行高层规划的一个阶段
        """
        if self.current_htn_index >= len(self.high_level_plan):
            return None, True  # 规划完成
        
        current_goal = self.high_level_plan[self.current_htn_index]
        
        # 检查是否到达当前里程碑
        if self.reached_milestone(current_state, current_goal):
            self.current_htn_index += 1
            return None, False  # 进入下一阶段
        
        # 在当前阶段内规划
        next_action = self.low_level_plan(current_state, current_goal)
        
        return next_action, False
    
    def decompose_task(self, start, goal):
        """任务分解：返回关键里程碑"""
        # 使用领域知识或 LLM 分解
        milestones = [
            {'start': start, 'goal': 'subgoal_1'},
            {'start': 'subgoal_1', 'goal': 'subgoal_2'},
            {'start': 'subgoal_2', 'goal': goal},
        ]
        return milestones
```

### 5.3 方案三：置信度与重规划阈值

```python
class ConfidenceBasedPlanner:
    """
    基于置信度的规划器：控制重规划频率
    """
    
    def __init__(self, confidence_threshold=0.8, replan_cooldown=3):
        self.current_plan = None
        self.plan_confidence = 1.0
        self.confidence_threshold = confidence_threshold
        self.replan_cooldown = replan_cooldown  # 重规划冷却步数
        self.steps_since_replan = 0
        self.execution_failures = 0
    
    def should_replan(self, observation, expected_observation):
        """
        判断是否需要重规划
        
        触发条件：
        1. 置信度低于阈值
        2. 超出冷却期
        3. 执行失败
        """
        # 更新置信度
        self.update_confidence(observation, expected_observation)
        
        self.steps_since_replan += 1
        
        # 检查是否触发重规划
        if self.execution_failures > 2:
            return True
        
        if (self.plan_confidence < self.confidence_threshold and
            self.steps_since_replan > self.replan_cooldown):
            return True
        
        return False
    
    def update_confidence(self, actual, expected):
        """更新规划置信度"""
        if actual == expected:
            self.plan_confidence = min(1.0, self.plan_confidence * 1.1)
        else:
            self.plan_confidence *= 0.7
            self.execution_failures += 1
        
        # 自然衰减
        self.plan_confidence *= 0.99
```

### 5.4 方案四：图搜索与最短路径

```python
class GraphSearchPlanner:
    """
    基于图搜索的规划器：保证最优路径
    """
    
    def __init__(self):
        self.state_graph = {}   # 状态图
        self.path_cache = {}    # 路径缓存
    
    def build_state_graph(self, states, transitions):
        """构建状态图"""
        self.state_graph = {s: [] for s in states}
        for src, dst in transitions:
            if src in self.state_graph:
                self.state_graph[src].append(dst)
    
    def plan_with_dijkstra(self, start, goal):
        """
        Dijkstra 算法：找到最短路径
        """
        import heapq
        
        # 距离表
        distances = {start: 0}
        previous = {start: None}
        visited = set()
        
        pq = [(0, start)]
        
        while pq:
            current_dist, current = heapq.heappop(pq)
            
            if current in visited:
                continue
            visited.add(current)
            
            if current == goal:
                break
            
            for neighbor in self.state_graph.get(current, []):
                if neighbor in visited:
                    continue
                
                new_dist = current_dist + 1  # 假设每步 cost=1
                
                if neighbor not in distances or new_dist < distances[neighbor]:
                    distances[neighbor] = new_dist
                    previous[neighbor] = current
                    heapq.heappush(pq, (new_dist, neighbor))
        
        # 重建路径
        return self.reconstruct_path(previous, start, goal)
    
    def reconstruct_path(self, previous, start, goal):
        """重建路径"""
        path = []
        current = goal
        
        while current is not None:
            path.append(current)
            current = previous.get(current)
        
        path.reverse()
        
        if path and path[0] != start:
            return []  # 无法到达
        
        return path
```

## 10. 验证方式

```python
def test_anti_oscillation():
    """测试防震荡机制"""
    
    planner = PathAwarePlanner(max_history=50)
    
    # 模拟震荡场景
    states = ['A', 'B', 'C', 'D']
    actions = ['move_right', 'move_left', 'move_up', 'move_down']
    
    oscillation_count = 0
    for step in range(100):
        current = states[step % 4]
        goal = 'D'
        
        action = planner.plan(current, goal, actions)
        
        # 检测震荡
        if planner.is_in_loop(current):
            oscillation_count += 1
    
    # 验证震荡率降低
    assert oscillation_count < 10, f"震荡过多: {oscillation_count}"
    print(f"✅ 震荡率: {oscillation_count}%")
```

## 11. 总结

1. **震荡根源**：缺乏全局规划、路径记忆和环境变化过度响应
2. **核心策略**：路径记忆约束、分层规划、置信度阈值、图搜索
3. **推荐方案**：组合使用路径记忆 + 置信度控制
4. **关键参数**：历史长度、置信度阈值、重规划冷却期
5. **验证重点**：震荡率检测、路径稳定性、任务完成率
