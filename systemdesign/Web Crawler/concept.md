**Web Crawler**（网络爬虫），通常也被称为**网络蜘蛛**（Spider）或**网络机器人**（Bot），是一种按照一定的规则，自动地在互联网上抓取信息的程序或脚本。

简单来说，你可以把它想象成一只不知疲倦的“电子蜘蛛”，它顺着互联网这张“大网”（World Wide Web），从一个网页爬到另一个网页，把沿途看到的数据（文字、图片、视频等）“搬运”回来。

以下是关于 Web Crawler 的详细解析：

------

### 1. 它是如何工作的？（基本原理）

网络爬虫的工作流程通常是一个循环的过程：

1. **种子 URL (Seed URLs)：** 爬虫首先需要一个起点，即一组初始的网页地址。
2. **发送请求 (Request)：** 爬虫向这些 URL 所在的服务器发送 HTTP 请求（就像你的浏览器访问网站一样）。
3. **获取响应 (Response)：** 服务器返回网页内容（通常是 HTML 代码）。
4. **解析与提取 (Parse & Extract)：**
   - **提取数据：** 爬虫分析 HTML，提取出有用的信息（如标题、正文、价格）。
   - **发现新链接：** 爬虫在页面中寻找指向其他页面的链接（URL）。
5. **入队 (Queue)：** 将新发现的链接放入待爬取的队列中。
6. **重复 (Loop)：** 爬虫从队列中取出下一个 URL，重复步骤 2-5，直到满足停止条件（如爬够了数量、时间到了、或者爬完了整个网站）。

### 1.1 如何解析 HTML、JSON 和 XML

爬虫解析不是简单字符串匹配，真实项目里要按内容类型选择解析器。

#### HTML 解析

HTML 页面通常结构不完全规范，应该使用容错能力强的 HTML parser，再用 CSS Selector、XPath 或 DOM API 提取字段。

常见步骤：

1. 根据响应头和页面 meta 判断编码，统一转成 UTF-8。
2. 用 HTML parser 构建 DOM 树。
3. 用 selector 提取标题、正文、链接、时间、作者等字段。
4. 对相对链接做 URL 规范化，去掉无意义参数，处理 canonical URL。
5. 对正文做去噪，过滤导航栏、广告、页脚和推荐列表。

#### JSON 解析

很多现代页面的数据来自接口返回 JSON。处理 JSON 时应优先使用结构化解析：

1. 根据字段路径提取数据，例如 `data.items[].title`。
2. 对字段缺失、类型变化、数组为空做兼容。
3. 大 JSON 可以用流式解析，避免一次性载入内存。
4. 接口数据要记录 schema 版本或样例，便于字段变化后告警。

#### XML 解析

XML 常见于 RSS、站点地图、老系统接口。解析方式分两类：

1. DOM：一次性构建树，代码简单，适合小文件。
2. SAX/StAX：流式读取，内存占用低，适合大文件。

XML 要注意命名空间、实体解析和 XXE 安全问题。默认不要允许解析外部实体，避免服务端请求伪造或本地文件泄露。

### 1.2 去重和调度

爬虫规模变大后，URL 队列不能只用一个普通队列。

常见设计：

1. **URL 去重**：规范化 URL 后用 hash set、Bloom Filter 或分布式 KV 去重。
2. **内容去重**：对正文做 simhash/minhash，识别镜像页、转载页和重复内容。
3. **站点限速**：按 host 维度控制并发和访问间隔，避免压垮对方服务。
4. **优先级队列**：重要站点、深度更浅、更新更频繁的 URL 优先抓。
5. **失败重试**：区分 4xx、5xx、超时、DNS 错误，设置最大重试次数和退避。

工程上还要打通抓取、解析、存储和索引的监控：抓取成功率、解析成功率、字段缺失率、队列堆积、重复率和单站点错误率都应该可观测。

### 2. 爬虫的主要用途

- **搜索引擎 (Search Engines)：**
  - 这是最著名的应用（如 Google、Baidu）。它们派出大规模的爬虫遍布全网，把网页内容抓取下来建立索引，这样你才能搜索到内容。
- **数据挖掘与分析：**
  - **价格监控：** 电商公司爬取竞争对手的价格。
  - **舆情监控：** 爬取社交媒体上的评论，分析用户对品牌的看法。
  - **金融数据：** 爬取股票、汇率等实时数据。
- **AI 模型训练：**
  - 像 ChatGPT 这样的大语言模型，其训练数据大部分来自于爬虫抓取的互联网文本。
- **网站监测与测试：**
  - 检查网站是否有死链（404 错误）或 SEO 问题。

### 3. 核心概念与“潜规则”

在爬虫领域，有几个非常重要的概念：

- **robots.txt：**
  - 这是网站管理员放在网站根目录下的一个协议文件。它告诉爬虫：“哪些页面你可以爬，哪些页面你不可以爬”。
  - *遵守 robots.txt 是爬虫的基本礼仪（Politeness）。*
- **User-Agent (用户代理)：**
  - 爬虫在访问网站时表明身份的“名片”。合法的爬虫（如 Googlebot）会明确表明身份，而恶意爬虫可能会伪装成普通浏览器（如 Chrome）。
- **爬取速率 (Rate Limiting)：**
  - 礼貌的爬虫会控制访问频率，避免在一秒钟内发送成千上万次请求，从而导致对方服务器崩溃（这被称为 DoS 攻击）。

### 4. Crawler (爬虫) vs. Scraper (刮削器)

虽然这两个词经常混用，但在技术上有细微区别：

- **Crawler (爬虫)：** 重点在于**“游走”**和**“发现”**。它的目标是尽可能多地发现页面和链接（例如 Google 的爬虫）。
- **Scraper (数据采集器)：** 重点在于**“提取”**。它的目标是从特定页面中精确地把数据抠出来（例如只抓取亚马逊商品页面的价格和库存）。

### 5. 面临的挑战

现在的网站为了防止数据被随意抓取，会设置各种**反爬虫 (Anti-Scraping)** 机制：

- **IP 封禁：** 如果同一个 IP 访问太快，服务器会封锁该 IP。
- **验证码 (CAPTCHA)：** 弹出拼图或文字验证，确认操作者是人不是机器。
- **动态渲染 (Dynamic Rendering)：** 很多现代网站（如使用 React/Vue）的内容是靠 JavaScript 动态生成的，普通的 HTTP 请求抓不到内容，需要模拟真实的浏览器环境（如使用 Selenium 或 Puppeteer）。
