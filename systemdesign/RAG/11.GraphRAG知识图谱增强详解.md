# GraphRAG 知识图谱增强的 RAG 系统

## 1. 问题背景

GraphRAG 是微软提出的基于知识图谱增强的 RAG 系统，用于解决传统 RAG 在处理全局性、跨文档问题时的局限性。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  传统 RAG 的局限：                                        │
│                                                             │
│  1. 局部检索强，全局理解弱                                │
│     • 只能回答具体事实性问题                               │
│     • 无法回答"总结全文主题"等全局问题                    │
│                                                             │
│  2. 关系感知差                                           │
│     • 无法理解实体间的关系                                 │
│     • 缺乏语义关联推理                                     │
│                                                             │
│  GraphRAG 解决方案：                                      │
│  将知识图谱与 RAG 结合，增强全局理解能力                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 主题摘要失败 | 问"文档主要讲了什么"效果差 |
| 关系推理缺失 | 无法回答实体间关系 |
| 上下文碎片化 | 缺乏全局视角 |

---

## 3. 影响范围

- 文档理解与摘要
- 跨文档关系推理
- 复杂问答系统

## 4. 原因分析

### 4.1 传统 RAG 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  传统 RAG 流程：                                          │
│                                                             │
│  文档 → 分块 → 向量化 → 存入向量数据库                   │
│                                                             │
│  查询时：                                                  │
│  用户问题 → 向量化 → 相似度检索 → 返回 Top-K 块        │
│                                                             │
│  局限性：                                                 │
│  • 只考虑语义相似性                                      │
│  • 不考虑实体关系                                        │
│  • 无法做全局推理                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 GraphRAG 原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  GraphRAG 核心思想：                                      │
│                                                             │
│  1. 实体抽取                                             │
│     从文档中抽取实体（人名、地点、组织等）               │
│                                                             │
│  2. 关系抽取                                             │
│     抽取实体之间的关系                                    │
│                                                             │
│  3. 构建知识图谱                                         │
│     实体 + 关系 → 图结构                                 │
│                                                             │
│  4. 社区检测                                             │
│     使用图算法（如 Louvain）划分社区                      │
│                                                             │
│  5. 社区摘要                                             │
│     为每个社区生成摘要                                    │
│                                                             │
│  6. 两阶段检索                                           │
│     用户问题 → 定位社区 → 检索社区摘要 + 原始块         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 解决方案

### 5.1 GraphRAG 架构

```python
class GraphRAG:
    """
    GraphRAG 核心组件
    """
    
    def __init__(self, llm, config):
        self.llm = llm
        self.config = config
        
        # 核心组件
        self.entity_extractor = EntityExtractor(llm)
        self.relation_extractor = RelationExtractor(llm)
        self.kg_builder = KnowledgeGraphBuilder()
        self.community_detector = CommunityDetector()
        self.summarizer = CommunitySummarizer(llm)
        self.retriever = GraphRetriever(config)
    
    def index(self, documents: list):
        """
        索引阶段：构建知识图谱
        """
        # 1. 实体和关系抽取
        entities, relations = self.extract_entities_relations(documents)
        
        # 2. 构建知识图谱
        kg = self.kg_builder.build(entities, relations)
        
        # 3. 社区检测
        communities = self.community_detector.detect(kg)
        
        # 4. 生成社区摘要
        community_summaries = self.summarizer.summarize(kg, communities)
        
        # 5. 存储
        self.store(kg, community_summaries)
    
    def query(self, question: str) -> str:
        """
        查询阶段：回答问题
        """
        # 1. 全局检索：定位相关社区
        relevant_communities = self.retriever.search_communities(question)
        
        # 2. 获取社区摘要
        summaries = self.get_community_summaries(relevant_communities)
        
        # 3. 局部检索：获取原始文本块
        relevant_chunks = self.retriever.search_chunks(question)
        
        # 4. 生成回答
        answer = self.generate_answer(question, summaries, relevant_chunks)
        
        return answer
```

### 5.2 实体抽取实现

```python
class EntityExtractor:
    """
    实体抽取器
    """
    
    PROMPT = """
    从以下文本中抽取实体，并按类型分类：

    文本：{text}

    输出格式（JSON）：
    {{
        "entities": [
            {{"name": "实体名", "type": "PERSON/ORG/LOC/EVENT", "description": "描述"}}
        ]
    }}
    """
    
    def extract(self, text: str) -> list:
        """使用 LLM 抽取实体"""
        prompt = self.PROMPT.format(text=text)
        response = self.llm.generate(prompt)
        return parse_json(response)["entities"]
```

### 5.3 社区检测算法

```python
class CommunityDetector:
    """
    社区检测：使用 Louvain 算法
    """
    
    def detect(self, kg: KnowledgeGraph) -> list:
        """检测图中的社区"""
        import networkx as nx
        from community import community_louvain
        
        # 转换为 networkx 图
        G = nx.Graph()
        for node in kg.entities:
            G.add_node(node.id, **node.attributes)
        for edge in kg.relations:
            G.add_edge(edge.source, edge.target, weight=edge.weight)
        
        # Louvain 社区检测
        partition = community_louvain.best_partition(G)
        
        # 按社区分组
        communities = {}
        for node_id, community_id in partition.items():
            if community_id not in communities:
                communities[community_id] = []
            communities[community_id].append(node_id)
        
        return list(communities.values())
```

## 11. 总结

1. **核心创新**：将知识图谱引入 RAG，解决全局理解问题
2. **关键步骤**：实体抽取 → 关系抽取 → 社区检测 → 社区摘要 → 两阶段检索
3. **优势**：全局理解强、关系推理好、主题发现准
4. **劣势**：实现复杂、成本较高、依赖 LLM
5. **适用场景**：复杂文档分析、跨文档推理、多跳问答
