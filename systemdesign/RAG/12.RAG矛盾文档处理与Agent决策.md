# RAG 矛盾文档处理与 Agent 决策

## 1. 问题背景

RAG（检索增强生成）在实际应用中经常遇到召回文档相互矛盾的问题，Agent 需要具备处理这种矛盾信息的能力。

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  RAG 矛盾文档问题：                                        │
│                                                             │
│  用户问题：产品 X 的价格是多少？                         │
│                                                             │
│  召回文档：                                               │
│  Doc1: 产品 X 价格 100 元                                │
│  Doc2: 产品 X 价格 120 元（含税）                        │
│  Doc3: 产品 X 价格 80 元（促销价）                       │
│                                                             │
│  Agent 如何处理这些矛盾信息？                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 问题现象

| 现象 | 描述 |
|------|------|
| 信息冲突 | 不同文档说法矛盾 |
| 置信度低 | 模型无法判断真假 |
| 回答模糊 | 刻意回避矛盾 |
| 用户困惑 | 不知信哪个 |

---

## 3. 影响范围

- RAG 系统准确性
- Agent 回答可靠性
- 用户信任度

```text
│                                                             │

│     → 随时间变化的信息                                    │
│                                                             │
│  2. 来源不同                                              │
│     • Doc1: 官方文档                                      │
│     • Doc2: 用户评论                                      │
│     → 权威性不同                                          │
│                                                             │
│  3. 条件差异                                              │
│     • Doc1: 标准价格                                      │

│     → 未说明前提条件                                       │
│                                                             │
│  4. 错误信息                                              │
│     • Doc1: 正确信息                                      │
│     • Doc2: 错误信息                                      │

│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 Agent 处理流程

```python
class DocumentConflictAnalyzer:
    """
    文档矛盾分析器
    """
    
    def analyze(self, documents, question):
        """
        分析文档间的矛盾
        """
        conflicts = {
            'detected': False,
            'conflict_pairs': [],
            'conflict_types': [],
            'resolution_hints': []
        }
        
        # 1. 提取关键断言
        assertions = []
        for doc in documents:
            assertion = self.extract_assertion(doc, question)
            assertions.append(assertion)
        
        # 2. 检测矛盾
        for i in range(len(assertions)):
            for j in range(i + 1, len(assertions)):
                if self.are_conflicting(assertions[i], assertions[j]):
                    conflicts['detected'] = True
                    conflicts['conflict_pairs'].append((i, j))
                    conflicts['conflict_types'].append(
                        self.classify_conflict(assertions[i], assertions[j])
                    )
        
        # 3. 生成解决提示
        if conflicts['detected']:
            conflicts['resolution_hints'] = self.generate_hints(
                assertions, conflicts['conflict_types']
            )
        
        return conflicts
    
    def extract_assertion(self, doc, question):
        """从文档中提取与问题相关的断言"""
        # 简化实现
        return {
            'content': doc['content'],
            'source': doc.get('source', 'unknown'),
            'timestamp': doc.get('timestamp'),
            'confidence': doc.get('score', 1.0)
        }
    
    def are_conflicting(self, a1, a2):
        """判断两个断言是否矛盾"""
        # 检测数值矛盾
        if self.is_numeric_claim(a1) and self.is_numeric_claim(a2):
            val1 = self.extract_number(a1['content'])
            val2 = self.extract_number(a2['content'])
            if val1 and val2 and abs(val1 - val2) > 0.1 * max(val1, val2):
                return True
        return False
```

## 5. 解决方案

### 5.1 方案一：时间衰减策略

```python
class TimeDecayResolver:
    """
    基于时间的矛盾解决策略
    """
    
    def resolve(self, documents):
        """
        按时间排序，越新的信息越可信
        """
        # 1. 过滤无时间戳的文档
        with_time = [d for d in documents if d.get('timestamp')]
        
        if not with_time:
            return documents
        
        # 2. 按时间倒序
        sorted_docs = sorted(
            with_time,
            key=lambda x: x['timestamp'],
            reverse=True
        )
        
        # 3. 时间差超过阈值，选用最新
        if self.time_difference_exceeds_threshold(sorted_docs):
            return [sorted_docs[0]]
        
        return sorted_docs
    
    def time_difference_exceeds_threshold(self, docs, threshold_days=30):
        """判断时间差是否超过阈值"""
        if len(docs) < 2:
            return False
        
        newest = docs[0]['timestamp']
        oldest = docs[-1]['timestamp']
        
        diff = (newest - oldest).days
        return diff > threshold_days
```

### 5.2 方案二：权威性加权

```python
class AuthorityWeightedResolver:
    """
    基于权威性的矛盾解决策略
    """
    
    authority_scores = {
        'official': 1.0,      # 官方文档
        'documentation': 0.9,  # 技术文档
        'article': 0.7,        # 文章
        'forum': 0.5,         # 论坛
        'qa': 0.4,            # 问答
        'comment': 0.3        # 评论
    }
    
    def resolve(self, documents):
        """
        按权威性加权选择
        """
        # 1. 计算综合分数
        scored = []
        for doc in documents:
            authority = self.authority_scores.get(
                doc.get('source_type', 'article'),
                0.5
            )
            retrieval_score = doc.get('score', 1.0)
            time_decay = self.time_decay(doc.get('timestamp'))
            
            # 综合分数
            total_score = authority * 0.5 + retrieval_score * 0.3 + time_decay * 0.2
            scored.append((doc, total_score))
        
        # 2. 按分数排序
        scored.sort(key=lambda x: x[1], reverse=True)
        
        return [doc for doc, _ in scored]
    
    def time_decay(self, timestamp, half_life_days=180):
        """时间衰减"""
        if not timestamp:
            return 0.5
        
        age_days = (datetime.now() - timestamp).days
        return math.exp(-0.693 * age_days / half_life_days)
```

### 5.3 方案三：LLM 仲裁

```python
class LLMConflictResolver:
    """
    基于 LLM 的矛盾仲裁
    """
    
    SYSTEM_PROMPT = """
    你是一个信息矛盾分析专家。
    当你收到多个可能矛盾的文档时，需要：
    
    1. 识别矛盾的本质
    2. 判断是否可以调和
    3. 如果不可调和，给出最可能的答案并说明原因
    4. 如果可以调和，给出综合后的答案
    
    回答格式：
    - 矛盾类型：[时间/来源/条件/不可调和]
    - 推荐答案：...
    - 置信度：[高/中/低]
    - 原因：...
    """
    
    def __init__(self, llm):
        self.llm = llm
    
    def resolve(self, question, documents):
        """使用 LLM 解决矛盾"""
        
        # 1. 构造输入
        doc_summaries = "\n\n".join([
            f"文档 {i+1} (来源: {d.get('source', '未知')}, 时间: {d.get('timestamp', '未知')}):\n{d['content']}"
            for i, d in enumerate(documents)
        ])
        
        prompt = f"""
        问题：{question}
        
        相关文档：
        {doc_summaries}
        
        请分析这些文档之间的矛盾，并给出处理建议。
        """
        
        # 2. 调用 LLM
        response = self.llm.generate(
            prompt,
            system_prompt=self.SYSTEM_PROMPT
        )
        
        # 3. 解析结果
        return self.parse_resolution(response, documents)
    
    def parse_resolution(self, llm_response, documents):
        """解析 LLM 的解决建议"""
        # 简化实现
        return {
            'resolution': llm_response,
            'used_documents': documents,  # LLM 判断使用的文档
            'confidence': 'medium'
        }
```

```python
class MultiDocumentReasoning:
    """
    多文档联合推理
    """
    
    def __init__(self, llm):
        self.llm = llm
    
    def reason(self, question, documents):
        """
        对矛盾文档进行联合推理
        """
        # 1. 识别每个文档的约束条件
        constraints = []
        for doc in documents:
            constraint = self.extract_constraints(doc, question)
            constraints.append(constraint)
        
        # 2. 检查约束是否相容
        is_consistent = self.check_consistency(constraints)
        
        if is_consistent:
            # 约束相容：综合所有信息
            return self.merge_constraints(constraints, question)
        else:
            # 约束冲突：使用 LLM 仲裁
            return self.llm_arbitrate(question, documents)
    
    def extract_constraints(self, doc, question):
        """提取文档中的约束条件"""
        prompt = f"""
        从以下文档中提取与问题相关的约束条件：
        
        问题：{question}
        文档：{doc['content']}
        
        提取格式：
        - 条件：[如：会员价格/含税价格/促销价格]
        - 适用人群：[如：所有人/会员/新用户]
        - 有效期：[如：2024年内/长期有效]
        """
        
        result = self.llm.generate(prompt)
        return result
    
    def check_consistency(self, constraints):
```

## 6. 可选方案对比

| 方案 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 时间衰减 | 时效性信息 | 简单直接 | 无法处理其他类型矛盾 |
| 权威性加权 | 多源异构 | 可量化 | 权威性难以定义 |
| LLM 仲裁 | 复杂矛盾 | 智能 | 成本高、延迟大 |
| 多文档推理 | 需要综合信息 | 深度分析 | 实现复杂 |

## 11. 总结

1. **矛盾原因**：时间、来源、条件、错误信息导致文档不一致
2. **处理策略**：时间衰减（简单）、权威性加权（可量化）、LLM 仲裁（智能）、多文档推理（深度）
3. **推荐方案**：多层组合策略（快速过滤 → LLM 仲裁 → 多文档推理）
4. **输出规范**：附带置信度、来源说明、推理过程
5. **核心原则**：透明化矛盾处理过程，让用户了解信息可靠性
