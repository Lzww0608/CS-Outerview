# 2. 密码存储与加盐哈希

密码不能以明文存储，也不建议用可逆加密直接存储。服务端应该保存的是密码经过专用慢哈希算法计算后的结果，并为每个用户使用独立随机盐。

## 1. 为什么不能明文或普通哈希

明文存储的问题是数据库、日志、备份或运维账号一旦泄漏，用户密码会直接暴露，并且用户可能在多个网站复用密码。

普通哈希例如单次 `MD5(password)`、`SHA256(password)` 也不够安全：

1. 算法太快，攻击者可以用 GPU 大规模暴力枚举。
2. 相同密码得到相同摘要，能被彩虹表和撞库利用。
3. 没有算法参数，后续很难平滑升级安全强度。

正确目标不是“加密后还能解密”，而是“服务端也不知道用户原始密码，只能验证用户输入是否匹配”。

## 2. 盐、慢哈希和 Pepper

### 盐 Salt

盐是每个用户独立生成的随机值，和密码一起参与哈希。盐不需要保密，可以和哈希结果一起存储。

作用：

1. 相同密码在不同用户上得到不同哈希。
2. 让攻击者不能复用一张彩虹表攻击所有用户。
3. 提高批量破解成本。

### 慢哈希

密码哈希要使用专门的 KDF 或 Password Hashing 算法，例如：

1. **Argon2id**：推荐优先考虑，能配置内存、迭代次数和并行度。
2. **bcrypt**：工程使用成熟，通过 cost 控制计算成本。
3. **scrypt**：强调内存开销，增加硬件暴力破解成本。
4. **PBKDF2**：兼容性好，但需要足够高的迭代次数。

### Pepper

Pepper 是系统级密钥，和密码、盐一起参与计算，但不存数据库，通常放在 KMS、环境密钥或配置中心。数据库泄漏时，攻击者还需要拿到 Pepper 才能离线验证猜测。

Pepper 的注意点：

1. 要能轮换，并设计多版本验证。
2. 不能硬编码进代码仓库。
3. 泄漏后需要触发密码哈希迁移或强制用户重置。

## 3. 存储格式

推荐把算法、参数、盐和哈希结果一起存储，方便未来升级：

```text
argon2id$v=19$m=65536,t=3,p=2$base64(salt)$base64(hash)
```

用户登录时：

```text
读取用户密码哈希记录
-> 解析算法和参数
-> 用用户输入密码、salt、pepper 重新计算
-> 常量时间比较 hash
-> 成功后如果参数过旧，异步或同步升级哈希
```

常量时间比较可以降低计时侧信道风险，避免比较函数在第一个不同字节处提前返回。

## 4. 注册和登录示例

伪代码：

```java
String register(String rawPassword) {
    byte[] salt = secureRandom(16);
    String encoded = argon2id(rawPassword, salt, pepper, memory, iterations, parallelism);
    return encoded;
}

boolean login(String rawPassword, String encoded) {
    PasswordHash parsed = PasswordHash.parse(encoded);
    byte[] actual = argon2id(rawPassword, parsed.salt(), pepper, parsed.params());
    return constantTimeEquals(actual, parsed.hash());
}
```

工程上还要配合登录失败限流、验证码、设备风控、异常地提醒、密码重置 token 单次有效等机制。密码存储只解决数据库泄漏后的离线破解成本，不能替代登录态和账号风控。

## 5. 易错点

1. 不要把“加盐哈希”说成“加密”，哈希不可逆，加密可逆。
2. 不要全站共用固定盐；盐应该每个用户随机生成。
3. 不要使用 MD5、SHA1 或单次 SHA256 存密码。
4. 不要把原始密码写入日志、消息队列、链路追踪或异常堆栈。
5. 忘记限流会让在线爆破仍然可行。
6. 参数设置要结合机器性能，不能让登录接口被慢哈希拖垮；可以用限流和异步升级降低风险。

## 6. 面试回答模板

密码入库不能存明文，也不建议可逆加密。通常用 Argon2id、bcrypt、scrypt 或 PBKDF2 这类慢哈希算法，每个用户生成独立随机盐，保存算法、参数、盐和哈希值；登录时用用户输入重新计算并做常量时间比较。盐用于防彩虹表和相同密码同哈希，Pepper 可以作为系统级密钥放在 KMS 中进一步降低数据库泄漏风险。真实项目还要配合登录限流、验证码、异常登录风控、密码哈希参数升级和敏感日志脱敏。
