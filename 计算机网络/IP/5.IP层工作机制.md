# 5. IP 层工作机制

IP 层位于网络层，解决的是“把数据包跨网络送到目标主机”的问题。它提供统一的 IP 地址、路由选择、逐跳转发、TTL 防环路、分片控制和错误诊断，但不保证可靠、有序和不重复。

## 1. IP 层负责什么

IP 层的核心职责：

1. **寻址**：用源 IP 和目的 IP 标识通信双方的网络层地址。
2. **路由**：根据目的 IP 和路由表选择下一跳。
3. **转发**：每台路由器逐跳处理 IP 包，把包送往下一跳。
4. **封装上层协议**：通过 IPv4 `Protocol` 或 IPv6 `Next Header` 区分 TCP、UDP、ICMP 等载荷。
5. **生存时间控制**：TTL/Hop Limit 每过一跳减 1，避免环路无限转发。
6. **分片和 MTU 处理**：IPv4 可以分片，IPv6 由源主机处理路径 MTU。
7. **诊断和差错报告**：ICMP 用于不可达、超时、需要分片等网络层反馈。

IP 层不负责端口、连接、重传、拥塞控制和应用语义。这些分别由 TCP/UDP、QUIC 或应用层处理。

## 2. 主机发送一个 IP 包的过程

主机发送数据时通常按这个流程：

```text
应用数据
  -> TCP/UDP 封装，得到 segment/datagram
  -> IP 层添加源 IP、目的 IP、TTL、Protocol
  -> 查本机路由表，选择出口接口和下一跳
  -> ARP/邻居发现拿到下一跳 MAC
  -> 数据链路层封装成帧发送
```

如果目的 IP 在本机直连网段内，下一跳就是目标主机；如果不在本地网段，下一跳通常是默认网关。

注意：ARP 解析的是下一跳的 MAC，不一定是最终目标主机的 MAC。跨网段访问时，主机解析的是网关 MAC。

## 3. 路由器转发机制

路由器收到帧后：

1. 校验二层帧，确认帧是发给自己的接口。
2. 解封装得到 IP 包。
3. 检查 IP 首部，TTL 减 1；如果 TTL 为 0，丢弃并返回 ICMP Time Exceeded。
4. 根据目的 IP 查路由表，使用最长前缀匹配选择最具体路由。
5. 得到出口接口和下一跳地址。
6. 查询 ARP/邻居表，必要时发起 ARP 或 NDP。
7. 重新封装新的二层帧，从出口接口发出。

每一跳二层源/目的 MAC 都会变化；源 IP 和目的 IP 通常不变，除非经过 NAT。

## 4. 路由表和最长前缀匹配

路由表项通常包含：

| 字段 | 作用 |
| --- | --- |
| 目的网段 | 要匹配的 IP 前缀，例如 `10.1.2.0/24` |
| 下一跳 | 下一个路由器或网关 IP |
| 出口接口 | 从哪个网卡发出 |
| metric | 多条路由可用时的代价 |
| 来源 | 直连、静态、OSPF、BGP、DHCP 等 |

最长前缀匹配示例：

```text
10.0.0.0/8      -> eth0
10.1.0.0/16     -> eth1
10.1.2.0/24     -> eth2
0.0.0.0/0       -> default
```

目的 IP 是 `10.1.2.3` 时选择 `/24`，因为它最具体。默认路由 `0.0.0.0/0` 只是兜底。

## 5. IP 层为什么不保证可靠

IP 是 best effort 协议，可能出现：

1. 路由器拥塞丢包。
2. TTL 归零丢包。
3. MTU 不足且不能分片时丢包。
4. 路由变化导致乱序。
5. 链路层错误或中间设备策略丢弃。

这种设计让网络层保持简单，端系统按需实现可靠性。TCP 在传输层提供序号、ACK、重传、流量控制和拥塞控制；UDP 则把可靠性选择权交给应用。

## 6. 易错点

1. IP 地址属于网络层，端口属于传输层，MAC 地址属于数据链路层。
2. 路由器根据目的 IP 转发，不看 TCP/UDP 端口做基本路由选择。
3. TTL 不是按秒减少，而是按路由跳数减少。
4. 跨网段通信时二层 MAC 每一跳都会变，IP 源/目的地址通常不变。
5. ARP 不会跨路由器广播，只解析同一链路上的下一跳 MAC。
6. IP 分片不是可靠性机制，反而会增加丢包和重组成本。

## 7. 真实场景

排查“某服务访问外网失败”时，可以按 IP 层链路检查：

1. `ip addr` 看本机 IP 和掩码是否正确。
2. `ip route get <dst>` 看系统选择的出口和下一跳。
3. `arp -a` 或 `ip neigh` 看下一跳 MAC 是否解析成功。
4. `ping` / `traceroute` 看在哪一跳超时。
5. `tcpdump` 抓包确认是否发出、是否收到 ICMP、是否存在 MTU 黑洞。
6. 云环境还要检查安全组、路由表、NAT 网关、ACL 和防火墙策略。

## 8. 面试回答模板

IP 层负责网络层寻址和跨网络转发。发送端根据目的 IP 查本机路由表，确定出口接口和下一跳；如果下一跳在同一链路上，就通过 ARP 或邻居发现拿到 MAC，再封装二层帧发送。路由器每一跳都会解封装二层帧、检查 IP 包、TTL 减 1、按最长前缀匹配查路由表、重新封装新的二层帧转发。IP 本身是 best effort，不保证可靠、有序和不重复，可靠传输通常由 TCP 或应用层实现。
