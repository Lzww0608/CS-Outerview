# 路由器与路由表

路由器工作在网络层，核心职责是在不同网络之间转发 IP 数据包。它不关心应用层语义，也不会像交换机那样只根据二层 MAC 地址转发，而是根据目的 IP、路由表和最长前缀匹配决定下一跳。

## 1. 路由器是哪一层

在 OSI 模型中，路由器主要工作在第三层网络层；在 TCP/IP 模型中，对应网际层。

它的主要功能：

1. **跨网段转发**：把一个网络中的 IP 包转发到另一个网络。
2. **路径选择**：根据路由表选择下一跳和出口接口。
3. **隔离广播域**：二层广播不会直接跨路由器传播。
4. **TTL 递减**：每经过一跳，IP 头部 TTL 减 1，防止环路包无限转发。
5. **可选功能**：NAT、防火墙、ACL、QoS、策略路由、隧道等。

## 2. 路由寻址怎么找

路由器收到数据包后，一般按以下流程处理：

1. 校验二层帧，确认目标 MAC 是自己或广播/组播。
2. 取出 IP 包，检查目的 IP。
3. TTL 减 1，如果 TTL 变成 0，丢弃并返回 ICMP Time Exceeded。
4. 查路由表，使用**最长前缀匹配**找到最具体的路由。
5. 得到下一跳 IP 和出口接口。
6. 如果不知道下一跳 MAC，在出口网段发 ARP 或查邻居表。
7. 重新封装二层帧并从出口接口发出。

最长前缀匹配示例：

```text
目的 IP: 10.1.2.3

10.0.0.0/8      -> eth0
10.1.0.0/16     -> eth1
10.1.2.0/24     -> eth2
0.0.0.0/0       -> default
```

最终选择 `10.1.2.0/24 -> eth2`，因为 `/24` 前缀最长、最具体。

## 3. 路由表存什么

路由表不是只存目的 IP，它通常包含：

1. **目的网段**：例如 `10.1.2.0/24`。
2. **下一跳 gateway**：下一台路由器或网关 IP；直连路由可能没有 gateway。
3. **出口接口**：例如 `eth0`、`ens33`。
4. **metric/cost**：多条路由都匹配时的优先级或代价。
5. **路由来源**：直连、静态、OSPF、BGP、RIP、DHCP 等。
6. **作用域和协议属性**：本地路由、链路路由、默认路由、策略路由等。

Linux 上可以用：

```bash
ip route
ip route get 8.8.8.8
```

`ip route get` 很适合面试或排障说明“系统会如何选择出口”。

## 4. 路由表从哪里来

1. **直连路由**：网卡配置 IP 和掩码后自动生成。
2. **静态路由**：管理员手动配置，简单可靠，但维护成本高。
3. **动态路由协议**：路由器之间交换可达性和代价信息。
4. **默认路由**：没有更具体匹配时走 `0.0.0.0/0` 或 `::/0`。

常见动态路由协议：

1. **RIP**：距离向量，按跳数计算，适合小规模网络。
2. **OSPF/IS-IS**：链路状态协议，适合自治系统内部。
3. **BGP**：路径向量协议，互联网自治系统之间的核心路由协议。

## 5. 易错点

1. 路由器查的是目的 IP，不是目的端口；端口属于传输层。
2. 每一跳都会重新封装二层头，源/目的 MAC 会变，但源/目的 IP 通常不变，NAT 场景除外。
3. 默认路由是兜底路由，不是优先级最高的路由。
4. ARP 只解析下一跳 MAC，不会解析最终远端主机的 MAC。
5. 路由表决定下一跳，ARP/邻居表决定下一跳的二层地址。

## 6. 面试回答模板

路由器主要工作在网络层，根据目的 IP 查路由表并选择下一跳。查找时使用最长前缀匹配，匹配到最具体的目的网段后得到出口接口和下一跳 gateway，再通过 ARP/邻居表拿到下一跳 MAC，重新封装二层帧转发出去。路由表通常包含目的网段、下一跳、出口接口、metric 和路由来源。每经过一台路由器 TTL 会减 1，防止环路。
