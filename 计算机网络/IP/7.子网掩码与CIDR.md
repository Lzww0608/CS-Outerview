# 7. 子网掩码与 CIDR

子网掩码用于把 IP 地址划分为网络号和主机号。网络号表示这个地址属于哪个网段，主机号表示该网段内的具体主机。

## 1. 基本定义

IPv4 地址是 32 位。子网掩码中连续的 `1` 表示网络位，连续的 `0` 表示主机位。

例如：

```text
IP:        192.168.1.130
Mask:      255.255.255.192
CIDR:      192.168.1.130/26
```

`/26` 表示前 26 位是网络位，剩下 6 位是主机位。`255.255.255.192` 的二进制最后一个字节是 `11000000`，所以它等价于 `/26`。

## 2. 核心计算

判断一个 IP 属于哪个网段，核心公式是：

```text
网络地址 = IP 地址 & 子网掩码
```

以 `192.168.1.130/26` 为例：

```text
/26 每个网段大小 = 2^(32 - 26) = 64
网段边界：192.168.1.0、192.168.1.64、192.168.1.128、192.168.1.192
```

因此：

```text
网络地址:   192.168.1.128
广播地址:   192.168.1.191
可用主机:   192.168.1.129 - 192.168.1.190
可用数量:   2^6 - 2 = 62
```

`-2` 是因为传统 IPv4 子网中网络地址和广播地址不能分配给普通主机。`/31` 点到点链路和 `/32` 单主机路由是特殊场景，不能机械套用 `-2`。

## 3. 同网段判断

两台主机是否在同一网段，不是看 IP 前几段字符串是否相同，而是看：

```text
(ip1 & mask) == (ip2 & mask)
```

例如：

```text
192.168.1.130/26 -> 192.168.1.128
192.168.1.170/26 -> 192.168.1.128
192.168.1.200/26 -> 192.168.1.192
```

前两个地址同网段，第三个不在同一 `/26` 网段。

如果目标 IP 在同一网段，主机会 ARP 解析目标主机 MAC 后直接发二层帧；如果目标 IP 不在同一网段，主机会把包交给默认网关，ARP 解析的是网关 MAC。

## 4. CIDR 的意义

CIDR（Classless Inter-Domain Routing，无类别域间路由）用 `IP/前缀长度` 表示网段，例如：

| CIDR | 子网掩码 | 单个网段地址数 |
| --- | --- | --- |
| `/8` | `255.0.0.0` | `2^24` |
| `/16` | `255.255.0.0` | `2^16` |
| `/24` | `255.255.255.0` | `256` |
| `/30` | `255.255.255.252` | `4` |
| `/32` | `255.255.255.255` | `1` |

CIDR 取代了早期 A/B/C 类地址的固定划分，可以更灵活地分配地址，并支持路由聚合。

## 5. 和路由表的关系

路由表中的目的网段也用 CIDR 表示，例如：

```text
10.0.0.0/8       via 10.1.1.1
10.1.2.0/24      dev eth0
0.0.0.0/0        via 192.168.1.1
```

当多个路由都能匹配目标 IP 时，路由器或主机使用最长前缀匹配，也就是选择网络位更多、更具体的那条路由。

例如访问 `10.1.2.33`：

1. `10.0.0.0/8` 能匹配。
2. `10.1.2.0/24` 也能匹配。
3. `/24` 更具体，所以选择 `10.1.2.0/24`。

## 6. 易错点

1. 子网掩码不是网关。掩码用于判断网段，网关是跨网段转发的下一跳。
2. `255.255.255.0` 才是 `/24`，不要把 `/24` 理解为“前三段一样”这种字符串规则。
3. 跨网段通信时，ARP 解析的是网关 MAC，不是最终目标主机 MAC。
4. CIDR 已经取代传统 A/B/C 类地址划分，面试里优先用 CIDR 解释。
5. 公网 IP、私网 IP、NAT 是地址可达性问题，和子网掩码不是同一概念。

## 7. 真实场景

1. **本机网络排障**：`ip addr` 看 IP/掩码，`ip route` 看默认网关和目标网段路由。
2. **VPC 和容器网络规划**：为业务、Pod、Service、数据库子网划分不重叠 CIDR，避免路由冲突。
3. **安全组和 ACL**：用 `10.0.0.0/8`、`192.168.1.0/24` 控制来源范围。
4. **负载均衡和网关**：根据客户端网段做访问控制、灰度路由或机房调度。
5. **IP 地址容量评估**：根据前缀长度估算一个子网可容纳多少主机。

## 8. 面试回答模板

子网掩码用连续的 1 表示网络位、连续的 0 表示主机位。把 IP 和掩码按位与，就能得到网络地址；两个 IP 与同一个掩码计算后网络地址相同，就在同一网段。同网段可以 ARP 到目标主机 MAC 直接通信，跨网段要发给默认网关。CIDR 用 `/前缀长度` 表示掩码，例如 `/24` 等价于 `255.255.255.0`。真实路由选择使用最长前缀匹配，优先选择更具体的网段路由。
