# 7. TCP 报文首部字段

## 1. TCP 首部最小长度

TCP 首部最小 20 字节，最大 60 字节。超过 20 字节的部分是可选项 options。

TCP 是面向字节流的可靠传输协议，首部字段主要服务于：

1. 连接标识。
2. 可靠传输。
3. 流量控制。
4. 拥塞控制辅助。
5. 连接建立和关闭。

## 2. 核心字段

| 字段 | 长度 | 作用 |
| --- | --- | --- |
| Source Port | 16 bit | 源端口 |
| Destination Port | 16 bit | 目的端口 |
| Sequence Number | 32 bit | 序号，表示本报文段第一个字节的序号 |
| Acknowledgment Number | 32 bit | 确认号，表示期望收到的下一个字节序号 |
| Data Offset | 4 bit | TCP 首部长度 |
| Flags | 多个 bit | 连接控制和状态标记 |
| Window Size | 16 bit | 接收窗口，用于流量控制 |
| Checksum | 16 bit | 校验首部和数据完整性 |
| Urgent Pointer | 16 bit | 配合 URG 使用，指向紧急数据 |
| Options | 0 到 40 字节 | MSS、窗口扩大、时间戳、SACK 等 |

## 3. 常见标志位

| 标志 | 含义 |
| --- | --- |
| SYN | 建立连接，同步初始序号 |
| ACK | 确认号有效 |
| FIN | 发送方数据发送完毕，请求关闭一个方向 |
| RST | 重置连接 |
| PSH | 提示接收方尽快把数据交给应用层 |
| URG | 紧急指针有效 |
| ECE/CWR | ECN 拥塞通知相关 |

三次握手主要用 `SYN`、`ACK`；四次挥手主要用 `FIN`、`ACK`。

## 4. Options 常见内容

TCP option 是 TCP 首部中超过固定 20 字节的可变长扩展区域。`Data Offset` 字段记录 TCP 首部长度，单位是 4 字节，所以 TCP 首部最大是 60 字节，options 最多 40 字节。

常见 option：

| 选项 | 常见出现位置 | 作用 |
| --- | --- | --- |
| MSS | SYN | 协商本端愿意接收的最大 TCP 数据段长度 |
| Window Scale | SYN | 扩大接收窗口，突破 16 bit window size 的 65535 限制 |
| SACK Permitted | SYN | 表示本端支持选择性确认 |
| SACK | 连接建立后 | 告诉发送方哪些不连续区间已经收到，便于只重传真正缺失的数据 |
| Timestamp | SYN 和后续报文 | RTT 测量、PAWS，降低旧报文序号回绕带来的风险 |
| NOP | 任意 | 填充对齐，让后续 option 落在 4 字节边界 |
| EOL | 任意 | 标记 option 列表结束 |

MSS 和 MTU 的关系：

```text
MSS = MTU - IP header - TCP header
```

以无 IP/TCP option 的以太网 IPv4 为例：

```text
MTU = 1500
IPv4 header = 20
TCP header = 20
MSS = 1460
```

如果启用了 TCP timestamp 等 option，TCP 首部变长，单个报文可承载的应用数据会相应变小。工程上通常依赖 MSS 协商和路径 MTU 发现来避免 IP 分片。

## 5. 易错点

1. 序号和确认号按字节编号，不是按报文编号。
2. `ACK = x` 表示 `x` 之前的字节都已收到，下一步期待 `x`。
3. TCP 校验和计算时包含伪首部，伪首部来自 IP 层的源/目的地址、协议号和长度。
4. `Window Size` 是接收窗口，不是拥塞窗口；拥塞窗口 `cwnd` 不在 TCP 首部里。
5. TCP option 不是应用层可随意塞业务字段的地方，它是协议栈扩展能力区，由内核 TCP 实现解析。

## 6. 面试回答模板

TCP 首部最少 20 字节，核心字段包括源端口、目的端口、序号、确认号、首部长度、标志位、窗口大小、校验和、紧急指针和 options。序号和确认号用于可靠有序传输，窗口大小用于流量控制，SYN/ACK/FIN/RST 等标志位用于连接建立、确认、关闭和异常重置。options 里常见 MSS、窗口扩大、SACK、时间戳。要注意 TCP 的序号是按字节编号，`cwnd` 不在首部里。
