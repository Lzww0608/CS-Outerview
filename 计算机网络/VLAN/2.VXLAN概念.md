# 2. VXLAN 概念

VXLAN（Virtual eXtensible LAN）是一种二层 over 三层的网络虚拟化技术。它把原始二层以太网帧封装在 UDP 报文中，通过三层 IP 网络转发，从而在不同机房、不同三层网络之间构建逻辑二层网络。

## 1. 为什么需要 VXLAN

传统 VLAN 只有 12 bit VLAN ID，常用范围约 4094 个。在云计算和多租户场景下，租户、业务和容器网络数量远超过这个规模，而且虚拟机或容器可能跨物理三层网络迁移。

VXLAN 解决的问题：

1. **扩展隔离空间**：VXLAN 使用 24 bit VNI，理论上可支持约 1600 万个逻辑网络。
2. **跨三层承载二层语义**：底层只要 IP 可达，上层就能构造逻辑二层网络。
3. **适合云和容器网络**：多租户、虚拟机迁移、Kubernetes Overlay 网络都常见 VXLAN 思路。
4. **减少对物理交换网络的依赖**：租户网络变化主要由虚拟交换机、VTEP 和控制面维护。

## 2. VXLAN 报文结构

VXLAN 会把原始二层帧封装为：

```text
外层以太网头
外层 IP 头
外层 UDP 头（默认目的端口 4789）
VXLAN 头（包含 VNI）
内层以太网帧
```

其中 VNI（VXLAN Network Identifier）用于标识逻辑网络，类似扩展版 VLAN ID。负责封装和解封装的端点叫 VTEP（VXLAN Tunnel Endpoint），通常位于宿主机虚拟交换机、ToR 交换机或网关设备上。

## 3. 通信过程

假设虚拟机 A 和虚拟机 B 属于同一个 VNI，但在不同宿主机上：

1. A 发出普通二层以太网帧。
2. 源宿主机上的 VTEP 根据目标 MAC 或控制面信息找到目标 VTEP IP。
3. 源 VTEP 把原始以太网帧封装进 VXLAN/UDP/IP 报文。
4. 物理三层网络按外层 IP 转发到目标宿主机。
5. 目标 VTEP 解封装，取出内层以太网帧并交给 B。

如果不知道目标 MAC 所在 VTEP，早期方案会用组播泛洪；现代数据中心更多依赖 EVPN、SDN 控制器或集中式控制面下发 MAC/VNI/VTEP 映射。

## 4. VLAN 和 VXLAN 的区别

| 对比项 | VLAN | VXLAN |
| --- | --- | --- |
| 工作层次 | 二层隔离 | 二层 over 三层 Overlay |
| 标识长度 | 12 bit VLAN ID | 24 bit VNI |
| 可扩展性 | 约 4094 个 VLAN | 约 1600 万个 VNI |
| 转发依赖 | 二层交换网络 | 三层 IP 网络 |
| 常见场景 | 企业局域网、机房基础隔离 | 云平台、多租户、容器网络、跨三层二层网络 |

## 5. 易错点

1. VXLAN 不是加密协议，只是封装和隔离技术；安全仍要依赖 ACL、安全组、隧道加密或零信任策略。
2. VXLAN 增加外层头部，会降低有效 MTU。生产环境要调整物理网络 MTU，避免封装后分片。
3. VXLAN 解决的是大规模二层网络和多租户隔离，不等于自动解决服务发现、负载均衡或网络策略。
4. VTEP 映射如果依赖泛洪，规模变大后成本很高，云平台通常配合 EVPN 或 SDN 控制面。
5. 排查 VXLAN 问题要同时看内层地址、外层 VTEP 地址、VNI、UDP 端口、MTU 和安全策略。

## 6. 真实场景应用

1. **Kubernetes Overlay 网络**：Flannel VXLAN、部分 CNI 插件会用 VXLAN 跨宿主机转发 Pod 流量。
2. **云主机多租户隔离**：不同租户使用不同 VNI，底层物理网络只负责 IP 转发。
3. **虚拟机迁移**：逻辑二层网络不随物理三层边界变化，便于业务迁移和扩容。
4. **数据中心 EVPN-VXLAN**：EVPN 作为控制面分发路由和 MAC 信息，VXLAN 作为数据面封装。

## 7. 面试回答模板

VXLAN 是二层 over 三层的 Overlay 技术。它把原始以太网帧封装进 UDP/IP 报文，通过 VTEP 在三层网络上转发，并用 24 bit VNI 标识逻辑网络。相比 VLAN，VXLAN 解决了 VLAN ID 数量有限和二层网络难以跨三层扩展的问题，适合云计算、多租户、容器网络和数据中心网络。工程上要注意 MTU 变小、VTEP 映射控制面、泛洪成本和安全策略，VXLAN 本身不负责加密。
