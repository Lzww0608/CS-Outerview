# 1. VLAN 概念

VLAN（Virtual Local Area Network，虚拟局域网）是在二层网络中划分逻辑广播域的技术。它可以让同一台交换机上的端口被划分到不同逻辑网络，也可以让跨交换机的同一 VLAN 像一个局域网一样工作。

## 1. 为什么需要 VLAN

如果所有主机都处于同一个二层广播域，ARP、DHCP 等广播会在整个局域网扩散，安全隔离和故障控制都比较差。

VLAN 的作用：

1. **隔离广播域**：不同 VLAN 的二层广播默认互相不可见。
2. **提升安全性**：不同部门、租户、业务可以隔离。
3. **便于管理**：不用按物理位置划分网络，可以按业务逻辑划分。
4. **降低故障影响面**：广播风暴或环路问题被限制在单个 VLAN 内。

## 2. 802.1Q 标签

常见 VLAN 使用 IEEE 802.1Q，在以太网帧中插入 4 字节 VLAN Tag。

Tag 的核心字段：

| 字段 | 含义 |
| --- | --- |
| TPID | Tag Protocol Identifier，常见值 `0x8100` |
| PCP | 优先级，3 bit，可用于 QoS |
| DEI | 丢弃指示位 |
| VID | VLAN ID，12 bit |

VID 是 12 bit，理论范围是 0 到 4095，其中 0 和 4095 有保留含义，常用 VLAN ID 是 1 到 4094。

## 3. Access 和 Trunk

交换机端口常见模式：

| 模式 | 特点 | 典型连接对象 |
| --- | --- | --- |
| Access | 只属于一个 VLAN，进出主机侧通常不带 Tag | PC、服务器普通网口 |
| Trunk | 允许多个 VLAN 通过，帧中携带 802.1Q Tag | 交换机之间、交换机到路由器、虚拟化宿主机 |

Access 口收到无标签帧后，会按端口所属 VLAN 打上内部 VLAN 标记；发给主机时通常去掉 Tag。

Trunk 口用于承载多个 VLAN，交换机根据 Tag 识别帧属于哪个 VLAN。

## 4. VLAN 间通信

不同 VLAN 是不同二层广播域，默认不能直接二层通信。如果 VLAN 之间需要访问，要通过三层转发：

1. **单臂路由**：路由器一个物理口上配置多个子接口，每个子接口对应一个 VLAN。
2. **三层交换机 SVI**：交换机为每个 VLAN 配置虚接口网关，直接做三层转发。
3. **防火墙网关**：让跨 VLAN 流量经过防火墙，便于访问控制和审计。

生产环境通常会配合 ACL、安全组、防火墙策略控制 VLAN 间访问，而不是只依赖 VLAN 隔离。

## 5. 真实场景

1. **办公网隔离**：研发、财务、访客 Wi-Fi 分别放入不同 VLAN。
2. **数据中心网络**：不同业务或租户使用不同 VLAN，配合 VXLAN 扩展更大二层网络。
3. **虚拟化宿主机**：宿主机网口配置 Trunk，虚拟机网卡按业务 VLAN 打 Tag。
4. **安全域划分**：管理网、业务网、存储网分别划 VLAN，降低横向移动风险。

## 6. 易错点

1. VLAN 是二层逻辑隔离，不是加密技术。
2. 不同 VLAN 通信需要三层设备或三层交换能力。
3. Access 口通常不带 Tag 给终端，Trunk 口通常带 Tag 承载多个 VLAN。
4. VLAN ID 只有 12 bit，普通 VLAN 数量上限约 4094。
5. VLAN 隔离不能替代防火墙和权限控制，错误的 Trunk 配置可能导致 VLAN 泄漏。

## 7. 面试回答模板

VLAN 是二层网络里的逻辑广播域划分技术，通过 802.1Q Tag 在以太网帧中标识 VLAN ID。它能隔离广播、提升安全性和管理灵活性。Access 口通常连接终端，只属于一个 VLAN；Trunk 口用于交换机或宿主机之间，承载多个 VLAN。不同 VLAN 默认不能二层互通，需要路由器、三层交换机 SVI 或防火墙做三层转发。实际使用中 VLAN 主要用于部门、租户、管理网和业务网隔离，但它不是加密和强安全边界，还要配合 ACL、防火墙和访问控制。
