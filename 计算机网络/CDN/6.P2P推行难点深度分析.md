### 2.2 节点质量问题

```python
# P2P 节点质量分析
class PeerQualityAnalyzer:
    def analyze_peer(self, peer):
        issues = []
        
        # 1. 上行带宽不足
        if peer.upload_bandwidth < 1 * 1024 * 1024:  # 1Mbps
            issues.append("上行带宽过低")
        
        # 2. 在线不稳定
        if peer.uptime_ratio < 0.7:  # 在线时间比例
            issues.append("节点不稳定")
        
        # 3. 地理分布不均
        if peer.region in ['偏远地区']:
            issues.append("区域覆盖不足")
        
        # 4. NAT 类型差
        if peer.nat_type in ['对称型', '端口限制']:
            issues.append("NAT 类型差")
        
        return {
            'is_usable': len(issues) == 0,
            'issues': issues,
            'quality_score': self.calculate_score(peer)
        }

# 统计结果
# 优质节点（可用率）：约 20-30%
# 普通节点（勉强可用）：约 40-50%
# 劣质节点（难以穿透）：约 20-30%
```

### 3.2 内容审核困难

```python
# P2P 内容审核难题

class ContentModeration:
    def __init__(self):
        self.moderation_rate = 0  # 实际可审核比例
    
    def challenges(self):
        return {
            'decentralized_storage': '数据分散在全球节点',
            'encryption': '端到端加密无法检测',
            'anonymity': '用户身份难以追踪',
            'jurisdiction': '跨国执法困难',
            'scale': '海量内容无法全量审核',
            'real_time': '内容实时分发，审核滞后'
        }
    
    def why_hard(self):
        """
        为什么 P2P 内容审核困难：
        
        1. 无中心节点
           - 无法在一个地方审查所有内容
           - 节点可能在任何国家
        
        2. 加密传输
           - 内容加密后无法检测
           - 甚至协议本身也可能加密
        
        3. 匿名参与
           - 匿名账号发布内容
           - 无法追溯责任人
        
        4. 实时分发
           - 内容瞬间传遍全球
           - 审核速度跟不上传播速度
        """
```

## 八、面试常见问题

### Q1: P2P 最大的难点是什么？

技术难点可解决，政策难点难以根本解决。版权和监管是 P2P 推行的最大障碍。

### Q2: 为什么 P2P 金融在中国被清退？

P2P 网贷缺乏有效监管，导致非法集资、跑路频发；国家为了防范金融风险，要求全面清退。

### Q3: P2P 内容审核如何实现？

1. 节点白名单过滤
2. 内容指纹上传（如 YouTube Content ID）
3. 加密内容无法检测（这是 P2P 的两难）
4. 法律威慑替代技术手段

### Q4: P2P 的未来在哪里？

1. 混合架构（CDN+P2P）
2. 合规化运营
3. 垂直领域深耕
4. Web3 基础设施

## 九、总结

1. **技术难点**：NAT 穿透、节点质量、安全隐私
   - 有技术解决方案，但成本高

2. **政策难点**：版权、审核、监管
   - 难以根本解决，需要配合

3. **核心结论**：政策难点 > 技术难点

4. **成功关键**：找到技术与政策的平衡点

5. **未来趋势**：合规化、混合架构、Web3 基础设施
