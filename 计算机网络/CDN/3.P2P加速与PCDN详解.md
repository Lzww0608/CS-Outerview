# P2P 加速与 PCDN 详解

## 一、P2P 技术概述

### 1.1 什么是 P2P

P2P（Peer-to-Peer，对等网络）是一种分布式网络架构，节点之间直接共享资源，无需中心服务器中转。

## 二、P2P 核心原理

### 2.1 P2P 下载原理

```python
# BitTorrent 协议核心流程

class BitTorrentClient:
    def __init__(self, torrent_file):
        self.torrent = parse_torrent(torrent_file)
        self.pieces = {}  # 已下载的分片
        self.peers = []   # 邻居节点
        
    def start_download(self):
        # 1. 从 Tracker 获取 peers 列表
        peers = self.tracker.get_peers(self.torrent.info_hash)
        
        # 2. 与 peers 交换 pieceAvailability
        for peer in peers:
            peer.send_bitfield(self.available_pieces)
            
        # 3. 优先下载稀有分片
        rarest = self.find_rarest_piece()
        self.request_piece(peer, rarest)
        
        # 4. 上传已完成的分片给其他节点
        self.share_pieces()
```

### 2.2 分片算法

```python
# 稀有优先算法
def find_rarest_piece(self):
    # 统计每个 piece 的可用副本数
    availability = Counter()
    
    for peer in self.peers:
        for piece_index in peer.available_pieces:
            if piece_index not in self.completed_pieces:
                availability[piece_index] += 1
    
    # 选择副本数最少的 piece
    return min(availability, key=availability.get)
```

```python
# P2P 节点调度
class HybridScheduler:
    def select_source(self, content_id, user_location):
        # 1. 检查 CDN 缓存命中率
        cdn_hit_rate = self.cdn.get_hit_rate(content_id)
        
        # 2. 检查附近 P2P 节点可用性
        nearby_peers = self.p2p.get_nearby_peers(
            user_location, 
            content_id
        )
        
        # 3. 选择最优来源
        if cdn_hit_rate > 0.8:
            return SourceType.CDN
        elif len(nearby_peers) > 3:
            return SourceType.P2P
        else:
            return SourceType.ORIGIN
    
    def load_balance(self, peers):
        # 根据节点上行带宽分配任务
        sorted_peers = sorted(
            peers, 
            key=lambda p: p.bandwidth_upload, 
            reverse=True
        )
        return sorted_peers
```

## 四、PCDN 详解

### 4.1 什么是 PCDN

PCDN（P2P + CDN）是运营商和内容提供商联合部署的 P2P CDN 方案，利用用户闲置带宽做内容分发。

### 4.2 PCDN vs 传统 CDN

| 对比项 | 传统 CDN | PCDN |
|--------|----------|------|
| 节点来源 | 自建/合作机房 | 用户终端 |
| 带宽成本 | 按带宽付费 | 激励分成 |
| 覆盖范围 | 有限节点 | 用户分布广 |
| 稳定性 | 高 | 受用户行为影响 |
| 适用场景 | 全场景 | 长尾内容、热点分发 |

### 6.2 解决方案

```python
# NAT 穿透方案

class NATTraversal:
    def stun_binding(self, public_ip, stun_server):
        # STUN：查询公网 IP 和端口
        response = send_binding_request(stun_server)
        return response.mapped_address
    
    def udp_hole_punching(self, peer_a, peer_b, stun_server):
        # UDP 打洞
        addr_a = self.stun_binding(public_ip, stun_server)
        addr_b = self.stun_binding(peer_b.public_ip, stun_server)
        
        # 双方同时向对方地址发包
        peer_a.sendto(addr_b, b'ping')
        peer_b.sendto(addr_a, b'ping')
        
        # NAT 记录映射，形成"洞"
        return addr_a, addr_b
    
    def turn_relay(self, peer_a, peer_b, turn_server):
        # TURN：中继转发（无法打洞时兜底）
        relay_addr = allocate_relay_address(turn_server)
        
        peer_a.sendto(relay_addr, data)  # A → 中继 → B
        peer_b.sendto(relay_addr, data)  # B → 中继 → A
        
        return relay_addr
```

## 七、面试常见问题

### Q1: P2P 和 CDN 的区别？

CDN 是中心化的边缘节点分发，P2P 是去中心化的用户节点共享。CDN 稳定但成本高，P2P 成本低但受用户行为影响。

### Q2: P2P+CDN 混合架构的优势？

1. 降低成本：用户闲置带宽分担流量
2. 提高覆盖率：用户分布广
3. 减轻源站压力：多级回源
4. 提升体验：就近访问

### Q3: PCDN 合规性问题？

PCDN 使用用户带宽需用户知情同意，通常通过积分奖励激励；运营商侧需符合网络管理法规。

### Q4: NAT 穿透的原理？

通过 STUN 服务器获取公网映射，UDP 打洞让双方 NAT 形成通路；无法打洞时用 TURN 中继转发。

## 八、总结

1. **P2P 定义**：去中心化节点直接共享资源
2. **核心原理**：分片下载、稀有优先、节点调度
3. **P2P+CDN**：CDN 为主 + P2P 分担长尾流量
4. **PCDN**：运营商+内容商合作的 P2P CDN 方案
5. **技术挑战**：NAT 穿透、安全版权、节点质量
