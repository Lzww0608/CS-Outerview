# ChaCha20-Poly1305、Curve25519、BLAKE2s 算法详解

## 二、ChaCha20-Poly1305

### 2.1 算法原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  ChaCha20-Poly1305 组成：                                │
│                                                             │
│  ChaCha20：流密码（Stream Cipher）                        │
│  • 基于 Salsa20 改进                                      │
│  • 256 位密钥，64 位 nonce，64 位计数器                  │
│  • ARX 架构（加法、循环、异或）                         │
│                                                             │
│  Poly1305：消息认证码（MAC）                              │
│  • 基于 Carter-Wegman+ONE 模式                          │
│  • 生成 128 位认证标签                                  │
│  • 速度快于 HMAC                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 ChaCha20 核心

```c
// ChaCha20 核心操作
struct ChaChaState {
    uint32_t state[16];
};

// 初始状态
void chacha20_init(ChaChaState* s, 
                   uint8_t key[32], 
                   uint8_t nonce[12]) {
    // 常量："expand 32-byte k"
    s->state[0]  = 0x61707865;
    s->state[1]  = 0x3320646e;
    s->state[2]  = 0x79622d32;
    s->state[3]  = 0x6b206574;
    
    // 密钥（8 个 32 位字）
    for (int i = 0; i < 8; i++)
        s->state[4+i] = load32_le(key + 4*i);
    
    // Nonce（3 个 32 位字）
    s->state[13] = load32_le(nonce);
    s->state[14] = load32_le(nonce + 4);
    s->state[15] = load32_le(nonce + 8);
}

// ChaCha20 块函数
void chacha20_block(ChaChaState* s) {
    uint32_t x[16];
    memcpy(x, s->state, 64);
    
    // 10 轮 QR 操作
    for (int i = 0; i < 10; i++) {
        quarterround(&x[0], &x[4], &x[8], &x[12]);
        quarterround(&x[1], &x[5], &x[9], &x[13]);
        quarterround(&x[2], &x[6], &x[10], &x[14]);
        quarterround(&x[3], &x[7], &x[11], &x[15]);
        quarterround(&x[0], &x[5], &x[10], &x[15]);
        quarterround(&x[1], &x[6], &x[11], &x[12]);
        quarterround(&x[2], &x[7], &x[8], &x[13]);
        quarterround(&x[3], &x[4], &x[9], &x[14]);
    }
    
    // 加上初始状态
    for (int i = 0; i < 16; i++)
        s->keystream[i] = x[i] + s->state[i];
}
```

### 2.3 Poly1305 认证

```c
// Poly1305 MAC
struct Poly1305State {
    uint128_t r;     // 130 位密钥
    uint128_t s;     // 128 位密钥
    uint128_t acc;   // 累加器
};

// 初始化
void poly1305_init(Poly1305State* st, uint8_t key[32]) {
    // r = clampu(key[0..15])
    st->r = clamp(key);
    
    // s = key[16..31]
    st->s = load128(key + 16);
    
    st->acc = 0;
}

// 计算
void poly1305_update(Poly1305State* st, uint8_t* msg, size_t len) {
    while (len >= 16) {
        // acc += msg (little-endian)
        st->acc += load128(msg);
        
        // acc = (acc * r) mod (2^130 - 5)
        st->acc = mulmod(st->acc, st->r);
        
        msg += 16;
        len -= 16;
    }
    
    // 处理剩余字节
    // ...
}

// 最终认证标签
void poly1305_finish(Poly1305State* st, uint8_t tag[16]) {
    st->acc += st->s;
    store128(tag, st->acc);
}
```

### 2.4 ChaCha20-Poly1305 优缺点

| 优点 | 缺点 |
|------|------|
| 软件实现高效（比 AES 快） | 硬件加速支持较少 |
| 无时序攻击风险 | 不是 NIST 标准 |
| 抗缓存攻击 | 相对较新（2013年发布） |
| 移动设备友好 | - |

## 三、Curve25519

### 3.1 算法原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Curve25519 原理：                                        │
│                                                             │
│  1. 椭圆曲线                                               │
│     y² = x³ + 486662x² + x (mod 2^255 - 19)             │
│                                                             │
│  2. DH 密钥交换                                           │
│     • 双方各选随机私钥 a, b                               │
│     • 公钥 A = a*P, B = b*P                             │
│     • 共享秘密 = a*B = b*A = ab*P                       │
│                                                             │
│  3. 设计原则                                              │
│     • Montgomery 曲线（计算快）                          │
│     • 255 位素数域                                        │
│     • 避免弱密钥                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 密钥交换流程

```c
// Curve25519 DH 交换
#include <curve25519.h>

// 生成密钥对
void keygen(uint8_t public_key[32], 
            uint8_t private_key[32]) {
    // 生成随机 32 字节
    randombytes(private_key, 32);
    
    // 修剪私钥
    private_key[0] &= 248;
    private_key[31] &= 127;
    private_key[31] |= 64;
    
    // 计算公钥
    curve25519_base(public_key, private_key);
}

// 计算共享秘密
void curve25519_shared(uint8_t shared_secret[32],
                       uint8_t private_key[32],
                       uint8_t peer_public[32]) {
    curve25519(shared_secret, private_key, peer_public);
}
```

### 3.3 代码示例

```python
# Python 实现
import nacl.bindings as nacl

def generate_keypair():
    """生成 Curve25519 密钥对"""
    private_key = nacl.crypto_scalarmult_curve25519_random()
    public_key = nacl.crypto_scalarmult_curve25519_base(private_key)
    return public_key, private_key

def shared_secret(private_key, peer_public):
    """计算共享秘密"""
    return nacl.crypto_scalarmult_curve25519(private_key, peer_public)

# 使用
alice_pub, alice_priv = generate_keypair()
bob_pub, bob_priv = generate_keypair()

# Alice 计算共享秘密
shared_alice = shared_secret(alice_priv, bob_pub)

# Bob 计算共享秘密
shared_bob = shared_secret(bob_priv, alice_pub)

# 两者相同
assert shared_alice == shared_bob
```

### 3.4 Curve25519 优缺点

| 优点 | 缺点 |
|------|------|
| 性能优秀（比 RSA 快） | 需要正确实现避免侧信道 |
| 密钥短（32 字节） | 不是 NIST P-曲线 |
| 简单设计 | 相对较新 |
| 无需曲线参数选择 | - |

## 四、BLAKE2s

### 4.1 算法原理

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  BLAKE2 原理：                                            │
│                                                             │
│  1. 基于 SHA-3 候选算法（Hash 函数）                      │
│  2. 比 SHA-256/SHA-512 更快                              │
│  3. 支持可调输出长度（1-32 字节 for BLAKE2s）            │
│                                                             │
│  BLAKE2s：                                                │
│  • 160-256 位输出                                        │
│  • 针对 32 位处理器优化                                   │
│  • 比 SHA-256 快 2 倍                                    │
│                                                             │
│  BLAKE2b：                                                │
│  • 256-512 位输出                                        │
│  • 针对 64 位处理器优化                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 核心压缩函数

```c
// BLAKE2s 压缩函数
void blake2s_compress(blake2s_state* S, 
                      const uint8_t block[BLAKE2S_BLOCKBYTES],
                      uint64_t total_len) {
    uint32_t v[16], m[16];
    
    // 初始化工作向量
    memcpy(v, S->h, 32);
    v[8]  = BL95527a; v[9]  = BL95527b;
    v[10] = BL95527c; v[11] = BL95527d;
    v[12] = S->t[0] ^ 0x6a09e667;
    v[13] = S->t[1] ^ 0xbb67ae85;
    v[14] = S->s[0] ^ 0x3c6ef372;
    v[15] = S->s[1] ^ 0xa54ff53a;
    
    // 加载消息块
    for (int i = 0; i < 16; i++)
        m[i] = load32(block + 4*i);
    
    // 12 轮 G 函数
    for (int i = 0; i < 12; i++) {
        G(v, 0, 4,  8, 12, m[ 0], m[ 1]);
        G(v, 1, 5,  9, 13, m[ 2], m[ 3]);
        G(v, 2, 6, 10, 14, m[ 4], m[ 5]);
        G(v, 3, 7, 11, 15, m[ 6], m[ 7]);
        G(v, 0, 5, 10, 15, m[ 8], m[ 9]);
        G(v, 1, 6, 11, 12, m[10], m[11]);
        G(v, 2, 7,  8, 13, m[12], m[13]);
        G(v, 3, 4,  9, 14, m[14], m[15]);
    }
    
    // 最终哈希
    for (int i = 0; i < 16; i++)
        S->h[i/4][i%4] ^= v[i];
}

// G 函数
#define G(a, b, c, d, x, y) \
    a = (a + b + x) % 2^32; \
    d ^= a; d = rotr32(d, 16); \
    c = (c + d) % 2^32; \
    b ^= c; b = rotr32(b, 12); \
    a = (a + b + y) % 2^32; \
    d ^= a; d = rotr32(d, 8); \
    c = (c + d) % 2^32; \
    b ^= c; b = rotr32(b, 7);
```

### 4.3 使用示例

```python
import hashlib

# BLAKE2s-256 哈希
def blake2s_hash(data):
    return hashlib.blake2s(data, digest_size=32).digest()

# BLAKE2s-128 哈希（更快）
def blake2s_128(data):
    return hashlib.blake2s(data, digest_size=16).digest()

# 带密钥的哈希（MAC）
def blake2s_mac(data, key):
    return hashlib.blake2s(data, key=key, digest_size=32).digest()

# 文件哈希
def hash_file(filepath):
    h = hashlib.blake2s(digest_size=32)
    with open(filepath, 'rb') as f:
        while chunk := f.read(8192):
            h.update(chunk)
    return h.hexdigest()
```

### 4.4 BLAKE2s 优缺点

| 优点 | 缺点 |
|------|------|
| 速度快（比 SHA-256 快 2 倍） | 不是 NIST 标准 |
| 可调输出长度 | 生态不如 SHA 家族 |
| 支持密钥哈希（MAC） | 新算法，审计历史短 |
| SIMD 友好 | - |

## 五、综合对比

### 5.1 算法对比表

| 特性 | ChaCha20-Poly1305 | Curve25519 | BLAKE2s |
|------|-------------------|------------|----------|
| 类型 | 对称加密+认证 | 非对称密钥交换 | 哈希函数 |

| 密钥长度 | 256 位 | 256 位 | 可变（160-512） |
| 性能 | 快（软件） | 非常快 | 快 |

### 5.2 WireGuard 中的应用

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  WireGuard 密钥派生流程：                                  │
│                                                             │
│  1. Curve25519 DH                                         │
│     共享秘密 = Curve25519(私钥, 对端公钥)                 │

│  2. BLAKE2s HKDF                                          │
│     输入：共享秘密                                         │
│     输出：                                                     │
│     - 发送密钥（ChaCha20）                                  │

│     - 发送 nonce                                            │
│     - 接收 nonce                                            │
│                                                             │
│  3. ChaCha20-Poly1305                                      │
│     加密 = ChaCha20(发送密钥, nonce, 明文)                │
│     认证 = Poly1305(发送密钥, 加密数据)                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 六、面试常见问题

### Q1: 为什么 WireGuard 选择这些算法？

这些算法组合提供了高性能、高安全性，同时避免专利和硬件依赖。相比 AES，它们的软件实现效率更高，特别适合移动和嵌入式场景。

### Q2: ChaCha20 为什么比 AES 快？

AES 在无硬件支持时需要查表，面临缓存时序攻击风险；ChaCha20 使用 ARX 操作，天然抗时序攻击，且代码更简单。

### Q3: Curve25519 比 RSA 安全吗？

Curve25519 使用 256 位密钥，提供约 128 位安全强度；RSA-2048 提供约 112 位安全。Curve25519 更安全且性能更好。

### Q4: BLAKE2 vs SHA-3？

BLAKE2 是 BLAKE 的优化版，比 SHA-3 更快；SHA-3 适合需要高安全保证的场景，BLAKE2 适合性能敏感场景。

## 七、总结

1. **ChaCha20-Poly1305**：对称加密+认证，软件高效，适合移动设备
2. **Curve25519**：椭圆曲线 DH，密钥短，性能优秀
3. **BLAKE2s**：快速哈希，可调长度，支持 MAC
4. **组合优势**：三者组合提供完整现代密码学方案
5. **适用场景**：WireGuard、TLS、移动安全、物联网
