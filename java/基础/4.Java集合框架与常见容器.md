# 4. Java 集合框架与常见容器

Java 集合框架把常用容器按接口抽象成 `Collection` 和 `Map` 两大体系。面试里问“常见集合有哪些”时，建议按 List、Set、Queue/Deque、Map 来回答，并说明底层结构、复杂度和适用场景。

## 1. Collection 体系

### List

`List` 表示有序、可重复集合。

| 实现 | 底层结构 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| `ArrayList` | 动态数组 | 随机访问 `O(1)`，中间插删 `O(n)` | 读多、尾部追加多 |
| `LinkedList` | 双向链表 | 已知节点插删快，但随机访问 `O(n)` | 队列、少量链式操作 |
| `Vector` | 动态数组 + 同步方法 | 线程安全但锁粒度粗 | 历史类，现代项目少用 |

`ArrayList` 扩容会分配新数组并复制元素，所以能预估容量时可以在构造时指定初始容量。

### Set

`Set` 表示不重复集合。

| 实现 | 底层结构 | 特点 |
| --- | --- | --- |
| `HashSet` | 基于 `HashMap` | 无序，平均 `O(1)` 查找 |
| `LinkedHashSet` | 哈希表 + 双向链表 | 保留插入顺序 |
| `TreeSet` | 红黑树 | 有序，查找插入删除 `O(log n)` |

自定义对象放入 `HashSet` 时，同样要正确实现 `equals()` 和 `hashCode()`。

### Queue 和 Deque

`Queue` 表示队列，`Deque` 表示双端队列。

1. `ArrayDeque`：数组循环队列，适合栈、队列、双端队列，不允许 `null`。
2. `LinkedList`：也实现了 `Deque`，但节点对象更多，缓存局部性较差。
3. `PriorityQueue`：基于二叉堆，堆顶访问 `O(1)`，插入和删除堆顶 `O(log n)`。
4. `BlockingQueue`：并发阻塞队列，例如 `ArrayBlockingQueue`、`LinkedBlockingQueue`、`DelayQueue`。

`PriorityQueue` 不是排序容器，它只保证每次 `peek/poll` 得到当前优先级最高或最低的元素，内部数组不是全局有序。

## 2. Map 体系

`Map` 保存 key-value 映射，不属于 `Collection` 子接口。

| 实现 | 底层结构 | 特点 | 场景 |
| --- | --- | --- | --- |
| `HashMap` | 数组 + 链表/红黑树 | 无序，平均 `O(1)` | 通用 key-value |
| `LinkedHashMap` | 哈希表 + 双向链表 | 保留插入顺序或访问顺序 | LRU、本地缓存 |
| `TreeMap` | 红黑树 | key 有序，`O(log n)` | 范围查询、排序遍历 |
| `Hashtable` | 哈希表 + synchronized | 线程安全但老旧 | 历史兼容 |
| `ConcurrentHashMap` | CAS + 桶级锁等 | 高并发安全 Map | 多线程共享状态 |

`HashMap` 允许一个 `null` key 和多个 `null` value；`ConcurrentHashMap` 不允许 `null`，避免并发下 `get(key) == null` 无法区分不存在和 value 为 null。

## 3. 如何选型

1. 按下标高频读取：`ArrayList`。
2. 需要去重且不关心顺序：`HashSet`。
3. 需要有序集合或范围查询：`TreeSet` / `TreeMap`。
4. 需要保持插入顺序：`LinkedHashSet` / `LinkedHashMap`。
5. 需要队列或栈：优先 `ArrayDeque`。
6. 需要 Top K、任务优先级、定时调度：`PriorityQueue`。
7. 多线程共享 Map：`ConcurrentHashMap`。
8. 生产消费阻塞队列：`BlockingQueue`。

不要只根据接口名选择容器，要结合访问模式、是否有序、是否允许重复、并发安全和内存开销。

## 4. 易错点

1. `ArrayList` 查找某个值是 `O(n)`，只有按下标访问才是 `O(1)`。
2. `LinkedList` 插入不一定总是 `O(1)`，如果要先按下标找到位置，查找本身是 `O(n)`。
3. `HashMap` 平均 `O(1)`，但 hash 冲突严重时会退化；JDK 8 树化后桶内查找可变为 `O(log n)`。
4. `TreeMap` 有序但不是哈希表，所有核心操作通常是 `O(log n)`。
5. 普通集合的 fail-fast 迭代器不是并发安全保证，只是尽力发现结构修改。
6. 线程安全集合也不代表复合操作天然原子，例如“先判断不存在再插入”要用 `putIfAbsent`。

## 5. 面试回答模板

Java 常见集合可以分为 List、Set、Queue/Deque 和 Map。List 里 `ArrayList` 是动态数组，随机访问快，`LinkedList` 是双链表；Set 里 `HashSet` 基于哈希表，`TreeSet` 基于红黑树；Queue 里 `ArrayDeque` 适合普通队列和栈，`PriorityQueue` 基于堆；Map 里 `HashMap` 是数组加链表/红黑树，`LinkedHashMap` 能维护顺序，`TreeMap` 支持有序和范围查询，`ConcurrentHashMap` 用于并发场景。选型要看是否需要有序、去重、范围查询、并发安全和访问复杂度。
