# 4. 倒水问题变体

倒水问题通常给两个或多个容量固定的杯子，允许装满、倒空、从一个杯子倒到另一个杯子，问能否得到目标水量，或者求最少操作次数。

## 1. 两个杯子的可达性

如果有两个杯子，容量分别是 `a` 和 `b`，目标水量是 `target`。在允许无限水源和倒空操作的情况下，能得到 `target` 的充要条件是：

```text
target <= max(a, b)
target % gcd(a, b) == 0
```

原因是所有能表示出来的水量本质上都可以看成 `a` 和 `b` 的整数线性组合：

```text
x * a + y * b
```

根据裴蜀定理，能表示的水量必须是 `gcd(a, b)` 的倍数。容量上还不能超过最大杯子容量。

## 2. 求最少步数：BFS

如果题目要求最少操作次数，更稳妥的做法是把每个状态看作 `(x, y)`，表示两个杯子当前水量，然后做 BFS。

每个状态最多有 6 类操作：

1. 装满 A。
2. 装满 B。
3. 倒空 A。
4. 倒空 B。
5. A 倒向 B，直到 A 空或 B 满。
6. B 倒向 A，直到 B 空或 A 满。

BFS 第一次到达目标状态时，步数就是最少步数。

```cpp
#include <algorithm>
#include <queue>
#include <set>
#include <utility>
#include <vector>

struct State {
    int x;
    int y;
    int step;
};

int minSteps(int a, int b, int target) {
    std::queue<State> q;
    std::set<std::pair<int, int>> visited;

    q.push({0, 0, 0});
    visited.insert({0, 0});

    while (!q.empty()) {
        State cur = q.front();
        q.pop();

        if (cur.x == target || cur.y == target || cur.x + cur.y == target) {
            return cur.step;
        }

        std::vector<std::pair<int, int>> next;
        next.push_back({a, cur.y});
        next.push_back({cur.x, b});
        next.push_back({0, cur.y});
        next.push_back({cur.x, 0});

        int pourAB = std::min(cur.x, b - cur.y);
        next.push_back({cur.x - pourAB, cur.y + pourAB});

        int pourBA = std::min(cur.y, a - cur.x);
        next.push_back({cur.x + pourBA, cur.y - pourBA});

        for (auto [nx, ny] : next) {
            if (!visited.count({nx, ny})) {
                visited.insert({nx, ny});
                q.push({nx, ny, cur.step + 1});
            }
        }
    }

    return -1;
}
```

## 3. 常见变体

### 目标是某个杯子里有 target

判断条件是：

```text
x == target || y == target
```

### 目标是总水量为 target

判断条件是：

```text
x + y == target
```

这种版本允许目标水量大于单个杯子容量，但不能超过 `a + b`。

### 多个杯子

多个杯子时仍然可以 BFS，只是状态变成向量：

```text
(v1, v2, v3, ...)
```

操作包括装满任一杯、倒空任一杯、任意两个杯子之间倒水。状态空间上界是：

```text
(c1 + 1) * (c2 + 1) * ... * (ck + 1)
```

杯子多或容量大时，BFS 可能爆炸，需要用数学判定、双向 BFS 或启发式搜索优化。

## 4. 易错点

1. 只问“能否得到”时，可以先用 `gcd` 快速判断。
2. 问“最少步数”时，贪心倒水不一定覆盖所有变体，BFS 更稳。
3. 状态要去重，否则会在装满、倒空、互倒之间循环。
4. 要问清楚目标是“某个杯子里有 target”，还是“两个杯子总量为 target”。
5. 如果容量和目标都很大，直接 BFS 可能不可接受，需要先做可达性剪枝。

## 5. 面试回答模板

倒水问题先看题目问可达性还是最少步数。两个杯子只问能否得到目标水量时，可以用裴蜀定理判断：目标必须是两个容量最大公约数的倍数，并且不能超过容量约束。若问最少操作次数，把 `(x, y)` 当作状态，用 BFS 枚举装满、倒空、A 倒 B、B 倒 A 六种操作，第一次到达目标就是最少步数。变体的关键是明确目标判断条件和状态去重。
