# 3. 抛硬币概率与随机数转换

## 1. 面试官先抛硬币，先正面者胜

题目：两个人轮流抛一枚公平硬币，面试官先抛。谁先抛到正面谁赢，问面试官获胜概率。

面试官获胜有这些情况：

1. 第一轮面试官直接正面：概率 `1/2`。
2. 第一轮两人都是反面，第二轮面试官正面：概率 `(1/2 * 1/2) * 1/2 = 1/8`。
3. 前两轮双方都是反面，第三轮面试官正面：概率 `(1/4)^2 * 1/2 = 1/32`。

所以：

```text
P = 1/2 + 1/8 + 1/32 + ...
  = 1/2 * (1 + 1/4 + 1/16 + ...)
  = 1/2 / (1 - 1/4)
  = 2/3
```

也可以列方程：

```text
P = 1/2 + 1/4 * P
P = 2/3
```

## 2. 用有偏 0/1 生成器生成等概率 0/1

题目：生成器返回 0 的概率是 `p`，返回 1 的概率是 `1-p`，要求生成等概率 0 和 1。

使用 Von Neumann 方法：

1. 连续生成两次。
2. 如果结果是 `01`，返回 0。
3. 如果结果是 `10`，返回 1。
4. 如果结果是 `00` 或 `11`，丢弃重来。

因为：

```text
P(01) = p(1-p)
P(10) = (1-p)p
```

两者概率相等，所以返回 0 和 1 等概率。

伪代码：

```cpp
int fair01() {
    while (true) {
        int a = biased01();
        int b = biased01();
        if (a == 0 && b == 1) {
            return 0;
        }
        if (a == 1 && b == 0) {
            return 1;
        }
    }
}
```

## 3. 用等概率 0-4 生成等概率 0-6

题目：已有 `rand5()` 等概率返回 `[0, 4]`，实现 `rand7()` 等概率返回 `[0, 6]`。

思路是拒绝采样。

两次 `rand5()` 可以生成 `[0, 24]`：

```text
x = rand5() * 5 + rand5()
```

取其中 `[0, 20]` 的 21 个值，正好可以均匀映射到 7 个结果：

```text
return x % 7
```

如果 `x >= 21`，丢弃重来。

```cpp
int rand7() {
    while (true) {
        int x = rand5() * 5 + rand5(); // 0..24
        if (x < 21) {
            return x % 7;
        }
    }
}
```

## 4. 易错点

1. `rand5() % 7` 没意义，范围不够。
2. `rand5() * 2` 之类的线性变换不能保证覆盖且均匀。
3. 拒绝采样必须只保留目标范围整数倍大小的样本空间。
4. Von Neumann 方法要求两次生成独立同分布。

## 5. 面试回答模板

先后手抛硬币问题可以列方程：先手赢要么第一下正面，要么双方都反面后回到原问题，所以 `P = 1/2 + 1/4P`，得到 `P = 2/3`。有偏 0/1 生成公平 0/1 用 Von Neumann 方法：`01` 返回 0，`10` 返回 1，`00/11` 重来，因为 `01` 和 `10` 概率都是 `p(1-p)`。`rand5` 生成 `rand7` 用两次生成 `0..24`，只接受 `0..20`，返回 `% 7`，其余拒绝重采样。
