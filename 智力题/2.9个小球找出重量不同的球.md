# 2. 9个小球找出重量不同的球

## 1. 题目

有 9 个外观相同的小球，其中 1 个重量不同。使用天平，找出这个异常球。

这个题目要先问清楚一个条件：异常球是已知偏重/偏轻，还是不知道偏重还是偏轻。两个版本需要的称量次数不同。

## 2. 已知异常球偏重或偏轻：2 次

以“已知异常球偏重”为例：

1. 把 9 个球分成三组：`A={1,2,3}`，`B={4,5,6}`，`C={7,8,9}`。
2. 第一次称 `A` 和 `B`。
3. 如果相等，异常球在 `C`；如果不相等，偏重的一组里有异常球。
4. 第二次在嫌疑组里称任意两个球。
5. 如果相等，第三个球异常；如果不等，偏重的那个异常。

如果已知异常球偏轻，逻辑相同，只是选择偏轻的一组。

## 3. 不知道偏重还是偏轻：至少 3 次

如果不知道异常球偏重还是偏轻，一共有：

```text
9 个球 * 2 种状态 = 18 种可能
```

天平每次称量只有三种结果：左重、右重、平衡。两次最多区分：

```text
3^2 = 9 种结果
```

`9 < 18`，所以两次一定不够，至少需要三次。

## 4. 3 次称量策略

编号为 `1` 到 `9`。

第一次称：

```text
1,2,3  vs  4,5,6
```

### 情况一：第一次平衡

异常球在 `7,8,9` 中，`1` 到 `6` 都是正常球。

第二次称：

```text
7  vs  8
```

1. 如果平衡，异常球是 `9`。第三次称 `9 vs 1`，判断它偏重还是偏轻。
2. 如果 `7` 重，可能是 `7` 偏重或 `8` 偏轻。第三次称 `7 vs 1`：如果 `7` 重，则 `7` 偏重；否则 `8` 偏轻。
3. 如果 `8` 重，可能是 `8` 偏重或 `7` 偏轻。第三次称 `7 vs 1`：如果 `7` 轻，则 `7` 偏轻；否则 `8` 偏重。

### 情况二：第一次左边重

可能性只剩：

```text
1重、2重、3重、4轻、5轻、6轻
```

此时 `7,8,9` 是正常球。

第二次称：

```text
1,4,5  vs  2,7,8
```

1. 如果平衡，只可能是 `3重` 或 `6轻`。第三次称 `3 vs 7`：如果 `3` 重，则 `3重`；如果平衡，则 `6轻`。
2. 如果左边重，只可能是 `1重`。第三次可用于确认。
3. 如果右边重，可能是 `2重`、`4轻`、`5轻`。第三次称 `4 vs 5`：如果平衡，则 `2重`；如果 `4` 轻，则 `4轻`；如果 `5` 轻，则 `5轻`。

### 情况三：第一次右边重

和情况二对称，可能性只剩：

```text
1轻、2轻、3轻、4重、5重、6重
```

第二次仍称：

```text
1,4,5  vs  2,7,8
```

1. 如果平衡，只可能是 `3轻` 或 `6重`。第三次称 `3 vs 7`：如果 `3` 轻，则 `3轻`；如果平衡，则 `6重`。
2. 如果右边重，只可能是 `1轻`。第三次可用于确认。
3. 如果左边重，可能是 `2轻`、`4重`、`5重`。第三次称 `4 vs 5`：如果平衡，则 `2轻`；如果 `4` 重，则 `4重`；如果 `5` 重，则 `5重`。

## 5. 易错点

1. 不要默认“重量不同”一定是已知偏重，面试里要先澄清题意。
2. 如果不知道偏重还是偏轻，两次称量信息量不够，必须至少三次。
3. 每次称量后要把“正常球”利用起来，正常球是后续判断偏重/偏轻的基准。
4. 天平策略的本质是把剩余可能性尽量平均分到左重、右重、平衡三个结果里。
