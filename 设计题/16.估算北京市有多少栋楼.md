# 16. 估算北京市有多少栋楼

## 1. 题目本质

“如何知道北京市有多少栋楼”是一个估算和数据获取设计题。面试官通常不关心你能背出一个真实数字，而是看你是否能：

1. 定义清楚“楼”的口径。
2. 找到可靠数据源。
3. 设计采集、去重、统计和校验方法。
4. 给出误差评估。

## 2. 先定义口径

必须先澄清：

1. **楼栋口径**：独立建筑轮廓算一栋，还是一个小区单元楼算一栋。
2. **范围口径**：北京市行政区，还是六环内、建成区。
3. **类型口径**：住宅、办公、商业、厂房、学校、医院、临建是否都算。
4. **时间口径**：截至某一天，还是实时动态。

如果口径不清，统计结果没有意义。

## 3. 数据源方案

可以组合多个数据源：

1. **遥感影像 + 建筑物轮廓识别**：通过卫星图或航拍图识别建筑 footprint。
2. **地图数据**：POI、小区楼栋、建筑轮廓、地址库。
3. **政府/住建/不动产数据**：楼盘、建筑许可、房屋登记、地名地址库。
4. **街景和实地抽样**：校验遥感和地图数据漏检、误检。
5. **众包或企业内部数据**：配送、地图、房产、物业等业务数据。

工程上不要依赖单一来源，应该多源融合并交叉校验。

## 4. 技术路线

### 路线一：直接数据统计

如果能拿到权威楼栋库：

```text
获取楼栋表 -> 按行政区过滤 -> 清洗重复记录 -> 按楼栋 ID 去重 -> 汇总
```

关键是数据口径和更新日期。

### 路线二：遥感识别

如果没有权威数据：

```text
获取遥感影像
-> 图像分割识别建筑物轮廓
-> 合并相邻重复轮廓
-> 过滤道路、桥梁、临时结构
-> 按行政区裁剪
-> 统计轮廓数量
```

可使用建筑物语义分割模型，人工抽样标注一部分区域做精度评估。

### 路线三：分层抽样估算

如果只能快速估算，可以按城市区域分层：

1. 核心城区高密度区。
2. 普通住宅区。
3. 郊区低密度区。
4. 工业园区。
5. 山区/水域/绿地。

每类随机抽样若干网格，统计单位面积楼栋数，再乘以对应区域面积：

```text
总楼栋数 = Σ(区域面积_i * 样本平均楼栋密度_i)
```

同时计算置信区间，给出误差范围。

## 5. 去重和质量控制

常见问题：

1. 一个建筑被多个数据源重复记录。
2. 一个大楼被切成多个轮廓。
3. 连体楼、裙楼、地下建筑口径不一致。
4. 新建和拆除建筑数据更新不及时。
5. 地图 POI 是店铺或机构，不等于楼栋。

处理方法：

1. 使用空间相交和 IoU 合并重复轮廓。
2. 建立楼栋唯一 ID。
3. 对抽样区域人工复核。
4. 按区域类型分别估计误差。
5. 用历史版本对比发现异常变化。

## 6. 面试回答模板

我不会直接猜一个数，而是先定义口径：北京市行政区内，什么算一栋楼，住宅和商业是否都算，统计截至哪一天。然后用多源数据：优先拿住建或不动产楼栋库；拿不到则用地图建筑轮廓和遥感影像识别，按行政区裁剪后做空间去重。为了校验结果，可以按核心城区、郊区、工业区等分层抽样，人工核验样本网格，计算楼栋密度和误差区间。最终输出的不只是一个数字，还应该包括口径、数据源、更新时间和置信度。
