# Python 装饰器与字符串拼接

面试里问 Python 装饰器和字符串拼接，通常不是考语法细节，而是看你是否理解函数对象、闭包、语法糖和不可变字符串的性能影响。

## 1. 装饰器是什么

装饰器本质上是一个可调用对象，它接收一个函数或类，返回一个新的函数或类，用来在不修改原始代码的情况下增强行为。

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    return a + b
```

上面的 `@log_call` 等价于：

```python
add = log_call(add)
```

## 2. 保留函数元信息

普通 wrapper 会丢失原函数的 `__name__`、`__doc__` 等元信息，工程中应使用 `functools.wraps`：

```python
from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

这对日志、调试、自动文档、路由注册和测试框架都很重要。

## 3. 带参数的装饰器

带参数装饰器需要多包一层函数：

```python
from functools import wraps

def retry(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for _ in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception as exc:
                    last_error = exc
            raise last_error
        return wrapper
    return decorator

@retry(times=3)
def request_remote():
    ...
```

这里 `@retry(times=3)` 等价于：

```python
request_remote = retry(times=3)(request_remote)
```

## 4. 常见应用场景

1. **日志记录**：记录函数调用参数、耗时、返回值。
2. **鉴权**：Web 框架中校验登录态和权限。
3. **重试**：远程调用失败时自动重试。
4. **缓存**：例如 `functools.lru_cache`。
5. **限流和熔断**：保护高成本接口。
6. **事务管理**：函数执行前开启事务，结束后提交或回滚。

异步函数装饰器要注意 wrapper 也应是 `async def`，并在内部 `await func(...)`。

## 5. 装饰器易错点

1. 忘记 `return wrapper`，装饰后函数变成 `None`。
2. 忘记调用原函数或忘记返回原函数结果。
3. 不使用 `functools.wraps`，导致函数名和文档丢失。
4. 多个装饰器执行顺序容易混淆：

```python
@a
@b
def f():
    pass

# 等价于 f = a(b(f))
```

5. 装饰器闭包捕获可变对象时，要注意共享状态和线程安全。

## 6. Python 字符串拼接

Python 字符串是不可变对象，常见拼接方式：

```python
a = "hello"
b = "world"

s1 = a + " " + b
s2 = f"{a} {b}"
s3 = "{} {}".format(a, b)
s4 = " ".join([a, b])
```

选择建议：

1. 少量字符串直接用 `+` 或 f-string，f-string 可读性最好。
2. 循环中拼接大量字符串，优先把片段放入 list，最后 `''.join(parts)`。
3. 需要复杂格式化时使用 f-string 的格式控制，例如 `{cost:.2f}`。
4. 需要构造二进制内容时使用 `bytes`、`bytearray` 或 `io.BytesIO`。

## 7. 为什么循环里不建议大量使用 `+`

字符串不可变，`s += part` 通常会创建新字符串并复制旧内容。大量循环拼接可能退化为较高的时间和内存开销。

推荐写法：

```python
parts = []
for item in items:
    parts.append(str(item))
result = ",".join(parts)
```

如果是流式写入，也可以使用 `io.StringIO`：

```python
from io import StringIO

buf = StringIO()
for item in items:
    buf.write(str(item))
result = buf.getvalue()
```

## 8. 面试回答模板

Python 装饰器本质是接收函数并返回新函数的可调用对象，`@decorator` 是 `func = decorator(func)` 的语法糖。它常用于日志、鉴权、重试、缓存、事务和限流。工程中要用 `functools.wraps` 保留原函数元信息，带参数装饰器需要外面再包一层函数。字符串拼接方面，少量内容用 `+` 或 f-string，大量循环拼接不要反复 `+=`，更推荐先收集到 list 再 `''.join()`，或用 `io.StringIO`。
