# Python 与 Pandas 面试基础

面试里问“会不会 Python、有没有用过 Pandas”，通常不是考语法背诵，而是看你能不能用 Python 快速处理数据、写脚本、做实验和排查问题。

## 1. Python 常用能力

后端和算法项目里常用 Python 做这些事：

1. **脚本自动化**：批量处理文件、日志、配置、测试数据。
2. **数据分析**：读取 CSV、Excel、JSON、Parquet，做聚合和可视化。
3. **模型实验**：配合 NumPy、Pandas、PyTorch、scikit-learn 快速验证。
4. **服务开发**：用 Flask、FastAPI 写轻量 API 或模型服务。
5. **运维排查**：调用 HTTP/RPC 接口、生成压测数据、分析错误日志。

基础语法要能说明：

1. list、tuple、dict、set 的区别。
2. 生成器和迭代器适合流式处理大数据。
3. 装饰器可以做日志、鉴权、重试、耗时统计。
4. `with` 上下文管理器用于自动关闭文件、锁、连接。
5. 虚拟环境和依赖管理可以用 `venv`、pip、Poetry、Conda。

## 2. Pandas 常用操作

Pandas 的核心数据结构：

1. `Series`：一维带索引数组。
2. `DataFrame`：二维表格，类似内存中的关系表。

常用操作：

```python
import pandas as pd

df = pd.read_csv("log.csv")

# 过滤
errors = df[df["status"] >= 500]

# 分组聚合
stat = (
    df.groupby("api")
      .agg(count=("api", "size"), avg_latency=("latency_ms", "mean"))
      .reset_index()
)

# 排序
top = stat.sort_values("avg_latency", ascending=False).head(10)
```

常见场景：

1. 按用户、接口、时间窗口统计指标。
2. 清洗缺失值、异常值和重复行。
3. 合并多张表：`merge`、`join`、`concat`。
4. 时间序列重采样：`resample`、滑动窗口。
5. 离线分析模型输入特征分布。

## 3. Pandas 易错点

1. DataFrame 默认很多操作会复制数据，大表处理要关注内存。
2. 避免逐行 `for` 循环，优先用向量化、`groupby`、`merge`。
3. 链式赋值可能触发 `SettingWithCopyWarning`，修改前最好显式 `.copy()` 或用 `.loc`。
4. `NaN` 和 `None` 行为不同，聚合时默认可能跳过缺失值。
5. 时间列要转成 `datetime64`，否则排序和窗口统计可能按字符串处理。

示例：

```python
df = df.copy()
df.loc[df["latency_ms"].isna(), "latency_ms"] = 0
df["time"] = pd.to_datetime(df["time"])
```

## 4. `__new__` 方法

`__new__` 是对象创建阶段调用的方法，负责“分配并返回对象实例”；`__init__` 是对象初始化阶段调用的方法，负责“给已经创建好的对象填充状态”。面试里可以用一句话区分：`__new__` 决定有没有这个对象，`__init__` 决定这个对象初始化成什么样。

调用顺序大致是：

```python
obj = cls.__new__(cls, *args, **kwargs)
if isinstance(obj, cls):
    cls.__init__(obj, *args, **kwargs)
```

常见使用场景：

1. **不可变类型定制**：继承 `tuple`、`str`、`int` 这类不可变对象时，值必须在 `__new__` 阶段确定。
2. **单例或对象池**：`__new__` 可以返回缓存中的旧对象，而不是每次创建新对象。
3. **框架级对象构造**：ORM、序列化框架、代理对象可能需要控制实例创建过程。

示例：

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self, name):
        self.name = name
```

易错点：

1. `__new__` 必须返回对象；如果返回的不是当前类实例，`__init__` 可能不会被调用。
2. 单例写在 `__new__` 里还要考虑线程安全，否则并发创建时可能产生多个实例。
3. 大多数业务代码不需要重写 `__new__`，优先使用普通构造函数、工厂函数或依赖注入。

## 5. 元类 metaclass

Python 中“一切皆对象”，类本身也是对象；创建类的类叫元类。普通对象由类创建，普通类默认由 `type` 创建，所以 `type` 既可以用来查看对象类型，也可以动态创建类。

```python
class User:
    pass

print(type(User))  # <class 'type'>
```

元类的核心作用是拦截“类对象的创建过程”，在类创建时统一校验、注册、改写属性或生成方法。Python 3 使用 `metaclass=` 指定元类：

```python
class ModelMeta(type):
    def __new__(mcls, name, bases, namespace):
        fields = {
            k: v for k, v in namespace.items()
            if isinstance(v, Field)
        }
        namespace["__fields__"] = fields
        return super().__new__(mcls, name, bases, namespace)

class User(metaclass=ModelMeta):
    id = Field("id")
    name = Field("name")
```

典型应用：

1. **ORM 模型收集字段**：Django ORM、SQLAlchemy Declarative 都会在类定义阶段收集字段和表信息。
2. **插件注册**：类定义完成时自动加入注册表，后续按名称创建实例。
3. **接口约束**：校验子类是否实现必要属性或方法。
4. **DSL 构造**：把类定义语法转成框架内部的描述对象。

注意事项：

1. Python 2 里常见 `__metaclass__`，Python 3 里应写成 `class X(metaclass=Meta):`。
2. 能用装饰器、基类 `__init_subclass__` 或普通注册函数解决时，不要过早使用元类。
3. 多个基类使用不同元类时可能出现 metaclass conflict，需要让元类之间存在继承关系。

## 6. 如何回答学习和使用方式

可以从项目驱动回答：

1. 遇到日志分析、实验数据处理、模型评估时，用 Python 快速写脚本。
2. 常查官方文档和库源码示例，关注 API 参数、边界行为和性能。
3. 对性能敏感场景，会从 Pandas 切到 NumPy、Polars、DuckDB 或 Spark。
4. 脚本沉淀后会加参数解析、日志、异常处理和单元测试，而不是只写一次性 notebook。
