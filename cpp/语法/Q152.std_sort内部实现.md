# std::sort 内部实现

`std::sort` 是 C++ 标准库提供的通用排序算法，要求随机访问迭代器，平均复杂度为 `O(n log n)`。标准不规定具体实现，但主流实现通常采用内省排序（introsort）：快速排序作为主流程，递归过深时切换到堆排序，小区间使用插入排序。

## 为什么不是单纯快排

普通快速排序平均很快，但最坏复杂度是 `O(n^2)`。如果输入已经有序、逆序，或者 pivot 总是选得很差，递归会退化。

内省排序的思路是：

1. 开始使用快排分区，获得较好的平均性能和缓存局部性。
2. 记录递归深度，深度超过阈值时认为可能退化。
3. 退化时切换到堆排序，保证最坏 `O(n log n)`。
4. 小区间使用插入排序，减少递归和分区常数开销。

常见深度阈值：

```text
2 * floor(log2(n))
```

## 简化流程

```text
sort(first, last):
    depth_limit = 2 * log2(last - first)
    introsort(first, last, depth_limit)
    insertion_sort_small_ranges(first, last)
```

`introsort` 简化逻辑：

```text
while range_size > threshold:
    if depth_limit == 0:
        heap_sort(range)
        return
    depth_limit--
    pivot = choose_pivot(range)
    mid = partition(range, pivot)
    recursively sort smaller side
    loop on larger side
insertion_sort(range)
```

真实标准库会做更多优化，例如三数取中、unguarded partition、尾递归消除、对小区间延迟插排等。

## `sort` 和 `stable_sort`

| 对比项 | `std::sort` | `std::stable_sort` |
| --- | --- | --- |
| 稳定性 | 不稳定 | 稳定 |
| 典型算法 | 内省排序 | 归并排序或其变体 |
| 额外空间 | 通常 `O(log n)` 递归栈 | 通常需要额外缓冲区 |
| 适用迭代器 | 随机访问迭代器 | 随机访问迭代器 |
| 使用场景 | 默认排序，性能优先 | 相等元素原相对顺序必须保留 |

## 比较器要求

`std::sort` 的比较器必须满足严格弱序：

1. `comp(a, a)` 必须为 false。
2. 如果 `comp(a, b)` 为 true，则 `comp(b, a)` 必须为 false。
3. 传递性要成立。
4. 等价关系也要传递。

错误比较器会导致排序结果异常，甚至在部分实现中触发越界或死循环。

错误示例：

```cpp
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a <= b; // 错：a == b 时也返回 true
});
```

正确写法：

```cpp
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a < b;
});
```

## vector 自定义排序怎么写

改写 `vector` 排序通常不是改 `vector` 本身，而是给 `std::sort` 传入比较规则。常见方式有三种：

### 1. lambda 比较器

```cpp
struct User {
    int id;
    int score;
};

std::vector<User> users = {{1, 90}, {2, 95}, {3, 90}};

std::sort(users.begin(), users.end(), [](const User& a, const User& b) {
    if (a.score != b.score) {
        return a.score > b.score; // 分数降序
    }
    return a.id < b.id;           // id 升序，保证等价关系清晰
});
```

### 2. 重载 `operator<`

当类型存在自然顺序时，可以定义 `operator<`：

```cpp
struct Point {
    int x;
    int y;

    bool operator<(const Point& other) const {
        if (x != other.x) {
            return x < other.x;
        }
        return y < other.y;
    }
};
```

### 3. 函数对象

复杂比较逻辑可以封装成函数对象，便于复用和保存配置：

```cpp
struct SortByScore {
    bool desc = true;

    bool operator()(const User& a, const User& b) const {
        return desc ? a.score > b.score : a.score < b.score;
    }
};
```

如果要求相同关键字保持原有相对顺序，用 `std::stable_sort`。无论哪种方式，比较器都必须满足严格弱序，尤其不要写 `<=` 或让比较结果依赖会变化的外部状态。

## 易错点

1. `std::sort` 不稳定，相等元素顺序可能变化。
2. `std::sort` 要求随机访问迭代器，不能直接用于 `list`；`list` 有自己的 `list::sort()`。
3. 比较器不能写成 `<=` 或 `>=`。
4. 排序过程中不要修改参与排序的容器结构。
5. `std::sort` 不是标准规定的某一种固定算法，面试回答“主流实现是内省排序”更准确。

## 面试回答模板

`std::sort` 标准只要求复杂度和语义，不强制规定实现。主流实现一般是内省排序：先用快速排序分区，平均性能好、缓存友好；当递归深度超过大约 `2logn` 时切换堆排序，避免快排最坏 `O(n^2)`；小区间用插入排序降低常数。它不稳定，如果要保持相等元素的相对顺序，用 `std::stable_sort`。比较器必须满足严格弱序，不能写成 `<=`。
