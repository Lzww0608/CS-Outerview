# sizeof and strlen

1. `sizeof` 是一个编译时运算符，用于确定变量或数据类型在内存中所占的字节大小。它返回的是分配给变量或数据类型的总空间大小，而不是实际存储的内容长度。例如，`sizeof(int)` 通常会返回 4，表示一个整型变量占用 4 个字节的空间。`sizeof` is a compile-time operator used to determine the size in bytes of variables or data types in memory. It returns the total size of space allocated to variables or data types, rather than the length of the content stored. For example, `sizeof(int)` typically returns 4, indicating that an integer variable occupies 4 bytes of space.
2. `strlen` 是一个运行时函数，用于计算字符串的长度，不包括结尾的空字符（'\0'）。它遍历字符串直到遇到空字符，然后返回遍历过的字符数。例如，`strlen("hello")` 会返回 5，因为 "hello" 包含五个字符。`strlen` is a run-time function used to calculate the length of a string, excluding the null character('\0').  It traverses the string until it encounters the null character, and then returns the number of characters traversed. For example,  `strlen("hello")` will return 5, because "hello" contains five characters.

简而言之，`sizeof` 返回数据类型或变量分配的内存大小，而 `strlen` 返回字符串的实际长度（不包括空字符）。需要注意的是，`sizeof`可以求任何类型的大小，而`strlen`只能用于计算字符串的长度。In summary, `sizeof` returns the memory size allocated to a variable or data type, while  `strlen` returns the actual length of a string(excluding the null character). It's important to note that `sizeof` can be used to calculate the size of any type, however, `strlen` can only be used to calculate the length of a string.

note: `sizeof` is an operator, so the parentheses can be omitted.

```c++
#include <stdio.h>
#include <string.h>

int main() {
    int number = 0;
    char str[] = "hello";
	//sizeof is an operator, so the parentheses can be omitted. 
    printf("Size of number (int): %lu bytes\n", sizeof number);//4 bytes
    //Size of char array including null character
    printf("Size of str (char array): %lu bytes\n", sizeof(str)); //6 bytes
    // Length of string excluding null character
    printf("Length of str (string): %lu characters\n", strlen(str)); //5 cahracters

    return 0;
}

```

## sizeof 的核心规则

1. `sizeof` 是运算符，不是函数。
2. 对普通对象或类型求值时，结果类型是 `std::size_t`。
3. 大多数情况下 `sizeof` 在编译期确定，不会真正求值表达式。
4. `sizeof(char)`、`sizeof(signed char)`、`sizeof(unsigned char)` 恒为 1。
5. `sizeof` 得到的是对象占用字节数，包括结构体 padding，不是有效数据长度。

## 常见 sizeof 数值怎么回答

面试里问 `sizeof(int)`、`sizeof(char*)` 这类问题时，要先说明平台模型。常见 64 位 Linux/macOS 使用 LP64，64 位 Windows 使用 LLP64：

| 表达式 | 常见 32 位平台 | 64 位 Linux/macOS | 64 位 Windows | 标准层面的保证 |
| --- | --- | --- | --- | --- |
| `sizeof(char)` | 1 | 1 | 1 | 必为 1 |
| `sizeof(int)` | 4 | 4 | 4 | 至少 2 字节，常见为 4 |
| `sizeof(long)` | 4 | 8 | 4 | 至少不小于 `int` |
| `sizeof(char*)` | 4 | 8 | 8 | 取决于地址宽度 |
| `sizeof(int*)` | 4 | 8 | 8 | 取决于地址宽度 |

`int` 不一定是 4 字节，标准只规定了相对大小和最小范围。工程里如果协议、文件格式或网络包要求精确位宽，应使用 `<cstdint>` 中的 `std::int32_t`、`std::uint64_t` 等固定宽度类型，而不是假设 `int`、`long` 的大小。

表达式通常不会被执行：

```cpp
int x = 1;
std::size_t n = sizeof(++x);
// x 仍然是 1，++x 不会执行
```

例外是 C99 的 VLA 在 C 中可能运行期求值；标准 C++ 不支持 VLA。

## 数组和指针

数组在 `sizeof` 中不会退化为指针：

```cpp
int a[10];
int* p = a;

sizeof(a); // 10 * sizeof(int)
sizeof(p); // 指针大小，64 位下通常是 8
```

但数组作为函数参数时已经退化为指针：

```cpp
void f(int arr[10]) {
    sizeof(arr); // sizeof(int*)，不是 10 * sizeof(int)
}
```

所以函数里不能靠 `sizeof(arr) / sizeof(arr[0])` 获得实参数组长度。C++ 中更推荐使用 `std::array`、`std::vector` 或 `std::span`。

## 类对象的 sizeof

类对象大小受这些因素影响：

1. 非静态数据成员。
2. 内存对齐和 padding。
3. 虚函数带来的 `vptr`。
4. 多继承可能有多个 `vptr` 或基类子对象。
5. 空类大小至少为 1，保证不同对象有不同地址。

不计入对象大小：

1. 普通成员函数。
2. 静态成员函数。
3. 静态成员变量。
4. 虚函数表本身。

示例：

```cpp
struct A {};
struct B { int x; static int y; };
struct C { virtual void f(); int x; };

sizeof(A); // 通常是 1
sizeof(B); // 通常是 4，static y 不计入
sizeof(C); // 64 位下常见是 16：vptr 8 + int 4 + padding 4
```

具体结果和 ABI、编译器、平台位数有关，面试回答不要把数值说死。

## 类和模板类大小什么时候确定

普通类或结构体的对象大小通常在编译期确定。编译器看到完整类定义后，会根据 ABI、成员声明顺序、对齐规则、继承关系、虚函数和虚继承等信息确定对象布局。

```cpp
struct A {
    char c;
    int x;
};

static_assert(sizeof(A) >= sizeof(char) + sizeof(int));
```

这里 `sizeof(A)` 不需要等到运行期，因为对象布局已经是类型的一部分。注意：类的成员函数、静态成员函数、普通静态成员变量不计入单个对象大小；虚表本身也不在对象里，对象通常只保存 `vptr`。

模板类则要等到用具体模板实参实例化时才能确定大小：

```cpp
template <class T>
struct Box {
    T value;
    char tag;
};

sizeof(Box<int>);    // 根据 int 的大小和对齐计算
sizeof(Box<double>); // 根据 double 的大小和对齐计算
```

`Box<int>` 和 `Box<double>` 是两个不同类型，它们的大小可以不同。类模板定义本身只是生成类型的模式，未实例化时没有一个唯一的对象大小。

特殊情况：

1. 如果类中有不完整类型成员，例如 `T member;` 但 `T` 尚未完整定义，则不能计算对象大小。
2. 指针或引用成员的大小不依赖指向类型是否完整，所以可以保存前向声明类型的指针。
3. 标准 C++ 不支持运行期可变长数组成员；对象大小一般不随运行期值改变。
4. `std::vector<T>` 对象本身大小固定，元素存储在堆上，元素个数不影响 `sizeof(vector<T>)`。

## sizeof 和 strlen 对比

```cpp
char s1[] = "hello";
const char* s2 = "hello";

sizeof(s1); // 6，包含 '\0'
strlen(s1); // 5
sizeof(s2); // 指针大小，64 位下通常是 8
strlen(s2); // 5
```

`strlen` 要运行期从指针位置一直扫描到 `'\0'`，如果传入的字符数组没有以 `'\0'` 结束，会越界读取，属于未定义行为。

## 易错点

1. `sizeof` 返回无符号的 `size_t`，和有符号整数比较时可能发生隐式转换。
2. `sizeof(pointer)` 得到指针大小，不是指向内存块大小。
3. 结构体大小通常大于成员大小之和，因为有对齐填充。
4. `sizeof(std::string)` 是 string 对象本身大小，不是字符串内容长度。
5. `sizeof` 不会计算动态数组长度，例如 `new int[n]` 的 `n`。

## 面试回答模板

`sizeof` 是编译期运算符，返回对象或类型占用的字节数，类型是 `size_t`；`strlen` 是运行期函数，只能用于 C 字符串，统计到 `'\0'` 前的字符数。数组直接做 `sizeof` 得到整个数组大小，但数组作为函数参数会退化成指针。类对象的 `sizeof` 包含非静态成员、对齐 padding 和可能存在的 `vptr`，不包含普通成员函数、静态成员和虚表本身。空类大小至少为 1，静态成员变量不计入对象大小。
