# C 和 C++ 的区别

C++ 起源于 C，但不是“带类的 C”这么简单。它在兼容大量 C 语法的基础上，引入了类型系统、面向对象、泛型、RAII、异常、标准库和更强的编译期能力。

## 编程范式

1. **C**：以过程式编程为主，核心是函数、结构体、指针和手动资源管理。
2. **C++**：支持多范式，包括过程式、面向对象、泛型编程、函数式风格和模板元编程。

C++ 的类、继承、多态、模板、运算符重载、lambda、`constexpr` 等能力，使它能表达更高层抽象，同时仍然保留接近底层的性能控制。

## C++ 的主要特性和面向对象理解

面向对象不是简单地“把函数放进类里”，而是用类型把数据、行为和约束组织起来。C++ 的面向对象通常从四个角度回答：

1. **封装**：把对象状态和操作状态的方法放在一起，通过 `public/private/protected` 控制访问边界。
2. **继承**：表达“is-a”关系，复用基类接口或实现，但要避免为了复用代码滥用继承。
3. **多态**：同一接口在不同派生类上有不同行为，C++ 中主要通过虚函数和动态绑定实现运行期多态，也可以通过模板实现编译期多态。
4. **抽象**：把稳定接口暴露给调用方，隐藏底层实现细节，例如用纯虚基类表达接口。

C++ 除了面向对象，还常见这些语言特性：

1. **RAII 和确定性析构**：用对象生命周期管理内存、锁、文件、socket 等资源。
2. **泛型编程**：模板、STL 容器和算法让代码在类型维度复用。
3. **值语义和移动语义**：通过拷贝构造、移动构造、赋值运算符表达对象复制和资源转移。
4. **函数重载和运算符重载**：增强接口表达力，但需要避免语义反直觉。
5. **异常机制**：把错误传播和正常返回值分离，但跨 C ABI、析构函数和高性能路径要谨慎。
6. **现代 C++ 工具**：`auto`、lambda、`constexpr`、智能指针、线程库、原子操作等。

### `class` 和 `struct` 的区别

在 C++ 中，`class` 和 `struct` 的能力基本相同，`struct` 也可以定义成员函数、构造函数、析构函数、静态成员、运算符重载、虚函数和继承。

真正的语言层差异主要是默认访问权限：

1. `class` 的成员默认是 `private`，默认继承也是 `private`。
2. `struct` 的成员默认是 `public`，默认继承也是 `public`。

工程约定上，`struct` 更常用于简单数据聚合、配置项、返回值对象；`class` 更常用于维护不变量、封装资源和暴露受控接口。不要把“`struct` 不能有函数”当成 C++ 结论，那是 C 语言结构体的限制。

## 资源管理

C 常见写法：

```c
FILE* fp = fopen("a.txt", "r");
if (fp != NULL) {
    // ...
    fclose(fp);
}
```

C++ 推荐用 RAII：

```cpp
std::ifstream in("a.txt");
// 离开作用域自动关闭
```

RAII 把资源生命周期绑定到对象生命周期，适合管理内存、文件、锁、socket、事务句柄等资源。异常路径下也能自动释放资源，这是 C++ 工程代码区别于 C 的关键点。

## 类型和抽象能力

1. C++ 有引用、函数重载、默认参数、命名空间、类访问控制。
2. C++ 有构造/析构、拷贝/移动语义，可以把资源所有权写入类型。
3. C++ 模板支持泛型编程，STL 容器和算法就是典型应用。
4. C++ 支持异常，C 通常用返回码和 `errno`。
5. C++ 的 `new/delete` 会调用构造和析构，C 的 `malloc/free` 只负责内存分配释放。

## 编译和链接差异

1. C++ 支持函数重载，编译器会做 name mangling，把参数类型编码进符号名。
2. C 没有函数重载，符号名通常更直接。
3. C++ 调 C 接口时常用 `extern "C"` 禁止 C++ 名字改编，暴露 C ABI。
4. C++ 模板通常在头文件中定义，因为实例化需要看到完整定义。

## 标准库差异

C 标准库偏底层：

1. `malloc/free`
2. `printf/scanf`
3. `qsort/bsearch`
4. 字符串和内存函数

C++ 标准库提供更高层组件：

1. 容器：`vector`、`string`、`map`、`unordered_map`
2. 算法：`sort`、`find`、`lower_bound`
3. 智能指针：`unique_ptr`、`shared_ptr`、`weak_ptr`
4. 并发：`thread`、`mutex`、`condition_variable`、`atomic`
5. 工具：`optional`、`variant`、`function`、`chrono`

## C++ 仍然要注意的成本

1. 虚函数有间接调用和对象模型成本。
2. 异常会影响 ABI 和控制流设计。
3. 模板可能增加编译时间和代码膨胀。
4. 隐式拷贝、临时对象和所有权不清仍可能带来性能或安全问题。
5. C++ 和 C 混用时要明确 ABI、内存分配器和异常边界。

## 面试回答模板

C 主要是过程式语言，强调函数、结构体、指针和手动资源管理；C++ 在兼容 C 的基础上支持面向对象、泛型、RAII、异常和更丰富的标准库。工程上最大的区别是 C++ 可以用类型系统表达资源所有权，例如构造析构、智能指针、容器和锁守卫，把释放逻辑绑定到对象生命周期。底层上 C++ 支持函数重载和模板，所以有 name mangling 和模板实例化问题；跨 C/C++ 边界时要用 `extern "C"` 暴露 C ABI。
