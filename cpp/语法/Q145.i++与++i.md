# Q145.i++与++i

## 1. 定义

`++i` 是前置自增，先把 `i` 加 1，再返回自增后的值。

`i++` 是后置自增，先保留自增前的旧值作为表达式结果，再把 `i` 加 1。

```cpp
int i = 1;
int a = ++i; // i = 2, a = 2
int b = i++; // b = 2, i = 3
```

## 2. 内置类型的区别

对 `int` 这类内置类型，现代编译器在表达式结果未被使用时通常能优化成相同机器码：

```cpp
++i;
i++;
```

如果表达式结果要被使用，语义不同，不能简单说性能一样。

## 3. 迭代器和自定义类型

对迭代器、自定义类，后置 `operator++(int)` 通常需要保存旧值：

```cpp
class Iter {
public:
    Iter& operator++() {
        // 前置：修改自身并返回自身
        ++pos_;
        return *this;
    }

    Iter operator++(int) {
        // 后置：保存旧值，修改自身，返回旧值
        Iter old = *this;
        ++(*this);
        return old;
    }

private:
    int pos_ = 0;
};
```

因此对迭代器一般推荐写 `++it`，避免不必要的旧值拷贝。虽然很多编译器可以优化，但前置自增更直接表达“不需要旧值”。

## 4. 易错点

1. 不要在同一个表达式里多次无序修改同一变量，例如早期 C++ 中 `i = i++ + ++i` 属于未定义或容易混淆的写法；现代标准对部分求值顺序有收紧，但仍不建议这样写。
2. `i++` 的返回值是旧值，`++i` 的返回值是新值。
3. 对复杂对象，后置自增可能产生临时对象和拷贝成本。
4. 循环里如果不需要旧值，优先使用前置自增，尤其是迭代器。

## 5. 面试回答模板

`++i` 是先自增再返回新值，`i++` 是先返回旧值再自增。对内置整数，如果返回值不用，编译器通常能优化成一样；但对迭代器或自定义类型，后置自增为了返回旧值通常要保存临时副本，因此更推荐 `++it`。同时要避免在一个表达式里多次修改同一个变量，容易引发求值顺序问题。
