# C++11 Lambda 表达式

Lambda 表达式是 C++11 引入的匿名函数对象语法，常用于回调、排序比较器、异步任务和局部策略注入。它的本质是编译器生成一个闭包类型，并重载 `operator()`。

基本形式：

```cpp
[capture](params) mutable -> return_type {
    body
};
```

各部分含义：

1. `capture`：捕获外部变量，例如 `[=]`、`[&]`、`[x]`、`[&x]`、`[this]`。
2. `params`：参数列表，和普通函数类似。
3. `mutable`：允许修改按值捕获的闭包副本。
4. `return_type`：返回类型通常可省略，由编译器推导。
5. `body`：函数体。

排序比较器示例：

```cpp
std::vector<int> nums{3, 1, 2};
std::sort(nums.begin(), nums.end(), [](int a, int b) {
    return a > b; // 降序
});
```

捕获方式的核心区别：

1. 按值捕获保存一份副本，闭包对象生命周期内副本有效。
2. 按引用捕获保存引用语义，要求被引用对象活得比 lambda 更久。
3. `[this]` 捕获当前对象指针，异步执行时要特别注意对象生命周期。
4. 无捕获 lambda 可以转换为普通函数指针，有捕获 lambda 不行。

下面从**基本用法**、**传参方式**、**进阶捕获模式（C++17）**以及**底层原理**四个方面展开。

---

### 1. 如何访问私有成员：核心在于捕获 `this`

要访问类的私有成员，Lambda 必须捕获当前对象的指针，也就是 `this` 指针。

#### 方式一：显式捕获 `[this]` (推荐)
这是最清晰、最标准的写法。

```cpp
class Calculator {
private:
    int base_value = 100; // 私有成员

public:
    void compute() {
        // [this] 表示捕获当前对象的指针
        auto lam = [this](int x) {
            // 可以直接访问 private 成员，就像在成员函数里一样
            // 等价于 this->base_value + x
            return base_value + x; 
        };

        std::cout << lam(50) << std::endl; // 输出 150
    }
};
```

#### 方式二：隐式捕获 `[=]` 或 `[&]`
*   `[=]`：以值捕获所有局部变量。在 C++ 类成员函数中，它会自动捕获 `this` 指针（注意：不是拷贝对象，是捕获指针）。
*   `[&]`：以引用捕获所有局部变量。同样会自动捕获 `this` 指针。

```cpp
auto lam = [=](int x) { return base_value + x; }; // 同样有效，通过 this 指针访问
```
> **注意**：在 C++20 中，使用 `[=]` 隐式捕获 `this` 被标记为废弃（deprecated），建议显式写成 `[=, this]` 以增加代码可读性。

---

### 2. 如何传参

Lambda 的参数传递（圆括号内的部分）与普通函数完全一致。

```cpp
class Processor {
private:
    void private_helper(const std::string& msg) { // 私有函数
        std::cout << "Log: " << msg << std::endl;
    }

public:
    void run() {
        // 1. 捕获 this 以访问 private_helper
        // 2. 定义参数 (int id, string status)
        auto task = [this](int id, std::string status) {
            // 逻辑处理
            std::string log_msg = "ID:" + std::to_string(id) + " is " + status;
            
            // 访问私有成员函数
            this->private_helper(log_msg); 
        };

        // 调用传参
        task(101, "Running");
    }
};
```

### 3. 进阶与陷阱：生命周期问题与 `[*this]` (C++17)

这是面试中的**加分项**。

#### 陷阱：悬垂指针 (Dangling Pointer)
如果你把 Lambda 扔到了一个异步线程或者回调中执行，而原本的类对象（Calculator）已经被销毁了，那么捕获的 `this` 指针就会变成野指针，导致 Crash。

```cpp
// 危险代码示例
std::function<void()> get_callback() {
    return [this]() { std::cout << base_value << std::endl; }; 
}
// 如果外部对象销毁了，再调用这个 callback 就会崩溃。
```

#### 解决方案：C++17 的 `[*this]` 捕获
C++17 引入了 `[*this]`，允许你**按值拷贝整个对象**到 Lambda 内部，而不是捕获指针。

```cpp
class SafeTask {
private:
    int data = 42;

public:
    auto get_async_task() {
        // [*this] 会把当前对象完整拷贝一份存入 Lambda 对象中
        // 即使原对象销毁，Lambda 里的副本依然存在，安全访问 data
        return [*this]() { 
            std::cout << data << std::endl; // 访问的是副本的 data
        };
    }
};
```
*注意：使用 `[*this]` 前提是你的类是可拷贝的，且拷贝成本可以接受。*

---

### 4. 底层原理：编译器实际上做了什么？

为了彻底理解，我们需要看编译器生成的代码（伪代码）。

当你写下：
```cpp
[this](int x) { return base_value + x; }
```

编译器实际上生成了一个**匿名类（Closure Type）**：

```cpp
// 编译器生成的匿名类
class __Lambda_Generated_Name {
private:
    MyClass* __this; // [this] 捕获实际上就是存了一个指针成员

public:
    // 构造函数
    __Lambda_Generated_Name(MyClass* ptr) : __this(ptr) {}

    // operator() 重载
    int operator()(int x) const {
        // 通过存储的指针访问私有成员
        // 为什么能访问？因为 Lambda 定义在类内部，拥有上下文权限
        return __this->base_value + x; 
    }
};
```

### 总结

1.  **可以访问吗？** 可以，拥有完全的私有访问权限。
2.  **如何访问？** 必须捕获 `this`（推荐显式写 `[this]`）。
3.  **如何传参？** 在 Lambda 的 `()` 中定义参数，与普通函数无异。
4.  **注意事项：** 如果 Lambda 是异步执行的，小心 `this` 指针失效，必要时使用 C++17 的 `[*this]` 进行对象拷贝捕获。

## Lambda 可以拷贝吗

Lambda 表达式会生成一个闭包对象。这个闭包对象能否拷贝，取决于它捕获的成员能否拷贝。

1. 不捕获变量的 lambda 通常是可拷贝的，也可以转换成函数指针。
2. 按值捕获普通可拷贝对象时，闭包对象可拷贝；拷贝后每个闭包有自己独立的捕获副本。
3. 按引用捕获时，闭包里保存的是引用语义；拷贝 lambda 后仍然引用同一个外部对象。
4. 如果按值捕获了 `std::unique_ptr` 这类不可拷贝对象，闭包通常不可拷贝，只能移动。

示例：

```cpp
int a = 10;
auto f = [a]() mutable {
    ++a;
    return a;
};

auto g = f;        // 拷贝闭包，g 里也有一份 a=10

std::cout << f();  // 11
std::cout << f();  // 12
std::cout << g();  // 11，g 的捕获副本独立
```

如果 lambda 按值捕获变量 `a`，再拷贝这个 lambda，结果是捕获值也被拷贝一份。两个闭包对象之间不会共享这份按值捕获的数据。只有使用引用捕获、指针捕获、`shared_ptr` 捕获时，多个闭包才会观察到同一份外部状态。

易错点：

1. lambda 的 `operator()` 默认是 `const`，按值捕获的变量不能直接修改；要修改闭包内部副本，需要加 `mutable`。
2. `[=]` 在成员函数中捕获的是 `this` 指针，不是把所有成员变量逐个拷贝。
3. 异步场景中按引用捕获局部变量风险很高，任务执行时局部变量可能已经销毁。
4. 比较器 lambda 必须满足严格弱序，不能写成 `a <= b`。
5. 捕获 `shared_ptr` 会延长对象生命周期，捕获 `weak_ptr` 再 `lock()` 更适合观察者和异步回调。

面试回答模板：lambda 是 C++11 的匿名函数对象语法，编译器会生成闭包类并把捕获变量保存为成员。无捕获 lambda 可转函数指针；有捕获 lambda 通常作为闭包对象使用。按值捕获复制数据，按引用捕获依赖外部生命周期，成员函数中要显式关注 `[this]` 的生命周期风险。常见用途是 STL 比较器、回调、异步任务和局部策略。
