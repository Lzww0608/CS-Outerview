# C 和 C++ 常用库函数

面试里问“有哪些库函数”，通常不是让背 API 列表，而是看能否区分 C 标准库、C++ 标准库、字符串/内存/算法函数的语义和易错点。

## 1. C 字符串函数

常见函数：

1. `strlen`：计算 C 字符串长度，不包含结尾 `\0`。
2. `strcpy/strncpy`：复制字符串，容易越界或不补 `\0`。
3. `strcat/strncat`：拼接字符串，要保证目标缓冲区足够。
4. `strcmp/strncmp`：按字典序比较。
5. `strchr/strstr`：查找字符或子串。

易错点：

1. C 字符串必须以 `\0` 结尾，否则 `strlen/strcpy` 会越界读。
2. `strncpy` 不一定写入结尾 `\0`，不能把它当成安全版本。
3. 现代 C++ 优先使用 `std::string` 和 `std::string_view`。

## 2. C 内存函数

常见函数：

1. `memset`：按字节填充内存。
2. `memcpy`：复制不重叠内存。
3. `memmove`：复制可能重叠内存。
4. `memcmp`：按字节比较。

示例：

```cpp
char buf[16];
std::memset(buf, 0, sizeof(buf));
std::memcpy(buf, "hello", 5);
```

易错点：

1. `memset(arr, 1, sizeof(arr))` 对 `int` 数组不是把每个元素设为整数 1，而是每个字节设为 `0x01`。
2. 源和目标区域可能重叠时必须用 `memmove`，不能用 `memcpy`。
3. 对非平凡 C++ 对象不要随意 `memcpy`，可能破坏对象语义。

## 3. C++ 容器和字符串

常见类型：

1. `std::vector`：连续动态数组，随机访问快，扩容会导致迭代器失效。
2. `std::deque`：分段连续，头尾插入较方便。
3. `std::list`：双向链表，随机访问慢，节点分配成本高。
4. `std::map`：有序红黑树，操作 `O(log n)`。
5. `std::unordered_map`：哈希表，平均 `O(1)`，最坏可能退化。
6. `std::string`：管理字符序列，通常有 SSO 优化。
7. `std::string_view`：不拥有字符串，只观察一段字符，生命周期要小心。

## 4. C++ 算法库

`<algorithm>` 里常用函数：

1. `std::sort`：排序，通常是内省排序，平均和最坏复杂度都能控制在 `O(n log n)`。
2. `std::stable_sort`：稳定排序，保留等价元素相对顺序。
3. `std::find`：线性查找。
4. `std::binary_search`：判断有序区间是否存在目标。
5. `std::lower_bound/upper_bound`：二分找边界。
6. `std::reverse`：翻转区间。
7. `std::unique`：把相邻重复元素移到末尾，常配合 `erase`。
8. `std::nth_element`：找第 k 小/大，平均线性。
9. `std::accumulate`：累加，需要包含 `<numeric>`。

示例：

```cpp
#include <algorithm>
#include <vector>

std::vector<int> a{3, 1, 2, 2};
std::sort(a.begin(), a.end());
a.erase(std::unique(a.begin(), a.end()), a.end());
```

## 5. 智能指针和并发库

常见工具：

1. `std::unique_ptr`：独占所有权，不能拷贝，可以移动。
2. `std::shared_ptr`：共享所有权，引用计数管理生命周期。
3. `std::weak_ptr`：弱引用，打断循环引用。
4. `std::thread`：线程对象，析构前必须 `join` 或 `detach`。
5. `std::mutex`：互斥锁。
6. `std::lock_guard/std::unique_lock`：RAII 加锁。
7. `std::condition_variable`：条件变量，必须配合谓词处理虚假唤醒。
8. `std::atomic`：原子操作，适合简单共享状态和无锁结构。

## 6. 面试回答模板

C 里常用的库函数包括字符串函数 `strlen/strcmp/strcpy`，内存函数 `memset/memcpy/memmove/memcmp`，但要注意缓冲区、`\0` 和重叠内存问题。C++ 更常用标准库容器和算法，例如 `vector/map/unordered_map/string`，算法里的 `sort/lower_bound/unique/nth_element`，资源管理用 `unique_ptr/shared_ptr/weak_ptr`，并发用 `thread/mutex/condition_variable/atomic`。真实工程里优先使用 C++ RAII 和 STL，只有在性能敏感或底层接口需要时才直接用 C 风格函数。
