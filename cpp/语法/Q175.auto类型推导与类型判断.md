# C++ auto 类型推导与类型判断

## 问题背景

使用 `auto` 推导类型时，有时候需要知道编译器推导出了什么类型，或者在模板代码中需要根据类型做不同的处理。那么如何判断一个 `auto` 推导出的对象是否是期望的类型呢？

---

## 一、基本类型判断方法

### 1.1 使用 `std::is_same` 判断类型相等

```cpp
#include <type_traits>
#include <iostream>
#include <vector>

int main() {
    auto x = 42;
    auto y = 3.14;
    auto z = std::vector<int>{1, 2, 3};

    // 判断 x 是否是 int 类型
    if constexpr (std::is_same_v<decltype(x), int>) {
        std::cout << "x is int" << std::endl;
    }

    // 判断 y 是否是 double 类型
    if constexpr (std::is_same_v<decltype(y), double>) {
        std::cout << "y is double" << std::endl;
    }

    // 判断 z 是否是 std::vector<int>
    if constexpr (std::is_same_v<decltype(z), std::vector<int>>) {
        std::cout << "z is vector<int>" << std::endl;
    }
}
```

`decltype(x)` 获取 `x` 的类型，然后和期望类型用 `std::is_same` 比较。`std::is_same_v` 是 C++17 提供的便捷写法，等价于 `std::is_same<T1, T2>::value`。

### 1.2 使用 `typeid` 运行时判断

```cpp
#include <typeinfo>
#include <iostream>

int main() {
    auto x = 42;

    // typeid 可以获取类型的运行时信息
    std::cout << typeid(x).name() << std::endl;  // 输出 "i" 表示 int

    // 比较两个 type_info 是否相同
    if (typeid(x) == typeid(int)) {
        std::cout << "x is int at runtime" << std::endl;
    }
}
```

**注意**：`typeid` 是运行时操作，有运行时开销；`std::is_same` 是编译时操作，没有运行时开销。生产代码中优先使用编译时判断。

## 二、编译时类型信息获取

### 2.1 `decltype` 获取变量类型

```cpp
auto x = 42;
decltype(x) y = 100;  // y 也是 int 类型

// decltype 可以保留引用和const限定符
const int& ref = x;
decltype(ref) ref2 = x;  // ref2 是 const int& 类型
```

### 2.2 `typeid` vs `decltype` 对比

| 特性 | `decltype` | `typeid` |
|------|------------|----------|
| 阶段 | 编译时 | 运行时 |
| 保留限定符 | 是（const、引用等） | 否（只保留类型基本信息） |
| 开销 | 无 | 有（运行时比较） |
| 使用场景 | 模板元编程、类型推导 | 运行时多态、调试输出 |

## 三、常见类型判断场景

### 3.1 判断是否是指针或引用

```cpp
#include <type_traits>

auto ptr = new int(42);
auto ref = *ptr;

if constexpr (std::is_pointer_v<decltype(ptr)>) {
    std::cout << "ptr is a pointer" << std::endl;
}

if constexpr (std::is_reference_v<decltype(ref)>) {
    std::cout << "ref is a reference" << std::endl;
}
```

### 3.2 判断是否是整型或浮点型

```cpp
auto a = 42;
auto b = 3.14;

if constexpr (std::is_integral_v<decltype(a)>) {
    std::cout << "a is integral type" << std::endl;
}

if constexpr (std::is_floating_point_v<decltype(b)>) {
    std::cout << "b is floating point type" << std::endl;
}
```

### 3.3 完整类型判断示例

```cpp
#include <type_traits>
#include <iostream>
#include <string>

template<typename T>
void printTypeInfo(T val) {
    std::cout << "=== Type Info ===" << std::endl;

    // 基本类型判断
    std::cout << "is_integral: " << std::is_integral_v<T> << std::endl;
    std::cout << "is_floating_point: " << std::is_floating_point_v<T> << std::endl;
    std::cout << "is_pointer: " << std::is_pointer_v<T> << std::endl;
    std::cout << "is_reference: " << std::is_reference_v<T> << std::endl;
    std::cout << "is_array: " << std::is_array_v<T> << std::endl;
    std::cout << "is_class: " << std::is_class_v<T> << std::endl;

    // 类型名称（需要 demangle）
    std::cout << "type name: " << typeid(T).name() << std::endl;
}

int main() {
    auto i = 42;
    auto d = 3.14;
    auto s = std::string("hello");

    printTypeInfo(i);
    printTypeInfo(d);
    printTypeInfo(s);
}
```

## 四、模板中的类型判断

### 4.1 使用 `if constexpr` 静态分派

```cpp
#include <type_traits>
#include <iostream>
#include <vector>

template<typename T>
void process(T val) {
    if constexpr (std::is_same_v<T, int>) {
        std::cout << "Processing int: " << val * 2 << std::endl;
    } else if constexpr (std::is_same_v<T, double>) {
        std::cout << "Processing double: " << val * 2.0 << std::endl;
    } else if constexpr (std::is_same_v<T, std::string>) {
        std::cout << "Processing string: " << val + val << std::endl;
    } else {
        std::cout << "Unknown type" << std::endl;
    }
}

int main() {
    auto a = 10;
    auto b = 3.14;
    auto c = std::string("hello");

    process(a);  // 输出 "Processing int: 20"
    process(b);  // 输出 "Processing double: 6.28"
    process(c);  // 输出 "Processing string: hellohello"
}
```

`if constexpr` 是 C++17 引入的，条件在编译期求值，不满足的分支不会被编译，非常适合模板元编程。

### 4.2 使用标签分发（Tag Dispatch）

```cpp
#include <iostream>
#include <type_traits>

// 泛型版本（不会调用到）
template<typename T>
void processImpl(T val, std::false_type) {
    std::cout << "Other type: " << val << std::endl;
}

// int 特化版本
template<typename T>
void processImpl(T val, std::true_type) {
    std::cout << "Processing int: " << val * 2 << std::endl;
}

// 分发入口
template<typename T>
void process(T val) {
    processImpl(val, std::is_same<T, int>{});
}

int main() {
    process(42);      // 输出 "Processing int: 84"
    process(3.14);    // 输出 "Other type: 3.14"
}
```

标签分发是 C++11/14 时代常用的技巧，现在 `if constexpr` 更简洁。

### 4.3 使用 `std::enable_if` 约束模板

```cpp
#include <type_traits>
#include <iostream>

// 只接受整型的模板
template<typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
T doubleValue(T val) {
    return val * 2;
}

// 只接受浮点型的模板
template<typename T, typename = std::enable_if_t<std::is_floating_point_v<T>>>
T doubleValue(T val) {
    return val * 2.0;
}

int main() {
    std::cout << doubleValue(42) << std::endl;      // 84
    std::cout << doubleValue(3.14) << std::endl;    // 6.28
}
```

## 五、实际应用场景

### 5.1 调试时查看 auto 推导类型

```cpp
#include <typeinfo>
#include <cxxabi.h>
#include <memory>
#include <iostream>

template<typename T>
std::string getTypeName() {
    int status;
    char* demangled = abi::__cxa_demangle(typeid(T).name(), nullptr, nullptr, &status);
    std::string result = (status == 0 && demangled) ? demangled : typeid(T).name();
    if (demangled) std::free(demangled);
    return result;
}

int main() {
    auto vec = std::vector<int>{1, 2, 3};
    std::cout << getTypeName<decltype(vec)>() << std::endl;  // "std::vector<int, std::allocator<int>>"
}
```

### 5.2 在模板函数中保留 auto 的灵活性

```cpp
#include <iostream>
#include <type_traits>
#include <vector>

// 使用 auto 保留具体类型，模板参数 T 推导
template<typename T>
auto sum(T a, T b) -> decltype(a + b) {
    return a + b;
}

// 如果想限制类型
template<typename T, typename = std::enable_if_t<std::is_arithmetic_v<T>>>
T safeSum(T a, T b) {
    return a + b;
}

int main() {
    auto r1 = sum(1, 2);           // 返回 int
    auto r2 = sum(1.0, 2.0);       // 返回 double
    // sum(1, 2.0); 编译失败，类型不一致

    auto r3 = safeSum(1, 2);       // 返回 int
    // safeSum("a", "b"); 编译失败，非算术类型
}
```

## 六、常见面试问题

### Q1: `auto` 和 `decltype` 的区别？

| 特性 | `auto` | `decltype` |
|------|--------|------------|
| 推导规则 | 去掉引用和 cv 限定符 | 保留引用和 cv 限定符 |
| 使用场景 | 变量类型推导 | 获取表达式的类型 |
| 示例 | `auto x = 42;` | `decltype(x) y = 100;` |
| 表达式推导 | `auto` 推导值类别 | `decltype` 区分左值和右值 |

```cpp
int x = 42;
int& ref = x;

auto a = ref;      // a 是 int，去掉了引用
decltype(ref) b = x; // b 是 int&，保留了引用

auto c = 42;       // c 是 int
auto d = int(42);  // d 是 int
auto&& e = 42;     // e 是 int&&，引用折叠
decltype(42) f = 42; // f 是 int（42是纯右值）
int g = 42;
decltype(g = 42) h = g; // h 是 int&（g=42是左值表达式）
```

### Q2: 如何在编译期判断两个类型是否相同？

使用 `std::is_same`，不接受隐式转换：

```cpp
static_assert(std::is_same<int, int>::value, "");
static_assert(std::is_same<int, long>::value == false, "");

// 注意：不接受隐式转换
static_assert(std::is_same<int, const int>::value == false, ""); // 失败！
static_assert(std::is_same_v<int, const int> == false, "");     // C++17 写法
```

### Q3: `auto` 能不能推导出 `auto&`、`auto*`？

可以，需要显式写明：

```cpp
auto x = 42;      // int
auto& rx = x;     // int&，rx 是 x 的引用
auto* px = &x;    // int*，px 是指向 x 的指针
auto&& rx2 = x;   // int&（引用折叠：auto=int, && + & = &）
auto&& rx3 = 42;  // int&&（引用折叠：auto=int, && + && = &&）
```

### Q4: 为什么 `if constexpr` 比普通 `if` 更好？

普通 `if` 的两个分支都会被编译，只是运行时选择执行哪个：

```cpp
template<typename T>
void f(T val) {
    // 普通 if：两个分支都会被编译，如果某个分支有语法错误则编译失败
    if (std::is_same_v<T, int>) {
        std::cout << val + "hello";  // 编译失败！字符串不能和int相加
    } else {
        std::cout << val;
    }
}
```

`if constexpr` 只编译满足条件的分支：

```cpp
template<typename T>
void f(T val) {
    if constexpr (std::is_same_v<T, int>) {
        std::cout << val * 2;  // 只有 T 是 int 时才编译
    } else {
        std::cout << val;      // 其他情况编译这个分支
    }
}
```

## 七、总结

判断 `auto` 推导类型的方法：

1. **`std::is_same`**：编译期判断两个类型是否相等，最常用
2. **`decltype`**：获取变量的完整类型（保留引用和 cv 限定符）
3. **`typeid`**：运行时获取类型信息，用于调试
4. **类型特质判断**：用 `std::is_pointer_v`、`std::is_reference_v` 等判断类型属性
5. **`if constexpr`**：C++17 的编译期条件分支，配合类型判断实现静态分派
