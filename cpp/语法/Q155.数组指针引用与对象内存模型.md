# Q155. 数组、指针、引用与对象内存模型

## 1. 数组和指针的区别

数组是一段连续对象的集合，数组名在大多数表达式中会退化为指向首元素的指针；指针本身是一个变量，保存某个对象的地址。

```cpp
int a[4] = {1, 2, 3, 4};
int* p = a;

sizeof(a); // 4 * sizeof(int)
sizeof(p); // 指针大小，64 位下通常是 8
```

核心区别：

1. **类型不同**：`a` 的类型是 `int[4]`，`p` 的类型是 `int*`。
2. **大小不同**：数组 `sizeof` 是整个数组大小，指针 `sizeof` 是指针变量大小。
3. **是否可改指向不同**：数组名不是可赋值左值，`a = other` 不合法；指针变量可以改变指向。
4. **生命周期不同**：数组对象拥有元素存储；指针只保存地址，不拥有指向对象。
5. **函数参数退化**：数组作为函数形参时会退化为指针，丢失长度信息。

函数中不要用 `sizeof(arr) / sizeof(arr[0])` 计算外部传入数组长度：

```cpp
void f(int arr[10]) {
    sizeof(arr); // sizeof(int*)
}
```

C++ 中更推荐用 `std::array` 表达固定长度数组，用 `std::vector` 表达动态数组，用 `std::span` 表达“不拥有的连续视图”。

## 2. 指针和引用的区别

引用可以理解为对象的别名，指针是保存地址的对象。

| 对比项 | 指针 | 引用 |
| --- | --- | --- |
| 是否可为空 | 可以是 `nullptr` | 正常引用必须绑定对象 |
| 是否可改绑定 | 可以改指向 | 初始化后不能改绑 |
| 是否占存储 | 指针对象本身占空间 | 语言语义是别名，底层实现可能用地址 |
| 使用方式 | `*p`、`p->x` | 直接当对象使用 |
| 多级间接 | 可以有 `int**` | 没有“引用的引用”语义，折叠后仍是引用 |
| 常见用途 | 可选对象、数组遍历、动态资源 | 参数传递、返回别名、运算符重载 |

示例：

```cpp
int x = 1;
int y = 2;

int* p = &x;
p = &y;      // 可以改指向

int& r = x;
r = y;       // 不是改绑，而是把 y 的值赋给 x
```

易错点：

1. 引用不是“安全指针”，悬垂引用同样危险。
2. `const T&` 可以延长临时对象生命周期，但只限直接绑定的临时对象。
3. 函数返回局部变量引用和返回局部变量指针一样都是未定义行为。

## 2.1 指针自增与 `*p++`

`*p++` 要按运算符优先级和求值语义理解。后缀 `++` 的优先级高于一元 `*`，所以：

```cpp
*p++
```

等价于：

```cpp
*(p++)
```

含义是：先取出 `p` 原来指向的元素，再让 `p` 移动到下一个元素。指针自增不是简单地址加 1 字节，而是加上一个元素的大小：

```cpp
int a[] = {10, 20, 30};
int* p = a;

int x = *p++; // x = 10, p 指向 a[1]
int y = *p;   // y = 20
```

常见相似表达式：

| 表达式 | 等价理解 | 含义 |
| --- | --- | --- |
| `*p++` | `*(p++)` | 取旧指针指向的值，然后指针后移 |
| `(*p)++` | `(*p)++` | 指针不变，指向的元素自增 |
| `*++p` | `*(++p)` | 指针先后移，再取新位置的值 |
| `++*p` | `++(*p)` | 指针不变，指向的元素先自增再取值 |

易错点：

1. 指针移动步长由指针类型决定，`int*` 自增通常移动 `sizeof(int)` 字节。
2. 不要在同一个表达式里多次修改同一个指针或对象，例如 `*p++ = *p++` 可读性差且容易踩求值顺序问题。
3. 指针必须指向数组元素或尾后位置附近的合法范围，越界自增或解引用都是未定义行为。

## 2.2 `const int* p` 和 `int* const p`

读指针声明时可以从变量名出发，也可以记住：`const` 修饰它左边的东西；左边没有类型名时修饰右边。

```cpp
const int* p1; // p1 指向 const int，不能通过 p1 修改 *p1，但 p1 可以改指向
int const* p2; // 和 const int* 等价
int* const p3 = &x; // p3 是 const 指针，不能改指向，但可以修改 *p3
const int* const p4 = &x; // 指针本身和指向内容都不能通过 p4 修改
```

示例：

```cpp
int x = 1;
int y = 2;

const int* p = &x;
p = &y;     // 可以改指向
// *p = 3;  // 不可以通过 p 修改内容

int* const q = &x;
*q = 3;     // 可以修改 x
// q = &y;  // 不可以改指向
```

工程建议：

1. 函数只读一段数据时，用 `const T*` 或 `const T&` 表达不会修改内容。
2. 指针变量不应改绑时，可以使用 `T* const`，但函数参数里较少单独使用，因为形参本身就是局部副本。
3. 多级指针的 const 更复杂，例如 `const char* const*`，应从变量名逐层读，不要只靠口诀。

## 3. C++ 对象内存模型

一个 C++ 对象在内存中主要包含非静态数据成员和编译器为对象语义插入的必要字段，例如虚函数表指针。

通常计入对象大小：

1. 非静态数据成员。
2. 对齐填充 padding。
3. 虚函数带来的 `vptr`。
4. 多继承或虚继承带来的多个基类子对象、多个 `vptr`、虚基类指针等实现细节。

通常不计入对象大小：

1. 普通成员函数代码。
2. 静态成员函数。
3. 静态数据成员。
4. 虚函数表本身。

```cpp
struct A {};
struct B { int x; static int y; };
struct C { virtual void f(); int x; };
```

常见结果：

1. `sizeof(A)` 至少为 1，保证不同对象有不同地址。
2. `sizeof(B)` 通常是 4，`static y` 不在对象内。
3. `sizeof(C)` 在 64 位下常见是 16，包含 8 字节 `vptr`、4 字节 `int` 和 padding。

具体布局受 ABI、编译器、平台位数和继承方式影响，面试不要把某个数值说成绝对。

## 3.1 union 的作用域、存储期和活动成员

`union` 的所有非静态成员共享同一块存储空间，对象大小至少能容纳最大的成员，并满足最严格成员的对齐要求。

```cpp
union U {
    int i;
    char bytes[4];
};
```

“`union` 放在函数外和函数内有什么区别”要分清两个层次：

1. `union U { ... };` 是类型定义。放在函数外时类型作用域更大，放在函数内时类型只在该函数块内可见。
2. `U u;` 是对象定义。对象放在函数外通常具有静态存储期，未显式初始化会零初始化；对象放在函数内通常具有自动存储期，未显式初始化时内容不确定。

```cpp
union U {
    int i;
    char bytes[4];
};

U g; // 静态存储期，零初始化，g.i 初始为 0

void f() {
    U x;   // 自动存储期，未初始化，读取 x.i 是未定义行为
    U y{}; // 值初始化，清零
}
```

易错点是通过 `union` 随意做类型双关。C++ 中只有当前活动成员可以被安全读取，复杂对象还涉及构造和析构；如果要表达“同一时刻只保存多种类型之一”，优先考虑 `std::variant`。判断大小端时用 `union` 在很多平台能工作，但更稳妥的方式是通过 `std::uint32_t` 和 `std::memcpy`/字节视图观察对象表示。

## 4. 类成员变量和成员函数的内存分布

C++ 类对象本身只保存每个对象独有的状态。成员函数代码不随对象复制，静态成员也不属于单个对象。

```cpp
struct A {
    int x;
    static int y;

    void f();
    virtual void g();
};
```

通常可以这样理解：

1. **非静态成员变量**：存放在每个对象内部，例如 `x` 会计入 `sizeof(A)`。
2. **静态成员变量**：属于类，不属于某个对象，存放在静态存储区，需要类外定义时拥有独立存储。
3. **普通成员函数**：函数代码在代码段，所有对象共享；调用时编译器隐式传入 `this` 指针。
4. **静态成员函数**：函数代码也在代码段，不带 `this` 指针，因此不能直接访问非静态成员。
5. **虚函数**：函数代码仍在代码段；虚表通常位于只读数据区，对象中一般只保存虚表指针 `vptr`。

面试里可以用一句话收束：对象大小由非静态数据成员、对齐填充和可能存在的编译器辅助指针决定，成员函数和静态成员不随对象实例分配。

## 5. `int *p[10]` 和 `int (*p)[10]`

这两个声明的关键区别是 `[]` 的优先级高于 `*`。

```cpp
int* p1[10];   // p1 是数组，数组里有 10 个 int* 指针
int (*p2)[10]; // p2 是指针，指向一个包含 10 个 int 的数组
```

对比：

| 表达式 | 含义 | 常见大小 |
| --- | --- | --- |
| `int *p[10]` | 指针数组，10 个元素，每个元素是 `int*` | `10 * sizeof(int*)` |
| `int (*p)[10]` | 数组指针，指向 `int[10]` 这一个数组对象 | `sizeof(int*)` |

示例：

```cpp
int a[10] = {};
int (*p)[10] = &a;

(*p)[0] = 1; // 访问 a[0]

int x = 1;
int y = 2;
int* arr[10] = {&x, &y};
```

读复杂声明时可以从变量名开始，先看右边，再看左边；遇到括号时先处理括号内的部分。

## 6. 真实场景

1. 网络缓冲区、序列化、系统调用常用指针和长度一起传递，不能只传裸指针。
2. API 参数如果不能为空且不需要改绑，优先用引用；可能为空或需要延迟绑定时用指针或智能指针。
3. 性能敏感结构体要关注成员顺序和对齐，减少 padding 和 false sharing。
4. 涉及多态删除时，基类析构函数应为虚函数，避免只析构基类部分。

## 7. 面试回答模板

数组是连续对象集合，指针是保存地址的变量；数组名多数场景会退化为首元素指针，但在 `sizeof`、取地址等场景不会退化。指针可以为空、可以改指向，引用初始化后不能改绑，语义上是对象别名。`*p++` 等价于 `*(p++)`，先取旧指针指向的值，再按元素大小移动指针。`const int*` 是指向常量的指针，`int* const` 是常量指针。`int *p[10]` 是指针数组，`int (*p)[10]` 是数组指针。C++ 对象大小主要由非静态数据成员、对齐填充和可能存在的 `vptr` 决定，成员函数、静态成员和虚表本身不在对象内。实际回答时要结合数组退化、引用悬垂、对象对齐和虚函数表这些易错点。
