# C/C++ 手写 scanf 实现

## 一、问题背景

`scanf` 是 C 语言标准库中的格式化输入函数，本质上是通过解析格式字符串，从标准输入读取数据并转换到指定变量。本文档将手写实现一个简化版的 `my_scanf`，支持常见的格式化说明符。

---

## 二、scanf 的工作原理

### 2.1 scanf 函数原型

```c
#include <stdio.h>

int scanf(const char *format, ...);
// 返回成功匹配的参数个数，出错或遇到文件结束返回 EOF
```

### 2.2 scanf 格式字符串解析

```text
格式字符串组成：
┌─────────────────────────────────────────────────────────────┐
│ %[*][width][length]specifier                                │
│                                                             │
│ *      : 抑制赋值，跳过该输入项                               │
│ width  : 最大字符数                                         │
│ length : h/l/ll/L 修饰符                                   │
│ specifier: d/i/o/u/x/f/e/g/c/s/%                          │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 支持的格式说明符

| 说明符 | 含义 | 对应类型 |
|--------|------|----------|
| %d | 有符号十进制整数 | int |
| %i | 整数（十进制/八进制/十六进制） | int |
| %u | 无符号十进制整数 | unsigned int |
| %o | 八进制整数 | unsigned int |
| %x | 十六进制整数 | unsigned int |
| %f | 浮点数 | float |
| %s | 字符串 | char* |
| %c | 字符 | char |
| %% | 转义百分号 | - |

## 三、C 语言实现

### 3.1 整体架构

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>
#include <stdarg.h>

// 跳过空白字符
static int skip_whitespace(const char **fmt) {
    int count = 0;
    while (isspace(**fmt)) {
        (*fmt)++;
        count++;
    }
    return count;
}

// 读取下一个非空白字符
static int read_char(const char **fmt) {
    skip_whitespace(fmt);
    return *(*fmt)++;
}

// 解析整数
static int parse_int(const char **input, int *result) {
    const char *p = *input;
    skip_whitespace(&p);
    
    int sign = 1;
    if (*p == '-') {
        sign = -1;
        p++;
    } else if (*p == '+') {
        p++;
    }
    
    int value = 0;
    int has_digit = 0;
    
    // 检测进制
    int base = 10;
    if (*p == '0' && (*(p+1) == 'x' || *(p+1) == 'X')) {
        base = 16;
        p += 2;
    } else if (*p == '0') {
        base = 8;
    }
    
    while (1) {
        int digit = -1;
        char c = *p;
        
        if (isdigit(c)) {
            digit = c - '0';
        } else if (base == 16 && isxdigit(c)) {
            digit = tolower(c) - 'a' + 10;
        }
        
        if (digit < 0 || digit >= base) {
            break;
        }
        
        value = value * base + digit;
        has_digit = 1;
        p++;
    }
    
    if (!has_digit) {
        return 0;
    }
    
    *result = sign * value;
    *input = p;
    return 1;
}

// 解析浮点数
static int parse_float(const char **input, float *result) {
    const char *p = *input;
    skip_whitespace(&p);
    
    int sign = 1;
    if (*p == '-') {
        sign = -1;
        p++;
    } else if (*p == '+') {
        p++;
    }
    
    double value = 0.0;
    int has_digit = 0;
    
    // 整数部分
    while (isdigit(*p)) {
        value = value * 10 + (*p - '0');
        has_digit = 1;
        p++;
    }
    
    // 小数部分
    if (*p == '.') {
        p++;
        double fraction = 0.1;
        while (isdigit(*p)) {
            value += (*p - '0') * fraction;
            fraction *= 0.1;
            has_digit = 1;
            p++;
        }
    }
    
    // 指数部分
    if (*p == 'e' || *p == 'E') {
        p++;
        int exp_sign = 1;
        if (*p == '-') {
            exp_sign = -1;
            p++;
        } else if (*p == '+') {
            p++;
        }
        
        int exp = 0;
        while (isdigit(*p)) {
            exp = exp * 10 + (*p - '0');
            p++;
        }
        
        value *= pow(10, exp_sign * exp);
    }
    
    if (!has_digit) {
        return 0;
    }
    
    *result = sign * (float)value;
    *input = p;
    return 1;
}

// 解析字符串
static int parse_string(const char **input, char *dest, int width) {
    const char *p = *input;
    skip_whitespace(&p);
    
    int count = 0;
    while (*p && !isspace(*p) && count < width - 1) {
        *dest++ = *p++;
        count++;
    }
    *dest = '\0';
    
    *input = p;
    return count;
}

// 解析字符
static int parse_char(const char **input, char *dest) {
    skip_whitespace(input);
    *dest = *(*input)++;
    return 1;
}

// 核心 my_scanf 实现
int my_scanf(const char *format, ...) {
    va_list args;
    va_start(args, format);
    
    const char *p = format;
    int match_count = 0;
    
    // 读取第一个非空白字符作为输入
    // 这里简化处理，假设 input 来自 stdin
    char buffer[1024];
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        va_end(args);
        return EOF;
    }
    const char *input = buffer;
    
    while (*p) {
        if (isspace(*p)) {
            // 跳过格式字符串中的空白字符
            p++;
            skip_whitespace(&input);
        } else if (*p == '%') {
            p++;
            
            // 处理 %%
            if (*p == '%') {
                p++;
                if (*input != '%') {
                    // 不匹配，终止
                    break;
                }
                input++;
                continue;
            }
            
            // 解析宽度
            int width = 0;
            while (isdigit(*p)) {
                width = width * 10 + (*p - '0');
                p++;
            }
            if (width == 0) {
                width = 1024;  // 默认大宽度
            }
            
            // 解析格式说明符
            switch (*p) {
                case 'd':  // 有符号十进制整数
                case 'i': {
                    int *val = va_arg(args, int*);
                    if (parse_int(&input, val)) {
                        match_count++;
                    }
                    break;
                }
                case 'u':  // 无符号十进制整数
                case 'o':
                case 'x':
                case 'X': {
                    unsigned int *val = va_arg(args, unsigned int*);
                    int tmp;
                    if (parse_int(&input, &tmp)) {
                        *val = (unsigned int)tmp;
                        match_count++;
                    }
                    break;
                }
                case 'f':  // 浮点数
                case 'e':
                case 'E':
                case 'g':
                case 'G': {
                    float *val = va_arg(args, float*);
                    if (parse_float(&input, val)) {
                        match_count++;
                    }
                    break;
                }
                case 's': {  // 字符串
                    char *str = va_arg(args, char*);
                    match_count += parse_string(&input, str, width);
                    break;
                }
                case 'c': {  // 字符
                    char *ch = va_arg(args, char*);
                    match_count += parse_char(&input, ch);
                    break;
                }
                default:
                    // 未知格式说明符
                    break;
            }
            p++;
        } else {
            // 普通字符，需要匹配
            skip_whitespace(&input);
            if (*input++ != *p++) {
                break;
            }
        }
    }
    
    va_end(args);
    return match_count;
}
```

### 4.1 使用模板和流操作

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
#include <cctype>
#include < <>>

template<typename T>

// 格式化扫描器类
class ScanFormatter {
public:
    // 解析整数
    static bool parse_int(const std::string& input, int& result, int& pos) {
        skip_whitespace(input, pos);
        
        int sign = 1;
        if (pos < input.size() && input[pos] == '-') {
            sign = -1;
            pos++;
        }
        
        result = 0;
        bool has_digit = false;
        
        while (pos < input.size() && isdigit(input[pos])) {
            result = result * 10 + (input[pos] - '0');
            has_digit = true;
            pos++;
        }
        
        if (!has_digit) return false;
        
        result *= sign;
        return true;
    }
    
    // 解析浮点数
    static bool parse_float(const std::string& input, float& result, int& pos) {
        skip_whitespace(input, pos);
        
        int sign = 1;
        if (pos < input.size() && input[pos] == '-') {
            sign = -1;
            pos++;
        }
        
        double value = 0.0;
        bool has_digit = false;
        
        // 整数部分
        while (pos < input.size() && isdigit(input[pos])) {
            value = value * 10 + (input[pos] - '0');
            has_digit = true;
            pos++;
        }
        
        // 小数部分
        if (pos < input.size() && input[pos] == '.') {
            pos++;
            double fraction = 0.1;
            while (pos < input.size() && isdigit(input[pos])) {
                value += (input[pos] - '0') * fraction;
                fraction *= 0.1;
                pos++;
            }
        }
        
        if (!has_digit) return false;
        
        result = sign * value;
        return true;
    }
    
    // 解析字符串
    static bool parse_string(const std::string& input, std::string& result, int& pos) {
        skip_whitespace(input, pos);
        
        result.clear();
        while (pos < input.size() && !isspace(input[pos])) {
            result += input[pos++];
        }
        
        return !result.empty();
    }
    
private:
    static void skip_whitespace(const std::string& input, int& pos) {
        while (pos < input.size() && isspace(input[pos])) {
            pos++;
        }
    }
};

// C++ 风格的 scanf 实现
class MyScanner {
public:
    MyScanner(const std::string& input) : input_(input), pos_(0) {}
    
    // 扫描并赋值
    int scanf(const char* format, ...) {
        va_list args;
        va_start(args, format);
        
        int match_count = 0;
        const char* p = format;
        
        while (*p) {
            if (isspace(*p)) {
                p++;
                ScanFormatter::skip_whitespace(input_, pos_);
            } else if (*p == '%') {
                p++;
                
                // %%
                if (*p == '%') {
                    p++;
                    if (pos_ >= input_.size() || input_[pos_] != '%') {
                        break;
                    }
                    pos_++;
                    continue;
                }
                
                // 跳过宽度
                while (isdigit(*p)) p++;
                
                // 解析并赋值
                switch (*p) {
                    case 'd': {
                        int* val = va_arg(args, int*);
                        if (ScanFormatter::parse_int(input_, *val, pos_)) {
                            match_count++;
                        }
                        break;
                    }
                    case 'f': {
                        float* val = va_arg(args, float*);
                        if (ScanFormatter::parse_float(input_, *val, pos_)) {
                            match_count++;
                        }
                        break;
                    }
                    case 's': {
                        std::string* val = va_arg(args, std::string*);
                        if (ScanFormatter::parse_string(input_, *val, pos_)) {
                            match_count++;
                        }
                        break;
                    }
                }
                p++;
            } else {
                ScanFormatter::skip_whitespace(input_, pos_);
                if (pos_ >= input_.size() || input_[pos_] != *p) {
                    break;
                }
                pos_++;
                p++;
            }
        }
        
        va_end(args);
        return match_count;
    }
    
private:
    std::string input_;
    size_t pos_;
};

// 使用示例
int main() {
    std::string input = "42 3.14 hello 100";
    
    MyScanner scanner(input);
    
    int a, b;
    float f;
    std::string s;
    
    int ret = scanner.scanf("%d %f %s %d", &a, &f, &s, &b);
    
    std::cout << "Parsed: " << ret << " items" << std::endl;
    std::cout << "a = " << a << std::endl;
    std::cout << "f = " << f << std::endl;
    std::cout << "s = " << s << std::endl;
    std::cout << "b = " << b << std::endl;
    
    return 0;
}
```

## 六、面试常见问题

### Q1: scanf 的返回值表示什么？

返回成功匹配的参数个数。如果第一个参数就匹配失败，返回 0；如果遇到文件结束或错误，返回 EOF。

### Q2: scanf 和 gets 的区别？

| 函数 | 安全性 | 空格处理 | 缓冲区 |
|------|--------|----------|--------|
| scanf("%s") | 较好 | 遇到空白停止 | 可能溢出 |
| gets | 危险 | 遇到换行停止 | 必然溢出 |

### Q3: 为什么 scanf("%s") 不安全？

如果输入长度超过目标数组大小，会发生缓冲区溢出。应使用宽度限制：

```c
char buf[32];
scanf("%31s", buf);  // 限制最多31个字符
```

## 七、总结

1. scanf 通过解析格式字符串逐个匹配输入
2. 核心是 skip_whitespace、parse_int、parse_float、parse_string 等解析函数
3. 使用 va_list、va_arg 处理可变参数
4. 需要注意空白字符处理、宽度限制、进制检测等细节
5. C++ 版本可以用类封装，使用模板和流操作更灵活
