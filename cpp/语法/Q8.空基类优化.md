# 空基类优化（EBCO）

**面试题：C++中void类型占几个字节的内存，空类呢？**

C++的设计者们不允许类的大小为0，其原因很多。比如它们构成数组，其大小必然也是0，这会导致指针运算中普遍使用的性质失效。例如，假设类型ZeroSizedT的大小为0，下面的操作会出现错误：

> ZeroSizedT z[10];
>
> ...
>
> &z[i] - &z[j]; //计算两个指针或地址之间的距离

通常而言，示例中的差值，一般用两个地址之间的字节数除以类型大小得到，而类型大小为0就不妙了。

虽然不能存在“类型”大小为0的类，但这扇门也没彻底关死。C++标准规定，**当空类作为基类时，只要不会与同一类型的另个一个对象或子对象分配在同一地址（类内没有任何其他成员），就不需要为其分配任何空间**。这称之为，**空基类优化**（empty base class optimization, EBCO)技术。

```c++
#include <vector>
#include <iostream>
class EmptyClass {
	typedef int I; // typedef 并不会使得类成为非空
};
class EmptyClass1: public EmptyClass {
	
};
int main() {
	std::cout << sizeof(EmptyClass) << std::endl;
	std::cout << sizeof(EmptyClass1) << std::endl;
	return 0;
}
```

## 空类加成员函数、静态成员、虚函数后大小怎么变

面试里常问“空类是多大，加上成员函数、静态成员函数、静态成员、虚函数后分别是多少”。核心判断标准是：**只有每个对象需要单独保存的非静态数据成员，才会进入对象内存布局**。

在 64 位常见 ABI 下可以这样理解：

| 类内容 | 对象大小影响 | 原因 |
| --- | --- | --- |
| 空类 | 通常 `1` 字节 | C++ 要保证不同对象有不同地址 |
| 普通成员函数 | 不增加对象大小 | 函数代码在代码段，对象里不保存函数本体 |
| 静态成员函数 | 不增加对象大小 | 静态成员函数不依赖 `this` 指针 |
| 静态数据成员 | 不增加单个对象大小 | 静态成员属于类，存储在静态/全局存储区 |
| 虚函数 | 通常增加一个 vptr 指针大小 | 每个多态对象要保存虚表指针 |

示例：

```cpp
#include <iostream>
using namespace std;

struct A {};
struct B { void f() {} };
struct C { static void f() {} };
struct D { static int x; };
struct E { virtual void f() {} };

int D::x = 0;

int main() {
    cout << sizeof(A) << '\n';
    cout << sizeof(B) << '\n';
    cout << sizeof(C) << '\n';
    cout << sizeof(D) << '\n';
    cout << sizeof(E) << '\n';
}
```

典型 64 位环境下输出常见为：

```text
1
1
1
1
8
```

如果类里再加入 `int`、`double` 等非静态数据成员，对象大小还要考虑成员大小、对齐和 padding。例如一个有虚函数和 `int` 成员的类，在 64 位环境下可能是 16 字节：8 字节 vptr + 4 字节 int + 4 字节 padding。

## 有虚函数和没有虚函数的类大小怎么计算

计算类大小时可以按这个顺序判断：

1. 先看是否有非静态数据成员，成员按声明顺序参与布局。
2. 再看是否是多态类：只要类自身声明或继承了虚函数，对象通常需要保存 `vptr`。
3. 再考虑多继承、虚继承：一个完整对象可能包含多个多态基类子对象，从而出现多个 `vptr`。
4. 最后按最大对齐要求补 padding，使数组中相邻对象也满足对齐。

示例：

```cpp
struct A {
    int x;
};

struct B {
    virtual void f() {}
    int x;
};

struct C1 {
    virtual void f1() {}
};

struct C2 {
    virtual void f2() {}
};

struct D : C1, C2 {
    int x;
};
```

在 64 位常见 ABI 下，`sizeof(A)` 常见为 4；`sizeof(B)` 常见为 16，因为 8 字节 `vptr` + 4 字节 `int` + 4 字节 padding；`sizeof(D)` 可能包含两个 `vptr`，再加上 `int` 和 padding，常见结果可能是 24。具体数值仍以编译器 ABI 为准。

所以“一个对象只能有一个虚表指针吗”的答案是否定的。单继承多态对象通常一个 `vptr`，多继承或虚继承下可能多个；虚表本身是类级别的只读数据，不是每个对象复制一份。

## 易错点

1. `sizeof(空类)` 不是 0，通常是 1。
2. 普通成员函数不在对象里，每个对象不会复制一份函数代码。
3. 静态成员变量不属于具体对象，不计入 `sizeof(对象)`。
4. 有虚函数的对象通常有 vptr，但虚表本身不在对象里。
5. 具体大小受 ABI、编译器、平台位数和对齐规则影响，面试回答要说明“通常”。
6. 多继承多态对象可能有多个 `vptr`，不要把“单继承常见一个 `vptr`”误答成所有对象都只能一个。
