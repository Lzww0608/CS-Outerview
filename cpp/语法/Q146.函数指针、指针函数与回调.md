# Q146.函数指针、指针函数与回调

## 1. 函数指针

函数指针是指向函数的指针。它保存函数入口地址，可以通过它间接调用函数。

```cpp
int add(int a, int b) {
    return a + b;
}

int (*fp)(int, int) = add;
int ans = fp(1, 2);
```

这里 `fp` 是函数指针，类型是：

```text
int (*)(int, int)
```

含义是：指向一个函数，这个函数接收两个 `int`，返回 `int`。

## 2. 指针函数

指针函数是返回指针的函数。

```cpp
int* find(int* arr, int n, int target) {
    for (int i = 0; i < n; ++i) {
        if (arr[i] == target) {
            return &arr[i];
        }
    }
    return nullptr;
}
```

判断方式：

```text
int (*fp)(int)  // 函数指针
int* f(int)    // 指针函数
```

括号优先级很关键。`*` 和函数名结合，通常是函数指针；返回类型里带 `*`，通常是指针函数。

## 3. C++ 回调

回调是把一段可执行逻辑传给另一个模块，由对方在合适时机调用。

常见形式：

1. 函数指针。
2. 函数对象。
3. lambda。
4. `std::function`。
5. 成员函数指针 + 对象指针。

### 函数指针回调

```cpp
#include <iostream>

void run(int x, void (*callback)(int)) {
    callback(x);
}

void print(int x) {
    std::cout << x << std::endl;
}

int main() {
    run(10, print);
}
```

函数指针轻量，但只能保存普通函数或无捕获 lambda，不能直接保存有状态闭包。

### std::function 回调

```cpp
#include <functional>
#include <iostream>

void run(int x, const std::function<void(int)>& callback) {
    callback(x);
}

int main() {
    int base = 5;
    run(10, [base](int x) {
        std::cout << x + base << std::endl;
    });
}
```

`std::function` 可以类型擦除，统一保存函数指针、lambda、函数对象，但可能有分配和间接调用开销。

### 模板回调

性能敏感场景可以用模板避免 `std::function` 的类型擦除成本：

```cpp
template <typename Callback>
void runFast(int x, Callback&& callback) {
    callback(x);
}
```

## 4. 真实应用

1. 异步 I/O 完成后调用回调处理结果。
2. 定时器到期后调用回调。
3. 事件循环中注册事件处理函数。
4. 排序函数传入比较器。
5. RPC 框架收到响应后触发业务回调。

## 5. 易错点

1. 回调对象捕获引用时，要保证被引用对象生命周期长于回调执行时间。
2. 跨线程回调要关注线程安全和执行线程，不能默认在注册线程执行。
3. `std::function` 可能有额外开销，热路径可以用模板或函数指针。
4. 成员函数指针不能当普通函数指针用，必须绑定对象。
5. 回调中不要在持锁状态调用未知用户逻辑，容易引发死锁或重入问题。

## 6. 面试回答模板

函数指针是指向函数入口的指针，例如 `int (*fp)(int,int)`；指针函数是返回指针的函数，例如 `int* f(int)`。回调就是把可执行逻辑交给其他模块稍后调用，C++ 中可以用函数指针、lambda、函数对象、`std::function` 或模板参数实现。函数指针轻量但表达能力有限，`std::function` 灵活但有类型擦除开销，异步和跨线程回调要特别注意捕获对象生命周期。
