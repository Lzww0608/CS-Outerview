# struct 和 class 的区别

在 C++ 中，`struct` 和 `class` 都可以定义成员变量、成员函数、构造函数、析构函数、继承、虚函数和访问控制。二者不是“一个只能放数据，一个才能放函数”，核心区别只有默认访问权限和默认继承权限。

## 1. 默认访问权限

`struct` 默认成员访问权限是 `public`：

```cpp
struct Point {
    int x;
    int y;
};
```

等价于：

```cpp
struct Point {
public:
    int x;
    int y;
};
```

`class` 默认成员访问权限是 `private`：

```cpp
class Point {
    int x; // private
    int y; // private
};
```

## 2. 默认继承权限

`struct` 默认是 public 继承，`class` 默认是 private 继承：

```cpp
struct A {};
struct B : A {}; // public A

class C {};
class D : C {}; // private C
```

工程中建议显式写出继承权限，避免读者靠默认规则猜。

## 3. 对象模型没有本质区别

只要成员相同、访问权限不影响布局，`struct` 和 `class` 的对象大小、对齐、构造析构、虚表机制都遵循同一套 C++ 对象模型。

```cpp
struct S {
    virtual void f() {}
    int x;
};

class C {
public:
    virtual void f() {}
    int x;
};
```

这两个类型都可以是多态类型，通常对象里都有 `vptr`。`struct` 也可以有私有成员，`class` 也可以全是 public 成员。

## 4. 什么时候用 struct

常见约定：

1. 简单数据聚合、配置项、坐标点、消息体，优先用 `struct`。
2. 类型主要暴露数据，没有复杂不变量，适合用 `struct`。
3. 需要和 C 结构体交互时，常用 `struct`，但要注意 C++ 成员函数、构造函数、虚函数会破坏 C ABI 兼容。

## 5. 什么时候用 class

常见约定：

1. 类型需要封装不变量，例如文件句柄、连接对象、线程池。
2. 成员变量不应被外部随意修改，需要通过方法维护状态。
3. 需要表达资源所有权、生命周期、并发控制或多态接口。

## 6. 易错点

1. `struct` 可以有构造函数、析构函数、虚函数和私有成员。
2. `class` 也可以写成纯数据结构，只是默认 private。
3. C++ 的 `struct` 不等于 C 的结构体；一旦包含非平凡构造、虚函数、私有成员等，就不能按 C ABI 随意传递。
4. 是否是 POD、standard-layout、trivial，不取决于关键字是 `struct` 还是 `class`，取决于成员和特殊成员函数规则。

## 7. 面试回答模板

`struct` 和 `class` 在 C++ 里能力基本相同，都能有成员函数、构造析构、继承和虚函数。核心区别是默认权限：`struct` 成员和继承默认是 `public`，`class` 成员和继承默认是 `private`。工程上通常用 `struct` 表示简单数据聚合，用 `class` 表示有封装、有不变量或资源管理的类型，但这只是风格约定，不是语言能力限制。
