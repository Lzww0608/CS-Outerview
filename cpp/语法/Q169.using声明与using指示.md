# Q169. using 声明与 using 指示

`using std::cin;` 和 `using namespace std;` 都能让代码里直接写 `cin`，但它们的作用范围、引入名称数量和冲突风险不同。

## 1. using 声明

`using std::cin;` 是 using declaration，意思是只把 `std::cin` 这个名字引入当前作用域。

```cpp
#include <iostream>

using std::cin;
using std::cout;

int main() {
    int x;
    cin >> x;
    cout << x << '\n';
}
```

特点：

1. 只引入明确指定的名字。
2. 冲突面小，可读性更强。
3. 适合在函数内部或 `.cpp` 文件局部使用。
4. 如果当前作用域已有同名实体，可能直接报重定义或二义性，问题更早暴露。

## 2. using namespace 指示

`using namespace std;` 是 using directive，意思是把 `std` 命名空间里的名字纳入当前作用域的非限定查找。

```cpp
#include <iostream>

using namespace std;

int main() {
    int x;
    cin >> x;
    cout << x << '\n';
}
```

特点：

1. 会让 `std` 中大量名字都参与查找，例如 `vector`、`count`、`distance`、`begin`。
2. 写示例代码方便，但大型工程里容易引入命名冲突。
3. 放在头文件里影响所有包含它的翻译单元，污染范围很大。
4. 和第三方库、业务函数、宏混用时可能出现二义性或选到非预期重载。

## 3. 二者使用 cin 的区别

如果只看下面一行：

```cpp
cin >> x;
```

二者都能让编译器找到 `std::cin`。区别在于：

1. `using std::cin;` 只让 `cin` 这个名字可见。
2. `using namespace std;` 让整个 `std` 命名空间参与查找，`cin` 只是其中一个名字。
3. 前者冲突范围小，后者更容易和用户自定义函数、变量、类型发生冲突。

## 4. 真实项目建议

1. 头文件里不要写 `using namespace std;`。
2. 头文件里也谨慎写 using 声明，除非是类内部别名或非常明确的局部设计。
3. `.cpp` 文件中可以局部使用 `using std::cin;`、`using std::string;` 等明确声明。
4. 示例和算法题中为了简洁可以写 `using namespace std;`，但面试里要知道它不适合工程头文件。
5. 公共接口签名里尽量显式写 `std::string`、`std::vector`，让依赖清晰。

## 5. 面试回答模板

`using std::cin` 是 using 声明，只把 `std::cin` 这个名字引入当前作用域；`using namespace std` 是 using 指示，会让 `std` 里的大量名字都参与非限定查找。二者都能让代码直接写 `cin`，但前者影响小、冲突少，后者方便但容易污染命名空间。工程里尤其不能在头文件写 `using namespace std`，否则所有包含该头文件的代码都会被影响。
