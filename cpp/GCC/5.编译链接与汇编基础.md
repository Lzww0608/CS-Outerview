# 5.编译、链接与汇编基础

面试里问“编译和链接了解吗”“学过汇编吗”，重点不是手写大量汇编，而是能说明从源代码到可执行文件的阶段、目标文件里有什么、链接器解决什么问题，以及汇编和机器指令的关系。

## 1. 从源码到可执行文件

以 C/C++ 为例，典型流程：

```text
.cpp
  -> 预处理
  -> 编译
  -> 汇编
  -> 链接
  -> 可执行文件 / 动态库 / 静态库
```

各阶段职责：

1. **预处理**：展开 `#include`、处理 `#define`、条件编译，生成预处理后的源码。
2. **编译**：把源码翻译成汇编或中间表示，完成语法/语义检查和优化。
3. **汇编**：把汇编代码转成机器码，生成目标文件 `.o`。
4. **链接**：把多个目标文件和库合并，解析符号引用，做重定位，生成最终产物。

常用命令：

```bash
g++ -E main.cpp -o main.i     # 预处理
g++ -S main.cpp -o main.s     # 编译到汇编
g++ -c main.cpp -o main.o     # 编译汇编到目标文件
g++ main.o util.o -o app      # 链接
```

## 2. 目标文件里有什么

目标文件通常包含：

1. `.text`：机器指令。
2. `.rodata`：只读常量、字符串字面量。
3. `.data`：已初始化全局/静态变量。
4. `.bss`：未初始化或零初始化全局/静态变量。
5. 符号表：函数、全局变量、外部引用。
6. 重定位信息：哪些地址要等链接时再修正。
7. 调试信息：`-g` 时包含源码行号、类型等信息。

## 3. 链接解决什么

链接器主要做三件事：

1. **符号解析**：把函数调用和全局变量引用绑定到某个定义。
2. **重定位**：确定各段最终地址，修正机器指令和数据中的地址引用。
3. **库合并**：把静态库需要的目标文件拷进产物，或记录动态库依赖。

常见链接错误：

1. `undefined reference`：声明存在，但链接阶段找不到定义。
2. `multiple definition`：多个目标文件里有同名强符号定义。
3. ABI 不兼容：编译器版本、标准库、结构体布局或 name mangling 不一致。
4. 动态库运行时找不到：编译链接成功，但运行时 `LD_LIBRARY_PATH`、rpath 或系统库路径不对。

## 4. 静态链接和动态链接

| 对比项 | 静态链接 | 动态链接 |
| --- | --- | --- |
| 产物 | 库代码复制进可执行文件 | 可执行文件记录依赖 `.so` |
| 启动依赖 | 依赖少，部署简单 | 运行时需要找到动态库 |
| 文件体积 | 通常更大 | 通常更小 |
| 内存共享 | 多进程难共享同一份库代码 | 多进程可共享只读代码页 |
| 升级 | 需要重新发布可执行文件 | 可独立升级库，但要注意 ABI |

服务端常用动态链接节省内存和便于升级；基础工具、容器镜像、嵌入式场景可能偏向静态链接以降低运行时依赖。

## 5. 汇编基础

汇编是机器指令的文本形式。了解汇编有助于看懂函数调用、栈帧、寄存器、性能瓶颈和 core dump。

常见概念：

1. **寄存器**：CPU 内部高速存储，例如 x86-64 的 `rax/rbx/rsp/rbp/rip`。
2. **栈指针**：`rsp` 指向当前栈顶，函数调用会调整栈指针保存局部变量和返回地址。
3. **调用约定**：规定参数放在哪些寄存器/栈上，返回值放哪里，谁负责保存寄存器。
4. **函数序言/尾声**：建立和销毁栈帧，例如保存 `rbp`、调整 `rsp`。
5. **条件跳转**：编译器把 `if/while` 翻译成比较和跳转指令。

一个很小的函数：

```cpp
int add(int a, int b) {
    return a + b;
}
```

优化后可能接近：

```asm
lea eax, [rdi + rsi]
ret
```

`rdi/rsi` 是 System V x86-64 ABI 下前两个整型参数寄存器，`eax` 保存返回值。

## 6. 易错点

1. 编译错误和链接错误不是一回事；头文件找不到是编译期，函数定义找不到多半是链接期。
2. 头文件只提供声明，真正代码通常在 `.cpp` 或库文件里。
3. `inline`、模板、ODR 和头文件定义会影响链接行为。
4. Debug 和 Release 反汇编差异很大，优化会内联、重排、删变量。
5. 汇编依赖 CPU 架构和 ABI，x86-64、ARM64 的寄存器和调用约定不同。

## 7. 面试回答模板

C++ 从源码到可执行文件通常经历预处理、编译、汇编、链接。预处理展开宏和头文件；编译做语法语义分析、优化并生成汇编；汇编生成目标文件；链接器把多个目标文件和库合在一起，解析符号并做重定位。目标文件里有代码段、数据段、符号表和重定位信息。静态链接把库代码复制进产物，动态链接在运行时加载共享库。汇编是机器指令的文本形式，了解寄存器、栈帧、调用约定和跳转指令，有助于调试 core dump 和分析性能热点。
