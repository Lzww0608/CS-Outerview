## 1. 异步编程
异步编程是一种编程范式，允许程序在等待某些操作完成时不阻塞执行，而是可以继续处理其他任务。这对于I/O密集型应用（如网络请求、文件读写）特别有用。

示例：
```rust 
use futures::executor;
use std::time::Duration;
// 异步版本 - 可以并发执行
async fn async_task(name: &str, duration: u64) {
    println!("开始{}", name);
    // 在真实场景中，这里会是异步I/O操作
    tokio::time::sleep(Duration::from_secs(duration)).await;
    println!("{}完成", name);
}
async fn async_example() {
    // 并发执行两个任务
    let task1 = async_task("任务1", 2);
    let task2 = async_task("任务2", 2);
    // 等待两个任务都完成
    futures::join!(task1, task2);
    // 总耗时：约2秒（并发执行）
}
```

## 2. 特点
+ **零成本抽象**：Rust的异步编程通过生成状态机来实现，避免了运行时开销。
+ **无阻塞**：异步函数不会阻塞线程，可以同时处理多个任务。
+ **内存安全**：Rust的所有权系统确保了异步代码的内存安全。

## 3. 核心概念
### Future trait 
​​​`​Future`​​​​ 是Rust异步编程的核心抽象，代表一个可能尚未完成的计算。
```rust
trait Future {
    // Future 完成时值的类型
    type Output;

    // 尝试解析 Future 的值，返回 Poll::Ready(output) 或 Poll::Pending
    fn poll(&mut self) -> Option<Self::Output>;
}
```

## 4. async/await 语法
Rust提供了`async`和`await`语法糖，使得编写异步代码更直观。
```rust
async fn fetch_data() -> String {
    // await 另一个 Future 完成
    let result = some_async_operation().await;
    format!("Fetched data: {}", result)
}

async fn some_async_operation() -> String {
    "Hello, Async World!".to_string()
}
```
### futures-rs 库
`futures-rs`是Rust生态中最流行的异步编程库，提供了丰富的工具和实用程序来构建异步应用。
**核心 traits**：
+ `Future`：表示一个异步计算。
+ `Stream`：表示一个异步序列。
+ `Sink`：表示一个异步数据接收器。

**执行器**：
+ `block_on`：在当前线程上运行一个Future，直到它完成。
+ `ThreadPool`：在一个线程池中运行多个Future。

**组合器**：
+ `join!`：并行等待多个Future完成。
+ `select!`：等待多个Future中的任意一个完成。
+ `map, and_then, or_else`：对Future的结果进行转换和组合。

**通信原语**：
+ `mpsc`：多生产者单消费者通道。
+ `oneshot`：一次性通信通道。

## 5. 异步示例
```rust
use futures::executor::block_on;
use futures::join;
use futures_timer::Delay;
use std::time::Duration;

async fn async_example(name: &str, delay: Duration) -> String {
    println!("Hello, {name}!");
    Delay::new(delay).await;
    println!("Goodbye, {name}!");
    format!("Finished async task for {name}")
}

async fn main_async() {
    println!("Starting async main...");

    let task1 = async_example("Alice", Duration::from_secs(1));
    let task2 = async_example("Bob", Duration::from_secs(2));
    let (result1, result2) = join!(task1, task2);

    println!("Result: {result1}");
    println!("Result: {result2}");
    println!("Async main completed.");
}

fn main() {
    block_on(main_async());
}
```

## 6. 总结
### Poll 状态
+ `Poll::Ready(value)`：Future 已完成，返回结果。
+ `Poll::Pending`：Future 尚未完成，需要等待更多时间。

### 执行模型
+ **协作实调度**：Future 需要自己决定何时让出控制权，允许其他任务运行。
+ **事件驱动**： 基于事件循环和回调机制。
+ **状态机**：编译器将 async 函数转换为状态机，管理异步操作的状态。

### 内存模型
+ **Pin**：确保 Future 在内存中不会被移动，允许安全地引用自身。
+ **Send + Sync**：Future 可以跨线程安全地发送和共享。

## 7. 计算 Fibonacci 数列
```rust

use futures::executor::block_on;
use futures::future::join_all;
use futures_timer::Delay;
use std::env;
use std::time::Duration;

const MAX_TERMS: usize = 187; // F(186) still fits in u128

fn fibonacci(index: usize) -> u128 {
    match index {
        0 => 0,
        1 => 1,
        _ => {
            let mut a = 0u128;
            let mut b = 1u128;
            for _ in 2..=index {
                let next = a + b;
                a = b;
                b = next;
            }
            b
        }
    }
}

async fn fibonacci_async(index: usize) -> u128 {
    // Add an async boundary so multiple tasks can be awaited together.
    Delay::new(Duration::from_millis(1)).await;
    fibonacci(index)
}

async fn fibonacci_series_async(n: usize) -> Vec<u128> {
    let tasks = (0..n).map(fibonacci_async);
    join_all(tasks).await
}

fn parse_n() -> Result<usize, String> {
    let Some(arg) = env::args().nth(1) else {
        return Err("用法: cargo run -- <n>".to_string());
    };

    let n: usize = arg
        .parse()
        .map_err(|_| "n 必须是正整数，例如: cargo run -- 10".to_string())?;

    if n == 0 {
        return Err("n 必须大于 0".to_string());
    }

    if n > MAX_TERMS {
        return Err(format!(
            "n 过大（最大 {}），再大将导致 u128 溢出",
            MAX_TERMS
        ));
    }

    Ok(n)
}

fn main() {
    let n = match parse_n() {
        Ok(value) => value,
        Err(message) => {
            eprintln!("{message}");
            std::process::exit(1);
        }
    };

    let values = block_on(fibonacci_series_async(n));

    println!("Fibonacci 前 {n} 项:");
    for (i, value) in values.iter().enumerate() {
        println!("F({i}) = {value}");
    }
}
```
