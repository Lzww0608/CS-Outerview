# Memory Alignment（内存对齐）

## 定义与作用
内存对齐是指数据在内存中的起始地址为特定 2 的幂整数倍的约束，解决非对齐访问导致的硬件性能惩罚甚至程序崩溃问题。

## 核心原理
- CPU 访问内存时以固定宽度（如 8 字节）的"颗粒"进行，若数据跨颗粒边界则需要多次内存访问，再拼接结果
- 现代 CPU 要求基本数据类型按自身大小对齐：char(1)、short(2)、int(4)、long(8)、指针(8)、SIMD 向量(16/32/64)
- 编译器自动在结构体字段间插入填充字节（Padding）以满足对齐要求，这会导致结构体"膨胀"

## 软硬件协同点
1. **硬件非对齐访问支持**：x86 支持非对齐访问但有 2-3 倍性能惩罚；ARMv7 及以前版本非对齐访问直接触发 Bus Error 导致崩溃
2. **编译器对齐控制**：通过 `__attribute__((aligned(N)))`（GCC）或 `alignas(N)`（C++11）指定变量或类型的对齐要求，编译器据此安排内存布局
3. **内存分配器对齐保证**：malloc 保证至少 8/16 字节对齐；posix_memalign / aligned_alloc 支持自定义对齐大小，需用户显式调用
4. **SIMD 指令对齐要求**：AVX-512 的 `vmovdqa32` 要求 64 字节对齐，使用非对齐版本 `vmovdqu32` 虽能工作但性能下降 15-30%

## 典型应用场景
1. **高性能内存分配器**：jemalloc 按不同大小类（Size Class）管理内存，每个大小类严格对齐到自身大小，确保分配的对象天然满足对齐要求
2. **网络报文缓冲区**：DPDK 要求报文缓冲区（mbuf）按 64 字节对齐，配合 DMA 直接写入到缓存友好的地址，避免网络控制器与 CPU 间的数据搬运开销
