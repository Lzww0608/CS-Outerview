# Branch Prediction（分支预测）

## 定义与作用
分支预测是 CPU 硬件动态猜测条件分支的跳转方向，提前执行预测路径的指令，解决流水线处理器中分支指令导致的流水线停顿（Bubble）问题。

## 核心原理
- 现代 CPU 是 15-30 级深度流水线，分支指令在第 N 级才能确定是否跳转，预测错误需要清空流水线，浪费约 15-20 个时钟周期
- 分支预测器（如 TAGE、Perceptron）记录分支的历史跳转模式，动态调整预测准确率，现代 CPU 预测准确率可达 95% 以上
- 编译器也可通过 `__builtin_expect` 提供静态分支预测提示，配合硬件预测
- 分支预测错误惩罚 = 流水线深度 × 时钟周期，典型值约 10-20ns

## 软硬件协同点
1. **分支目标缓冲区（BTB）**：CPU 硬件维护 BTB，记录每条分支指令的地址和上次跳转目标，取指阶段直接从 BTB 预测下一条指令地址
2. **返回地址栈（RAS）**：专门优化函数返回的预测，调用时将返回地址压栈，返回时从栈顶弹出预测，准确率接近 100%
3. **编译器分支重排**：GCC 配合 Profile-Guided Optimization（PGO）收集运行时分支数据，将热路径（经常执行的分支）放在顺序执行位置，冷路径放在跳转位置，利用 CPU 的"默认不跳转"预测偏好
4. **条件移动（CMOV）**：对于简单分支，编译器可生成 CMOV 指令（条件移动），完全消除分支，将控制依赖转化为数据依赖，彻底避免预测错误惩罚

## 典型应用场景
1. **JSON 解析优化**：RapidJSON 使用 SIMD 指令和计算跳转（Computed Goto）减少分支，并通过 PGO 优化分支布局，解析速度比传统实现快 3-5 倍
2. **高频交易风控引擎**：将风控规则编译为无分支的位运算序列，使用 CMOV 替代所有 if-else，确保执行时间完全确定，避免分支预测错误导致的延迟抖动
