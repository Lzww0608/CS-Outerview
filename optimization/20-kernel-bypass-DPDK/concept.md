# Kernel Bypass / DPDK（内核旁路 / 数据平面开发工具包）

## 定义与作用
内核旁路让应用程序直接访问网卡硬件，绕过内核网络协议栈的所有开销；DPDK 是实现内核旁路的工业级标准工具集，解决通用操作系统网络栈处理 40Gbps+ 高速网络时的性能瓶颈。

## 核心原理
- 传统内核网络栈路径：网卡硬中断 → 软中断 → 协议栈处理 → 套接字缓冲区 → 拷贝到用户态，每跳都有开销
- DPDK 采用 UIO/VFIO 驱动将网卡寄存器映射到用户空间，应用直接读写硬件队列
- 轮询模式（Poll Mode Driver）替代中断，避免中断上下文切换开销
- 大页内存、CPU 亲和性、无锁队列等技术综合运用，达到线速处理能力

## 软硬件协同点
1. **VFIO 硬件直通**：VFIO（Virtual Function I/O）利用 IOMMU 硬件将设备直接分配给用户空间，DMA 安全可控，无需 root 权限即可访问硬件
2. **网卡多队列（RSS）**：网卡硬件根据报文五元组（源IP/目的IP/源端口/目的端口/协议）计算哈希值，分发到不同接收队列，每个队列绑定一个 CPU 核，真正并行处理
3. **SR-IOV 虚拟功能**：支持 SR-IOV 的网卡可将一个物理网卡虚拟出多个 VF（Virtual Function），每个 VF 可独立分配给虚拟机或应用，直接硬件访问，性能接近裸金属
4. **硬件卸载能力**：DPDK 利用网卡的硬件卸载（Checksum Offload、TSO/GSO、VLAN Tagging、Crypto Offload），将报文处理任务卸载到硬件，CPU 零开销

## 典型应用场景
1. **软件定义网络（SDN）**：Open vSwitch 使用 DPDK 加速数据平面，25Gbps 网卡可跑满线速转发，而内核 OVS 只能达到 5Gbps
2. **高性能负载均衡器**：CloudFlare 的 L4 负载均衡器使用 DPDK，单台服务器可处理 10Mpps 报文，支持 100Gbps 流量，延迟稳定在微秒级
